## 2. Найденные амбигуости / дыры (с формулировками фикса)

В текущем состоянии файла **MAJOR нет**: все найденные неоднозначности не меняют вердикт на
ЭТИХ данных (V3 fired ⇒ V3_PATHOLOGY при любом из вариантов реализации), но влияют на
воспроизводимость/отчётные числа.

**MINOR**
1. **MINOR-1 (gap-конвенция):** правило «отделение на ≥ 1 шага сетки (v2-правило)» не фиксирует
   способ замера. Машина v2 реализовала `gap_steps` как «точка CI → ближайшая граница
   интервала» (point-to-interval: в L1-случае дало бы **7**, а не 6); pre-reg ТЗ (6/0/3)
   соответствует interval-to-interval (мин. расстояние между граничными узлами двух
   locator-интервалов). Вердикт идентичен (оба ≥ 1 в L1/L3, 0 в L2), но отчётное число
   зависит от конвенции — при несовпадении с pre-reg сработал бы ложный ¬ожидание-протокол.
   **Фикс:** в п.2: «gap = мин. число шагов сетки между граничными узлами двух
   locator-интервалов; общая граница или общая клетка ⇒ gap = 0 (не отделено)».
2. **MINOR-2 (единица per-seed span):** «span > 1 шага сетки» — в шагах или в клетках?
   Данные: клетки L3 = {idx5, idx6, idx5} → span-в-шагах = 1 (правило НЕ срабатывает),
   distinct cells = 2 (сработало бы). Отчётное поле; вердикт не меняется.
   **Фикс:** «span = (max − min) индексов per-seed L3-клеток в шагах сетки; на этих данных:
   1 шаг ⇒ правило не срабатывает (отчётно)».
3. **MINOR-3 (L3 tie):** две клетки с равной max-скоростью — не определено, какая берётся.
   На данных тиев нет (dip: 41.9745 уникален; per-seed: 61.52/42.92/36.18 уникальны).
   **Фикс:** «tie ⇒ клетка с меньшим λ; множество тиевых клеток — отчётное».
4. **MINOR-4 (V3 argmin tie):** минимум dip на двух соседних λ — не определено. На данных
   уникален (seed-avg 0.70; per-seed 0.70/0.70/0.65 — все уникальны).
   **Фикс:** «λ* = минимальный из argmin-клеток; множество аргминимума — отчётное».
5. **MINOR-5 (per-seed C2-агрегация):** агрегация eff_rank внутри сида не указана. Pre-reg-числа
   (5.86/6.46/7.49) = медиана по 6 докам; C2 истинно для всех сида и по медиане, и по среднему
   (6.22/6.64/7.80 < 13.199), т.е. вердикт робастен, но число зависит от агрегации.
   **Фикс:** «per-seed C2: медиана по 6 докам (каноническая конвенция seedavg)».

**NIT**
1. «nll: 2.30 vs 0.876» — 0.876 = медиана, порог правила = 2×med = 1.7516. Формулировка:
   «nll: 2.3006 > 2×0.8758 = 1.7516».
