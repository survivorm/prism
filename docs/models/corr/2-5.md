### 1.3. E5: «одна строка» или отдельная функция?

**Позиция Спикера 3:** «одна строка в §5.1 — часть вменяемости рецептуры».

**Позиция Спикера 1:** «отдельная функция `align_signs_and_columns` внутри модуля `transport` (M5), с собственным юнит-тестом».

**Мой вердикт:** Спикер 1 прав по реализации, Спикер 3 прав по статусу. Это **не новая сущность** и не новый тест — это **предусловие корректности** уже принятой рецептуры. Но реализация требует:

1. Выравнивание знаков: `sign(u_j(t)ᵀ·u_j(t+1)) → +1` до полярного фактора.
2. Сопоставление столбцов: по максимуму `|U_tᵀU_{t+1}|` (венгерский алгоритм), не по рангу σ. Флаг `order_cross` при расхождении.
3. Проверка близости: `‖log Q_U‖_F` мал, спектр $Q_U$ вдали от −1. Иначе флаг `unstable_transport`.
4. Артефакт: все флипы/перестановки → в `E40_5_transport.json`.

Это **одна функция** внутри `transport`, не отдельный модуль. Юнит-тест: синтетика (случайная ортогональная $Q$ с известным $\log Q$ → реконструкция через align+transport → сравнение). Стоимость: секунды на CPU.

В пререгистрации 0.5 записываю: «транспортная рецептура включает `align_signs_and_columns` как предусловие; без него `log Q` не определён при флипе знака или перестановке». Это не новая строка в очереди — это спецификация уже принятой строки.
