## C2. Mean-тест на бимодальной статистике — «kill» не установлен ⛔ (может флипнуть)

Пре-рег kill-условие (ТЗ T0.3): «**одинаковое распределение** у loopy и чистых». Тест: `perm_two_sample` на **разности средних**. Это разные утверждения.

Мой пересчёт из артефакта:

| | mean (в тесте) | median (в strata) | mean − median | CI медианы |
|---|---:|---:|---:|---|
| du loopy | 0.6274 | **0.5214** | **+0.106** | [0.490, **0.725**] |
| du clean | 0.6283 | **0.6125** | +0.016 | [0.599, 0.650] |
| h_raw loopy | 0.6269 | 0.5214 | +0.106 | [0.489, 0.718] |
| h_raw clean | 0.6278 | 0.6122 | +0.016 | [0.597, 0.651] |

```
d_obs(mean)   = −0.00092   → p = 0.965
d(median)     = −0.09106   → в 100 раз больше
```

Медиана loopy имеет CI шириной 0.235 (clean — 0.050) ⇒ **распределение loopy бимодально**, медиана нестабильна. У `v_tangent` loopy CI медианы вообще [0.484, **1.000**] — прямая подпись двух мод (одна у 1.0).

Средние «случайно» совпали: у loopy смесь мод ~1.0 и ~0.45 даёт mean ≈ 0.63, у clean унимодальная 0.61–0.63. **Тест на средних слеп к этому по построению.**

**Фикс:** пре-регистрировать distributional-тест (KS / Anderson–Darling permutation) **или** permutation на разности медиан + тест на разброс. По текущим числам медианный тест, скорее всего, значим ⇒ вердикт может стать `refuted (различимо, направление против пре-рега)`, а не `kill`.

## C3. Null был почти форсирован: `odd_frac` различает только period-2 ⛔ (G10)

Мой расчёт для чистого цикла периода p, ρ(k)=cos(2πk/p), K=96:

| p | odd_frac | | p | odd_frac |
|---:|---:|---|---:|---:|
| 1 | нет отриц. площади | | 8 | 0.586 |
| **2** | **1.000** | | 12 | 0.464 |
| 3 | 0.500 | | 16 | 0.520 |
| **4** | **0.000** | | 20 | 0.487 |
| 5 / 6 / 7 | **0.500** | | **24** | **0.509** |

Taper (1−k/N) не меняет ничего (третий столбец совпадает).

**Известные периоды лупов в проекте: 1, 5, 7, 8, 24** (`wiki_0/4` p=1, `math_12` p=5, `code_11` p=5, `code_13` p=7, `chat_15` p=8, `code_1` Δ(24)=1). **Ни один не равен 2.** Для p∈{5,7} odd_frac = ровно 0.500, для p=24 — 0.509.

То есть пре-рег «у loopy отрицательная площадь на нечётных k» **не мог выполниться** на этом пуле: он проверяет period-2, а лупы имеют другие периоды. Наблюдаемые 0.52 (медиана loopy) — ровно то, что даёт смесь p=5/7/24.

Это нарушает G10 («ни один исход не форсирован тождеством/архитектурой»): null форсирован **несоответствием estimand и известного состава пула**, и это не объявлено.

**Фикс:** period-matched estimand — для каждого дока взять его собственный p (из Δ(k)≈1 / rep-n) и мерить долю отрицательной площади на лагах `k ≡ p/2 (mod p)` против остального. Тогда «периодический носитель» becomes falsifiable, а не тавтологично мёртв.

## C5. Estimand не K-гомогенен; артефакт того же порядка, что и эффект ⚠️

`K = max{24,32,96} ≤ N−1` per doc, а `odd_frac`/`tail_frac` считаются по `k=1..K`. **Ограничения K=96 в первичном тесте нет** (в T0.1 P4 оно было: исключены `cor_w11`, `cor_w8`). Оба этих дока сидят в `docs_C`.

Что это значит (мой расчёт):

| K | нечётных лагов | tail покрывает |
|---:|---:|---|
| 24 | 12 | k=9..24 (16 лагов) |
| 32 | 16 | k=9..32 (24) |
| 96 | 48 | k=9..96 (88) |

На clean-подобном спектре (лаг1 −0.37 + плоский хвост −0.008/лаг):

```
K=96: odd_frac=0.660  tail=0.623
K=32: odd_frac=0.793  tail=0.311
сдвиг на коротко-K док: odd +0.133, tail −0.312
2/53 доков → сдвиг mean_C = +0.0050
наблюдаемый |d_obs| = 0.00092   ← в 5 раз МЕНЬШЕ артефакта
```

**Наблюдаемый нуль лежит внутри погрешности, внесённой неоднородностью estimand.** Плюс `tail_frac` для K=32 усечён втрое — вторичное сравнение хвостов тоже затронуто. Дополнительно: T-нормировка даёт taper (1−k/N), а N=82..383 ⇒ двойная зависимость от длины.

**Фикс:** первичный пул = `{K=96}` (как T0.1 P4), либо отчитывать `odd_frac` на фиксированной полосе k=1..24 для **всех** доков + K=96 как отдельный estimand.

## C6. L/C конфаундирован с источником/доменом; matched-теста нет ⚠️

Разложение по `docs_L`/`docs_C`:

| | wiki | own | code | chat | math | corpus |
|---|---:|---:|---:|---:|---:|---:|
| **L** (41) | **15** | **13** | 8 | 5 | 0 | 0 |
| **C** (53) | 1 | 1 | 8 | 11 | **16** | **16** |

L = 68% own+wiki; C = 60% corpus+math. Контраст «loopy vs clean» ≈ «свои-жадные+wiki vs корпус+math». Внутридоменно L vs C возможны только chat (5 vs 11) и code (8 vs 8) — **оба n<12 по L**.

⇒ первичный контраст **не идентифицирован отдельно от источника/домена**. Это надо объявить, а не подавать как чистый тест вырожденности. Source-стратификации (gen-only / +corpus / +own), которую я требовал для AT0_1, здесь нет вообще.

Отдельно: **corpus (16 доков, все в C) без токенов** ⇒ `degen` для них работает только по `mcos`, а `add_flags` выбрасывает `mshare` (`fl, mcos, _ = degen(...)`). Док с 93% одного токена и mcos<0.95 попадёт в «чистые». Это **смещает к нулю** — то есть работает в пользу полученного `kill`.

## C7. `layer_type_slice`: непарный тест на парных данных ⚠️

```python
rows.append((nm, fu, li))          # fu, li — по ОДНОМУ доку
res = perm_two_sample(fu, li)      # непарная перестановка пула
```

Full и linear считаются на **одном и том же доке** ⇒ дизайн парный. Непарная перестановка ломает обменяемость (под H0 значения обменяемы **внутри** дока, не между доками). Нужен paired sign-flip permutation. Сейчас d=−0.0158, p=0.368; парный тест мощнее и может дать другой ответ.

Плюс коллизия имён: `mean_L`/`mean_C` здесь означают full/linear, а во всём остальном артефакте — loopy/clean. Читать опасно.

## Что делать

**Без новых форвардов, постобработкой store:**

1. Первичный пул → `{K=96}`; `odd_frac` дополнительно на фиксированной полосе k=1..24 для всех.
2. Пре-регистрировать **distributional** тест (KS/AD permutation) + медианный; отчитать оба. Mean-тест оставить как secondary.
3. Period-matched estimand: доля отрицательной площади на `k ≡ p/2 (mod p)` по собственному p дока.
4. Source-стратификация primary (gen-only / +corpus / +own) + внутридоменные chat/code с явным `n<12`.
5. `layer_type` → paired sign-flip.
6. `v_tangent` descriptive → `forced_outcome: true`, p не цитировать.
7. Переписать вердикт.

**Как я бы сформулировал честный итог сейчас:**

> Period-2 как носитель отрицательной площади — **не подтверждён и не мог подтвердиться**: измеренные периоды лупов (1, 5, 7, 8, 24) дают `odd_frac` ≈ 0.5 по построению. При этом локация отрицательной площади у loopy и clean **резко различна и инвертирована относительно пре-рега**: loopy несут её в хвосте k≥9 (0.89), чистые — на лаге 1 (0.335 против 0.074, 4.5×, CI не пересекаются). Распределение `odd_frac` у loopy бимодально (CI медианы [0.49, 0.72]), у clean унимодально ([0.599, 0.650]); равенство средних — артефакт смеси, а не одинаковость распределений.

Это **положительный результат**, а не kill. И он согласуется с T0.1: у `v_tangent` clean единственный отрицательный лаг — k=1, то есть «чистый путь платит на лаге 1», а лупы размазывают плату по своему периоду.

**VERDICT: REVISE** — вердикт `kill` в текущей формулировке не поддержан ни тестом (mean ≠ distribution), ни данными (k1/tail различены), ни дизайном (null форсирован несоответствием period-2 известным периодам).
