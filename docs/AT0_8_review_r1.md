## Пропущено (с аргументом — «спорь»)

- **«dip(λ=1)=−0.179 против E-64 P0-анкора −0.07±0.015 — расхождение»:** НЕ баг. P0-анкор
  — другой слой/режим (батарея e64 валидировала dip на своём наборе слоёв [1,5,11,17,23]
  на corpus-сканах; здесь — h23 на первых 256 ток. wiki_0). Наш L_H=23 = LAYERS[-1] e64 —
  конвенция совпадает, абсолютный dip не переносится.
- **«loopy=1 на base — артефакт z-score/константной серии»:** проверено по тексту — base
  реально зациклился на prompt wiki_0[:32] («…designed to help you master the art… The
  program is designed to help you mas…») — луп фраз, h-шаги повторяются с периодом лупа →
  ACF-спайк. λ=0 (коллапс в повторение одного токена) — loopy=0: серия почти постоянна,
  vpath-шаги <1e-6 отбрасываются, кривая вырождается — конвенция machines e64, зафиксирована
  в пре-реге («ACF-кривая той же curves_series-машины»).
- **«p_raw при ns<4»:** `separated` требует ns==3 (все сида) И CI без пересечения — при ns<3
  p_raw лишь записывается (вторичная статистика), verdict не берёт. Согласовано с пре-регом.
- **«S2 sha-проверка после генерации»:** модель между генерацией и проверкой не меняется
  (greedy без мутации весов) — проверка валидна; S2-референс (BASE_SHAS) зафиксирован ДО
  первого set_interp (проверено: в main между load и seed-циклом).
- **«NaN в hump/plateau»:** main-доки ≥64 ток. (пин n16/min64) → len(c)≥21 → hump/plateau
  finite по построению; S5 всё равно ловит.
