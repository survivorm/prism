# ТЗ: E-33r. Gauge anatomy: где живёт gauge и что выживает после P(p)

Формат: название → цель и идеология → математика → подводные камни → сбор → интерпретация → критерии остановки → артефакты. Все символы — по §2 paper.md. «r» = redesign; не путать с исходным E-33 (см. Exp33.md), который оставлен как отрицательный контроль.

## Цель и идеология

**Проблема исходного E-33.** Текущий preflight мерил транспорт gauge-вектора `u_g = J Jᵀ·1/‖·‖` под действием `P(p)`. Но `u_g` коллинеарен uniform-направлению `1`, а `P(p)·1 = 0` точно. Транспорт шёл по аннигилированному вектору; наблюдаемый `cos ≈ 0.005–0.056` — это шум, а не результат. P-value `0.0445` на L23 — флуктуация одного слоя из пяти, не проходит Bonferroni.

**Идеология редизайна.** Вместо бинарного «транспорт ≠ случайный» — **анатомия gauge-режима**: где он локализован, сколько энергии J уносит, что именно убивает оператор `P(p)`, и становится ли дифференциальная структура (после снятия gauge) устойчивее — по позициям и по глубине. Три содержательных вопроса, на которые исходный E-33 ответить не мог:

1. **Где gauge сидит?** — топ-мода ESG = uniform-направление или что-то другое?
2. **Что выживает после P(p)?** — сколько энергии, какие моды, сохраняется ли rank?
3. **Что выжившее делает?** — устойчивее ли gauge-free структура по Δ (позиции) и по глубине по сравнению с raw J?

Идеология: редизайн превращает E-33 из изолированного preflight в **связку E-28 ↔ E-35** через общее сравнение raw/gauge-free подпространств. Ранее измеренные `Δ_SVD`, `κ`-Procrustes, `C_top-r` считались на raw `J` — теперь те же метрики считаются на `P(p_t)·J_t` и сопоставляются.

**Ожидание (гипотеза).** На mid-слоях (L6–L18) gauge-компонента — это uniform-шум, и её снятие делает подпространства стабильнее. На L23 gauge-компонента мала (E-10a: uniformity ≈ 0.5), факторизация точна (E-35: level 2 = level 3), и gauge-free ≡ raw. Это ожидание проверяемо и содержательно — в отличие от «тривиально / нетривиально».

## Математика

**Gauge-оператор.** `P(p_t) = diag(p_t) − p_t p_tᵀ`; не проектор (`P² ≠ P`), ker = span{𝟙}, rank = K−1.

**Gauge-free Jacobian.** `J^(p)_t = P(p_t)·J_t` — канонический Якобиан выходного распределения `∂p/∂h` (paper.md, §8 `[L-gauge]`). Всё, что ниже, сравнивает статистику `J_t` (raw) и `J^(p)_t` (gauge-free) на одной и той же траектории.

**Шесть срезов.**

**Срез 1. Локализация gauge-режима** (per layer, per position).

- `u_top(t)` — топ-левый сингулярный вектор `J_t J_tᵀ` (точный, не cheap proxy `u_g`).
- `uniformity_0(t) = ⟨u_top(t), 1/√K⟩²` — доля uniform-направления в топ-моде.
- `gauge_share(t) = λ_top(t)·uniformity_0(t) / trace(J_t J_tᵀ)` — вклад топ-моды в uniform-энергию (E-10a top-1 proxy; точная формула — ниже).
- `gauge_share_exact(t) = Σ_k (u_kᵀ·1)²·λ_k / Σ_k λ_k` — точная (E-14), по всему спектру.
- `align(u_top, u_g_cheap) = |⟨u_top, J Jᵀ·1/‖·‖⟩|` — совпадает ли cheap-proxy с настоящим топом.
- `align(u_top, p_t) = |⟨u_top, p_t/‖p_t‖⟩|` — совпадает ли gauge с выходным распределением.

**Срез 2. Что выживает после P(p)** (per layer, per position).

- `survive_frac(t) = ‖P(p_t)·J_t‖_F / ‖J_t‖_F`.
- `kill_frac(t) = 1 − survive_frac(t)`.
- `σ_gf(t) / σ_raw(t)` — топ-8 сингулярных чисел `P(p_t)J_t` vs `J_t` (по компонентам).
- `rank_ratio(t) = rank(P(p_t)·J_t) / rank(J_t)` — численно через `σ_i / σ_max > 1e-6`.

**Срез 3. Устойчивость выжившей структуры по позиции** (per layer, per Δ ∈ {1, 4, 8, 16}).

- `Δ_SVD_raw(t; Δ, r)` — max главный угол между топ-r правыми подпространствами `J_t` и `J_{t+Δ}` (E-28 метрика).
- `Δ_SVD_gf(t; Δ, r)` — то же для `P(p_t)J_t` и `P(p_{t+Δ})J_{t+Δ}`.
- `Δ_gain(t; Δ) = Δ_SVD_raw − Δ_SVD_gf` — **выигрыш от снятия gauge**. Положительный = gauge-free устойчивее.
- Агрегация: медиана и IQR по парам внутри документа, затем медиана по документам (протокол E-34).

**Срез 4. Реконструкция «убитого»** (per layer, per position).

- `K_t = J_t − P(p_t)·J_t = (I − P(p_t))·J_t` — «убитая» компонента.
- SVD `K_t`: топ-4 сингулярных числа `σ(K_t)`, alignment топ-левого вектора с `1`.
- `rank_K(t) = #{σ_i(K_t) / σ_1(K_t) > 1e-6}` — ранг «убитого».
- `‖K_t‖_F / ‖J_t‖_F = kill_frac(t)` (согласованность со срезом 2).

**Срез 5. Depth coherence: raw vs gauge-free** (per layer pair (a, b) ∈ {(6,12),(12,18),(18,22),(22,23)}).

- `v_top^raw(l, t)` — топ правый сингулярный вектор `J_t^{(l)}`.
- `v_top^gf(l, t)` — топ правый `P(p_t^{(l)})·J_t^{(l)}`.
- `cos_depth_raw(a, b) = median_t |⟨v_top^raw(a,t), v_top^raw(b,t)⟩|`.
- `cos_depth_gf(a, b) = median_t |⟨v_top^gf(a,t), v_top^gf(b,t)⟩|`.
- `depth_gain(a, b) = cos_depth_gf − cos_depth_raw` — выигрыш в межслойной когерентности от снятия gauge.

**Срез 6. Смыкание с E-28 / E-35.**

- Для L23: `Δ_SVD_gf` vs `û`-траектория (E-35). Ожидание: совпадение (факторизация точна).
- Для L6–L22: `Δ_SVD_gf` vs E-28 `Δ_SVD` (raw). Ожидание: gf > raw (устойчивее), но картина «нить» сохраняется.
- `Δ_gain` vs `gauge_share` — коррелирует ли выигрыш с долей gauge.

## Подводные камни

1. **P(p) — не проектор.** `‖P(p)·J‖_F` нормирован как отношение к `‖J‖_F`; абсолютные значения `σ_gf` не имеют собственного смысла, сравнение только относительное.
2. **Numeric rank при малых σ.** Порог `σ_i / σ_1 > 1e-6` для fp32 достаточен, но на L22/L23 (J почти factored) возможны вырождения — фиксировать `NaN`, не «0».
3. **Sentinel-маска — только endpoints.** Исходный E-33 маскировал всю цепочку `[t..t+L]`, что при `sentinel ≈ 0.5` давало `n_docs = 1` для `L = 8`. В редизайне: пара `(t, t+Δ)` валидна, если `sent[t] = sent[t+Δ] = False` (endpoints). Промежуточные позиции не маскируются — `P(p_t)` определён для любого `p ∈ Δ^K`, включая суб-стохастический `p_RAW`.
4. **Согласованность K при SVD.** `J_t` — [K, D]; `P(p_t)·J_t` — [K, D]; SVD `full_matrices=False` → `[min(K, D)] = K` сингулярных чисел. Не путать с эконом-вариантом.
5. **Δ_SVD на top-r.** r фиксирован в основной сетке {16}; sweep {1, 8, 32} — опционально. Согласован с E-28.
6. **Сравнение с предыдущим E-33.** Старые `pos1`/`pos8` остаются в JSON как `degenerate_test_result` (явно помечены); не выбрасывать.
7. **Depth leg — не транспорт.** `cos(v_top^raw(a), v_top^raw(b))` — это когерентность, не параллельный перенос (нет `D_l` в кэше). Явно помечено в JSON `note`.
8. **Sentinel и стопроцентное вырождение.** Если `p_t` близко к uniform, `P(p_t)·J_t` может давать `survive_frac → 0`; фиксировать как `NaN`, не как 0.

## Как

1. Загрузить exp27b dense-кэш (`JR`, `P128`, `P128_RAW`, `H`, `U128`) для слоёв {6, 12, 18, 22, 23}.
2. Для каждого слоя и документа — батченный `torch.linalg.svd(J_t)` на `[S, K, D]` (или через `eigh(J Jᵀ)` для `u_top` + `V_r` для правого, как в E-31 `vtop16`).
3. То же для `P(p_t)·J_t` (элементарное произведение по батченной оси позиций).
4. Срезы 1–6 — из этих SVD + `P(p_t)` операций.
5. Агрегация: per-doc → медиана/IQR → медиана по 32 документам (протокол E-34).
6. Sentinel: endpoints-only, доля исключённых пар фиксируется.
7. Selfcheck: на синтетике `J = u·vᵀ` (rank-1): `uniformity_0 = ⟨u, 1/√K⟩²`, `kill_frac = uniformity_0` точно; `Δ_SVD_gf = Δ_SVD_raw` при `p = uniform`.

**Ключевые формулы в коде:**

```python
def gauge_share_exact(Jt):               # [K, D]
    U, s, _ = torch.linalg.svd(Jt, full_matrices=False)
    one = torch.ones(Jt.shape[0], device=Jt.device) / Jt.shape[0] ** 0.5
    return float(((U.T @ one) ** 2 * s ** 2).sum() / (s ** 2).sum())

def survive_frac(Jt, p):
    P = torch.diag(p) - p.unsqueeze(1) * p.unsqueeze(0)
    PJ = P @ Jt
    return float(PJ.norm() / Jt.norm())

def delta_svd(V_a, V_b):                  # [D, r] ортонорм
    M = V_a.T @ V_b
    sv = torch.linalg.svdvals(M).clamp(max=1.0 - 1e-12)
    return float(torch.acos(sv).max())
```

## Интерпретация

| Паттерн | Что означает | Следствие |
|---|---|---|
| `uniformity_0 ≈ 0.95` на L6–L18, `≈ 0.5` на L23 | Топ-мода ESG = uniform-направление на mid-слоях, дифференциальная на выходе | Согласовано с E-10a/E-14; E-33 даёт точную картину по позициям |
| `gauge_share ≈ 0.2–0.4` на L6–L18, `< 0.1` на L23 | Uniform несёт заметную долю энергии в середине | Квантифицирует «сколько J — gauge» |
| `survive_frac ≈ 1 − gauge_share` | P(p) убирает именно gauge-компоненту | Подтверждает селективность оператора |
| `rank_ratio ≈ (K−1)/K` | P убивает ровно 1 направление (uniform) | Gauge = чистая uniform мода |
| `rank_ratio < (K−1)/K` | P убивает больше одной моды | Gauge переплетён с differential; `P` — не только uniform-removal |
| `rank_K(t) = 1` на mid-слоях | «Убитое» — чистая uniform-мода | Картина «gauge = uniform shift» корректна |
| `rank_K(t) > 1` на L6/L23 | Gauge entangled | Требует внимания в квантовании: защита uniform не достаточна |
| `Δ_gain > 0` (gf устойчивее raw) | Gauge — шумовая компонента, её снятие стабилизирует | Подтверждает, что gauge мешает позиционной стабильности |
| `Δ_gain ≈ 0` | Gauge не влияет на устойчивость | Gauge и differential ортогональны по стабильности |
| `depth_gain > 0` | Gauge-free топ-правые когерентнее по глубине | Gauge ухудшает межслойное согласование |
| `Δ_gain(L23) ≈ 0` | На L23 факторизация точна (E-35), gauge-free ≡ raw | Согласовано с E-35 |
| `Spearman(Δ_gain, gauge_share) > 0.5` | Выигрыш растёт с долей gauge | Внутренняя согласованность срезов |

**Итоговый verdict** — качественная картина (не бинарный):

```
Gauge mode = uniform direction (uniformity_0 ≈ 0.95) на L6–L18; смешанный на L23.
P(p) убивает gauge_share ≈ 0.2–0.4 энергии J; rank(P·J) ≈ rank(J) − 1 (mid), 
≈ rank(J) (L23). Gauge-free подпространства устойчивее raw по Δ на mid-слоях 
(Δ_gain > 0), на L23 совпадают. Depth coherence gauge-free выше raw на 1.2–1.5×.
```

## Критерии остановки

- Пилот на L22 и L23 — один прогон, ~10–15 минут CPU.
- Если `gauge_share_exact` совпадает с E-14 (проверка консистентности) → развернуть на все 5 слоёв.
- Если `Δ_gain > 0.05` на ≥ 3 слоях → **это новый содержательный результат**; E-33r входит в основной §18 как карта «raw vs gauge-free устойчивость».
- Если `Δ_gain ≈ 0` везде и `rank_ratio = (K−1)/K` везде → E-33r закрывается как подтверждение «gauge = чистая uniform мода, тривиальна» (но с количественной картиной, не «≈ 0.005»).
- Отрицательный контроль (`pos1`, `pos8` с endpoints-маской) — оставлен, отчёт включает как `degenerate_test_result`.
