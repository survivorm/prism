## 1. Четыре расхождения между 1-6 и 2-6 — вердикты

**1.1. Flat-null для ESG — снимаю, побеждает позиция 2-6 §1.5.** Аргумент провенанса решающий: если плоский спектр в E-27.6 T6 измерен на матрицах сходства / кросс-сэмпловых грамианах, то предпосылка «спектр ESG плоский» не заработана, и третий «фундаментальный» нуль для пер-сэмпловых ESG вводить нечем. Для ESG законные нули уже есть: суррогат E-34 (Q^T diag(√ESG_ii) — рандомизация векторов при сохранении собственных значений), Haar-подпространства, Wishart/MP для формы. «Плоскость» остаётся **диагностическим нулём для матриц сходства** — с явной меткой объекта. Заметьте, это же почти закрывает противоречие №3 моего реестра (98–99% нормы vs r_eff = 24–31/31): если r_eff из той же T6-карточки, он вообще не про ESG, и reconciliation не нужен. Аудит 0.1 фиксирует.

**1.2. R(l) — статус по 2-6.** Диагностика, не порядок параметра: R_raw(l) и R_gf(l) на E_K = J^(p)(J^(p))^T (или после удаления топ-gauge-моды), с явной оговоркой. Статус «порядок параметра» зарабатывается только немонотонностью и устойчивостью к срезу — после аудита. У 1-6 в 0.6 он назван «числовым порядком параметра» — формулировка снимается.

**1.3. Мастер-кривая — без гейта от 0.2.** Зависимость «2.3 зависит от 0.2» у 1-6 неверна по существу: коллапс (bridge, drift) — модельно-лёгкое утверждение об уравнении состояния, он не опирается на экспоненциальную форму (это мы зафиксировали ещё в таблице выживания). Двойной фит определяет **интерпретацию** коллапса (WLC против generic EOS), но не его запуск. Принимаю формулировку 2-6: «не отождествлять коллапс с доказательством экспоненты» — и снимаю зависимость.

**1.4. «Четыре канала» у 1-6 — на самом деле шесть строк; финализируем четырёхкоординатную метку 2-6 §1.6.** Таблица 1-6 §4.4 (H^R_top … H^ΔW_tail) — это реализованные срезы, а не таксономия. Каноничной делаем метку

[естественный / редактируемый] × [raw / gf / fixP] × [top / tail] × [left / right],

и каждый результат без полной метки не интерпретируется. Это строже и не оставляет щелей.

## 2. Три поправки, выпавшие при консолидации — возвращаю в финальный текст

Это единственное содержательное требование моего круга. Обе консолидации молча потеряли результаты 3-5 §1.2–1.3, и без них финальный текст математически неполон.

**2.1. Кинетическая декомпозиция — пять каналов, не четыре.** 1-6 (0.5) и 2-6 (1.4) пишут «правый транспорт / радиальная / левая / остаток». Но мы установили в 3-5: члены с ΔΣ взаимно ортогональны остальным, однако **лево-правый кросс-член 2·tr(Σ M Σ N)** (M = dU^T U, N = dV^T V, обе антисимметричны) — величина **первого** порядка по углам и не прячется в residual. Финальный протокол отчитывает **пять** каналов:

правый транспорт ‖Σ dV‖² / радиальная ‖dΣ‖² / левая ‖dU Σ‖² / **кросс-член 2tr(ΣMΣN)** / остаток + калибровка.

И — главное — кросс-член не мусор: это σ-взвешенная фробениусова корреляция левых и правых инфинитезимальных поворотов, то есть **дешёвый напарник теста 1.2 (запирание)**. Заперто — кросс-член систематически ненулевой; независимы — нулится в среднем. Один постпроцессинг даёт и декомпозицию движения, и грубую оценку связи сторон до всякой регрессии. При r = 1 кросс-член тождественно нулевой — согласуется с тривиальностью.

**2.2. Разности — в транспортном фрейме.** ΔV и ΔU осмыслены только после выравнивания (t, t+1) транспортом R_t; иначе декомпозиция смешивает физику с выбором базиса. Ни одна из двух консолидаций этого не написала — возвращаю как обязательное условие 0.7.

**2.3. Протокол зазоров — двухосевой, с правильными законами.** У 1-6 нули выписаны смешанно («GOE (полукруг)» — полукруг это закон **плотности**, не зазоров; «Poisson (экспонента)» — экспонента это закон **зазоров**). Финальная форма: ось A — форма плотности (Wishart/MP против spiky), ось B — корреляции зазоров (Wigner surmise β=1 против экспоненты Пуассона); оси независимы, четыре комбинации легальны, и «плоский + шум» даёт Пуассоновские зазоры, а не ВД. Плюс суррогат E-34 и блочный/гейдж-контроль. Сортированный паринг и перестановка пар для запирания у 1-6 §3.7 сохранены — хорошо, они входят в пререгистрацию 1.2 дословно; транспортный фрейм и σ-взвешенные/сырые доли — в пререгистрацию 0.7.

## 3. Статус H5 после ответа 2-6 — фиксирую точно

2-6 §7.1 дал ответ на мой вопрос: по всей видимости, Δ_gf ≈ π/2 — это **L23, правая/скрытая сторона, срез gauge-free P(p_t)J, соседний позиционный угол** (не κ, не агрегат; d_3,gf из E-32r.3 — другая величина и другой срез), с обязательным аудитом кода exp33r перед пререгистрацией. Принимаю.

Следствие для статуса H5 — аккуратная лестница:

1. **Сейчас**: H5 — гипотеза на одном числе с неаудированным объектом.
2. **После аудита 0.1** (если подтвердится чтение 2-6): H5 получает **одно измеренное подспорье** — сырая когерентность листа на L23 (0.289) почти целиком гибнет при проекции аддитивной калибровки (π/2). Это уже факт про углы, а не интерпретация.
3. **После 1.1** (κ_raw vs κ_gf vs κ_fixP): решается, распространяется ли тень с углов на **кривизну**. κ_fixP ≈ 0 — вся голономия p-тень, геометрия переселяется на инварианты; κ_fixP ≈ κ_raw — кривизна инвариантна, H5 в сильной форме умирает (остаётся слабая: углы-да, кривизна-нет).
4. **После 1.2** (запирание на natural-канале): H5 получает и условие смерти из матрицы 2-6 — κ_fixP ≈ κ_raw **и** лево-правая согласованность в естественном канале. Отмечу красиво: это условие гейтится измерением, которого ещё не существует, — тест 1.2 создаст **первое** измерение natural-левой голономии и natural-хвостовых дефектов (закрывая ограничение №6.4 из 2-6). Один тест — три вердикта и закрытие дыры в данных.

## 5. Реестр противоречий — финальный статус

С моей стороны консенсус **достигнут** при условиях 2-6 §8 (все шесть приняты), с четырьмя вердиктами §1 и тремя возвращёнными поправками §2. Замороженная несущая конструкция — в формулировке 2-6 §9:
