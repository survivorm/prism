## 6. Crash-прогоны (до валидного)

1. **r-crash-1**: `spearman` (prism/nulls_and_stats.py) возвращает float, а не tuple —
   unpack-краш на S4. Фикс: `r = spearman(...)` + `None`-ветка.
2. **r-crash-2**: zero-size `np.min` в bin-boundary-поле, когда у дока 0 позиций в бине.
   Фикс: guard `sel.sum()`. Оба фикса — точечная проверка до перепуска; оба crash-рана
   записаны в trackio (status=crash, fin-точки).

## 7. Итог (по пре-регу)

**Вердикты T3.1: TF = (b) suffix-map/weak, генерация = (b) suffix-map/insufficient_power.**
Boundary-версия ТЗ («dip | низкая margin существенно глубже») **не подтверждена** ни на
одной стороне: на чтении dip не зависит от margin (плоско), на генерации направление
есть (CI целиком < 0, 10/14 доков), но эффект слабее пререгистрированного порога 0.02.
Материал «сверх карты» (TЗ-ветка c): **L17-генерация с монотонным обратным трендом** —
описательный факт, для отдельного пре-рега (T3.2/follow-up), вердиктом не является.
Отклонения D1–D3 (пре-рег §5) не изменили интерпретации: D1 (gate 1.000 не
воспроизводится) — единственный нераскрытый факт TЗ §4.2.

**Не делать:** перепуск (детерминировано, S6 recheck); новые слои/базы — отдельный
пре-рег. Следующий кандидат по блоку T3 — T3.2 (аномалия b=2), но только после
решения по L17-наблюдению (возможный объединённый пре-рег).
