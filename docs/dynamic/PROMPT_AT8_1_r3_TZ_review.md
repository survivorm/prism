## Формат ответа

Файл `docs/dynamic/AT8_1_r3_TZ_review.md`:
- шапка: дата, sha256 ревьюируемого (секция ТЗ — цитируй строки), список прочитанных файлов;
- таблица: пункт ТЗ → статус (ок / замечание) + аргумент с числами;
- найденные амбигуости — отдельно, с предложенной формулировкой фикса;
- **VERDICT: PASS | REVISE | FAIL** (REVISE — если есть MAJOR; MINOR/NIT — если вердикт PASS);
- финальная строка ровно: `REVIEW_AT8_1_R3_TZ_DONE`.

Критерии: MAJOR = правило неоднозначно и может дать разный вердикт при разной реализации,
пре-рег-число неверно, пункт патча пропущен. MINOR = недоговорённость, не влияющая на вердикт
на ЭТИХ данных (но влияющая на воспроизводимость). NIT = оформление.
