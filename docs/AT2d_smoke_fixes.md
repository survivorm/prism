## 1. КРИТИЧЕСКИЙ: pre-study CE off-by-one (self-conditional)

Все pre-study-скрипты (hooktest2/pos/power) считали CE как
`−log p(ids[i+1] | logit-позиция i+1)` — т.е. **self-conditional** (токен
предсказывается из контекста, в котором он уже есть). Метрика ТЗ §5 —
стандартная next-token: logit-позиция i → ids[i+1] (позиции 64..126 = цели
65..127, 63 значения).

Последствия (подтверждено замерами):
- pre-study «CE_plain = 14.7 nats» — другая величина; правильная
  CE_plain(wiki,0) = **2.80 nats** (нормально для 0.8B-модели на wiki).
- pre-study «все армы дают ОТРИЦАТЕЛЬНЫЙ ΔCE_P (softening)» — **артефакт**:
  под метрикой ТЗ ΔCE_P(top4) **положителен** (smoke: +0.083/+0.041;
  pf-окно: top +0.026, weak +0.007, randG +0.007 — «удаление направлений
  ухудшает предсказание», стандартный знак).
- pre-study excess(weak4−rand4) = +0.127 (127-окно, buggy CE) — под
  правильной CE и pf-окном: **+0.0002** (≈0). Сигнал «weak-сторона
  softening'ится сильнее top» не подтверждается метрикой ТЗ.

НЕ затронуты: DS1 (max|Δh| = 0.18 — сырой state, без CE), скорости,
детерминизм (S9), G2c (cos=1.0), L23 (G-zero), энергии/dose/KL_pred
(disk-only, без CE).

## 4. DS1-проба — уточнение (TZ r5.1)

TZ r5: «max|Δh| на выходе хука (P_future, top4, per док) ≥ 0.1 (pre-study:
0.18)». Pre-study 0.18 измерен при α=1 (raw-проекция). Реализованная проба
в арме измеряла |α·proj| (α-matched, α≈0.32-0.43) → 0.058-0.078 < 0.1 —
ложный FAIL (плаumbing исправен). Фикс: проба = max|proj| (α=1) в том же
arm-ran без доп. форварда. Smoke-факт: 0.1805/0.1367 → PASS (0.1805 —
совпадает с pre-study). α-пламбинг проверяется отдельно DS5.
