## Вердикт и последствия

**VERDICT: SUBSPACE_CONTROL_FAIL** (пре-рег §4, ветка 0 дерева).

- Клетка T2.1b выполнена как пререгистрировано: центрированная метрика работает
  (R²_c > 0, floor в нуле, DC-пол убран), гейты/провенанс целы, дерево достижимо.
- **Ответ на T2 (считывается ли будущее из weak-компонент J-спектра) НЕ получен**:
  k=0-контроль не пройден на 2/4 слоях (L6 — перевёрнуто), и по пре-реге k≥1
  не интерпретируется. Это провал функциональной проверки разбиения top/weak,
  а не провал readout-метрики (метрика теперь валидна — S6/S6b/R²_c).
- T2.1 **останавливается** (пре-рег §4: «T2.1 останавливать, не переписывать readout»).
- Дальнейшие ходы — только новым пре-регом (T2.1c+): кандидаты на формулировки
  (не дизайн, только гипотезы): (i) layer-стратифицированный T2 (глубокие слои
  L18/L22 — контроль пройден, возможно, T2 пересчитывать только на них);
  (ii) проверка, что Haar-аномалия k=0 — не артефакт фиксированных направлений
  (per-doc Haar); (iii) отказ от top/weak-разбиения в пользу прямого сравнения
  J-базисов с null-базисами на k≥1 без функционального гейта.
