## F3 ⚠️ dose: g = w вместо 1+w, порядок множителей — PRINATO, исправлен + пересчитан

Ревьювер прав по обоим пунктам. Проверено по исходнику
(transformers qwen3_5/modeling_qwen3_5.py:729–733):
`Qwen3_5RMSNorm.forward: output = (x/rms(x))·(1 + weight)`,
`weight = nn.Parameter(torch.zeros(dim))` → **g = 1 + w, init g ≡ 1**;
канонический порядок (§2.5): diag(g) СЛЕВА ⇒ radial ПЕРВЫМ, diag ПОТОМ.
Код r5.1 делал gain первым и с g = w.

**Численный fingerprint подтверждён** (disk-only пересчёт,
experiments/at2/AT2d_dose_check.py + reanalysis, без форвардов):
- **sanity**: r5.1-формула точно воспроизводит артефакт — 1600 значений,
  max_rel_diff = 1.9e-8 (пересчёт верен);
- **fingerprint ревью**: D(g≡1) = 4.0702 vs E·1024 = 4.0945 (L6 randG4) —
  сходится (оценка 4.096); D(r5.1)/D(канон) ≈ mean(w²) ≈ 0.027 (w-rms L6 =
  0.164);
- **mismatch (истинная dose после α-матчинга; 1.0 = матч)** — из AT2d_v2.json
  dose_correction_F3:

| арм | mismatch (mean per cell) | per-doc range |
|---|---|---|
| **weak (verdict)** | 1.014–1.203 | 0.933–1.325 |
| top | 0.568–1.266 | 0.481–1.296 |

| L23-P top4 | 1.004 | 1.001–1.007 |

Канонические дозы в 6.3–126 раз больше r5.1 (g = 1+w); **отношения** между
армами сдвигаются не более чем на 20% для weak.

**Влияние на вердикт**: дозовый артефакт в excess_match(weak) ≤ ~0.001
