# E-34. Кластеризация сэмплов по ESG-спектру без доменных меток (5.md высший-4, ставка №3)

Нумерация = порядок запуска. Мэппинг правок из `docs/exps_review.md`: нет отдельного раздела в ревью (затронут косвенно) → **E-34**.

## Инфраструктура (общая, E-30…E-35)

- **E-30, E-31, E-33, E-35 — postprocessing на локальном CPU** (GPU/Kaggle не нужны).
  **E-34 — кластеризация** (тоже CPU, кэш). **E-32 — единственный новый GPU-прогон** (инъекции).
- **Слои в кэше `LAYERS_DEFAULT = (6,12,18,19,22,23)`, L0 в кэше нет.** E-30 и E-33 берут
  `{6,12,18,22,23}` (L19 исключён для консистентности с E-14; на L0 нечего считать).
- **Позиционная конвенция — cache-t:** `p128[S-1-t]`, `ids[:, :S-t]`, `H[...]=hs[S-1-t]`.
  **t=0 — последняя позиция, t=127 — первая** (инвертировано к наивной). `seq_pos = S-1-t`.
- **Состав кэша exp27b_dense.pt:** `JR` = **полный (raw) J** (НЕ gauge-free — gauge-free
  = softmax-проекция, применяется downstream); `P128` = **нормализованный p** (сумма 1 по U128);
  `H` = hidden states позиции по слоям; `RANKS` = (entropic, stable, PR) **уже посчитаны**.
- **g = RMSNorm.weight не в кэше** — достаётся из модели (один forward на 0.8B), нужен E-33 (M_K).

## Тело

**Цель.** Есть ли кластерная структура в ESG-спектрах, независимая от доменных меток.

**Протокол.** Слои `{6,12,18,22,23}` (L0 нет, L19 исключён). Агрегация per-сэмпл.
ARI + permutation-test. **Sentinel-обработка** (позиции с rank<r).
K-инвариантность после фикса (ρ из E-30).

**Артефакт:** `results/exp34_esg_clustering.json`.
