N2: ок. Обнуление mean (model.norm 3.31, A_log −1.24) — объявленная конвенция N(0,σ_t): σ-таблица с mean в артефакте; один S → стволы R1/R2 побайто (код: torch.equal, RC=4) → контрасты P2/P4 не смещены. N3: в целом ок. P1-полоса [0.75,1.5] — априорна: E[r]=1 для некоррелированных Δu при ЛЮБОМ размере шага, нуль правосторонний → шире вверх обосновано; полоса стабильна v1→v3 (не подгонка) (TZ §5 P1). P2/P4 0.1 — априорно, без калибровки: добавить перестановочный нуль Δu (перемешать порядок Δu по докам → нулевое распределение медианы |Δr|). vacuous(r_max<1) — не уход от фальсификации: объявленный исход-режим с геометрической причиной (r_max<1 ⇔ Σ‖Δu‖²>4 — антиподальные прыжки, чтение «марш» неприменимо). Не хватает: пре-рег-нуль для сравнения — для независимых случайных unit-векторов E[Σ‖Δu‖²]≈2N=766 → r_max≈0.005, т.е. a priori vacuous — наиболее вероятный исход для истинно случайной модели; в TZ это стоит объявить явно (TZ §5 P1).

N4: ок. d_eff≥3 обосновано: точка→1, линия→2, random×real≈5 (vocab-limited, nuniq 16..66) проходит — порог ловит только коллапс (смоук: R0 11..21) (TZ §4.2). cv>0.05, ent>0.5 — коллапс/вырождение выхода; ent у random-модели ≈1 → гейт тривиально проходит для целевых клеток (ловит лишь патологию). Правило «ВСЕ доки вырождены → not_testable» корректно: r определён при c0>0, один док не должен убивать инстанс (TZ §4.2; код gnd). Дефект: точечный коллапс (Δu≡0, c0=0) → неловленный ValueError → краш ДО метки G_nd — объявленный not_testable недостижим ровно в главном его случае (НОВЫЕ #2).
