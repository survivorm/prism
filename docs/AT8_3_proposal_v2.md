## Б. Скорректированное ТЗ — `AT8_3` (T8.3), версия 1.0

### 0. Вопрос и место в программе

Тест **двух необходимых условий** солитона (аддентум §4, ТЗ_4-8 §8): **локализация** и **квази-интеграл вдоль позиции**.

> **Локализация** — необходимое условие: `не локализовано ⇒ не солитон`, независимо от остальных критериев. **Обратное неверно**: `локализовано ≠ подтверждение солитона`.

Главный урок `AT8_2`: оконная медиана косинусов **слепа к локализованному объекту**. Поэтому все наблюдаемые здесь — **позиционные**, не оконные скаляры.

Ключевое исправление относительно черновика: наблюдаемая строится на **векторных разностях состояний** `δh`, а не на отношениях норм (п. 10 ответов).

### 1. Модель и среда

- `Qwen3.5-0.8B`, fp32, `.eval()`, `grad off`, `use_cache=False`.
- **`attn_implementation="sdpa"`** — согласовано с референсом серии (`AT8_2-R2`), **не `eager`** (п. 8). Обязательный смоук-кроссчек `eager`/`sdpa` (см. §8, `S0`).
- CPU, `OMP_NUM_THREADS=6` через `run_one.sh`, fla заглушен `None`.
- **Слои:** `L ∈ {6, 11, 18, 23}` — 2 GDN (6, 18) + 2 full (11, 23). Хуки на всех 4 одновременно, один форвард даёт все слои. `L23` — readout-adjacent, отчитывается отдельно.

### 2. Документы

- 16 документов, 4 домена × 4 (`wiki/math/code/chat`), из существующих пинов `data/calib_pins/*__n192__max512__plain.json`.
- **`S_base` — фильтр невырожденности (точное правило, самокоррекция):** документ отбрасывается, если есть 9-грамма со счётчиком ≥ 4 **или** `rep_rate(≥3) > 0.02`. Выбор — первые 4 прошедших в порядке пина.
- `T ≥ 192`, `docs_sha256` по токенам.

### 3. Вставка, доза, выравнивание

- Фраза `PHRASE`, `L_n = 9n`, доза `n ∈ {2,4,8,16}`, вставка в `cut = T//2`.
- **Ось дозы — информационная** `D(n)` из per-position CE вставленного блока, не число повторов (урок `AT8_2`). Отчёт по `n` и по `D(n)`.
- Выравнивание суффикса: `t_inj(d) = cut + L_n + d`, `t_ctrl(d) = cut + d`, `d = 0..D`.

### 4. Наблюдаемые (позиционные, векторные — исправление п. 10)

Для каждого документа, дозы `n`, слоя `L`, позиции `d`:

```
δh_loop(d)    = h_loop(cut+L_n+d)   − h_ctrl(cut+d)
δh_fillerA(d) = h_fillerA(cut+L_n+d) − h_ctrl(cut+d)
δh_fillerB(d) = h_fillerB(cut+L_n+d) − h_ctrl(cut+d)
```

Три контраста, одна линейная схема (векторные разности, затем норма, нормировка на `‖h_ctrl‖`):

- **`A_spec(d) = ‖δh_loop(d) − δh_fillerA(d)‖ / ‖h_ctrl(cut+d)‖`** — специфичность лупа (главная наблюдаемая локализации).
- **`A_null(d) = ‖δh_fillerA(d) − δh_fillerB(d)‖ / ‖h_ctrl(cut+d)‖`** — эмпирический нуль (вариативность двух не-луповых блоков).
- **`A_ins(d) = ‖δh_loop(d)‖ / ‖h_ctrl(cut+d)‖`** — реакция вообще (включая эффект вставки).

Вторичные (отчёт, не вердикт): `cos_lag1`, `norm_delta`, per-position CE — как в `AT8_2-R2`.

**Квази-интеграл (вторичный):** `q(d) = Σ_{i≤r} c_i(d)²`, `c_i = ⟨δh_loop(d), v_i⟩`, `v_i` — топ-`r` мод контроля. **Диагностика `capture(d) = q(d)/‖δh_loop(d)‖²`** (п. 11): если медиана `capture < 0.5`, квази-интеграл помечается «вне подпространства» и в вердикт не входит.

### 5. Контроли

- **Филлеры** — не-луповый текст той же длины `L_n`, из того же пула (cross-doc), два разных (`fillerA`, `fillerB`) на каждой дозе. Гейт: нет период-9 повторов.
- **`δ_min(n, L, d)` — позиционный, из нуль-контраста (исправление п. 3):** `δ_min = 95-й перцентиль `A_null(d)` по 16 докам`, на каждой позиции `d`. Сравнение `A_spec(d)` против `δ_min(d)` на той же позиции. «Дальний пол» — вторичная диагностика.
- **Положительный контроль:** случайный блок (144 токена, `uniform(0,248320)`, seed 0, список в пре-реге) должен давать `A_ins` заметно выше `δ_min` — иначе клетка нечувствительна.
- **Нуль-контроль:** `fillerA` vs `fillerB` (это и есть источник `δ_min`).

### 6. Эстиманды и вердикты (исправленная агрегация, п. 4 и 6)

**Длина локализации** `ξ` (для `A_spec`): наименьшее `d`, начиная с которого `A_spec(d') ≤ δ_min(d')` для всех `d' ∈ [d, d+m]`, `m = 8`. Если до горизонта `D` не падает — `ξ = D`, флаг `PERSISTENT`.

**Диагностика дальнего бампа (п. 5):** `FAR_BUMP` — доля `d ∈ [ξ+m, D]` с `A_spec > δ_min` > 10%. Групповой тег, если >25% локализованных доков. Не гейт.

**Цепочка агрегации (п. 6):**
1. **`(док, n, слой)`:** статус ∈ {`NO_RESPONSE` (`A_spec ≤ δ_min` всюду), `LOCALIZED` (`ξ < D`), `PERSISTENT` (нет устойчивого падения)}.
2. **`(док, n)`:** статус присваивается, если **≥3 из 4 слоёв** одного статуса, среди них **≥1 GDN и ≥1 full**. `ξ_док(n)` = медиана `ξ` по согласованным слоям. Иначе `LAYER_INCONSISTENT`.
3. **`(n)`:** `frac_persistent(n)`, `frac_localized(n)` = доли доков.

**Вердиктное дерево (приоритет):**
```
1. INSENSITIVE_CELL      — положительный контроль провален
2. NOT_LOCALIZED         — ≥2 из 4 доз: frac_persistent ≥ 0.5
3. LOCALIZED             — ≥2 из 4 доз: frac_localized ≥ 0.5
4. NOT_RESOLVED          — иначе (+ теги BELOW_RESOLUTION / WIDE_CI / FAR_BUMP / LAYER_INCONSISTENT)
```
Доза-зависимость `ξ` — **только диагностика** (п. 4), тег `DOSE_TREND` при монотонном росте. В вердикт не входит.

**Квази-интеграл** — отдельный вторичный отчёт: `Q_sat = (Q(D) − Q(⌊0.75D⌋))/max(Q(D),1e-9) ≤ 0.10` ⇒ «насыщен» (п. 7). Только при `capture ≥ 0.5`. В вердикт не входит.

### 9. Цена (исправление п. 2)

- На документ: `1 (ctrl) + 4 дозы × 3 (луп/филлерA/филлерB) + 1 (случайный) = 14 условий`.
- **16 доков × 14 = 224 форварда** (хуки на 4 слоях в одном форварде).
- При 6.2 с/форвард (без нагрузки) ≈ **23 мин**; при 14.3 с/форвард (под нагрузкой) ≈ **53 мин**. Бюджет **60–90 мин**.

### 10. Границы (не менять)

- Не измеряется форма-инвариантность, упругое столкновение, внутренняя мода — это двухобъектный дизайн.
- Локализация **не повышает** статус до «солитон».
- Генерация не считается.
- «Время» = позиция последовательности; динамическая эволюция не измеряется (квази-интеграл в строгом смысле в статическом режиме не измеряется — только пространственный профиль и насыщение).

## В. Итог

Черновик корректируется по **всем 12 пунктам** ответов — они обоснованы, и два из них (векторная разность вместо отношения норм; `δ_min` из нуль-контраста вместо дальних позиций) исправляют мои содержательные ошибки. Мои два дополнения: обязательный смоук-кроссчек `sdpa`/`eager` и сохранение «дальнего пола» как вторичной диагностики.

Результат — рабочий, самосогласованный ТЗ на **224 форварда (~1 час)**, который честно отвечает на вопрос о локализации как **необходимом** условии солитона, не претендуя на большее.
