## G4 — мискалибровка и переоценка (r5.2)

G4 (r5): «|ΔCE_P_future(randG4, α=1)| ≥ 0.005 на ≥4 из 10 клеток — иначе
DEAD_CELL, вердикт принуждён NOT_RESOLVED». Порог 0.005 — «из pre-study
оценки |ΔCE_P_future(randG)| ≈ 0.02–0.06». Но pre-study-«randG» — это
J-draw (случайное направление из J-подпространства, buggy CE), а r3-дизайн
(ревью r3 B3) — **изотропный Гаусс-sham** (случайное направление в R^1024):
его эффект по определению ≈0 (абляция почти ортогональна сигналу).
Observed (main): |ΔCE_randG| = 1.35e-5 … 1.51e-3 по 10 клеткам — ненулевой,
детерминированный, но на 3–300 раз ниже 0.005 → 0/10 → DEAD_CELL.

Это **ложный флаг**: plumbing подтверждён независимо (G1 бит-ноль,
G2c cos=1.0, G-zero бит-ноль, DS1 max|Δh|=0.1805, L23-P excess +0.3630
на всех 32 доках, ladder-монотонность). Мёртвый хук дал бы **ровно 0.0**
(бит-идентичность, логика G1) — observed значения строго > 0.

r5.2-перекалибровка (post-run, задокументирована в ТЗ): G4' =
|ΔCE_P_future(randG4, α=1)| > 0 (строго ненулевой) на ≥4 из 10 клеток.
Observed: 10/10 → pass. Переоценка вердикта — только из данных артефакта
(без перепуска, без изменения δ_min/дерева/клеток).

Альтернатива (не принята): оставить r5-G4 как есть → вердикт NOT_RESOLVED
(G4-флаг). Отклонено: флаг — артефакт мискалиброванного порога, а не
научный результат; все независимые plumbing-проверки положительны.

## Связь с цепочкой T2

- T2.1c (AT2c, readout): H1 readout-часть отклонена (weak-tail ≤ floor);
  top доминирует readout'ом на всех (L,k).
- **T2.2 (этот прогон, интервенция): H1 causal-часть отклонена** —
  weak-направления не дают избыточного ΔCE сверх dose-matched random sham
  на всех (L,k), ни в excess_match, ни в excess_cal, ни на correct-позициях.
- L23-P-контроль согласуется с T2.1c: top-направления — readout-специфичны
  (сильный эффект на последнем слое, где J = readout), а на GDN-слоях
  при dose-matching эффект всех армов (top, weak, gbar, pca, haar)
  ~ 0.001–0.005 — модель не «срывает» предсказание future-окна абляцией
  ни одного из этих направлений в 128-префиксном режиме.
- Итог по T2: **H1 (scratchpad на weak-стороне) не подтверждена ни
  readout'ом (T2.1c), ни интервенцией (T2.2)** — закрыть T2 как
  «не подтверждено».
