## 3. Что внести — по секциям

### 3.1. Часть II — новая лемма `[L-taylor]` и связанные определения

**Где:** новый подраздел `§8.5. Второй порядок readout: Тейлор вдоль нормированной инъекции` сразу после `[L-rms]`.

**Содержание:**

1. **Определение инъекции.** Для токена `i ∈ 𝒮`:
   `δ_i = ε · J_lᵀe_i / ‖J_lᵀe_i‖ ∈ R^D`, `‖δ_i‖ = ε`.
   `h' = h + δ_i`.

2. **Тейлор логита `j`:**
   `z_j(h + δ_i) − z_j(h) = ε·a_ji + ε²·b_ji + ε³·c_ji + O(ε⁴)`,
   где
    - `a_ji = (ESG_l)_ji / √((ESG_l)_ii)` — нормированный первый порядок;
    - `b_ji = ½ · (J_lᵀe_i)ᵀ H_j (J_lᵀe_i) / (ESG_l)_ii` — второй порядок;
    - `H_j = ∂²z_j / ∂h_l² ∈ R^{D×D}` — Гессиан логита `j`.

3. **Лемма `[L-taylor]`.** При фиксированном `‖δ_i‖ = ε`:
    - (а) `a_ji` тождественно воспроизводит нормированную ESG (валидация метода);
    - (б) `b_ji` — **билинейная форма Гессиана** вдоль направления `J_lᵀe_i`; корректно определена как симметризованная форма (Гессиан симметричен);
    - (в) `b_ji` **не** выражается через `a_ji` — это независимый объект (см. E-32-tail: T2-инверсия).

4. **Разведение диагонали/off-diagonal.** `b_off = b − diag(b)` — cross-talk второго порядка (аналог gauge-free в первом); `diag(b)` — вторая производная self-response, отдельный объект.

5. **Безразмерная амплитуда кривизны:**
   `s_l = ε_canon · ‖offdiag(b)‖_F / ‖offdiag(ESG_raw)‖_F`, `ε_canon = 0.15‖h‖`.
   Значение ≪ 1 — readout линеен в рабочей точке; ~1 — нелинейность сравнима; ≫ 1 — линейная защита некорректна.

6. **Связь с `[L-fisher]` (содержательная).** Первый порядок инвариантен к uniform shift (softmax); `[L-fisher]` даёт `JᵀPJ` как информацию Фишера. Второй порядок **не инвариантен** к shift — `H_j` зависит от полного `z_j`, но `b_ji` определён только вдоль directions `J_lᵀe_i`, т.е. **в подпространстве активных направлений** — gauge-shift в ортогональном дополнении не влияет.

> **Критерий приёмки §8.5:** после вставки леммы все последующие упоминания `a_ji/b_ji/c_ji/s_l` в §18 имеют ссылку `[L-taylor, §8.5]`; ни одно определение не дублируется.

>
> 4. **Token-space (E-32-tail): T2 — полная инверсия.** Первый порядок (off²) локализован в **хвосте** ESG (r ∈ [119,128]); второй (`b_off`) — в **топ-модах** k=1..6 (97.3–98.5% энергии в r ≤ 118). >
> 5. **Следствие для E-30b-мишени:** мишень {123..127} для второго порядка **неверна**. Если E-32 нужен (управление кривизной), мишень — **top-моды** (k ≈ 1..6 на L18/L22). Nonlinearity и residual cross-talk первого порядка живут в **разных** спектральных регионах.

## 5. Единая нить E-32 (narrative для читателя)

В §20 (Синтез) **вставить** перед таблицами «Подтверждено» короткий абзац (3–4 предложения):

## 6. Готовые формулировки (для прямой вставки)

### 6.1. Математический блок (§8.5, после `[L-rms]`)

```markdown
### 8.5. Второй порядок readout: Тейлор вдоль нормированной инъекции

**Определение (инъекция).** Для токена `i ∈ 𝒮` пусть `δ_i = ε · J_lᵀe_i / ‖J_lᵀe_i‖ ∈ R^D`,
`‖δ_i‖ = ε`. Тогда `h' = h + δ_i`.

**Тейлор логита.** Для логита `j`:

  z_j(h + δ_i) − z_j(h) = ε·a_ji + ε²·b_ji + ε³·c_ji + O(ε⁴),

где
  a_ji = (ESG_l)_ji / √((ESG_l)_ii)                     — нормированный 1-й порядок,
  b_ji = ½ · (J_lᵀe_i)ᵀ H_j (J_lᵀe_i) / (ESG_l)_ii       — 2-й порядок,
  H_j  = ∂²z_j / ∂h_l² ∈ R^{D×D}                        — Гессиан логита j,
  c_ji — остаток (абсорбирует все высшие порядки).

**Лемма [L-taylor].** При фиксированном ‖δ_i‖ = ε:
 (а) a_ji тождественно воспроизводит нормированную ESG (валидация метода).
 (б) b_ji — билинейная форма Гессиана вдоль направления J_lᵀe_i
     (симметризованная, т.к. H_j симметричен).
 (в) b_ji не выражается через a_ji — независимый объект
     (см. E-32-tail: T2-инверсия по спектру ESG).

**Разведение диагонали/off-diagonal.** b_off = b − diag(b) — cross-talk
второго порядка (аналог gauge-free в первом); diag(b) — вторая производная
self-response, отдельный объект, не включается в offdiag-норму.

**Амплитуда.** s_l = ε_canon · ‖offdiag(b)‖_F / ‖offdiag(ESG_raw)‖_F,
ε_canon = 0.15‖h‖. Значение ≪ 1 — readout линеен в рабочей точке;
~ 1 — нелинейность сравнима с линейностью; ≫ 1 — линейная защита некорректна.

**Связь с [L-fisher].** Второй порядок не инвариантен к uniform shift логитов
(H_j зависит от полного z_j); но b_ji определён только вдоль directions
J_lᵀe_i — gauge-shift в ортогональном дополнении не влияет. Тем самым
[L-fisher] (gauge-free первого порядка) корректно расширяется на второй
порядок: b_ji — квадратичная форма в подпространстве активных направлений.
```
