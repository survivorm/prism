## §0.1. Почему именно эти два слота, а не другие

Инвентаризация покрытия T0–T10 по осям:

| ось | покрыта | чем |
|---|---|---|
| время `t` | ✅ | T0 (учёт), T3 (карта) |
| глубина `l` | ✅ | T5 (калибровка) |
| канал / сжатие | ✅ | T1 |
| видимость / наказуемость | ✅ | T2 |
| повреждение / репарация | ✅ | T4 |
| режим / routing | ✅ | T6 |
| проекция наружу | ✅ | T7 |
| порог в пространстве весов | ✅ | T8 |
| обучение (порядок) | слот | T9 |
| корпус / вход | слот | T10 |
| **совместная ось `(l,t)`** | ❌ | **нет** |
| **вырождение как объект** | ❌ | **нет — только как фильтр** |

Две дыры, и обе — не «ещё одна идея», а непокрытые измеренные объекты:

**T11.** Измерена **временная** согласованность межслойного тангенса (чтение B, дословно: `g = nrm(h_{l'}−h_l)`, `real = median_t cos(g(t), g(t+1))`; проверено по коду `exp64_A1246.py`), где пара слоёв — **параметр**, а не ось. Совместная ось `(l,t)` чтением B не занята. Числа 0.350–0.608 (избыток +0.24–0.5 над crossdoc 0.068 / bigshift 0.109) — измерение временной статистики, **не** свидетельство совместной оси. Слот T11 остаётся открытым, но его основание — плакетка `F_lt` (§2.8 `paper.md`, **условный объект** — существует только при совпадении знака β по трём определениям транспорта) и **невычисленное** чтение A, а не числа 0.350–0.608. Мост «аддентум ↔ статья», которого требовал ревьюер, проходит ровно здесь. **Априор T11.1 зафиксирован: чтение B обязано воспроизвести 0.350/0.518/0.608/0.548 (±1e-3) — якорь; чтение A — новое измерение без якоря.**

**T12.** Вырождение — самый крупный измеренный поведенческий факт программы (63% лупов на greedy raw, rep8 median 1.0 у 14/16, onset8 ≈17, p1-потолок 1.000). Во всех ТЗ оно присутствует **как фильтр** (G4), never как объект. При этом именно оно определяет, в каком режиме модель работает по умолчанию, и именно его снимают три независимых вмешательства (T, шаблон, teacher-K). Теории нет.

Не ввожу слотов под Goodhart (уже в T4 как луч здоровья + сквозной гейт) и под ёмкость (уже в T1/T6 как три ресурса).

# §1. T9 — «Порядок возникновения канала»

**ID:** T9-ORDER · **Уровень:** M (механизм), требует реальной траектории
**Статус:** слот. **Честная оговорка сразу:** в сильной форме (порядок при претрейне) на доступном compute **не проверяем**. Ниже — что проверяемо и чем это отличается.

## 1.1. Постановка

1. Компоненты поля (дип / горб / плато) и семантика (nll) возникают одновременно или разнесены?
2. Порог один для всех наблюдаемых или у каждого свой?
3. Совпадает ли порядок на реальной траектории обучения с порядком на прямой в пространстве весов?

## 1.2. Обоснование

| факт | число | provenance |
|---|---|---|
| R-null: всё поле от нуля | dip 4e-6 (±4e-5, n=24) vs −0.111; hump 0.005 vs 0.148; plateau 0.002 vs 0.064 | artifact |
| D-1 половина архитектура | random 0.49 (ctrl 0.07) vs trained 0.97 | artifact |
| R-leaf: лист выучен | pr_sigma 30.5 vs 112.7±0.1; g_uni 0.066 vs 0.0085; s16/s1 0.28 vs 0.90; j_norm 7.7 vs 7.2 | artifact |
| E-71A порог | dip ≈0 до λ=0.5, взрыв 0.6→0.7, плато −0.22 **глубже** финального −0.174 | prose + **дефект кода** |
| E-69c: репарация разнесена | ритм вылечен, семантика нет | artifact |

**Дефекты E-71A, установленные ревью:** `nll` вычисляется и выбрасывается; `sd_r` рандомизирует только `ndim≥2` (RMSNorm gain остаются обученными); один сид; resume по truthiness.

## 1.3. Математика

Траектория `θ(s)`, `s` — шаг обучения. Наблюдаемые `O_i(s) ∈ {dip, hump, plateau, nll, D-1_own, pr_sigma, copy, loopy}`.

Порог каждой наблюдаемой — **нормированный переход (v1.1, масштабно-свободное правило):**

```
Первичная статистика:
  u_i(λ) = (O_i(λ) − O_i(0)) / (O_i(1) − O_i(0)),   λ_c^i := λ при u = 0.5
  устойчивость на u = 0.3/0.7; только МОНОТОННЫЕ по λ наблюдаемые (copy исключить, B4);
  **критерий монотонности зафиксирован ДО прогона (v1.2, D6): |Spearman(λ, O_i)| ≥ 0.9 по усреднённым сидам;
  отсечённые наблюдаемые — в поле артефакта `excluded_non_monotone: [...]`; исключение — исход
  `non_monotone_excluded`, а не молчаливый дроп (при 13 точках × 3 сида это позволяло бы убрать
  неудобного члена семейства и получить «согласованность внутри семейства» по построению)**;
  **overshoot `u > 1` — флагать (v1.2, D6; как в T9.2)**;
  персистентность: первое пересечение, удержанное ≥2 соседних точки сетки
Вторичная: выход за 2σ_null.
Семейства наблюдаемых: поле {dip, hump, plateau} | семантика {nll_holdout} | лист {pr_sigma, eff-rank}.
  Требование согласованности — ВНУТРИ семейства; содержание теста — расхождение МЕЖДУ семействами.
Сетка: {0, 0.05, 0.1, 0.2, 0.4, 0.5, 0.55, 0.6, 0.65, 0.7, 0.75, 0.85, 1.0}; Δs := шаг сетки;
  бисекция до Δs ≤ 0.02 вокруг найденного λ_c (критерий останова, ≤5 итераций).
«Совпадают» ⇔ |λ_c^i − λ_c^j| ≤ шаг И CI по сидам перекрываются.
«Отделён» ⇔ |Δλ_c| ≥ 2 шага И CI не перекрываются; Bonferroni α = 0.05/(число пар).
CI — по СИДАМ (≥3), не по докам (λ_c — статистика первого пересечения).
```

Порядок — перестановка `π` по `λ_c^i`.

- **Гипотеза разнесённости:** `∃ i,j: |λ_c^i − λ_c^j| ≥ 2 шага` и CI не пересекаются.
- **Гипотеза общности:** все `λ_c^i` совпадают в пределах шага и CI пересекаются ⇒ генерическое включение компетентности, а не рождение отдельного канала.

**Невердиктная оговорка (v1.1):** `u_exit` (выход за 2σ_null) различается в **405×** между наблюдаемыми (dip 7.2e-4 vs D-1_own 0.292) ⇒ порядок выходов из полос задан их шириной, не механизмом; выходы — только вторичная статистика.

**Различие объектов (принципиальное):**

$$\theta_{\text{interp}}(\lambda)=\lambda\theta_{\text{trained}}+(1-\lambda)\theta_{\text{random}}$$

— **прямая**, не траектория SGD. Проходит через области, которых обучение не посещало. Порядок на ней — свойство прямой, не обучения. Это не «слабее», это **другой объект** (уже в бан-листе).

LoRA-прокси: `θ(s) = θ₀ + B(s)A(s)`, ранг `r` фиксирован ⇒ реальная траектория **в подпространстве ранга r**. Порядок может зависеть от `r`.

## 1.4. Подводные камни

1. **λ ≠ s.** Не выдавать порядок на интерполяции за фазы обучения.
2. **LoRA ≠ full fine-tune.** Ранг ограничивает доступные направления; нужны ≥2 ранга, иначе порядок — артефакт `r`.
3. **Зазубривание.** Обучение на узком корпусе даёт nll↓ без канала. Holdout обязателен (урок E-69c: wiki-nll 0.38 зазубрено, чужие 7–9).
4. **Начальная точка.** От pretrained канал уже есть — порядок не измерить. От random-init осмысленный nll на 0.8B недостижим на нашем compute. Это и есть граница исполнимости.
5. **Разрешение сетки.** Логарифмическая сетка {1,10,100,1000} не различает разнесённость в 3×. Нужна адаптивная бисекция вокруг найденного порога.
6. **Все наблюдаемые — одним оценщиком, на одних доках** (G1, G3). Иначе порядок = порядок смены прибора.
7. **rep16/loopy обязателен.** Углубление дипа — красный флаг; на промежуточных шагах модель почти наверняка вырождена.
8. **Полная рандомизация** при λ=0, включая 1-D (урок E-71A).

### T9.2 — «attention-repair of MLP-lesion» (CPU) — честная замена

От SVD8-поражённой модели, LoRA-ladder, шаги {0,1,3,10,30,100,300} = 0.477–0.523 декады, `r ∈ {8,32}`, holdout-доки. Одна клетка, **не тест независимости**.

**Наблюдаемые:** `R = dip-band-hinge |dip − dip*|` (**НЕ** знаковый dip: E-66 углубляет) и `P = nll_holdout`.
**Метрика: нормированное закрытие зазора**

$$u_O(s)=\frac{O(s)-O_{\text{lesion}}}{O_{\text{healthy}}-O_{\text{lesion}}},\qquad s_O^\star := \text{первое пересечение } u_O=0.5 \text{ с персистентностью}$$

overshoot `u > 1` — флагать.

**Обязательна бисекция** (≤5 итераций, до Δs ≤ 0.02), если `|s_R* − s_P*| ≤ шаг` — иначе §1.4 п.5 (разрешение сетки) нарушен собственным дизайном.

**Это порядок репарации, не эмергенции.** Явно другой вопрос, но реальная траектория.
**Пре-рег (v1.1, v1.2 — D10):** `s_R* < s_P*` (ритм раньше семантики) ⇒ вердикт «**порядок репарации: R раньше P**» + обязательная строка «**это НЕ доказательство разнесённости каналов**» (порядок репарации ≠ независимость; для канала нужен паритет Q2 (MLP→MLP) vs Q4 (attn→MLP) — T4.2). Ранг: **различие ПОРОГОВ (s_R*/s_P*) при общем порядке по r — результат «пороги зависят от ранга» (разная ёмкость), не артефакт; артефакт — только различие самого порядка внутри CI по сидам при фиксированном r** (v1.2: старое «неустойчивость по r при общем порядке ⇒ артефакт ранга» — слишком широко: общий порядок с разными порогов = законный результат о ранговой зависимости). ## 2.3. Математика

Гипотеза-трансдьюсер:

$$\Delta_{\text{model}}(k)\ \approx\ F_{\text{model}}\big(\rho_{\text{text}}(k)\big)$$

Разделение: **форма** (положение горба, ширина плато; нормированный профиль) ← текст; **амплитуда** (глубина дипа, scale) ← модель.

Проверяемое следствие:

$$\mathrm{Var}_{\text{corpus}}(\text{форма}) > \mathrm{Var}_{\text{model}}(\text{форма}),\qquad \mathrm{Var}_{\text{model}}(\text{амплитуда}) > \mathrm{Var}_{\text{corpus}}(\text{амплитуда})$$

**Мера избыточности — канонический выбор обязателен (v1.1):**

| кандидат | статус |
|---|---|
| ACF эмбеддингов токенов | ❌ **запрещена**: MA(1)-артефакт, −0.5 на любом порядке (E-64a), информационный ноль |
| **профиль ΔH(k) — маргинальная информация лага** | ✅ **канон** (лаг-разрешённый; кумулятивная `H(k)` монотонна по k по построению ⇒ как предиктор формы **запрещена** — конфаунд трендом) |
| MDL/zlib-стоимость (bits/токен) | ✅ **контроль** (скаляр; E-85 калибр готов, L0-страж реализован) |
| n-gram lookup покрытие | ✅ **контроль** (скаляр; T-23 машина) |
| условная энтропия по n-gram (кумулятивная) | ❌ не предиктор (монотонна по k); только диагностика |
| novelty | ≡1.0 на естественном тексте (E-85 калибр) ⇒ нулевая дисперсия ⇒ **контроль/якорь, не предиктор** |

Форма и амплитуда определяются **операционально до счёта** (v1.1):

- **форма** = L2-нормированный профиль **поля Δ(k)** (v1.2, D1: **НЕ** ΔH — ΔH(k) это **предиктор**, не форма; регресс ΔH на ΔH — подмена estimand; побочное подтверждение: `pos_hump = argmax_k` для ΔH(k) — маргинальная информация лага убывает ⇒ **константа 1**, аспект вырождается; для Δ(k) горб на 3–4 осмыслен); три скалярных аспекта, три **ОТДЕЛЬНЫХ** теста: `pos_hump = argmax_k` профиля **Δ(k)**; `width_plateau = |{k≥9: profile > 0.8·plateau}|`; `dip_hump_ratio`;
- **амплитуда** = `dip` + scale-фактор.

## 2.4. Подводные камни

2. **emb-ACF запрещена** как мера избыточности (MA(1)).

| LFM3 нить_Г | real 0.43–0.50, избыток +0.25–0.35, профиль плоский | **ОТОЗВАНО** (токенизатор) |

## 3.3. Математика

Переносы на решётке `(l,t)`:
- горизонтальный (по времени, внутри слоя): `R^l_{t,t+1}`;
- вертикальный (по глубине): `Q_{l,t} = polar(D_l V_{l,t})` — канон §2.7; QR и проекция — **контрольные**, не равноправные.

**Замкнутый контур** (обязательно, по [L-trivial]):

$$(l,t)\to(l,t{+}1)\to(l{+}1,t{+}1)\to(l{+}1,t)\to(l,t)$$

$$H_{\text{plaq}}=\text{произведение четырёх переносов вдоль контура},\qquad \kappa_{\text{plaq}}=\|H_{\text{plaq}}-I\|_F$$

Инварианты: `κ_plaq`, спектр `{θ_j}`, `Σθ_j`, `Var({θ_j})`. Компонентное разложение — **не** инвариант (конвенция eigenframe, `[D-holonomy-frame]`).

Решётка глубины неравномерна; `β = dκ/dln l` нормируется на зазор.

### Реестр объектов: нить_Г требует разведения **до счёта** (v1.1 — реестр в §0.2; **v1.2, D12: определения нити_Г и ΔH(k) НЕ закреплены кодом** — пиненный набор `prism/field.py` sha `bcc607c5` = vpath, dcurve, acf_moments, f_dc, ra_split, degen — их не содержит; требуется реализация + пин до счёта)

Формулировка в артефактах — «`g(L→L') = median cos(Δh-тангенсов соседних t)`» — допускает **два чтения**:

| чтение | определение | что мерит | статус |
|---|---|---|---|
| **нить_Г-B** | `cos(g_l(t), g_l(t+1))`, где `g_l = nrm(h_{l'}−h_l)` — тангенс пары слоёв | **временная** согласованность межслойного приращения | **ИЗМЕРЕНО** (A4, дословно по коду) |
| **нить_Г-A** | `cos(Δh_l(t), Δh_{l'}(t))`, где `Δh_l(t)=h_l(t+1)−h_l(t)` | согласованность **записи разных слоёв** в один момент | **НЕ ИЗМЕРЕНО** |
| **нить_Г-A-F** | то же на `ΔF_l = Δh_l − Δh_{l−1}` | послойное приращение без вложенности | обязательно (T11.1) |
| **нить_Г-A-perp** | A с проекцией `⊥ EΔx_t` | A, очищенная от общего члена EΔx (**B НЕ подвержена ему: в `h_{l'} − h_l` член EΔx сокращается тождественно** — v1.2, D8; ⊥EΔx-коррекция нужна A, не B) | обязательно (T11.1) |

Это разные объекты. **ТЗ требует зафиксировать все имена и отчитать все** — иначе T11 повторит ошибку О1/О2 (два объекта под одним именем), которая уже стоила серии двух раундов.

**Вектор-представители (T11.2):** скаляр не имеет направления; из четырёх вариантов первичны **оба** — `thread_mean` (DC) и `thread_pc1_centered`; `thread_dt = Δh_l − Δh_l'` — это **Δ_t межслойного тангенса, третий объект**, не переименовывать в «нить». Оба первичных обязательны: при `f_DC ≈ 0.5` косинус с weak-J иначе меряет DC, а не направление.

## 3.4. Подводные камни

1. **[L-trivial] — теорема, не рекомендация.** Path-транспорт тривиализует объект тождественно. Только замкнутый контур. Любое «сравнение двух путей без замыкания» даёт 0 по построению.
2. **Определение нити_Г неоднозначно** (§3.3). Развести до счёта.
3. **Тип слоя.** Путь `t→t+k` идёт через attention (full) или рекуррентное состояние (GDN). Плакетка через пару **разного** типа ≠ через пару одного типа. Matched pairs обязательны (как в T5.3).
4. **Matched step по обеим осям.** E-50v4 W16 помечен INVALID при step-ratio ×5.17. Плакетка без matched step не интерпретируется.
5. **lead-lag asym ≤0.03 не убивает T11**, но запрещает интерпретацию «сигнал течёт по глубине». Голономия ≠ направленное распространение: можно иметь нулевой lead-lag и ненулевую петлевую кривизну.
6. **random → null — центральный фальсификатор.** Если нить_Г про токен, «ток записи-чтения» — неверная архитектурная метафора. Исход определяется **mix-колонкой T11.3, не только random-колонкой** (v1.2, D9): random→null + **нужна связность** ⇒ **T3** (выученная карта над структурой); random→null + связность не нужна ⇒ токен-статистика (сведение к T10 — только для ветки «связность не нужна»).
7. **LFM3-числа отозваны.** Не использовать как вторую точку.
8. **Неравномерная решётка глубины.** β нормировать на зазор; не сравнивать κ между парами с разным зазором без нормировки.

## 4.3. Математика

Детерминированная карта `Φ: h ↦ h'` при argmax. Цикл периода `p`: `Φ^p(h*) = h*`. Токенный повтор периода 1 — фикс-точка.

Состояния: `{transient, absorbing cycle}`. Время до входа `τ_onset`.

**Важно: при T=0 «поглощение» — тавтология детерминизма.** `P(выход | вошёл, T=0) = 0` по построению, это не открытие. Содержательны только три вещи:

**(а) Распределение `τ_onset`:**

$$\tau_{\text{onset}}\sim\mathrm{Geom}(q)\ \Rightarrow\ \text{геометрическое попадание};\qquad \text{узкое/сдвинутое}\ \Rightarrow\ \text{дрейф к аттрактору}$$

**(б) Две операциональные температуры (v1.1; «T_c как escape rate > 0» изъято — тавтология при конечном словаре ⇒ T_c ≡ 0):** `T_suppress` (подавление входа) и `T_escape` (выход после входа) — определения в T12.3; зависимость от корпуса/шаблона.

**(в) Предвестник (v1.1, v1.2 — D14):** задача — предсказать **onset на горизонте ≥8 шагов ДО первого повтора** (на этом горизонте `eq_prev_rate` не выровнен с меткой тривиально, но остаётся вычислимым признаком и **законным слабым baseline** — не «неприменим по построению»: E-47c лечится условным приростом над лучшим baseline, а не удалением признака). `margin/p1/entropy` в окне до onset против matched окна; обязан побить лучший тривиальный baseline **условным** приростом (не маргинальным ΔAUC).

Связь с T3: цикл в графе ячеек длины `p` ↔ наблюдённый период лупа `p` (вершины — **кластеры скрытых состояний**, не токенные n-граммы; argmax-ячейки — тавтология, D4 — см. T12.5).

## 4.4. Подводные камни

1. **Тавтология детерминизма.** Не публиковать «луп навсегда при T=0» как находку.
2. **K(1)=0.958 против ≈0.0** — противоречие прогонов. Не цитировать как факт до разрешения (перепуск e83 идёт).
3. **instruct vs base.** Лупы могут быть следствием подачи сырого текста выровненной модели, а не свойством карты. E-73 — обязательная клетка, не опция.
4. **copy ≠ degeneracy.** B4: copy немонотонен, degeneracy монотонен. Разные объекты, не сливать (уже в бан-листе T1).
5. **Инверсия фильтра.** Здесь вырождение — **объект**, а не помеха. G4 применяется наоборот: изучаем именно отфильтрованное. Явно оговорить в артефакте, чтобы не путать с остальными ТЗ.
6. **Скрытые лупы.** `code_1 Δ(24)=1.00`, `uniq>25%` не ловил. Детектор: `Δ(k)≈1` при некотором `k≥2` **плюс** rep-n.
7. **dip углубляется в лупе** ⇒ dip не «здоровье» здесь; только луч `(dip, loopy, nll)`.
8. **Стек-хрупкость.** loopy 10/16 против August 28/64. `τ_onset` может зависеть от стека ⇒ sha-якорь обязателен (источник — E-81b REPLAY, метка в артефакте), кросс-стековые сравнения только с ним.
9. **Baseline обязателен.** `eq_prev_rate` до 0.938 ⇒ любая предсказательная заявка бьёт **его**, а не случайный. Это урок E-47c/E-48 (лист не добавил сверх тривиальных фич).
10. **Один τ на док ⇒ hazard не идентифицируем в принципе (v1.1).** Смесь геометрических (гетерогенность по докам) сама не геометрична: убывающая hazard, сверхрассеяние. Различить «постоянная hazard внутри дока» и «разные hazard между доками» на одной реализации нельзя — это сильнее, чем «geom требует стохастики». Форма распределения — да (T12.1), различение «случайное попадание vs дрейф» — только в T12.3 (T>0).

### T12.1 — Распределение τ_onset (disk-only) ⭐ первый

- bimodal ⇒ бистабильная карта;
- одномодальное широкое ⇒ prompt-driven (**только после отклонения геометрического**);
- одномодальное узкое с большим τ ⇒ карта без предпочтения к лупам.
«Geom vs дрейф» **здесь неразличим в принципе** (подводный камень 10) — вопрос целиком в T12.3.

**Мощность (v1.2, D5):** считать для **ЦЕНЗУРИРОВАННОГО LR-теста (симуляцией)** — не по CV полной выборки: интервалы CV 95% ∈ [0.54, 1.46] (n=10) / [0.62, 1.41] (n=16) — для **полных** экспоненциальных выборок; при KM-цензурировании onset'ов CV по наблюдаемым смещён **вниз** (длинные onset'ы цензурированы) — ровно в сторону «узкое», против которой и введён KM. Мощность и оценщик обязаны быть согласованы: MDE пересчитать симуляцией ДО прогона; ниже ⇒ `not_testable`, не «попадание».
**Доменных строк нет** (16 доков / 4 домена; `row_allowed` — только math 16 и P2_corpus 16) ⇒ только пул.

### T12.5 — Циклы в графе ячеек (disk-only)

**Вершины графа = кластеры скрытых состояний (k-means по `h_l`, НЕЗАВИСИМО от эмиссии) (v1.2, D4).** Ветка «argmax-ячейки (конусы T3)» **УДАЛЕНА**: посещённая ячейка `C_i` индексируется **эмитированным токеном** — `h_l^t ∈ F_{x_t}` по определению предобраза — значит последовательность посещённых ячеек **тождественна токенной**, граф изоморфен токенному, и «период лупа = длина цикла» снова тавтология (G10). «Или» не свободный выбор: первая ветка не проходит G10. Граф из lk4/lookup (токенные n-граммы) даёт p-цикл для период-p лупа **ПО ПОСТРОЕНИЮ** ⇒ как вердикт тавтологичен (G10 не проходит). **Токенный цикл — БАЗЛАЙН, который надо побить, а не подтверждение.**

**Пре-рег (v1.1):** период лупа = длина цикла в графе ячеек **И** токенный базлайн не объясняет совпадение ⇒ луп живёт в графе ячеек (связка T12×T3); иначе — партиция слишком груба, нужна мельче.
**Цена:** ~30 мин (переиспользует T3.4).

Четыре блока, из них **два новых слота обоснованы непокрытыми объектами**, а не желанием расширить каталог:
