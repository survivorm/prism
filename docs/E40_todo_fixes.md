### §1.2. Правка №3 — §7.2 (`Σ5` + `eps3`), математическая

**Что не так (по исполнителю, точная алгебра):**

При `E_cross = 2 tr(Σ̄ M Σ̄ N)` (подпись `E-40_ans`; в `prism/kinetic.py:128` ровно так):

$$\|\Delta J_{\text{proj}}\|^2 - \Sigma_{5,\text{diag}} = 2\langle\Delta\Sigma,\, M\bar\Sigma - \bar\Sigma N\rangle + 2\langle\Delta J_{\text{lin}},\, \text{resid}\rangle$$

**Вообще nonzero.** Это:
- смешанный cross-radial терм `2⟨ΔΣ, MΣ̄ − Σ̄N⟩` — произведение двух малых величин, `O(ε³)`;
- cross-term линеаризации `2⟨ΔJ_lin, resid⟩` — `O(ε³)`.

`eps3` определён как разрыв замыкания ⇒ **тавтологичен** как «канал». `Σ6 + eps3 = ‖ΔJ‖²` — не физическое утверждение, а определение `eps3`.

**Три следствия (все три в текущем ТЗ неверны):**

1. **§12 приёмка «closure Σ6 < 1e-2»** — алгебраически **невозможно** на реальных данных: сумма всегда даст `‖ΔJ‖²` по определению `eps3`. На L6–L22 код `kinetic.py` возвращает `None` для каналов (гейт сам её отключает по `linearization_valid = False`) — приёмка на этих слоях **не запускается**.

2. **§14.6 стоп-условие** «Σ6 + eps3 не замыкает ‖ΔJ‖²» — **вакуумно**: `eps3` определён как разрыв замыкания, не может не замкнуть.

3. **§7.2 «Σ5 замыкает ‖ΔJ_proj‖²»** — **не тождество** (формула выше).

**Точная структура:**

```
Точное замыкание (алгебраически, все слои):
    5×5 Gram matrix over channels (channel_energy_matrix):
    Σ_{ij} G_ij = ‖ΔJ_proj‖²       (exact, tol 1e-10)
    
    На synthetic (E_off = 0): ‖ΔJ_proj‖² = ‖ΔJ‖², 5×5 замыкает ‖ΔJ‖².
    На real (L6–L22): 5×5 замыкает ‖ΔJ_proj‖², НЕ ‖ΔJ‖².
    
Приближённое (эмпирика линеаризации, только linearization_valid слои):
    Σ6 = Σ5_diag + E_off_manifold
    eps3_correction = ‖ΔJ‖² − Σ6   (диагностика нелинейности, НЕ канал)
    На L23 (linearization_valid = True): eps3_correction/‖ΔJ‖² ≤ 1e-2   (эмпирика, не алгебра)
    На L6–L22: каналы не определены (log Q вне главной ветви) — код возвращает None.
```

**Правки:**

- **§7.2** — заменить формулировку: «5×5 Gram — **точное** замыкание `‖ΔJ_proj‖²`; `Σ5_diag` — приближение `‖ΔJ_proj‖²` с точностью `O(ε³)` (смешанный cross-radial + cross линеаризации)». `eps3` — **диагностика нелинейности**, не канал.

- **§12 приёмка** — заменить «closure Σ6 < 1e-2» на **два пункта**:
    - «5×5 Gram `channel_energy_matrix` sum = `‖ΔJ_proj‖²` (tol 1e-10, все слои)»;
    - «на L23 (linearization_valid): `Σ6` приближает `‖ΔJ‖²` с относительной ошибкой ≤ 1e-2 (эмпирика линеаризации)».

- **§14.6 стоп-условие** — **удалить** вакуумное «Σ6 + eps3 не замыкает». Заменить: «5×5 Gram sum ≠ `‖ΔJ_proj‖²` (> 1e-10) — bug в `kinetic.py`».

### §1.3. Правка №4 — §7.3 (`rotation_unique`), размерность

**Что не так:**

- Код (`prism/kinetic.py:20`, докстринг): `min |σᵢ² − σⱼ²| > 1e-2 · σ₁²` — **обе стороны в σ²**.
- ТЗ: «min σ-gap > 1e-2·σ₁²» — σ против σ², **размерностная несогласованность**.

Плюс два разных 0.0092, которые могут склеиться в тексте:
- `gap_min(L23) = 0.0092` — из E-38c, **в единицах σ**;
- `κ_flat = 0.009275` — из E-39d, **кривизна Procrustes**, другая величина.

Совпадение чисел — **случайное**, нужен дискламб.

**Правка:** §7.3 — «`rotation_unique = (min_{i≠j} |σᵢ² − σⱼ²| > 1e-2 · σ₁²)`» (обе стороны в σ²). Сноска:

> Числа 0.0092 (E-38c, `gap_min`, в σ) и 0.009275 (E-39d, `κ_flat`, curvature) — **разные объекты** с разной размерностью; совпадение значений случайное. В `kinetic.py` используется σ²-форма.

### §2.5. Правка №8 — §3.2, `s²` в mean-ячейке

Замыкание `frac_K = 1 − 2c + s²` в mean-ячейке держится только если:

$$s^2 = \overline{O1_t} = \frac{1}{N}\sum_t \frac{\|P(p_t)J_t\|^2}{\|J_t\|^2} \quad\text{(mean of position-wise energies)}$$

**Не** `s² = (mean_t √O1_t)²` — это другая величина (≤ из-за Коши–Буняковского).

Наивный реализатор без явного определения получит «не замкнулось» на верных данных. Зафиксировать в §3.2.

**Плюс:** `g_uni_checkpoint` — по **всем 5 слоям**, не только L6.

### §2.6. Правка №9 — §1.2, `ValueError` для `Σp²`

«Любая ссылка на `Σp²` без `p_mode` → `ValueError`» — **механически недостижимо** для текстовых ссылок.

**Переформулировать:** «поле артефакта `Σp²` без `p_mode` → `ValueError` при сериализации». Текстовые ссылки — не ловятся автоматически, проверка ревью.

### §2.7. Правка №10 — §4, сетка Δ и `not_distinguishable`

**(а)** `C(Δ) = A·Δ^(−α) + c₀` **расходится** при `Δ = 0`. Сетка **обязана** начинаться с `Δ ≥ 1` — записать явно в §4.

**(б)** Подпись `not_distinguishable_at_N32` сбивает: различимость форм идёт по **~64 точкам кривой**; документы (`N = 32`) входят **только через bootstrap-дисперсию** параметров.

**Переименовать:** `not_distinguishable_at_curve_length` (или `not_distinguishable_at_Δ_grid`). Одна строка.

### §2.8. Правка от Спикера 2 №1 — числа в JSON-схемах → `null`

Собственное правило §1.5 («якоря → `null`, не значения прошлых прогонов») нарушено в двух местах:

### §2.9. Правка от Спикера 2 №2 — фраза T4a

Текущая: «`mean × ratio_of_means` (при `ratio_of_means` это одно и то же для `s²` и `frac_K`)» — нечитаемо (среднее отношений ≠ отношение сумм, в этом и суть T4a).

**Заменить:**

> Ожидаемое поведение: ячейка `{ratio_of_means × all × p_t}` **обязана замкнуться** (тождество выведено из сумм). Ячейки с `mean` (= mean-of-ratios) и `median` — **не замкнутся** (ожидаемое различие агрегаций). `alive`-вариант, вероятно, тоже замкнётся (на кэше `p` одинаков по слоям).

### §2.10. Правка от Спикера 2 №3 — метка канала §7

Метка `top+tail` нестандартна: `window ∈ {"top", "tail", "full"}`. «top+tail» — не одно из них.

**Заменить на `window = "full"`** (декомпозиция покрывает всё `‖ΔJ‖²` через 6 каналов + `eps3`); пояснение в §7.2 остаётся: `Σ5` покрывает проекцию на top-r, `E_off_manifold` — комплемент.
