# Ревью r2: ТЗ гейтов G1/G2/G6 — только дельта после REVISE

Ты — новый внешний ревьюер ревизии **r2b** файла `docs/TZ_methodology_gates.md` (sha256 ниже).

## 0. Жёсткие правила (нарушение = ревью не засчитано)

1. **Не переписывать и не копировать** текст `docs/dynamic/TZ_GATES_REVIEW.md` (это ревью r1).
   Предыдущий прогон именно так и сделал — выдал ревью r1 вместо дельты, файл не написал.
   Твой вывод обязан **отличаться** от r1: другой файл, другой разбор.
2. Ты пишешь **ровно один** файл: `docs/dynamic/TZ_GATES_REVIEW_r2.md`. Пиши его **инкрементально**:
   после каждого раздела дописывай в файл (тот, кто молча умирает с RC=0, теряет всю работу).
3. Каждая проверка числа — **своя команда** + её вывод в файле. Не верить числам ТЗ.
4. Бюджет: ≤ 20 tool-вызовов, каждая команда под `timeout 120`, только чтение.
5. STOP: число не воспроизвелось и причина неясна → пиши «не воспроизвелось: <команда> → <вывод>»
   и ставь `REVISE`. Не угадывать.
6. Последняя строка файла — `REVIEW_TZ_R2_DONE`.

## 1. Что ревьюится

`docs/TZ_methodology_gates.md` — ТЗ трёх гейтов (G1 «тест-файл без тестов», G2 «путь от `__file__`
в несуществующее место», G6 «артефакт не описывает сам себя»). Преролл r1 дал `VERDICT: REVISE`
с тремя блокерами:

- **B1 (G1):** противоречие «гейт не импортирует torch», хотя `pytest --collect-only` импортирует
  модули; и конфликт baseline'ов «0 ERROR» против файла, который даёт RC=2.
- **B2 (G6):** вход задан как `results/**/*.json*` (497 файлов, 18 из них — не JSON), сводка с
  зашитым `files=479`.
- **B3 (G2):** ложное обоснование «у `exp45b_analysis.py` относительный путь»; чекер
  `experiments/_audit_checks/paths_resolve.py` слеп к алиас-переменной (`HERE = dirname(abspath(__file__))`),
  а это и есть основатель класса.
