## Чек-лист ревью (отвечай по каждому пункту)
1. **Однозначность ℓ_rec(n,W).** Определение §4: `min{d : max_{d'∈[d,D_max]} pert ≤ 0.25·pert0}`,
   `pert0=pert(0)`, `D_max = T−cut−W`. Есть ли случаи, когда оно не определено/неоднозначно
   (pert0=0, D_max<0, D_max<8, не-монотонность pert)? Правильно ли обрабатываются границы?
2. **Dilution-check (§4).** `to_global`: резиденты на дальнем крае (D_max) vs контроль и vs
   глобальный dip вставленного. Есть ли неоднозначность (что если D_max мало, что если
   dip_global ≈ dip_ctrl)? Корректен ли порог 0.25·pert0 в определении to_global?
3. **Вердикт-пороги (§5).** DIFFUSION (ratio≥4, b>0, R²≥0.6) / ELASTIC (ratio≤2, frac_to_global≤0.4)
   / DILUTION (frac_to_global>0.6) / NOT_RESOLVED. Покрыты ли все случаи (gap 2<ratio<4,
   0.4<frac<0.6)? Приоритет DIFFUSION>ELASTIC>DILUTION обоснован? ratio при ℓ_rec(2)=0?
   Достаточно ли 4 доз (n=2,4,8,16) для R² линейной регрессии (шум)?
4. **Оси A/B и агрегация.** Медиана по докам — корректна? Объединение по W — не смешает
   масштабы? Ось A «объединённо по W» — как именно (медиана ℓ_rec по всем (doc,W) для дозы)?
5. **Гейты (§6).** S1–S8. S8 (самопроверка E-71B-механики на wiki_1, n=8, W=64, d=0,

6. **Цена (§7).** 40 форвардов, ~65–80 мин CPU. Верно ли (8×1 контроль + 8×4 дозы)? Нет ли
   скрытых форвардов (например, на бисекцию/уточнение)?
7. **Границы (§8).** Нет ли противоречия «λ=1 здоровая модель» с тем, что T8.1 нашёл

9. **Артефакты (§9).** Достаточно ли полей для интерпретации (l_rec по (n,W,doc), оси A/B,
