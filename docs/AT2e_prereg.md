## 0. Клетка одной строкой

Патчим ОДНО состояние в ОДНОЙ позиции (h_l^t += a·v), читаем логиты на t..t+8 с полной точной
Fisher P = diag(p)−ppᵀ; ищем направление, максимизирующее ОТНОШЕНИЕ будущей видимости к текущей
(подъём обобщённого Рэлея на K1, не сэмплирование хвоста), сравниваем с rank-референсом
(rank против 64 случайных — скрин; калиброванное сравнение — идентичный поиск на random-модели,
r3 M5), пер- (l,t), с линейным гейтом по амплитудам, гейтом здоровья знаменателя (знаменатель
выше численного пола) и split-half по k (out-of-sample по K2, r3 N1).
Дешёвая стадия даёт нижнюю границу: «найдено» — существование
установлено; «не найдено» — «не найдено в B₀+подъёме», НЕ «нет».

## 2. Базисы (B₀ и направления)

B₀ per cell (32 направления, ‖·‖=1, все f64-считаются, f32-применяются): ортонормальность —
**внутри групп** (r3 N3); между группами (gQR ⊥ PCA) — НЕ ортогонально, это зафиксировано и
учтено в явном pencil (G = BᵀB, §3.3). GS по всем 32 НЕ делается: gQR-часть стала бы «гауссовы,
спроецированные ⊥ PCA-16» — другой ансамбль, чем референс (чистый gQR), и инвариант 16 ломался
бы по-настоящему.
- **8 top-PCA**: SVD центрированной матрицы hidden-состояний слоя L на 128 позициях дока
  (128×1024, из baseline-forward output_hidden_states — 0 доп. форвардов); top-8 главных направлений
  (ортонормальны по построению SVD).
- **8 bottom-PCA**: последние 8 из 127-мерного sample-пространства (ранк ≤ 127; «bottom» — произвольный
  базис sample-null-space; ортонормальны по SVD). Метка обязательна: **sample_null_space**, НЕ
  «каноническое низковариантное подпространство» (response §2).
- **16 gQR (per-cell seed)**: A = RandomState(SEED + cell_id).standard_normal(16, 1024); направления
  = **столбцы QR(Aᵀ)** (1024×16: unit + ортонормальные, Stiefel-Haar; r3 N2: строки R из reduced QR
  широкой (16×1024) — НЕ unit/не ортогональны — численно проверено: нормы ~30–33, cos ~0.07;
  нормировка строк R без реортогонализации — не гауссов ансамбль, тоже исключён). Метка gqr_cellseed.
  **r2 (B3): строки Sylvester–Hadamard (Уолш) исключены**: (a) ансамбль отличается от гауссового
  референса — нарушена обмениваемость rank-теста при H₀; (b) фиксированность по всем 16 клеткам —
  коррелированные траектории и FOUND, FWER-декларация при независимости неверна; (c) метка «Haar»
  ложна (AT2c/AT2d — настоящий QR-Хаар, другой объект под одним именем). Референс (§3.6) — то же
  семейство (столбцы QR(Aᵀ_ref), Aᵀ_ref из стандарт_normal(64, 1024)).

Свойства: B₀ зависит от (дока, слоя, per-cell seed) — position-специфичность через PCA +
отсутствие межклеточной фиксированности через per-cell gQR (r2: фиксированность Адамара снята).
Каждое направление нормируется (f64); **гейт: max |‖v‖−1| < 1e-9 И max |G−I| < 1e-9,
G = BᵀB per-группа** (r3 N2/N3: и нормы, и ортогональность внутри групп).

### 3.2 Patch-forward (одна позиция, центральные разности)
Патч: выход слоя L в позиции t: out[:, t, :] += a·v (in-place на clone — autograd-верно, проверено:
inplace ≡ functional-хук точно, pre-study r1). a = ε_a·‖h_t‖ (инвариант 12).
Центральные: z⁺ = F(+a·v), z⁻ = F(−a·v) → Δz_s^{cent} = (z⁺_s − z⁻_s)/2, s = t..t+H
(инвариант: центральные, точность O(a²)). **Критичная индексация (r1 self-audit): текущий ответ =
logit в позиции t (предсказывает токен t+1) — s = t, k = 0; будущее = s = t+k, k = 1..H.**
J_s = ∂z_s/∂h_l^t: J_0 (позиция t — текущий, знаменатель), J_k, k≥1 (будущее, числитель).
Из z⁺, z⁻, z⁰ (бесплатно из тех же forward):
- Δz_s⁺ = z⁺_s − z⁰_s (one-sided, для κ и floor-оценок), Δz_s^{cent} = (z⁺_s − z⁻_s)/2 (для q);

  (инвариант 4: q И κ отчитываются оба; κ ≈ ½q в линейном режиме — классический результат
  pullback-Фисхера через softmax);

  в t и в t'; цена 0 — повторные 256 forward для t96 не нужны). Независимость клеток: разные (док, L) —
  разные фреймы (16 фреймов на 16 клеток); обмениваемость rank-теста при H₀ не меняется (r3 N3/M5 —
  подъём, не состав B₀).
  направления = **столбцы QR(A_refᵀ)** (1024×64 unit-ортонормальная кадра, Stiefel-Haar; r3 N2 —
  строки R из wide-QR не unit/не ортогональны) — то же семейство ансамбля, что gQR-часть B₀
  (r2 B3; per-cell seed — независимость клеток); r3 N3/M5: обмениваемость rank-теста при H₀
  обеспечивается подъёмом (v* — фиксированная траектория, не старт и не референс), а не составом B₀;
  **r4 m6 (subset запинен)**: pos-spec-subset (§3.10) = первые 16 в порядке столбцов QR(A_refᵀ)
  (тот же объект, что N=64) — при n=16 p10 интерполируется между 2-м и 3-м порядковыми, состав
  subset влияет на порог;
- per направление: q_k per k (все k), λ_ε(τ) per τ, ρ (при q_t > 10·floor), per окна {1,2}, {4,8};
- **rank-тест (первичный, инвариант 14)**: per τ: rank_τ(v*) среди {v*, r_1..r_64} по λ_ε(τ);
  **p_cell = 1/(N+1) = 1/65 приписывается K2-rank (out-of-sample, r4 m5)**; полный-λ rank —
  отчёт, НЕ калиброван (содержит in-sample K1 — при H0 его rank инфлирован поиском);
  **FWER (r2 B4, пересчёт; восстановлено в r5 — потеряно при r4-редактиве)**:
  P(rank-1 где-то в 16 клетках | H₀) = 1−(1−1/65)^16 ≈ 22% — это per-cell-аларм-рейт, НЕ FWER
  глобального гейта. FWER глобального гейта (≥4 клетки FOUND/SHO, FOUND ≥2, И из ≥2 разных
  доков, §5) ≤ 2.0%: per-док p = 1−(1−1/65)^4 ≈ 6.01% (верхняя граница при независимости
  внутри дока), P(≥2 из 4 доков) = 1 − (1−p)⁴ − 4p(1−p)³ ≈ 2.0%; стадия 1d (r5 R1) —
  дополнительная конъюнкция на FOUND/SHO → FWER только уменьшается;
- effort-match: N=64 ≈ полное число оценённых направлений в поиске (32 пробы + 8 шагов + верификация)
  (response §0).

### 3.7 Split-half (per cell, 0 доп. forward) — **r3 N1: согласовано с §3.4 (подъём на K1)**
- Первичное: поиск v* на окне K1 = {k=1,2} — **подъём максимизирует λ_{ε}^{K1} = 2·q̄_{k∈{1,2}}/(q_t + a²ε)**
  (Σ_{k∈K1}, §3.4); валидация:
  rank по λ_{ε}^{K2}, K2 = {k=4,8}, против тех же 64 random (их λ^{K2} — бесплатно из 3.6).
  **K2-rank — out-of-sample относительно ПОИСКА: v* не использовал k=4,8 в поиске (инвариант 7
  держится по построению, N1); окно K2 также входит в ρ (ρ — гейт-условие на ПОЛНОМ окне k=1..8,
  вход K2 осознан: scratchpad-семантика — «будущее в целом»; out-of-sample статус K2 относится к
  K2-rank, не к ρ — r5 минор 4) и в secondary (r4 m4: «K2 не использовался» формулируется только
  относительно поиска/первичных гейтов; companion-гейт — по K1, ниже);**
- rank-условия split-half (полное per-cell определение FOUND/SHO с companion/scratchpad/
  специфичностью — §5):
  FOUND (полный) = rank-1 ≥2/3 τ на K1 И rank-1 ≥2/3 τ на K2;
- SHORT_HORIZON_ONLY = rank-1 ≥2/3 τ на K1, провал на K2 (response §2);
- secondary отчёт: обратное (поиск {4,8} → валидация {1,2}) — **подъём симметрично на K2
  (Σ_{k∈{4,8}}, N1)**, 8 итераций на подмножестве 4 клеток
  (L11/L12 × 2 дока, t=32) — 4×8×6.5 = 208 ф.-э. (0.25 ч) — входит в стадию 1 как отчётный блок.

### 3.8 G-zero (L23, 2 forward)
Патч выхода слоя 23 в позиции t (wiki/0, t=32): после layers[23] только per-position
final-norm + head → логиты t+k (k≥1) НЕ зависят от позиции t (свойство графа, не эвристика —

### 3.9 Числовой пол (floor_q, 16 замеров = 32 forward)
a_floor = 1e-9·‖h_t‖ (Δz ниже fp32-разрешения логитов ~4e-6): q(a_floor) = уровень fp32-шума.
**16 замеров × 2 forward (центральные) = 32 forward: 4 дока × 2 слоя × t ∈ {32, 96} — pre-pass
ДО клеток, дедупликация: каждый (док,L,t) меряется ОДИН раз (в r5 — дважды: как t и как t'
соседа; бит-идентично, r3 M6). (r3 M3: q_quant зависит от позиции — max|z_t| и p_max в t=96
другие; floor_q = max по 16 — ГЛОБАЛЬНАЯ верхняя граница для ВСЕХ гейтов стадии 1; стадия 1d
использует per-(док,L,t') значение (§3.11.5), НЕ глобальный max).**
**r2 (M4): floor_q := max(floor_measured, q_quant), q_quant = (2⁻²³·max|z_t|)²·p_max** — при
a_floor центральная разность двух fp32-логитов часто побитово равна → floor_measured = 0, и
companion-гейт не вырождается в хардкод 1e-12, а опирается на явную границу квантования
(пер-компонентный ulp-шум, распространённый через Var_p ≤ (макс. ошибка)²·p_max).
Companion-гейт (§3.5) против max(10·floor_q, 1e-12).

### 3.10 Positional specificity: weak-скрин (необходимое условие, r2 M5; r3 N4/M1; r4 N-new-1;
r5 R1/R2: скрин — не дискриминатор, дискриминатор — §3.11, ≤ 320 forward)

**r5 R1 (принято)**: двойной гейт r4 (p10 + ratio(v₀)) закрыл effort-match частично: v₀ отобран
из 32 проб, v* — из 32 проб + 8 градиентных шагов → «оба отобраны в t» верно, но v* отобран
сильнее (прирост подъёма g = λ(v*;t)/λ(v₀;t) ≥ 1): гейт ratio(v*) ≤ ratio(v₀) ⟺ g' ≤ g — почти
автоматичен, когда подъём работает, а p10-гейт остаётся смещённым (референсы неоптимизированы,
f-дефляция). **Следовательно: §3.10 — только weak-скрин (необходимое условие + early-exit);
со-первичный дискриминатор — transfer-gap стадии 1d (§3.11), где оба направления — максимизаторы
своей позиции с идентичным усилием.**

Для каждой клетки, прошедшей rank (K1) + companion: тот же v* в другой позиции того же дока
(t=32↔96), 2 forward + baseline (бесплатен):
- **r5 R2 (эстиматор и амплитуда запинены)**: ВСЕ pos-spec-замеры (v*, v₀, референсы — в обеих
  позициях) — **центральные разности при a_hi**, тот же фиксированный ε; знаменатель
  λ^{K1,ε}(v;t) — из верификации v* при том же a_hi-центральном (0 доп. forward). r4-текст
  содержал два чтения («2 forward (a₁, a₂)» = one-sided на двух амплитудах для v*/v₀ и
  «2 forward ±a₁» = центральные на одной для референсов) — разные эстиманды (O(a) vs O(a²)-
  загрязнение), при p10 от 16 значений (интерполяция между 2-м и 3-м порядковыми) сдвиг в
  несколько % материален. С r5 — один эстиматор везде; смета не меняется (2 forward на
  направление в обоих чтениях);
- **r3 N4 (фиксированный ε)**: ε = τ_primary·ε₀(t) — ОДИН ε из ИСХОДНОЙ клетки в обоих замерах
  (при плавающем ε₀(t') в ε-доминируемом режиме λ ∝ 1/ε₀ → ratio флипается от смены
  регуляризатора). Вариант с ε₀(t') — диагностика-отчёт;
- **κ-флаги в t'** (N4): |2κ_s(t')−q_s(t')|/max(q_s,floor) ≤ 0.5 для всех s = t'..t'+H — из тех
  же логитов (бесплатно);
- **r3 M1 (калиброванный порог)**: из 64 референсных направлений клетки t берём r_1..r_16
  (r4 m6: первые 16 в порядке столбцов QR(A_refᵀ)) и прогоняем их в t' (2 forward, центральные
  a_hi, тот же фиксированный ε) → ratio_ref per направление (16 парных замеров);
- **r4 N-new-1 (v₀)**: v₀ = argmax_{b∈B₀} λ^{K1}(b;t) прогоняется в t' (2 forward, центральные
  a_hi, фикс. ε) → ratio(v₀);
- **отчёты (0 forward)**: r* = argmax_{r∈ref₁₆} λ^{K1}(r;t) → ratio(r*);
  f = λ^{K1}(v*;t)/median(λ^{K1}(ref₁₆;t)) — величина инфляции знаменателя (читается вместе с
  исходом 1d).

**Скрин (r5): pos_spec_ratio(v*) = λ^{K1,ε}(v*;t')/λ^{K1,ε}(v*;t) ≤ p10(ratio_ref) И
pos_spec_ratio(v*) ≤ ratio(v₀)** — необходимое условие: провал → **POSITION_GENERIC**
(финально, 1d не гоняется — провал скрина сильнее, чем его прохождение: смещение р4 было
в сторону ложных прохождений); прохождение → клетка-кандидат на стадию 1d (§3.11).
Цена: v* и v₀ в t' — 2 forward each: worst case 16 кл. × 2 × 2 = 64; референс —
8 (док,слой)-пар × 16 × 2 = 256 forward (≈ 0.31 ч) — в смете стадии 1.

### 3.11 Стадия 1d — transfer-gap (условная, со-первичный дискриминатор, r5 R1)
Только для клеток-кандидатов стадии 1 (companion OK + rank-1 K1 ≥2/3 τ + scratchpad-сигнатура
[ρ > p90_ref OR denom_below_floor] + скрин §3.10 пройден). Для каждой такой клетки — в t' того
же дока:
1. **B₀(t')-проба**: 32 направления × 2 forward (центральные a_hi, фикс. ε из исходной клетки,
   r3 N4) = 64 ф.-э. → λ^{K1,ε}(b; t') per b;
2. **v₀(t') = argmax_{b∈B₀} λ^{K1,ε}(b; t')**; **независимый подъём в t'** — те же
   гиперпараметры, что подъём в t (§3.4: 8 итераций, η-адаптация, K1-объект, ε = фикс. ε) =
   8 × 6.5 = 52 ф.-э.; **v*_{t'} = argmax траектории i = 0..8 (v₀(t') включён, правило m3)**;
3. λ^{K1,ε}(v*; t') — уже измерено в стадии 1 (pos-spec блок, 2 forward) — 0 доп. ф.-э.;
4. **гейт (r5 R1, препрегистр. маржа 0.3)**: оба направления — максимизаторы СВОЕЙ позиции с
   идентичным усилием (32 пробы + 8 шагов в своей позиции) → сравнение не конфаундится ни
   поиском, ни составом:
   **λ^{K1,ε}(v*; t') ≤ max(10·floor_q(t'), 0.3·λ^{K1,ε}(v*_{t'}; t'))**;
   эквивалентно gap = λ(v*;t')/λ(v*_{t'};t') ≤ 0.3 при живом знаменателе (floor-терм — защита
   от мёртвого t');
   **обоснование маржи (a priori; r5 U2: модель явная)**: модель r5-симуляции —
   линейный ландшафт: generic-фон уровня L (одинаков в обеих позициях, тот же док) +
   scratchpad-контраст S в позиции t (S = 0 в t') + шум конечного поиска (32 пробы +
   8 итераций, 300 реализаций); H₀ = S = 0 в обеих позициях. В этой модели: (a) H₀ —
   оба максимизатора находят тот же generic-вектор: gap ≈ 1 (медиана 1.000,
   p10 0.998; нижний хвост 0.6/300 — шум конечного поиска); (b) специфичное: gap =
   доля generic-компоненты ≈ 1/√(1+(S/L)²) → **gap ≤ 0.3 ⟺ S/L ≥ 3.18** (при
   S/L = 3 gap = 0.316).
   **Задекларированное допущение (r5 U2)**: gap ≈ 1 при H₀ требует, чтобы generic-
   максимизатор был примерно одним и тем же вектором в t и t' (generic top-λ
   подпространство не поворачивается с позицией). Эмпирический sanity-якорь маржи
   (0 forward, из стадии 1): распределение ratio_ref (§3.10) — это и есть
   λ(r;t')/λ(r;t) по 16 парным референсам + ratio(r*) — если масса массово ≪ 1,
   допущение нарушено → маржу читать с оговоркой (интерпретация, не перегейт,
   не перепуск). Near-threshold
   полоса gap ∈ (0.3, 0.5] — флага-отчёт (вердикт не меняется); при кластере кандидатов в
   полосе — обсуждение при интерпретации, без перегейта;
5. **тест-страж**: если λ^{K1,ε}(v*_{t'};t') ≤ 10·floor_q(t') (t' — мёртвая позиция) →
   вердикт клетки — **NOT_TESTABLE** (одна метка для этого случая в §3.11 и §5, r5
   гигиена; клетка НЕ считается в «denom+companion OK ≥ 8» для NOT_FOUND_IN_SUBSPACE —
   её t'-замер невалиден); floor_q(t') = per-(doc,L,t') значение из 16 floor-замеров
   стадии 1a (§3.9: t' = 96 входит в 16), НЕ глобальный max (r5 гигиена: формула
   однозначна);
6. **семантика (явно, r5)**: если направление, найденное в t, читаемо в t' (в т.ч. через
   рекуррентное состояние GDN), гейт засчитает его как НЕ-специфичное — это корректно: «скретчпад
   в точке» локален; широко читаемый канал — generic, и так должно читаться.

**Исход**: pass → FOUND (при rank-1 K2 ≥2/3 τ) или SHORT_HORIZON_ONLY (при провале K2);
fail → **POSITION_GENERIC** (финальный вердикт клетки: экстремальное отношение O/C есть,
специфичности точки нет — свойство модели).
**Несходимость подъёма консервативна (r5)**: если подъём в t' (или в t) не сошёлся —
λ(v*_{t'};t') занижен → gap завышен → FOUND меньше: `ascent_not_converged` — безопасный
флаг, не дыра.
**Цена: 64 + 52 = 116 ф.-э. на клетку-кандидата; worst case 16 × 116 = 1856 ф.-э. ≈ 2.2 ч**
(условная стадия по образцу 1b, в смете §6; T4: ≈ 2 с wall — пренебрежимо).

### 3.13 Recovery-ветка по амплитуде (r7; r9 N1/N3/R4 — скоуп и readout) — УСЛОВНАЯ, ≤ 5 клеток
- **Триггер (запинено, r7)**: linear-fail на первичной сетке в normal-режиме — κ-решительный
  (правило §3.5 r6) ИЛИ L1/L2 провал. **ВНЕ: denom/below_floor-провалы (c3/c11) и fallback** —
  у них причина не в нелинейности; recovery-амплитуду они не исправят. По r3-данным под r6-правилом
  цели = {c1, c9, c13, c6} (4; c12 — больше не linear-fail: k7 вне окон → PG на первичной);
  бюджет — 5 клеток (запас: в r4-данных с новым подъёмом κ-флаги на v* могут отличаться).
- **Сетка: {a_lo_r = 1e-4·‖h‖, a_hi_r = 3e-4·‖h‖}** (верхняя точка = первичная a_lo; q падает
  в 9 раз — режим «линеен ли при 1/3 первичной дозы»).
- **Действие: полный перепуск клетки той же per-cell-функцией** на recovery-сетке (B₀-пробы,
  подъём, verify (включая κ-гейт §3.5 с тем же S_floor — floor-уровень не зависит от амплитуды),
  random-референс, rank-тест, pos-spec, 1d — **refs ОБЯЗАНЫ перемеряться на recovery-амплитуде**:
  сравнивать v*(recovery) с refs(primary) — смешать линейное с нелинейным, ровно тот дефект,
  ради которого recovery и нужен).
- **Правило решения (запинено, r7 + r9 N3)**: глобальный вердикт — **только по первичной сетке**
  {3e-4, 1e-3}·‖h‖. Recovery-клетки помечаются `amplitude_grid: recovery`, НЕ входят в
  n_found_sho/docs_found/оба дерева (в tree-счёте — своим первичным исходом, NOT_TESTABLE);
  дают **отдельный `global_recovery` (exploratory-метка, «линеен при 1/3 первичной дозы»)**.
  Вердикт клетки — по прошедшей сетке (слабое утверждение, декларируется явно).
  **Линейность провалилась на обеих сетках → NOT_TESTABLE (`linear_fail_both_grids`).**
- **Fallback-правило (r5 F3) на recovery НЕ действует (r9 N1)** — только 10·floor denom-гейт
  (см. §3.5: порог 100 амплитудно-специфичен, q ∝ a²).
- **R4-декларация (р10): recovery — readout природы κ-флага, НЕ правило решения.**
  q_k ∝ a² ⇒ |2κ−q| при recovery: genuine-нелинейность (~a³) → ÷27 (c1: 0.67·floor-уровня) →
  pass; шумовой (~floor, константа) → ≈floor → fail. Т.е. исход recovery сам различает
  природу флага, независимо от S_floor. «Все 5 пройдут» НЕ бюджетировать.
  **Denom-маржины на recovery тонкие: c6 28.0 vs 10 (2.8×), c13 44.3 vs 10 (4.4×);**
  `denom_gate_vstar` берёт q_t(v*), не медиану B₀ — может быть ниже. Если провалится — честный
  исход «позиция не тестируема в линейном режиме ни на одной доступной амплитуде»
  (предел разрешения), а не «recovery не помог» — объявлено заранее.
- **Смета: 464 ф.-э./клетку** (128 B0-пробы + 52 подъём + 4 verify + 128 refs + 36 pos-spec +
  116 1d) × ≤5 = **≤ 2320 ф.-э. ≈ 12–15 мин T4** (измеренный r3: ~170 ф.-э./мин).

## 5. Дерево вердиктов (стадия 1 + условная 1d)

### Per-cell (16 клеток; FOUND/SHO/POSITION_GENERIC — финальные, после стадии 1d)

**Приоритет веток (явный, r4 m2; r5: 1d-кандидаты уточняются 1d)**: NOT_TESTABLE → FOUND →
SHORT_HORIZON_ONLY → POSITION_GENERIC → REDUNDANT → NOT_FOUND (первая совпавшая).

**1d-кандидат (р5 §3.11)**: companion OK (по K1) + rank-1 ≥2/3 τ (K1) + scratchpad-сигнатура
[ρ(v*) > p90_ref OR q_t(v*) ≤ 10·floor_q] + weak-скрин §3.10 пройден.

- **NOT_TESTABLE**: провал линейного гейта (единое определение §3.5: normal — L1+L2;
  denom_below_floor — L1_num+L2_num+κ; fallback — κ-флаги) ИЛИ denom-гейта клетки
  (медиана по B₀ q_t(a_lo) ≤ 10·floor_q, r5 R3) ИЛИ companion-гейта (q̄_fut^{K1}(v*) < 10·floor,
  по K1 — r4 m4) ИЛИ 1d-тест-стража (λ(v*_{t'};t') ≤ 10·floor_q(t'), §3.11.5 — вердикт клетки
  NOT_TESTABLE (единая метка §3.11.5/§5, r5-гигиена; r3: синхронизировано — формулировка
  «сохраняет стадию-1-метку» убрана), клетка НЕ считается в ≥8 для NOT_FOUND_IN_SUBSPACE) →
  «не тестирована», НЕ refuted (теория §V.0, r2 B1).
- **FOUND** (финальный, после 1d): 1d-кандидат + rank-1 ≥2/3 τ (K2) + линейность (по §3.5)
  + **1d-гейт пройден** (§3.11.4: λ(v*;t') ≤ max(10·floor_q(t'), 0.3·λ(v*_{t'};t'))).
  p90_ref — перцентиль ρ(v*) в распределении ρ 64 random-референсов (r2 B5: референс измеренный,
  не prior; scratchpad-семантика: невидим в текущем ИЛИ аномально читаем в будущем).
  **p_cell = 1/65 — по K2-rank (out-of-sample, r4 m5)**; 1d-гейт — доп. конъюнкция,
  FWER только уменьшается (≤ 2%, ниже).
- **SHORT_HORIZON_ONLY** (финальный, после 1d): 1d-кандидат + провал K2 + линейность (§3.5)
  + **1d-гейт пройден** (response §2 — эффект живёт только на k=1..2; слабый, но содержательный
  исход).
- **POSITION_GENERIC**: companion OK (по K1), rank-1 (K1) ≥2/3 τ, scratchpad-сигнатура,
  и **(weak-скрин §3.10 провален — early-exit, 1d не гоняется) ИЛИ (скрин пройден +
  1d-гейт провален)** (r5 R1/R4: экстремальное отношение O/C есть, но оно — свойство модели,
  не точки; при B4 (≥2 дока) — содержательный положительный факт о модели, см. глобальную
  ветку ниже; null стадии 1b не запускается — нет кандидата).
- **REDUNDANT**: companion OK (по K1), rank-1 ≥2/3 τ (K1), q_t(v*) > 10·floor_q (a_lo) И
  ρ-rank(v*) ∈ [p10_ref, p90_ref] (r2 B5: сейчас видно + будущее доминирует, отношение
  типичное — redundancy с видимым каналом, не скретчпад. Generically ρ<1 — ветка достижима).
  (Нет scratchpad-сигнатуры → не 1d-кандидат; 1d не гоняется.)
- **NOT_FOUND (резидуальная ветка)**: companion OK (по K1) и ни одна позитивная ветка не
  накрывает — включая rank > 1 (все τ) на K1.

- **REDUNDANT_DOMINANT**: 0 FOUND/SHORT_HORIZON_ONLY, и ≥8 клеток REDUNDANT (per-cell, выше;

- **NOT_FOUND_IN_SUBSPACE**: 0 FOUND/SHORT_HORIZON_ONLY, И **r4 m7: denom-гейт клетки пройден

  стадия 2 (полный подъём на подвыборке, рестарты) — отдельное ТЗ (теория §VIII).
- **NOT_RESOLVED**: иначе.

## 7. Инварианты (18; «оптимизация» любого = другая клетка)

1. **Одна позиция, не окно** (theory §VII.1). Окно = отклик системы, не частная производная.
2. **Числитель и знаменатель — из одного forward-пара** (theory §VII.2).
3. **Полный вокабуляр, точная P = diag(p) − ppᵀ** (theory §VII.3). U128-pooled / диагональ —
   другой объект.
4. **q (оператор) и κ (отклик) отчитываются оба** (theory §VII.4); флаг |2κ−q|/max(q,floor) > 0.5.
5. **ε относительно λ_max(C_t|_B), свип τ ∈ {1e-3, 1e-2, 5e-2}; подъём — при ε = 1e-2·ε₀ (primary
   τ), тот же объект, что v₀ и вердикт** (r2 B2: поиск и эстиманд согласованы; theory §VII.5 +
   response §4.4: λ_max(C|_B) — нижняя граница полного λ_max(C), отчитывается как таковая).
6. **ρ нормировано на H (mean, не sum)** (theory §VII.6); **распределение ρ референса
   ИЗМЕРЕННО (N=64), не prior** (r2 B5: prior «ρ≈1» снят — generically ρ<1 из-за затухания,
   ветка REDUNDANT на нём недостижима).
7. **Подбор и проверка v* разделены** (split-half, theory §VII.7).
8. **Teacher forcing, не свободная генерация** (theory §VII.8).
9. **l ≤ 22; L23 только как нуль-гейт** (theory §VII.9).
10. **Кэш — только для выбора проб/report-only; ни одно вердиктное число из кэша** (theory §VII.10;
    в r1: кэш вообще не нужен для эстимандов — только cext_ref report-only).
11. **Ограничение на span(B₀) отчитывается как нижняя граница**, состав B₀ в артефакте
    (theory §VII.11). «Не найдено» ≠ «нет».
12. **Амплитуда относительная к ‖h_t‖** (a = ε_a·‖h_t‖, theory §VII.12).
13. **Guard окружения: `sys.modules["fla"] = None` ДО импорта transformers** (response §6).
    Без guard'а forward крашится (triton 3.8.0 без CPU-driver, fla 0.5.x CUDA-only).
    Инвариант окружения, не опция: определяет численный путь и саму исполнимость.
14. **Rank-тест — необходимый скрин, НЕ калиброванное сравнение (r3 M5)**. N=64 выравнивает
    ЧИСЛО оценённых направлений, не информативность поиска (подъём использует градиент Ov, Cv —
    строго информативнее 64 проб). Калиброванное сравнение — идентичный поиск на null
    (стадия 1b, условная); дискриминатор против generic-направлений модели — transfer-gap
    (стадия 1d, r5 R1; weak-скрин §3.10 — необходимое условие). Стадия 1 заявляет «кандидат»,
    не «структура есть» (staged-дизайн). Сравнение max поиска со средним случайных запрещено
    (порядковая статистика форсирует гейт). **p_cell = 1/65 приписывается K2-rank (out-of-sample,
    r4 m5); полный-λ rank не калиброван (in-sample K1)**.
15. **Companion-гейт на абсолютный q̄_fut^{K1} выше численного пола (по K1, r4 m4)** (response §6).
    Иначе большое λ_ε может быть ε-артефактом при микро-числителе. K2-окно не входит в
    первичные гейты (оно — в K2-rank, out-of-sample, и в ρ, полное окно — декларированный отчёт).
16. **Стартовый набор смешанный, референс — чистый gQR; обмениваемость — через подъём (r3 N3/M5)**.
    B₀ = PCA(16) + gQR(16): ортонормален внутри групп, НЕ между группами (pencil с G = BᵀB, §3.3);
    референс — чистый gQR (столбцы QR(Aᵀ), Stiefel-Haar). Обмениваемость rank-теста при H₀
    обеспечивается тем, что v* определяется фиксированной траекторией подъёма (не стартом B₀ и
    не референсом), а не тождеством составов. Адамар/Уолш исключён: расхождение ансамблей,
    межклеточная фиксированность (корреляция FOUND, FWER), ложная метка «Haar». Строки R из
    wide-QR исключены (r3 N2: не unit/не ортогональны — численно проверено).
17. **Знаменатель выше пола** (r2 B1/M4, r5 R3: на a_lo): клетка testable только при медиане по B₀
    q_t(a_lo) > 10·floor_q;
    для v* — q_t(v*) > 10·floor_q либо режим denom_below_floor (линейные гейты → отчёт).
    floor_q = max(замер, (2⁻²³·max|z_t|)²·p_max) — явная граница квантования при degenerate-замере.
18. **Transfer-gap (r5 R1)**: со-первичный дискриминатор специфичности — независимые максимизаторы
    СВОЕЙ позиции (B₀-проба + 8 итераций подъёма в t и в t' отдельно), идентичное усилие,
    один фикс. ε из исходной клетки; маржа 0.3 — препрегистр (модель + эмпирический якорь —
    §3.11, r5 U2; при H₀ gap ≈ 1, gap ≤ 0.3 ⟺ S/L ≥ 3.18). Weak-скрин §3.10 —
    необходимое условие (early-exit), НЕ дискриминатор (r4-двойной гейт фильтровал только
    анти-специфичный случай, r5 R1).

Центральные разности + f64-аккумуляция квадратичных форм — часть инварианта 2/3 (точная P).
Thread-pinning (OMP/OPENBLAS/MKL=4 ДО импортов, torch 4 тр.) — дет-условие инварианта 1 (как в AT2d).
