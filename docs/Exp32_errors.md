### 2. Остающийся критический баг: `resid_frac_t` (S vs T)

```python
resid_frac_t = np.zeros((S, NEPS))          # ← S = 128 (module constant)
for e in range(NEPS):
    num = np.linalg.norm(resid[:, :, :, e], axis=(1, 2))   # [T]
    den = np.linalg.norm(dz_all[:, :, :, e], axis=(1, 2))  # [T]
    resid_frac_t[:, e] = num / np.maximum(den, 1e-12)      # ← [T] → [128]
```

`resid` имеет форму `[T, K, K, NEPS]`, `num` — `[T]`. При `T=64` (все слои кроме L23) присваивание `resid_frac_t[:, e] = num` бросает `ValueError: could not broadcast input array from shape (64,) into shape (128,)`.

Причина: **шаг инъекции/reshape починили, а инициализацию `resid_frac_t` — нет**. В предыдущей версии `T=128=S` для всех слоёв, поэтому баг не проявлялся. С введением `T=64` для не-L23 он обязательно выстрелит.
