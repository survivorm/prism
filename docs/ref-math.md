**Пространства.** Token-пространство — векторы длины `K` (направление `u`, ESG-собственные векторы `JJ^T`). Hidden-пространство — векторы длины `D` (`v`, правые сингулярные векторы `J^T J`). Uniformity определён только для векторов token-пространства; применять его к `v_g` (hidden) — ошибка.

**Линейный (first-order) режим.** Все формулы в этой части — линейные: первое-порядковое отображение `J: δh ↦ J·δh`, `ESG = JJ^T`, `E_K = J^(p)J^(p)ᵀ`. Допустимость: E-32r.3 — $s_l = 0.0016–0.0726 \ll 0.3$ на всех 6 слоях, slope ≈ 1.0, quad_frac 0.8–3.1%; квадратичные/кубические члены — §ref-exp (блок 4.5/4.7) (E-32r.2–r.3), desync-профиль.

**Обозначение «𝒮» против «𝒰».** В v3.3 набор токенов обозначался `𝒰`; в v4.0 — `𝒮` (support), чтобы не путать с `U` (ESG, §paper §3) и `U_r` (defrag, §paper §3). JSON-артефакты не переименованы — см. глоссарий, Приложение A.

## 2. Глоссарий

Расширенные определения понятий с прозой. Однозначные символы — в §ref-math §1 (индекс символов); здесь — понятия, у которых есть семантическая нагрузка, два смысла или которые легко спутать.

| Термин | Определение | Каноническая секция |
| --- | --- | --- |
| **v3.3 → v4.0 (история)** | v3.3 — предшествующая редакция спецификации; v4.0 — текущая. Разведённые термины: (1) `gap` (lower=better) vs `bridge` (higher=better) — до v4.0 оба имени означали одно; (2) `gauge_share_softmax` vs `gauge_share_raw` (строка «gauge_share — два смысла» ниже); (3) `𝒮` (v4.0) vs `𝒰` (v3.3) для токен-сета; (4) дефолт τ: 10⁻⁶ (v3.3, decay-маска) → 0 (v4.0, sentinel-only). | **gap (разрыв)** | $\mathcal{G}_{\text{gap}}(l) = \sum_{i \in \mathcal{S}} w_i\,(1 - \cos(J_S[i], J_S^{\text{target}}[i]))$ — вероятностно-взвешенное среднее $(1-\cos)$ по токенам $\mathcal{S}$, $w_i = p_L(i)/\sum_j p_L(j)$ (нормирована на $\mathcal{S}$; асимметрия осознанна — система отсчёта старшей модели). $\in [0,2]$: 0 — коллинеарны, ≈1 — уровень ортогональности. **Меньше = лучше**. Эксперименты 1–15 отчётуют gap. | §paper §3, §paper §3 |
| **bridge (мост)** | $\mathcal{B}_{\text{bridge}}(l) = \sum_{i \in \mathcal{S}} w_i\,\cos(J_S[i], J_S^{\text{target}}[i])$ — то же, что gap, но среднее $\cos$: $\mathcal{G}_{\text{gap}} = 1 - \mathcal{B}_{\text{bridge}}$ (при совпадающих весах). **Больше = лучше**. Эксперименты 16–19 отчётуют bridge (higher-is-better). Исторически именовалось «Л_bridge» — вызывало путаницу, в v3.3 разведены. | §paper §3, §paper §3 |

| **gauge mode / uniform mode** | Направление $\mathbf{1}/\sqrt{K}$ в token-пространстве (common-mode, uniform shift). Softmax инвариантен к нему, но он несёт сигнал уверенности (E-10a, E-10d). | §paper §3 |
| **gauge direction** | Правый сингулярный вектор $J$, чей левый вектор $u_g$ ≈ равномерен (в hidden-пространстве). Uniformity 0.61–0.98 (E-12a). | **desync-профиль** | Профиль расхождения $JR$ (full-path, $\partial\logits/\partial h$ через $W_{lm}$) vs $J$ forward (forward pass до слоя $l$) по слоям: $a_{vs\,ESG\,cos}$ 0.557→0.992, matrix ID cos 0.095→1.0000 (L6→L23). ## 3. Формулы E-34 (пересчёт, 2026-10-06)

## D.1 Формула null-модели

**Опровергнутая формула:** `$\mathbb{E}_Q[\mathrm{off}^2(Q\,\mathrm{diag}(d)\,Q^T)] = (S_2 - S_1^2)/2$`, где `$S_1 = \sum_i d_i$`, `$S_2 = \sum_i d_i^2$`.

**Почему неверна:** для K=2, d = (d₁, d₂) формула даёт `$\mathbb{E}_Q[\mathrm{off}^2] = -d_1d_2 < 0$` — отрицательная величина для неотрицательной.

**Точная формула** (моменты Хаара, `$\mathbb{E}_Q[q_{ij}^2 q_{ij}^2] = (K S_2 - S_1^2)/((K+1)(K+2))$`, `$\mathbb{E}_Q[q_{ij}^2 q_{ji}^2] = S_1^2/(K(K+1))$`):

$$\mathbb{E}_Q[\mathrm{off}^2(Q\,D\,Q^T)] = \frac{K S_2 - S_1^2}{K+2}$$

Проверка: K=1 → 0; K=2, d=(1,0) → `$\mathbb{E}_Q[q_{12}^4] = 1/2$` ✓.

**Код:** `experiments/exp34_p1_coupling.py::null_rho_batched` — числовое по 16 Хааровским Q, без аналитической формулы. Значения `$\rho_{null}$` из прогона 2026-10-06 12:00 получены численно и верны.

## D.2 J_rand (порядок множителей)

Верно: `$J_{rand} = Q^T \cdot \mathrm{diag}(\sqrt{ESG_{ii}})$`. В ТЗ было `diag(√ESG_ii)·Q` — опечатка: `$ESG_{rand} = J_{rand}J_{rand}^T = \mathrm{diag}(ESG_{ii})$`, offdiag ≡ 0, дегенерация калибровки. Тот же член ТЗ (`$\mathbb{E}_Q[\mathrm{off}^2(Q D Q^T)]$`) подтверждает порядок `Q D Qᵀ`.

## D.3 Порядок P·ESG·P

`$A = P\,ESG\,P$`: cross-члены через elementwise `p⊙(Ep)`, не `Ep` (ТЗ-формула была неточной, код корректен). `$\mathrm{off}^2(ESG - \lambda_1 u_1 u_1^T) = \|ESG\|_F^2 - \lambda_1^2$` (не −λ₁).

## D.4 Уровни 1/2/3 и условия

Иерархия — в §paper §3 («Иерархия уровней»): уровень 3 = `J → ESG → P(p)ESG P(p) → E_r` (точный); уровень 2 = `P(p)·J`, `P_u M diag(√D/√(r·r)) Mᵀ P_u`, `P_u AᵀA P_u` (редуцированный, приближённый); уровень 1 = `M diag(√D/√(r·r)) Mᵀ`, `AᵀA`, `ESG` без проекций (только `L = L_max`). Условие `p ≈ uniform` требуется для совпадения уровней 2 и 3 (`P·ESG·P ≈ ESG − λ₁u₁u₁ᵀ` при `u₁ ≈ 1`); оба числа вычисляются, `$|\rho_{gf} - \rho_{top1}|$` — сигнал p-фокуса (E-34).

## 4. Доказательства формализации [M-1]–[M-5] (2026-10-08)

## E.1 [L-gauge-J]: структурное тождество gauge-направления

**Дано.** Факторизация L23 (E-35, точна): `J = c·M·(I − ûûᵀ)`, `c = √D/r_t`, `M = M_K ∈ R^{K×D}`, `û = û_t`, `‖û‖ = 1`. Определение `w = Mᵀ·(1/√K) = αû + βv_⊥`, `α = ⟨w, û⟩`, `β = ‖w − αû‖ ≥ 0`, `v_⊥ = (w − αû)/β` (`β > 0`; случай `β = 0` — следствие ниже).

**(1).** `Jᵀ·(1/√K) = c·(I − ûûᵀ)·Mᵀ·(1/√K) = c·(w − ⟨û, w⟩û) = c·β·v_⊥`. Использованы: `(I−ûûᵀ)` симметричен и самопроективен, `ûᵀû = 1`, `ûᵀv_⊥ = 0`.

**(2).** Нормирование: `‖Jᵀ(1/√K)‖ = c·β > 0` при `β ≠ 0`, и знак `v_⊥` фиксирован разложением `w` — `v_pred = Jᵀ(1/√K)/‖·‖ = v_⊥` (знак совпадает, не «с точностью до знака», при данной конвенции).

**(3).** `v_g` — правый сингулярный вектор `J` с левым `u_g`, максимизирующим `|cos(u_g, 1/√K)|` (определение §paper §3). Разложение `1/√K` по левым сингулярным векторам: `1/√K = Σ_k cos(u_k, 1/√K)·u_k`, откуда `Jᵀ·(1/√K) = Σ_k σ_k cos(u_k, 1/√K)·v_k` — в общем случае вклад имеют **все** моды, и векторное равенство `Jᵀ(1/√K) = σ_g cos(u_g, 1/√K)·v_g` **неверно** (оно было бы эквивалентно `v_⊥ ∥ v_g`; численно `(√D/r_t)β ≈ 5.0` при `σ_g|cos(u_g, 1/√K)| ≈ 0.0007`). Корректная версия — скалярное тождество

$$\langle J^T(1/\sqrt K),\, v_g\rangle = \sigma_g \cos(u_g, 1/\sqrt K),$$

тавтология при определении `v_g` (проекция разложения `1/√K` на `u_g`).

Неравенство: `c·β = ‖Jᵀ(1/√K)‖ ≥ σ_g·|cos(u_g, 1/√K)|` (Коши–Буняковский для разложения `1/√K` по базису левых сингулярных векторов: `‖1/√K‖ = 1 = Σ_k cos²(u_k, 1/√K)`). **Равенство** т. и т.т., когда `cos(u_k, 1/√K) = 0` для всех `k ≠ g` — т.е. `1/√K` лежит в span(`u_g`), эквивалентно `v_⊥ ∥ v_g` (преобраз uniform-направления — точно gauge-направление). Численно (E-33r): `cos(u_g, 1/√K) ∈ [0.85, 0.99]` — неравенство близко к равенству, сдвиг ~15%.

**Следствие.** `β = 0 ⇒ Jᵀ(1/√K) = 0 ⇒ 1/√K ∈ ker Jᵀ = (im J)ᵀ ⇒ 1/√K ⊥ im J ⇒ cos(u_g, 1/√K) = 0` — противоречие с измеренным `[0.85, 0.99]`. Значит `β ≠ 0`. Идеализация `u_g = 1/√K` (все левые векторы ⊥ 1/√K, кроме `u_g`) читается как: `1/√K = u_g ⇒ ‖Jᵀ(1/√K)‖ = σ_g`, то есть равенство в (3) — противоречие с `β = 0` (тогда `σ_g = 0`, противоречие с `σ_g/σ_d ≈ 40×`, E-12a).

**Что это исправляет.** Формулы с `J⁺`/`M_K⁺`: `‖J⁺·1‖` доминируется хвостом спектра (`1/σ_k`), а не gauge-режимом — неверный alignment-фактор. Корректная версия — (3) с множителем `cos(u_g, 1/√K) ≈ 0.85–0.99`; без него `‖Jᵀ(1/√K)‖` переоценивает gauge-компоненту на ~15% (E-33r).

## E.2 [D-holonomy]: спектр H₀₁₂ и тождества

`R_ij` и `H = H₀₁₂ = R₀₁R₁₂R₀₂⁻¹` ортогональны, в общем случае из `O(r)` (без det-fix, §paper §3). Для чётного `r = 2m` с `det H = +1` и без собственных значений ±1 (случай измеренного `κ = 0.018`: `H ≈ I`) собственные значения — комплексно-сопряжённые пары `e^{±iθ_j}`, `θ_j ∈ [0, π]`, ровно `m` пар; трассовое тождество верно в этом случае, `κ²`-тождество — для любой ортогональной `H`.

**Трассовое тождество.** `tr(H) = 2Σ_j cosθ_j` — непосредственно из спектрального разложения; базисно-независимо: `tr(OᵀHO) = tr(H)`, сопряжение сохраняет характеристический многочлен.

**Тождество для κ.** Для ортогональной `H`: `‖H − I‖_F² = tr((H−I)ᵀ(H−I)) = tr(HᵀH − Hᵀ − H + I) = 2r − 2tr(H)` (использовано `tr(Hᵀ) = tr(H)` — собственные значения вещественно-парные). Подстановка `tr(H) = 2Σcosθ_j`: `κ² = 2r − 4Σ_j cosθ_j = 4Σ_j(1 − cosθ_j)`. Оба тождества — согласованность с числами E-28: для `r = 16`, `κ = 0.018`: `κ² = 0.000324 ⇒ Σ_j cosθ_j = (32 − 0.000324)/4 = 7.999919`, т.е. все 8 углов `≈ 0` (каждый `θ_j ≲ 0.013 rad` при равномерном распределении) — ротации малы, «rigid-but-curved».

**Базисная независимость инвариантов.** `κ` и спектр `{θ_j}` не зависят от выбора базиса внутри `V_t`: смена базиса `V_t → V_t O_t` (`O_t ∈ O(r)`) даёт `R_ij → O_iᵀ R_ij O_j`, и `H → O₀ᵀ H O₀` (сопряжение) — спектр и `‖H − I‖_F` инвариантны. Разложение на компоненты зависит — фиксация `[D-holonomy-frame]`.

## E.3 [M-3]: локальная сферическая кривизна

`u, v, w` — единичные векторы на `S^{D−1}`, `A(u,v) = arccos⟨u,v⟩ ∈ [0, π]` — геодезическое расстояние. Тройка лежит на одной геодезике (меньшем большом круге) т. и т.т., когда один вектор — выпуклая комбинация двух других в подходящем смысле: если `w` лежит на кратчайшей дуге между `u` и `v` (и `A(u,v) ≤ π`), то `A(u,w) + A(w,v) = A(u,v)`; обратное — классическое (строгая выпуклость метрики сферы: равенство в треугольном неравенстве т. и т.т. коллинеарности на сфере).

`Ω(t) = |A(u,v) + A(v,w) − A(u,w)|` — отклонение от равенства в одном из треугольных неравенств: `Ω ≥ 0` всегда (треугольное неравенство + симметрия по перестановкам через абсолютное значение), `Ω = 0` т. и т.т. когда тройка коллинеарна на сфере (лежит на одной геодезической). При `D ≥ 3` (в задаче `D = 1024`) тройка единичных векторов в общем положении **не** лежит на одной геодезике — `Ω > 0`; при `D = 3` геодезикам соответствуют круги в `R³`, и `Ω` связывается с телесным углом, но для `D ≫ 3` это диагностический скаляр (локальный Abelian-proxy кривизны траектории `û_t` по сфере), а не точный телесный угол. Численно: `A ∈ [0, π]`, `Ω ∈ [0, 2π]`, вычисление устойчиво при `arccos(clip(·, −1, 1))`.

## E.4 [M-4]: pre-flight применимости неабелева формализма

Неабелев формализм (разложение `H₀₁₂` на компоненты в eigenframe `M_K`, `[D-holonomy-frame]`) требует **разрешимости топ-r подпространств** — чтобы каждый сингулярный вектор транспортировался независимо, без перемешивания внутри топ-r блока.

Критерий: `gap_min(t) = min_{i=1..r−1}(σ_i(J_t)² − σ_{i+1}(J_t)²) > 0` (все внутренние зазоры положительны) ⇒ топ-r правое подпространство `J_t` изолировано от хвоста, формализм неприменим в смысле «каждый вектор отдельно» — подпространство жёсткое. Порог `ε = 0.01·σ₁²` (численно значимый зазор): `min_t gap_min(t) > ε` ⇒ неабелев формализм **неприменим** (все зазоры разрешимы); `< ε` ⇒ допустим, не обязателен.

Контекст чисел: E-27.6 T6 `r_eff = 24.4–31.6` — спектр `JJᵀ` плоский, намёк на малые внутренние зазоры. E-35 `eigengap_{16/17}(M_K) = 1.035` — это зазор между `σ₁₆` и `σ₁₇` **матрицы `M_K`** (граница топ-16 блока), а не внутренние зазоры `J_t`; pre-flight измерит именно внутренние `gap_min(t)` попозиционно на кэше, исправляя эту неточность.

**Moratorium.** WZ-терминология и каноническое трёхчленное разложение `κ` (на «сферическую», «Abelian» и «fiber» части) не вводится до прохождения pre-flight `[M-4]` и получения чисел `Ω(t)` vs `Σ_j θ_j(t)` (`[M-3]`). Нейтральные формулировки в тексте: «бесследовая часть» (`2r − 2tr(H) − κ²_сферическая`, если `Ω`-вклад мал), «разброс `{θ_j}`» (`Var{θ_j}` — неабелева мера).
