## Эксперимент 13 (`exp13_domain_esg.py`): Доменная специфичность ESG и мостов

**Цель:** проверить, насколько ESG-карты и bridge-лоссы зависят от домена калибровочных данных (текст / математика / код / агентные диалоги), и какие подпространства универсальны, а какие доменно-специфичны.

**Шаг 0 (данные):** добавить в `prism/calibration.py` параметр `domain ∈ {"wiki","math","code","chat"}`.
- Сначала проверить локально доступные датасеты (та же механика `Resolving data files`, что уже используется).
- скачать датасеты: GSM8K для математики, https://huggingface.co/datasets/mercor/apex-agents для кода, для чата поискать релевантный
- Фолбэк, если датасета нет: из имеющегося wikitext-пула собрать доменные подмножества эвристиками: `math` = фрагменты с максимальной плотностью цифр/операторов (`\d`, `=`, `+`, `-`), `code` = фрагменты с кодовыми токенами (скобки, `=`, `def`/`return`-подобные), `chat` = фрагменты с диалоговыми маркерами. Если и это невозможно — взять любой второй доступный датасет как `alt` и честно залогировать подмену.

**Параметры:** `n_samples=4`, `K=64`, `max_length=64`, слои = `[0, n//4, n//2, 3n//4, n-1]` для 0.8B; для моста — sampled-пары как в exp4 (`step = len(mapping)//5`).

**Алгоритм:**
1. Для каждого домена `d`: загрузить сэмплы, построить `token_set` из top-K логитов **большой** модели на первом сэмпле домена.
2. Для 0.8B: посчитать ESG (32 компоненты) на каждом слое, сохранить топ-8 собственных векторов `U_d[l]`.
3. Матрица пересечения подпространств между доменами: `overlap[d1][d2][l] = ||U_d1ᵀ U_d2||²_F / 8`.
4. Мост 4B→0.8B: `jacobian_bridge(J_L, J_S, E_L, E_S, probs)` по sampled-парам, `probs` из логитов большой модели на сэмплах домена `d`.

**Метрики в JSON:** `spectra[d][l]` (trace, top5), `overlap[d1][d2][l]`, `bridge[d][pair]`.

**Ожидания / критерии:**
- Топ-направление (gauge) универсально: overlap по v₁ между любыми доменами > 0.9.
- Дифференциальные подпространства (компоненты 2–8) в средних слоях доменно-специфичны: overlap(math, wiki) заметно ниже overlap(wiki, wiki-подмножества); поздние слои — промежуточно.
- Bridge-кривая по слоям сохраняет монотонный спад на всех доменах (Spearman ≤ −0.7), но абсолютный уровень может отличаться.

## Эксперимент 14 (`exp14_snr_pr.py`): SNR и Participation Ratio по слоям

**Цель:** послойно quantифицировать структуру спектра ESG (эффективная размерность) и согласованность Якобиана между сэмплами (SNR), в привязке к типам слоёв (GDN vs full).

**Параметры:** модель 0.8B, **все 24 слоя**, `n_samples=4`, `K=64`.

**Алгоритм (на слой):**
1. `J_s` для каждого сэмпла; `M = mean_s J_s`; `ESG = mean_s (J_s J_sᵀ)`.
2. Спектр `λ`; далее:
    - `PR = (Σλ)² / Σλ²` (effective rank, ∈ [1, K]);
    - `gauge_share = λ₁ / Σλ`; `uniformity(v₁)` как в exp10a;
    - `SNR_sample = ||M||²_F / max(eps, mean_s||J_s||²_F − ||M||²_F)` — отношение согласованной (межсэмплинговой) энергии к флуктуациям.
3. Сохранить `layer_type[l]`.

**Вывод:** JSON `per_layer[l] = {PR, gauge_share, uniformity, SNR, trace, layer_type}` + PNG: PR и SNR (log-y) против глубины, точки раскрашены по типу слоя.

**Ожидания:** PR растёт с глубиной (спектр расплывается), gauge_share падает, SNR_sample падает к поздним слоям (Якобиан всё более sample-зависим). Скачки/изломы коррелируют с границами full/GDN.

## Эксперимент 15 (`exp15_gdn_anchors.py`): Сдвиг anchor-слоёв и фазы вычислений

**Цель:** проверить, что тренд конвергенции моста не артефакт фазы выборки скрытых состояний (выход full-attention vs GDN-блока).

**Схемы якорей** (индексы строить из `config.layer_types`):
- **A (full):** якоря = индексы full-attention слоёв (ожидается 3,7,11,15,19,23 у 0.8B); у 4B — свои full-индексы; пары — пропорционально по номеру внутри списка.
- **B (post-full):** якоря = full-индекс + 1 (первый GDN после full), clip по длине.
- **C (pre-full):** якоря = full-индекс − 1 (последний GDN перед full), clip ≥ 0.

**Алгоритм:** одни и те же сэмплы (`n=1..2`, `K=256` как в exp4) для всех схем; для каждой схемы — bridge-лосс по парам, `monotonicity` (Spearman глубина↔лосс), `Spearman(A,B)`, `Spearman(A,C)`; плюс ESG-trace на якорях 0.8B для каждой схемы.

**Ожидания:** монотонный спад устойчив во всех схемах (Spearman ≤ −0.7); абсолютный лосс на full-якорях ниже в поздних слоях (глобальное смешивание выравнивает представления), на post-full — выше. Если в какой-то схеме монотонность ломается (Spearman > −0.5) — это артефакт фазы, фиксировать как ограничение метода.
