# Часть I. Постановка

## 1. Мотивация, цели, статус

**Задача.** Дать инструментарий анализа геометрических свойств трансформерских LLM — не через активации, а через **якобианы** `p` (выходные вероятности) по скрытым состояниям `h_l` промежуточных слоёв.

**Ключевая интуиция.** Для задач с softmax-выводом (классификация, LM) важны не все компоненты `h_l`, а только их проекция на пространство, реально влияющее на `p`. Математически это выражается через Якобиан `∂p/∂h_l`: он кодирует, какие направления в `h_l` двигают распределение выходов, а какие — нет.

**Четыре уровня анализа (P0–P3):**

| Уровень | Что измеряем | Метрика | Статус |
|---------|-------------|---------|--------|
| P0 | Локальная чувствительность | `J_l = ∂p/∂h_l`, `D_l = J_l ⊙ J_l` | см. `E-1` (identity), `E-3` (грамматика), `E-5` (ESG-валидация) |
| P1 | Спектральная структура | Eigenvalue Spectral Gap (ESG): `σ₁/σ_d`, `r_eff` | см. `E-12b,c` (ESG validated) |
| P2 | Межслойные связи | Jacobian bridge `G = J_L^T J_S / √(‖J_L‖_F²‖J_S‖_F²)` | см. `E-2` (карта) |
| P3 | Причинные рычаги | `h_23 += ε·v_23`, наблюдение bridge и KL | см. `E-16a` (dose-response), `E-16b` (поведение) |

**Исследуемые модели:** Qwen3.5-2B (24 слоя) и Qwen3-8B (36 слоёв). Обе — гибридные архитектуры (linear + full attention), см. §3.

**Ограничения:** CPU-only, batch=1, N=1–4 сэмпла (статистика предварительная, см. §13, §21), S ≤ 512 (сжатие контекста при S > 1024).

**Пространства (token vs hidden):**
- **Token-пространство:** векторы длины `K` (число токенов). `u_g` — левый сингулярный вектор (token-пространство), `v_g` — правый (hidden-пространство).
- **Hidden-пространство:** векторы длины `D_l`. `v_g`, направления perturbations.

**Типы:** скаляр (число), вектор (1D), матрица (2D). Uniformity определён только для векторов из token-пространства (`u_g`), не для hidden-векторов (`v_g`).

## 3. Архитектурный контекст: Qwen3.5

**Гибридная архитектура (оба семейства):**
- `full_attention` — стандартное attention с Q, K, V, O.
- `linear_attention` — GDN (Gated DeltaNet): рекуррентная ячейка с `A_log`, `b`, `dt_bias`, `norm`, projection. **Не трансформер** — производные через рекуррентную связь, см. §9.
- `layer_types` — чередование типов слоёв.
- **GDN recurrence:** hidden state обновляется рекуррентно: `h_t = f(h_{t-1}, x_t)`. Backprop через рекуррентную цепочку.
- **MRoPE (Multimodal RoPE):** позиционные кодировки с мультимодальным разделением осей. Влияет на attention-паттерны, см. §9.
- **Tied weights:** эмбеддинг и output head могут быть связаны (`lm_head` = `embed_tokens`).

**RMSNorm — не идентичность.** `RMSNorm(h) = h / RMS(h) ⊗ γ`, где `RMS(h) = sqrt(mean(h²) + ε)`. Производная не диагональна, зависит от `h`. Каноническая производная — §8, `[L-rms]`.

**Следствие для Якобиана:** в pre-norm трансформере `J_l = ∂p/∂h_l` включает цепочку через все последующие RMSNorm'ы и attention'ы. Невозможно факторизовать `J_l` как простое произведение весов.
