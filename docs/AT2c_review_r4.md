## S2. S6 (P-zero, L193-196): 1e-10 корректно?
Да. L193-195: «W_X = 0 (rel < 1e-10) И intercept = mean(y_c,f) (rel <
1e-10)». Обоснование ответки (f64-блок-солвер, Xf = zeros, тождества в f64,
резидуал ~1e-16) проверяется алгеброй: при ТОЧНО нулевых фичах XᵀX = 0 и
Xᵀy = 0 строго (в любой точности) ⇒ W = 0/α = 0 строго; intercept =
mean(y_c,f): даже при f32-данных y_c вычисления идут в f64 (по ответке
hstack с ones апкастует Xb до f64, идентично T2.1b/диагностике) — расхождение
с np.mean — порядок 1e-16 (разность порядка редукции f64) ≪ 1e-10. Порог
исполним; отличие от k=0-режима (где 1ᵀyf ≠ 0 из f32-складки centered-дока)
— конструктивное, не противоречие. ✓
