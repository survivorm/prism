## 3. Фиксации (до прогона)

- Слои: **l ∈ {6, 12, 18, 22}** (A1: l ≤ L_max−1 = 22). L23 — только контрольная строка
  (аналог G9), не в verdict. L19 — вне клетки (доступен, диагностика).
- k-сетка: **k ∈ {1, 2, 4, 8}** (TZ: k=1 первичен для top-J, k≥2 для weak-J).
- d_eff: считать per (l,doc,S): d_eff(S) = exp(H(λ(Π_S Cov(h_l^t) Π_S))), Cov — по t в доке
  (128 выбр., float64); для per-t базисов (top/weak) — базис позиции t=0 как репрезентативный
  (зафиксировано). Matching: если max(d_eff)/min(d_eff) > 1.2 по (l,doc) — пересчёт всех
  с r' = round(min d_eff), отчитывать ОБА r (правило ТЗ).
- ε = 1e-2 (диагностический порог weak-стороны: отчитывать число λ выше ε·λ_max).
- Ridge: **α = 1.0** (фикс), один солвер (closed-form), один CV: **leave-one-doc-out**
  (32 фолда). Capacity-эквивалентность (подводный камень 6 ТЗ): один ранг/солвер/регуляризация/CV
  для всех четырёх подпространств.
- SEED = **0** для всех RNG (`torch.Generator`/`np.random.default_rng`), детерминированно.
- Bootstrap verdict: **B = 1000**, per-doc (параметры бутстрапа — документы), 95% CI.

## 4. Подпространства (определения, фиксированы)

Для позиции (l,t): JR_t ∈ R^{128×1024} (K×D), P_t ∈ R^{128} (P128, row-sum 1).

- **C_t = JR_tᵀ P_t JR_t** (1024×1024, rank ≤ 124; не материализовать в цикле — см. спектр).
- **Спектр через 128×128 Грамиан** (AB/BA-тождество, ненулевые спектры равны):
  `G_t = P_t^{1/2} (JR_t JR_tᵀ) P_t^{1/2}`; `eigh(G_t)` → (λ_i, w_i), i=1..128 (ascending).
  **Лифт в h-пространство:** `v_i = JR_tᵀ (P_t^{1/2} w_i) / √λ_i` (λ_i > 0); проверка
  `‖C_t v_i − λ_i v_i‖ / ‖C_t v_i‖ < 1e-6` (гейт S5). НЕ `G' = (JR P) JRᵀ` — это ДРУГОЙ
  спектр (проверено: top1 84.87 против 30.91 у C).
- **top-J:** r = 32 eigvec с КРУПНЕЙШИМИ λ (v_{128−31..128}).
- **weak-J:** r = 32 eigvec с НАИМЕНЬШИМИ ненулевыми λ (weak-сторона null_ε).
- **ker-J (контроль):** r = 32 ортонорм. базис null(JR_t) через SVD (λ = 0 тождественно;
  произвольный базис ядра — контрольная строка, не в verdict). Считается на выборке
  **32 (l,t) на слой** (SEED=0) — полный SVD на 16384 позициях неоправданно дорог;
  контроль-метрика — медиана ‖Пр_jer(y)‖/‖y‖ на выборке.
- **PCA_doc:** r = 32 eigvec Cov(h_l^t) по t ∈ 0..127 внутри дока (per (l,doc);
  h — из H поля файла L{l}, float64).
- **Haar:** r = 32 первых строки детерминированного Hadamard-базиса H_1024 (FWT,
  H/√1024), глобально один для всех (l,doc,t) (без сида).
- Все базисы ортонормальны (assert ‖VᵀV − I‖_F < 1e-8); проекции Π_S = V Vᵀ.

## 5. lk4-базлайн (фиксация)

Канон (цитата, `experiments/exp64_at_battery.py:23–30`):

```python
def lk4(t):
    nxt={}; hit=np.zeros(len(t),dtype=bool)
    for i in range(3,len(t)-1):
        k=(int(t[i-3]),int(t[i-2]),int(t[i-1]),int(t[i]))
        pv=nxt.get(k)
        if pv is not None and pv==int(t[i+1]): hit[i]=True
        nxt[k]=int(t[i+1])
    return hit
```

- Токены: pool_ids `ids[dom][si]` (128 int; «будущий» токен для cache t — токен forward p+1
  = индекс 127−t в ряду, существует для t ≥ 1).
- k=1: hit-rate = доля hit[i] (канон). Сопоставление с readout на ОДНОЙ шкале:
  lk4-предсказание как 128-dim U128 one-hot (или zero, если промах) → тот же cos-метрики.
- k≥2: **k-ahead lookup**: `hit_k[i] ⇔` за последним вхождением 4-граммы t[i−3..i]
  (строка i−3 в `nxt`-словаре, расширенном до +k) шёл токен t[i+k]; если вхождений <1 — промах.
  Объявлено как расширение канона (version note §1). Ограничение: i + k ≤ 127 (иначе токен
  за окном — промах по построению).
- N8-страта: позиции с канон-hit (65, t ∈ 1..124) / без (4031): readout-метрики по стратам,
  per-домен, с оговоркой о мощности (размеры стратумов в артефакте); для k > 1 —
  пересечение стратума с t ≥ k (зафиксировано).

## 6. Readout (ridge, фиксирован)

- Features: `x = Π_S h_l^t` (r-dim; центрирование по (l,doc) — фиксированный mean-сдвиг,
  один и тот же для всех S; b — свободный член).
- Target: `y = z_U128(t−k)` (128-dim, из H_L23 @ Eᵀ, без повторной нормировки).
- Метрика ПЕРВИЧНАЯ: `cos(ŷ, y)` по позициям → **медиана по позициям** (документно-медианная
  конвенция серии), отчёт per (l, k, S). Вторичные: R² (per-фолд, среднее), cos против
  среднего направления (нулевой референс), cos для цели Δz = unit(z_{t−k} − z_t) (отдельно,
  не в verdict).
- CV: leave-one-doc-out (32 фолда): fit на 31 доке, predict на выдержанном (все t ≥ k).

## 8. Вердикты (приоритет (a) > (b) > (c) > NOT_RESOLVED; L23/ker-J — контроль, не в вердикт)

- **(a) SCRATCHPAD (T2 жива):** weak-J cos > max(PCA, Haar) per (l,k) с per-doc bootstrap
  B=1000 95% CI, исключающим 0, И weak-J cos > k-ahead-lookup cos (та же машина CI) на
  **≥2 из k ∈ {2,4,8}**; «per (l,k)» агрегируется строго: k считается значимым, если оба CI
  значимы для ВСЕХ 4 l (AND-over-l, консервативно); OR-over-l — вторичная статистика в
  артефакте, не в вердикт.
- **(b) DEADWEIGHT:** на ВСЕХ k ни одно из {top-J, weak-J} не превосходит
  max(PCA, Haar) статистически (CI перекрывают 0 везде).
- **(c) REDUNDANT_BASIS (переименованный базис):** на всех k все 4 подпространства
  попарно в перекрывающихся CI (разница < CI) И на k=1 top-J ≥ остальных (без требования
  значимости).
- Не вошёл ни в один → **NOT_RESOLVED** (детали в артефакте).
- Приоритет: (a), затем (b), затем (c); смешанные случаи (a на 1 k, (b) на остальном) →
  NOT_RESOLVED с деталью (зафиксировано).
