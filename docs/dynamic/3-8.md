## 1. Теории

### Т-1. «Читатель-дифференциатор» (масштаб k≤4, λ₁-плоскость)
**Ядро**: обучение делает шаг состояния анти-персистентным: в главной плоскости шаг примерно знак-флипует (v_{t+1} ≈ −v_t, λ₁ ≈ −0.92…−1). То есть модель кодирует **приращение** текста, а не его накопление — читатель реализует высокочастотный фильтр, «краевую детекцию» потока. Петля тогда не отдельный объект, а **вырождение дифференциатора**: на константном входе производная = 0 → фикс-точка → однотоковый цикл (e83 w0: K(1)=0.958 при p1-потолке 91%>0.9; корпус — анти-эхо −0.008…−0.005, читающий поток есть — петляющий нет).
**Что объясняет**: дип выучен (R-null 4e-6 против −0.111); corpus-дип глубже own (−0.167 vs −0.111 — форсированный честный текст чаще триггерит разворот); T-инвариантность поля (−0.159/−0.165/−0.156 — флип это карта, не сэмплер); mix-текст гасит дип до 0.2× (детектору нужен согласованный вход); «одна мода» чтения и петли (E-76); порог обучения 0.6→0.7 — производная выучивается кооперативно, фазовый переход в связности, а не линейный дрейф; частичность J-lens (cos 0.59–0.64): флип-плоскость должна *частично* совпадать с якобианом логитов — «производная состояния» и «чувствительность предсказания» родственные объекты, но не дубль.
**Фальсификатор**: флип-рейт по слоям/докам (тест α ниже). Если sign-флипы не концентрируются в L1/L11 или не коррелируют с дипом per-doc — Т-1 умирает в один удар.
**Интерфейс наружу**: вниз — архитектурная полка слойной инвариантности 0.49 (ствол без обучения уже даёт форму); вбок — J-lens; вверх — поведение (лупы/rep16/hit: флип остаётся, его вырождение умирает с T).

### Т-2. «Свёрточная дескрипция» (масштаб всей кривой)
**Ядро**: Δ(k) = свёртка трёх носителей: флип (k≤2) ⊗ двухшаговый возврат (горб k=3–4 — не гармоника, вторая компонента ядра шага) ⊗ медленный носитель (плато k≥9 = cross-член нить×остаток, +0.08…+0.14). Три моды (λ₁<0, θ≈1.0, λ₃≈0.97) — параметризация этой свёртки. blk2-результат (плато null 0.074 > real 0.043) говорит: значительная часть горба/плато — геометрия шага и патчворк-границы блоков, а не длинная память.
**Что объясняет**: воспроизводимость горба/плато уже blk2; плато без затухания до k=32; почему ω̂-оценщик не переносится на LFM3 (это свойство оценки, не закон).
**Фальсификатор**: фазово-сдвиговый тест (сдвиг resid ≥32 шагов + рекомбинация: плато выживает → блочная структура; умирает → cross-член) и трёхмодовый фит полного corpus-профиля — если θ≈1.0 + λ₃≈0.97 не дают нечётный пик k=3, нужна четвёртая компонента.
**Интерфейс**: к структуре текста (швы, MDL-масштаб), к ACF-канону (sum≈0 — дип как распределение мощности по k).

### Т-3. «Уверенность-такт» (масштаб внутреннего времени)
**Ядро**: margin/p1 — реальный канал (гейт 0.971; p1~lookup +0.78, margin~joint4 +0.50, p1~ω̂ +0.52), но не унификатор поля (margin~dip −0.24). Версия-теория: у модели есть внутренний темп = производство уверенности, и вырождение режима (петля, e83) живёт на p1-потолке. Это честная версия «часов» после смерти событийных: такт внутренний, не событийный.
**Что объясняет**: почему ω̂ вырождается на LFM3 (оценщик темпа, не собственная частота); почему degeneracy убывает с T (rep16 0.43→0.001) при неизменном поле; связку петля↔уверенность.
**Фальсификатор**: τ-репараметризация — если «внутреннее время» τ=Σmargin/p1 не схлопывает междокументную дисперсию кривых лучше, чем сырой k, канал остаётся коррелятом, и Т-3 снят с повестки до лучших данных.
**Интерфейс**: к AT/lucidity (паркованная линия) и к e81b p1-профилям.

## 4. Стыковка масштабов (то, чего ты просил: один масштаб + интерфейс)

- **Внутри одной кривой**: флип ↔ горб ↔ плато — тест η описывает весь Δ(k) тремя модами; это и есть «объяснить в рамках одного масштаба».
- **Кривая ↔ глубина**: флип-рейт по слоям + «форма без координат» (профиль 0.90–0.975 при cos базисов 0.007–0.058) — интерфейс «что именно переносится по глубине».
- **Кривая ↔ обучение**: порог 0.6→0.7 + E-78 — интерфейс «как производная выучивается»; если появятся чекпоинты — траектория флип-рейта по обучению станет главным сюжетом.
- **Кривая ↔ политика**: поле T-инвариантно, петля умирает — интерфейс «читатель ≠ сэмплер», уже откалиброван (hit 0.61→0.10).
- **Кривая ↔ текст**: швы/mix/MDL — интерфейс «вызов».
- **Кривая ↔ уверенность**: margin-канал — интерфейс к «времени» и дальше к AT.
