«Локальный отклик и релаксация поля после инъекции повторяющегося блока»

Происхождение: ревью-раунд r2 (17.11) — `docs/AT8_2_review.md` (644 стр., sha256
4ea557bc248e0b6638088cc0089f34dd1713fa6bd2e0e45f7c87d6dc7d815087) — черновик

## 1. Одна строка и вопрос

Вопрос (пререг): создаёт ли вставка повторяющегося блока специфическое изменение
пост-контекстного поля, отличимое от вставки того же длины не-повторяющегося
текста, выше эмпирического разрешения наблюдаемой? И если создаёт — затухает ли
отклик к базовой линии на измеренном горизонте?

Разрешимые исходы: **нет эффекта / эффект есть и затухает / эффект есть и не
затухает / неразрешимо** (+ «клетка невидящая», «эффект от вставки как таковой»).

**НЕ проверяется** (вынесено из вердикта):
1. Солитонная упругость (локализация, форма-инвариантность, столкновение,
   квази-интеграл, внутренняя мода) — нужен отдельный двухобъектный дизайн (T8.2-S).
2. «Среда восстанавливает ритм» в сильном смысле — только релаксация измеряемого
   парного косинуса/нормы/CE.
3. Старые вердикты `ELASTIC / DILUTION / DIFFUSION` не используются (дефектная
   машина, р1-ревью: NOT_RESOLVED).
4. Отношение `ℓ_rec(16)/ℓ_rec(2)` не является критерием (структурно вырождено на
   оконных медианах и цензуре — подтверждено р1: ratio=1.0 при невосстановлении,
   цензура D_max).

## 2. Главный сдвиг дизайна (от р1)

Было: окно-медиана (W=8/16/32/64) в inject-doc vs то же окно в ctrl — окна
токен-идентичны (вставка `ids[:cut] + phrase*n + ids[cut:]`, len(inj)=T+L_n),
сдвинуты по абсолютной позиции на L_n (RoPE-конфаунд A2), медиана слепа к
локальному эффекту, порог 0.25·pert0 — ниже шумового пола.

Стало: на каждую дозу — 4 условия (ctrl, loop, fillerA, fillerB) на одном доке;
два корректных контраста внутри дозы (loop и filler вставлены в один cut той же
длины — абсолютные позиции post-окон равны, суффикс общий; различается только
содержимое блока):

- **Контраст 1 (основной, специфичность лупа):**
  `e_spec_i,n(d) = c_loop_i,n(cut + L_n + d) − c_fillerA_i,n(cut + L_n + d)`
- **Контраст 2 (общий эффект вставки):**
  `e_generic_i,n(d) = c_fillerA_i,n(cut + L_n + d) − c_ctrl_i(cut + d)`
- **Контраст 3 (эмпирический нуль):**
  `e_null_i,n(d) = c_fillerA_i,n(cut + L_n + d) − c_fillerB_i,n(cut + L_n + d)`

`d = 0..H−1`. Dоза: `n ∈ {2, 4, 8, 16}`, `L_n = 9·n` (фразовая доза в токенах —
индекс условия; физическая доза — отдельно, §9).

## 3. Наблюдаемая

Первичная (вердикт — только по ней):

```
object = h_raw          (скрытое состояние слоя, без нормировки)
stat   = lag1_pair_cos  c(t) = cos(Δh_t, Δh_{t+1}),  Δh_t = h_{t+1} − h_t
layer  = L23
```

Вторичные (из того же форварда, отчёт + консистентность, не вердикт):
`du_unit` (unit Δh), `norm_delta` (‖Δh_t‖), per-position `ce` (nat/токен).

## 4. Слои

- Первичный: **L23** (full attention, readout-adjacent; преемственность с AT8_2).
- Подтверждающие: **L6, L12, L18** (linear/GDN) + **L19** (full attention).
  Раскладка Qwen3.5-0.8B подтверждена по config: 24 слоя,
  `full_attention_interval=4` → full: L3/L7/L11/L15/L19/L23, остальные linear
  (GDN). Набор {L6, L12, L18, L19, L23} = 3 GDN + 1 full + readout.
- Слои снимаются хуками за один форвард (цена ≈ 0, память ~13 MB на форвард).

## 5. Геометрия

```
T      = длина контроля (192..512, пул §6)
cut    = T // 2
L_n    = 9 * n
inj_index(cut, n, d) = cut + L_n + d     (loop/filler)
ctrl_index(d)        = cut + d           (ctrl)
H      = 64          (фиксировано ДО прогона)
near   = d ∈ [0, 15]
far    = d ∈ [H-16, H-1] = [48, 63]
```

Точное условие влезания (выражено через ИСХОДНЫЙ T; длина inj-последовательности
T + L_n, поэтому L_n сокращается): `cut + H ≤ T` (т.е. `T − T//2 ≥ 64`).
Документы с `T − T//2 < H + 3` помечаются `short_horizon` и исключаются
(маржа 3 — как в черновике; для T≥192 условие всегда выполняется).

  (HuggingFaceH4/ultrachat_200k, messages) — `prism.calibration.load_calibration_data`.
- Кандидаты: **12 на домен**, `min_length=192, max_length=512` (truncation),

  (PRISM_CALIB_PIN_WRITE=1, пин коммитится — воспроизводимость).
- Фильтр `S_no_baseline_loop` (на токенах): исключить док, если какая-либо

  ноль повторов, единственный вырожденный — таблица расписания; черновой тезис

- В артефакте: `pool_fp` (по пинам), `docs_sha256` (тексты), `doc_lens`,

## 7. Условия и стимулы

- **loop**: р1-фраза ` The class will be held at the park.` (9 токенов,
  E-71B-линия; `PHRASE_IDS = [561, 523, 668, 381, 5467, 506, 279, 5926, 13]`),
  `phrase*n` в позиции `cut`.
- **fillerA / fillerB**: чужой НЕ-луповый текст той же длины, первый `9n`
  токенов другого дока того же домена; детерминированное назначение внутри
  домена (доки домена d0..d3): для базового `di` — `fillerA = d[(di+1) mod 4]`,
  `fillerB = d[(di+2) mod 4]` (fillerA ≠ fillerB ≠ loop гарантировано:
  разные доки; loop — фраза, не док).
  - Fallback (домен с <3 доками, случается: math=2): филлеры берутся из
    СЛЕДУЮЩЕГО домена в порядке wiki→math→code→chat (циклически): fillerA —
    первый док следующего домена, fillerB — второй док следующего домена.
    (round-robin +1/+2 при k=2 даёт fillerB = базовый док = дублирование
    префикса — лупоподобный филлер, запрещён.)
- Гейт `S_stimulus` (на каждый n): `len(loop)==len(fillerA)==len(fillerB)==9n`,
  токены loop == phrase*n, fillerA ≠ fillerB (нестрокая несовпадение),
  filler не содержит phrase как подпоследовательность (проверка на 9-граммах).

## 8. Разрешение δ_min и положительный контроль

- **δ_min (пер слой, пререг):** `δ_min_L` = верхний 95-й процентиль
  `|e_null(d)|` по всем докам, дозам и d (пул-инвариант наблюдаемого шума).
  Если `δ_min` неконечен/нулевой → NOT_RESOLVED (гейт `S_null`).
- **Положительный контроль чувствительности (обязателен до вердикта):**
  - `G_inside_block`: внутри вставленного блока loop и fillerA различимы по CE:
    `CE_loop_block < 1.0 nat` И `CE_fillerA_block ≥ 2.0 nat`. Калибровка
    (предпрогон 17.11, wiki-док, n=8, use_cache=False): CE луп-блока
    **0.59** (1-я реплика 2.06, 2-я+ 0.38), CE филлер-блока **4.12** —
    пороги 1.0/2.0 зафиксированы с маржой ~2× от калибровки.
  - Гейт: ≥ **12 из 16** (док, n=16) прошли `G_inside_block`; иначе
    `INSENSITIVE_CELL` (вердикт про эффект не выносится).
- **`S_null`-диагностика (не гейт, отчёт):** если `δ_min` велик относительно
  всех эффектов — это читается как NOT_RESOLVED, не как «эффект есть».

## 9. Доза (ось, а не индекс)

- `I_loop_i(n) = Σ CE по токенам вставленного луп-блока` (док i, до n) —
  физическая доза в натах (per-position CE внутри блока снимается в том же
  форварде).
- Вторичный тег (не вердикт), по док-медианным `I(n)`:
  - `DOSE_FLAT`: `I(16)/I(2) ≤ 2`
  - `DOSE_SATURATING`: `I(16)/I(2) > 2` И `I(16)/I(8) ≤ 2`
  - `DOSE_MONOTONIC`: `I(16)/I(8) > 2` И строго растёт на каждом шаге
  - `DOSE_NOT_RESOLVED`: не строго монотонно
- Пререг-прогноз (из калибровки: 2-я+ реплика 0.38 nat/токен): `I_loop` растёт
  почти линейно с n (0.38 nat/реплика-токен не насыщается), тогда как
  док-уровневый прирост D(n) насыщался в р1 (75.8→88.3 nat) — диссоциация
  «доза растёт, эффект не растёт» будет записана в отчёт как отдельный факт.

## 10. Сводки и вердикт

Док-уровневые сводки по контрастам (первичный слой, каждый n):

```
near_n = mean_i ( p90 |e_spec_i,n(d)|,  d ∈ [0,15] )
far_n  = mean_i ( mean |e_spec_i,n(d)|,  d ∈ [48,63] )
```

(агрегация — среднее по докам; единица бутстрапа — док, §11).

### Вердиктный словарь (новые; ELASTIC/DILUTION/DIFFUSION убраны)

- `INSENSITIVE_CELL` — положительный контроль провален (клетка не видит
  различий вставок). Вердикт про эффект не выносится.
- `NO_LOOP_SPECIFIC_EFFECT` — `e_spec` не превышает δ_min ни в near, ни в far
  ни на одной дозе. Чтение: луп не создаёт измеримого специфического
  пост-эффекта сверх вставки той же длины. Не опровержение солитона.
- `GENERIC_INSERTION_EFFECT` — `e_spec` не значим, но `e_generic` значим
  (`max_n near_generic_n > δ_min`): поле реагирует на вставку как таковую,
  не на луп-содержимое.
- `LOOP_RESPONSE_DECAYS` — при дозе n\*: `near > δ_min`, `far ≤ δ_min`,
  CI95(near − far) целиком > 0: специфический отклик релаксирует к базовой
  линии. Это релаксация, НЕ упругость.
- `LOOP_RESPONSE_PERSISTS` — при n\*: `far > δ_min`: отклик не затухает до
  конца горизонта.
- `LAYER_INCONSISTENT` — тег: эффект на ≥2 слоях без L23 (см. тег-правила).
- `NOT_RESOLVED` — мало доков / широкие CI / противоречие слоёв / δ_min велик /
  far между «≤δ_min с CI>0» и «>δ_min».

### Доза n\* и слойная логика (пререг)

- **n\*** = максимальная значимая доза: наибольшее `n ∈ {16,8,4,2}` с
  `near_n > δ_min(L23)`; если нет — исходы п.3 дерева.
- **Слойный тег** (на n\*, слои {L6,L12,L18,L19,L23}, «значим» =
  `near_L(n\*) > δ_min_L`):
  - `FIELD_RESPONSE` — L23 значим И ≥1 подтверждаящий значим;
  - `READOUT_ONLY` — значим только L23;
  - `INTERNAL_ONLY` — значим ровно 1 слой, и это не L23 (возможнo при
    n\* по L23 не найдено, но значим внутренний — тогда вердикт по дереву
    выносится как NOT_RESOLVED-слои + тег);
  - `LAYER_INCONSISTENT` — значимы ≥2 слоя, L23 не значим.

### Дерево вердикта (порядок жёсткий)

```
1. Гейты качества: пул ≥12 доков/≥3 домена; S_stimulus (все n);
   G_inside_block ≥12/16; δ_min конечен.
   провал пула/стимула/δ_min → NOT_RESOLVED (причина в артефакте).
2. G_inside_block < 12/16 → INSENSITIVE_CELL.
3. n* не найдено (L23, all n):
   if max_n near_generic_n > δ_min(L23) → GENERIC_INSERTION_EFFECT
   else                                 → NO_LOOP_SPECIFIC_EFFECT
4. n* найдено:
   far ≤ δ_min И CI95(near−far) > 0   → LOOP_RESPONSE_DECAYS
   else far > δ_min                    → LOOP_RESPONSE_PERSISTS
   else                                → NOT_RESOLVED
5. + слойный тег (§10), 6. + дозовый тег (§9).
```

Композитный вердикт: `«<исход> + <слойный тег> + <дозовый тег> (n*=n)»`.

Интерпретация любого положительного исхода — о релаксации/персистентности
отклика, НЕ о солитонной упругости (черновик §17, принят).

## 11. Статистика

- Единица ресемплинга: **документ** (общий контроль, вложенность доз/позиций,
  автокорреляция). `doc-bootstrap, B = 2000`, seed = 0 (зафиксирован).
- Для каждого ресемпла: документы с повторением → пересчёт `near_n`, `far_n`,
  `near_n − far_n`, `near_generic_n` → CI95 (перцентили 2.5/97.5).
- Значимость `near − far`: CI95(near−far) целиком > 0 (док-уровневые разности
  ресемплируются по докам).
- `prism.nulls_and_stats` (paired_bootstrap) + numpy; позиции не ресемплируются
  (вторичный блок-бутстрап позиций — только для отчёта об автокорреляции).

## 13. Цена

- Форварды: 16 доков × (1 ctrl + 4 дозы × 3 условия) = **208**.
- Измерено (17.11, OMP=6): T=256 — 6.2 с/фд (р1, свободная машина) …
  11–19 с/фд (текущая загрузка LA≈18). Оценка: **22–66 мин CPU** +
  пул/анализ ~5 мин → **30–70 мин**.
- Запуск: `./run_one.sh at8_2_r2 ...` (setsid nohup, OMP=6, nice-10, watchdog),
  память-гейт run_one.sh (avail ≥ 10G).

## 14. Smoke-план (до полного прогона)

1. 1 домен (wiki) × 2 дока × n=2 (8 форвардов: 2 ctrl + 2×3):
   - CE ctrl-doc ∈ [2, 4] nat (якорь к р1-шкале 3.2);
   - CE loop-block < 1.0, CE filler-block ≥ 2.0 (G_inside_block работает);
   - ряды `cos_raw_lag1` конечны, форма: post-окно смещено на L_n (позиционный
     сдвиг виден на e_null ≈ 0 в среднем);
   - `δ_min` конечен > 0; длины filler ровно 9n (S_stimulus);
   - resume: прерванный smoke-прогон доходит до конца с resume_plan.
2. Синтетический store (4 сценария: нуль/затухание/персистентность/несвязно) →
   вердикт-машина даёт ожидаемые вердикты (pytest, как test_verdict_defects).
3. Дегенерации: док с `short_horizon` (исключается), filler = loop (S_stimulus
   ловит), NaN в хуке (S_layer ловит).
