# E-34. Pre-flight 1: где сидит cross-coupling токенов

## Цель и идеология

Локализовать источник off-diagonal структуры ESG — равномерный сдвиг (gauge), доминирующий токен, или распределённый cross-talk между токенами. Результат определяет, спасаема ли per-token защита (P1) в первом порядке, и, следовательно, статус E-32 (центральный vs уточняющий). Идеология: не запускать дорогое измерение второго порядка (E-32), пока не известно, что первый порядок нетривиален.

## Математика (сверх paper.md)

**ESG и её диагональ.** `ESG_l = (1/N) Σ_i J_l^{(i)} (J_l^{(i)})^T ∈ R^{K×K}`. Диагональ `ESG_ii = ||J_i||²` — self-response токена `i`; off-diagonal `ESG_ji = ⟨J_j, J_i⟩` — cross-talk.

**Три уровня снятия cross-talk.** Последовательно применяем три проектора к `ESG_l`:

- **Raw:** `ESG_l` как есть.
- **Gauge-free:** `ESG_l^{(p)} = P(p^{(t)}) · ESG_l · P(p^{(t)})` (P симметричен, поэтому `P·ESG·P^T = P·ESG·P`). `p` — функция позиции `t` и сэмпла, не слоя — отсюда нотация `P(p^{(t)})`, не `P(p_l)`.
- **Top-1 removed:** `ESG_l^{(-1)} = ESG_l − λ₁ · u₁ u₁ᵀ`, где `(λ₁, u₁)` — топ-собственная пара `ESG_l`.

**Основная метрика `ρ` (K-инвариантная).** Frobenius ratio `r = ‖offdiag(ESG)‖_F / ‖diag(ESG)‖_F` зависит от K: `r = √(K−1) · (RMS_off/RMS_diag)`, и пороги в шкале `r` «повисают» при смене K (при K=128 порог 0.3 — это per-element ratio ≈ 0.026). Поэтому основная метрика — per-element:

`ρ = RMS(offdiag) / RMS(diag) = r / √(K−1)`.

Абсолютные пороги, не зависящие от K: `ρ ≪ 0.1` — диагональ доминирует, `ρ ~ 0.3` — сравнимо, `ρ ≫ 0.3` — offdiag доминирует.

**Калибровка по нуль-модели.** Случайное `J_rand` с той же диагональю: `J_rand = diag(√ESG_ii) · Q`, случайный ортогональный `Q`. `ρ_null` — фон; решающее правило: `ρ_actual / ρ_null`.

**Сокращение по слоям.** L0 в dense-кэше нет (`LAYERS_DEFAULT = (6, 12, 18, 19, 22, 23)`, L19 исключаем для консистентности с E-14) → считаем на `{6, 12, 18, 22, 23}`. По E-10a `uniformity_0 = ⟨u₁, 𝟙/√K⟩²`:

- L23 = 0.503 → `u₁` не совпадает с `𝟙`, третий уровень информативен. Три числа.
- L6–L18 ∈ [0.85, 0.97] → `u₁ ≈ 𝟙`, `P(p^{(t)})·ESG·P(p^{(t)}) ≈ ESG − λ₁u₁u₁ᵀ`. Второй и третий уровни совпадают. Два числа.

**Пер-сэмпл агрегация.** Ratio считается **на каждом сэмпле отдельно** (на его собственном `ESG_l^{(i)} = J_l^{(i)}(J_l^{(i)})^T`), затем агрегируется медианой по сэмплам. Пул `ESG` по сэмплам до вычисления отношения некорректен: смешивает сэмплы с разными масштабами перед нелинейной функцией `offdiag/diag`.

**Инвариантность к нормировке.** Ratio инвариантен к умножению `ESG` на скаляр: `offdiag(c·ESG)/diag(c·ESG) = offdiag(ESG)/diag(ESG)`. Дополнительная нормировка на trace избыточна, но не вредит.

## Подводные камни

1. **Per-sample vs pooled.** Главный риск. Если пулить `ESG` по сэмплам до отношения, получим артефакт: смешение разных масштабов `||J||` искажает `r_raw` в сторону от истинной структуры.
2. **Sentinel-строки.** Если при взятии `ESG` часть строк замаскирована (норма ниже порога), диагональ содержит нули, и `diag → 0` даёт `r → ∞`. Решение: считать отношение только на сэмплах с полным набором ненулевых строк; фиксировать долю исключённых.
3. **K=128 vs D=1024.** Off-diagonal — `K×K`, не `D×D`. Это cross-talk по токенам, не по hidden-направлениям. Для P1 (защита) — правильно, потому что P1 защищает токены через их представление в hidden.
4. **P(p^{(t)}) — не проектор.** `P² ≠ P` (лемма `[L-gauge]`). `P·ESG·P` — не ортогональная проекция, а квадратичная форма. `ρ_gf` нормирован, но интерпретация «сколько энергии в off-diagonal после снятия gauge» — приблизительна. Это фиксируем явно.
5. **Диагональ ≠ self-response в строгом смысле.** `ESG_ii = ||J_i||²`, но `J_i` — градиент логита `i` по `h`. Это не «токен i защищает себя», а «насколько логит i чувствителен к h». Терминология важна для интерпретации P1.
6. **Малые N (N=32).** Bootstrap-CI широкие, точка может быть неустойчивой. Обязательно отчитываться разбросом, а не только медианой.

## Что собираем

Per-layer (L6, L12, L18, L22, L23):
- `ρ_raw`, `ρ_gf`, `ρ_top1` — медиана по сэмплам.
- `ρ_null` (нуль-модель) и `ρ_actual / ρ_null` на каждом уровне.
- IQR или std по сэмплам для каждой.
- Доля сэмплов, исключённых из-за sentinel.
- `uniformity_0` каждого слоя (подтверждение по E-10a).
- Контроль: корреляция `ρ_offdiag` (per-layer) с `|Δp|` на том же слое. Если coupling сидит там, где `p` прыгает, — это структура выходного распределения, не ESG; без этого контроля интерпретация неоднозначна.

## Как

1. Загрузить exp27b dense-кэш: `JR` — полный raw `J` (не гейдж-фри, `r_raw` не теряется), `P128` — нормализованный `p` (сумма 1 по `U128`, готов к использованию), `RANKS` — уже посчитаны. Все три уровня вычислимы на существующем кэше.
2. Для каждого сэмпла, позиции и слоя: посчитать `ESG_l^{(i)}`, `P(p^{(t)})^{(i)}`, `ρ_raw^{(i)}`, `ρ_gf^{(i)}`, `ρ_top1^{(i)}` (последний — только на L23).
3. Нуль-модель: `J_rand` с той же диагональю, `ρ_null`.
4. Агрегировать медианой и IQR по сэмплам.
5. Контроль: корреляция `ρ_offdiag` с `|Δp|` per-layer.
6. Сохранить `exp34_p1_coupling.json`.

## Интерпретация

| Паттерн | Что означает | Следствие для P1 |
|---|---|---|
| `ρ_raw ≫ 0.3` на L6–L18; `ρ_gf ≪ 0.1` | coupling сидит в uniform mode | P1 спасаема: убить gauge, защищать дифференциальные направления |
| `ρ_gf ~ 0.3` на L6–L18; `ρ_top1 ≪ 0.1` | coupling в доминирующем токене | P1 частично спасаема: защищать несколько токенов, не все |
| `ρ_gf ~ 0.3` и `ρ_top1 ~ 0.3` | распределённый cross-talk | **P1 фундаментально сломана в первом порядке** — публикуемый факт |
| `ρ_gf ≪ 0.1` везде | первый порядок диагонален | E-32 остаётся центральным (уточняет второй порядок) |
| `ρ_gf ≪ 0.1` на L6–L18, но `~ 0.3` на L23 | coupling растёт у выхода | P1 валидна в середине, ломается на выходе |

## Критерии остановки

- E-34 запускается первым, до всего остального.
- Если `ρ_gf ≪ 0.1` на L6–L18 (и `ρ_gf/ρ_null` мало) → **E-32 центральный**.
- Если `ρ_gf ~ 0.3` на L6–L18 → **E-32 уточняющий**, приоритет уходит к E-31 и E-35.
- Если результат неоднозначен (например, `ρ_gf` между 0.1 и 0.3) → разложить `ρ_gf` по модам `ESG` (какие собственные направления дают вклад в off-diagonal) — это дополнительный шаг внутри E-34.

# E-35. M-pinning: что управляет Δ_SVD из E-28

## Цель и идеология

Определить, что задаёт `Δ_SVD` из E-28: траектория `û_t` на сфере `S^{D−1}`, фиксированная структура `M_K = W_lm[𝒮]·diag(g)`, или эффект softmax-взвешивания `P(p_t)`. Идеология: E-28 нашёл лист на L23, но не объяснил его источник. Три уровня разложения отделяют чистую радиальную проекцию (уровень 1) от спектра `M_K` (уровень 2) и от вклада `p_t` (уровень 3).

## Математика (сверх paper.md)

**Разложение Якобиана L23.** По `[L-rms]` и `_last_layer_jacobian`: `J_raw^{L23}(t) = M_K · (√D / r_t) · (I − û_t û_tᵀ)`, где `r_t = ‖h_final_t‖`, `û_t = h_final_t / ‖h_final_t‖`, `M_K = W_lm[𝒮]·diag(g)`, `g = 1+w`. Константа `√D/r_t` не влияет на правые сингулярные векторы.

**Правые сингулярные векторы.** `J_raw^T J_raw = (√D/r_t)² · P_u A^T A P_u`, где `P_u = I − ûûᵀ`, `A = M_K`. Топ-`r` правое подпространство = топ-`r` собственных векторов `P_u A^T A P_u` на `û⊥`.

**Три уровня.**

- **Уровень 1 (идеальный).** Если `A^T A = λI` на `R^D`, то `P_u A^T A P_u = λ P_u`, все ненулевые собственные значения равны (вырождение), топ-`r` не определён канонически. Если вместо этого смотреть на полное `(D−1)`-мерное подпространство `û⊥`, то `Δ_SVD(t) = d_S(û_t, û_{t+1})` — геодезическое расстояние на сфере — **точно**.
- **Уровень 2 (гейджированный).** Общий `A`. Топ-`r` = собственные векторы `P_u A^T A P_u` с наибольшими собственными значениями. `Δ_SVD` — функция `û` и спектра `A^T A`.
- **Уровень 3 (данные E-28).** Добавляется `P(p_t)`: `J^{(p)} = P(p_t)·J_raw`. `Δ_SVD` — функция `û`, спектра `A^T A`, и `p_t`.

**Rank-ограничение.** `rank(J) ≤ K = 128` (при `D = 1024`). Значит, топ-`r` подпространство определено для `r ≤ 128`, а при `r = 128` это полный column space, не `û⊥` (которое 1023-мерно). Асимптота «`Δ_SVD → d_S(û, û')` при `r → D−1`» **недостижима** на K=128.

**Предсказание формы кривой.** По Дэвису–Кэхану: если у `A^T A` большой eigengap в топ-`r`, топ-подпространство `P_u A^T A P_u` «пришпилено» к `M`-направлениям и слабо зависит от `û`. Корреляция `Δ_SVD` с `d_S(û, û')` низкая. Если eigengap мал — топ-подпространство «следует» за `û`, корреляция высокая. Форма кривой: **неубывающая по `r`**, с возможными плато/изломами на eigengap.

**Shuffled-û baseline.** Для каждой actual пары `(û_t, û_{t+1})` найти random пару `(û_t, û_rand)` с тем же `d_S`. Сравнить `Δ_SVD(actual)` и `Δ_SVD(shuffled)`. Разница = `Δ_SVD` зависит не только от расстояния, но и от направления движения `û` относительно `A`-структуры.

**Зависимость `p_t` и `û_t`.** Оба — функции `h_final`. Это не независимые переменные, а две проекции одного источника. Разность `Δ_SVD(ур.3) − Δ_SVD(ур.2)` изолирует **эффект softmax-взвешивания при фиксированном `h_final`**, а не «независимый вклад `p_t`».

## Подводные камни

1. **K=128 ограничивает sweep.** `r > 128` даёт вырожденное подпространство. Не пытаться «приблизиться к D−1».
2. **Дегенерация при равных сингулярных числах.** Если у `P_u A^T A P_u` топ-`r` собственные значения совпадают (вырождение), топ-подпространство не единственно. Проверять: различимы ли λ_i − λ_{i+1} в топ-`r` для всех позиций.
3. **`r_t = ‖h_final_t‖` в знаменателе.** Если `‖h_final_t‖` мал, `J_raw` масштабируется; сингулярные векторы инвариантны, но при интерпретации численных `‖J_raw‖` нужно помнить о масштабировании.
4. **`g = 1+w` — выученный вектор.** Не `g = w`, именно `1+w` (RMSNorm Qwen инициализирован так, что `g = 1` на старте). Проверить по `_lm_module(model).norm.weight`.
5. **Позиционная vs кросс-сэмпловая ось.** E-28 работал внутри документа по позициям `(t, t+1)`. Не сравнивать позиции разных документов напрямую — `û_t` живут в разных областях сферы.
6. **Sentinel на ранних слоях.** На L6–L22 `Δ_SVD ≈ random-subspace baseline` из E-28. Это уже известный факт; E-35 нужен для L23 и для объяснения, почему там структура.
7. **Гейдж-фри версия E-28.** `J^{(p)} = P(p_t)·J_raw`. `P(p_t)` зависит от `p_t`, которое варьируется по позициям. Поэтому `Δ_SVD(ур.3)` — не функция только `û`, а функция пары `(û, p)`. Не приписывать весь эффект `û`.
8. **Смещение к top-1 направлению.** Если `û_t` лежит близко к топ-1 собственному вектору `M_K^T M_K`, проекция `P_u` «вырезает» доминирующую моду, и подпространство становится гиперчувствительным к движению `û`. Контроль: alignment `û_t` с топ-направлениями `M_K`.
9. **SVD M_K с K=128, не полного W_lm.** `M_K = W_lm[𝒮, :]·diag(g)` — это `128×1024`, rank ≤ 128. Спектр K-подмножества не совпадает со спектром полного `W_lm` (152k строк). Предсказание для E-28 — только `M_K`.
10. **Чёт/нечёт остатков в E-32.** Для интерпретации E-32 нужен факт: на L23 направление инъекции `J^T e_i ⊥ û` по построению RMSNorm (`û^T(I − ûûᵀ) = 0`). На L6–L22 это не гарантировано. Это фиксируем в E-35 как побочный результат.

## E-35-preflight. Регрессионный контроль: геометрия vs выходное распределение

**Цель:** определить, управляет ли траектория `û` вариацией `Δ_SVD` независимо от скачков `|Δp|`, или `Δ_SVD` — прокси для `|Δp|`. Результат определяет интерпретацию L23-листа (геометрический объект vs проекция выходного распределения) и **блокирует E-35-full**. Идёт **до** `r`-sweep: sweep покажет форму, но не то, что именно объясняет форму.

**Математика.** Регрессия per-position:

`Δ_SVD(t) = α · d_S(û_t, û_{t+1}) + β · |Δp_t| + residual(t)`

где:
- `Δ_SVD(t)` — максимальный главный угол между топ-r правыми подпространствами `J_t` и `J_{t+1}` (r=16, из E-28).
- `d_S(û_t, û_{t+1}) = arccos(⟨û_t, û_{t+1}⟩)` — геодезическое расстояние на `S^{D−1}`.
- `|Δp_t| = ‖p_{t+1} − p_t‖₂` — уже посчитано в E-28-semantic как `dP`.

Метод: OLS с VIF-контролем мультиколлинеарности (VIF > 5 → частичная корреляция `Δ_SVD` с `d_S` после вычитания линейной зависимости от `|Δp|`), robust SE (HC3).

**Подводные камни.**
1. **Мультиколлинеарность.** `d_S(û, û')` и `|Δp|` механически связаны через `p = softmax(W·RMSNorm(h))`. VIF > 5 → OLS-коэффициенты неустойчивы, использовать частичную корреляцию.
2. **Гетероскедастичность.** `Δ_SVD` и `|Δp|` разного масштаба на границах vs внутри листов → HC3.
3. **Выбор r.** E-28 использовал r=16; устойчивость при r ∈ {8, 32} (Jaccard границ из E-28-semantic: 0.60 и 0.42).
4. **Sentinel-позиции.** Исключить позиции с вырожденным SVD (rank < r) или sentinel `p` (сумма < 0.5 на `U128`).
5. **Нелинейность.** Если зависимость нелинейна — квадратичные члены или GAM; остатки проверить на неслучайность.

**Что собираем.** Per-document (32 документа, L23):
- коэффициенты `α`, `β` (OLS + robust SE), p-values.
- VIF предикторов.
- частичная корреляция `Δ_SVD` с `d_S` при контроле `|Δp|`.
- R², остатки: runs test, Breusch–Pagan.

**Как.**

```
Δ_SVD = load_exp28_delta_svd(layer=23, r=16)  # [N_docs, T-1]
dP    = load_exp28_dynamics()['dP']           # [N_docs, T-1]
û     = compute_u_hat(H_cache, layer=23)       # [N_docs, T, D]
d_S   = arccos(einsum('ntd,ntd->nt', û[:,:-1], û[:,1:]))

per doc: X = column_stack([d_S, dP]), y = Δ_SVD,
         OLS + add_constant, cov_type='HC3'; сохранить α, β, VIF, partial_corr
```

**Интерпретация.**

| Паттерн | Что означает | Следствие |
|---------|-------------|-----------|
| `α` значим (p<0.05), `β ≈ 0` | `û` управляет `Δ_SVD`, геометрия есть | E-35-full продолжается как планировалось |
| `β` значим, `α ≈ 0` | `Δ_SVD` — прокси для `|Δp|`, геометрия вторична | E-35 переопределяется: ищем, почему `Δ_SVD` коррелирует с `|Δp|` |
| Оба значимы, VIF < 5 | смешанный режим | добавить контроль `M_K` в E-35-full |
| Оба значимы, VIF > 5 | мультиколлинеарность | частичная корреляция; если она с `d_S` незначима — геометрии нет |
| R² < 0.3 | модель плохая | искать другие предикторы (например, `M_K`-структуру) |

**Дополнительные чеки (параллельно).**
1. **Δû на границах vs вне границ.** Среднее `d_S(û_t, û_{t+1})` на позициях-границах (MAD-детектор из E-28) vs не границах, permutation test (B=2000). Поддерживает «лист = траектория `û`», но не различает с `|Δp|`.
2. **Атрибуция оси 2.** Спроецировать ось 2 (из `P-axes` E-28-semantic) на топ-токены `U128`: пунктуация → границы структурные; содержательные токены → семантические.
3. **Контроль E-34:** корреляция `ρ_offdiag` (per-layer) с `|Δp|` на том же слое.
4. **Контроль E-32:** корреляция `‖b(t)‖` (Гессиан, per-position) с `|Δp(t)|`; если ~1 — Гессиан тоже прокси для `|Δp|`.

**Критерии остановки.**
- `β` значим и `α` незначим (или частичная корреляция незначима) → **стоп E-35-full**, переопределить как «почему `Δ_SVD` коррелирует с `|Δp|`».
- `α` значим и `β` незначим → E-35-full как планировалось (M-pinning, r-sweep).
- Оба значимы → E-35-full с `|Δp|` как ковариатой в r-sweep и кросс-чеке с Гессианом.

**Артефакты.**
- `results/exp35_preflight_regression.json`, `results/exp35_preflight_axis2_attribution.json`.

## Что собираем

Per-layer (L6, L12, L18, L22, L23; кросс-чек с E-28 (6 слоёв) будет на 5 из 6 — без L19):

- PCA траектории `û_t` (для L23): дисперсия по компонентам, топ-компонента и её объяснённая дисперсия.
- Корреляция `Δ_SVD(t)` с `d_S(û_t, û_{t+1})` на `J_raw` при `r = 16` — Спирмен ρ, p-value.
- Sweep `r ∈ {1, 8, 16, 32, 128}` — та же корреляция как функция `r`.
- `Δ_SVD(ур.3) − Δ_SVD(ур.2)` при `r = 16` — величина эффекта `P(p_t)`.
- SVD `M_K`: топ-16 сингулярных чисел, eigengap.
- Shuffled-û baseline: `Δ_SVD(actual) − Δ_SVD(shuffled)` при том же `d_S`.
- Alignment `|⟨û_t, v_top-k(M_K)⟩|` для k ∈ {1, 2, 4}.
- Кросс-чек: для каждого `r` корреляция `κ_r(E-28)` с `‖Гессиан(r)‖`; найти `r`, максимизирующее корреляцию. **Пост-E-32** (нужна матрица `b`); опциональный pre-flight — численный HVP через `torch.autograd.functional.hvp` на самой функции `z(h)` (тот же объект, что `b`, без полного forward-sweep по `ε`): закрывает кросс-чек на 2–3 позициях L23 за минуты, до полного E-32.

## Как

1. Загрузить exp27b dense-кэш: `JR` — raw `J`, `P128` — нормализованный `p`; gauge-free `J^{(p)} = P(p_t)·J` считается downstream. `g = RMSNorm.weight` в кэше нет — достать из модели (pre-flight: один forward на 0.8B).
2. Посчитать `û_t` для каждой позиции каждого документа (это `h_final_t / ‖h_final_t‖`).
3. Посчитать `M_K = W_lm[𝒮, :]·diag(g)` один раз.
4. SVD `M_K` один раз: топ-16 сингулярных чисел и векторов.
5. Для каждой позиции: `P_u = I − ûûᵀ`, топ-`r` собственные векторы `P_u A^T A P_u` для `r ∈ {1, 8, 16, 32, 128}` (Lanczos, не полный SVD `D×D`).
6. `Δ_SVD(t) = max` главный угол между топ-`r` подпространствами `t` и `t+1`.
7. `κ(t)` — голономия Прохореса на тройках `(t, t+1, t+2)`.
8. Корреляции и sweep.
9. `J^{(p)}` версия: `Δ_SVD^{(p)}(t)` через те же подпространства с дополнительной `P(p_t)`.
10. Сохранить `exp35_mpinning_sweep.json`.

| Паттерн | Что означает | Следствие |
|---|---|---|
| ρ высокая уже при `r = 8`, растёт с `r` | `û` доминирует; `M`-структура несущественна | модель «лист L23 = траектория `û`» полная; Ставка №2 закрыта в слабой форме |

# E-31. B9: полная корреляционная функция `C(Δpos)`

## Цель и идеология

Измерить длину когерентности `ξ` поля `J` вдоль траектории и проверить гипотезу «нить vs лист». E-0.1 дал две точки (соседние пары), E-27.6 показал рост `C_a` с глубиной. Полная кривая `C(Δpos)` даёт форму распада и локализацию разрывов, если они есть. Идеология: если поле — нить, `C` быстро падает; если лист — медленно. Карта разрывов отличает геометрическую нить от лингвистически структурированной.

## Математика

**Усреднённая кривая.** `C(Δpos) = E_t[cos(J_t, J_{t+Δpos})]` по всем допустимым парам `(t, t+Δpos)` внутри документа, где обе позиции имеют валидные `J` (не sentinel). `Δpos ∈ {1, 2, ..., S-1}`.

**Позиционная конвенция (фикс).** В dense-кэше `t=0` — последняя позиция последовательности, `t=127` — первая (инвертированная конвенция: `p128[S-1-t]`, `H[(dom, si, t)] = hs[l][S-1-t]`). `Δpos` определяется **в кэш-t**; при маппинге на границы предложений применяем `seq_pos = S-1-t`. Для симметричных метрик это неважно, для карты разрывов с локализацией границ — критично.

**Второй срез: `C_top-16(Δpos)`.** E-31 мерит Frobenius-когерентность **полного** `J`, E-28 — когерентность **топ-r подпространства**. Это разные объекты, и расхождение между ними — самостоятельный сигнал. Вторая кривая `C_top-16(Δpos)` через главные углы между топ-16 подпространствами — дёшево (те же SVD на существующих `JR`).

**Форма распада.** Аппроксимация `C(Δpos) ~ exp(−Δpos/ξ)` (марковский распад) vs `C(Δpos) ~ Δpos^{−α}` (степенной). Решаем по лог-линейному фиту и остаткам: экспонента даёт прямую в `log C`, степенная — в `log-log C`.

**Позиционно-разрешённая карта.** `C(t, Δpos) = cos(J_t, J_{t+Δpos})` — матрица `S × S`. Разрывы локализуются как позиции `t`, где `C(t, Δpos)` резко падает для средних `Δpos`.

**Сегментно-усреднённая.** `C(Δpos | segment)` — усреднение по парам внутри одного предложения (intra) vs между предложениями (inter). Требует границ предложений в токенах через `offset_mapping`.

**Три среза:**
- Усреднённый `C(Δpos)` → `ξ` и форма распада.
- Позиционно-разрешённый `C(t, Δpos)` → карта разрывов.
- Сегментно-усреднённый `C(Δpos | intra/inter)` → лингвистическая структура.

## Подводные камни

1. **Sentinel-строки.** На ранних слоях часть строк замаскирована; `cos` с нулевой строкой не определён. Решение: пара исключается, если хотя бы одна из двух позиций sentinel; фиксировать долю исключённых.
2. **Edge effects по `Δpos`.** Для `Δpos = S-1` доступна одна пара. Для больших `Δpos` — мало пар, шумная оценка. Обязательно CI по сэмплам.
3. **Пул по сэмплам.** `C(Δpos)` — скаляр на слой на `Δpos`. Per-sample сначала, потом агрегация. Пул `J` по сэмплам некорректен (C_b ≈ 0 из E-0.1).
4. **`offset_mapping` — требование к данным.** Токенизатор `Qwen3.5` даёт offset-маппинг; `calibration.py` должен его сохранять при загрузке. Без этого нельзя восстановить границы предложений.
5. **Сегментация по доменам.** `nltk.sent_tokenize` на code даёт мусор. Фикс: **wiki/chat:** `nltk.sent_tokenize`; **code:** границы строк (`\n\n`) или структурный парсер (границы функций через `ast` для Python, регексы для других языков); **math:** формулы как единицы (`\(...\)`, `\[...\]`). Если парсер не готов — ограничить E-31 доменами wiki/chat и зафиксировать это в протоколе.
6. **Усреднённая кривая vs карта.** Усреднённая даёт «колено» на длине предложения, но не локализует разрыв. Позиционно-разрешённая локализует, но шумит. Это не альтернативы, а комплементарные срезы — считать оба.
7. **Смещение из-за длины предложений.** Если предложения в разных документах разной длины, сегментно-усреднённое `C(Δpos | intra)` сравнивает несопоставимые длины. Нормализовать `Δpos` на длину сегмента или использовать одинаковую длину (первые `min_len` токенов).
8. **Chunk-boundary гипотеза закрыта.** Test 5: периодичности κ на `t ≈ 31/63/95` нет. Отдельную проверку на периодичность чанков в E-31 **не запускать**.

## Что собираем

Per-layer (L6, L12, L18, L22, L23):

- `C(Δpos)` для `Δpos = 1, ..., min(S-1, 32)` — усреднённая кривая с CI (полный J, Frobenius).
- `C_top-16(Δpos)` — вторая кривая, главные углы между топ-16 подпространствами (двойной срез: полный J vs подпространство).
- Параметры фита: `ξ` для экспоненциальной, `α` для степенной; AIC/BIC для выбора формы.
- Карта `C(t, Δpos)` для средних `Δpos` — матрица на документ.
- `C(Δpos | intra)`, `C(Δpos | inter)` — сегментно-усреднённые.
- Позиции границ предложений в токенах для каждого документа.
- Доля sentinel-пар.

## Как

1. Модифицировать `calibration.py`: сохранять `offset_mapping` при токенизации (`return_offsets_mapping=True`). Прогнать загрузку данных снова.
2. **Pre-flight: проверить, что пики `dP` совпадают с границами предложений** (согласование двух уже измеренных сигналов — E-31 и E-28-semantic; не гипотеза, а внешняя проверка сегментно-усреднённого среза).
3. Посчитать границы предложений по доменам (см. подводный камень 5), маппировать на токены через `offset_mapping`, применять `seq_pos = S-1-t`.
4. Загрузить exp27b dense-кэш `JR` (raw `J`) и `P128` (нормализованный `p`).
5. Для каждой пары `(t, t+Δpos)`: `cos(J_t, J_{t+Δpos})` и главный угол между топ-16 подпространствами.
6. Усреднить по парам и по сэмплам (per-sample сначала).
7. Фит `log C ~ −Δpos/ξ` и `log C ~ −α log Δpos`.
8. Построить карту `C(t, Δpos)`.
9. Сегментно-усреднить по intra/inter.
10. Сохранить `exp31_correlation_function.json`.

## Интерпретация

| Паттерн | Что означает |
|---|---|
| Экспоненциальный распад, `ξ ≈ 1–2` | нить: короткая память, марковское поле |
| Степенной распад | длинная память, возможно листовое поведение |
| `ξ` растёт с глубиной (параллельно `C_a`) | нить «утолщается» — согласуется с E-27.6 T7 |
| Резкие разрывы `C(t, Δpos)` на позициях границ предложений | нить лингвистически структурирована |
| Разрывов нет, плавный распад | нить чисто геометрическая |

**Двойной срез (полный J vs подпространство):**

| `C_Frobenius(Δpos)` | `C_top-16(Δpos)` | Что означает |
|---|---|---|
| высокая | высокая | нить/лист в обоих смыслах |
| низкая | высокая | подпространство когерентно (лист E-28), но сингулярные числа/нижние направления «дышат» |
| высокая | низкая | скалярная энергия когерентна, но подпространство вращается |
| низкая | низкая | ни листа, ни нити |

## Критерии остановки

- Pre-flight: `offset_mapping` (`return_offsets_mapping=True`) в `calibration.py` готов **до** запуска; пики `dP` совпадают с границами предложений (иначе сегментный срез без смысла).

- Если одинаковые кривые → зафиксировать как «форма не зависит от слоя», не разворачивать.

# E-32. Гессиан readout: cross-talk второго порядка

## Цель и идеология

Измерить второй порядок readout по `h_l` и определить, добавляет ли нелинейность cross-talk сверх первого. E-32 закрывает Ставку №2 в сильной форме (кривизна readout = RMSNorm, подтверждено на L23) и уточняет P1 вторым порядком. Идеология: первый порядок E-32 тавтологичен (воспроизводит ESG), поэтому содержательный сигнал — отклонение от ESG в полном нелинейном форварде.

## Математика (сверх paper.md)

**Разложение Тейлора.** Инъекция `δ_i = ε · J_lᵀ e_i / ‖J_lᵀ e_i‖` — **нормированная**: `‖δ_i‖ = ε` для всех токенов, `s_l` не смесь доз; соответствует `ε = ‖δ‖` в E-12a. Разложение логита `j`:

`z_j(h + δ_i) − z_j(h) = ε · (ESG_l)_{ji} + (ε²/2) · (J_lᵀ e_i)ᵀ H_j (J_lᵀ e_i) + O(ε³)`

где `H_j = ∂²z_j/∂h_l² ∈ R^{D×D}` — Гессиан логита `j` по `h_l`.

**Сырой отклик и нормировка.** Определяем `Δz_j(ε)` — эмпирически из полного форварда. Фит:

`Δz_j(ε) = a·ε + b·ε² + c·ε³ + O(ε⁴)`,

где `a_ji = (ESG_l)_{ji}` (первый порядок), `b_ji = (1/2)·(J_lᵀ e_i)ᵀ H_j (J_lᵀ e_i)` (второй порядок).

**Матрицы.** `a` и `b` — `K × K`, индексированы `(j, i)`. Диагональ `a_ii = ||J_i||²` — self-response; диагональ `b_ii` — вторая производная self-response.

**Безразмерный скаляр.** `s_l = ε · ‖offdiag(b)‖_F / ‖offdiag(ESG_l)‖_F` на рабочей точке `ε_canon = 0.15·‖h‖` (середина диапазона E-12a, 14–53%: нелинейности уже видны, Тейлор ещё адекватен). Первый порядок вклада — `ε·‖offdiag(ESG)‖`, второй — `ε²·‖offdiag(b)‖`. Их отношение и есть `s_l`. Sweep `ε ∈ {5%, 15%, 30%, 50%, 70%}` — только для диагностики режима (остатки, `Δz/ε` vs `ε`), не для `s_l`.

**Решающее правило.**
- `s_l ≪ 1` — readout практически линеен в рабочей точке, P1-защита независима.
- `s_l ~ 1` — нелинейность сравнима с линейностью, P1 должна учитывать cross-talk.
- `s_l ≫ 1` — readout существенно нелинеен, линейная защита некорректна.

**Диагностика режима.** График `Δz/ε` против `ε` — линейный, если доминирует второй порядок. Излом = выход из квадратичного режима. Остатки кубического фита: если случайны — второй порядок реален; если систематически растут — упёрлись в радиус сходимости.

**Чёт/нечёт остатков.**

- На L23: `û^T(J^T e_i) = 0` (по построению RMSNorm). Линейный член `2ε⟨û, v⟩/‖h‖` в разложении `1/r` обнуляется, `1/r` — чётная функция `ε`, высшие члены **чётные**. Симметричные остатки — норма.
- На промежуточных слоях: `⟨û_l, J_l^T e_i⟩ ≠ 0` в общем случае. Остатки могут быть антисимметричны без «третьего порядка». Чёт/нечёт — **вторичный** диагностик.

## Подводные камни

1. **Тавтологичность первого порядка.** `a_ji` воспроизводит `ESG_l`. Содержательный сигнал — только `b` и `c`. Не интерпретировать `a` как «новый результат».
2. **Нормировка.** Не смешивать конвенции `R_full = Δz` (вычитать `ε·ESG`) и `R_full = Δz/ε` (вычитать `ESG`). Фит по `ε` снимает путаницу — предпочтительный способ.
3. **Нормировка инъекции (фикс).** С нормировкой `δ_i = ε·J_lᵀ e_i / ‖J_lᵀ e_i‖` — `‖δ_i‖ = ε` для всех токенов; смешения доз нет. Без нормировки `‖δ_i‖ = ε·√((ESG_l)_ii)` зависит от токена — не использовать.
4. **Инъекция только в `h` последнего токена.** По `jacobian.py` `_run_decoder_pass` использует `prefix_cache` для префикса и получает `h` как вход. Модифицируем **только `h` перед `_run_decoder_pass`; `prefix_cache` остаётся чистым** — явно зафиксировать в коде E-32.
4. **Мощность кубического фита.** Минимум 5 точек `ε`. На 4 точках `dof = 1`, `p(c)` тест вырожден.
5. **Потолок диапазона ε.** Мощность растёт с `ε`, но валидность Тейлора падает. Потолок определяется структурой остатков, а не статистикой.
6. **Не-полиномиальность RMSNorm.** `z(h)` гладкая, но не полином. Коэффициент `c` абсорбирует все высшие порядки. Значимый `c` = «квадратичная модель неадекватна», не «третий порядок важен».
7. **Bootstrap по сэмплам.** Не по парам `(j, i)`. Пара — детерминированная функция от `h`, варьируется через `h`.
8. **Пилот на одном сэмпле.** `|T|=16` токенов одного сэмпла — CI нет, только ε-стабильность `b`. Не интерпретировать «b устойчив» как «b значим».
9. **Диагональ b.** `b_ii` — вторая производная self-response; отдельный объект, не часть cross-talk. Не включать в offdiag-норму.
10. **Функциональная зависимость `p_t` и `û_t`.** Оба функции `h_final`. Не путать с независимыми переменными.

## Что собираем

Per-layer (L22, L23 в пилоте; L6, L12, L18, L22, L23 в полном):

- Матрица `a` (первый порядок) — должна совпасть с `ESG_l` (валидация метода).
- Матрица `b` (второй порядок).
- Матрица `c` (остаток).
- `s_l = ε·||offdiag(b)||_F / ||offdiag(ESG_l)||_F` — скаляр.
- Per-pair остатки кубического фита: структура, зависимость от `ε`.
- График `Δz/ε` vs `ε` для диагностики режима.
- Bootstrap CI на `b` по сэмплам.
- Кросс-чек: корреляция `||b||` на L23 с `κ` из E-28 (sweep `r`).
- Опциональный контроль: корреляция `‖b(t)‖` (Гессиан, per-position) с `|Δp(t)|`; если ~1 — Гессиан тоже прокси для `|Δp|`, структура второго порядка не несёт независимой информации (ожидание — положительная, но не единичная).

## Как

**Пилот.**
1. `|T| = 16` токенов, 2 слоя (L22, L23), 5 точек `ε ∈ {5%, 15%, 30%, 50%, 70%}` (в долях `||h||`); `s_l` отчитывается на `ε_canon = 15%`.
2. Для каждого `i ∈ T`: инъекция в `h` последнего токена (`h_l += δ_i`, нормированный `δ_i`), `prefix_cache` чистый; полный форвард через `_run_decoder_pass`, получить `Δz_j` для `j ∈ T`.
3. Фит per-pair `Δz_j(ε) = a_ji·ε + b_ji·ε² + c_ji·ε³`.
4. Проверить: `c` значим? Остатки случайны? `Δz/ε` линейно по `ε`?
5. Критерий разворачивания: `c` незначим и остатки случайны по всему диапазону.

**Полный E-32.**
1. `|T| = 64`, 5 слоёв, 5 значений `ε`, N = 32 сэмпла.
2. Те же шаги.
3. Bootstrap CI по сэмплам для `b`.
4. Значимость: CI не включает 0.

**Кросс-чек.**
1. Для каждого `r ∈ {1, 8, 16, 32, 128}`: `κ_r(t)` из E-28.
2. Корреляция `κ_r` с `||b(t)||` по позициям.
3. Пик корреляции — `r`, при котором κ и Гессиан мерят одно.

## Интерпретация

| Наблюдение | Что означает |
|---|---|
| `a ≈ ESG_l` (валидация) | метод корректен |
| `s_l ≪ 1`, остатки случайны | readout практически линеен, P1 валидна |
| `s_l ~ 1` | нелинейность сравнима с линейностью, P1 требует cross-talk защиты |
| `s_l ≫ 1` | readout существенно нелинеен |
| `c` значим, остатки растут | мы вышли за радиус сходимости, нужен другой диапазон `ε` |
| Кросс-чек: пик на `r = 16` | E-28 и E-32 согласованы |
| Кросс-чек: пик смещён | E-28 и E-32 мерят разные режимы |

## Критерии остановки

- Пилот: `|T| = 16`, 2 слоя, 5 ε, критерий `c` незначим и остатки случайны.
- Если пилот проходит → полный E-32.
- Если пилот не проходит → добавить ε-точки или пересмотреть диапазон (возможно, `ε → 0`).

**Стоимость.** Полный E-32: `64·5·5·32 ≈ 51k` форвардов-от-слоя (в единицах `_run_decoder_pass`). Батчится по `i`, `ε` — но `K=64` инъекций на позицию = 64 отдельных `_run_decoder_pass` (нельзя батчить: инъекция разная). Оценка GPU: ~2–3 часа на T4. Планировать.

# E-33. Контроль: gauge-голономия

## Цель и идеология

Проверить, даёт ли gauge-голономия нетривиальный self-инвариант, или она тривиальна (случайна на L6–L22, как `Δ_SVD` в E-28). Идеология: контрольный эксперимент, а не ставка. Ожидание — тривиально, но подтвердить по коду дешевле, чем обсуждать.

## Математика

**Gauge-оператор.** `P(p_t) = diag(p_t) − p_t p_tᵀ`, не проектор (`P² ≠ P`), ker = span{𝟙}, rank = K−1.

**Плакетка.** «Петля в глубине» — не петля: одномерная ось, замкнутого контура нет. Нужен замкнутый контур в плоскости (глубина, позиция): `(l,t) → (l+1,t) → (l+1,t+1) → (l,t+1) → (l,t)`.

**Транспорт (пространства несовместимы).** `v_g` из E-12a живёт в `R^D` (hidden), `P(p)` действует в `R^K` (token) — транспорт `v_{l+1} = P(p)·v_l` некорректен. Два оператора на рёбрах разных типов:
- **Вдоль глубины:** `T_l^{(h)}: R^D → R^D` — транспорт скрытого направления между слоями через `D_l = ∂h^{l+1}/∂h^l`.
- **Вдоль позиции:** `T_t^{(p)}: R^K → R^K` — транспорт токенного направления через `P(p_t)`. (Нормализация обязательна: `P` не сохраняет норму.)

Голономия обхода плакетки — некоммутативность `T^{(h)}` и `T^{(p)}`: тут комбинируются два источника, что богаче, чем «gauge-голономия вдоль глубины».

**Предсказание.** Если gauge-направление `v_g` из E-12a транспортируется нетривиально → голономия ≠ 0 систематически. Если E-28 показал `κ ≈ random` на L6–L22 для Procrustes (не gauge), то и эта голономия ожидается случайной. Ставка на тривиальность сохраняется.

## Подводные камни

1. **P — не проектор.** `T^{(p)}` зависит от соглашения нормировки. Разные соглашения дадут разные скаляры. Не «канонический инвариант».
2. **Gauge share L6–L18 = 0.22–0.48** (E-14). Большой поворот в D=1024 даёт голономию близкую к случайной. Тривиальный результат почти гарантирован.
3. **Сравнение с random baseline.** Обязательно: случайные ортогональные матрицы того же размера, те же контуры.
4. **Sentinel.** На ранних слоях `p_t` может быть почти uniform (низкая confidence), `P` вырождается. Отчитываться разбросом.
5. **Alignment с E-28.** Gauge-голономия — частный случай Procrustes-голономии. E-28 показал random на L6–L22.

## E-33-preflight (вариант 2, один вечер)

Контрольный вопрос, достаточно для закрытия: **отличим ли транспортированный вектор от случайного той же нормы?** Если нет — gauge-связность тривиальна, вопрос закрыт.

- `v_g` (E-12a) транспортируем по одному циклу глубины (через `T^{(h)}`) и по позиции (через `T^{(p)}` на токене-копии).
- Baseline: случайные векторы той же нормы, тот же цикл; сравнение — углы/alignment, permutation test.
- Результат тривиален → E-33 закрывается как контроль.

## E-33 полный (вариант 1, условно)

Только если preflight покажет нетривиальность. Обход плакетки с разными операторами на рёбрах разных типов; голономия = `T_t^{(p)} T_l^{(h)} (T_{t+1}^{(p)} T_l^{(h)})^{-1}` (в соответствующих пространствах) vs случайный контур той же формы.

## Что собираем

**Preflight:**
- Транспорт `v_g` по глубине и по позиции vs случайный той же нормы (углы, permutation test).

**Полный (условно):**
- Голономия обхода плакетки per-layer (L6, L12, L18, L22, L23).
- Random baseline (Haar-ортогональные, те же контуры).
- Alignment с E-28 (корреляция).

## Как

1. Загрузить exp27b dense-кэш `p_t^{(i)}` (нормализованный `P128`) и hidden `H` (для `T^{(h)}`).
2. Preflight: транспорт `v_g` vs случайный той же нормы.
3. (Условно, полный) Обход плакетки per sample (per-sample сначала), усреднение.
4. Сравнить с random baseline.
5. Сохранить `exp33_gauge_holonomy.json`.

## Интерпретация

| Паттерн | Что означает |
|---|---|
| Транспорт ≈ случайный той же нормы (preflight) | gauge-связность тривиальна, согласуется с E-28 — E-33 закрыт |
| Транспорт ≠ случайному, `F ≪ random` на L6–L22 | gauge-структура несёт нетривиальный self-инвариант → разворачивать полный вариант 1 |
| Пик на L23 | gauge-голономия структурирована на выходе |

## Критерии остановки

- Preflight — один прогон на один вечер.
- Если preflight тривиален → закрыть как контроль, не развивать.
- Если preflight нетривиален → полный вариант 1 (плакетка), но не приоритет.
