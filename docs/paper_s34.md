### 4.1. Корректна ли цепочка и что несёт сигнал

**Вопрос.** Держится ли identity-цепочка, и какой компонент метрики несёт сигнал (learned W vs случайная ортогональная, полнота спектра EᵀE)?

**Что получили.**
- **E-1** (N=1, K=4; 0.8B): все 24 слоя gap ≈ 10⁻⁸ (макс 1.0×10⁻⁷); детерминизм PASS (макс разница 0.0).
- **E-3** (N=4, K=32; 0.8B, GPU-ре-ран): c `pinv(EᵀE)` gap(L0) = −1.4×10⁻⁸; без коррекции — 0.700; **случайная ортогональная R — 1.02 ± 0.01**. Разница corrected vs raw — 10⁷×.
- **E-5** (N=2, K=8; 0.8B): перестановка эмбеддингов ломает мост (L0: 1.7×10⁻⁸ → 0.98), обратная перестановка восстанавливает (4.3×10⁻⁸).
- **E-6b** (0.8B): κ(EᵀE) = 1684; все eigenvalues > 0 (полный ранг 1024, min eig 12.5); Tikhonov λ ≤ 0.01 не меняет результат.
- **E-8** (N=1, K=8; 0.8B): n_components: 16 → 0.89, 64 → 0.77, 256 → 0.51, 512 → 0.30, 1024 → 2.4×10⁻⁸.

**Вывод.** [И] Реализация корректна (E-1). Inverse Gramian критичен: без него loss 0.700 (L0; 0.533–0.861 по 24 слоям) vs 10⁻⁸. Три режима упорядочены: corrected (≈0) < raw (0.700) < random R (1.02) — Gramian correction убирает bias, learned W убирает rotation; learned W ≠ случайная ортогональная (E-3). Мост опирается на семантику эмбеддингов, а не только на размерности: перестановка ломает его, обратная восстанавливает (E-5) — H3 подтверждена. Нужен полный спектр EᵀE: усечение даже до 512 не даёт identity (E-8).

**Граница вывода.** N = 1–4 (демонстрация, не оценка на популяции); gap(L0) — один слой для E-3/E-8 (E-3: диапазон по слоям в JSON); E-5: N=2.

**Статус и следствие.** P0 (корректность) закрыт: цепочка воспроизводит identity до 10⁻⁸, сигнал несёт learned W + полный ранг Gramian. Далее метрика используется как валидная.

### 4.6. Первый порядок и локализация остатка

**Граница вывода.** (а) На L22–L23 часть ρ коррелирует с прыжками p: Spearman(ρ_raw, |Δp|) = 0.29 (L22) / 0.36 (L23) — интерпретация ρ на поздних слоях с этой оговоркой. (г) P(p) — не проектор ([L-gauge]): интерпретация «сколько энергии в off-diagonal после снятия gauge» приблизительна.

**Статус и следствие.** Статус E-32 переопределён: таргет — хвост r ≥ 118, приоритет L22 (E-30b). Запускает блок 4.7 (второй порядок).

**Источник.** ref-exp: E-34, E-30, E-30b (таблицы ρ; JSON `results/exp34_p1_coupling.json`, `results/exp30_mode_decomposition.json`, `results/exp30_full_spectrum.json`).

### 4.7. Линейный режим, кривизна, desync

**Вопрос.** Линеен ли readout, несёт ли кривизна (Гессиан) сигнал во втором порядке, и что такое desync?

**Что получили.**
- **E-12a** (N=8, K=64; ε-sweep 0.01/0.1/0.5/1.0): на масштабах ε/‖h‖ = 14–53% полный decoder даёт ratio ≈ 1.02–1.04, линейный предиктор — 7–59× — поведение поля J(h) важно; uniformity 0.61–0.98.
- **E-32r.2** (N=32; T=128; 16 ε; 5 слоёв): s_l = 0.0016–0.0726 ≪ 0.3 на всех слоях, slope ≈ 1.0 — **линейный режим**; (A) подтверждён: d₃(r=1, L23) = 0.162/1.494/0.042 (raw/gf/fixP); (B) отклонён: OLS α p = 0.76–0.94; a_vs_ESG_cos = 0.557→0.992 (L6→L23).
- **E-32r.3** (supersedes E-32r.2 + L19; 6 слоёв): s_l ≪ 0.3, slope ≈ 1.0, quad_frac 0.8–3.1%; d₃,raw(1): 1.393→0.162 (L6→L23, монотонно); d₃,gf(1) флэт ≈ 1.50; OLS α незначим → **исход (C): кривизна — независимый объект**, не desync; матричный cos(JR, J_tail): 0.095→1.0000 (L6→L23); chain rule a₁ = J_tail ê — в точности фита (single-point L6: +1.5%).
- **E-32r.3.1** (192 пар): матричный cos(JR, J_tail): 0.105/0.237/0.598/0.642/0.789/1.0000 (L6→L23) — desync раннего слоя количественно; d₃,raw,tail(1) ≈ 0.03 на всех ранних слоях — «ранний шум» d₃,raw ≈ 1.4 = **desync полного пути, не локальное отображение**; tail-кросс-чеки ρ(‖b‖, d₃) незначимы.
- **E-32-tail** (L18/L22, N=32; T=128; 16 ε): **(T2) — полная инверсия**: off² (первый порядок) в хвосте ESG (r∈[119,128], 34–91%), b_off (второй порядок) в **топ-модах k=1..6** (97.3–98.5% в r≤118); Spearman(ΔC_b, ΔC_off²) = −0.59/−0.41 (L18/L22); overlap top-5 = 0; tail_share_b = 2.5–2.7%; устойчив к базису.

**Вывод.** [П] H7 отклонена: readout линеен (s_l ≪ 0.3, quad_frac < 3.1%), кривизна несёт desync-сигнал во 2-м порядке — нет (OLS α незначим, d₃,gf флэт). [И] Desync — свойство полного пути (chain rule по слоям), не локального отображения: ранние слои desync-нуты (cos 0.095–0.105), L23 синхронен (cos 1.0000). [И] Первый и второй порядок живут в **разных** модах ESG: off² — в хвосте (r ≥ 119), b_off — в топ-шестёрке (k=1..6) — полная инверсия локализации (E-32-tail).

**Граница вывода.** N=32; T=128 (S=64 на части слоёв в E-32r.2); 16 ε — дискретная сетка. Pилот L18/L22 (E-32-tail): остальные слои — экстраполяция. «Матричная» метрика — по приращениям (кумулятивная Spearman вырождена в 1.0).

**Статус и следствие.** E-32 переформулирован как локализация второго порядка по модам ESG (E-32-tail). T2 (инверсия) — центральный результат: таргет второго порядка — топ-моды, первого — хвост. Открывает многоточечную метрику (P1): каждый порядок — свой режим ESG.

### 4.8. Прикладной контур, управляемость, Goodhart

**Вопрос.** Можно ли двигать мост редактированием readout, означает ли рост моста улучшение модели, и работает ли прикладной контур (defrag/квантование)?

**Что получили.**
- **E-11a** (N=4, K=32; слои 6/12/18): defrag сходится при r = 4; KL(gf) ~ 10.5.
- **E-11b** (N=2, K=256; слои 6/12/18): speedup 2.7–18.9× (sample-строки) / 4.0–17.8× (cell); fidelity-метрика v1 — баг (пересчёт).
- **E-11c** (N=8, K=64; 8 par, T4): defrag r ≤ 32 разрушает мост: Spearman r = 8/16/32 = 0.81/0.71/0.43 — мост ломается уже на low-probability хвосте топ-K.
- **E-12b** (N=4, K=32; слои 6/12/18): квантование по карте: KL ~ 15; Δh на 4× меньше.
- **E-12c** (N=4, K=32; слои 6/12/18): мост map 0.001 vs uniform 0.014–0.020 — карта несёт сигнал.
- **E-16a** (K=256, N=4; 100 шагов, T4; аналитический last-layer readout, loss (1−cos) + 0.1·KL(leash), Adam lr=1e-3): bridge **0.599965 → 0.7543** при ‖ΔW‖ **0 → 100.7**, KL leash **0 → 0.2403**; continuation до 1000 шагов: bridge **0.921** при ‖ΔW‖ = 128.8; V1 alpha-sweep — VOID.
- **E-16b** (финальный ΔW, 1000 шагов; C4 held-out, n=6): bridge 0.603 → 0.921; **top-p retention 0.837 → 0.416** — антикорреляция «bridge растёт / поведение ломается».
- **Exp 17–19** (P2): bridge-лосс движет LoRA-дистилляцию (P2 валидирован как механизм); downstream-валидация — не запущена.

**Вывод.** [И] Readout-редакция — causal lever: одна матрица (lm_head) двигает мост к target с ограниченным collateral по KL (E-16a). [П] «Рост bridge = улучшение» — **Goodhart на геометрическом прокси, не неудача оптимизации**: точечный bridge не является валидной целевой функцией качества (E-16b). Отсюда — требование многоточечного ограничения, а не более сильного оптимизатора. Прикладной контур: defrag дешёвый, но ломает мост при r ≤ 32 (E-11c); квантование по карте сохраняет мост (E-12c). H4 — частично (P2): механизм управляемости работает, downstream-эффект не валидирован.

**Граница вывода.** (а) exp16 — аналитический last-layer readout, exp19 — per-token full-path: **разные величины bridge, не сравнимы** (structural, не bug). (б) α\* не определена: knee за 100 шагов не достигнут; 0.3207 = ‖ΔW‖/‖W‖ на шаге 100 — доза, не оптимум. (в) V1 alpha-sweep VOID — caps ≥ 0.1 не bind, его «α\* = 0.01» — артефакт. (г) N = 4 — демонстрация механизма, не оценка на популяции. (д) Fidelity E-11b — v1-метрика (баг), значение не отчитывается.

**Статус и следствие.** Приоритет: многоточечная метрика + downstream-валидация, а не увеличение дозы. P2 открыт (LoRA-дистилляция), P3 (downstream) — закрыт до метрики.

**Источник.** ref-exp: E-11a, E-11b, E-11c, E-12b, E-12c, E-16a, E-16b, Exp 17–19 (JSON `exp16 JSON`, `results/exp11c JSON`).
