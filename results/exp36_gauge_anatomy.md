### Интерпретация

- **D1: динамика правых субпространств — в ⊥U-компоненте (L6–L22).** ⊥U ≈ raw
  (разница <0.01) — uniform-сплит почти не меняет Δ_SVD на L6–L22. На L23 сплит
  НЕ нейтрален: perp 0.2433 vs raw 0.2936 (~17%), и par мала (0.1934) — на L23
  всё когерентно, динамики почти нет в какой бы то ни было компоненте. Тренд:
  ∥U-когерентность падает с глубиной: 1.32 (L6) → 0.19 (L23); uniform-часть J
  становится quasi-стационарной.
- **D2: топ-1 левый вектор почти uniform.** uniformity(u_1) = 0.65–0.81
  при случайном 1/K = 0.0078. L22 аномалия: u_1+u_2 дают 0.52+0.36 —
  2D uniform-манифолд (согласуется с E-30b: L22 — приоритетный слой).
  L23 — парная структура: u_1, u_2 высокие (0.74, 0.14), u_3 низкий (0.003),
  u_4 подскок (0.021), u_5 низкий (0.002), u_6 подскок (0.024). Регулярный
  паттерн, не шум; возможно связан с факторизацией E-35 (M_K·(I−ûûᵀ)) — не
  разобран, фиксирован как наблюдение.
- **D3: различие фикс/динам — только в σ_1.** (refit с нормированным p̄_med,
  Σp=1.) На σ_1: P(p_t)·J < P(p̄)·J на L6–L22 (per-position P убивает чуть
  меньше, чем медианный), ΔP_t·J ≈ P(p̄)·J — вариационная часть того же
  порядка. На σ_2–σ_32 различие фикс/динам исчезает. L23: все три спектра
  совпадают — P-фактора там нет. Отклонение от ТЗ: ТЗ требует p̄ = mean_t(p_t);
  использована нормированная медиана по non-sentinel — осознанно (робастность
  к пиковым p_t; P(p) — якобиан softmax только для Σp=1); см. meta.deviation.
  Дата refit: 2026-10-12 (meta.d3_refit).
- **D4: α не объясняет Δ_SVD.** В верхних парах (6-12, 12-18) Δ_SVD в
  группах Q1/Q4 совпадает (1.5545/1.5546); даже в 22-23 эффект слабый
  (a: 1.47/1.44). |α| монотонно падает с глубиной: 0.972 → 0.616.
  Оговорка: α и глубина коррелированы (оба падают с глубиной), контроль по
  глубине (частичная корреляция/регрессия) не сделан — вывод «глубина —
  драйвер, не α» — интерпретация, не проверенный результат.
- **D5: û (E-35) ортогонален v_1 (L23).** |β| med = 0.02–0.03 (p90 < 0.06) в
  L6–L22, ровно 0 в L23 (по построению E-35). Ограничение: ‖v_⊥(t)‖ и
  Δ_SVD по v_∥/v_⊥ не считались (не в ТЗ-минимуме) — утверждение «структура
  живёт в ⊥v_1» подтверждено только малостью β, а не декомпозицией энергии.

## Финальный вердикт: (B) — gauge = смесь

По критериям ТЗ (§критерии): **(B) Gauge = смесь.**

- E-36.1 (D1) показывает разные роли ∥U и ⊥U — uniform-часть quasi-стационарна,
  дифференциальная часть несёт Δ_SVD (L6–L22); L23 — когерентен целиком.
- E-36.2 (D2) даёт колено на k>1: L22 — 2D uniform-манифолд (u_1+u_2=0.88),
  L23 — парная структура (u_4/u_6-подскоки).
- E-36.3 (D3) после refit: различие static/dynamic живёт только в σ_1
  (per-position P убивает на σ_1 чуть меньше медианного; на σ_2–σ_32 — нет
  различия), L23 — P-фактора нет. Критерий E-36.3 «разные структуры для
  static и dynamic» выполнен в слабой форме: на σ_1 есть разрыв, на остальном
  спектре — нет.

Формулировка: **«gauge» — категория объектов: uniform-сдвиг (L6–L18: топ-1
uniform) + L22 2D-компонента + σ_1-компонента P-фактора; каждая со своей
ролью.** Чистый (A) отклонён (декомпозиции дают разные ответы), чистый (C)
отклонён (есть выделенные компоненты с разными ролями). Связь с E-37: P(p_t) —
слабая операция (контрпример: random p убивает на L22 на 98.7%,
реальный p_t — на 2.6%; см. E-37, C.2).

Все три исхода равноценны как результаты; предсказать, какой получится, на
текущих данных нельзя.
