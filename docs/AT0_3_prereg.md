# AT0_3 — T0.3 «Кто несёт отрицательную площадь» (ТЗ v1.1 §1.5, disk-only)

## Формулировка (буква ТЗ)

Срез Σ (отрицательной площади под кривой ACF) по: loopy / non-loopy; квантилям
copy-rate; домену (n≥12); layer-type. **Знак исправлен:** период-2, ρ(k)=(−1)^k ⇒
r≈0. Σρ̂→−1/2 только при K→N−1 (все лаги); при используемом K≤96 |Σρ̂|≪1/2 — величина
несущественна, несёт знак: отрицательная площадь — на НЕЧЁТНЫХ k (основная доля на k=1),
положительная — на ЧЁТНЫХ. Пре-рег: у loopy-доков отрицательная площадь
сосредоточена на нечётных k; у чистых — в хвосте k≥9. Разрезы per-stratum, не pooled.
**Что убивает:** одинаковое распределение у loopy и чистых ⇒ период-2 не носитель.

## Фиксация дизайна (пре-рег, ДО прогона)

**Объекты (роли; (d)-решение — docs/AT0_3__N4.md, ревью архитектора):**
- **du_unit (Δu) — первичный** (зубы период-2 у du_unit: r≈0.0048, r_max<1, телескоп;
  h_raw норм-конфаундирован; v_tangent r≈24.9, не DC-free).
- **h_raw (Δh) — вторичный (robustness)**: тот же тест, то же пре-рег направление L>C;
  не co-primary (radial/norm-канал может имитировать период-2).
- **v_tangent (v̂) — описательно** (двухсторонний, no claim): источник loopy-стратификатора
  (dip_V,med L23) — **cross-object стратификация объявлена** (L/C по v_tangent,
  первичный эстиманд — du_unit).

**odd_frac ≠ знак excess(3,4)** (T0.1): объектно-зависимый знак excess (v_tangent —
горб +0.0121; h_raw/du_unit — анти-горб −0.0134/−0.0137) обосновывает выбор объекта,
но НЕ направление L>C (оно — из ТЗ §1.5).
**Слои:** L{1,5,11,17,23} (0-based 1,5,11,17,23). **Первичный** — L23 (как канон AT0_1).
  layer-type (0-based, из config Qwen3.5-0.8B): full_attention={11,23}, linear_attention={1,5,17}.

**Оценщик (per doc, per layer, per object):**
- `x_t` — приращения объекта; `N = T_states − 1`.
- ACF: `rho(k) = c(k)/c(0)`, `c(k)=Σ_{t<N−k}⟨x_t,x_{t+k}⟩`, k=1..K, **T-нормировка**
  (это Σρ̂ — частичная сумма точного G1-объекта; полное тождество 1+2Σρ̂=r — по всем
  лагам K→N−1; при K≤96 — частичная сумма, |Σρ̂|≪1/2).
  `K = k_of(n) = max{24,32,96} ≤ N−1` (как AT0_1; K<33 ⇒ banda {33..96} пуста).
- Отрицательная площадь по лагу: `neg(k) = min(rho(k), 0) ≤ 0`.
- Полная отрицательная площадь: `A_neg = Σ_{k=1..K} neg(k) ≤ 0`.
- Доли локации (per doc): если `A_neg < 0`, `frac[B] = (Σ_{k∈B} neg(k)) / A_neg ∈ [0,1]`:
  - `odd_frac` (нечётные k), `even_frac` (чётные k)
  - `k1_frac` (k=1), `tail_frac` (k≥9)
  - band_frac по полосам `{1},{2},{3..8},{9..32},{33..96}`
  - если `A_neg == 0` (нет отрицательной площади) → `no_negative_area=True`, доли undefined.

**Стратумы:**
1. **loopy/clean/remainder** (основное сравнение):
   - L (loopy): `loopy_ladder` = (max_{k≥2} dip_V,med L23 > 0.95) или wiki_0/wiki_4 — n=41.
   - C (clean): non-degenerate (`degen_tz==False`) — n=53.
   - R (remainder): degen и не-loopy — n=2 (own_w0, own_w4) — только отчёт, n<12.
   (loopy ⊆ degen; сверено по данным.)
2. **copy-rate квантили** (low/mid/high; резы q25/q75 — 25/50/25, не равные трети) —
   только 80 доков с токенами (n=80).
3. **домен** (n≥12 правило): доменное утверждение только при n≥12 невырожденных;
   остальные (n<12) — пул: описательная строка отчёта (per-doc odd_frac/локация, без
   стратум-теста, без доменного claim). nondeg per dom: corpus 16, math 16, chat 11,
   code 8, own 1, wiki 1.
4. **layer-type**: full_attention {11,23} vs linear_attention {1,5,17} (per doc).

**Первичный тест (период-2-носитель):**
- Эстиманд: `odd_frac` (du_unit, L23, per doc с A_neg<0; docs с A_neg==0
  исключены — no_negative_area, guard).
- Вторично (robustness, тот же тест, то же пре-рег направление L>C):
  `odd_frac` (h_raw, L23).
- Описательно (no claim): `odd_frac` (v_tangent, L23), двухсторонний — направление
  не заявлено (v_tangent — горб-объект по T0.1).
- Стратумы: L (n≈41) vs C (n≈53) — cross-object стратификация (L/C по v_tangent dip).
- Тест: двухсторонний перестановочный two-sample (B=1000, seed=117, коррекция +1).
- Пре-рег направление: L.odd_frac > C.odd_frac (loopy концентрируют отриц. площадь
  на нечётных) — для du_unit и h_raw.
- Вторично (описательно): C.tail_frac > L.tail_frac (чистые — в хвосте k≥9).
- **Решение (du_unit):**
  - p ≤ 0.05 И направление L > C → «период-2 — носитель: loopy доки концентрируют
    отрицательную площадь на нечётных k, чистые — в хвосте» (пре-рег подтверждён;
    h_raw — robustness, ожидается то же направление, mismatch — отчёт).
  - p > 0.05 → «период-2 НЕ носитель — распределение локации отриц. площади у loopy и
    чистых не различимо» (kill).
  - p ≤ 0.05 И противоположное направление → «пре-рег опровергнут (различимо, но не так)».

**Гейты (валидация ACF/площади):**
- G1_gram: `gram_resid < 1e-10` на всех (doc,L,obj) — валидация ACF.
- G3_rNfDC: `r = N·f_DC` (rel 1e-9).
- Telescope: `‖Σ_t Δu_t − (u_T − u_0)‖ < 1e-6` (per doc,L).
- G2: ожидаемое число клеток.

**Артефакты:** `results/AT0/store/<sha16>.json` (полный), `results/AT0/AT0_3_AREA.json`
(claim), `results/AT0/AT0_3_manifest.json`, `results/AT0/AT0_3_run.log`.

**Бан-лист (не делать):** pooled-фит; Σ на Δ_med; min/max бутстрап как CI; доменные
строки при n<12; «dip» без индексов; S(0)/Σ на медиане.

## Аддендум 2 (13.11, после внешнего ревью артефакта r2 — мета, не редизайн)

Внешнее ревью артефакта (docs/AT0_3_artifact_review_r2.md) дало 7 содержательных находок.
Приняты и применены ДО полного прогона (не post-hoc, код и артефакт пересчитаны):

1. **tail-предсказание — fail-loud.** Пре-рег содержал ДВА предсказания (loopy → нечётные k;

   внутри пары). p изменился (unpaired 0.368 → paired, см. артефакт); вывод «no effect»

4. **G0a-гейты добавлены (канон AT0_1).** `G0a_provenance` (sha256 трёх источников == AT0_1;

### 3.1. Первичный пул: K=96 (канон T0.1 P4)
Исключаются из ЛЮБОГО первичного теста доки с K<96 (cor_w8, cor_w11 — оба в C, K=32).
L=41, C=51. Fixed-band robustness-эстиманд: odd_frac на полосе k=1..24 для ВСЕХ доков

### 3.2. Тесты (первичный, K=96-пул, du_unit L23, L vs C)
- **PRIMARY: перестановочный KS** (расстоя́ние двух выборок, перестановка ярлыков, B=1000).
  Пре-рег-kill-условие — «одинаковое РАСПРЕДЕЛЕНИЕ», не «одинаковые средние» — тестируется
  непосредственно.
- **SECONDARY: перестановка на разности медиан** (robust location).
- **SECONDARY: mean-тест** (существующий; теперь не первичный).
- **ROBUST: fixed-band odd_frac k=1..24** (полный пул, mean-перестановка).
- Вердикт-правило: KS p≤0.05 → «различимо» (kill не установлен); направление — по медианам
  (L<C → «направление против пре-рега»). KS p>0.05 → kill по пре-регу.

### 3.3. Period-concentration estimand (новый механизм-тест)
Для каждого дока (du_unit L23): p = наименьший k≥2 с ρ(k)≥0.9 ∧ ρ(2k)≥0.81 (гармоника);
если не найден — p=None. Для p-доков: профиль массы отрицательной площади по классовым
остаткам mod p (p классов); метрики: max_res_share (доля A_neg в самом массовом остатке),
top2_res_share (сумма двух), concentration = max_res_share·p (база 1 = равномерность),
dom_residues (два топ-остатка), anti_frac (доля A_neg на k≡p/2 mod p — буквальный
C3-эстиманд, ожидаем ≈0). Per-doc перестановочный тест концентрации (позиции значений
перемешиваются, B=1000). Агрегаты: detection-rate L vs C (точный биномиальный тест),
средние концентрации. Гипотеза H2: «лоopy-доки несут периодическую лаговую структуру
(p∈{5..32}), а отрицательная площадь организована по классовым остаткам на фазе границы
лупа (остатки 1 и p−1) — НЕ на анти-фазе p/2 и не на нечётных k вообще; чистые — без
периода, площадь на лаге 1».

### 3.4. Source-стратификация (описательно, n<12 → no claim)
На K=96-пуле: L vs C по источнику (gen/own/corpus) и по домену (chat/code) — odd_frac +
odd_frac_k24, n явно, claim запрещён при n<12. Объявлен конфаунд: L=68% own+wiki,
C=60% corpus+math; corpus (16, все в C) без токенов — degen только по mcos (mshare
выброшен) → смещение к «чистым», т.е. в пользу нулевой гипотезы H1.

### 3.5. v_tangent: forced_outcome
Если mean(b1) у clean > 0.8 → forced_outcome=true, p не цитировать (odd_frac≡1
тождественно при b1≈1 — у чистых отрицателен только лаг 1).

### 3.6. G10-декларация (достижимые/форсированные исходы)

## Аддендум 4 (r3.1) — фиксы по fixreview (реестр, НЕ смена гипотез)

  Имя гейта: `G0a_tpu_curves`.

  (Примечание: исходный мин-гейт был ad-hoc — §3.3 фиксировал «detection-rate + концентрации»,

- **A6.** Docstring `perm_two_sample_stat`: p-формула two-sided для signed-статистики,
  **right-tail** для unsigned (KS) — не «two-sided для обоих».
