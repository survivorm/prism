### 1.1 Где я не согласен с F2 (и это проверимо)

Ревьюер: при T=0 `top_k` — no-op при обеих гипотезах, значит свип имел нулевую мощность.
Для двух из трёх моделей это так (эмиссия = аргмакс некоего распределения, усечение
аргмакс не удаляет). Но не для всех: модель «отчёт = дистрибуция движка, а выбор делает
ступенька **после** `top_k`, читающая уже усечённый набор» при `k=1` обязана была выдать
вершину 318. Выдано 310 ⇒ **эта конкретная модель свипом опровергнута**. То есть свип был
бессилен против вопроса гейта (M1-аргмакс vs штатная цепь штрафов), но не бессилен вообще.
Формулировка, с которой я согласен и которая идёт в протокол: «свип ширины при T=0 не может
различить модели, в которых эмиссия = аргмакс обработанных логов; он опроверг вариант
„выбор после усечения“; к условию 2 гейта он не имеет отношения».

## 4. Предрегистр S4c — решающая проверка BLOCK'а (записан ДО запуска)

Вопрос один: флип на `Q2 w13 k=117` создан штатной цепью (`penalties`/`dry`/`top_n_sigma`)
или нет. Запросы (один запуск сервера, `temperature=0`, `seed=8181`, `n_predict=1`,
`cache_prompt=false`, `n_probs=20`, адрес и ожидаемые литералы — из того же архива):

| tag | что |
|---|---|
| `S4c-bare` | адрес `w13 k=117`, `samplers="top_k,temperature"` (penalties/dry/top_n_sigma/typ_p/top_p/min_p/xtc выключены) |
| `S4c-bare-rep` | то же повторно, байт-в-байт (шумовой пол, MAJOR r10) |
| `S4c-base-rep` | адрес `w13 k=117` со штатной цепью, повтор запроса дважды (вторая строка = `S4c-base-rep2`) — тот же контроль шума без смены цепи |

Правило решения (иного чтения не будет):

1. `S4c-bare` выдал **3039** (вершину отчёта) ⇒ флип создаёт цепь штрафов; **вывод M1
   снимается**, остаётся «флип = эффект штатной цепи, механизм отчёта не различён»;
2. `S4c-bare` выдал **5522** (как со штатной цепью) ⇒ цепь не при чём, M1-ветка чиста от
   этого confound'а (но остаётся n=1);
3. выдал что-то третье ⇒ цепь влияет, но не объясняет: проба **невалидна** для вывода M1,
   записывается как есть;
4. `echo.samplers` не совпал с запрошенным ⇒ проба невалидна (запрошенное отключение не
   применилось), выводов нет;
5. шум: если `S4c-bare` и `S4c-bare-rep` различаются по эмиссенту ⇒ недетерминизм при T=0,
   весь прогон S4pp получает пометку «одна точка не повторяется», выводы по n=1 аннулируются;
   если эмиссенты равны, а логи различаются на `δ` — `δ` заносится в артефакт как допуск и
   все рассуждения «логи различаются/совпадают» перевыпускаются с этим допуском.

Само-аудит до запуска: (а) `samplers` — строка, а не список (проверить по `server-schema`
формату на mock, а не глазами); (б) assert 4 запроса; (в) mock-миры: `bare=3039`, `bare=5522`,
`bare=третье`, `echo.samplers` не совпал, `bare != bare-rep`; (г) артефакт пишется при любом
исходе; (д) запуск только `./run_one.sh`.
