# ТЗ: E-33r.2. Gauge как носитель структуры J

Формат: название → цель и идеология → математика → подводные камни → сбор → интерпретация → критерии остановки → артефакты. Все символы — по §2 paper.md. Расширение `docs/Exp33.md` (E-33r); не новый эксперимент.

---

## Цель и идеология

**Пилот E-33r (L22, L23) дал сильный контринтуитивный результат.** После снятия gauge `P(p_t)·J_t`:

- `Δ_SVD_gf(1) ≈ π/2` на обоих слоях (в отличие от raw: 0.29 на L23, 1.47 на L22);
- `Δ_gain(1) = −0.09` (L22) и **−1.27** (L23);
- `corr(Δ_SVD, d_S)` на L23 падает с 0.63 (raw) до 0.18 (gf);
- `depth_gain(22,23) = +0.53` (0.21 → 0.74) — межслойная когерентность растёт.

Это **не «анатомия gauge»** в исходном смысле, а **утверждение о локализации структуры J**: лист L23 и нить L6–L22 живут в gauge-компоненте; differential-компонента `P(p_t)·J_t` — неструктурированный остаток ~2% энергии.

**Идеология E-33r.2:** разложить «эффект P» на три независимых механизма и определить, какой из них доминирует:

1. **Изменчивость `p_t` по позициям** — P меняется от `t` к `t+1`, поэтому даже если P «почти изометрия на своём подпространстве», композиция `P(p_t)·J_t` и `P(p_{t+1})·J_{t+1}` может давать случайные подпространства.
2. **Фильтрация P как оператора** — при `p_max ≈ 0.9` P сильно сжимает всё, включая differential-компоненту; residual шумоподобный.
3. **Локализация структуры в спектре** — если структура живёт в 1–2 топ-модах, r=16 sweep усредняет её с шумом.

**Ожидание.** Скорее всего механизм (1) доминирует: change of `p_t` (Δp ≈ 0.05–0.1) даёт сдвиг проекции, достаточно большой чтобы 16-мерные подпространства разошлись в π/2. Diagnostic A отделит (1) от (2)/(3).

**Связка.** Если структура = gauge, это меняет рамку E-28 (лист = траектория `û` **плюс** gauge-структура), E-35 (факторизация `M_K·P_u` точна **включая** gauge), E-32 (cross-talk в хвостовых модах — не та мишень, потому что structure loss происходит уже в топе).

## Математика

**P(p) — не проектор.** `P = diag(p) − ppᵀ`, `‖P‖_op = p_max(1 − p_max)` при `p_max ≥ 1/2`. Для `p_max ≈ 0.9` — `‖P‖_op ≈ 0.09`; для `p_max ≈ 0.5` — `‖P‖_op ≈ 0.25`. Это объясняет `survive_frac ≈ 0.01–0.02` на L22/L23: P — широкополосный фильтр, не точечная аннигиляция uniform.

**Композиция P(p_t)P(p_{t+1}).** Не коммутирует с `P(p_{t+1})P(p_t)` при `p_t ≠ p_{t+1}` (диагональные матрицы `diag(p)` коммутируют, но `−ppᵀ` ломает). Насколько сильно это расхождение — определяется `‖p_{t+1} − p_t‖` и геометрией. **Это ключевая величина для механизма (1).**

**Четыре диагностики.**

**A. Fixed-P: изоляция изменчивости `p_t` от фильтрации P.**

Для каждого документа:
- `p_0 = p_{t*}` где `t* = argmax_t H(p_t)` — самая пиковая позиция (наибольший `p_max`, наименьшая энтропия).
- Вычислить `Δ_SVD^{fixP}(t) = ` max principal angle между топ-r правыми подпространствами `P(p_0)·J_t` и `P(p_0)·J_{t+1}`.
- Сравнить с `Δ_SVD_gf(t)` (когда `P` меняется на каждом шаге).

**Интерпретация:**
- `Δ_SVD^{fixP} ≈ Δ_SVD_gf ≈ π/2` → P сам разрушает структуру (механизм 2). Изменчивость `p_t` не главное.
- `Δ_SVD^{fixP} ≪ Δ_SVD_gf` (например, 0.3 vs 1.57) → изменчивость `p_t` — главный разрушитель (механизм 1).

**C. r-sweep: где в спектре живёт структура.**

`Δ_SVD_gf(Δ=1, r)` для `r ∈ {1, 2, 4, 8, 16, 32}`. То же для raw.

**Интерпретация:**
- Монотонный рост с r (r=1: 0.3, r=16: 1.57) → структура в топ-1–4, уничтожается на бо́льших r через random rotation оставшихся мод.
- Плоско на всех r (все `π/2`) → структура уничтожена целиком.
- Плоско на малых r, потом рост, потом насыщение → промежуточный случай.

**D. Alignment топ-16 подпространств `PJ_t` и `J_t`.**

`Ω_t = ‖U_{16}(PJ_t)ᵀ · U_{16}(J_t)‖²_F / 16` — средний косинус квадратов главных углов между топ-16 правыми подпространствами raw и gauge-free.

- `Ω ≈ 1` — подпространство не сдвинулось, P(fixed) почти изометрия на нём; вращение вызывается изменчивостью `p_t`.
- `Ω ≈ r/K = 16/128 = 0.125` (случайное пересечение двух 16-мерных подпространств в R^128) — подпространство полностью сменилось.
- Промежуточное — частичный сдвиг.

**E. α-sweep: непрерывная деградация.**

`P_α(p) = I − α·(I − P(p))` для `α ∈ {0, 0.25, 0.5, 0.75, 1}` (интерполяция между identity и полной P). Или альтернатива: `P_α(p) = diag(p^α) − ppᵀ` (мягкое сглаживание пика).

- Если `Δ_SVD` деградирует **непрерывно** с α → простое взвешивание структуры и шума.
- Если есть **порог** (резкий переход при α ≈ 0.3) → структура проходит через критическую точку; в этой точке интересны alignment `û` с топ-направлениями `P·J`.

**B. SNR-проверка (sanity).** `σ_16(PJ_t) / σ_17(PJ_t)` — eigengap. Если `≫ 1`, residual структурирован; если `≈ 1`, residual — шум. Ожидание из пилота: SNR высокий (не шум), но это стоит измерить явно.

**F. Cross-position P (опционально).** Применить `P(p_s)` с `s ≠ t` к `J_t`: `P(p_s)·J_t`. Если `Δ_SVD^{crossP} ≈ Δ_SVD^{fixP}` — важно только «какой P» (форма распределения), не «тот же P» (совпадение позиций). Если `Δ_SVD^{crossP} ≈ Δ_SVD_gf ≈ π/2` — критично «тот же P».

## Подводные камни

1. **Fixed-P выбор `p_0`.** `argmax_t H(p_t)` — детерминирован, но при близких энтропиях возможна неустойчивость. Альтернативы: median-энтропия, среднее по документу, случайный выбор (усреднить по 3 seeds). Рекомендую `argmax H(p_t)` с fallback на медиану при tie.

2. **α-sweep интерполяция.** `I − α(I − P)` недиагональна как матрица — прямое умножение `[K, K]` на `[K, D]` на позицию, дороже обычного P. Оптимизация: `(I − α(I − P))J = (1−α)J + α·P·J` — тот же `p_apply`, но с линейной комбинацией. **Не пересчитывать полную матрицу.**

3. **`Ω` для r > rank.** При r=32 `Ω = ‖Uᵀ W‖²_F / r`; если rank(PJ) < r, `U` неполный. Проверять `rank_gf` перед расчётом Ω; при `rank_gf < r` — `NaN`.

4. **Cross-position P (F).** При 32×128 позиций F даст `N_docs × 128 × 128` пар — 500k на документ. Ограничить: F только для `|s − t| ≤ 4` и `s = t + Δ` с `Δ ∈ {1, 4}`.

5. **Sentinel-mask.** Та же endpoints-only логика, что в E-33r. Для диагностик A/C/D sentinel не влияет (там одна позиция или весь документ); для F — та же маска по endpoints.

6. **`argmax H(p_t)` vs sentinel.** Если `argmax` попадает на sentinel-позицию — `p_0` суб-стохастический, `P(p_0)` другой. Исключать sentinel из выбора `p_0`; если все sentinel — fallback на `median p_t`.

7. **Согласование с E-28/E-35.** Все три диагностики — на тех же слоях {6,12,18,22,23}, той же позиционной конвенции, том же `r=16` базово. Диагностика C расширяет r, не заменяет базу.

## Что собираем

**Per-layer (L6, L12, L18, L22, L23):**

Diagnostic A:
- `Δ_SVD_fixP(Δ=1, r=16)` — per-doc медиана, IQR
- `Δ_gain_fixP = Δ_SVD_raw − Δ_SVD_fixP`
- `p_0_entropy` — распределение энтропии выбранной `p_0` по документам

Diagnostic C:
- `Δ_SVD_gf(Δ=1, r)` для `r ∈ {1, 2, 4, 8, 16, 32}` — per-doc, per-r
- `Δ_SVD_raw(Δ=1, r)` — то же для raw (для сравнения)
- `Δ_gain(Δ=1, r)` — per-r

Diagnostic D:
- `Ω_t` — alignment топ-16 подпространств `PJ_t` vs `J_t` (per-doc медиана)

Diagnostic E:
- `Δ_SVD_gf_α(Δ=1, r=16)` для `α ∈ {0, 0.25, 0.5, 0.75, 1}`
- `‖P_α·J‖_F / ‖J‖_F` — survive fraction как функция α

Diagnostic B (sanity):
- `σ_16 / σ_17` для `PJ_t` — eigengap residual

Diagnostic F (опционально):
- `Δ_SVD^{crossP}(Δ=1, r=16)` с `|s − t| ≤ 4`

**Обновлённый verdict:**
- Три ветки: `Δ_gain(1) < −0.5` (структура в gauge, доминирует либо изм. `p_t`, либо P-фильтр), `−0.5 ≤ Δ_gain < −0.05` (умеренное разрушение), `|Δ_gain| < 0.05` (факторизация точна, E-35).
- Дополнительное поле `dominant_mechanism ∈ {p_variation, P_filter, spectrum_localization, mixed}` — по результатам A/C/D.

## Как

1. Загрузить exp27b dense-кэш (та же загрузка, что E-33r.1).
2. Для каждого документа и слоя — SVD `J_t`, `P(p_t)·J_t`, плюс новый набор SVD: `P(p_0)·J_t`, `P_α(p_t)·J_t` для α-сетки, `P(p_s)·J_t` для cross-P.
3. Переиспользовать структуру `batch_metrics`: расширить аргументами `--diagnostics {A,C,D,E,F}`, `--r-sweep "1,2,4,8,16,32"`, `--alpha-sweep "0,0.25,0.5,0.75,1"`.
4. Агрегация — E-34 protocol (per-doc median → median/IQR по документам).
5. Sentinel endpoints-only.
6. Selfcheck: добавить тесты (a) `Δ_SVD^{fixP}` при `p_t = p_0` для всех t совпадает с `Δ_SVD_gf`; (b) α=0 совпадает с raw, α=1 совпадает с `Δ_SVD_gf`; (c) `Ω_t` при `P(p) = c·I` (например, `p = uniform`, c = 1/K) даёт `Ω = 1`.

**CLI:**
```
--diagnostics A,C,D,E,F    # default A,C,D
--r-sweep 1,2,4,8,16,32    # default только 16 (совместимость)
--alpha-sweep 0,0.25,0.5,0.75,1
--p0-method argmax_H       # или median_H, random
```

**Обратная совместимость:** без флагов `exp33r_gauge_anatomy.py` работает как раньше (только `r=16`, только 6 базовых срезов). С флагами — расширенный вывод.

| F: `crossP ≈ fixP` | Форма P важна, позиция — нет | Устойчивость к флуктуациям `p_t` |
| F: `crossP ≈ π/2` | Совпадение позиций критично | `p_t` — специфичный per-position ключ структуры |

**Обновлённый verdict для L23:**

Если Diagnostic A даёт `Δ_gain_fixP ≈ 0`, но `Δ_SVD_fixP` мало:
> **Структура J живёт в gauge-компоненте, и её разрушение вызвано изменчивостью `p_t` по позициям, не фильтрацией P. Лист L23 = (gauge-структура) × (per-position `p_t`) — два переплетённых объекта.**

Если Diagnostic A даёт `Δ_gain_fixP ≈ Δ_gain_gf`:
> **P(p_t) как оператор разрушает структуру J независимо от вариации `p_t`. Лист L23 живёт в подпространстве, которое P отображает в шумоподобный residual. Differential-часть PJ не несёт информации о позиции.**

Обе формулировки — новые результаты для §18.

## Критерии остановки

- **Пилот L22, L23** — один прогон, ~10–15 минут CPU (плюс α-sweep).
- Если Diagnostic A даёт чёткий ответ (изменчивость `p_t` vs фильтрация P) → зафиксировать как результат, развернуть A/C/D на все 5 слоёв.
- Если Diagnostic A неоднозначен → добавить E (α-sweep), F (cross-P) для разделения.
- Если `Ω ≈ 1` во всех случаях → диагностики A/C/D неинформативны; пересмотр всей рамки E-33r (возможно, `P` действует «правильно», а мы мерим не то подпространство).
- **Обязательное условие перед публикацией:** selfcheck проходит все новые тесты (a), (b), (c).
