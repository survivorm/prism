## 1. Одна строка и вопрос

R2-вердикт `NO_LOOP_SPECIFIC_EFFECT` (machine r2d) bounds контраст
`e_spec = loop − fillerA`, который одновременно несёт **«запоминаемое vs
новое»** И **«повторение vs не-повторение»** (TZ R2 §10, r2d-1.1). 2b
разделяет эти гипотезы вторым стимулом — **другой** фразой, повторённой n
раз, и факторным дизайном, где каждый канал меряется контрастом со своим
нулём:

- **H_phr (фраза-канал):** *контент повторяемой фразы* создаёт пост-
  эффект **в повторённой строке** — «запоминание именно этой фразы»,
  т.е. контентное различие L1 vs L2 (простой эффект `E_phr = L1 − L2`
  на периодических строках) превышает шкалу контентного различия
  shuffled-строк (`N_PHR`). **Bag-of-words режим (важен мешок токенов,
  порядок нет) — НЕ H_phr:** в нём `E_phr` и `N_PHR` одной шкалы → тест
  не срабатывает (синтетика 7).
- **H_rep (повторение-канал):** *периодический порядок* при **том же
  лексическом составе** (случайный порядок того же мультисета) создаёт
  пост-эффект.

Вопрос: какой из каналов (ни один / один / оба) несёт специфический
локальный пост-эффект поля при разрешении филлер-вариативности (нули из
shuffled-условий, §8)?

## 2. Главный сдвиг дизайна (от R2 и от 2b v1.0–v1.2)

- **Вердиктные количества (M1):** `E_phr := L1 − L2` (простой эффект на
  периодических строках; = PHR_main + INT) против `δ_PHR`; `REP :=
  (L1+L2−S1−S2)/2` (главный эффект периодичности) против `δ_REP`.
  PHR_main = D_L + D_S (контент в среднем по строкам) — **диагностика**.
- **Нули:** `N_PHR := S1' − S2'` (терм-непересекающийся с {L1,L2});
  `N_perm := (S1+S2−S1'−S2')/2` (сматчен: Var = σ_S² = Var(REP) при
  σ_L=σ_S; **знаковая** ковариация со статистикой отрицательна через
  общие S1,S2 — но на модульной статистике `p90|·|` знак не сохраняется
  (F4, контрпример в r4): защита — p95-маржин и измеренное σ_L/σ_S, §7.2).
- **Per-doc shuffle-сиды** (F1/r3-m1): `zlib.crc32(f"S{i}|{doc}|{n}")`
  — имя дока в стринге, без коллизий; draw-дисперсия в doc-bootstrap
  (прецедент AT2d-B1).
- **Дозы: n ∈ {2, 16}** (E_phr primary n=2 — контент жив; REP primary
  n=16 — максимальная доза периодичности; n=4/8 не гоняются — R2-плато).
- **R2-store заморожен и переиспользуется**: ctrl, loop1, fillerA,
  fillerB — read-only из `results/AT8/AT8_2_R2_store.json` (sha §10) на
  n=2 и n=16.
- Новые форварды: **5 условий × 14 доков × 2 дозы = 140** (R2: 182).
- Вердикт-машина R2 (per-doc δ, CI-правила, finite-гейт, doc-bootstrap) —
  сохраняется; меняются контрасты, нули, дозы, наблюдаемые, гейты, дерево
  (§11).

- **loop1 (зафиксирован R2):** `" The class will be held at the park."` —
  `PHRASE1_IDS = [561, 523, 668, 381, 5467, 506, 279, 5926, 13]` (9 токенов;

- **loop2 (новый, зафиксирован пре-регом v1.0, без изменений):**
  `" Three new buses wait near a quiet station."` —
  `PHRASE2_IDS = [14095, 491, 32275, 3655, 3043, 264, 11012, 7803, 13]`
  (9 токенов; верифицировано токенизатором Qwen3.5-0.8B; пересечение
  контент-токенов с phrase1 = ∅, общий только 13 «.»).
- **Shuffled-условия (новые, зафиксированы ЭТИМ пре-регом):**
  - `L_i(n)` = токен-последовательность `PHRASE_i_IDS × n` (длина
    `L_n = 9n`);
  - `S_i(n, doc)` = `L_i(n)[π_{i,doc,n}]`, где
    **`π_{i,doc,n} = default_rng(zlib.crc32(f"S{i}|{doc}|{n}".encode())).
    permutation(L_n)`** — **детерминированная per-doc перестановка** (F1).
    i ∈ {1,2,3,4} = (S1, S2, S1', S2'); `doc` = имя дока из таблицы §4
    (в сид-стринге — m2: индексу не нужна); `n` в стринге — явная
    независимость доз. **Полные 32 бита crc32, БЕЗ `% 99991`** (G17:
    `% 99991` в идиомах репо — для малых пространств; 112 сидов в
    99991 → P(≥1 коллизия) ≈ 6.2%, в 32 битах ≈ 1.5e-6). Старая v1.2-
    формула `10000·i + 1000·doc_idx + n` имела коллизию
    S1(doc10) ≡ S2(doc0) @ n=2 (= 20002; доки 10–13 между смежными i) —
    устранена.
    **Мультисет, длина, позиции — те же; сломан весь порядок (включая
    биграммы), периодичность в первую очередь.**
  - `S1'(n, doc)` — второй независимый draw от `L1(n, doc)` (i=3);
    `S2'(n, doc)` — второй независимый draw от `L2(n, doc)` (i=4).
- **Estimand REP (m3-r2, без изменений):** «**периодический порядок vs
  случайный порядок при том же мультисете**» — НЕ «повторение vs
  отсутствие повторения»: shuffled-блок сам повторяющийся (ожидаемое
  число смежных пар: n=2 → ≈1.0, n=16 → ≈15.0). `REPETITION_SPECIFIC`
  читается как «канал упорядоченности/периодичности». Сужение до
  «именно период-9» требует арма с другим периодом при том же мультисете
  ((p1+p2)×(n/2), +28 фд) — **follow-up, не в этом прогоне**.
- **Алгебра 2×2 (зафиксирована, M1; D_L = (L1−L2)/2, D_S = (S1−S2)/2,
  m_L = (L1+L2)/2, m_S = (S1+S2)/2):** `E_phr = 2D_L`, `REP = m_L − m_S`,
  `INT = D_L − D_S`, `PHR_main = D_L + D_S = E_phr/2 − INT`,
  `N_content := S1 − S2 = PHR_main − INT` (тождество, legacy-диагностика).
  Терм-непересекаемость: `{L1,L2}` (E_phr) vs `{S1',S2'}` (N_PHR) ✓.
- **Критерии phrase2** — как в v1.0 (форма, не CE/эффект; обучаемость —
  диагностика §9).
- **S_stimulus (fail-loud):** `L_n = 9n` для L1/L2/S1/S2/S1'/S2';

## 5. Геометрия (идентична R2)

```
T      = длина контроля (из R2-store, 196..512)
cut    = T // 2            (из R2-store)
L_n    = 9 * n             (L1/L2/S1/S2/S1'/S2' — равные длины и мультисеты пар)
inj_index(cut, n, d) = cut + L_n + d     (все 6 стимульных условий)
ctrl_index(d)        = cut + d           (ctrl)
H      = 64
near   = d ∈ [0, 15]
far    = d ∈ [48, 63]
```

Post-ряды L1/fillerA/fillerB — из R2-store (option A, M1: шов
`cos_raw[cut+L_n−1]` вне окна — без изменений). Post-ряды L2/S1/S2/S1'/S2'
— те же индексы (новые условия, тот же cut/L_n).

Геометрия верифицирована из стора (m4-r5): T−cut ∈ [98, 256] на всех 14
доках (минимум: code_0, T=196, cut=98); последовательность наращивается
(T_cond = T + L_n, len(ce) = T + L_n − 1 — проверено по стору), post-окно
(d ≤ 63) влезает для всех n (нужно T−cut ≥ 65) — кодовый путь смока на
n=16 безопасен.

## 7. Условия и контрасты

### 7.1 Условия

На (док, n∈{2,16}): `ctrl`, `L1`, `L2`, `S1`, `S2`, `S1'`, `S2'`,
`fillerA`, `fillerB` — 4 из R2-store (ctrl, L1, fillerA, fillerB), 5 новых
(L2, S1, S2, S1', S2').
**Соответствие ключей R2-store (запинено, m3-r5):** `L1 ↔ store["loop"]`,
`fillerA ↔ store["fillerA"]`, `fillerB ↔ store["fillerB"]`,
`ctrl ↔ store["ctrl"]` (проверено по стору).

### 7.2 Вердиктные контрасты и нули

```
E_phr := L1 − L2                    (H_phr: простой эффект на
                                    повторённых строках; = 2·D_L)
REP   := (L1 + L2 − S1 − S2)/2      (H_rep: главный эффект периодичности)
INT   := (L1 − S1 − L2 + S2)/2      (= D_L − D_S; report-only + тег)

N_PHR  := S1' − S2'                (нуль E_phr; терм-непересекающийся
                                    с {L1,L2}; не схлопывается —
                                    draw-шум > 0)
N_perm := (S1 + S2 − S1' − S2')/2  (нуль REP; Var = σ_S² = Var(REP)
                                    при σ_L=σ_S; знаковая ковариация со
                                    статистикой < 0 — НЕ защита модульных
                                    статистик, F4)
```

- **Row-type-несовпадение нулей — by design** (m3'): статистика —
  loop−loop, нуль — shuffle−shuffle: это и есть тест («контентное
  различие больше при повторении?»). Валидность = σ_L ≈ σ_S (P0:
  ×1.22 norm_delta@n2).

- **σ_L/σ_S (m3-r3, P0 r3 из R2-store, L23):** пороги строится с S-строк;
  если σ_L > σ_S — анти-консервативно для обоих контрастов. Замерено:
  across-doc SD-отношение SD(e_spec)/SD(e_null) = **0.756** (n2 cos_raw) /
  **1.220** (n2 norm_delta) / **1.023** (n16 cos_raw) / **1.470** (n16
  norm_delta) — не «≫»; для E_phr: ×1.22 — численно нематериально:
  инфляция добавляет к порогу срабатывания только ≈0.03 nat (≈0.11σ_S),
  M4-r5/§11. Чек — прокси (e_spec смешивает вариацию филлера): граница,
  не доказательство.
  **Пост-прогоновый прямой чек (m2', бесплатно):** на форвардах 2b
  `SD_docs(near_E_phr)/SD_docs(near_N_PHR)` (norm_delta@n2) и
  `SD_docs(near_REP)/SD_docs(near_N_perm)` (cos_raw@n16) — напрямую, не
  прокси. Если > 1.5 → тег `CALIBRATION_WARN`: вердикт читается с
  оговоркой «порог анти-консервативен» (§17). **Конфаунд (F4-r6):**
  при fires отношение включает вариацию реального эффекта
  (гетерогенность по докам) — это не несовпадение шумовых шкал;
  `CALIBRATION_WARN` в этой ветке не читается как анти-консервативность
  порога, чистая интерпретация — только при нулевом вердикте.
  Незагрязнённый якорь: σ-отношение на паре `(N_PHR, N_perm)` (обе
  стороны — нули, бесплатно на тех же форвардах).
- **INT:** нуля нет; report-only + тег `INTERACT_SIGNIFICANT` (значимый
  INT на первичной дозе = контентный эффект row-type-зависим: D_L ≠ D_S;
  направление — по signed near в claim).
- **PHR_main = D_L + D_S → диагностика** (M1: включает bag-of-words
  режим — «контент в среднем по строкам», не H_phr).
- **N_content = S1 − S2 = PHR_main − INT (тождество) → legacy/

## 8. Разрешение δ (C1: привязка к наблюдаемой; M4: проверенный пул)

**Каждый порог — только на наблюдаемой своего контраста:**

```
E_phr: near_phr_i,n  = p90 |N_PHR_i,n(d)| (norm_delta),   d ∈ [0,15]
       far_phr_i,n   = mean |N_PHR_i,n(d)| (norm_delta),  d ∈ [48,63]
       δ_PHR    = 95th pct {near_phr_i,n}   (28 значений: 14 док × 2 дозы)
       δ_far_PHR = 95th pct {far_phr_i,n}

REP:   near_rep_i,n  = p90 |N_perm_i,n(d)| (cos_raw),     d ∈ [0,15]
       far_rep_i,n   = mean |N_perm_i,n(d)| (cos_raw),    d ∈ [48,63]
       δ_REP    = 95th pct {near_rep_i,n}   (28 значений)
       δ_far_REP = 95th pct {far_rep_i,n}

Смешанные наблюдаемые (статистика на norm_delta, δ на cos_raw или
наоборот) = жёсткий флиппер (P0 r2: near 0.8681 vs δ 0.1526, ×5.7;
под H0 S_phr срабатывает всегда) — запрещено.

Per-layer (F3): δ_PHR(L), δ_far_PHR(L) — те же формулы на norm_delta,
per L ∈ {6,12,18,19,23}; δ_REP(L), δ_far_REP(L) — на cos_raw.
Вердиктные тесты — только на L23 (primary); δ(L) остальных слоёв —
для слойного тега (§11.6).
```

- **Пулинг по дозам — проверенное допущение на ОБЕИХ наблюдаемых**
  (M4, P0 r3 из R2-store, L23):

  | наблюдаемая | p95 n2 | p95 n16 | ratio | pooled(28) | vs per-dose |
  |---|---|---|---|---|---|
  | cos_raw | 0.1526 | 0.1328 | 1.149 (n2 ↑) | 0.1533 | +0.5% / −13.3% |
  | norm_delta | 1.1590 | 1.5668 | **1.352** (n16 ↑) | 1.4897 | **+28.5% / −4.9%** |

  Оба ratio < 1.5 → пул остаётся; направление разное (cos_raw: n2 выше;
  norm_delta: n16 выше); pooled ≥ min(per-dose) всегда.
- Вычисляются 2b-машиной **из новых форвардов** (S1, S1', S2, S2') —
  единый пайплайн. `δ_min` неконечен/нулевой → NOT_RESOLVED (гейт S_null).
- **Integrity-якорь (fail-loud, m2-r2):** пересчёт legacy-δ (e_null,
  cos_raw) из R2-store — **по ВСЕМ 4 дозам, R2-пайплайн verbatim**
  (14 док × 4 = 56 значений), **независимо от дозового списка 2b** [2,16]
  (P0: по 2 дозам = 0.1533/0.0306 — ложный STOP-ловушка). Ожидаемо
  bit-идентично R2: **0.1480 / 0.0332**; отклонение > 1e-6 → стоп
  (store повреждён/подменён). Это проверка пайплайна, **не** порог
  вердикта.
- **δ — хвост, не квантиль среднего** (R2 D4, повторено для новых нулей,
  m6-r5): δ_PHR/δ_REP — 95-й перцентиль 28 per-doc значений, не квантиль
  среднего по докам — порог консервативен по построению (мощность —
  §11).

## 9. Доза

- **E_phr (H_phr) primary: `n = 2`** (пререг). Обоснование (механика
  насыщения, зафиксирована до прогона): I_loop1(n) = 59.2/61.7/63.8/64.6
  (n=2/4/8/16, док-медианы; +9% — `DOSE_FLAT` R2); кривая обучения из
  R2-store: r1 CE 4.66 → r2 0.39 → r3 0.13 nat/tok (n16) — фраза выучена
  ко 2–3 повтору → на n=16 контентное различие L1/L2 минимально; на n=2 —
  максимально.
- **REP primary: `n = 16`** (пререг) — максимальная доза периодичности
  (16 повторов).
- Обе дозы, оба контраста — перекрёстная диагностика (2×2 дозовая таблица
  в claim). n=4/n=8 не гоняются (R2-плато).
- **I_loop2(n) = Σ CE по токенам блока L2** (новое; I_loop1 — из
  R2-store, заморожен).
- **Дозовый тег L2 — 2-дозное правило (переписано под {2,16}, F2; ссылка
  «как R2 §9» убрана — её формула требует n=8, который в 2b не
  гоняется; `DOSE_SATURATING` удалён — недостижим без средней дозы):**
  `I16/I2 ≤ 2` → `DOSE_FLAT` (насытилось на [2,16]);
  `I16/I2 > 2` → `DOSE_MONOTONIC` (ещё растёт на [2,16]; различить
  «насыщается посередине» от «растёт» с двумя дозами нельзя);
  не-finite или ≤ 0 → `DOSE_NOT_RESOLVED` (isfinite-гейт, r2d-2.3).
- **Learnability-parity (диагностика; тег на ОБЕИХ первичных дозах, F1 —
  оговорка на дозе своего контраста, то же правило, что M3):**
  `ratio_n = block-CE_L2(n) / block-CE_L1(n)` (док-медианы), n ∈ {2,16} —
  **ratio отчитывается непрерывно в claim** (обе дозы).
  - `LEARN_ASYMM_N16`: `ratio_16 ∉ (1/3, 3)` — порог калиброван на n=16
    (обе фразы у пола; пререг-ожидание ratio ~ 0.6–2.6 — по ожиданию тег
    не срабатывает, ветка объявлена, не форсирована).
  - `LEARN_ASYMM_N2`: `ratio_2 ∉ (1/3, 3)` — **некалиброванная эвристика**
    (3× калиброван на n=16; на n=2 L1(2) = 3.29 и ни одна фраза не
    выучена — различие обучаемости на этой дозе реально может быть
    большим: именно там конфаунд E_phr).
  E_phr читается с оговоркой по `LEARN_ASYMM_N2` (его доза); контекст
  REP — по `LEARN_ASYMM_N16`.

   И (wiki_0, n=16, `loop`) — сравниваются со стором (`store["loop"]`).
   Формулировка гейта (F1-r6): свежий ряд считается **тем же
   `cond_series`, что R2 (verbatim, вкл. `round(float(x), 6)` для
   ce/cos_raw/cos_state/norm_delta)**; гейт = **bit-identity округлённых
   значений** на всём сохранённом ряду (домен сравнения запинен: все
   позиции p = 0..T'−2, 5 слоёв, cos_raw + cos_state + norm_delta).
   Относительное 1e-6 — **только диагностика**, с абсолютным полом 5e-7
   (полпоследнего разряда): реальное расхождение пути в cos-единицах
   1e-6…1e-5 — ловится; само округление (≤5e-7 абсолюта) — по
   построению не ловится. Это единственный чек, ловящий расхождение
   численного пути: `E_phr = L1−L2` вычитает **сохранённый** L1 из
   **свежего** L2, а нуль `N_PHR = S1'−S2'` (оба свежие) этот сдвиг не
   содержит; n=16 покрывает `REP@n16` (тоже вычитает сохранённый L1;
   путь dose-зависим: 274 vs 400 токенов, F2-r6). Существующий
   смоук-чек e_spec1 — чистая дисковая переагрегация (оба слагаемых из
   стора) — по построению НЕ ловит. Провал → **fallback (задекларирован

   требование пересесть на свежий путь): перегон ВСЕХ 4 R2-условий
   свежими (ctrl, L1, fillerA, fillerB: 4×14×2 = +112 фд, итого 252 ≈
   60 мин) и 2b — только на свежих значениях; **смешение численных
   путей запрещено**. В fallback-режиме legacy-якорь 0.1480/0.0332
   (4 дозы) остаётся дисковой store-integrity-проверкой из стора,
   legacy-диагностика отчитывается из стора с меткой «store». Факт
   fallback'а — в манифест; стоп — только если сам fallback провалился.
3. **S_stimulus:** phrase_token_check (оба), shuffle_multiset_check

```
   S_rep := CI_low(near_REP(n=16), cos_raw)       > δ_REP

   ОБА контраста протестированы (гейты прошли на обеих дозах):
     S_phr ∧ S_rep → BOTH_SPECIFIC (+substructure каждого)
     S_phr only    → PHRASE_SPECIFIC (+substructure)
     S_rep only    → REPETITION_SPECIFIC (+substructure)
     neither       → NO_2B_SPECIFIC_EFFECT
   ОДНА доза с провалом гейта (M2 — отсутствие измерения ≠
   свидетельство отсутствия):
     решённый fires   → <CHANNEL>_SPECIFIC + GATE_N2/N16
                        (чтение не покрывает нерешённый канал)
     решённый нулевой → NOT_RESOLVED + GATE_N2/N16
   (substructure _AMBIGUOUS по единственному значимому → NOT_RESOLVED;
   BOTH_SPECIFIC + _AMBIGUOUS по одному каналу → вердикт BOTH_SPECIFIC
   сохраняется, _AMBIGUOUS остаётся тегом этого канала — m5')
4. Substructure (для каждого значимого C, его первичная доза, primary
   наблюдаемая):
   CI_low(C_near − C_far) > 0  И  CI_high(C_far) ≤ δ_far(C) → _DECAYS
   CI_low(C_far) > δ_far(C)                                  → _PERSISTS
   иначе                                                     → _AMBIGUOUS
5. INT (отчёт, не вердикт; первичная доза n=2, norm_delta):
   near_INT(n=2) + signed near (направление чтения) + CI — **всегда
   непрерывно с CI**. Тег INTERACT_SIGNIFICANT при
   CI_low(near_INT(n=2), norm_delta) > δ_PHR — **объявленная эвристика
   без калибровки (F5), не тест:** калиброванного нуля у INT в дизайне
   нет (лупы детерминированы — draw'а нет); INT Var-сматчен с N_perm
   (Var ≈ σ²), а не с N_PHR (2σ²) → порог δ_PHR на √2 ≈ 1.41× шире по
   дисперсии: консервативно (type-I < 0.025), но «контроль при 0.025» —
   нет. (δ_REP брать нельзя — C1: cos_raw.)
   Диагностика: near_INT(n=16) (обе наблюдаемые).
6. + слойный тег (M3): **per-contrast на СВОЙ первичной дозе**
   (E_phr@n2, REP@n16); «значим» = near_C_L > δ_L(C) (порог своего
   контраста на своём слое); объединение {E_phr, REP} — только если оба
   значимы **на L23** на своей первичной дозе (m7-r5: «значимы где»
   запинено — по L23, как вердиктная клетка; правила TZ R2 §10).
   **Тег — по точечной оценке (без CI) — наследие R2; в отличие от
   CI-правила вердикта.**
7. + дозовый тег L2, + LEARN_ASYMM_N2/_N16 (если) + CALIBRATION_WARN (если,
   m2'), + G_inside_legacy (отчёт).
```

**Вердиктный словарь** — как v1.2 (`NO_2B_SPECIFIC_EFFECT` /
`PHRASE_SPECIFIC` / `REPETITION_SPECIFIC` / `BOTH_SPECIFIC` /
`INSENSITIVE_CELL` / `NOT_RESOLVED`) + `_DECAYS`/`_PERSISTS`/`_AMBIGUOUS` +
теги `INTERACT_SIGNIFICANT` (эвристика без калибровки, F5),
`LEARN_ASYMM_N2` / `LEARN_ASYMM_N16`, `CALIBRATION_WARN` (m2'),
`GATE_N2`, `GATE_N16`, `LOW_MARGIN` (M2-r5).
Чтения — §17.

**Множественность (числом, r2/r3):** 2 односторонних теста, α ≈ 0.025 на
тест (CI_low = 2.5-й перцентиль doc-bootstrap; тест «CI_low > δ»
калиброван под H0 на ≈0.025). FWER(≥1 ложный) = 1 − 0.975² ≈ **4.94%**
при независимости; тесты не независимы (общие доки/стимулы) → фактический
FWER ∈ [2.5%, 4.9%] → семейный уровень ≈ 5% — **поправка не нужна**,
поверхность = ровно 2 зафиксированных пре-регом теста.

**Мощность (пререг-декларация, M4-r5/r6):** тест сравнивает **нижнюю
границу** (CI_low, 2.5-й перцентиль doc-bootstrap) **среднего по 14
докам** с **верхним хвостом 28 per-doc** значений нуля — очень
консервативно. В нормальной аппроксимации срабатывание: `mean_14
(near_C) > δ + 1.96·σ_L/√14`. MDE (P0: μ_null = 0.7538, p95 n2 =
1.1590, σ_S ≈ 0.246, σ_L ≈ 1.22σ_S; SE = 0.0802):
- против **пре-рег pooled** δ (P0: 1.4897): MDE ≈ 1.4897 + 0.157 ≈
  **1.65** (первично — это порог, по которому читается вердикт);
- per-dose-версия (против p95 n2 = 1.1590): ≈ **1.32**.
**MDE — оценка на прокси-σ** (σ_L ≈ 1.22σ_S из SD(e_spec)/SD(e_null):
loop−filler, а E_phr — loop−loop; σ(loop−loop) ≠ σ(loop−filler)):
фактический σ_L даёт пост-прогоновый чек, MDE пересчитывается как
отчёт, **не как порог**.
Четыре клетки (F5-r6; порог срабатывания = δ + 1.96·SE):

| объект | pooled δ (порог 1.647) | per-dose δ (порог 1.316) |
|---|---|---|
| type-I (mean = μ_null = 0.7538) | z = 11.1 → ≈ 4·10⁻²⁹ | z = 7.0 → ≈ 1.2·10⁻¹² |
| power при effect = e_spec-прокси 0.8681 | z = 9.7 → ≈ 10⁻²² | z = 5.6 → ≈ 1.4·10⁻⁸ |

(10⁻¹² из v1.5 была type-I per-dose, перенесённой с меткой «эффект
масштаба e_spec» — исправлено, m4/G14.) При z ≈ 5.6…11 и n = 14
доках нормальное приближение в таком хвосте **не идентифицируемо**
(doc-bootstrap CI): рабочая формулировка — **рабочий уровень type-I
много ниже 0.025; точное значение по 14-доковому бутстрапу не
оценивается; заявленный α = 0.025 — верхняя граница** (не рабочий
уровень). Два разных объекта (r6-reconcile): **инкремент** от σ-
инфляции ≈ 0.028 nat (≈ 0.11σ_S — вносит в порог срабатывания) и
**расстояние** от μ_null до порога срабатывания = 7.0 SE (per-dose)
/ 11.1 SE (pooled) — оба верны, не конфликт.
**Задекларировано: ожидаемый исход при умеренных эффектах —
`NO_2B_SPECIFIC_EFFECT`; это не свидетельство отсутствия** (r2d-1.5,
теперь — числом).

**Прочие оговорки (declare):** σ_L/σ_S (§7.2, P0-числа: max ×1.47, для
E_phr ×1.22 — bounded; инфляция ×1.22 добавляет к порогу срабатывания
только ≈0.03 nat (≈0.11σ_S) — численно нематериально, M4-r5);
v1.0-provenance:
абсолютные пороги G_inside_legacy (loop < 1.0, filler ≥ 2.0)

## 17. Пререг-чтения исходов

- `NO_2B_SPECIFIC_EFFECT` — R2-`NO_LOOP` усиливается: **оба канала
  протестированы** (M2): ни контент повторённой фразы (на n=2, где
  контент жив), ни периодичность (на n=16) не создают пост-эффекта сверх
  shuffled-нулей (на пре-рег-разрешении; отсутствие не доказано —
  конвенция r2d-1.5).
- `PHRASE_SPECIFIC` — канал: **контентное различие повторённой фразы
  (L1 vs L2, периодические строки) превышает шкалу контентного различия
  shuffled-строк — запоминание именно этой фразы** (M1: bag-of-words
  режим исключён — там шкалы совпадают, синтетика 7). Тег
  `INTERACT_SIGNIFICANT` (INT на n=2 значим) уточняет: эффект
  repetition-specific (D_L ≫ D_S). Без тега (INT ≈ 0) — чтение «контент
  (bag) эффект, порядок не установлен» (residual type-I, α ≈ 0.025).
  Согласуется с ответом архитектора «после ~2 повторов фраза выучена»
  (block CE 0.38–0.51) — CE внутри блока ≠ пост-эффект; теперь разделены
  (и меряются на дозе, где контент ещё жив).
- `REPETITION_SPECIFIC` — канал: **упорядоченность/периодичность** при
  том же мультисете (m3-r2: не «повторение как таковое»).
- `BOTH_SPECIFIC` — два канала; substructure каждого — в claim.
- `INTERACT_SIGNIFICANT` — контентный эффект row-type-зависим (D_L ≠ D_S;
  направление — по signed near в claim): вердикт читается с этой
  оговоркой. **Тег — эвристика без калибровки (F5):** консервативная
  (порог на √2 шире по дисперсии, калиброванного нуля нет), не тест —
  INT читается всегда вместе со своим непрерывным значением + CI.
- `NOT_RESOLVED + GATE_N2/N16` — канал не протестирован (гейт провален);
  отсутствие измерения — не свидетельство отсутствия (M2).
- `LEARN_ASYMM_N2` — phrase2 обучается иначе phrase1 **на n=2** (доза
  E_phr; ratio_2 вне (1/3, 3); некалиброванная эвристика, F1): E_phr
  читается с оговоркой «содержимое + обучаемость».
- `LEARN_ASYMM_N16` — то же на n=16 (калиброванный порог): контекст REP
  читается с оговоркой «порядок + обучаемость».
- `CALIBRATION_WARN` — пост-прогоновый прямой σ_L/σ_S > 1.5 (m2'): порог
  анти-консервативен — вердикт читается с этой оговоркой.
- `LOW_MARGIN` — смоук: 2-доковый `median(min(m₁,m₂))` на n=2 < 0.3
  (решение ДО main, M2-r5): порог маржи не блокирует — вердикт читается
  с оговоркой «маржа G_inside_rep мала — премисса „строка представлена
  как фраза“ слаба». **Остаточный риск (F6-r6):** 2-доковая медиана —
  шумная оценка 14-доковой; исход «смок ≥ 0.3, main < 0.3 → GATE_N2 →
  NOT_RESOLVED (при нулевом REP)» задекларирован как пре-рег-исход;
  манифест пишет и смок-значение, и реализованную 14-доковую медиану.

## 18. Границы (не делать)

- R2-store — **read-only** (sha зафиксирован §10); R2-вердикт/числа не
  пересчитываются; R2-документы — история, не переписывать.
- Новые форварды — **только L2/S1/S2/S1'/S2' (140), n ∈ {2,16}**;
  ctrl/loop1/fillerA/fillerB не перегоняются.
- Пул не пересобирается (14 доков R2, тот же filler_map).
- Фразы не меняются (пре-рег §3); сид-формула — **единый литерал, §3** —
  не меняется (дублировать литерал в §18/§19 не будем — m1-r5: искажённые
  переписи дали бы другие перестановки); автосидов нет (провал
  S_shuffle bug-guard — fail-loud, не пере-сид).
- **Слияние с AT8_3 — не в этом пре-реге.** 8_3 review r3
  (`docs/AT8_3_review.md`, патч-лист 1–8): 5 вердикт-критических пунктов
  (1–5) открыты в TZ v1.2 (H_eval=97; знаменатель/LOW_POWER; CI-таблица/
  гейт; строгий >0.5 или блокирующий WIDE_CI; доз-зависимый гейт
  филлеров) — слияние унаследовало бы их. Смета (r2 §1(d), r3 m6,
  верифицировано по `docs/AT8_3_TZ.md`: 14 условий/док × 16 доков):
  8_3 = **224**; 2b на пуле 8_3 с S2' = 5 × 2 × 16 = **160**; слияние =
  **384**; раздельно = 224 + 140 = **364** (112 — устаревшее число до
  S2') → **слияние дороже** (384 > 364). Объединённый пре-рег — после
  закрытия 8_3 (архитектор предлагает расписать: условия, контрасты с
  нулями, дерево E_phr/REP/INT + локализация 8_3, store с h-векторами,
  смета). До утверждения объединённого пре-рега standalone-прогон 2b может
  быть запущен отдельно (140 фд ≈ 35–40 мин); если объединённый пре-рег
  утверждён до запуска 2b — standalone пропускается (явное решение в PLAN).
