## Контекст, достаточный для суждения (не перепроверять)

Модель форка llama.cpp: при `temperature=0` эмитированный токен в 16/6144 позиций НЕ
совпадает с заявленной вершиной отчёта `top_logprobs`. Две гипотезы:
**M1** — отчётные логи привязаны к чужой копии (внутренний аргмакс = эмитированный);
**M2** — отчёт верен, жадная ступень не схлопывает дистрибуцию.
Проба: `logit_bias = -100` на эмитированном токене B по адресу флипа, ридаут —
ИДЕНТИЧНОСТЬ нового эмитированного токена. `logit_bias` пишется в
`params.sampling.logit_bias` (`server-schema.cpp:430-434`), то есть ban убивает и
внутренний аргмакс. Адрес пробы `Q2 w4 k=70`: A=318 (`lp=-0.477`), B=310 (`lp=-1.115`).
