## B1 — PRINATO

- Код `AT2b.py:495`: `r2rows.append(1.0 - float((pc ** 2).sum()) /
  float((yc ** 2).sum()))` — это `1 − ‖pred‖²/‖yc‖²`, а не
  `1 − ‖yc−pred‖²/‖yc‖²`.
- Meta-декларация `AT2b.py:858`: `"R2_c = 1 - SSE_c/TSS_c per (doc,k)"` —
  **формула в мете и в коде разные** (как указано в ревью).
- Диагностика повторяет ту же ошибку: `AT2b_diag_c2c1.py:387`
  (`r2rows_cd.append(1.0 - float((pc_cd ** 2).sum()) / ...)`).
- Арифметика ревьюера верна: «R²» 0.6656–0.7750 ⇒ ‖pred‖/‖yc‖ =
  0.578–0.474; при ρ=0 корректное R² = −0.225…−0.334.
- **Влияние**: R² НЕ входит в дерево вердикта AT2b (дерево: control —
  cos-CI; (a) — CI+median; (b) — median; (c) — CI+k=1 median; (d) — иначе;
  проверено `AT2b.py:702–760`). Вердикт `SUBSPACE_CONTROL_FAIL` арифметически
  стоит на cos/CI, а не на R². **Отзывается заявка** «центрированная метрика
  работает (R²_c > 0)» (`docs/AT2b_results.md:68,99`) — корректное R² не
  измерялось ни в прогоне, ни в диагностике.

## B1b — PRINATO

- `AT2b.py:543–545`: `tss = …; r2c = 1.0 - tss / tss; if not (tss > 0.0 and
  abs(r2c) < 1e-12)` — `1 − tss/tss ≡ 0`; предиктор не запускается. Гейт
  фактически = «цель неконстантна» (tss > 0).
- Наследовано в AT2c (`AT2c.py:637–641` — та же строка `r2c = 1.0 - tss/tss`),
  НО в AT2c реальный R²-floor-чек — **S6c** (designed-сценарий r6/r7):
  centered-цель + cos-вклад intercept константного предиктора
  (`dcos_wmean`, `AT2c.py:594–612`) — вычисляется, не тавтология.
- **Влияние**: «floor в нуле» — определение, не измерение. В AT2c это
  закрыто S6c (r3/r4 — пройден, артефакт r4).

## B2 — PRINATO (количественно подтверждено диагностикой)

- Код `AT2b.py:483`: `yf = np.vstack([y_all[d2] for d2 != d])` — сырые
  логиты; X центрирован (`:454`). Intercept впитывает ȳ_f; pc = WX +
  c(d), c(d) = ȳ_f − ȳ(d) — общий для всех армов.
- Количественно (артефакт диагностики `results/AT2b_diag/AT2b_diag.json`,
  `c2.offset_scale`): k=0: ‖c‖_med = 16.97, ‖c‖_max = 27.96,
  yc_perpos_med = 36.19 → **ratio_med = 0.47, ratio_max = 0.77** (k=1/2 —
  то же, 0.47/0.78). Смещение соизмеримо с целью — cos и «R²» на k=0
  искажены систематически.
- **Но не единственный механизм падения контроля**: `c2.control_cd`
  (центрированная цель, тот же код): L6 CI [−0.0356, +0.0208], L12 [−0.0085,
  +0.0242] — **CI⊃0 и после центрирования**. Т.е. per-t нестационарность
  (C1) реальна и мотивирует редизайн в AT2c (стационарный Jagg/Gagg-базис).
- **Исправлено в AT2c**: `AT2c.py:577,583` — `yc_all = y_all − y_all.mean(1,
  keepdims=True)`, `yf = vstack(yc_all[d2])` (CENTERED-обучающая цель, C2-фикс,
  пре-рег AT2c §2.2).

## B3 — ЧАСТИЧНО (баг реален; «один механизм» — отвергнуто)

**Баг подтверждён** (`AT2b.py:372`: `weak_i = np.argsort(lam)[:min(r_final,
n_nz)]` + `_lift_arr:161–169` — нулевые колонки → QR-дополнение).

**Измерено** (disk-only, скрипт `/tmp/at2b_b3check.py`, все 4×4096 клеток,
r_final = 7, порог 1e-12 — дословно код):

| L | n_nz min/med | n_dead_weak > 0 (frac клеток) | is_axes (все 7 dead → коорн. оси) |
|---|---|---|---|
| 6 | 85/128 | **2.4%** (98 клеток) | 0.29% |
| 12 | 100/128 | 1.5% | 0.15% |
| 18 | 106/128 | 1.1% | 0.15% |
| 22 | 102/128 | 1.0% | 0.15% |

- E_real/E_spec (weak и top): медиана 1.0000 — lift-алгебра для живых
  колонок корректна.
- Jfrac(weak QR) = ‖JV‖/‖J‖: медиана 0.062–0.154, max 0.23 — weak несёт
  малую, но ненулевую J-энергию (настоящие слабые направления).
- E_spec(buggy selection)/E_spec(fixed `nz[:7]`): медиана 1.000000 —
  в живых клетках отбор совпадает.

**Возражение против «одного механизма»**: контаминация — хвост ~1–2% клеток
(d,t). L6-инверсия контроля (CI [−0.0131, −0.0004] по среднему 32 дока × 128 t)
и Haar-аномалия (фиксированный базис ловит «текущую видимость», L23 k=0
haar 0.28) — это системные эффекты (B2-смещение ratio 0.47 на ВСЕХ клетках +
нестационарность), которые хвост из 98 клеток не способен выдать. Haar-
аномалия — свойство фиксированного базиса при L23-readout, не weak-хвост.

**Исправлено в AT2c (основной арм)**: `AT2c.py:453,456` —
`nz = np.where(lam_np > 1e-12 * lammax)[0]` (относительный порог) и
`weak_idx = nz[:min(r_final, len(nz))]` — **слабейшие среди ненулевых**.
Старый from-AT2b отбор остался только в `c1b`-блоке (`AT2c.py:484–489`) —
report-only, в вердикт не входит (проверено: дерево использует только
`cos_doc`/`agg`/`boot`).

## B5 — PRINATO (мягко)

- `AT2b.py:454` (центрирование по всем 128) → `:481` (`X = proj[...][k:]`) —
  для k>0 среднее X по окну обучения ≠ 0; y центрирован по своему окну
  128−k. Подтверждено.
- Мягкость: sдвиг **общий для всех армов** при данном (L,d,k) (proj
  арм-зависим, но центрировочный сдвиг одного порядка k/128 и не меняет
  межармного сравнения существенно); intercept частично поглощает; **k=0
  точен** (контроль не затронут).
- **Наследовано в AT2c** (`AT2c.py:507,581` — та же конструкция). Для AT2c:
  control — k=0 (точный); k≥1 — top-доминирование велико (weighted CI
  0.40–0.54 на всех (L,k)), сдвиг порядка k/128 его не переворачивает.
  Фикс для будущих экспериментов: центрировать X ПОСЛЕ среза `[k:]`.

## Последиствия для цепочки (решения)

1. **AT2b (T2.1b)**: **перепуск не нужен** — AT2b уже вытеснен AT2c

   `SUBSPACE_CONTROL_FAIL` остаётся арифметически (cos/CI); **отзываются**

   Субстантивный вывод (per-t базисы нестационарны; на L6/L12 top≈weak)
   поддержан control_cd (центрированная цель: CI⊃0 на L6/L12).
