# Ответ: рецептура линеаризации, шестой канал, и два условия валидности

**Коротко:** рецептура есть — это **линеаризация** `exp(M) Σ_{t+1} exp(−N) − Σ_t` первого порядка по `M, N`. `E_resid` — норма **разности матриц**, а не остаток от conservation. **Но ТЗ само по себе неполно:** в нём пропущен **шестой канал** `E_off_manifold` (часть `ΔJ` вне `U_t ⊗ V_t`), без которого при `r = 16 ≪ D = 1024` сумма пяти каналов к `‖ΔJ‖²` не имеет отношения. И есть **два условия валидности**, оба нарушены на L6–L22 — но по разным причинам. На L23 валидно только первое. Ниже — полная формулировка, готовая к вставке в ТЗ.

---

## 1. Что именно линеаризуется

Дано: `J_t = U_t Σ_t V_tᵀ`, `J_{t+1} = U_{t+1} Σ_{t+1} V_{t+1}ᵀ` (rank-`r` SVD, `U ∈ St(K,r)`, `V ∈ St(D,r)`, `Σ ∈ R^{r×r}_{+}`, `r = 16`).

**Проекция:** `ΔJ_proj = U_t U_tᵀ · ΔJ · V_t V_tᵀ`, где `ΔJ = J_{t+1} − J_t`. Ортогональна дополнению (проверяется идемпотентностью `P_U = U_t U_tᵀ`, `P_V = V_t V_tᵀ`).

**Точное тождество** (без линеаризации):

$$U_t^T \Delta J\, V_t = Q_U \Sigma_{t+1} Q_V^T - \Sigma_t, \qquad Q_U = U_t^T U_{t+1},\; Q_V = V_t^T V_{t+1}.$$

(Здесь `Q_U`, `Q_V` — **не** полярные факторы, а сами произведения. Полярные факторы — следующие.)

**Транспорт:** `R_U = polar(Q_U) ∈ O(r)`, `R_V = polar(Q_V) ∈ O(r)`. При `align_signs_and_columns` (§I.8 ТЗ) `R_U ≈ I`, `R_V ≈ I`.

**Логарифмы:** `M = log R_U`, `N = log R_V`, главная ветвь (`θ ∈ (−π, π)`; антисимметричны в блоковой форме).

**Линеаризация (та самая «рецептура»):**

$$\Delta J_{\text{lin}} := \Delta\Sigma + M\bar\Sigma - \bar\Sigma N, \qquad \bar\Sigma = \tfrac{1}{2}(\Sigma_t + \Sigma_{t+1}),\;\; \Delta\Sigma = \Sigma_{t+1} - \Sigma_t.$$

Это первые два члена Тейлора для `exp(M) Σ_{t+1} exp(−N) − Σ_t` по `M, N` (с точностью до `O(M², N², MN)` по `Σ̄`); эквивалентно — поскольку `M, N` антисимметричны — форма `ΔΣ + M Σ̄ − Σ̄ N` точна с точностью до `O(‖M‖² · ‖Σ‖) + O(‖N‖² · ‖Σ‖) + O(‖M‖ ‖N‖ ‖Σ‖)`.

**Пять каналов** — компоненты `‖ΔJ_lin‖²_F`:

$$E_{\text{radial}} = \|\Delta\Sigma\|_F^2,\quad E_{\text{right}} = \|\bar\Sigma N\|_F^2,\quad E_{\text{left}} = \|M\bar\Sigma\|_F^2,\quad E_{\text{cross}} = 2\,\mathrm{tr}(\bar\Sigma M \bar\Sigma N).$$

Знак `E_cross`: `⟨M Σ̄, Σ̄ N⟩ = tr(Σ̄ Mᵀ Σ̄ N) = −tr(Σ̄ M Σ̄ N)` (M антисимметрична), поэтому `‖M Σ̄ − Σ̄ N‖²_F = E_left + E_right − 2⟨M Σ̄, Σ̄ N⟩ = E_left + E_right + E_cross` — с `E_cross = 2 tr(Σ̄ M Σ̄ N)`. **Знаковый.**

`‖ΔJ_lin‖²_F = E_radial + E_right + E_left + E_cross + O(ε³)`, где `ε³`-член — `2⟨ΔΣ, M Σ̄⟩ − 2⟨ΔΣ, Σ̄ N⟩` (смешанный angular-radial, произведение двух малых), поглощается в residual.

## 2. `E_resid` — независимое определение

**Правильная формула:**

$$\boxed{\,E_{\text{resid}} := \|U_t^T \Delta J\, V_t - \Delta J_{\text{lin}}\|_F^2\,}$$

Разность **матриц**, не норм. Не может быть тавтологией: если `U_t^T ΔJ V_t ≠ ΔJ_lin`, разность ненулевая.

**Что запрещено:** `E_resid := ‖ΔJ_proj‖² − (E_radial + E_right + E_left + E_cross)` — это **conservation-остаток**, тождественно замыкающий сумму пяти каналов на `‖ΔJ_proj‖²` по определению. Такой `E_resid` тавтологичен и не измеряет качество линеаризации. **ТЗ запрещает** именно эту форму (см. §III.8).

**Ожидаемый масштаб:** `E_resid / ‖ΔJ_proj‖² ~ O(‖M‖², ‖N‖²) ~ ε²`. При `Δ_SVD = 0.27` рад (L23): ~ 7 %. При `Δ_SVD = 1.4–1.5` рад (L6–L22): `Q_U` не близка к I, `log Q_U` не определён в главной ветви (см. §5), `E_resid ~ ‖ΔJ_proj‖²`.

## 3. `E_off_manifold` — шестой канал, которого нет в ТЗ

**Это главный пропуск.** Пять каналов покрывают `‖ΔJ_proj‖²`, а не `‖ΔJ‖²`. Проекция отбрасывает компоненту `ΔJ` вне `U_t ⊗ V_t`, которая при `r = 16 ≪ D = 1024` **не мала** и не является «шумом линеаризации».

**Определение:**

$$\boxed{\,E_{\text{off\_manifold}} := \|\Delta J - U_t U_t^T\, \Delta J\, V_t V_t^T\|_F^2\,}$$

Независимо, из разности. Ортогональна `ΔJ_proj` (проверяется: `⟨P_U ΔJ P_V, ΔJ − P_U ΔJ P_V⟩_F = 0` для проекторов `P_U, P_V`).

**Почему она не мала (математически):**

`J_{t+1} = (U_t Q_U + δ_U) Σ_{t+1} (V_t Q_V + δ_V)ᵀ`, где `δ_U ∈ St(K,r)` ⊥ `U_t`, `δ_V ∈ St(D,r)` ⊥ `V_t`. Отсюда:

$$U_t U_t^T J_{t+1} V_t V_t^T = U_t Q_U \Sigma_{t+1} Q_V^T V_t^T, \quad \Delta J_{\text{proj}} = U_t\,(Q_U\Sigma_{t+1}Q_V^T - \Sigma_t)\,V_t^T - \delta\text{-terms перенесены}$$

Остальные три члена `ΔJ` (содержащие `δ_U`, `δ_V`, `δ_U Σ δ_V`) — это `ΔJ_perp`, и их норма:

$$\|J_{t+1}\|_F^2 \approx \|\Sigma_{t+1}\|_F^2 \cdot (1 - \|P_{\text{proj}} J_{t+1}\|_F^2 / \|J_{t+1}\|_F^2)$$

При `Δ_SVD ≈ π/2` (L6–L22): `P_{U_t} J_{t+1} ≈ 0`, `E_off_manifold ≈ ‖J_{t+1}‖²_F ≈ ‖ΔJ‖²_F/2` (если `‖J_t‖ ≈ ‖J_{t+1}‖`). На **L23** (`Δ_SVD = 0.27`, `‖δ_U‖ ≈ sin 0.27 ≈ 0.27`): `E_off_manifold / ‖ΔJ‖²` ~ `0.07 / ε²` — тоже не пренебрежимо; ожидаю **10–30 %** (точная величина — первый результат прогона).

**Вывод для ТЗ:** формула «пять каналов» — неполна. Полная accounting — **шесть** каналов:

$$\boxed{\,\|\Delta J\|_F^2 = E_{\text{radial}} + E_{\text{right}} + E_{\text{left}} + E_{\text{cross}} + E_{\text{resid}} + E_{\text{off\_manifold}} + O(\varepsilon^3)\,}$$

где `O(ε³)` — сумма двух cross-членов: `2⟨ΔΣ, M Σ̄⟩ − 2⟨ΔΣ, Σ̄ N⟩` (angular-radial mixing) + `2⟨ΔJ_lin, R_lin⟩` (linearization-cross). Эта `O(ε³)` — **не** residual; она отчитывается отдельно как `eps3_correction` и в инварианте учитывается как погрешность, а не как «седьмой канал» (иначе — тавтология).

## 4. Полная accounting-формула и что проверять

**Инвариант (обновление записи `channels_sum` в реестре M0):**

| Величина | Источник | Масштаб |
|---|---|---|
| `E_radial, E_right, E_left, E_cross` | формулы §1 (из `ΔΣ, M, Σ̄, N`) | ~`ε² · ‖Σ‖²` |
| `E_resid` | `‖U_tᵀ ΔJ V_t − ΔJ_lin‖²_F` (независимо) | ~`ε² · ‖ΔJ_proj‖²` |
| `E_off_manifold` | `‖ΔJ − U_t U_tᵀ ΔJ V_t V_tᵀ‖²_F` (независимо) | ~`sin²(Δ_SVD) · ‖Σ‖²` |
| `eps3_correction` | `‖ΔJ‖² − Σ6` (диагностика, **не** канал) | ~`ε³ · ‖Σ‖²` |

**Assertion (невакуитетная форма):**

$$\left|\, \|\Delta J\|_F^2 - (E_{\text{radial}} + E_{\text{right}} + E_{\text{left}} + E_{\text{cross}} + E_{\text{resid}} + E_{\text{off\_manifold}}) \,\right| \le \varepsilon_{\text{tol}} \cdot \|\Delta J\|_F^2,$$

с `ε_tol ~ 10⁻²` (калибруется из `eps3_correction / ‖ΔJ‖²` на пилоте).

**Два независимых теста (не один!):**
1. **Качество линеаризации:** `E_resid / ‖ΔJ_proj‖² ≤ ε_resid_max` (порог `10⁻²` для валидных слоёв).
2. **Качество проекции:** `E_off_manifold / ‖ΔJ‖² ≤ ε_proj_max` (порог `0.5` для «проекция информативна», `0.1` для «проекция точна»).

Эти два теста **разные**: слой может иметь плохую проекцию (off-manifold велик) — и тогда 5-канальная декомпозиция бессмысленна, даже если `E_resid` мал.

## 5. Два условия валидности (оба нарушены на L6–L22)

### 5.1. Условие A: малость поворота (`Δ_SVD ≪ π/2`)

`log Q_U` определён в главной ветви (действительная антисимметричная матрица) только если все собственные значения `R_U` имеют вид `e^{iθ_j}`, `|θ_j| < π/2`. Иначе `log` даёт комплексные члены, `M` — недействительная матрица, линеаризация `exp(M) Σ exp(−N)` не восстанавливает исходное `Q_U Σ Q_Vᵀ`.

**Проверка:** измерить `Δ_SVD(t)` — главный угол между `U_t, U_{t+1}`. Порог: **`Δ_SVD < π/2 − δ`, `δ = 0.3` рад** (эмпирически). Флаг `linearization_valid = false` при нарушении.

**По E-28:** `Δ_SVD` для r=16 по слоям = `1.549 / 1.542 / 1.495 / 1.483 / 1.378 / 0.266` (L6/L12/L18/L19/L22/L23). Это **максимальный** главный угол. Порог `π/2 − 0.3 ≈ 1.27` рад. **Все слои кроме L23 его нарушают** (`1.378 на L22 > 1.27`). На L22 — на грани.

### 5.2. Условие B: невырожденность `σ` (или блока)

Даже если `Δ_SVD` мало, `log Q_U` однозначно определён только если внутри top-r блока `σ_i` отделены друг от друга. При `σ_i ≈ σ_j` поворот между собственными направлениями `i, j` **не определён однозначно** — любая ротация внутри вырожденного подпространства допустима, `M` меняется на произвольную антисимметричную матрицу внутри блока.

**Проверка:** `min_{i<j∈top-r} |σ_i² − σ_j²| / σ₁² > ε_degap` (порог `10⁻²`). Флаг `rotation_unique = false` при нарушении.

**По E-38c:** внутренние gaps top-r — **near_degeneracy на всех слоях** (`fraction_well_separated = 0`, `gap_min(L23) = 0.0092 < 0.01·σ₁²`). То есть **условие B нарушено на всех слоях, включая L23**.

**Следствие:** 5-канальная декомпозиция **технически вычислима везде** (где `log` определён), но **интерпретационно однозначна только для well-separated блока**. На наших данных нет слоя, где оба условия выполнены одновременно.

### 5.3. Что это значит для ТЗ и для paper

**Практическая формулировка:**

- **E-40.5 как «пять каналов»** даёт числа на всех слоях, где `linearization_valid` (только L23 по условию A). Но на L23 нарушено условие B — то есть **E_right, E_left, E_cross неоднозначны** внутри вырожденных блоков.
- **Однозначны всегда:** `E_radial`, `E_off_manifold`, `E_resid` — они не зависят от выбора базиса внутри вырожденного блока (`E_radial` — диагональная норма, `E_off_manifold` — норма разности проекторов, `E_resid` — норма разности матриц).
- **Рекомендуемое поведение:** в артефакте отчитывать **все шесть каналов**, но помечать `rotation_unique = false`, если условие B нарушено, и в этом случае **из пяти каналов оставить только E_radial** (плюс E_off_manifold, E_resid как всегда корректные); `E_right, E_left, E_cross` — в отдельный блок `unstable_rotation` артефакта.

Это перекликается с ошибкой `[M-4]` (E-38c): там формализм неприменим, здесь — каналы неоднозначны. Не блокирует запуск, но **E-40.5 в paper формулируется как диагностика, а не как декомпозиция**: «пять каналов» остаются как механизм численной проверки суммы, но интерпретация (кто доминирует) применима только к `E_radial` и `E_off_manifold`.

## 6. `r=1` контроль (обновление)

При `r=1`, **после `align_signs_and_columns`:** `Q_U ∈ {+1}` (sign фиксирован), `Q_V ∈ {+1}`, `M = N = 0`. Тогда:

$$E_{\text{right}} = E_{\text{left}} = E_{\text{cross}} = 0, \qquad E_{\text{radial}} = \|\Delta\Sigma\|_F^2, \qquad \Delta J_{\text{lin}} = \Delta\Sigma.$$

`E_resid = ‖U_tᵀ ΔJ V_t − ΔΣ‖²` — теперь это честная независимая проверка: для `r=1` при малой ротации должна быть ≈ 0. `E_off_manifold = ‖ΔJ − U_t U_tᵀ ΔJ V_t V_tᵀ‖²` — ненулевая, но на L23 мала.

**Без `align`:** `Q_U = −1`, `log Q_U` не определён (или `iπ`), кросс-член `2 tr(Σ̄ M Σ̄ N)` не ноль (если M, N мнимые — но тогда матрица недействительна). **Это и есть тест `align_signs_and_columns`: без него r=1 не работает.**

## 7. Обновление инварианта `channels_sum` в реестре M0

**Было (неверно):**

```
E_right + E_radial + E_left + E_cross + E_residual = ‖ΔJ‖²
```

Неверно потому, что (а) не покрывает `ΔJ_perp`, (б) `E_residual` в форме «conservation-остаток» тавтологичен.

**Стало:**

```
identity: sum(6 channels) + eps3_correction = ‖ΔJ‖²
modules: (kinetic,)
assert: |Σ6 − ‖ΔJ‖²| / ‖ΔJ‖² < ε_eps3
status: passing
note: |
  E_resid and E_off_manifold computed independently (норма разности),
  not by conservation. eps3_correction = ‖ΔJ‖² − Σ6 is a diagnostic,
  not a 7th channel. ε_eps3 calibrated from pilot (~1e-2).
```

Плюс два новых поля в артефакте:

```
E_radial, E_right, E_left, E_cross,    # 5 channels on ‖ΔJ_proj‖²
E_resid,                                # ‖U_tᵀ ΔJ V_t − ΔJ_lin‖²
E_off_manifold,                         # ‖ΔJ − U_t U_tᵀ ΔJ V_t V_tᵀ‖²
eps3_correction,                        # ‖ΔJ‖² − Σ6 (diagnostic)
flags: linearization_valid, rotation_unique, order_cross_U, order_cross_V
diag: max_principal_angle, ‖M‖_F, ‖N‖_F, min_sigma_gap_ratio
```

## 8. Сигнатура

```python
def kinetic_decomposition(J_t, J_t1, r=16,
                          eps_angle=0.3,        # порог для linearization_valid (рад)
                          eps_gap=1e-2):        # порог для rotation_unique
    """
    Возвращает dict:
      E_radial, E_right, E_left, E_cross,    # 5 channels (на ‖ΔJ_proj‖²)
      E_resid,                                # независимо, ‖U_tᵀ ΔJ V_t − ΔJ_lin‖²
      E_off_manifold,                         # независимо, ‖ΔJ − U_t U_tᵀ ΔJ V_t V_tᵀ‖²
      eps3_correction,                        # ‖ΔJ‖² − Σ6
      flags: linearization_valid, rotation_unique, order_cross_U, order_cross_V,
             unstable_transport
      diag: max_principal_angle, ‖M‖_F, ‖N‖_F, min_sigma_gap_ratio
    """
```

**Обязательное предусловие:** вызов `align_signs_and_columns` (§I.8 ТЗ) на `(U_t, U_t1)` и `(V_t, V_t1)` до `polar` / `log`. Без него `M, N` не определены (или комплексные).

**Обязательные проверки перед отчётом каналов:**
- `linearization_valid = (max_principal_angle < π/2 − eps_angle)`;
- `rotation_unique = (min_sigma_gap_ratio > eps_gap)`;
- если `linearization_valid = False` — **не отчитывать** `E_right, E_left, E_cross`, `E_resid` (не имеют смысла); отчитывать только `E_radial` и `E_off_manifold`;
- если `rotation_unique = False` — отчитывать пять каналов, но помечать `E_right, E_left, E_cross` как `ambiguous` (число есть, интерпретации нет).

## 9. Краевые случаи и на что обратить внимание

1. **`log` главной ветви.** `R_U = polar(Q_U)`; `M = logm(R_U)` в главной ветви требует `|θ_j| < π/2` для всех собственных углов. Иначе — `linearization_valid = False`; `M` комплексная. `numpy.linalg.logm` вернёт комплексную матрицу без предупреждения — нужен явный `assert isreal(M)` и/или `‖Im M‖ < ε`.

2. **`Σ` не полного ранга.** Если `σ_r ≈ 0` (не наш случай, но на будущее): `Q_V` определён на подпространстве `span{σ_i > 0}`, log внутри нуль-пространства произволен. Флаг `rank_deficient`.

3. **`order_cross`.** Венгерское сопоставление столбцов `U_t ↔ U_{t+1}` может расходиться с сортировкой по `σ`. Это не ошибка — это сигнал, что `Σ_{t+1}` переупорядочивается относительно `Σ_t`. В артефакте отчитывать как флаг; на числа не влияет, если `Q_U` выровнена правильно.

4. **`eps3_correction` не «седьмой канал».** Если попытаться закрыть `‖ΔJ‖² = Σ6` **точно**, придётся ввести `eps3_correction` как remainder — и это снова тавтология. Правильно: `eps3_correction` — **диагностика** качества линеаризации, а не канал. Она входит в assert как погрешность с порогом.

5. **`E_cross` знаковая.** Отчитывать `signed` и `abs` отдельно; в долях использовать `|E_cross|`.

6. **`E_off_manifold` на L6–L22 ≈ ‖ΔJ‖²/2.** Не пугаться: это **правильное** поведение, отражающее, что `U_t` и `U_{t+1}` независимы (Δ_SVD ~ π/2). E-40.5 на L6–L22 **должен** дать `linearization_valid = False`, и это **ожидаемый результат**, а не провал эксперимента. Pre-registered ожидание: пять каналов дают информативный профиль только на L23.

7. **Не путать `E_resid` с `eps3_correction`.** `E_resid` — норма разности `U_tᵀ ΔJ V_t − ΔJ_lin`, `O(ε²)`. `eps3_correction` — сумма двух кросс-членов `O(ε³)`. Разные порядки, разные роли. В артефакте — разные поля.

8. **Pre-registered ожидание для E-40.5:** на L23 `linearization_valid = True`, `rotation_unique = False` (E-38c); интерпретация пяти каналов — **только** `E_radial` и `E_off_manifold`. На L6–L22 `linearization_valid = False`, отчёт только `E_radial` и `E_off_manifold`; никакой «декомпозиции» нет.

## Резюме в одну фразу для вставки в ТЗ

> **Рецептура линеаризации:** `ΔJ_lin = ΔΣ + M Σ̄ − Σ̄ N`, `M = log polar(U_tᵀ U_{t+1})`, `N = log polar(V_tᵀ V_{t+1})`. **Пять каналов** — компоненты `‖ΔJ_lin‖²`. **`E_resid`** — независимо: `‖U_tᵀ ΔJ V_t − ΔJ_lin‖²_F`, не через conservation. **Шестой канал `E_off_manifold`** — независимо: `‖ΔJ − U_t U_tᵀ ΔJ V_t V_tᵀ‖²_F`, обязателен при `r ≪ D`. Полная формула: `‖ΔJ‖² = Σ6 + eps3_correction`. **Два условия валидности:** `Δ_SVD < π/2 − 0.3` (иначе `linearization_valid = False`) и `min σ-gap > 10⁻² σ₁²` (иначе `rotation_unique = False`); на текущих данных первое выполнено только на L23, второе — нигде. **Pre-registered:** на L6–L22 отчитывать только `E_radial` и `E_off_manifold`; интерпретация пяти каналов применима только к L23 и только к `E_radial`.
