## 3. N2 — подтверждено в коде, принято

Механика (AT2e.py L512-522, `ascent`; та же схема в `secondary_k2`,
L923-933 — фикс идёт в оба подъёма): шаг принимается **безусловно**
(`v_new = v_cur + η·g/‖g‖` сразу в records), уменьшение λ обнаруживается
только на следующей итерации (`lam_seq[-1] < lam_seq[-2]` → η/=2), и
следующая точка считается от худшей. Числа: **4** шага вниз на первых
итерациях, не 3 — c1-t' (0.422), **c9-t' (0.544)**, c10-t (0.780),
c4-t (0.364).

Backtracking с переиспользованием градиента — принят. Бухгалтерия
(проверено по коду):
- текущий плохой шаг: 6 ф.-э. (probe 2 + vjp 4) И сдвигает траекторию в
  худшую точку;
- backtracking: trial = **2 ф.-э.** (t-fwd + B0-fwd в v_trial, градиент
  из v_cur переиспользован); принятый шаг = 6 ф.-э. (trial 2 + vjp 4 —
  probe в v_trial даёт dz/qs, следующий vjp их переиспользует);
- экономия = **4 ф.-э. на откат**, + монотонная траектория (v* перестаёт
  зависеть от порядка принятых ухудшений).

Запины в TZ §3.4 (одна ревизия подъёма, вместе с относительным стопом):
(i) семантика trial/отката — ваша формула; (ii) η-floor = 0.01 (существует);
если на floor trial всё ещё ухудшает → **break с converged=False**
(ascent_not_converged по обычному критерию) — ложная сходимость запрещена;
(iii) при backtracking траектория монотонно неубывающая ⇒ v* = последняя
точка; argmax сохраняется (0 ф.-э., страховка); (iv) S15 расширен случаем
«первый шаг вниз» (синтетика: assert отказ + η/2 + монотонность +
v* = last).
