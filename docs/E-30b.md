# ТЗ: E-30b. Полный спектр `Δoff²(r)`: локализация остаточного cross-talk

Дополнение к E-30. Не новый эксперимент, а расширение отчёта E-30 для проверки гипотезы о локализации структурного остатка. Запускается на существующем кэше `exp27b`, без дополнительных форвардов.

---

## Цель и идеология

E-30 показал, что на L22 `PR_modes ≈ 4.6` (концентрация), но первые 10 мод дают менее 0.1% от `off²(K)`. Значит, концентрация обязана сидеть в модах `r > 10`. Где именно — неизвестно, потому что в JSON сохранены только `Δoff²` для `r = 1..10`.

Цель E-30b: получить **полный спектр `Δoff²(r)` для `r = 1..128`** на слоях **L18 и L22** (пилот; при желании — на всех), с знаками и кумулятой, чтобы:

1. Найти моды, дающие основной вклад в `off²(K)`.
2. Отличить концентрацию в нескольких модах от деструктивной интерференции многих.
3. Дать E-32 список мод-кандидатов для проверки гипотезы «Hessian cross-talk в тех же модах».

---

## Математика

Используются определения E-30:

- `off²(r) = ‖A_r‖_F² − ‖diag(A_r)‖_F²`, `A_r = P · ESG_r · P`, `ESG_r = Σ_{k≤r} λ_k u_k u_kᵀ`.
- `off²(0) = 0`.
- `Δoff²(r) = off²(r) − off²(r−1)`, `r = 1..K`.
- `w_r = Δoff²(r) / off²(K)`, `Σ_{r=1}^K w_r = 1`.
- `PR_modes = 1 / Σ_{r=1}^K w_r²` (в коде: `(Σ w_r)² / Σ w_r²`; при `Σ w_r = 1` совпадает).
- Кумулята: `C(r) = off²(r) / off²(K)`, `r = 0..K`, `C(0)=0`, `C(K)=1`.
- Доля отрицательных `Δoff²` на моде `r`: `f_neg(r) = P(Δoff²(r) < 0)` по сэмплам.

Агрегация — протокол E-30: per-sample медианы по позициям внутри блока `(dom, si)`, затем медиана и IQR по блокам. Для каждого `r` хранятся `med`, `q1`, `q3`.

---

## Подводные камни

1. **`PR_modes` и отрицательные `Δoff²`.** Низкий `PR_modes` может отражать не концентрацию, а сокращение больших разнознаковых вкладов. Полный спектр с знаками обязателен, чтобы это различить.
2. **Немонотонность `off²(r)`.** `off²(r)` — разность двух возрастающих величин; она может убывать. Кумулята `C(r)` не обязана быть монотонной. Не интерпретировать плато как «насыщение», если рядом есть отрицательные `Δoff²`.
3. **Top-20 по медиане.** Медиана `|Δoff²(r)|` может скрывать бимодальность. Рекомендуется сохранять полный спектр, а top-20 использовать только как быстрый указатель.
4. **Sentinel.** На L18 и L22 `sentinel_fraction = 0.0`, но механизм исключения сохраняется.
5. **Стоимость.** Дополнительных `eigh` нет; только агрегация уже посчитанных `off2_full` и `d_full`. Время — секунды на слой.

---

## Что собираем

Для каждого слоя из `{18, 22}` (пилот) — массивы длины `K = 128`:

- `r`: `1..128`.
- `delta_off2_med`, `delta_off2_q1`, `delta_off2_q3` — статистики `Δoff²(r)`.
- `off2_cum_med`, `off2_cum_q1`, `off2_cum_q3` — статистики `C(r)`.
- `neg_frac_per_r` — медиана доли отрицательных `Δoff²` на моде `r` по блокам.
- `top20_by_abs_delta` — список из 20 словарей:
  ```json
  {"r": 42, "med_delta": -0.0031, "abs_med_delta": 0.0031, "neg_frac": 0.62}
  ```
  Сортировка по `abs_med_delta` убыв.

Дополнительно, если просто — те же массивы для всех слоёв E-30 (L6, L12, L18, L22, L23), но приоритет L18, L22.

## Как

Патч `exp30_mode_decomposition.py`:

1. В `process_layer` после вычисления `d_full` и `offK`:
   ```python
   off2_cum = off2f / safe[:, None]
   ```
2. Использовать `per_sample_stats` на `d_full` и `off2_cum`:
   ```python
   delta_stats = per_sample_stats(d_full, n_blk, npos)   # [med, q1, q3] длины K
   cum_stats   = per_sample_stats(off2_cum, n_blk, npos)
   ```
3. Вычислить `neg_frac_per_r`:
   ```python
   neg_mask = (d_full < 0).astype(np.float32)
   neg_frac_per_r = np.median(
       neg_mask.reshape(n_blk, npos, K).mean(axis=1), axis=0
   )
   ```
4. Top-20:
   ```python
   med_delta = np.array(delta_stats[0])
   abs_med = np.abs(med_delta)
   top_idx = np.argsort(abs_med)[::-1][:20]
   top20 = [{"r": int(i+1), "med_delta": float(med_delta[i]),
             "abs_med_delta": float(abs_med[i]),
             "neg_frac": float(neg_frac_per_r[i])} for i in top_idx]
   ```
5. Добавить в `res["full_spectrum"]`:
   ```python
   res["full_spectrum"] = {
       "r": list(range(1, K+1)),
       "delta_off2_med": delta_stats[0],
       "delta_off2_q1": delta_stats[1],
       "delta_off2_q3": delta_stats[2],
       "off2_cum_med": cum_stats[0],
       "off2_cum_q1": cum_stats[1],
       "off2_cum_q3": cum_stats[2],
       "neg_frac_per_r": neg_frac_per_r.tolist(),
       "top20_by_abs_delta": top20
   }
   ```
6. Чтобы не раздувать основной JSON, записывать `full_spectrum` только для слоёв из `--full-spectrum-layers` (по умолчанию `[18, 22]`) в отдельный файл `results/exp30_full_spectrum.json`. Либо добавить в основной JSON, если размер не критичен (≈ 128×6 чисел на слой).

CLI: добавить `--full-spectrum-layers 18 22`.

## Интерпретация

| Наблюдение | Что означает | Следствие |
|---|---|---|
| Top-20 содержит `r > 10` с большими `|Δoff²|`, `neg_frac` низкая | концентрация в нескольких модах, не в топах | E-32 таргетируется на эти моды |
| Top-20 с большими `|Δoff²|`, но `neg_frac ≈ 0.5` | деструктивная интерференция, не концентрация | E-32 ищет пары мод с сокращением |
| `C(r)` растёт ступенькой | локализованный вклад | кандидаты — моды на ступеньке |
| `C(r)` плавно, много отрицательных `Δoff²` | распределённый/интерферирующий cross-talk | E-32 не имеет одной мишени, искать пары |
| L22: top-20 в `r > 10`, L18: top-20 размазан | L22 действительно особый | приоритет L22 для E-32 |

## Критерии остановки

- Один прогон на L18 и L22.
- Если top-20 даёт чёткие моды-кандидаты (например, 3–5 мод с `|Δoff²| > 10×` медианы) → E-32 запускается на этих модах.
- Если top-20 размазан и `neg_frac` высока → E-30 закрывается как «локализованных мод нет; cross-talk распределён или интерферирует», E-32 не таргетируется на конкретные моды.

### 1. Защита от деления на ноль в кумуляте
В патче `off2_cum = off2f / safe[:, None]` переменная `safe` — это `off2f[:, -1]` (полная off-diagonal энергия на $r=K$). Теоретически, если на каком-то сэмпле/позиции матрица $A_K$ окажется идеально диагональной, `safe` будет равен нулю, и мы получим `NaN`.
**Фикс:**
```python
safe = off2f[:, -1].copy()
safe = np.where(safe < 1e-12, 1.0, safe)  # или np.clip(safe, 1e-12, None)
off2_cum = off2f / safe[:, None]
```

### 2. Концептуальное уточнение: почему `Δoff²` бывает отрицательным
В ТЗ это названо «деструктивной интерференцией», и это верно. Но для того, кто будет читать JSON, стоит зафиксировать механику:
$P$ — не ортогональный проектор, поэтому спроецированные моды $w_k = P u_k$ **не ортогональны**.
Когда мы добавляем моду $r$, квадрат нормы $\|A_r\|_F^2$ растёт не только на «собственную энергию» моды $r$ ($\lambda_r^2 \|w_r w_r^T\|_F^2$), но и на **перекрёстные члены** с предыдущими модами $k < r$: $2 \lambda_r \lambda_k \langle w_r w_r^T, w_k w_k^T \rangle$.
Если `Δoff²(r) < 0`, это означает, что перекрёстный член (интерференция с уже накопленным подпространством) **отрицателен и по модулю больше**, чем собственная энергия моды $r$.
*Вывод:* Если мы увидим, что топ-20 мод по $|\Delta \text{off}^2|$ имеют `neg_frac ≈ 0.5` или выше, это будет означать, что низкий $PR_{modes}$ на L22 — это не «скрытая структура в хвосте», а **сильное взаимное гашение** мод при прохождении через $P$. В таком случае E-32 придётся искать не «одну виновную моду», а пары/группы мод, которые интерферируют. ТЗ это предусматривает (строка в таблице интерпретации), и это правильный подход.
