# 3. H5: Ловушка избежута (самое важное)

В предыдущем ревью я предупреждал (N6), что тождество `S_x^sur(p) = S_x(p)` (и, следовательно, `R_resid ≡ 0`) выполняется **для любого** `x` по построению суррогата, а не только для copy-paste. Делать из этого вывод "p-структура = необходимое feedforward-следствие" — логическая ошибка.

Смотрим, как это реализовано в `AT0_7_loop.py` и артефакте:
```json
"H5": {
  "R_resid_median": 0.0,
  "R_resid_max": 0.0,
  "note": "АЛГЕБРАИЧЕСКОЕ ТОЖДЕСТВО, не измерение. Разделение copy-paste vs динамика требует контрфактуального форварда."
}
```

Код **намеренно не использует** H5 для бинарного вердикта. Он честно констатирует тождество и оставляет содержательный вывод на долю H1/H2/H4 (которые опираются на реальные измерения `rep_frac`, `maxrun` и `Q`). Это высший пилотаж методологической дисциплины.
