## Эксперимент E29. «Фишерова линза»

### Мотивация

Косинусная когерентность $C$, которую мы использовали, — это евклидова метрика в пространстве матриц. Но естественная метрика на распределениях — информация Фишера $F = J^T M_p J$, где $M_p = \text{diag}(p) - pp^T$. Фишерова метрика учитывает уверенность модели: сдвиг в зоне уверенного предсказания «дороже» сдвига в зоне неопределённости.

Проверяем:
1. Видит ли фишерова метрика структуру, невидимую косинусу.
2. Разделяет ли фишерова метрика внутрисэмпловую и межсэмпловую когерентность лучше косинусной.
3. Есть ли «эффективная температура» (след Фишера), монотонная по глубине.

### Математика

**Объекты на входе** (из кэша):
- Якобианы $J^{(p)}_t$ для позиций $t$.
- Векторы вероятностей $p_t \in \mathbb{R}^K$ для каждой позиции (должны быть в кэше, иначе эксперимент не пойдёт).

**Шаг 1. Фишерова метрика.**

Для каждой позиции $t$:
$$F_t = (J^{(p)}_t)^T \left(\text{diag}(p_t) - p_t p_t^T\right) J^{(p)}_t \in \mathbb{R}^{D \times D}$$

Это симметричная положительно полуопределённая матрица. Её след — суммарная чувствительность распределения к скрытому состоянию.

**Шаг 2. Локальное фишерова расстояние.**

Для пары последовательных позиций $(t, t+1)$ с разностью $\delta = h_{t+1} - h_t$:
$$d_F(t) = \sqrt{\delta^T F_t \delta}$$
(локальная аппроксимация геодезической).

Для сравнения: евклидова разность $d_E(t) = \|\delta\|_2$ и косинусная метрика $d_C(t) = 1 - \cos(h_t, h_{t+1})$.

**Шаг 3. Фишерова когерентность.**

Для пары позиций $(t, s)$ внутри одного документа:
$$C_F(t, s) = \frac{\delta_{ts}^T F_t \delta_{ts}}{\|\delta_{ts}\|^2}$$
(нормированная фишерова длина). Сравниваем с косинусной $C(t,s)$.

Для межсэмпловых пар — аналогично, но $t$ и $s$ из разных документов.

**Шаг 4. Эффективная температура.**

$$T_{\text{eff}}(l) = \text{tr}(F_l) = \text{tr}\left((J^{(p)}_l)^T M_{p_l} J^{(p)}_l\right)$$

Отслеживаем по глубине $l$ и между моделями.

### Краевые условия и подводные камни

1. **Наличие $p_t$ в кэше.** Если вероятности токенов не сохранялись, эксперимент невозможен без нового прохода. Проверить кэш первым делом.

2. **Вырожденность $M_p$.** Если $p_t$ сконцентрирован на одном токене ($p_i \approx 1$), $M_p \approx 0$ и $F_t \approx 0$. Это не ошибка, а сигнал: модель полностью уверена, чувствительность к скрытому состоянию минимальна. Но такие позиции нужно отмечать отдельно.

3. **Размерность $D$.** Матрица $F_t$ имеет размер $D \times D$. Для $D = 4096$ это 16 млн элементов на позицию. Если позиций много, хранение $F$ может быть затратным. Альтернатива: не хранить $F$ целиком, а считать только след и квадратичные формы $\delta^T F \delta$ на лету.

4. **Сравнение косинусной и фишеровой когерентности.** Косинусная когерентность нормирована в $[0, 1]$. Фишерова не нормирована. Для сравнения нужно нормировать обе на диагональные элементы или на след. Иначе масштабы несопоставимы.

5. **Межсэмпловые пары.** Для межсэмпловых пар нужно использовать $F$ из одного документа (например, $F_t$ для позиции $t$ из первого документа). Смешивать $F$ из разных документов некорректно.

### Тонкости ТЗ

- «Фишерова метрика видит структуру» означает: отношение $C_F^{\text{intra}} / C_F^{\text{inter}}$ больше, чем отношение $C^{\text{intra}} / C^{\text{inter}}$ для косинусной метрики. Если отношение не улучшается — фишерова метрика не даёт дополнительной информации.
- «Эффективная температура» не обязана быть монотонной. Если она монотонна по глубине — это новый факт. Если нет — ищем немонотонность и интерпретируем.
- Не путать $F$ (фишерова метрика, $D \times D$) с $JJ^T$ (грамманиан, $K \times K$). Это разные объекты: $F$ живёт в скрытом пространстве, $JJ^T$ — в токенном.

### Выход

- Профили $d_F(t)$, $d_E(t)$, $d_C(t)$ для каждого документа.
- Матрицы когерентности $C_F(t,s)$ и $C(t,s)$ внутри и между документами.
- Кривая $T_{\text{eff}}(l)$ по глубине для каждой модели.
- Сравнение: в скольких процентах позиций фишерова метрика даёт другое ранжирование пар, чем косинусная.

Если кэш содержит несколько слоёв и моделей — запускаем для каждой комбинации (слой, модель) отдельно. Это даст карту: как листовая структура и кривизна меняются по глубине и между масштабами.
