## 2. Дизайн против T2
- **Дерево даёт ответ на T2 при пройденном контроле:** T2-гипотеза
  (AT2_prereg.md §8): «weak-J cos > max(PCA, Haar) per (l,k) … на ≥2 из
  k ∈ {2,4,8}», AND-over-l для ВСЕХ 4 l — ветка (a) ТЗ реализует ровно это
  (односторонний CI lower > 0 + weighted mean > DELTA_MIN, ≥2 из {2,4,8}) ✓.
- **(i) Стационарный базис из того же J-кэша:** валиден для ФУНКЦИОНАЛЬНОГО
  k=0-контроля (тест работоспособности разбиения top/weak, не неоправленная
  оценка); в k≥1 базис не зависит от будущего t — утечки в T2-цель нет.
  ТЗ покрывает: C1 (подтверждён) в преамбуле, §2 «конструкция — ТОЧНО как в
  диагностике (S8-якорь)» ✓.
- **(ii) Общий ridge на 31×(128−k):** часть дизайна, валидирована диагностикой
  C1c (top>weak с ним, CI +0.21…+0.36); ТЗ покрывает (C1 + S8-якорь) ✓.
- **(iii) Асимметрия pca per-(l,doc) vs top per-layer:** объявлена (§2
  «Асимметрия объявлена (F7-наследник)» + meta-блок `asymmetry` в артефакте) ✓.
- **Weighted-метрика:** w(d,t) = ‖y_c(d,t)‖² зависит только от (d,k,t), ОБЩИЕ
  для всех армов на позиции — формулировка §3 явна («одинаковая статистика на
  обеих сторонах»); систематической фаворизации нет: в diff arмов веса
  сокращаются как общий множитель на позиции ✓.
