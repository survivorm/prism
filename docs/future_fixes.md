## 📋 Идеи для future-work абзацев (по абзацу каждый, не в эксперименты)

### F1. Гессиан / second-order bridge
**Откуда:** Kimi 4.2
**Почему нет сейчас:** Дорого — O(D²) память, не O(D). Нелинейность уже честно задокументирована как граница метода.
**Как записать:** «Second-order Jacobian bridge (Hessian-based) остаётся открытым направлением для захвата нелинейных взаимодействий между токенами. При текущем масштабе моделей это требует O(D²) памяти, что делает практическое применение ограниченным.»

### F2. Cross-family / cross-lingual мост
**Откуда:** Qwen D, Kimi
**Почему нет сейчас:** Требует выравнивания словарей; это отдельная статья, не эта.
**Как записать:** «Мост между моделями разных семей (Llama ↔ Qwen) или с разными словарями требует дополнительного выравнивания. Это перспективное направление, но выходит за рамки текущей работы.»

### F3. Адаптивный контроллер квантования
**Откуда:** Qwen B
**Как записать:** «ESG-структура может служить контроллером для adaptive quantization: направления с высоким eigenvalue — более чувствительны к ошибкам и требуют更高的 точности. Перспективно для INT4/INT2 квантования без потери качества.»

### F4. ESG-детектор галлюцинаций
**Откуда:** Qwen A
**Как записать:** «Аномальный shift в ESG eigen-directions может сигнализировать о галлюцинации: если скрытые состояния смещаются в направлении, нетипичном для данного слоя, это может быть ранним индикатором. Требует валидации на benchmar ks.»

### F5. Vocabulary pruning
**Откуда:** GLM 4
**Как записать:** «Токены с нулевым/низким вкладом в ESG (eigenvalue ≈ 0) — кандидаты на pruning из словаря без потери качества представления. Потенциал для сжатия без training.»

### F6. Optimal Transport bridge
**Откуда:** GLM 2
**Как записать:** «Мост через Optimal Transport (Wasserstein-2) между распределениями hidden states — альтернатива linear projection. OT даёт глобальную оптимизность, но O(n²) сложность по токенам ограничивает масштабируемость.»

### F7. Trigger tokens / adversarial surgery
**Откуда:** GLM 1
**Как записать:** «Целенаправленная surgery в gauge- или token-discriminating направлениях может служить инструментом adversarial robustness testing. Добавление/удаление gauge-shift изменяет output distribution предсказуемым образом — это можно использовать для генерации adversarial examples.»
