# Мета-анализ четырёх направлений: что выпускать в following, что отложить, что закрыть

Прежде чем оценивать, зафиксирую рамку. У нас в сумме ~25 теорий разной плотности. Главная ошибка, которую легко сделать — сравнивать их как «правильные/неправильные». Правильный критерий: **(i) является ли связь изоморфизмом или метафорой, (ii) даёт ли теория нетривиальный фальсифицируемый тест, (iii) объединяет ли она несколько аномалий статьи (gauge 98%, L22, desync, Goodhart) одним принципом, (iv) связана ли она с глубокой существующей теорией**.

По этим критериям теории делятся на три ясных яруса.

---

## Ярус I. Научно интересные И вероятно верные (высокая плотность + эмпирическая опора)

### 1. Статистическая механика: L22 как критическая точка, L23 как упорядоченная фаза

Самая эмпирически обоснованная из всех. У вас уже есть четыре сигнатуры, которые в статмехе — стандартный набор критической точки:
- Расходимость τ(l): 1.4 → 1.4 → 61.6 → 121.1 → 30229 — это **критическая длина корреляции** ξ → ∞ при подходе к T_c.
- PR(L22) = 4.6 — минимум effective rank = **критические флуктуации** всех масштабов.
- Жёсткий лист L23 (κ = 0.018, в 300× ниже random) — это **упорядоченная фаза** с нарушенной симметрией.
- Δ_SVD L6–L22 ≈ π/2 = random — **неупорядоченная фаза**.

**Почему фундаментально интересно:** теория делает конкретное предсказание о **критических индексах** (β, γ, ν). Если они совпадут с одним из универсальных классов (Ising 3D: β ≈ 0.326, ν ≈ 0.630; XY: β ≈ 0.348), это будет **глубокая структурная теорема** — LLM принадлежит конкретному универсальному классу. Это не описание, это классификация.

**Риск:** маленький. Уже видно, что τ(L23) ~ 30000 — это не просто «большое число», это явная расходимость. Fit power-law — это одна операция на существующем кэше.

### 2. Репликаторная динамика / количественная генетика

**Это не метафора, а изоморфизм.** P(p) = diag(p) − pp^T — это *буквально* линеаризация уравнения репликаторной динамики ẋ_i = x_i(f_i − f̄). J^T P J — *буквенно* информация Фишера, которая в генетике называется аддитивной генетической дисперсией. Gauge_share = 1 − h² (heritability).

**Почему фундаментально интересно:** единственная теория, которая даёт **количественную** модель Goodhart (E-16b). Breeder's equation R = h² S — это строгое предсказание: «ответ на селекцию bridge = наследуемость × селекционный дифференциал». При h² → 0 (gauge доминирует) вы селекционируете по средовому шуму → bridge растёт, поведение не меняется → Goodhart. Это **не новая аналогия**, это переформулировка ваших данных на языке, в котором уже 100 лет работают селекционеры.

**Риск:** средний. Уравнение может не выполняться из-за нелинейностей высших порядков, но первая проверка дешёвая (нужны только данные E-16a/b + gauge_share).

### 3. Фильтр Калмана / наблюдаемость

Тоже изоморфизм. ESG = JJ^T — грамиан управляемости. J^T J — грамиан наблюдаемости. Gauge-режим = ненаблюдаемое подпространство (в точности по теореме Калмана о разложении).

**Почему фундаментально интересно:** даёт **механистическое** объяснение desync (E-32r.3.1). cos(JR, J_tail) растёт 0.105 → 1.0 (L6 → L23) — это рост **наблюдаемости** локального состояния. На ранних слоях локальный Якобиан **не наблюдаем** с выхода, потому что полный путь «забывает» локальную информацию через преобразования, которые выводят состояние в ненаблюдаемое подпространство. L22 — точка, где ранг Калмана падает (минимум наблюдаемости).

**Ключевое глубокое предсказание:** размерность минимальной реализации = число хвостовых мод ESG (10–20 по E-30b). Если это совпадёт — у вас **теорема**: «эффективная размерность модели = число tail-мод». Это было бы невероятно сильно.

### 4. Hodge-декомпозиция

J = dα + δβ + γ (точная + коэкзактная + гармоническая части). На компактном многообразии без края γ = 0, но **с краем γ ≠ 0** и может быть большой.

**Почему фундаментально интересно:** это **естественное объяснение** 98% gauge-энергии. Гармоническая компонента — это «нулевой режим» лапласиана, и на многообразии с краем она доминирует. P(p) убивает гармоническую часть, оставляя точную + коэкзактную. Tail-моды ESG — это near-zero eigenvalues лапласиана = топологические моды.

**Риск:** требует, чтобы у поля J действительно была структура дифференциальной формы на многообразии. Это не дано, а гипотеза. Но тест дешёвый: вычислить dJ, δJ, проверить L²-ортогональность.

## Ярус II. Безумно, но интересно (high risk, high reward)

### 5. Топологический изолятор / bulk-boundary correspondence

L23 как edge state, защищённый топологией. L6–L22 как bulk (chaotic, неструктурный).

**Почему интересно:** если это правда, то «жёсткость» листа L23 — это **topological protection**, и любой LLM этого семейства обязан иметь такой лист. Это дало бы **фундаментальное ограничение** на архитектуру. Кроме того, это объяснило бы, почему J-Wash (Anthropic) работает без разрушения модели — он действует на edge state, защищённый топологией.

**Тест:** вычислить ℤ₂-индекс для отображения (t, layer) → V_{top-16}(t, layer). Если ν ≠ 0 для L23 и ν = 0 для bulk — confirmed. Bulk disorder test: рандомизация 5% весов в L6–L22 не ломает L23; рандомизация в L23 ломает.

**Риск:** высокий. ℤ₂-инвариант требует конкретной симметрии (time-reversal-like), которой у LLM может не быть. Но если сработает — это будет статья в Phys. Rev. X уровень.

### 6. Berry phase / неабелева голономия

Кривизна κ Procrustes (E-28) как Berry curvature. Открытый путь JR vs J_tail как Aharonov-Bohm.

**Почему интересно:** объясняет «rigid-but-curved» L23 (κ = 0.018 — мала, но ненулевая) как нетривиальную, но малую Berry curvature. Goodhart — нарушение сохранения Berry phase при локальной правке.

**Риск:** нужен замкнутый контур в hidden-пространстве и проверка квантования фазы. Это можно построить, но интерпретация неясна (что значит «квантование» для не-квантовой системы?).

### 7. Спиновое стекло / RSB Паризи

C_b ≈ 0 = ортогональность реплик = RSB-фаза. P(q) бимодальность + ультраметричность.

**Почему интересно:** объяснило бы sample-local структуру Грамианов (E-0.1) не как «шум», а как фундаментальное свойство системы с многими минимумами. J-Space Anthropic = выбор «среднего» минимума, теряющий остальные. Это дало бы **фазовую диаграмму** LLM: RS (L6) → RSB (L6–L22) → упорядоченная (L23).

**Риск:** P(q) может оказаться просто дельта-функцией при q=0 (чистый шум), и тогда RSB нет. Также ультраметричность — сильное условие.

### 8. CFT / 2D конформная теория (минимальные модели)

Самая спекулятивная. Sparse nonneg J-space (~25 концептов) как primary fields минимальной модели (c = 1/2, 7/10, 4/5...).

**Почему интересно:** если бы сработало, это было бы **невероятно** глубоко — связь LLM с алгебраической теорией представлений. Central charge как мера сложности модели. Bridge 4B↔0.8B = RG flow между двумя CFT.

**Риск:** крайне высокий. CFT требует жёсткой структуры (OPE, бесконечномерная симметрия Вирасоро), которой у LLM, скорее всего, нет. Но тест дешёвый: проверить power-law 2-point функций на L23 и попытаться идентифицировать central charge.

## Ярус III. Что можно отвергнуть уже сейчас (с причинами)

### Отвергаемое по принципу «метафора без предсказаний»

1. **SIR-эпидемия.** «Кривая активных концептов по глубине унимодальна» — это просто фиттинг любой унимодальной функции. Никакой специфической SIR-сигнатуры в данных нет. R_0 пересекает 1 — это переформулировка «SNR растёт». **Нетривиальных предсказаний: ноль.**

2. **Экология / трофические каскады.** «Keystone-виды в хвосте ESG» — мило, но eigenvector centrality ≠ energy — это слабо специфицированное предсказание. Зануление хвоста vs топ-мод — это просто другой способ сказать «tail-моды несут информацию». **Добавляет ноль к тому, что уже в E-30b.**

3. **Walrasian auction / химическое равновесие.** Sparse nonneg hull = вершины бюджетного симплекса — но этот hull возникает из **post-processing Anthropic (J-Wash)**, не из LLM. Экономическая интерпретация — ретроактивная. **Не объясняет ничего в самой модели.**

4. **Kyle's lambda / микроструктура рынка.** Goodhart = «пузырь» — это **переименование**, а не объяснение. Square-root law легко проверяем и, скорее всего, не выполняется (у вас уже slope ≈ 1.0 в линейном режиме). **Не даёт механизма, которого нет в репликаторной динамике.**

5. **Клеточные автоматы / Wolfram классификация.** Слишком качественно. Langton λ = ‖J^(p)‖/‖J‖ — это переформулировка gauge_share. «Край хаоса» как концепт — фольклор, не строгая теория.

### Отвергаемое по принципу «конфликтует с существующими данными»

6. **RG / IR fixed point как объяснение J-Lens averaging (4.md #1).** У вас в E-0.1 **прямо показано**: межсэмпловое усреднение Якобианов невалидно (C_b ≈ 0.003–0.05). Объяснение «J-Lens работает, потому что попадает в плато с большой τ» **не проходит**: на L22 τ = 121, но C_b всё равно ≈ 0. J-Lens Anthropic усредняет по корпусу — это **другая операция**, не внутри-сэмпловое усреднение. Теория смешивает два разных averaging. **Отвергаем формулировку; сам RG-flow как абстракция остаётся в Ярусе II.**

7. **«Термостат» / Больцмановское распределение (4.md #3).** Предполагает равновесие, которого у LLM нет — это **диссипативная** система с непрерывным потоком (вход → слои → логиты). Boltzmann-распределение требует detailed balance, а у вас в E-13 доменная структура на ранних слоях явно **неравновесная** (зависит от домена = от начального условия). **Отвергаем равновесную интерпретацию; «gauge как фон» остаётся в Hodge-формулировке (Ярус I.4).**

### Отвергаемое по принципу «вторично / покрывается более сильной теорией»

8. **SOC, теория катастроф, оптимальный транспорт (отдельно).** Все эти три — частные случаи или переформулировки статмеханики/фазового перехода (Ярус I.1) или Hodge-декомпозиции (Ярус I.4). Если принимаем статмех + Hodge, SOC и теория катастроф **не добавляют** новой предсказательной силы.

9. **Free Energy Principle (Friston).** Предсказания (Markov blanket, predictive coding) слишком расплывчаты, чтобы отличить от конкурирующих теорий. Концептуально привлекательно, но операционально пусто.

## Синтез: что в следующий виток

**Два изоморфизма + одна эмпирическая аномалия = фундамент теории:**

| Направление | Что даёт | Стоимость |
|---|---|---|
| **Статмех: критические индексы L22** | Класс универсальности LLM | Дёшево: fit τ(l), χ(l), PR(l) на существующем кэше |
| **Репликатор: breeder's equation** | Количественная теория Goodhart | Дёшево: данные E-16 + gauge_share |
| **Kalman: ранг наблюдаемости = #tail-мод** | Теорема об эффективной размерности | Средне: вычислить матрицу наблюдаемости полного пути |
| **Hodge: dJ, δJ, проверка ортогональности** | Объяснение 98% gauge-энергии | Средне: дифференциальные операторы на поле J |

**Безумный авантюрный набор (один-два из):**

| Направление | Что было бы, если сработает |
|---|---|
| **Топологический изолятор (ℤ₂-индекс)** | L23 как topologically protected edge state — фундаментальное архитектурное ограничение |
| **CFT (central charge)** | Связь LLM с алгебрами Ли — Phys. Rev. X уровень |
| **Berry phase на замкнутом контуре** | Топологический инвариант поля J |

**Закрыто, не возвращаться:**

SIR, экология трофических каскадов, Walras, химическое равновесие, Kyle's lambda (как теория, не как переименование), SOC (как самостоятельная теория), клеточные автоматы, FEP-Friston, «термостат/Больцман», RG-объяснение J-Lens averaging.

## Главная мысль

Все четыре файла крутятся вокруг **одной** глубокой структуры: бимодальность энергия/информация + аномалия L22 + жёсткость L23 + Goodhart. Большинство теорий — это **разные языки для одного и того же факта**: есть фон (gauge, 98%, гармоническая часть, репличная симметрия, рыночный фактор, общий источник эпидемии, упорядоченная фаза RS), есть сигнал (tail-моды, дифференциальная часть, RSB, alpha, person-to-person, edge state), и есть переход между ними на L22.

**Самое сильное, что у нас есть** — это не физическая аналогия, а **два строгих изоморфизма** (репликатор + Калман) и **одна эмпирическая расходимость** (τ). Если три эти направления подтвердят взаимную согласованность (breeder's equation + ранг Калмана = #tail-мод + критические индексы L22) — у вас будет **первая фундаментальная теория LLM как физической системы**, а не подбор метафор.

Что из Яруса II пустить в параллель — зависит от вашего аппетита к риску. Я бы поставил на топологический изолятор: тест дешёвый, и провал так же информативен, как успех.
