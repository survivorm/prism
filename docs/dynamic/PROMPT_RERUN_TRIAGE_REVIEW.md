## Что ещё оценить (без команд, по тексту)

- **Согласованность классов:** нет ли скрипта, который по дефектам должен быть в Б, но лежит в В
  (или наоборот). Особое внимание: E-65b (W4/W3), E-72 (4B в fp32 ≈16 GB при 17 GB avail), E-77b (v2).
- **Ценность списка Г:** это идеи или пересказ уже сделанного? (5 пунктов)
- **Нет ли пропущенных дефектов**, видимых с первого чтения: у каждого скрипта из В проверь, что он
  реально может запуститься (импорты, пути, имена функций, аргументы хуков).
- **Не выдуманы ли факты:** любое число в триаже без команды-подтверждения = пункт REVISE.
