## §2. E-40.2 — Двойной фит `C_F` / `C_top16`

**Канал:** `[natural] × [canonical (дефолт; если в exp31 raw — пересчёт)] × [CF: full L+R; C_top16: top-16 right] × [both sides]`.

### §2.1. Процедура

Для каждого слоя и каждой наблюдаемой (`C_F`, `C_top16` **отдельно**) фитим четыре формы:

| Форма | Уравнение | Параметры |
|---|---|---|
| Экспонента | `C(Δ) = A exp(−Δ/ℓ) + c` | `A, ℓ, c` |
| Степень | `C(Δ) = A Δ^(−α) + c` | `A, α, c` |
| Растянутая экспонента | `C(Δ) = A exp(−(Δ/ℓ)^β) + c` | `A, ℓ, β, c` |
| Степень × лог-периодика | `C(Δ) = A Δ^(−α)(1 + B cos(2π log Δ/log λ + φ)) + c` | `A, α, B, λ, φ, c` |

Метрики: `AICc` (с поправкой на малые выборки и автокорреляцию), `BIC`, **ресэмпл документов** (N=32) → рефит на каждом → перцентильные CI параметров (не блок по `Δ` — правило зависимых измерений из `2-8` §8.3).

### §2.2. Пре-регистрированные исходы (четыре, не больше)

| Исход | Условие | Что умирает / выживает |
|---|---|---|
| **1. Two-channel** | Экспонента/растянутая для `C_F` (`β≈1`, `ℓ≈1.4`), степень/лог-периодика для `C_top16` | Полимер для скалярной когерентности; связность для подпространственной динамики |
| **2. Both exp** | Экспонента для обеих | Полимер усилен; `τ = ℓ_p` подтверждён |
| **3. Both power** | Степень для обеих | `τ = ℓ_p` **мёртв**; WLC-термодинамизация **мертва**; коллапс `(bridge, drift)` переживает как феноменология |
| **4. Unstable** | Формы нестабильны по слоям | Нет единого закона; полимер и лог-периодика сняты; «режимная» картина |

### §2.3. Якорь E-39d (L23-only)

Не измерение (нет форвардов в этом тесте). В интерпретацию входит как граница диапазона:

> Полимерная интерпретация `τ = ℓ_p` жива в диапазоне `[κ_floor, κ_baseline]` = `[0.0092, 0.016]` **на L23 только** (E-39d honest floor: `corr_f = 0.9992` при `κ −42%`). Ниже floor — `not_testable` (не «мертва»). Для других слоёв — `not_testable` без оговорок.

### §2.4. H5 — статус

H5 в этом тесте — **угловая гипотеза с одним аргументом**. Энергетическая поддержка отозвана (`E39_supplement`). `corr_f` **не применим** (наблюдательный канал).

### §2.5. Резолюция

Bootstrap CI параметров как `resolution_floor`. Если `Δ AICc < 10` между двумя формами — `not_distinguishable_at_N32`.

**Стоимость:** часы.

## §3. E-40.3 — FFT остатка после вычета периодичностей

**Канал:** тот же, что E-40.2. **Зависит от 0.2** (нужна корректная огибающая).

### §3.1. Процедура

1. Проверить сетку `Δ` — dyadic?
2. Регрессия на позиционные индикаторы (sentinel-доля, позиция, длина, домен, слой); остаток `C_res`.
3. FFT по `log Δ` → пик на `ω = 2π/log 2 ≈ 9.06`?
4. Сравнение `S=64` vs `S=128`.

### §3.2. Null

- Перестановка `Δ` (разрушает лог-периодику);
- Конвейерный суррогат (случайный объект через тот же пайплайн);
- Равномерная сетка `Δ`.

### §3.3. Порог

Пик значим, если амплитуда `> 3σ` над нулём (B=1000) после вычета известных периодичностей.

### §3.4. Что умирает

| Исход | Статус |
|---|---|
| Пик на `ω ≈ 9.06`, устойчив к вычету | Лог-периодичность реальна; скейлинговые фиты нужно переписать |

## §5. E-40.5 — Кинетическая SVD-декомпозиция (5 каналов, энергии)

**Канал:** `[natural] × [canonical] × [top (K=128)] × [both sides]`.

### §5.1. Транспортная рецептура (дословно, `3-8` §4.3)

```
SVD обоих полей без пред-вращения
Q_U = polar(U_t^T U_{t+1});  Q_V = polar(V_t^T V_{t+1})
M = log Q_U;  N = log Q_V  (главная ветвь)
Σ̄ = (Σ_t + Σ_{t+1})/2
U^T ΔJ V ≈ MΣ̄ + ΔΣ − Σ̄N
C_LR = 2 tr(Σ̄ M Σ̄ N)  — знаковый
Residual = O(ε²), диагностика не мусор (10–15% нормы)
```

### §5.2. Пять каналов (энергии, не доли)

| Канал | Выражение | Примечание |
|---|---|---|
| Right transport | `‖Σ dV‖²` | — |
| Radial | `‖dΣ‖²` | — |
| Left | `‖dU Σ‖²` | **порог `unstable_left`** (§5.4) |
| Cross | `2 tr(Σ M Σ N)` | **знаковый** |
| Residual + calibration | норма остатка | диагностика |

Две нормировки: σ-взвешенная (энергетическая) и сырая (геометрическая).

**`r=1`-контроль:** при `r=1` антисимметричные `1×1` матрицы `M, N` нулевые, кросс-член тождественно ноль.

### §5.3. 5×5 матрица — **на энергиях, не на долях**

Доли `s_i = E_i/‖ΔJ‖²` удовлетворяют `Σ s_i = 1` тождественно — композиционные данные. Ранг ≤ 4 по построению, средняя внедиагональная корреляция `−1/(p−1) = −0.25` до всякой физики. Критерий «rank ≥ 4» вакуумен. Замена:

**Матрица 5×5 по энергиям `{E_right, E_radial, E_left, E_cross, E_resid}`.**

Трёхступенчатое чтение:
1. **Равнокорреляционный уровень `ρ̂`** (медиана внедиагонали) — общая мода (шкала `‖ΔJ‖²`).
2. **Отклонения пар от `ρ̂`** — структура сверх общей моды.
3. **Собственные значения против перестановочного нуля** (метки документов). MP-скобка `p=5, n=32`: `λ+ ≈ 1.95`.

**Пре-регистрированные предсказания:**
- `ρ(radial, right/left) < ρ̂` (амплитуда ≠ углы, E-39f);
- `ρ(right, cross) > ρ̂` (σ-взвешенная связка);
- `ρ̂ → 1` (λ₁ → 5) = **переупаковка** — пять каналов суть одна ось.

### §5.4. Левый канал: двухчастный порог

```
E_left ≥ max(0.05·E_right, Q_95(E_left^null))
```

Ниже — `unstable_left`, исключается из канальной статистики (доля отчитывается отдельно). Причина — 98–99% нормы усечено и левая сторона нестабильна; фиксированная доля 0.05 защищает от малой нормы, нулевой перцентиль — от шума.

### §5.5. Что умирает

| Исход | Что |
|---|---|
| Радиальный канал доминирует | «Радиальный нуль в объёме» мёртв |
| `ρ̂ → 1` | Пять каналов — одна ось; кросс-член как напарник запирания отпадает |
| Пара-предсказания не выполняются | Декомпозиция не та, что заявлена |

**`corr_f` НЕ применим** (наблюдательный канал).

**Стоимость:** день.

## §6. E-40.6 — `R_can(l)` и `R_raw(l)`

**Канал:** `[natural] × [canonical (для R_can) + raw (для R_raw)] × [top] × [right]`.

### §6.1. Процедура

- `R_can(l) = λ_max(E_K)/tr(E_K)`, `E_K = J^(p)(J^(p))ᵀ` (канонический срез);
- `R_raw(l) = λ_max(JJᵀ)/tr(JJᵀ)` (диагностика амплитуды, **не** параметр порядка);
- Профиль по слоям.
- **Partial out по частоте токена** для `R_raw − R_can` (E-39k lesson: `ρ(p̄, s^gf) = 0.966`).

### §6.2. Критерий «фаза vs монотонный» (а′)∧(a)∧(b)∧(c)

- **(a′):** `R_can(L23) = max_l R_can(l)` по доступным слоям;
- **(a):** `min_body R_can ≤ 0.5 · R_can(L23)` (порог 0.5 — пре-регистрированная константа, её ошибки не контролируемы, но лучше произвольная константа до прогона, чем спор после);
- **(b):** парный бутстрап `P(R_can(peak) − R_can(trough) > 0) ≥ 0.95`, где `trough = argmin_body` **пересчитывается в каждой реплике** (селекция на тех же данных);
- **(c):** вердикт **инвариантен** к срезу (с/без удаления топ-gauge-моды).

**Без L0:** критерий односторонний, `not_testable_no_L0`. Любые три из четырёх → `ambiguous` (валидный исход, не failure).

### §6.3. Что умирает

| Исход | Статус |
|---|---|
| Монотонный `R_can` | «Радиальный нуль как фаза» мёртв (death-list цел) |
| Плоский `R_can` | То же |
| `corr(R_can, κ)` **высокая** | Разделение «радиальное/угловое» неверно; **консенсусный каркас требует пересмотра** |
| `corr(R_can, κ)` **низкая** | **Подтверждение** ортогональности каналов; это **положительный результат**, не провал |

**Стоимость:** часы.

## §7. E-40.7 — Профиль `G(l)`

**Канал:** `[natural] × [fixP/raw] × [top] × [right]`.

### §7.1. Процедура

- `G(l) = 1 − Δ_fixP(l)/Δ_raw(l)` — «доля p-индуцированной декорреляции», не «доля калибровки»;
- Корреляции с `|Δp|`, энтропией, `C_a`, `C_top16`;
- **Partial out по частоте токена** (E-39k lesson).

### §7.2. Даунгрейд при отсутствии данных per layer

Если `Δ_fixP/Δ_raw` есть только на L23 (пункт (d) аудита) — `G(l)` даунгрейдится до `G(L23) + корреляции`; слой-обобщение H5 получает метку `not_testable`, не «опровергнуто».

### §7.3. Что умирает

| Исход | Статус |

## §8. E-40.8 — Синтез: матрица 6×6 (после 0.2–0.7)

**Канал:** `[synthesis]`. Ноль новых вычислений.

### §8.1. Вход

### §8.2. Носитель

- **Первичный:** per-(doc, layer) ячейки, `n = 32 × 6 = 192`;
- **Сопровождающий:** per-doc скаляры, `n = 32` (робастность);
- Наивный per-layer носитель (6 наблюдений, 8 переменных) **математически вырожден** (ранг ≤ 5).

### §8.3. Критерий ранга

- **Первичный:** перестановочный нуль (метки документов **независимо по переменным**); ранг = число собственных значений выше 95-го перцентиля нуля;
- **Аналитическая скобка:** MP-край `λ+ = (1+√(p/n))²`; `p=8`: `λ+(n=32)=2.25`, `λ+(n=192)=1.45`;
- **Сводная:** `PR = (Σλ)²/Σλ² ∈ [1,8]`.

Отчёт: `[rank, PR]` с bootstrap CI.

### §8.4. Априорная кластеризация (заморожена до прогонов)

- **C1 = {0.2, 0.3, 0.4}:** временная корреляционная структура — три функционала одного объекта; взаимные корреляции **дефинициональны**, информативна **межкластерная** матрица;

### §8.5. Асимметричные правила R1–R3

## §9. E-44 — Ключевые поля пререгистрации (черновик пишется параллельно tier-0)

Полная пререгистрация отдельным документом; здесь — **замороженные ключевые поля**, которые согласованы тремя голосами.

### §9.1. Объекты

| Объект | Определение | Назначение |
|---|---|---|
| `b_mag := ‖Δz_{t+k}‖²` | Квадрат L2-нормы (нотация `‖·‖²` только) | Primary, logit space |
| `b_lin := ε²‖J_{t→t+k}·v‖² = ε²σ₁²` | Линейный предиктор | Редукционный контроль |
| `b_res := b_mag − b_lin` | Residual | Discovery cell |
| `b_qual := corr_f` family | Ранговая сохранность K-логитов | **Классификатор режима, не фильтр** |
| `KL_lin := ½ε²(Jv)ᵀF(z)(Jv)` | Фактор Фишера `F = diag(p) − ppᵀ` | Robust-дубль, калибровочно-инвариантный |
| `g_2` | Top-r выравнивание `J_{t→t+k}` vs `J_{t→t}` | Вторая тавтологически-чистая ось |

**Голая `½ε²σ₁²` — отставлена** как недостижимая верхняя граница (`F ⪯ p_max·I` строго).

### §9.2. Доменное согласование (`3-11` §4.1)

- **Primary:** `Δz` и `σ₁` оба на **top-128** (бесплатно);
- **Companion:** оба полный словарь (`σ₁` через power iteration);
- **Cross:** `b_mag(full) − b_mag(top128)` — **H2-прокси** поведенческого хвоста;
- То же для `v` и `b_qual`.

### §9.3. Два null'а (правило 23)

- **`iid`** — `J ~ N(0,1)`, механическая проверка;
- **`content-matched`** — реальные нормы строк, рандомизированные направления;
- Отношение `ρ(g, b_mag)` — против **обоих**; pre-registered признак «signal» = значимо выше обоих.

### §9.4. `g_2` — порядок операций (E39_supplement + `3-11` §5.3)

1. В пилоте сначала проверить дисперсию `g_2` против `resolution_floor`. Если IQR < floor → `degenerate`, корреляции **не считаются**.
2. Иначе — корреляции по заранее объявленным ролям:
    - `ρ(g, b_mag)` — **контроль тавтологии** (ожидаем высокая, не ячейка открытия);
    - **Ячейки открытия:** `ρ(g, b_res)`, `ρ(g_2, b_mag)`, `ρ(g_2, b_res)`.
3. Вердикты (четыре, пятый не нужен):
    - только `ρ(g, b_res)` → нелинейный отклик топ-моды;
    - только `g_2` → подпространственная структура;
    - в обоих → сильнее;
    - **`first_order_coupling`** → ожидаемый-дефолтный.

### §9.5. Per-cell floors

`resolution_floor` считается **пер-ячейка (t, k)**, не глобально. A2/A4 кондиционированы на floor.

### §9.6. Абсолютные пороги вердиктов

- `universal_orthogonality`: `ρ < 0.3` для всех (t, k) при `resolution ±0.15`;
- `sequential_reasoning_mechanism`: `ρ > 0.5` для некоторых (k, layer) при `corr_f > 0.95`;
- `scale_dependent_alignment`: `ρ ≈ 0` для `k ≤ 4`, `> 0.5` для `k ≥ 8`.

**Пилот:** N=8, S=32, `k∈{1,2,4,8}`, слои `{6,18,23}`, ~2–3 ч CPU. Abort-criteria действуют.
