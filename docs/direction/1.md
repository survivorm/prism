Отличный вопрос — разбор полётов по структуре, которую ещё никто не искал. Сначала брейншторм, потом классификация, потом мои «защищаемые» пики, потом пробелы в математике.

## 1. Брейншторм: какие структуры ещё можно искать

### Блок A. Глубина как «время» динамической системы
Сеть — это динамическая система с дискретным временем $l$, и у нас есть точный tangent map. Что искать:

1. **Спектр Ляпунова по глубине.** $D_l = \partial h^{l+1}/\partial h^l$, QR-итерация (Бенеттин) → конечно-глубинные показатели $\lambda_1 \geq \dots \geq \lambda_D$. Карта: где спектры 4B и 0.8B расходятся, и коррелирует ли это с кривой gap. Вопрос «почему gap падает монотонно» — пока без механизма.
2. **Обратная рекурсия readout-направлений.** $v(l) = D_l^T v(l+1)$ — это степенная итерация; скорость схождения = $\sigma_2/\sigma_1$. «Захвачено» ли топ-направление readout уже на мелких слоях? Откуда «виден» lm_head?
3. **Спектральный поток ESG.** $\lambda_i(l)$ как энергетические зонны по глубине (band structure). Точки band-divergence между моделями vs точки, где gap прыгает.
4. **Периодограмма J-статистик.** Trace / SNR / PR / gauge_share как функции индекса слоя: скрытая периодичность архитектуры (чередование GDN/full), совпадает ли фаза с `config.layer_types`?
5. **Ранг слой-перехода.** $\mathrm{rank}(D_l)$ эффективный: где бутылочные горлышки в глубине? Связь с PR-кривой (Exp 14).

### Блок B. Gauge-геометрия (наша уникальная конструкция)
6. **Gauge-связность и голономия.** Параллельный перенос чувствительного направления через слои с помощью $P(p_l) = \mathrm{diag}(p_l) - p_l p_l^T$: кривизна $F$, голономия вдоль глубины. Предсказание: gap(l_L, l_S) коррелирует с накопленной голономией — **self-инвариант без кросс-модельных вычислений**.
7. **Прецессия gauge-направления.** $\cos(v_g(l), v_g(l+1))$ по глубине: где gauge «переключается», есть ли фазовые границы.
8. **Gauge как векторное поле.** Интегральные кривые поля $v_g(h)$: совпадают ли с направлением роста уверенности (Exp 10d)?

### Блок C. Листовая (trajectory) структура — поле расслоено, копаем дальше
9. **Профиль $C(\Delta \mathrm{pos})$.** Измеряли только соседние пары $(S{-}2, S{-}1)$. Нужна полная корреляционная функция по расстоянию внутри документа: экспоненциальный распад? Степенной закон? Длина корреляции по слоям?
10. **Слияние листов.** На L22 был пик $C_b = 0.30$ (code). Тест: бимодальность = часть пар «слилась» в один лист, остальные — ортогональны? Матрица пар + пермутационный тест «слитые vs мёртвые».
11. **Касательная vs чувствительность.** $\cos(\Delta h_t / \Delta t,\ \text{топ-сингулярные направления } J)$: движется ли траектория вдоль «плоских» направлений поля? Это объяснило бы $C_a$ механически, а не феноменологически.
12. **Границы чанков GDN.** Их собственная непроверенная гипотеза из оговорок §13: разрывы J с периодом длины чанка. Только наш аппарат (deepclone GDN-кэша) вообще может это увидеть.
13. **Особые позиции.** BOS, attention-sink позиции, позиции пунктуации: аномалии нормы/направления J?
14. **Горячие точки.** Распределение $\|J^{(p)}_t\|$ вдоль траектории: тяжёлый хвост = редкие «чувствительные позиции» (факты? имена? числа?).

### Блок D. Токенная структура (строки J — почти не копали!)
15. **Функциональный токенизатор.** Кластеризация токенов по строкам J / по eigenvectors ESG в токенном пространстве. Группы токенов, которые модель различает синхронно — это «модельный токенизатор», не совпадающий с BPE.
16. **Чувствительность vs частота.** Закон Ципфа для $\|J[i]\|$: держится ли? Отклонения = семантически «специальные» токены.
17. **Per-token разложение gap.** Какие токены несут bridge-разрыв (sensitivity debt): редкие? длинные? из конкретных доменов? Это карта для целевой защиты при квантовании.
18. **Хвостовой сигнал.** Exp 11c: bridge чувствителен к low-prob токенам вне top-K. Расширить $\mathcal{U}$ до top-p = 0.999 и построить карту «где живёт разрыв».

### Блок E. Условная структура сэмплов (стратификация)
19. **Энтропийные фазы.** reff ~ H уже есть (T8): есть ли кластеры в плоскости (H, reff, σ)? «Фазы уверенности»?
20. **Детектор мемоизации.** Кросс-сэмпловые J почти всегда ортогональны ($C_b \sim 0.003$–0.05) — значит **любая аномально когерентная кросс-сэмпловая пара** — красный флаг: мемоизированный/дублированный текст, contamination. Мёртвый результат (нет доменной оси) превращается в инструмент аудита данных.
21. **Ковариаты: длина, язык, форматирование, loss.** Чужие сэмплы (высокий loss) — выбросы J?

### Блок F. Межмодельная структура
22. **Интерполяция скрытых состояний.** $h(\alpha)$ по пути от $h_S$ к спроецированному $h_L$, J вдоль пути: барьеры/сингулярности. Mode connectivity **в activation space**, а не в weight space — дёшево и ново.
23. **Масштабные законы J-статистик.** Trace ~ $D^\gamma$? Предсказание bridge для 8B/32B без запуска.
24. **Не́рерывное сопоставление глубин.** Не якоря, а оптимальное непрерывное отображение $l_S = f(l_L)$ минимизирующее gap — «геодезическая» между моделями.

### Блок G. Функциональная (управляющая) структура
25. **J как контроллер (closed-loop).** $h \leftarrow h + \varepsilon \cdot (J^{(p)})^T e_i$ → проверяем реальный рост $p_i$. Доля успехов = функциональный ранг Якобиана: несёт ли J управляющую информацию, а не только диагностическую.
26. **Сравнение со steering-векторами.** Правые сингулярные векторы $J^{(p)}$ vs активационные steering ( refusal / style / язык): эффективность направлений.
27. **Спайковость J.** $\max_{ij} |J_{ij}|$ vs типичное значение: тяжёлые хвосты = локализованные «фактические» связи (сцепка с 20).

### Блок H. Топологическая/многомасштабная (exploratory)
28. **Персистентная гомология** поля нормы J вдоль траектории. Дорого, но уникально.
29. **Мультимасштабность «снизу».** $C(\delta)$ при $\delta \ll \sigma_d$ (микропертурбации внутри позиции): локальная размерность поля, куски/изломы — kill-switch Exp 0.1 проверял только $\delta \sim \sigma_d$.

## 3. Что я готов защищать лично

**Пик 1 — Ляпунов-спектр (№1).** Это, на мой взгляд, первое, что стоит сделать, по трём причинам. (а) У вас есть главный подтверждённый факт без механизма: gap монотонно падает (Exp 2, 4, 10b), SNR растёт в 26× (Exp 14), PR немонотонен — всё это кричит, что глубина организует чувствительность динамически, но *как* — неизвестно. Спектр Ляпунова — канонический язык для этого. (б) Он недоступен конкурентам: CKA/KL видят активации, а не tangent maps; у вас autograd-инфраструктура уже написана и провалидирована (Exp 1 identity). (в) Чистый фальсифицируемый прогноз: если расхождение спектров 4B/0.8B коррелирует с gap(l) — мост получает механистическую теорию; если нет — мы узнаём, что мост измеряет принципиально иное, чем динамическая устойчивость, и это тоже сильный результат. Плюс замечу про стоимость: полный D_l (1024×1024) не нужен — QR-Бенеттину нужны только vjp на ортонормированных наборах векторов, это k≪D обратных проходов на слой.

**Пик 2 — Мемоизация-детектор (№20).** Самое дешёвое из высокоприоритетных и с немедленной внешней ценностью. Логика переворачивает негатив: доменной оси нет — значит, кросс-сэмпловая когерентность концентрирована у нуля с известным шумовым полом F; любая пара с C ≫ F — аномалия. Проверяемо за один вечер на существующем кэше: известные мемоизированные тексты (телефонные номера, стихи, GPL-код в датасетах) должны давать пары-выбросы. Это превращает три «inconclusive» подряд в утилиту для аудита contamination — то есть публикационная история «мы ничего не нашли» превращается в «мы построили детектор».

**Пик 3 — Gauge-голономия (№6).** Самое рискованное и самое «наше». Gauge-направление — ваша единственная по-настоящему оригинальная конструкция (uniformity, сигнал уверенности, немонотонная доля). Если транспорт через P(p_l) имеет нетривиальную голономию вдоль глубины, вы получаете **один скаляр на слой**, предсказывающий кросс-модельный gap *без кросс-модельных вычислений* — то есть диагностику, которую можно считать на одной модели. Проверка дешёвая (0.8B, один forward-градиентный прогон на слой). Риск: P(p) не ортогональный проектор, транспорт не сохраняет норму — придётся аккуратно определить связность (см. математику ниже). Но даже отрицательный результат структурирует §gauge полностью.

Если выбирать порядок: №1 → №20 → №2 (многоточечный мост, это же ваш заявленный next step) → №6. №3 как фоновый.

## 4. Какой математики не хватает

1. **Слой-переходный Якобиан и композиция.** Формальное определение $D_l = \partial h^{l+1}/\partial h^l$, правило композиции $J_l = W \prod_{i \geq l} D_i$, и — критично — учёт RMSNorm: производная RMSNorm не ортогональна и масштаб-зависима, нужен explicit вид или соглашение (работать ли с «сырыми» D_l или с центрированными/gauge-free). И отдельно: для GDN-слоёв D_l должен включать recurrent/conv state — нужно определение расширенного tangent map (или осознанное ограничение hidden-only блоком).
2. **Конечно-глубинные показатели Ляпунова.** Нормировка (на 1? на число слоёв в продукте?), устойчивость в float32, сходимость QR при n = 24–32 слоям (это мало — формально это не asymptotic Ляпунов, а finite-time FTLE; нужно определение и оговорки).
3. **Gauge-связность для неортогонального проектора.** P(p) — ковариационный оператор, не проектор в строгом смысле: перенос через него не сохраняет норму и не идемпотентен. Нужна конструкция: либо нормированный транспорт с явной записью сжатия как части связности, либо регуляризованный ортогональный транспорт + определение кривизны/голономии для этого случая.
4. **Нуль-модель для outlier-детекции.** Распределение максимума попарной когерентности при шумовом поле F (extreme value theory), поправка на множественные сравнения по ~496 парам — у вас есть пермутационный и spectral null, нужна их формализация именно как нуль для max-статистики.
5. **Per-token разложение bridge.** Формальное определение взвешенного per-token gap с масками §1.6 (половина там есть) + доверительные границы на уровне строк — сейчас sentinel-проблема (§6 Exp 13) маскирует ранние слои, и per-token анализ без границ будет переинтерпретировать шум.
6. (Опционально) формальное определение «листа» — кластер траекторий/точек с внутренней когерентностью J — чтобы №2, №10, №11 опирались на термин, а не на метафору.

Если дополните математику пунктами 1–3, я бы сразу расписал дизайн Exp 20 (Ляпунов) и Exp 21 (голономия) — там вопросы реализации (GDN-расширенный tangent map, QR на T4) уже можно продумывать.
