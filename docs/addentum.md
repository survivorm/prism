# 1. Сцена: тюрьма, коридор, доска, надзиратель

Это только сцена, не онтология.

- **Камеры** — блоки трансформера.
- **Личные мастерские** — скрытые вычисления MLP.
- **Коридор / доска** — residual stream `h_l^t`.
- **Адресная шина** — attention / KV / GDN-state.
- **Надзиратель** — loss.
- **Наказание** — градиент.
- **Карта наказуемости** — Якобиан `J_l^t`.

Важная поправка: надзиратель не коллективный.

Backprop не наказывает всех поровну. Он даёт маржинальную атрибуцию:

\[
\frac{\partial \mathcal L}{\partial h_l^t}
=
\underbrace{
\left(J_l^t\right)^\top
\frac{\partial \mathcal L}{\partial z_t}
}_{\text{за текущий ответ}}
+
\underbrace{
\sum_{s>t}
\left(
\frac{\partial h^s}{\partial h_l^t}
\right)^\top
\frac{\partial \mathcal L}{\partial h^s}
}_{\text{за будущие ответы}}.
\]

Отсюда центральный вопрос:

> Есть ли направления, которые текущий `J` почти не видит, но будущие позиции видят хорошо?

Операционально:

> **Мышление** — состояние, которое не обязано менять текущий ответ, но меняет будущие ответы.

Никаких утверждений о сознании.

# 2. Объекты и запреты

## 2.1. Объекты

- `h_l^t ∈ R^D` — residual stream.
- `n_l^t = RMSNorm(h_l^t)` — вход следующего блока.
- `Δ_l^t = h_{l+1}^t − h_l^t` — запись слоя.
- `x_t = argmax W n(h_L^t)` — внешняя токенная проекция.
- `J_l^t = ∂z_t / ∂h_l^t` — текущая видимость.
- `v_t` — V-тангенс, ортогонализованное приращение направления.
- `ρ̄(k)` — per-doc moment ACF тангенсов.
- `Δ_med(k)` — медиана косинусов тангенсов.
- `d_t = h_{t+1} − h_t` — сырое приращение состояния, отдельный объект.

## 2.2. Запреты

1. **Медиана не сохраняет линейные тождества.**  
   `Σρ̄(k)` нельзя подменять `ΣΔ_med(k)`.

2. **Число без объекта и агрегатора не публикуется.**  
   “dip = −0.1” без `V/raw/emb`, `mean/median`, `per-doc/pooled` — не число.

3. **RMSNorm не временной DC-block.**  
   Он нормирует позицию, не время.

4. **Глубина — не время.**  
   Плоскость величины по слоям не есть сохранение во времени.

5. **λ-интерполяция весов — не траектория обучения.**  
   Порог на прямой в пространстве весов не есть фазовый переход SGD.

6. **`ker J` не использовать, если ядра нет.**  
   `U_obs` полноранговая; речь о слабо наблюдаемых направлениях.

7. **Послойный профиль без контроля типа слоя не есть профиль по глубине.**  
   GDN/full-attention чередование — конфаунд.

8. **LFM3 cross-model числа отозваны до собственного энкодера.**  
   Qwen-id, поданные LFM3, — правдоподобный мусор.

9. **Random weights × own garbage не доказывает “выученность представления”.**  
   Это доказывает только trained-conditioned различие в текущей клетке.  
   Факторизация `weights × text` должна быть явно указана.

10. **Квантоподобные тесты E-67 не являются теориями.**
    CHSH на ко-измеренных бинаризациях тождественно даёт `|S|≤2`.
    g₂ в текущей конструкции — лаг-1 автоковариация интенсивности, не оптический g₂.

11. **Блочная лестница null'ов без исключения швов не измеряет масштаб.**
    При блоке b доля испорченных соседних пар = 1/b (разбавление), а masked-вариант —
    детерминированный позиционный подотбор (обязателен control: случайный подотбор
    того же размера из нешаффленной). Масштаб сверх локальности измеряется суррогатом
    (R9-6), не лестницей.

12. **Собственная генерация без template не считается «естественным письмом»** (v1 §9.1).

13. **Численный гейт без человекочитаемой выборки не подтверждает теорию** (v1 §9.1).

# 3. Теории

## T0. Гейт-арбитр: учёт мощности, не источник дипа

**Статус:** обязательный арбитр (учётный гейт), не объяснение. «Ограниченный коридор» — **описание, не ограничение** — пока не измерен `r_max < 1` per-doc (G4).

**(G1) Грам-инвариант — точно, без стационарности, для любого объекта**
(`x_t` — приращение Δh, Δu или v̂; `N = T_states − 1`):

\[
r \equiv \frac{\lVert \sum_t x_t\rVert^2}{c(0)} = 1 + 2\sum_{k\ge1}\hat\rho(k),\qquad
c(0)=\sum_t\lVert x_t\rVert^2,\ \ \hat\rho(k)=\frac{\sum_{t}\langle x_t,x_{t+k}\rangle}{c(0)}.
\]

**(G3)** `r = N·f_DC` — это ровно DC-доля, ничего больше; «sum-rule» — утверждение о среднем
приращении, а не о памяти. **(G5)** Плато в `ρ̄(v̂)` разрешено: `‖Σ v̂_t‖ ≤ N` ⇒
`Σρ̂ ≤ (N−1)/2` — никакого противоречия с ограниченностью единичного пути (нормировка убивает телескоп).

**(G4) Где у T0 есть зубы:** для Δu `r = ‖u_N−u_0‖²/Σ‖Δu‖² ≤ 4/Σ‖Δu‖² ≡ r_max`;
ограничение что-то запрещает **только если `r_max < 1`** (rms-хорда > 2/√N ≈ 0.102 рад при N=384;
измеренный шаг ≈ 0.10 рад — T0 стоит ровно на границе вырожденности, решается измерением, не спором).
Для Δh и v̂ числитель не ограничен ⇒ зубов нет вообще.

Контрпример к равенству: путь ограничен, а приращения белые по окружности — тогда
`S_v(0)=1`, а не 0. Ограниченность пути влечёт только неотрицательность спектральной
плотности, а не подавление низких частот. Равенство `S_v(0)=0` — дополнительная гипотеза,
не следствие ограниченности.

**(G7)** `r` и `Σρ̂` инвариантны к любой перестановке приращений ⇒ тест
«Σ_real против полосы permutation-суррогатов» вырожден тождественно (real всегда точно в центре
полосы); null-тест строится на **форме** профиля при фиксированной сумме.

**Что T0 обязана делать:**

- проверять per-doc `ρ̄`, не медиану; плюс грам-учёт `r = 1+2Σρ̂` (G1);
- измерять `r_max` и декларировать статус арбитра **per-doc** (G4);
- проверять распределение площади по лагам при фиксированной сумме (форма, G7);
- требовать от любой механистической теории воспроизвести этот учёт;
- не объяснять дип сама по себе.

**Что T0 не делает:**

- не выводит дип из сферы;
- не объявляет RMSNorm DC-block;
- не заменяет механистическую теорию.

**Разводящая клетка 3×2** `{R0, R1, R2} × {real, mix}` (R1 = random trunk + trained tied embed+head),
измерять `r`, `f_DC`, форму профиля — не дип (сумма инвариантна к перестановкам, G7;
дип поодиночке гипотезы не различает):

- trained × real: правило держится (e64-gpu вердикт, ACF-учёт sum≈0);
- random × real: не держится (dip 4e-6, полоса ±4e-5);
- trained × mix: dip гаснет до 0.2×;
- random × mix: 4 CPU-форварда. Состояние: R9-2 (exp91) готов, в очереди
  (два запуска умерли от голода памяти).

**Сумма на опубликованной кривой.** Опубликованная corpus-строка — `dip_raw,mean`
(сырые приращения состояния, среднее); ярлык `Δ_med` ошибочен (подмена объекта). Её
Σ_{k≥2} ≈ +5.6 **не противоречит ничему**: по (G1) это `r ≈ 1+2Σρ̂ ≈ 10–12`, т.е.
`f_DC ≈ 3 %` — измерение когерентного дрейфа, не парадокс. Медианный ряд (Δ_med) ломает линейные
тождества (Σρ ≈ +1.8 на пуле медиан) — ровно Запрет 1: правило определено только на per-doc
моментном `ρ̄`; пересчёт — R9-14 (в очереди). До него T0 не утверждается и не
хоронится: она не определена на измеряемом объекте.

**LADDER_V2 фиксирует границу локальности для `Δ_med`:**

| blk | masked / real |
|---:|---:|
| 2 | 0.740 |
| 4 | 0.892 |
| 8 | 0.934 |
| 16 | 0.989 |
| 32 | 1.004 |
| 64 | 0.997 |

Чтение (R9-1, 11.11, results/e90/LADDER_V2.json):

- шовный конфаунд реален: unmasked-лестница = разбавление (1−1/b), совпадение в пределах 0.005 по всем шести ступеням (B1 подтверждён);
- masked-вариант **тоже не мера масштаба**: это детерминированный позиционный подотбор (blk=2 — чётные лаги), masked ≠ control (случайный подотбор того же размера из нешаффленной);
- «масштаб 2–4 токена» мёртв; сходимость masked 0.989@blk16 — нижняя граница для дипа, не масштаб носителя;
- seam_delta blk2 = −0.0042 [−0.0083, −0.0032] формально ≠ 0 — вероятный Грам–Шмидт-артефакт на разрывах, синтетическая проверка в списке ревью;
- горб/плато masked-лестницей не измеримы (нет пар k ≥ blk);
- вопрос масштаба сверх локальности переехал в R9-6 (surrogate VAR) целиком.

**Фальсификация T0 как объяснения:**  
если она заявляет равенство `S_v(0)=0`, а per-doc `ρ̄` даёт устойчиво положительную низкочастотную мощность.

**Подтверждение T0 как арбитра:**  
если все принятые механистические теории воспроизводят per-doc учёт мощности, форму распределения площади при фиксированной сумме и R/A-split.

## T1. Канал с памятью: сжатие, ошибка, буфер

**Статус:** инженерная теория сжатия + гипотеза KV-буфера.

В базовой недеквантованной модели **нет внутреннего квантователя коридора**.  
Единственная жёсткая проекция — эмиссия токена наружу:

\[
x_t = \arg\max W n(h_L^t).
\]

Поэтому T1 разделяется.

### T1a. Теория сжатия

Если канал квантуется, ущерб определяется не только нормой ошибки, а:

- корреляционной структурой ошибки;
- динамическим диапазоном;
- обнулением малых компонент;
- SNR в функциональных подпространствах.

Квантователь с буфером ошибки:

\[
q_t = Q(h_t + b_{t-1}),
\]
\[
b_t = h_t + b_{t-1} - q_t.
\]

Тогда:

\[
q_t - h_t = b_{t-1} - b_t,
\]
\[
\sum_{t=1}^T(q_t-h_t)=b_0-b_T.
\]

Если буфер ограничен, средняя ошибка телескопируется, а не накапливается как случайное блуждание.

Дизер:

\[
q_t = Q(h_t+d_t)-d_t
\]

при известных условиях делает ошибку статистически независимой от сигнала.

**Уже прогнанный дизер (опора T1a):** T-сэмплинг — дизер токенного канала.
Он убивает коррелированное искажение квантователя (лупы: rep16 0.43→0.001,
hit 0.61→0.10), не трогая сигнал (поле T-инвариантно, e64-gpu). Это подпись
dизера в чистом виде. Дешёвое следствие: дизер h-канала (малый шум перед
RMSNorm при инференсе) должен защищать ритм под квантованием весов (per-group W4
vs per-tensor W8 × {с дизером, без}) — CPU, не требуется для вердикта T1.
Две уточнения: subtractive dither на **весах** ставит веса вне сетки — это механизм-проба,
не deployable квантование (контроль — off-grid шум той же нормы); error feedback
**на весах не существует** (временной механизм: буфер между шагами) — клетка C2 переносится
на канал активаций.

**Successive refinement vs multiple description:**

- token + residual error — successive refinement;
- token + independent raw — multiple description, с штрафом за избыточность.

Остальные механизмы v1-списка для постоянно переквантуемого канала (noise shaping,
residual coding) остаются инструментами сжатия и в теорию T1 не входят.

### T1b. KV как буфер остатка

Гипотеза:

> Токен — внешний регенерирующий повторитель.  
> KV / GDN-state несёт остаток, который не вошёл в текущий токен, но нужен будущим позициям.

Это не доказано.

**Граница:**
буфер должен быть видим будущему и адресуем.
Композиция T1×T2 (правильная): буфер пишется в направления с **высоким** `O_H^fut`
(они обязаны быть видны будущему), а не «невидимые настоящему» — это разные условия,
которые пересекаются, но не совпадают. Штраф за текущий лосс не запрещает использование
направления, он калибрует величину. Корреляция «буфер ↔ слабо-J» — отдельная
проверяемая гипотеза, не логическое следствие.

**Фальсификация T1a:**  
если после matching по subspace SNR и структуре ошибки ущерб всё равно объясняется только полной нормой.

**Фальсификация T1b:**  
если остаток не адресуется будущими позициями или не отличается от обычного контекстного состояния.

## T2. Невидимый коридор: слабо наблюдаемое будущее-состояние

**Статус:** центральная механистическая гипотеза.

Текущая видимость:

\[
J_l^t=\frac{\partial z_t}{\partial h_l^t}.
\]

Будущая наблюдаемость:

\[
O_H^{fut}(l,t)
=
\sum_{k=1}^{H}
\left(
\frac{\partial z_{t+k}}{\partial h_l^t}
\right)^\top
P_{t+k}
\left(
\frac{\partial z_{t+k}}{\partial h_l^t}
\right),
\]

где `P_{t+k}` — явная метрика в логитовом пространстве, например softmax/Fisher-метрика.

Текущая метрика:

\[
C_l^t = (J_l^t)^\top P_t J_l^t.
\]

Скретчпад — не пороговое множество, а обобщённая задача:

\[
O_H^{fut} v
=
\lambda
\left(C_l^t+\varepsilon I\right)v.
\]

Большие `λ` = направления, слабо видимые текущему ответу, но сильно видимые будущему.

**Важно:** такие направления существуют всегда.  
Теория должна предсказывать спектр, устойчивость и функциональную адресуемость, а не существование.

**Null (до любых утверждений о черновике):** random weights × real text teacher-forced —
измерить спектр `O_H^fut (C_l^t + εI)^{-1}` на случайных весах. Если спектр такой же, как
у обученных, T2 — свойство архитектуры, не обучения. Важно: полный random × *собственная*
мусорная генерация — не тот null (dip=0 там по построению оценщика, конфаунд «вход стал
мусором», Запрет 9). Состояние: клетки R9-2 (exp91: trained/random/half-random × corpus/shuffled,
вердиктная клетка half-random) готовы, в очереди.

Три альтернативы:

1. **Скретчпад:** патч меняет будущее, не текущее.
2. **Мёртвый груз:** патч не меняет ничего.
3. **Редундантная запись:** патч меняет текущее и будущее одинаково.

**Границы:**

- `ε` обязателен: `U_obs` полноранговая (ядра нет), но `r_eff^U(0.05)=178` ⇒ нижние ~800
  направлений численно нулевые, и отношение взрывается на шуме; отчёт по `ε` обязателен;
- архитектурный нуль (A1): `O_H^fut(l = L_max) ≡ 0` — `h_{L_max}^t` входит только в голову
  позиции t, слоя выше нет ⇒ **T2 живёт только при `l ≤ L_max−1`**; L23-числа
  (E-76 v4 `stab_half` 0.49, E-79) — объекты **текущей** видимости, не будущего;
  L23 допустима только как positive-control нуль (G9);
- сравнение по слоям требует транспорта базиса (язык T5);
- «выученность» не заявляется без факторизации weights × text;
- нить_Г не тождественна скретчпаду: она схлопывается в нуль на случайных весах
  (0.003–0.005 = null) ⇒ она про токен (текстовая согласованность соседних шагов),
  не про архитектуру. Разводящая клетка (офлайн): `cos(нить_Г, слабо-J)` — выровнен =
  черновик; ортогонален = текстовая согласованность. Пока клетка не прогнана, T2-бис
  («ток записи-чтения») — слот, не подтверждение.

**Нулевой шаг (до связи λ₁ ↔ дип):** привести дип к единому определению, затем разложить
тангенсы по плоскости λ₁ оператора шага и её дополнению и посчитать вклад каждой части
в лаг-1 корреляцию + matched-null. Пока два разных объекта (тангенс+медиана vs сырое
приращение+среднее) не сведены, связка «λ₁ ↔ дип» не заявляется — это ровно ошибка О2.

**Фальсификация:**  
слабо-J направления не предсказывают будущее лучше PCA/Haar той же размерности; патч не даёт future-only эффекта; спектр не устойчив; null-спектр random×real совпадает с обученным.

**Подтверждение:**  
устойчивый спектр `λ`, future-only каузальный эффект, адресуемость будущими позициями.

## T3. Кусочно-гладкая карта решений

**Статус:** локальная механистическая теория.

Argmax разбивает пространство на ячейки.

В `n`-пространстве:

\[
C_i=\{n:(w_i-w_j)^\top n\ge0\;\forall j\}.
\]

В `h`-пространстве ячейки argmax — **точные полиэдральные конусы** (голова без bias:
`z = √D·W̃h/‖h‖`, `W̃ = diag(g)W`); «искривлённость из-за RMSNorm» изъята — анизотропия
условна на `g` и проверяется по весам чекпоинта.

Внутри ячейки токен фиксирован:

\[
x_t=i,\qquad h_{t+1}=F_i(h_t,KV_t).
\]

Направление шага локально по суффиксу:

\[
d(h_t)\approx f(x_{t-k+1:t}).
\]

P1 даёт:

- `k50≈2`;
- `k90≈12–16`;
- состояние несёт более длинный контекст, но он не весь входит в направление шага.

LADDER_V2 добавляет **зерно карты**:

\[
K(d)=\mathbb E[\cos(\text{шаги})\mid \text{локальная порча контекста глубины }d].
\]

Маска seam-exclusion показывает (с оговоркой R9-1: masked ≠ control, это позиционный подотбор):

- `blk2` не восстанавливает real;
- `blk16` почти восстанавливает;
- есть аномалия чётности / лага-2 (seam_delta blk2 формально ≠ 0, см. T0).

**Margin/flip-версия:**

Близость к границе:

\[
m_t=z_{top1}-z_{top2}.
\]

Гипотеза:

> дип концентрируется в позициях малой margin / высокой flip-rate.

Это не “отражение” в teacher-forced.  
Это кусочная гладкость и переключение карты.

**Происхождение T-тренда (проверено):** старый B4 T-тренд дипа (−0.071→−0.111, +56%)
взят из B4 T-таблицы, чей код потерян — не воспроизводимо. Исправленный e64-gpu
(sha_gen TRUE, побитовый эталон): поле T-инвариантно — med −0.159/−0.165/−0.156
при rep16 0.0→0.067→0.0. T-инвариантность убивает только версию “дип = свойство
жадной политики” (закрыто P2: hit/con/mix дают одну кривую), но не boundary-версию:
при T>0 траектория всё равно проходит через границы ячеек (просто другие).

**Граница:**

- “масштаб 2–4” для дипа отозван; для направления карты `k50=2` остаётся;
- margin-факты (e64-gpu): p1~lookup +0.78, margin~dip −0.24 — канал уверенности,
  не унификатор; нужен количественный фальсификатор “дип коррелирует с 1/margin”.

**Измеренные якоря символического графа ячеек:**

- e83 K(1)=0.958 (own-генерация) — фикс-точка внутри ячейки (период-1);
- флип-мода (λ₁ ≈ −0.92, L1/L11, с оговоркой неустойчивости оценщика — §9) —
  линейзация периода-2 орбиты через границу;
- корпусное анти-эхо k=1..3 = −0.0078/−0.0077/−0.0049 (L4-канон, rng99) —
  отсутствие циклов в графе на чтении.

**Фальсификация:**  
дип не связан с margin/flip; суффиксная модель не предсказывает направление OOS; зерно карты не воспроизводит masked-лестницу.

**Подтверждение:**  
margin-условный дип, суффиксная предсказуемость, символический граф ячеек объясняет лупы и зерно.

## T4. Протокол чтения vs содержание

**Статус:** сильная феноменология с механистическим долгом.

Каналы:

- `R` — ритм / протокол чтения;
- `P` — семантика / содержание.

Но они не обязательно аддитивны.

Канонический split:

\[
h=s+r.
\]

Для raw-dot функционала:

\[
R(k)=\langle x_t,x_{t+k}\rangle,
\]

кросс-член:

\[
C(k)=
\langle s_t,r_{t+k}\rangle
+
\langle r_t,s_{t+k}\rangle.
\]

Для cos-метрики добавляется нелинейность нормировки.

**Фальсификаторы:**

1. `C≈0` при каноническом split ⇒ неаддитивность — артефакт split.
2. `C≈0` в raw-dot, но есть в cos ⇒ нелинейность в метрике, не в карте.
3. Ритм после лечения становится константой на чистых текстах ⇒ возврат в полосу, не канал.
4. Всё объясняется loopy-rate ⇒ двухканальность не нужна.

**Здоровье — луч, не ось:**

\[
\mathcal H=(dip,\;loopy,\;nll).
\]

Углубление dip может быть патологией.  
Signed-dip loss опасен.

**Граница:**  
E-69c: обещанный rep16-прокси не считался нигде в коде (терапия не может отличить
“ритм вылечился” от “лупы убрали” — единственную альтернативу, которую §30 обязал
исключать); healthy_anchor взята из другой агрегации (медиана по 12 vs среднее по 8) —
исправлено в коде; evalm считал nll на тренировочных доках; lesion MLP / therapy attention
— одна клетка, не полная 2×2. Состояние: R9-13 (holdout + healthy-LoRA) и 2×2 (P2-18)
в очереди. Частичное спасение: ритм после лечения различает тексты (свои лупы vs чистые,
E-69b), но это снова ось лупов; нужна дискриминация между чистыми чужими текстами разных типов.
Теория не утверждает независимые подсистемы.

**Функциональный вопрос (открыт, не тестирован):** делает ли reading субстрат ICL?
Гипотеза: reading-субстрат — необходимое условие ICL; модель с тем же ритмом, но
сломанным семантическим каналом, должна хуже решать ICL. Это связь T4 с capability;
без неё “ритм = протокол чтения” — описание, а не функция.

## T5. Слойная калибровка / shared profile

**Статус:** слабая форма жива, сильная форма не доказана.

После P4 (Qwen):

- own cross-layer ≈ 0.93–0.97;
- correct xdoc control ≈ 0.80;
- excess ≈ +0.13–0.17.

Это:

> почти-универсальный профиль + тонкий документный остаток.

Не “форма без документа”.

**Двусоставность (обязательна):** документный остаток модель-специфичен. На LFM3:
own 0.971, xdoc-контроль 0.927, избыток +0.04 (профиль глобальный), cross-model 0.846
(последнее — до собственного энкодера, Запрет 8). Т.е. “избыток” — не универсальная
константа 0.13–0.17, а модель-зависимая величина (+0.13–0.17 у Qwen, +0.04 у LFM3);
в одной форме T5 на второй архитектуре уже не выполняется.

Сильная форма:

\[
M_L \approx R_L M_0 R_L^\top.
\]

Ортогональное сопряжение сохраняет характеристический многочлен для любой `M`:

\[
\det(RMR^\top-\lambda I)=\det(M-\lambda I).
\]

Сингулярные значения тоже сохраняются при `R∈O(D)`.

Симметризация не нужна и вредна: она убивает антисимметричную часть.

Но приближённое сопряжение требует устойчивости спектра:

\[
\max|\Delta\lambda|
\lesssim
\kappa(M)\frac{\|\delta\|}{\|M\|},
\]

где `κ(M)` — обусловленность собственных векторов.

T5 разделяется:

- **T5a:** спектр инвариантен по глубине.
- **T5b:** базис поворачивается ортогонально.

Они независимы. T5b может провалиться при верной T5a.

**Границы:**

- контроль типа слоя обязателен (запрет 7); пары (L, L+1) обоих типов на 3 глубинах —
  дизайн (docs/dynamic/2-8.md §2.4), не выполнен; до него любой “профиль по глубине”
  (в т.ч. U-форма) — потенциально чередование full/linear-attention, а не глубина;
- LFM3 cross-model числа отозваны;
- random-weights опора: 0.49 против trained 0.97 (контроль 0.07) — половина слойной
  инвариантности архитектурный скелет, половина выучена (количественная форма слабой версии);
- корреляция профилей не есть спектральная инвариантность.

**Фальсификация:**  
собственные значения дрейфуют; профиль объясняется типом слоя; нет OOS переноса оператора.

**Подтверждение:**  
спектр стабилен, базисные углы ведут себя как калибровочные вращения, held-out слой предсказывается.

## T6. Routing: режим как приор, не компетенция

**Статус:** поведенческая теория с операциональной опорой.

Маршруты чтения `r`, качество на длине `L`:

\[
a_r(L)=P(\text{hit}\mid r,L).
\]

Режим задаёт приор:

\[
\pi_m(r).
\]

Тогда:

\[
P(\text{hit}\mid L,m)=\sum_r \pi_m(r)a_r(L).
\]

AT-режим меняет `π`, не `a`.

**Композиция T6×T2:** если AT чинит routing, а routing живёт в скретчпаде (T2), то
AT должен увеличивать размерность активного скретчпада (спектр `O_H^fut (C+εI)^{-1}`
на AT-пулах). Это связывает поведенческий и механистический уровни. Проверяемо на
существующих npz (AT-пулы gen_AT_C1..C5). Не проверено.

Опора:

- 32k: BASE теряет роль детерминированно;
- G1/C1 держат её;
- G1≡C1: лёгкая раскачка достаточна;
- nudge вредит на потолке.

Но:

> “nudge добавляет дисперсию приору” — гипотеза.  
> Он может содержательно ломать адресацию.

**Границы:**

- filler = повторы своего текста, не diverse corpus;
- random-length prefix не проверен;
- C-controls на 32k не закрыты;
- teacher-K substitution не доказан.

**Фальсификация:**  
AT улучшает компетенцию везде; случайный префикс той же длины даёт тот же эффект; shuffled control работает; diverse filler убивает эффект; teacher-K и AT строго аддитивны.

**Подтверждение:**  
режим спасает роль на потолке, локальное поле не меняется, teacher-K замещает режим
(количественная форма v1: `AT+K ≈ max(AT,K)`).

## T7. Видимое мышление как отчёт

**Статус:** информационно-каузальная теория.

Токенный канал:

\[
x_t=Q(h_t).
\]

CoT — цепочка регенерирующих повторителей.  
Он сбрасывает дрейф, но проецирует состояние в конечный алфавит.

Rate-distortion сторона (v1 T7): скорость токенного канала ограничена,

\[
R_{\text{token}} \le \log |V|,
\]

а нюанс теряется в проекции:

\[
D = \mathbb E \lVert h - \hat h(x) \rVert^2_{\mathcal S},
\]

где `\mathcal S` — функционально релевантное подпространство.

Пусть:

- `X` — видимый токен-поток;
- `Z` — невидимое рабочее состояние;
- `Y` — финальный ответ.

**Sufficiency CoT:**

\[
Y \perp Z \mid X.
\]

Если патч `Z` при фиксированном `X` меняет `Y`, CoT не достаточен.

**Necessity CoT:**

Если патч `X` при фиксированном `Z` меняет `Y`, CoT необходим.

Обе ветки независимы.

**Граница:**  
любой патч конечной нормы может менять жадную генерацию.  
Без амплитудно-согласованного контроля положительный ответ не идентифицирует канал.

**Фальсификация:**  
видимый CoT — достаточная статистика ответа; невидимый патч ничего не меняет; continuous thought не даёт преимущества там, где теория предсказывает потерю нюансов.

**Подтверждение:**  
ответ меняется при невидимом патче с тем же CoT; continuous thought сохраняет нюансы; token CoT снижает дрейф, но теряет информацию.

## T8. Солитон / пороговое возбуждение

**Статус:** программа фальсификации, не теория.

Солитонные требования:

1. пороговое рождение;
2. локализация;
3. форма-инвариантность;
4. упругое восстановление;
5. квази-интеграл вдоль времени;
6. внутренняя мода.

Текущий пакет не принят (статус audit2 B2/B3, 11.11: понижен с «солитон родился»
до «пороговая нелинейность + робастность статистики», 0/5 по строгим критериям):

- λ-интерполяция — не время и не обучение (Запрет 5);
- перелёт dip на λ=0.7 (−0.207 глубже финального −0.174 на 19%) без nll/rep16 —
  nll вычислялся и выбрасывался из артефакта; «рождение» и «промежуточный вырожденный
  режим» неразличимы без него;
- «упругость» (E-71B) = медианы по текстам разной длины (~20% массы — повтор),
  т.е. разбавление, не восстановление формы после прохождения;
- 1-D-параметры (sd_r) обучались при λ=0 и рандомизируют только ndim≥2 — все RMSNorm
  gain остаются обученными, λ=0 ≠ from_config; один сид; resume по truthiness;
- Σc² по глубине не есть сохранение во времени;
- period-2 flip не есть бризер без локализации и внутренней частоты.

**Фальсификация:**  
все наблюдаемые включаются на одной λ; overshoot объясняется loopy; нет оконного восстановления; нет локализованной формы.

**Состояние:** R9-3 (random→random null интерполяции — нуль-полоса «рождения») и R9-4
(E-71 перепуск: dip/nll_med/rep16-прокси K_gen/eff-rank по λ, 3 сида, окно после вставки,
гейт ступенька/линейная) в очереди. Солитон остаётся гипотезой, только если порог dip
отделён от порогов остальных наблюдаемых.

## T9. Порядок возникновения канала при обучении

**Статус:** теоретический слот, требует траектории обучения.

Вопрос:

> Канал возникает раньше семантики, позже или вместе?

λ-интерполяция весов не отвечает на этот вопрос.  
Допустимый прокси — реальная fine-tune траектория, например LoRA-ladder, но это уже не интерполяция.

**Фальсификация:**  
порядок возникновения не воспроизводится на реальных шагах обучения; поле и семантика всегда возникают вместе.

**Подтверждение:**  
устойчивый порядок: поле на шаге N, семантика на шаге M, N≠M.

## T10. Корпусная зависимость / текстовая избыточность

**Статус:** теоретический слот, альтернатива архитектурному инварианту.

Гипотеза:

\[
\Delta_{\text{model}}(k)
\approx
F_{\text{model}}\big(\rho_{\text{text}}(k)\big).
\]

Форма кривой может быть считанной избыточностью текста, амплитуда — моделью/обучением.

Это объясняет:

- текстовую вызываемость;
- смерть mix-текста;
- почти-универсальность профиля;
- слабость документной магии.

**Граница:**  
если cross-model сходство выше cross-corpus — носитель модель;  
если cross-corpus выше cross-model — носитель текст.

LFM3 требует собственного энкодера.  
Qwen-id в LFM3 не является текстом.

**Фальсификация:**  
форма не следует за корпусной избыточностью; mix не убивает правило; cross-model сильнее cross-corpus.

**Подтверждение:**  
форма сдвигается с избыточностью корпуса, амплитуда — с моделью; mix ломает правило.

# 6. Минимальная формула аддентума

Не GUT, а скелет:

\[
\boxed{
\text{LLM}
=
\text{обученный читатель}
+
\text{ограниченный коридор}
+
\text{кусочная карта решений}
+
\text{слабо наблюдаемое будущее-состояние}
+
\text{routing-приоры}
+
\text{внешний токенный повторитель}
}
\]

В процессной форме:

\[
h_{t+1}
=
F_{\text{cell}(x_t)}
\big(
h_t,
KV_t,
b_t
\big),
\]

\[
x_t=Q(h_t),
\qquad
Y=f(X_{\text{visible}},Z_{\text{invisible}}).
\]

Но каждое слагаемое имеет статус:

- `обученный читатель` — trained-conditioned, не доказанная факторизация weights×text;
- `ограниченный коридор` — описание, не ограничение (пока не измерен `r_max<1` per-doc);
  T0 — учётный арбитр, не источник дипа;
- `кусочная карта` — T3, локальная гипотеза;
- `слабо наблюдаемое будущее-состояние` — T2, центральная гипотеза;
- `routing-приоры` — T6, поведенческая гипотеза;
- `токенный повторитель` — T7, информационная рамка.

**Связь (single-teacher)** — помеченная спекуляция, не вывод.
При единственном глобальном учителе и общем рабочем пространстве код ограничивает
мыслимое: нельзя выучить мысль, невыразимую в формате шины, потому что её не за что
научить. Один конкретный фальсификатор: если cross-model канал похожее на cross-corpus —
«единственный учитель» — фольклор; если нет — гипотеза жива. Не проверено
(cross-model требует собственного энкодера, Запрет 8).

# 10. Итоговая позиция

Аддентум v2 больше не пытается объяснить всё одной картинкой.

Он фиксирует:

1. **T0** — что обязано сходиться.
2. **T3** — где локально платится дип.
3. **T2** — где может жить будущее-состояние.
4. **T1** — как канал несёт ошибку и остаток.
5. **T4** — почему ритм и смысл расходятся.
6. **T5** — почему профиль почти универсален по слоям.
7. **T6** — почему режим чинит извлечение, не добавляя ума.
8. **T7** — почему видимое мышление видно, но не полно.
9. **T8/T9/T10** — что пока является программой, а не теорией.

Критический путь: **T0** (арбитр: все теории обязаны воспроизвести учёт) и **T2**
(центральная гипотеза с null'ом random × real). Остальное — либо производные, либо
проверки; приоритетный порядок: T0 → T2+null → T3 → T1 → T4 → T7 → T5 → T6.

Это честная теоретическая карта.  
ТЗ на эксперименты — следующий шаг.
