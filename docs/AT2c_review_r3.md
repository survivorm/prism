- **S7-формула:** 625 = Σ_k(128−k) = 128+127+126+124+120; 4×32×625×6 = 480000;

  клеток — верно.
- **Дерево/гейты/армы/смоки:** новых противоречий правками r2 не введено
  (структура r1/r2 уже сверена): pass-критерий §4 (weighted CI lower > 0,
  AND-over-l) идентичен конфигурации pre-run замера §11.0 (полный пул, LOO,

- **NIT (новый, необязательный) 1 — S10: `md5 лога` отсутствует в t=0 config.**
  AGENTS.md trackio (п.5): «config обязателен: `device`, `model`, `log`,
