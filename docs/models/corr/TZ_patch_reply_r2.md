## 1. А1 — принято, но `b_res = O(ε³)`, не `O(ε⁴)`

Разложение: `Δz = εJv + (ε²/2)H[v,v] + O(ε³)`, откуда

```
‖Δz‖² = ε²‖Jv‖² + ε³⟨Jv, H[v,v]⟩ + (ε⁴/4)‖H[v,v]‖² + O(ε⁵)
b_res = ε³⟨Jv, H[v,v]⟩ + O(ε⁴) = O(ε³)
```

`O(ε⁴)` — только если `⟨Jv, H[v,v]⟩ = 0`, а это проверяемое условие, не тождество: линейно-квадратичная связка в общем случае ненулевая.

Следствия (в текст ТЗ и теста):
1. Тест редукционного контроля: `b_res/(ε²σ₁²) → 0` при `ε → 0` (т.е. `o(ε²)`), **не** `O(ε⁴)` — иначе первое ненулевое ε³-слагаемое будет прочитано как баг редукции.
2. `⟨Jv, H[v,v]⟩` — самостоятельный измеримый объект (линейно-квадратичная связка) → обязательное signed-поле артефакта.
3. Ваш анализ первой степени (`b_res = O(ε)`, редукция мертва) — подтверждён; `b_mag := ‖Δz‖²` фиксирую как исправление протокола, строка в `paper.md` §9 — ок. Д2 (`unverified_b_mag`) — ок.

## 3. Б2 — принято, но фиксируем, какое тождество безусловное

- `κ_curv² = 2r − 2tr H` — верно для **любой** `H ∈ O(r)`, чистая алгебра: `‖H−I‖²_F = 2r − 2tr H`. Безусловное.
- `κ_curv² = 4Σⱼ(1 − cosθⱼ)` — требует `tr H = 2Σcosθⱼ`, т.е. парный спектр (чётное r, det +1, нет ±1 — ref-math §…). Условное.

Тест путей (а) vs (б) корректен только при выполнении спектрального условия; вне его путь (б) не определён. Признаю: в моём патче оговорка стояла на не том тождестве. Разведение `κ_curv`/`κ_cond` — принято, имена — в ref-math и в сигнатурах обоих модулей.
