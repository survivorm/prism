## 3. Точный текст по блокам — E-30

### 3.1. Цель (NEW)

> **Цель.** E-34 дал `ρ_gf ≈ 0.06` (абсолютно мало) и `ρ_gf/ρ_null = 0.98 (L6) → 3.61 (L23)`: по абсолютному порогу первый порядок диагонален, по относительному gauge-free cross-talk статистически отличим от нуль-модели начиная с L12. Открытый вопрос — **какая часть `ρ_gf` сидит в топ-2..5 модах ESG (структурный остаток), а какая — в хвосте (распределённый)?** Ответ определяет, идёт ли `ρ_gf/ρ_null` из readout второго порядка (E-32) или из распределённого первого порядка, где per-token защита в первом порядке частично сломана. Идеология: чистая линейная алгебра, без Гессиана. Если хвост мод несёт >50% `off²(A)`, «диагональность первого порядка» — артефакт агрегации, а не структура.

### 3.2. Математика (NEW)

> **Математика.** Объект `A = P(p)·ESG·P(p)`, `P = diag(p) − pp^T` (gauge-оператор §8, **не проектор**). Собственное разложение `ESG = Σ_k λ_k u_k u_k^T`, `λ_1 ≥ λ_2 ≥ …`. Для `r ∈ {1..K}`:
>
> - `ESG_r = Σ_{k≤r} λ_k u_k u_k^T` — топ-r усечение ESG;
> - `A_r = P·ESG_r·P` (усечение коммутирует с P);
> - `off²(r) = ‖A_r‖_F² − ‖diag(A_r)‖_F²`;
> - `ρ_gf(r) = √(off²(r)/(K−1)) / ‖diag(A_r)‖_F` (при `r=K` воспроизводит `ρ_gf` из E-34);
> - `Δoff²(r) = off²(r) − off²(r−1)`; `Δρ_gf(r) = ρ_gf(r) − ρ_gf(r−1)`;
> - `w_r = Δoff²(r) / off²(K)`; `PR_modes = (Σ_r w_r)² / Σ_r w_r² = 1 / Σ_r w_r²` (при `Σ w_r = 1`).
>
> **Нуль-модель per-r.** `diag(ESG_r)_i = Σ_{k≤r} λ_k u_k[i]²` меняется с `r`, поэтому `ρ_null(r) = E_Q[ρ(Q^T diag(ESG_r) Q)]` пересчитывается на каждом `r` (тот же batched-метод, что в E-34: 16 Q). Два режима отчёта: **абсолютный** (`ρ_gf(r)`) и **относительный** (`ρ_gf(r)/ρ_null(r)` — растёт ли сигнал быстрее нуль-модели с `r`).
>
> **Альтернативная декомпозиция (диагностическая).** Собственные моды `A` (не ESG): `A = Σ_j μ_j v_j v_j^T`, `A_j = Σ_{j'≤j} μ_j v_j v_j^T`. Даёт «чистую» модульную картину без P-смешивания; сравнение с ESG-версией показывает, насколько P перепутывает ESG-моды.
>
> **Alignment топ-мод.** `|⟨v_j, u_k⟩|` для `j,k ∈ {1..5}` — насколько топ-моды A совпадают с топ-модами ESG. Если топ-1 A-моды имеют низкий alignment с ESG-модами, P радикально перемешивает базис.

### 3.3. Подводные камни (NEW, 7 пунктов из ТЗ)

> **Подводные камни.**
> 1. **P не проектор — усечение не сохраняет диагональ.** `diag(A_r) ≠ diag(A)` для `r<K`. `ρ_gf(r)` — не «часть ρ_gf», а «ρ_gf усечённого объекта». Кумулятивная кривая — эвристика, а не разложение.
> 2. **Кросс-члены между модами.** `off²(A) ≠ Σ_k off²(P λ_k u_k u_k^T P)`. Разложение неаддитивно; `Δoff²(r)` — приращение, не вклад; может быть отрицательным при деструктивной интерференции (см. механику в E-30b).
> 3. **unif0 топ-мод сдвигает нуль.** На L6–L18 `u_1` близок к uniform (`unif0 = 0.64–0.80`), `P u_1` мал → `ρ_gf(1)` может быть крошечным. На L23 `unif0 = 0.74`, но топ-мода ESG в E-10a давала `unif0 = 0.50` — расхождение с E-34 уже зафиксировано.
> 4. **Нуль-модель per-r.** `ρ_null(r)` меняется с `r`; `ρ_gf(r)/ρ_null(r)` — отношение двух кривых. Не интерпретировать `ρ_gf(1)` как «вклад моды 1».
> 5. **Конечный ранг P·ESG·P.** `rank(P) = K−1`, значит `rank(A) ≤ K−1`. Мода `u_K` (если `P u_K ≠ 0`) может стать нулевой в A. Проверять ранг `A_r` через `μ_j > ε`.
> 6. **Порог K=128.** Не путать с E-35 `r ∈ {1,8,16,32,128}`. E-30 — разложение полного ESG по модам, r — число мод, не размерность подпространства.
> 7. **Per-sample vs pooled.** Как в E-34: `ρ_gf(r)` считается на каждом сэмпле, агрегируется медианой по сэмплам. Пул ESG до отношения некорректен.

### 3.4. Метод (расширить)

Текущий params → структурировать:

> **Метод.** Post-processing dense-кэша E-27 (`JR` — raw J; `P128` — нормализованный p). Шаги: (1) для каждого `(sample, position, layer)`: `ESG = JJ^T`, `P = diag(p) − pp^T`, `eigendecomposition(ESG)`; (2) для `r ∈ {1..K}`: `A_r = P·ESG_r·P`, `off²(r)`, `ρ_gf(r)`; (3) `ρ_null(r)` — тот же `null_rho_batched`, что в E-34, но на `diag(ESG_r)`; (4) `Δoff²(r)`, `w_r`, `PR_modes`; (5) собственные моды `A = A_K`, топ-5 `μ_j, v_j`, `alignment(v_j, u_k)`, `unif0(u_k)`; (6) per-sample → медиана + IQR. Batched `torch.linalg.eigh` — секунды на слой; итого <1 ч CPU на 5 слоёв.

## 4. Точный текст по блокам — E-30b (промоут из postscript)

### 4.1. Заголовок и позиционирование

Текущий «E-30b. Локализация мод остаточного cross-talk (полный спектр Δoff²(r); L18/L22, пилот)» — оставить заголовок, но переформатировать из postscript в подсекцию с полным набором блоков. Сохранить пометку «extension E-30» в заголовке.

### 4.2. Цель (NEW)

> **Цель.** E-30 показал, что на L22 `PR_modes ≈ 4.6` (концентрация), но первые 10 мод дают < 0.1% от `off²(K)`. Значит, концентрация обязана сидеть в модах `r > 10`. Где именно — неизвестно: в JSON E-30 сохранены только `Δoff²` для `r = 1..10`. E-30b получает **полный спектр `Δoff²(r)` для `r = 1..128`** на L18/L22, с знаками и кумулятой, чтобы: (1) найти моды, дающие основной вклад в `off²(K)`; (2) отличить концентрацию в нескольких модах от деструктивной интерференции многих; (3) дать E-32 список мод-кандидатов.

### 4.3. Математика (NEW)

> **Математика.** Используются определения E-30. Дополнительно: кумулята `C(r) = off²(r) / off²(K)`, `r = 0..K`, `C(0)=0`, `C(K)=1`; доля отрицательных `Δoff²` на моде `r`: `f_neg(r) = P(Δoff²(r) < 0)` по сэмплам; `neg_frac_per_r` — медиана `f_neg(r)` по блокам `(dom, si)`. Агрегация — протокол E-30 (per-sample медианы по позициям внутри блока, затем медиана/IQR по блокам). Для каждого `r` хранятся `med`, `q1`, `q3`. Top-20 по `|Δoff²|` — быстрый указатель, не замена полного спектра.

### 4.4. Подводные камни (NEW)

> **Подводные камни.**
> 1. **`PR_modes` и отрицательные `Δoff²`.** Низкий `PR_modes` может отражать не концентрацию, а сокращение больших разнознаковых вкладов. Полный спектр с знаками обязателен, чтобы это различить.
> 2. **Немонотонность `off²(r)`.** `off²(r)` — разность двух возрастающих величин; может убывать. Кумулята `C(r)` не обязана быть монотонной. Не интерпретировать плато как «насыщение» при наличии отрицательных `Δoff²` рядом.
> 3. **Механика отрицательного `Δoff²`.** `P` — не ортогональный проектор, спроецированные моды `w_k = P u_k` не ортогональны. При добавлении моды `r` квадрат нормы `‖A_r‖_F²` растёт не только на «собственную энергию» (`λ_r² ‖w_r w_r^T‖_F²`), но и на **перекрёстные члены** с предыдущими модами `k < r`: `2 λ_r λ_k ⟨w_r w_r^T, w_k w_k^T⟩`. Если `Δoff²(r) < 0` — перекрёстный член отрицателен и по модулю больше собственной энергии моды `r`. **Вывод:** если топ-20 мод по `|Δoff²|` имеют `neg_frac ≈ 0.5` или выше, низкий `PR_modes` — не «скрытая структура в хвосте», а **сильное взаимное гашение** мод при прохождении через P. E-32 в этом случае ищет пары/группы мод, а не «одну виновную моду».
> 4. **Top-20 по медиане.** Медиана `|Δoff²(r)|` может скрывать бимодальность. Рекомендуется сохранять полный спектр; top-20 — только быстрый указатель.
> 5. **Sentinel.** На L18 и L22 `sentinel_fraction = 0.0`, но механизм исключения сохраняется.
> 6. **Защита от деления на ноль в кумуляте.** `safe = off2f[:, -1].copy(); safe = np.where(safe < 1e-12, 1.0, safe); off2_cum = off2f / safe[:, None]`. Теоретически, если на каком-то сэмпле/позиции `A_K` идеально диагональна, `safe = 0` → NaN.
> 7. **Стоимость.** Дополнительных `eigh` нет; только агрегация уже посчитанных `off2_full` и `d_full`. Секунды на слой.

### 4.5. Метод (NEW)

> **Метод.** Патч `exp30_mode_decomposition.py`: (1) `off2_cum = off2f / safe[:, None]` с защитой от нуля; (2) `per_sample_stats` на `d_full` и `off2_cum`; (3) `neg_frac_per_r = median(neg_mask.reshape(n_blk, npos, K).mean(axis=1), axis=0)`; (4) Top-20 по `|Δoff²|`; (5) запись `full_spectrum` (r, delta_off2_med/q1/q3, off2_cum_med/q1/q3, neg_frac_per_r, top20_by_abs_delta) в отдельный `results/exp30_full_spectrum.json` (не в основной JSON — чтобы не раздувать). CLI: `--full-spectrum-layers 18 22`.

Доля `r ∈ [90, 128]`: 76.3% (L18), 91.2% (L22). Max одиночной моды: r=123: 5.4% (L18), r=127: 14.6% (L22). ### 4.7. Выводы (расширить текущие 4 буллета)

> - **Остаточный cross-talk сидит в конце спектра ESG — в 10–20 наименьших по eigenvalue модах** (L22: 68.6% `off²(K)` в 10 последних модах, L18: 34.3%). Кривая `C(r)` растёт плавно, экспоненциально к `r=K` — это не «ступеньки» на отдельных модах и не равномерное распределение.
> - **Ни интерференция, ни единичная мода:** `Δoff²(r) > 0` почти везде (`neg_frac ≈ 0.12–0.17` — не деструктивное гашение), max одиночной моды ≤ 14.6% (L22, r=127 = вторая наименьшая); `PR_modes = 4.6` на L22 читается как «~5 эффективных мод» — и спектр подтверждает: топ-5 мод несут 50% энергии на L22 (22% на L18), но это моды `r ≈ 119–128`, т.е. **низ частот спектра, а не топ**.
> - **Усиливает вывод E-30:** «топ-моды диагональны» — буквально: 110 крупнейших по eigenvalue мод несут лишь 14.1% (L22) / 38.5% (L18) off-diagonal энергии; остальные 18 наименьших мод (r ≥ 111) — 85.9% / 61.5%. **Весь сигнал — в хвосте спектра.**
> - **Для E-32:** мишень — не «конкретные моды», а хвост `r ≥ 118` (10–20 наименьших мод ESG), приоритет L22 (r=126–128, `Δoff²` до 130× медианы); Hessian cross-talk проверяется на этих модах. **Статус E-32 по ТЗ-правилу:** на L22 — «чёткие моды-кандидаты» (130× med ≫ 10× порога), на L18 — менее чётко (16–11× med).
> - **Постскрипт-механика:** `P` не проектор — спроецированные моды не ортогональны; `Δoff²(r) < 0` означает, что перекрёстный член с предыдущими модами отрицателен и по модулю больше собственной энергии. Наблюдаемое `neg_frac ≈ 0.12–0.17` — **не** деструктивное гашение, а нормальный фон; если бы `neg_frac ≈ 0.5`, картина была бы «интерференция», и E-32 искал бы пары мод.

### 4.8. Синергии (NEW)

> **Синергии.**
> - **E-34 (гейт).** E-34: `ρ_gf/ρ_null` = 0.98→3.61 — «запустить E-30». E-30: `PR_modes` 4.6–21.9, картина «топ-диагональна, хвост несёт». E-30b: **локализация хвоста** — 10–20 наименьших мод. **Цепочка:** E-34 (есть ли сигнал) → E-30 (где структурно) → E-30b (в каких модах) → E-32 (какой порядок).
> - **E-31 (вращение топ-16 vs хвостовые моды).** E-31: `C_F` = 0.30–0.91 на L6–L22 (энергия когерентна), `C_top16` = 0.02–0.15 (топ-16 подпространство вращается); L23 — оба высоки. E-30b: cross-talk в 10–20 наименьших модах. **Гипотеза (совместная):** «дышащий спектр» — топ-моды когерентны по энергии, но вращаются как подпространство; хвостовые моды несут cross-talk. Оба наблюдения — два среза одного эффекта. Проверка: совместный анализ `C_top-r` и `Δoff²(r)` на одних слоях.
> - **E-32r.2/r.3 (наследование gauge-структуры).** E-32r.2: `d_3 r=1` на L23 = 0.162/1.494/0.042 (raw/gf/fixP) — кривизна наследует gauge-структуру. Это уточняет (A): «кривизна наследует gauge» = «кривизна наследует uniform-топ-моду», а не хвост.

> - **E-37 (K = J − P·J: dense residual).** E-37: `align_K1` = 0.71–0.90, но `e_top1` = 0.15–0.27, `e_top8` = 0.36–0.64, спектр плотный — «dominant uniform-фон + плотный остаток», не rank-1 блок.
