## E-30. ESG rank-лестница: где «тысяча измерений» листа (5.md высший-1)
**Input**: exp27b_dense.pt (r_gf на K=128 уже в RANKS).
**Output**: results/exp30_esg_ranks.json — r_raw, r_gf per (layer, sample, pos)
при K ∈ {64, 128} + медианы по слоям.
**Steps**:
1. G = J_t J_t^T (dense, slice K=64/128). r = (Σλ)²/Σλ² (participation ratio;
   stable rank как secondary).
2. r_raw — по J; r_gf — по P(p_t)J (RANKS из ckpt для K=128 сверить).
3. Лестница r_raw(l), r_gf(l); сравнить с T_eff из E-29 (совпадают ли шкалы).
**Предсказание**: «r~1000» — gauge ⇒ r_gf < 0.3·r_raw; genuine ⇒ r_gf > 0.7·r_raw.
**Решение**: gauge ⇒ лист = объект 1–2D (лист в 5.md — про нить, не про r-плоскость);
genuine ⇒ лист реально высокоразмерный, E-33 интерпретировать через r.

## E-31. C(Δpos) полного J: границы предложений (5.md высший-1)
**Input**: exp27b_dense.pt + тексты пула (pool_fp-совместимые, tokenizer с
return_offsets=True — calibration.py offsets не просит, pool грузится внутри
эксперимента по fp из ckpt).
**Output**: results/exp31_cpos_full.json — C(Δpos) per layer (полные 128×128 J,
gauge-free) + профиль «внутри предложения / через границу».
**Steps**:
1. C_a(Δ) по всем парам позиций (256² пар, cos gauge-free J, без truncation).
2. Границы предложений: offset_mapping по слову; граница = t, где слово t
   завершает предложение (точка/!/?) или бэкс페이스-пробел в offsets.
3. Δ ∈ {1,2,3}: медиана C внутри-предложения vs через-границу.
4. Secondary: C(Δ) на top-32 токенах (slice dense) — переживает ли dip truncation.
**Предсказание**: E-28 (r=16) не нашёл TZ-flat; полный J может показать dip на
границах ⇒ предложение = шов листа (связность/кривизна — следующий шаг).
**Kill**: dip нет ⇒ границы не на уровне предложений (синтаксис — вне ТЗ).

## E-32. Инъекции в mid-layers: видит ли Hessian-направление b (5.md высший-2)
**Input**: пул E-27b (8 сэмплов, 2×4 домена), 0.8B; направления b — из ckpt.
**Output**: results/exp32_injection.json — per (sample, layer, direction, α):
KL, Δentropy, cos(z₀, z′) на целевой позиции.
**Steps**:
1. b_l = главный направл. H = J^T P J в слое l (power iteration, 10 итераций,
   matrix-free HVP, J из exp27b_dense.pt на том же сэмпле/позиции t=128).
2. Инъекция h_l += α·v на позиции t=128, v ∈ {b_l, random unit}, α ∈ {1, 3},
   слои {6, 12, 18}. forward с graph; замер z на t+4 (и на S-1).
3. Контроль: α=0 (reproducibility) и v = b_l из другого сэмпла (spatial control).
**Гипотеза**: инъекция вдоль b_l двигает entropy/calibration сильнее random
при том же α («ручка уверенности»).
**Kill**: Δentropy(b) ≈ Δentropy(random) ⇒ особого направления нет.
**Бюджет**: 8×2×2×3 = 96 forwards + HVP — <1h T4, kernel 2h.

## E-33. Кривизна L23-листа: геодезика vs линейная интерполяция (5.md высший-8, ставка №2)
**Input**: exp27b_dense.pt (L23, h_t и lm_head).
**Output**: results/exp33_l23_curvature.json — geodesic/linear error ratio per
sample + профиль по позициям.
**Steps**:
1. Пары (t, t+4, t+8): h_mid = (h_t + h_{t+8})/2, z_lin = W·h_mid.
2. h_geo = геодезическая середина на листе (1-й порядок: поправка на κ из
   локальной плоскости E-28-transport, SVD на тройке точек).
3. Ratio = ‖z_geo − z_{t+4}‖ / ‖z_lin − z_{t+4}‖; медиана + per-pos.
**Предсказание**: κ=0.018 накапливается ⇒ geo лучше linear ≥2×.
**Kill**: ratio < 1.2 ⇒ лист «эффективно плоский», linear readout достаточен,
кривизна декоративна (E-28 κ-находка не влияет на readout).

## E-34. Кластеризация сэмплов по ESG-спектру без доменных меток (5.md высший-4, ставка №3)
**Input**: exp27b_dense.pt.
**Output**: results/exp34_esg_clustering.json — спектры, кластеры, ARI, p_perm.
**Steps**:
1. Per (dom, si) при l ∈ {18, 23}: спектр ESG (энтропия сингулярных, PR,
   gauge share, углы топ-3 векторов) → вектор признаков (нормированный).
2. Agglomerative (average) на D = 1 − cos, k = 2..8, silhouette S_max,
   gap-statistic B=100 (reuse кода exp27.5).
3. Domain permutation test B=1000 (reuse exp27.5) — значима ли доменная ось.
4. ARI(кластер, домен) + отдельный кластер math? (проверка ставки №3:
   math = низкоразмерный изолят).
**Предсказание**: S_max ≥ 0.3 и math — отдельный кластер ⇒ «режимы рассуждения».
**Kill**: S_max < 0.3 и ARI ≈ 0 ⇒ спектр не структурирует, sample-local — всё.
