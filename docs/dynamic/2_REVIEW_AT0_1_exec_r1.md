### m1. MINOR (лог/метка): П5 h_raw печатает `pos3=8/53`, но валидная выборка n=36
`experiments/AT0_1_accounting.py:507-508` печатает `pos3={p5[obj]['pos3']}/{len(nong)}` — для h_raw знаменатель
53 (=все nondeg), но в e3-массив h_raw попадают только 36 доков (17 TPU-skipped), и p_pos3 считается по n=36.
**Доказательство:** `sum(comb(36,i) for i≥8)/2^36 = 0.9998437244212255` (== артефакт), а при n=53
`sum(comb(53,i) for i≥8)/2^53 = 0.9999999799840191` (≠). Лог-строка «8/53» читается как доля 15%, фактическая
8/36 = 22%. В самом артефакте в П5 нет поля n (у П4 есть n_docs) — неоднозначность остаётся и там.
**Фикс:** печатать знаменатель = len(e3); добавить `n` в запись П5 (3 строки).

### m2. MINOR (метод/презентация): П4 — точечная оценка = медиана, CI = бутстрап среднего
`boot_ci_diffs` (AT0_1:121-127) возвращает медиану diff, но бутстрапит **среднее**; запись П4 (AT0_1:380-388)
ставит их рядом. Для h_raw: медиана = −0.002122, CI = [−0.01578, −0.00308] — **медиана вне своего CI**
(среднее = −0.00879 — внутри). Вердикт-логика `consistent = 0 ∈ CI` — корректный парный тест для среднего,
но читатель видит точечную оценку, не покрытую отчётом CI.
**Фикс (любой):** отчитывать среднее как точечную оценку, либо бутстрапить медиану (1 строчка).

### m3. MINOR (ясность реестра): TPU-L1 клетки h_raw/du_unit несут чужую (dip_V) кривую в `dip_med`
AT0_1:184-202: для всех трёх объектов TPU-L1 `dip_med` = meta-кривая dip_V (одна и та же). Для v_tangent это
канонично; для клеток с `space=h_raw`/`du_unit` значение — суррогат (dip этих объектов на L1 TPU как раз
деградирован, — причина absent). Ячейка само-документирована (`provenance`-строка + manifest P14), G3
удовлетворён, но потребитель, читающий `cells[...,'h_raw']['dip_med']` по space, получит кривую v_tangent.
**Фикс (опционально):** meta-кривую — только в v_tangent-клетке, в остальных `dip_med: None` + тот же
provenance.
