## 1. Принимаю из `E39_supplement` — и что это меняет в моих собственных ранних формулировках

### 1.1. Числовая ошибка на порядок

Шесть раундов я цитировал «`P(p)` убивает 98–99% энергии `J`» как фундамент для каноничности `J^(p)`. Это было неверно:

| Величина | Определение | Значение |
|---|---|---|
| `survive_frac = ‖PJ‖_F/‖J‖_F` | **норма** | 0.010–0.022 → убито 97.8–99.0% **нормы** |
| `O1 = ‖PJ‖²_F/‖J‖²_F` | **энергия** | 1.7e-4 – 4.7e-4 → убито 99.95–99.98% энергии |
| `iso = ‖P‖²_F/K` | изотропный референс | 6.90e-4 (константа) |
| `O1/iso` | реальное/изотропное | **0.249–0.685×** |
| `g_uni = ‖QJ‖²/‖J‖²` | настоящая uniform-доля энергии | **0.126–0.215** |
| `O2 = O3` | `g_uni ≡ ESG gauge_share` | тождество, разница ≤ 7.7e-16 |
| `g_uni(J^gf)` | uniform-доля после `P` | **≤ 2.2e-15** (тождественно 0: `P·1 = 0`) |

Ключевой вывод: **`P` убивает меньше энергии, чем убил бы на совершенно случайном `J`** (0.25–0.69× от изотропного референса). Никакого «gauge доминирует энергетически» из этой величины не следует. Она — свойство оператора, не данных.

### 1.2. Что это меняет в моих ранних утверждениях

Я тоже виноват в энергетической риторике. В раундах 2–4 я писал:

- «`P(p)` убивает 98–99% энергии, поэтому `J^(p)` — канонический объект» → **неверная мотивация**. Каноничность `J^(p) = ∂p/∂h` — **алгебраическая** (якобиан софтмакса, инвариантность к сдвигу логитов), не эмпирическая.
- «Топ-мода ESG = gauge, несёт подавляющую часть нормы» → **неверно для энергии**: uniform-доля энергии 13–22%, не 98–99%. Направление топ-моды действительно почти uniform (uniformity 0.74–0.92), но энергии на нём мало.
- «`gauge_share` ESG = 98–99%» → **это был другой объект** (норма оператора), не `g_uni`.

Принимаю полностью. Энергетическая риторика вычищается из всех моих формулировок.

### 1.3. Что НЕ меняется

- **`P(p)` не проектор** (`P² ≠ P`) — это я подчёркивал с первого раунда, и это остаётся центральным. Именно поэтому `J^(p)` — не «проекция на физическое подпространство», а якобиан отображения в симплекс.
- **Каноничность `J^(p)`** — теперь опирается на алгебру (`P = ∂softmax/∂z`, `J^(p) = ∂p/∂h`), не на «убийство доминирующей моды». Это **более прочный** фундамент.
- **Угловые метрики** (`Δ_gf`, `κ`, `align`) — не затронуты, они не используют энергетические доли.
- **Таксономия каналов** (natural/ΔW × raw/gf/fixP × top/tail × left/right) — не затронута.

## 2. Геометрический смысл `cos(J, PJ) ≈ 0.08` — новое число, которое нужно интегрировать

`E39_supplement` §2.2.1 даёт прямое измерение, которого раньше не было:

| Слой | `c = ⟨J,PJ⟩/‖J‖²` | `cos(J, PJ)` | `‖K‖²/‖J‖²` |
|---|---|---|---|
| L6 | 1.22e-3 | 0.088 | 0.9966 |
| L12 | 1.07e-3 | 0.085 | 0.9966 |
| L18 | 5.49e-4 | 0.066 | 0.9981 |
| L22 | 4.81e-4 | 0.064 | 0.9983 |
| L23 | 2.09e-3 | 0.108 | 0.9943 |

Три следствия, которые я считаю **центральными для геометрической картины**:

**(а) `PJ` почти ортогонален `J`.** Угол 82–86°. Из `P` симметрична и `P ⪰ 0` следует только `c ≥ 0`, но не «выровненность». `P` убирает компоненту, **почти не связанную с самим `J`**. Это прямое следствие того, что `P` — не проектор: проектор `Π` удовлетворяет `Π² = Π`, и `‖Πx‖² = ⟨x, Πx⟩`, т.е. `cos(x, Πx) = ‖Πx‖/‖x‖`. Для `P ≠ P²` это не так, и `PJ` может быть почти ортогонален `J` при малой норме `PJ`.

**(б) Примирение парадокса.** `‖PJ‖ ≈ 0.02‖J‖` (малая норма) и `‖(I−P)J‖ ≈ ‖J‖` (почти полная норма) — не противоречат друг другу именно потому, что `PJ ⊥ J` (приблизительно):
```
‖J − PJ‖² = ‖J‖² + ‖PJ‖² − 2⟨J, PJ⟩ ≈ ‖J‖² + 0 − 0 = ‖J‖².
```
«Убитая» компонента мала и почти ортогональна, поэтому её удаление почти не меняет норму.

**(в) `frac_K ≈ 0.997` с `mean ≈ median`** — нет бимодальности. Распределение узкое. Это опровергает ранние предположения о «двух популяциях позиций» (сильно/слабо затронутых `P`).

**Интеграция в картину:** `P` — это не «вырезание доминирующего направления», а **почти ортогональная фильтрация**, которая убирает малую, слабо связанную с `J` компоненту. Геометрически это согласуется с тем, что `P` — якобиан софтмакса (отображение в касательное пространство симплекса), а не проектор на физическое подпространство.

## 3. Статус H5 после дополнения

### 3.1. Что было

H5 («токен-слепок — калибровка») поддерживалась двумя аргументами:
1. **Угловой:** `Δ_gf ≈ π/2`, `align(u_top, 1) = 0.85–0.99`, `uniformity(u₁) = 0.74–0.92`.
2. **Энергетический:** «`P` убивает 98–99% энергии ⇒ gauge доминирует».

### 3.2. Что стало

Аргумент (2) **умер** (это была норма оператора, не энергия данных; реальная `g_uni = 13–22%`). Аргумент (1) остаётся, подтверждён заново в `E39_supplement` (uniformity 0.74–0.92 в таблице §2).

**H5 — угловая гипотеза с одним несущим аргументом.** Если угловые метрики в E-40/E-41 не воспроизведутся, H5 умирает без запасного аргумента, а не «переформулируется в энергетическую версию».

Принимаю демоцию Спикера 1: в таблице синтеза §5 статус H5 меняется с «подтверждена двумя аргументами» на «подтверждена одним (угловым); энергетическая поддержка отозвана».

### 3.3. Что это значит для `κ_fixP` vs `κ_raw` (тест 1.1)

Тест остаётся **главным дискриминатором** для H5. Но теперь его интерпретация чище:
- `κ_fixP ≈ κ_raw` → кривизна инвариантна, геометрия реальна, H5 слабеет.
- `κ_fixP ≈ 0` → вся голономия — `p`-тень, H5 подтверждается (но только углово).

Энергетический аргумент больше не «подстраховывает» ни один из исходов.

### 4.3. Композиционные доли в 5×5 матрице — принимаю

Спикер 3 прав: доли `s_i = E_i/‖ΔJ‖²` удовлетворяют `Σs_i = 1` тождественно. Это композиционные данные:
- Ранг ≤ 4 всегда (центрированные доли в 4-мерном аффинном подпространстве).
- Наведённые отрицательные корреляции: средняя внедиагональная корреляция = `−1/(p−1) = −0.25` до всякой физики.

**Фикс:** матрица 5×5 строится на **ненормированных энергиях** каналов `{E_right, E_radial, E_left, E_cross, E_resid}`. Чтение трёхступенчатое: (1) равнокорреляционный уровень `ρ̂`; (2) отклонения пар от `ρ̂`; (3) собственные значения против перестановочного нуля. Принимаю.

### 4.4. Фактор Фишера в `KL_lin` — принимаю и подтверждаю

Спикер 3 прав: `KL_lin = ½ε²(Jv)ᵀF(z)(Jv)`, где `F = diag(p) − ppᵀ`. Форма `½ε²σ₁²` предполагает `F = I`, что неверно: `tr F = 1 − ‖p‖² < 1`, `λ_max(F) ≤ p_max(1−p_max)·(1...2)`.

Численно: при пиковом `p_top = 0.9`, `λ_max(F) ≈ 0.09–0.18` — смещение не ×2, а **×5–×11**. При плоском `p` по словарю `K = 128`: `λ_max(F) = 1/K ≈ 0.008` — до **четырёх порядков**.

Принимаю. `KL_lin` с фактором Фишера — обязательное поле в пререгистрации E-44, не опция.

### 4.5. Критерий `R_can` — принимаю с затяжками

Конъюнкция `(a′) ∧ (a) ∧ (b) ∧ (c)`:
- **(a′):** `R_can(L23) = max_l R_can(l)` по доступным слоям.
- **(a):** `min_body R_can ≤ 0.5 · R_can(L23)`.
- **(b):** Парный бутстрап `P(R_can(peak) − R_can(trough) > 0) ≥ 0.95`, с селекцией `trough` внутри реплики.
- **(c):** Инвариантность вердикта к срезу (с/без удаления топ-gauge-моды).

Без L0 критерий односторонний: `not_testable_no_L0`. Любые три из четырёх условий → `ambiguous`. Принимаю.
