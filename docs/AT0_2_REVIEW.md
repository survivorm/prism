## 1. Что видно из AT0_3 и относится к AT0_2

### 1.1. AT0_3 наследует seed-конвенцию AT0_2 — это надо сверить

В `AT0_3_area.py`:

```python
SEED_STRIDE = 1009  # r3.2 (fixreview #3): per-doc-шаг перестановочных сдвигов
                    # (конвенция серии AT0_2: SEED_BASE + doc_idx*SEED_STRIDE)
```

и дальше:

```python
gidx = {nm: i for i, nm in enumerate(L + C + R)}   # глобальный индекс по ВСЕМ докам
```

AT0_3 явно ссылается на конвенцию AT0_2 и исправляет в ней баг: если `doc_idx` — позиция **внутри стратума**, то `L[0]/C[0]/R[0]` получают один seed и при равном K — идентичный первый перестановочный выбор ⇒ cross-стратумная корреляция нуля.

**Вопрос к AT0_2:** там `doc_idx` глобальный или позиционный? Если позиционный — тот же баг, и он влияет на `Dns`/`p_doc`. Это первое, что стоит посмотреть.

### 1.2. Расхождение учёта клеток между AT0_2 и AT0_3

| клетка | учёт |
|---|---|
| AT0_1 | `excluded_L1 = ['own_w0','own_w4']` (fp16-деградация L1) |
| AT0_2 (прежняя версия) | `n_cells = 478` на объект = 96×5 − 2 |
| AT0_3 (видимый сейчас) | `G2_cells: n_cells=1440, n_present=1440` — **absent нет вообще** |

1440 = 96×5×3, то есть AT0_3 считает L1-клетки для `own_w0/own_w4`, которые AT0_1/AT0_2 помечали как деградированные.

На вердикты AT0_3 это **не влияет** (primary — L23; `layer_type` — только gen-доки, без TPU). Но:

- `G2_cells 1440/1440` в AT0_3 **не сопоставим** с учётом AT0_2;
- в серии нет единого правила «что делать с fp16-деградированным L1».

Надо либо унифицировать, либо в каждом артефакте писать, применяется ли L1-exclusion.

### 1.3. Перестановочный бюджет в серии разный

```
AT0_3: B_PERM = 1000  → p_floor = 1/1001 ≈ 0.000999
AT0_2 (прежняя версия): p_docs_median = 0.047619… = 1/21 → B_null = 20
```

Если новая AT0_2 подняла B — это закрывает мой E3. Если нет — в серии два несовместимых разрешения p, и `frac_cells_p_lt_alpha` из AT0_2 нельзя ставить рядом с p из AT0_3.

### 1.4. Общие sha — сверяемы

AT0_3 фиксирует:

```
gen_layers f142f297…  P1_own 783e1633…  P2_corpus 5f42a084…
match_AT0_1: все true
G1p_field sha bcc607c5…  selfcheck ok
```

AT0_2 должен нести **те же** три sha и тот же `field` sha. Если расходится — оцениватели разные, и числа серии несравнимы.

## 2. Минимум, который закрывает открытые пункты

Достаточно прислать эти куски — не весь файл.

| # | открытый пункт | что нужно увидеть |

| **E2** | blk-nulls без seam-exclusion ≠ locality-null | функция построения blk-null: исключаются ли швы; и формулировка verdict («локальность ≤b не объясняет» vs «отличается от unmasked block-null») |

| **E5** | AR-null diagnostics | значение/доля `sigma2_clipped`, max AR root, matched `ρ̄(1..p)` real vs null |

## 3. Что остаётся в силе из прежнего ревью AT0_2

Помечаю как **не проверено в этой версии** — это чеклист, не вердикт.

Принято было:
- Fourier демотирован в positive control, круговой vs линейный ACF разведены, wrap отчитан;
- G0 fail-loud на вырожденных строках, обход `_hn`-бага продюсера;
- `aggregates_verified_only` (80 доков = gen64+own16, corpus исключён);
- `sign_check_ok` для AR;
- разделение уровней cells/docs в `frac_*`;
- `seam_excluded` помечен «Σ с real НЕ СРАВНИВАТЬ».

Открыто было (по приоритету):
1. **E1** estimand drift — главный;
2. **E2** blk-null: сохранение веса `max(0, 1−k/b)`, а не чистый cutoff ≤b;
3. **E4** separate-CI verdict вместо paired;
4. **E3** saturated p-counter;
5. **E5** AR diagnostics;
6. **E6/E7** primary pool / nondeg;
7. **E8** `h_raw` provenance.

Плюс мелочи: Wilson upper >1 (clamp), `D_bands_L1` рядом с `D_center_l1` (citation trap), `not_testable` floor динамический вместо пре-рег `DELTA_MIN`.
