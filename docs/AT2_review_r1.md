**wiki 8 / math 41 / code 36 / chat 5, total 90/4096 (2.2%)**. Перебраны варианты: last

(ошибка scope-аудита). Гейт S4 по тексту заведомо провален («провал = артефакта нет»).
Требование: пересчитать S4 на реально воспроизводимые 90/4096 (8/41/36/5) — либо найти точный
рецепт scope и зафиксировать его; синхронно исправить §1 (2.2%, 8/41/36/5) и §5 (90/4006);

**M2 — MAJOR — S2: буквальная формула KL не проходит порог и не определена; scope-число не её.**
Место: §7 S2 «mean KL(softmax(z_U128) ‖ P128_RAW) < 1e-5 на 2 дока × 128 позиций
(scope-замер: 4.4e-08)».
Аргумент (измерено, 4 доменных дока × 128 поз., fp64, E — bf16→fp32 slice из зафикс. модели):
букв. форма (сырой slice softmax vs сырая P128_RAW): wiki_0 4.2e-05, code_0 4.1e-05,
chat_0 4.1e-05 — **> 1e-5** (math_0 9.2e-06 — под порогом, т.е. исход зависит от «2 дока»,
которые не зафиксированы); при этом KL(субстохастичный q ‖ субстохастичный p) даёт отрицательные
значения (−4.2e-05) — метрика на не-распределениях не определена. Форма E39d/scope
(**ренормированный** slice softmax ‖ ренормированная P128) = 4.2e-12 (fp64) / ~6e-09 (fp32) —
т.е. scope-«4.4e-08» соответствует ренорм-форме, а не букварианту. Гейт по тексту провален
на wiki/code/chat.
Требование: записать формулу явно — KL( softmax(z)[U128]/Σ ‖ P128 = P128_RAW/ΣP128_RAW )
(форма E39d `route_exact.KL_vs_P128_RAW_renorm_mean`), порог < 1e-5 можно оставить (проходит
с запасом 10⁴), и зафиксировать 2 конкретных дока (напр. wiki_0, math_0).

**M3 — MAJOR — S5 и определение weak-J: «ненулевой» без порога + lift-гейт <1e-6
самопротиворечивы на реальных данных; weak-J вбирает численно-нулевые направления (подв. камень 2).**
Место: §7 S5 «lift-резидуал < 1e-6 для λ > 1e-12·λ_max»; §4 «C_t = … (1024×1024, rank ≤ 124)»,
«weak-J: r = 32 eigvec с НАИМЕНЬШИМИ ненулевых λ»; §1 «weak-J = 32 наименьших ненулевых λ
(weak-сторона null_ε, ε=1e-2 — диагностический порог, не селектор)».
Аргумент (зафикс. точка L6 ('wiki',0,0)): из 128 eigvec G только 107 дают lift-резидуал < 1e-6;
**32 наименьших λ (idx 0..31 — ровно weak-J при пороге «nonzero» = 1e-12) содержат 21 вектор с
резидуалом 1.8e-5…2.4e-2** (λ = 7.4e-9…5.7e-6). Т.е. S5 по тексту заведомо провален на
зафиксированной супервизором точке. Причина: 4 наименьших eigval ≈ 1e-8 (относит. ~1e-9) —
это не точные нули (rank при 1e-12 = 128, а не 124 — «rank ≤ 124» верно лишь при пороге ~1e-9),
но это именно «численно-нулевые направления» (подводный камень 2 ТЗ: «без регуляризации
скретчпад = артефакт оценщика»), а их eigvec определены только с точностью ~1e-3 (fp64).
ε=1e-2 объявлено «не селектор» ⇒ отбор weak-J ничем не защищён от этих 4–21 направлений.
Требование: (1) явный порог «ненулевого» T_num, связанный с надёжностью lift-а
(напр., λ > 1e-6·λ_max: на зафикс. точке 32 наименьших сверх него дают резидуалы ≤ 2.6e-8;
проверить на всех 32 выборочных (l,t) S5); (2) S5 — либо «lift < 1e-6 для λ > T_num» (то же
T_num), либо ослабленный допуск для малых λ (явной формулой); (3) исправить «rank ≤ 124»
(rank = 128 при 1e-12; 124 при 1e-9 — назвать порог); (4) явность: weak-J = 32 наименьших λ
сверх T_num.
