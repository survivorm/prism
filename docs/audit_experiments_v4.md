# Аудит экспериментов, раунд 4 (2026-11-05, вечер): цепочка хвоста E-11/E-12

Фокус: тихие баги в интервенционных экспериментах E-11a/E-12a/E-12b/E-12c
(полный путь «спрямление в h → истинный хвост → KL»), metadata-слой,
повторяющиеся классы из раунда 1–3.

## Найденные баги (по тяжелости)

### A1. Якорь линеаризации ≠ выход модели (E-11a, E-12a, E-12b) — КРИТИЧЕСКИЙ
`z0 = lm_head(model.norm(h_base))` на промежуточных слоях 6/12/18 — это НЕ
z(h_base): между h и выходом ещё (n−layer−1) слоёв декодера. Истинный
KL(p_true(δ=0) ‖ softmax(z0)) = 8.9 ната (L12) уже при нулевом возмущении,
тогда как J — полный дека-якобиан (‖J‖_F ≈ 58). Следствие: все абсолютные KL
в E-11a/E-12a/E-12b были насыщены константой якоря:
- E-11a: KL gauge/sem/rand = 12.67/12.78/12.59 — метрика НЕ различала
  направления; выводы «gauge-free 10.5 vs raw 13.4» и «предел первого порядка
  10.5» — артефакт якоря.
- E-12a: «полный decoder ratio = 1.02–1.04» — следствие того, что оба KL =
  якорь + малый прирост ⇒ отношение → 1. Вывод «неразличимость полных
  forward при больших ε» висел на этом числе.
- E-12b: ppl_orig = 3.7e6 (уже было видно как аномалия).
Симметричные величины (KL(+)/KL(−), ratio_lin, uniformity, σ-спектры) —
сокращали якорь и выжили.

### A2. `run_full_decoder` кладёт h поверх полного кэша (E-11a, E-12a, E-12b) — КРИТИЧЕСКИЙ
Локальная копия хвоста клонировала `out.past_key_values` ПОЛНОГО forward
(позиции 0..S-1) и декодировала h на позиции S-1 поверх него: последнее слово
учитывалось трижды — (i) K/V позиции S-1 в кэше, (ii) GDN conv/recurrent
состояние, уже «прожевавшее» S-й токен, (iii) сам h. Корректный префикс —
`_run_prefix_pass` (ids[:, :-1], позиции 0..S-2), как в `prism/jacobian`
(именно через него дифференцируется J). Проверка: `_run_decoder_pass` c
правильным префиксом воспроизводит full-forward с KL ≈ 1e-7 (L6/12/18),
со старым способом — KL 5.4–9.1 ната. Исправлено: публичный helper
`prism.jacobian.last_position_logits`; все три эксперимента вызывают только
его; во всех трёх добавлен fail-loud ассерт якоря (δ=0 ↔ out.logits).

### A3. Двойной softmax в p-space предикторах (E-11a) — КРИТИЧЕСКИЙ
`p_gf = softmax(p0 + J_p @ δ)` — повторное экспонирование вероятностей, плюс
единичная нестыковка: J_p и dp живут в K-мерной нормированной p-координате,
а p0 — полная V-вероятность. Результат: KL_true_gf/dr ≡ 6.7 ната — константа,
не зависящая НИ от направления, НИ от масштаба (карточка E-11a описывала это
как «gauge-free пространство покрыто при r=4» и «предел первого порядка»).
Исправлено: предикторы меряются на условном распределении по token_set,
q' = clamp(q + dp, 0)/Σ — честная линеаризация вероятности. Формула
`softmax(log p0 + J^(p)δ)` из карточки тоже была не тем, что делал код.

### A4. Потерянные функции при патче (exp12b) — ПОЙМАНО НА ХОДУ
При замене области run_full_decoder→main пропали quantize_vector /
uniform_quantize (ловируется AST-проверкой вызываемых-но-неопределённых).

### A5. Metadata-writer: keys-идентификаторы (14 файлов, commit 1bc4a30) — ТИХИЙ
`results["params"] = {model: model, n_samples: n_samples, ...}` — ключи dict
равны ЗНАЧЕНИЯМ переменных: в JSON попадает
`{"Qwen/Qwen3.5-0.8B": "...", "4": 4, "32": 32}` вместо имён параметров.
В exp13 `{domains: domains}` — list как ключ → TypeError в самом конце
часового прогона. Сохранённые артефакты НЕ задеты (написаны до коммита), но
любой свежий прогон портил бы provenance. Исправлено кавычками в 14 файлах;
артефакт E-11a перепрогона (запущен до фикса) промаркирован.

### A6. Мелочи
- `ppl_*` в E-12b — это НЕ перплексия: CE(z(S-1), ids[-1) — self-conditioned
  single-token target (таргет входит в контекст). Оставлен как относительный
  диагностик, перемаркирован в карточке.
- Квантизатор E-12b режет сетку ±‖x‖_∞ во всех направлениях; легитимный
  коэффициент |⟨v,x⟩| ≤ ‖x‖₂ ≫ ‖x‖_∞ — 8-битная «защита» дифф-направлений
  может съедаться климпом. Добавлена диагностика (|c|, clamp_frac) в
  артефакт; дизайн квантизатора — вопрос отдельного прогона, не баг чисел.
- **Kaggle-охота (сбор результатов):** ядро `e-38e-true-j-l23-vs-e-39m-carriers`
  «COMPLETE» с пустым output — в логе `ModuleNotFoundError: prism.spectral`
  (dynamic-import exp39a/exp28 не инлайнится build_kernel'ом; статус COMPLETE
  не гарантирует результат — надо смотреть output). `prism-exp27c-positional-
  cache`: jcache_L12.pt **0 байт** на сервере — та же тихая смерть. Оба требуют
  перепуша с фиксом инлайна (не блокирует статью: локальные E38e-артефакты
  полные, 32 doc × 4096 pos, сверены в этом раунде). Для exp12a это
  использован GPU-путь (ядро kernel-exp12a, ~15 мин vs час на CPU).
- exp4_top_p: `mask = cumsum <= p` — nucleus БЕЗ первого «переполняющего»
  токена (нестандартная конвенция, не ошибка).
- exp6 KL-lens на промежуточных слоях — карточка уже честная («garbage,
  lm_head не обучен»), теперь у нас есть механическое объяснение (A1).
- `_round3_exp12a_recompute.py` помечен DEPRECATED (унаследовал A1+A2).

## Перепрогоны и новые числа (заполнено 2026-11-05, 18:00)

**E-11a (переснят, N=4, K=32):** метрика живая. gauge: KL < 1e-4 на всех
масштабах и предикторах (J убивает common mode — квадратичный закон [L-fisher]
в чистом виде). sem_0: raw 5e-5→7e-4 при s 0.5→2.0; gf 1e-4→3.4e-2.
**r_KL ≤ 4 сильно: KL(dr4) = KL(dr32) bitwise на всех слоях/направлениях** —
численный ранг J^(p) (K=32) ≤ 4 во float32; рост v1-метрики E-11b с r = тот
же хвост округления (оговорка E-11b подтверждена). **Сырой логит-предиктор
всегда лучше p-space** (L18 s=2: 0.0027 vs 0.823) — «gf лучше raw» отозвано.
top1_raw = 1.0 везде, TV 0.04–0.09.

**E-12b (переснят, N=4, K=32): VOID по замыслу.** KL(map) 3.6e-9…2.3e-8,
KL(uniform) 4.6e-8…5.5e-7 (max 1.9e-6), top1 = 1.0 везде — прежние
«KL≈15 / PPL 10⁶ / оба разрушают» были чисто артефактом A1+A2. Выводы пайплайна («карта направляет разрушение эффективнее») сняты. Климп-диагностика:
доля |c| > ‖x‖_∞ = 0.00 (опасение по квантизатору не подтвердилось).
`ppl_*` в JSON — self-conditioned удивление (не PPL), base 4667.5 одинаков на
всех слоях — consistency-доказательство исправленного якоря.

**E-12a (переснят на Kaggle GPU, N=8, K=64): вывод ПЕРЕВЕРНУТ.** Исправленный
полный decoder **различает** gauge/differential: ratio KL_d/KL_g при ε=1.0 =
2.22/1.20/4.11× (L6/12/18), растёт с ε (L18: 2.3→4.1×). Прежний
«ratio ≈ 1.02–1.04, полный forward неразличим» был суммой якорной константы
(оба KL = якорь 8.9 + малый прирост). Нелинейности **сжимают** линейное
различие (59×→4×) но не стирают. Якорь-независимое (uniformity 0.61–0.98,
σ_g/σ_d ≈ 40×, ratio_lin 7–59×, ‖h‖) воспроизвелось бит-в-бит с round-3 —
пересъём корректен.

**A7 (мелочь, конвенция): exp27.6** permutation p-values были `.mean()`
(может уйти в 0), а не `(1+h)/(B+1)` как exp27.5 и остальной проект. Приведено
к конвенции. Опубликованные p (6 шт.) не на нулевом полу → перепрогон не нужен.
