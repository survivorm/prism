# Часть V. Эмпирика

> Каждый эксперимент: цель → протокол (кратко) → результат → вывод. Полная карта «E-ID → старый номер эксперимента → секция» — Приложение B. Типы — §14.

## 15. Фундамент поля J: kill-switch и sample-local Gramians

### E-1. Identity (самопроверка)

**Цель.** Проверить цепочку `JacobianBridge` на идентичной модели: при `M_S = M_L` должно быть `𝓖_gap = 0`, `𝓑_bridge = 1`, `s(l) = 0` (`[L-dim]` + `[L-gram]`, §5).

**Протокол.** Одна модель (Qwen3.5-4B), один сэмпл, все 32 слоя, `𝒮` — top-512. «Младшая» модель — та же «старшая».

**Результат.**

| Слой | gap | bridge |
| --- | --- | --- |
| L0–L5 | 1.000 (sentinel) | 1.000 (sentinel) |
| L6 | 0.9998 | 0.9998 |
| L7–L31 | ≈ 0.0 | 1.0000 |

**Вывод.** Identity работает на L6–L31: `gap ≈ 10^-4` (на уровне fp32), `bridge ≈ 1`. L0–L5 — **sentinel**: все строки `J_S` ниже порога `τ` (§7), маскируются, возвращается дефолт `1.000` (`prism/bridge.py:31`). Это **не** «плохое выравнивание», а отсутствие сигнала — ранние слои имеют мизерный вклад в декодирование. **Kill-switch пройден.**

### E-12a. 512 токенов

**Цель.** Проверить, что результаты не зависят от размера `𝒮` (512 vs 64).

**Протокол.** Qwen3.5-4B, 32 слоя, 4 сэмпла, `𝒮` — top-512.

**Результат.** gap `0.98–1.01`, bridge `−0.02–0.02` (на уровне нуля). Расхождение с результатами при `K = 64` — < 0.01.

**Вывод.** Метод стабилен при `K = 512`. Зависимость от `K` — E-11c (§18).

### E-12c. Sentinel-порог

**Цель.** Оценить влияние порога `τ` на долю sentinel-строк и на итоговые метрики.

**Протокол.** Qwen3.5-4B, 32 слоя. Порог `τ` меняется от `1e-6` до `3.61e-12`.

**Результат.** При `τ = 1e-6` — доля sentinel `0.04`; при `τ = 3.61e-12` — `0.36`. Изменение gap: `1.0045 → 1.0041` (−0.04%); bridge: `−0.0045 → −0.0041` (+8.9%).

**Вывод.** Sentinel-доля чувствительна к `τ`, но итоговые метрики — нет (< 0.1%). Порог не является источником систематической ошибки. **Каноническая формулировка sentinel-режимов — §7.**

### E-6. Sample-local Gramians

**Цель.** Проверить, зависит ли Gramian `G_S^-1` от сэмпла. Если да — глобальный кэш некорректен.

**Протокол.** 8 сэмплов, один слой (L12), `E_S` фиксирован. Сравнивается `‖G_a − G_b‖_F / ‖G_a‖_F` для всех пар.

**Результат.** `max ‖G_a − G_b‖_F / ‖G_a‖_F = 2.9×10^-16` (ноль для fp64). Condition number: `min κ = 1.56×10^4`, `max κ = 2.07×10^5`, `mean κ = 4.5×10^4`.

**Вывод.** Gramian — функция только `E_S`, не от сэмпла. Глобальный кэш корректен.

### E-6b. Cross-model Gramians (condition number)

**Цель.** Оценить число обусловленности `E_S^T E_S` для обеих моделей: если велико — Gramian-коррекция неустойчива.

**Протокол.** SVD `E_S^T E_S` (размер `D×D`), `κ = σ_max / σ_min`.

**Результат.**

| Модель | mean κ | min κ | max κ |
| --- | --- | --- | --- |
| Qwen3.5-4B | 7.1×10^2 | 3.4×10^2 | 2.1×10^3 |
| Qwen3.5-0.8B | 1.0×10^3 | 6.4×10^2 | 1.7×10^3 |

**Вывод.** Condition number умеренный (≪ 10^6). Gramian-коррекция числово устойчива для обеих моделей.

### E-8. Gramian-коррекция (абляция)

**Цель.** Проверить, нужна ли Gramian-коррекция (`G_S^-1`) для корректности `J_S_target`.

**Протокол.** Qwen3.5-4B, L6. Сравнивается `J_S_target` с и без `G_S^-1`. Полный протокол и таблица — **E-8a** (§16).

**Результат (кратко).** Без коррекции: `gap = 0.9227`, `bridge = 0.0773` (ложное «выравнивание»). С коррекцией: `gap = 1.0045`, `bridge = −0.0045` (реальное выравнивание — на уровне нуля).

**Вывод.** Gramian-коррекция **обязательна**: без неё метрики дают ложный сигнал.
