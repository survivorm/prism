# ТЗ: E-36. Анатомия gauge — один объект или категория?

**Статус:** exploratory. Не гипотеза-тест, а карта возможных декомпозиций. Результат может быть «gauge — один объект», «gauge — смесь N компонент», или «gauge — операциональный артефакт P, ничего за ним нет». Все три исхода равно информативны, потому что фиксируют природу объекта.

Формат: цель → математика → пять декомпозиций → приоритеты → интерпретация → критерии остановки → артефакты. Все символы по §2 paper.md.

---

## Цель

**Вопрос.** E-33r и E-33r.2 показали, что «gauge-компонента» J ведёт себя неоднородно: uniformity топ-1 ESG варьируется 0.50–0.80, `depth_gain` меняет знак между L18 и L22, `rank(P·J)` теряет 7–12 рангов вместо одного, `Ω ≈ 0.205` при random baseline 0.016. Всё это совместимо с **гипотезой комплексности**: «gauge» — не один объект, а смесь нескольких компонент с разной природой.

Но это также совместимо с **гипотезой операционального артефакта**: «gauge» = «то, что P(p) убивает», а P(p) убивает широкий спектр, зависящий от распределения p_t, и наблюдаемые вариации — просто следствие разного распределения p_t на разных слоях.

**Цель E-36.** Различить эти две картины. Если gauge — смесь, найти её естественные компоненты и их роли. Если артефакт — доказать это напрямую.

**Идеология.** Не строить одну большую гипотезу, а провести пять независимых декомпозиций, каждая из которых даёт ответ на свой подвопрос. Если хотя бы одна декомпозиция показывает разные роли компонент — комплексность реальна. Если все пять дают один и тот же ответ — «gauge» монолитен (или пуст).

**Важно.** Эксперимент не таргетирован. Результат «gauge — один объект» — валидный результат. Результат «gauge — операциональный артефакт, за ним ничего нет» — тоже валидный результат, возможно даже более ценный, потому что закрывает целую ветку рассуждений.

## Математика

**Пространство.** `J_t ∈ R^{K×D}` (K=128, D=1024), правые сингулярные векторы `v_k(t) ∈ R^D`, левые `u_k(t) ∈ R^K`, сингулярные числа `σ_k(t)`. Обозначим:
- `P_U = 1·1ᵀ/K` — проектор на uniform-направление в R^K
- `P_{v_top} = v_1 v_1ᵀ` — проектор на топ-1 правое направление в R^D
- `P_{p_t} = p_t p_tᵀ / ‖p_t‖²` — проектор на p_t в R^K
- `P(p_t) = diag(p_t) − p_t p_tᵀ` — gauge-оператор

**Пять декомпозиций.**

### D1. Uniform vs non-uniform (ортогональная, каноническая)

Разбить `J_t` на две ортогональные части:

$$J_t = J_t^{\parallel U} + J_t^{\perp U}, \quad J_t^{\parallel U} = J_t \cdot P_U, \quad J_t^{\perp U} = J_t \cdot (I - P_U)$$

(действие P_U справа — проекция столбцов J на uniform; это `u_k`-компонента).

Метрики: `‖J^{\parallel U}‖_F`, `‖J^{\perp U}‖_F`; их Δ_SVD по Δt; их межслойная когерентность.

**Ключевой вопрос:** несёт ли Δ_SVD-структуру uniform-часть, не-uniform часть, или обе, или ни одна?

### D2. Спектральная профильность: profile(k) = uniform(e_k)

Для каждого k ∈ {1, …, 8}: `uniformity(u_k) = ⟨u_k, 1/√K⟩²` где `u_k` — k-й левый сингулярный вектор.

Метрики: profile `uniformity(u_k)` vs k для каждого слоя.

**Ключевой вопрос:** существует ли k*, при котором uniformity резко падает? Если да — «gauge-подпространство» имеет размерность k*, и это операциональное определение complex gauge.

### D3. Static p̄ vs dynamic δp_t

Разложить `p_t = p̄ + δp_t`, где `p̄ = mean_t(p_t)`. Соответственно:

$$P(p_t) = P(p̄) + [P(p_t) - P(p̄)]$$

Метрики: применить `P(p̄)` ко всем `J_t` (fixed-P, уже сделано в E-33r.2 Diagnostic A). Сравнить структуру `P(p̄)·J_t` и её дополнения `[P(p_t) − P(p̄)]·J_t`.

**Ключевой вопрос:** структура J живёт в компоненте, которую **убивает** динамическая часть? Или в той, которую она **оставляет**?

### D4. Cross-layer decomposition: invariant vs specific

Для пары слоёв (a, b) и одной позиции t: `u_1(a, t), u_1(b, t)` — топ-1 левые сингулярные векторы. Разложить:

$$u_1(a, t) = \alpha \cdot u_1(b, t) + u_{\perp}(a \to b, t)$$

где `α = ⟨u_1(a, t), u_1(b, t)⟩`, `u_⊥` — ортогональный остаток.

Метрики: `|α|` как функция пары слоёв и позиции; Δ_SVD внутри high-α группы vs low-α группы.

**Ключевой вопрос:** depth_gain sign flip (L6–L18 отриц., L18–L23 положит.) соответствует разным α?

### D5. Positional: p_t-aligned vs p_t-orthogonal

Разложить топ-1 правый сингулярный вектор `v_1(t) ∈ R^D` по отношению к `û_t = h_t / ‖h_t‖` (E-35):

$$v_1(t) = \beta \cdot \hat{u}_t + v_{\perp}(t), \quad \beta = \langle v_1(t), \hat{u}_t \rangle$$

Метрики: `|β(t)|`, `‖v_⊥(t)‖`; Δ_SVD обеих частей.

**Ключевой вопрос:** если структура L23 = траектория û (E-35), то она должна быть в `v_∥`-компоненте. Если структура живёт в `v_⊥`, E-35 неполон.

## Пять экспериментов E-36.1 — E-36.5

Каждый — отдельный прогон, ~15–30 минут CPU на кэше exp27b. Все используют те же слои {6, 12, 18, 22, 23}, 32 документа, sentinel endpoints.

### E-36.1. Uniform vs non-uniform split

**Что делаем.** Для каждого документа и слоя: `J_t^{∥U} = J_t · P_U`, `J_t^{⊥U} = J_t − J_t^{∥U}`. Compute SVD обеих, Δ_SVD(Δt ∈ {1, 4, 8, 16}) каждой части, отдельно от raw J.

**Что смотрим.**
- `‖J^{∥U}‖_F / ‖J‖_F` по слоям: какая доля энергии в uniform.
- `Δ_SVD(∥U, Δ=1)` vs `Δ_SVD(⊥U, Δ=1)` vs `Δ_SVD(raw, Δ=1)`.
- Сравнение `depth_gain` для ∥U и ⊥U частей.

**Возможные исходы.**
- ∥U даёт структуру, ⊥U нет → gauge = uniform, монолитен, структура в uniform.
- ⊥U даёт структуру, ∥U нет → gauge = uniform-«шум», структура в non-uniform части; E-33r мерил не то.
- Обе дают разную структуру → gauge = 2-компонентная смесь.
- Ни одна не даёт структуру → «структура J» не разлагается по uniform-оси; искать в другом месте.

### E-36.2. Спектральный профиль uniformity

**Что делаем.** Для каждого (слой, документ, позиция): `uniformity(u_k)` для k = 1..8. Агрегация: медиана по позициям и документам.

**Что смотрим.** Profile `uniformity(k)` per layer. Ищем колено: где uniformity падает ниже 1/K = 0.0078 (равномерное случайное)?

**Возможные исходы.**
- Резкое колено на k=1 → «gauge» = 1-мерный.
- Плавное падение → «gauge» = k-мерный с распределением.
- Колено на разных k для разных слоёв → «gauge» = слой-зависимый объект.

### E-36.3. Static vs dynamic p_t

**Что делаем.** Два прогона SVD: (1) с `P(p_t)` (уже есть), (2) с `P(p̄)` (fixed-P, E-33r.2 A). Дополнительно: `ΔP_t = P(p_t) − P(p̄)`, применить к `J_t`, SVD.

**Что смотрим.** Δ_SVD каждой из трёх версий. Сравнить с raw.

**Возможные исходы.**
- `P(p̄)·J` имеет малый Δ_SVD (структура), `ΔP_t·J` — нет → structure position-invariant, dynamic часть — шум.
- Наоборот → structure position-specific, static часть — шум.
- Обе имеют структуру → 2-компонентная position-decomposition.

### E-36.4. Cross-layer invariant vs specific

**Что делаем.** Для пар (6,12), (12,18), (18,22), (22,23) и каждой позиции: `α(t) = ⟨u_1(a,t), u_1(b,t)⟩`. Разделить позиции на Q1 (low |α|) и Q4 (high |α|). Δ_SVD внутри каждой группы.

**Что смотрим.** `Δ_SVD_Q1` vs `Δ_SVD_Q4` для каждой пары. И `|α|` profile по парам.

**Возможные исходы.**
- Q4 имеет малое Δ_SVD, Q1 большое → gauge имеет layer-invariant компоненту, несущую структуру.
- Одинаковы → layer-invariant и layer-specific части структурно эквивалентны.

### E-36.5. û-aligned vs û-orthogonal

**Что делаем.** Из E-35: `J_raw^{L23} = M_K · (√D/r) · (I − ûûᵀ)`. Значит `v_1(L23)` ⊥ û по построению. Проверить это число: `⟨v_1(t), û_t⟩` для всех слоёв. Для L23 должно быть 0, для L6–L22 — произвольно.

**Что смотрим.** `|⟨v_1(t), û_t⟩|` по слоям. И Δ_SVD `v_1`-части vs raw.

**Возможные исходы.**
- L23: ровно 0 → факторизация E-35 подтверждена, но структура v_1 не в û.
- L6–L18: значимо ≠ 0 → на промежуточных слоях v_1 имеет û-компоненту, что не следует из факторизации.

## Интерпретация (сводная)

| Наблюдение | Что означает |
|---|---|
| E-36.1: `‖J^{∥U}‖/‖J‖` ≈ uniformity_0 | Uniform split эквивалентен стандартной мере; структура не разлагается по uniform-оси. |
| E-36.1: ∥U несёт Δ_SVD, ⊥U не несёт | «Gauge = uniform», монолитен; E-33r мерил правильный объект. |
| E-36.1: ⊥U несёт Δ_SVD, ∥U не несёт | «Gauge» — артефакт uniformity-оси; структура живёт в differential части (что странно, потому что P её убивает). |
| E-36.2: profile uniformity(k) имеет колено на k=1 | Gauge = 1-мерный объект. |
| E-36.2: profile плавно падает | Gauge = многомерная категория без чёткой размерности. |
| E-36.2: колено на разных k для разных слоёв | Gauge = layer-dependent размерность; фундаментальная вариативность. |
| E-36.3: структура в `P(p̄)·J` | Gauge = position-invariant; dynamic часть — шум. |
| E-36.3: структура в `ΔP_t·J` | Gauge = position-dependent по своей природе; E-33r.2 частично это показал. |
| E-36.4: high-α группа имеет малый Δ_SVD | Gauge = layer-invariant; depth_gain sign flip объясняется размером инвариантной части. |
| E-36.5: L23 `⟨v_1, û⟩ = 0` точно | Факторизация E-35 подтверждена; структура v_1 не в û-направлении. |
| E-36.5: на L6–L18 `⟨v_1, û⟩ ≠ 0` | Промежуточные слои имеют û-компоненту в gauge; качественное отличие от L23. |

**Возможные итоговые формулировки.**

**(A) Gauge = один объект.** Все пять декомпозиций дают один и тот же ответ: структура в uniform-части, position-invariant, layer-invariant, top-1. Depth_gain sign flip — масштабный эффект. E-33r/E-33r.2 закрыты как «gauge = uniform mode».

**(B) Gauge = смесь.** E-36.1 показывает разные роли ∥U и ⊥U; E-36.2 даёт колено на k > 1; E-36.3 даёт разные структуры для static и dynamic. Формулировка: «gauge — категория объектов: uniform-сдвиг + top-2..k-структура + position-invariant компонента; каждая со своей ролью».

**(C) Gauge = артефакт P.** Все пять декомпозиций показывают, что разные срезы P действуют на разные части J, но нет выделенной «gauge-компоненты». P — широкополосный фильтр, «gauge» — термин без референта. Это **полезный отрицательный результат**: закрывает целую линию рассуждений (P1-защита, E-33r, E-33r.2).

Все три исхода равноценны как результаты. Предсказать, какой получится, на текущих данных нельзя.

## Критерии остановки

- **Preflight (E-36.1 + E-36.2 + E-36.5)**: один прогон, ~1 час. Даёт ответ на три вопроса из пяти.
- Если три preflight-прогона дают **консистентный** ответ (все указывают на A, B или C) → развернуть E-36.3, E-36.4, приоритеты 1–2.
- Если preflight даёт **неконсистентные** ответы (E-36.1 говорит A, E-36.2 говорит B) → **это уже результат**: «gauge операционально многозначен; разные определения дают разные ответы». Остановиться, зафиксировать как observation.
- Если результаты всех пяти декомпозиций одинаковы → **насыщение карты**, дальше не разворачивать.
- Полная версия (все 5 слоёв, bootstrap CI, стратификация) — только если пилот на L23+18 показывает чёткую комплексность.

**Стоимость.** Preflight ~1 час CPU. Полная версия ~4 часа CPU. Не требует GPU, всё на exp27b dense-кэше.
