## Найденное и исправленное

### M1 (MAJOR): щель в партиции вердиктов — ИСПРАВЛЕНО (r2)
Пре-рег v1: (a) «CI целиком < −0.02», (b) «CI содержит 0 **или** Δ ≥ −0.02»,
(c) «CI целиком > +0.02». Контрпример: CI = [−0.07, −0.01] (целиком < 0, но не
ниже −0.02): (a) нет (верх −0.01 > −0.02), (b) нет (0 вне CI, Δ = −0.05 < −0.02),
(c) нет → вердикт не определён. Правка r2: **(b) = всё, что не (a) и не (c)**,
с под-метками weak / insufficient_power (описательно). Партиция полная.

### M2 (MINOR): fp16-шум бинации TF без отчёта — ИСПРАВЛЕНО (r2)
TF-margin из fp16-состояний (maxdiff логитов ~4, типичный ~0.02 на margin) может
перекидывать позиции между квантилями вблизи границ (width бина ~0.45 → ~4%
позиций в ±0.05 от границы). Правка r2: описательное поле `bin_boundary_frac`
(frac позиций в ±0.05 от ближайшей границы, на сторону) — без гейта (шум
независим от margin → размывает контраст, не смещает его; gen-сторона — saved fp64).

  dropped = 0 во всех 32 (док, слой) — ok-маска не теряет позиции.

  доков в бинах допустимо.
