## A: state tol 1e-9 может дать fail на вырожденном h (‖row‖ < 1e-12)

**Принято как осознанное поведение.** Механизм ревью верен: `u = h/max(‖row‖, 1e-12)` —
при ‖row‖ < 1e-12 делитель — 1e-12, ‖u‖ = ‖row‖/1e-12 ≪ 1 → пин падает. Это **desired
fail-loud на degenerate h** (ревью это и говорит: «скорее всего desired, но стоит
осознать»). Зафиксировано: docstring `g0a_hn_gate` + поле `gates.G0a_hn_field.state.edge`
в claim. Тест: вырожденная строка (‖row‖ = 1e-15) → **CAUGHT** (‖u‖ = 1e-3 > 1e-9).
В текущих данных таких строк нет (замер: state unit-dev 3.33e-16).

ПЕРМУТИРОВАННЫЙ _hn (mean/rms/CV инвариантны к перестановке)». Дополнительный guard
ревью («корреляция _hn с ‖_u·_hn‖ поэлементно») — это пересчёт h из тех же полей,
т.е. tавтология (‖U·hn‖_row = hn по строке тождественно), реальной проверки не даёт.
