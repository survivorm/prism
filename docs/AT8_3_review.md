## F1. Варьирующий горизонт делает статус функцией длины документа

Арифметику фикса проверил — она верна:

| T | cut | T−cut | D = T−cut−1 |
|---|---|---|---|
| 256 | 128 | 128 | **127** |
| 254 | 127 | 127 | 126 |
| 238 | 119 | 119 | 118 |
| 205 | 102 | 103 | 102 |
| 200 | 100 | 100 | 99 |
| 196 | 98 | 98 | **97** |

Диапазоны «98…128 / 97…127» сходятся. Индексация корректна: `A_spec` считается на **состояниях**, поэтому `d_max = T−cut−1` (последний токен суффикса), а не −2. ✓

**Но:** в ТЗ `PERSISTENT` = «нет окна m=8 ниже floor **до горизонта D**». Теперь D = 97…127:

- док с D=97 объявляется PERSISTENT, если возмущение держится 97 позиций;
- док с D=127 — только если держится 127.

Если истинная длина релаксации лежит между 97 и 127, **короткие доки дадут LOCALIZED, длинные — PERSISTENT**, и `frac` будет определяться составом пула (5 коротких из 16 = 31%), а не физикой. Это флиппер на границе порога 0.5.

Второй аспект того же: **позиционный `δ_min(d)` при d ∈ [98,127] оценивается по 11 докам вместо 16** — порог меняет и точность, и популяцию по ходу горизонта.

**Фикс:** зафиксировать **общий оценочный горизонт `H_eval = min_i D_i = 97`** (или 96 для круглости) — один для всех доков, для всех статусов и для δ_min. Полный D оставить как вторичную диагностику (`ξ_full`, `PERSISTENT_full`). Цена не меняется: те же форварды, только анализ.

Смоук-окно 0…64 при min D=97 влезает ✓ — здесь всё чисто.

## F2. «NO_RESPONSE на вердикт не влияет» — неверно при знаменателе 16

Цепочка агрегации из ТЗ: `frac_persistent(n) = #PERSISTENT/16`, `frac_localized(n) = #LOCALIZED/16`.

**Знаменатель фиксирован 16 и включает NO_RESPONSE и LAYER_INCONSISTENT.** Значит:

```
9 доков NO_RESPONSE  →  max frac_localized = 7/16 = 0.4375 < 0.5
                     →  LOCALIZED недостижим по этой дозе
8 доков NO_RESPONSE  →  max frac_localized = 8/16 = 0.5  (ровно порог)
```

NO_RESPONSE **прямо управляет достижимостью вердикта**. Заявление верно только при знаменателе «#доков с определённым статусом» — но это другая формула, и её надо объявить.

Оба варианта законны, выбор меняет исход:

| знаменатель | эффект | риск |
|---|---|---|
| 16 (как в ТЗ) | NO_RESPONSE размывает обе доли | смещение к NOT_RESOLVED; «нет отклика» читается как «не локализовано» |
| #resolved | NO_RESPONSE исключён | frac может считаться по 3 докам из 3 → 1.0 на трёх наблюдениях |

**Фикс:** явно пре-регистрировать знаменатель + обязательный отчёт `n_resolved(n)` и `n_no_response(n)`; при `#resolved < 8` — тег `LOW_POWER` и вердикт по этой дозе не выносится.

## F3. Арифметика «CI95 исключает 0.5 только при ≥14/16» не воспроизводится

Посчитал порог `k`, при котором нижняя граница 95% CI доли превышает 0.5, при n=16:

| метод | первый k с CI_lower > 0.5 | доля |
|---|---|---|
| Clopper–Pearson | **13** (lower ≈ 0.544; при 12 → ≈ 0.476) | 0.8125 |
| Wilson | **12** (lower ≈ 0.505) | 0.750 |
| normal approx | **12** (0.75 − 1.96·0.1083 = 0.538) | 0.750 |
| doc-bootstrap percentile | **12** (≈ 0.538) | 0.750 |

Ни один не даёт 14/16 = 0.875. Проверил и меньшие знаменатели (если после слой-фильтра resolved < 16): n=14 → порог 10/14 = 0.714; n=12 → 10/12 = 0.833. Тоже не 0.875.

**Плюс концептуальная подмена.** «Недостижимая ветка» в смысле G10 — это условие, **тождественно ложное** (как `CI_upper ≤ 0` под нулём в AT2d, или `ratio ≤ 2` при полном невосстановлении в AT8_2). Требование 14/16 — не тождество, а **высокая планка**, достижимая при сильном эффекте. Строгий критерий законен; тождественно мёртвый — нет. Аргумент «сделал бы вердикт недостижимым» не обосновывает снятие CI.

Итог: правило решения ослаблено (CI выведен из вердикта) на основании неверной арифметики и неверной классификации. Это ровно тот класс, который мы шесть раундов ловили в AT2d.

**Фикс:** предъявить метод и таблицу `k → CI_lower` для k = 8…16. Если подтвердится 12–13 — **вернуть CI-гейт** (`CI_lower(frac) > 0.5`) либо честно объявить: «выбран точечный критерий, потому что при n=16 CI широк; риск ложного вердикта при p̂ ≈ 0.5 признан», и тогда — см. F4.

## F4. Порог `≥ 0.5` при 8/16 — вердикт на монетке; WIDE_CI декоративен

Это дефект **моего** ТЗ v1.0, который фикс 6 не закрыл, а усугубил.

`frac_localized ≥ 0.5` при 16 доках пропускает **ровно 8/16** — точку максимальной неопределённости, где CI гарантированно накрывает 0.5. С снятым CI-гейтом вердикт `LOCALIZED` выносится на подбрасывании монеты, а `WIDE_CI` остаётся тегом в отчёте — то же, что `W8_noisy_flag` в AT8_2 r1 (декоративный флаг).

**Фикс (один из двух, объявить до прогона):**
- строгое `frac > 0.5` (тогда 8/16 не проходит, нужно ≥9);
- либо `≥ 0.5` **с блокирующим** `WIDE_CI`: если CI95(frac) накрывает 0.5 → `NOT_RESOLVED`, тег становится гейтом.

Второй вариант ближе к духу «CI обязателен», первый дешевле. Оба снимают монетку.

## F5. Гейт филлеров `≥3` структурно слеп к лупу при малых дозах

Смягчение до «count ≥ 3» разумно для 144-токенного окна: единичный повтор 9-граммы (18 из 144 токенов) — текстовый шум, не луп. Здесь согласен, и измерение «максимум = 2 по всем 16» — правильный способ закрыть вопрос.

**Но гейт применяется к филлер-окну длиной `L_n = 9n`, а не всегда 144:**

```
n=2  → L_n=18 → окно = ДВЕ 9-граммы
     → если они идентичны, count = 2
     → гейт «≥3» НЕ срабатывает
     → филлер = (некоторая фраза)×2 проходит как «не-луп»
```

Тогда контраст на n=2 — это **луп против лупа**, `A_spec ≈ 0` по построению → `NO_RESPONSE` на этой дозе гарантирован, независимо от физики. При n=4 (36 токенов) count=2 означает половину окна, тоже существенно.

Заявленный максимум 2 измерен «в первых 144 токенах» — это не отвечает на вопрос про первые 18/36.

**Фикс:** доз-зависимая проверка. Для каждой дозы n и каждого филлера: `max count любой 9-граммы в окне [0, 9n) ≤ 1` при n ≤ 4 (или эквивалентно: окно не периодично с периодом 9). Отчитать **per-dose таблицу** max count, а не один максимум по 144. Плюс процедура замены филлера при провале (взять следующий док), иначе гейт остановит прогон на текстовом шуме.

## Мелочи

**m1. `LAYER_INCONSISTENT` смешивает противоречие и неполноту.** «≥3 из 4 слоёв одного статуса» не выполняется и при 2 LOCALIZED + 2 PERSISTENT (противоречие), и при 2 LOCALIZED + 2 NO_RESPONSE (частичный отклик). Это разные состояния; второй — не несогласованность. Развести теги: `LAYER_CONFLICT` vs `LAYER_PARTIAL`. Тот же пункт, что F6 в AT8_2-R2.

**m2. sha-сериализация.** Второй инцидент с sha в этом ТЗ. `sha256(json.dumps(...))` зависит от separators/ensure_ascii — надо зафиксировать точную форму (или унифицировать с AT8_2: `sha256(np.asarray(ids, dtype=int64).tobytes())`, одна функция на все артефакты). И **список rand-блока должен лежать в артефакте**, не только sha: иначе воспроизводимость зависит от версии `default_rng`.

**m3. Горизонт вторичных наблюдаемых.** `A_spec` на состояниях → `d ≤ T−cut−1`. Lag-1 cos на приращениях → `d ≤ T−cut−3`. Если вторичные считаются на том же D — IndexError или молчаливое усечение. Объявить общий `min` или per-observable горизонт.

**m4. rand-блок `uniform(0, 248320)`** включает зарезервированные id — вход вне обученного распределения. Для positive control это допустимо (нужно большое возмущение), но вывод про чувствительность — качественный, не «естественный текст». Одна строка в границы.

## Что принято без возражений

Отдельно отмечу качество **фикса 2**: неоднозначность `rep_rate` закрыта не спором об определении, а показом, что первые 4 в порядке пина совпадают при всех трактовках → множество 16 доков инвариантно. Это правильный способ снять произвол в правиле, и его стоит зафиксировать как приём в общий протокол. Расхождение «math 10 → 11» объяснено сменой правила v1(≥3) → v2(≥4) — честная самокоррекция, не подгонка.

Фикс 1 (T≠256) — тоже корректная самокоррекция моего же непроверенного утверждения; арифметику cut/D сверил построчно, она верна. Претензия не к факту, а к тому, что varying-горизонт не был доведён до вердиктной логики.
