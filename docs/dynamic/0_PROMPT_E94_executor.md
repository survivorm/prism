## 2. Что строишь
Один `llama-server` (`-m /data/Qwen/Qwen3.5-0.8B-Q4_K_M.gguf -sm none -mg 0 -ngl 99 -fa on -c 2048
-np 1 --host 127.0.0.1 --port <free> --log-disable`), stdout/stderr только в файл. Готовность — GET `/health`.
Устройства — GET `/metrics`: `decode_device` обязан содержать SYCL/Iris, иначе `RUN_RC=10` (не «починить»,
а остановиться и задокументировать).

Три фазы, строго в порядке ТЗ §2:
- **spike** (до любого кода метрик): (а) 1 запрос Q1 на `w0` → зафиксировать фактическую схему ответа и
  имена ключей; (б) **prompt-count гейт**: `tokens_evaluated == 64`; (в) **гейт кэша**: `k=64` против `k=128`
  при `cache_prompt:true` → `tokens_cached ≥ k-2` и отсутствие роста prompt-времени; (г) время на позицию →
  Extrapolation и **выбор скоупа Q2 (число доков) до полного прогона**, потолок 40 мин; (д) эхо
  `generation_settings` сверяется с посланными штрафами; (е) поведенческий пробы `repeat_penalty:1.1`.
  Результат — `results/e94/FORMAT.md` (схема, гейты, скоуп, отклонения). Провал гейта → `RUN_RC=2/13`.
- **Q1**: 16 доков × r=2, `prompt` = HF-иды (64), `n_predict 384`, temp 0, штрафы нулевые,
  `logprobs:true, top_logprobs:2`, `cache_prompt:false`, seed 8181. Сырые ответы → `/tmp/e94raw/q1_*`
  (идемпотентно: существующий файл не перезапрашивается). Метрики ТЗ §2.1: `prefix_len/384`, rep8
  (формула exp81b дословно, `off=64`, 12 сегментов, `rep8=mean(segments['8'])`) против CPU-той же функции,
  медиана |Δrep8| главная, тай-корректный Spearman + пермутационный null (2000, seed 8181) вспомогательно,
  `repro_rate` r=1/r=2 с гейтом 0.95 и судьбой «non-interpretable (determinism)».
- **Q2/Q3**: teacher-forced probe `prompt = ids[:k]`, `n_predict:1`, `cache_prompt:true`
  (k = 65..448) на выбранном spike'ом подset'е; CPU-референс — transformers fp32, один forward на док,
  **обязательно воспроизводящий `REPLAY.gen_p1` с max|Δ| < 1e-3** (иначе `RUN_RC=14` и Q2 не считается).
  Метрики ТЗ §2.2 (медиана |Δp_max|, доля |Δ|<0.05, top-2 hit rate в обе стороны, top1_agree,
  Spearman с null) и §2.3 (`margin = p_top1 − p_top2`, корреляции **внутри** движка, null каждой;
  кросс-движковое смешение позиций запрещено).
- **Q4** (побочно, 16 запросов `/tokenize` по текстам) — `tok_drift`, в Q1/Q2 не участвует.

## 4. Порядок работы (не переставлять)
1. §0 → список всех имён полей/флагов с grep-доказательствами (в `0_E94_EXEC_NOTES.md`).
2. Код. **Само-аудит ДО запуска** по чек-листу `AGENTS.md`: одинаковая статистика на обеих сторонах;

6. Не коммитить. Последняя строка stdout: `E94_EXEC_DONE` либо `E94_FAIL <фаза>:<RUN_RC>`;
