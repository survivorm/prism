# Аудит E-50/E-52: математика и логика (2026-11-07)

Само-аудит по просьбе + перечитывание `docs/E52_review.md` (оба раунда).
Каждый пункт — вердикт с доказательством (строка кода или эмпирика).

## E52_review: разбор пунктов

### R1 (раунд 2 §1). `synth_white_matched` сломан в √r — ОТВЕРГНУТ
`frame_kinematics` возвращает `(s, p, P, Θ)`, и `s = sqrt(Σθᵢ²) = ‖Θ‖₂` —
во Фробениус-норме, не θ_max (docstring: «s = ||Θ||_2, p = Θ_max/s»).
Суррогат крутит все r плоскостей на `step/√r` ⇒ ‖Θ‖₂ суррогата = step — матчинг
точный. **Эмпирическая проверка, которую просил ревьюер** (knn_probe, wiki_0):
`mean_step(real)=0.0979, mean_step(sur)=0.0979` — совпадение полное.
Аргумент ревьюера про E-28 (Δ=0.266=15.3° «значит θ_max») не выдерживает:
0.266 — и есть ‖Θ‖₂ доминирующей связки углов. Числа Δ_d16 в силе.

### R2 (раунд 2 §2). `kinetic_decomposition` без Procrustes ⇒ rad_share артефакт — ОТВЕРГНУТ
`prism/kinetic.py:112-121`: `align_signs_and_columns(U0,U1)`/`(V0,V1)` — знаки И
столбцы согласуются до дифференцирования, σ едет ЗА согласованными столбцами
(`Sig_t1 = diag(S1[permU])`, M2-fix), несогласия флагуются
(`sigma_perm_mismatch`, `order_cross_U/V`). E_radial сравнивает σ в согласованном
базисе. 0.26% — не артефакт рассогласования.

### R3 (оба раунда). `rtn` in-place — ОТВЕРГНУТ
`rtn` = `(clamp((A/sc).round(),...) * sc)` — только функциональные опсы, A не
мутируется. base в e52a/e52e — настоящий fp.

### R4. `g = load_model.last_g` — ПОДТВЕРЖДЁН как design smell, не баг
`load_model.last_g = g` в рабочей версии ЕСТЬ (exp49_leaf_info.py, перед return) —
AttributeError нет. Все прогоны e52e легитимны. Скрытая зависимость реальна
(второй load_model перезапишет) — в текущих скриптах один load на процесс;
лечится явным возвратом при следующем касании файла.

### R5. Нет контролей τ_amp² — ПОДТВЕРЖДЁН, ИСПОЛНЕНО (`exp52f_amp_controls.py`)
MC (R=16, T=96):
| контроль | τ_amp² |
|---|---|
| геодезика (линейный дрейф + малый шум) | **0.0008** |
| белый iid (позиции) | 0.9996 |
| **белое случайное блуждание** | **0.5783** |
| тесные σ, с сортировкой vs без | 1.0012 vs 1.0015 (перескок НЕ смещает) |
| геодезика + fp16 round-trip | 0.0024 (fp16 шум ничтожен) |
| дрейф+умеренный шум+сортировка | 0.667 |

Вывод: метрика корректна (геодезика→0); правильный верхний эталон для
ТРАЕТОРИИ — 0.578 (константа 2−√2 относится к блужданию, не к iid-позициям).
Реальные τ_amp² = 0.326 (q08b) / 0.429 (lfm3) — МЕЖДУ геодезикой и белым,
57%/74% белого константы → структурированный сигнал, ранжирование архитектур
сохраняется (lfm «шумнее» по амплитуде, как и по τ_geo? нет — наоборот; амплитуда
и геометрия ранжируют иначе, что само по себе аргумент независимости).

### R6. Кеш SVD vs пересчёт в e52e — ПОДТВЕРЖДЁН, ИСПРАВЛЕНО
`set(svs)==range` действительно никогда True при T=96 ⇒ τ_amp² пересчитывал SVD.
Численно разницы нет (тот же fp64 вход ⇒ побитово те же σ, LAPACK детерминирован;
знаки U,V на σ не влияют), но расточительно и неаккуратно. Исправлено: один
`allsv` на все кадры, τ_amp²/rad_share/статика из него. Добавлен пер-док
диагност `jump_gap_ratio` (шаг σ против разрыва σ-уровней — чувствительность к
перескоку). Числа q08b/lfm3 НЕ меняются (тот же σ), пересчёт не требуется.

### R7. Формулировка «константа среды» — ПРИНЯТО, переформулировка
Два отдельных факта: (1) τ_amp² не годится как health-ось: не отслеживает
гибель τ_geo (flat: τ_geo→0, τ_amp² растёт) и не реагирует на rtn-квантование;
(2) два канала НЕ избыточны: под flat амплитудный отклик РАЗРАСТАЕТСЯ
(0.326→0.42, к белому 0.578) — неаддитивность каналов, перекладывание структуры.
«Константа среды» — переобещание, снято.

### R8. Мелочи ревью — статус
- краевой эффект W−1: документирован в `smoothed_us`; e52a/e52e НЕ отбрасывают
  первые W−1 (обещание в docstring не выполнено) — парные сравнения симметричны,
  смещение II рода; завести отбрасывание при следующем касании.
- один xi на все доки в u_ns — так и в e52a, согласовано (когерентное nuisance-
  направление, не iid шум — помечено в аудите как семантика семейства).
- `_EYE16/_TAG/_DEV` — однопоточные прогоны, глобалки безопасны (per-tag max-
  диагностика не сбрасывается — осознанно).
- knn-фолбэк на случайный выбор — лечится в v4.1 (ниже), плюс fall-back-фракция
  теперь пишется в диагностику.
- fp16 u в npz — контроль Q4: вклад ≤0.002 в τ_amp², в κ (0.01) ~10% — принято.

## Собственные находки аудита (не было в ревью)

### A1. E-50v4 knn-null: ШАГ не сматчен — КРИТИЧНО, исправлено (v4.1)
Пробник (wiki_0, L=16): шаг kNN-пути **0.185 против реального 0.098** (×1.9) —
самоизбегающий обход шагает через ~2 временны́х шага. κ_knn = 0.0084–0.0127
против κ_real = 0.0010: раздуто и порядком (площадь полигона ∝ шаг²), и порядком
обхода — Δ_knn был бы конфаундом в сторон sub_geodesic. **Фикс v4.1**: band-knn —
переходы только с sim в полосе [q25,q75] соседних пар реального пути;
per-doc `knn_step_ratio`, `knn_fallback_frac`. Промежуточный прогон 3×3 доков
убит (главный вердит-параметр был бы неинтерпретируем).
Важно: фикс записан ДО вердиктных чисел; основание — диагностические контрольные
числа null-семейства (шаг), не данные вердикта.

### A2. E-50v4 rev-гейт сравнивал РАЗНЫЕ окна — исправлено
Позиция i перевёрнутого пути = полигон реального пути на старте T−1−L−i
(петля→P⁻¹, углы Шюра идентичны). Прежний «средний по позициям» гейт с порогом
1e-6 был размыт. Теперь точное парное сравнение max|·| (пробник: 9.5e-10 —
пайплайн замкнут; гейт стал настоящим канари).

### A3. e47b route-проверка и bf16 — исправлено (e52k v6)
`max|H@W_Uᵀ − logits_U| < 1e-3` — абсолютный порог, убитый bf16-округлением на
масштабе логитов (~30): честные 3e-2 ловили assert на всех заходах Kaggle.
Теперь `rt < 1e-3 ИЛИ rel = rt/max|logits| < 2e-2`. Гейт при этом живой: ровно
он и поймал бы прежнюю ошибку семантики нормы — не пропустил.

### A4. e52k:Prev-кэш Kaggle мог возвращать НЕДОКАЧАННУЮ модель — исправлено
Self-source монтирует /kaggle/working прошлого versions с частичными shard'ами
(ENOSPC на 9B). Добавлена проверка полноты `-of-N` перед использованием prev.

### A5. Мелочи
- e52k n_docs=4 в трассе vs `--n-docs 16` в e52a — безвредно (обрезается по npz),
  но вводит в заблуждение; поправить label.
- `knn_path` симметрия S: ‖VᵀV‖_F² — корректная метрика соседства (не расстояние,
  но для топ-k достаточно; диагональ исключена).
- `tau_triplets` фильтр `x > 1e-6` — на реальных трассах срабатывает редко
  (проверено amb_frac ≈ 0).
- v4 summary при пустом списке доков: med по пустому → nan + boot_ci [None,None]
  — осознанно (снаружи видно n=0).

## 4B-сюрприз: разбор по запросу ревьюера (2026-11-07, второй заход)

Три дешёвых запроса по rtn2 на 4B (все из лежащих JSON, N=16 пар):

1. **Δτ_amp² = −0.063, CI [−0.087, −0.011], 13/16** — значимо, НЕ шум.
2. **Δrad_share = +0.00009, CI [−0.000, +0.0003] (∋0), 9/16** — энергия канала НЕ
   меняется (0.193%→0.220%); сдвигается только аддитивность σ-траектории.
3. **Spearman(τ_geo, τ_amp²) по base-докам = +0.37** (N=16 ⇒ CI закрывает 0);
   Spearman(Δτ_geo, Δτ_amp²) = **−0.33** — под квантом оси движутся РАЗНОнаправленно.
   Чтение «одна ось ёмкости» (C′) не подтверждается ни по уровням, ни по Δ.

**Q6-контроль (exp52f, решающий):** τ_amp² на синтетической траектории, сжатой
symmetric-RTN сеткой, БЕЗ изменения динамики: 2-bit **0.667→0.046**, 3-bit 0.622,
8-bit 0.692. Залипание σ(t) на сетке {−g,0,+g} делает траекторию кусочно-
постоянной и задёшево «аддитивной». Значит −0.063 на 4B rtn2 (2-bit) —
преимущественно **сеточный артефакт метрики**, а не отклик амплитуды на квант;
реальный вклад ≤ этой доли и неотличим от нуля имеющимся разрешением.

**Итог E-52:** закрывается в текущей формулировке: τ_amp² — не health-ось;
каналы неаддитивны (flat-активация остаётся фактом); 4B-исключение — артефакт
2-bit сетки (Q6), а не C′.

**Поправка формулировки (принято):** по 0.8B/lfm3 — «эффект масштаба ~5× ниже
разрешения (ожидаемый ~0.015 при CI ±0.02), НЕ отвергнут», а не «мёртвая ось».
Ограничение интерпретации, не претензия.

## Итог по «подозрениям»
Живыми оказались ровно те места, которые обычно и ломают выводы: null без
матчинга шага (A1), гейт не на том (A2), порог без масштаба (A3), кэш без
целостности (A4). Два «критичных» подозрения ревью (√r-матчинг, отсутствие
Procrustes) опровергнуты кодом и контрольным числом; rtn/last_g — безопасны.
τ_amp² обзавёлся контролями: 0.326 между геодезикой (0) и белым (0.578),
метрика корректна; health-осью не является, независимость каналов — факт.
