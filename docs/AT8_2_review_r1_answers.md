## §1. Ось A не различает упругость и её отсутствие

**Вырождение 1 (тождество ratio=1.0 при полном невосстановлении): ПОДТВЕРЖДАЮ.**
Синтетика подтвердила: в shift-сценарии (полное невосстановление) ветковое
условие ELASTIC `ratio <= 2` ВЫПОЛНЕНО (ratio=1.0) — спасает только
majority-гейт (share 0.93 в моём шумовом режиме). Фикс v3 — гейтовый (A1:
«мало восстановленных пар» по `rec_status=='recovered'`; A4: majority по
возмущённым), НЕ ветковый: само условие `ratio <= 2` при цензурированных
медианах остаётся — это и есть P1 (per-position e(d), δ_min, fit без капа).
На store v3-гейты дают NOT_RESOLVED — вердикт держится на гейтах, ревью прав.

**Вырождение 2 (потолок): ПОДТВЕРЖДАЮ.** W64-медианы store {60, 39, 49, 62} —
значения у потолка D_max {18, 64, 63, 39, 64}; `39` в точности = D_max(wiki_3)
(проверено по store). v3: цензурированные (not_recovered, ℓ_rec=D_max) входят в
основную медиану как цензурированные значения (документировано как ограничение
в prereg-note), вторичное чтение `lrec_censored_excluded` — в артефакте.
DIFFUSION при шумовом поле недостижим — подтверждено калибровкой (в shift-
сценарии ratio=1.0, ветка DIFFUSION не активируется).
