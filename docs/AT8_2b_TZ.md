# AT8_2b — ТЗ (пре-рег): второй стимул (loop2) — «повторение» vs «фраза», факторный дизайн 2×2

**Статус: пре-рег (TZ v1.2, 18.11).** v1.1 → v1.2 по ревью r2
(`docs/AT8_2b_review_r2.md`, sha `9195b81e…`; ответы —
`docs/AT8_2b_review_r2_answers.md`): **per-doc shuffle-сиды** (F1,
AT2d-B1); `S2'` + терм-непересекающийся нуль `N_PHR = S1' − S2'` (F2,
тождество `N_content = PHR − INT` зафиксировано); `G_inside_rep` на обеих
первичных дозах про shuffle-строки (F3, filler-гейт → диагностика);
per-контраст наблюдаемые: PHR → **norm_delta**, REP → **cos_raw** (F4,
P0 по R2-store); δ-пул сохранён как **проверенное допущение** (F5,
ratio 1.149); legacy-якорь — **все 4 дозы** R2-store verbatim (m2);
estimand REP: «периодический vs случайный порядок при том же мультисете»
(m3); shuffle-гейты — диагностика (m1); store — массивы контрастов +
block-CE (m4); FWER ≈ 4.9% (текст).

## 1. Одна строка и вопрос

R2-вердикт `NO_LOOP_SPECIFIC_EFFECT` (machine r2d) bounds контраст
`e_spec = loop − fillerA`, который одновременно несёт **«запоминаемое vs
новое»** И **«повторение vs не-повторение»** (TZ R2 §10, r2d-1.1). 2b
разделяет эти гипотезы вторым стимулом — **другой** фразой, повторённой n
раз, и факторным дизайном, где каждый канал меряется контрастом со своим
нулём:

- **H_phr (фраза-канал):** специфическое *содержание* повторяемой фразы
  (запоминание именно этой фразы) создаёт пост-эффект.
- **H_rep (повторение-канал):** *периодический порядок* при **том же
  лексическом составе** (случайный порядок того же мультисета) создаёт
  пост-эффект.

Вопрос: какой из каналов (ни один / один / оба) несёт специфический локальный
пост-эффект поля при разрешении филлер-вариативности (нули из shuffled-
условий, §8)?

## 2. Главный сдвиг дизайна (от R2 и от 2b v1.0/v1.1)

- **2×2 {периодичность × содержимое} + независимые нули:** клетки `L1`
  (loop1, R2-store), `L2` (loop2, новый), `S1`/`S2` (shuffle
  phrase1×n / phrase2×n — новые), `S1'`/`S2'` (вторая независимая
  выборка shuffle — новые; `S1'` — чистый нуль REP, `S2'` —
  терм-непересекающийся нуль PHR).
- **Ортогональные контрасты** (коэффициенты ±1/2, попарно
  неперекрывающиеся): `REP`, `PHR`, `INT` (§7); каждый вердиктный
  контраст — со **своим нулём** (§7.2) на **своей наблюдаемой** (§7.3).
- **Per-doc shuffle-сиды** (F1): каждый док получает свой draw —
  draw-дисперсия входит в doc-bootstrap (прецедент AT2d-B1).
- **Дозы: n ∈ {2, 16}** (PHR primary n=2 — контент жив; REP primary n=16 —
  максимальная доза периодичности; n=4/8 не гоняются — R2-плато).
- **R2-store заморожен и переиспользуется**: ctrl, loop1, fillerA,
  fillerB — read-only из `results/AT8/AT8_2_R2_store.json` (sha §10) на
  n=2 и n=16.
- Новые форварды: **5 условий × 14 доков × 2 дозы = 140** (R2: 182).
- Вердикт-машина R2 (per-doc δ, CI-правила, finite-гейт, doc-bootstrap) —
  сохраняется; меняются контрасты, нули, дозы, наблюдаемые, гейты, дерево
  (§11).

## 3. Стимулы

- **loop1 (зафиксирован R2):** `" The class will be held at the park."` —
  `PHRASE1_IDS = [561, 523, 668, 381, 5467, 506, 279, 5926, 13]` (9 токенов;
  13 = «.»).
- **loop2 (новый, зафиксирован пре-регом v1.0, без изменений):**
  `" Three new buses wait near a quiet station."` —
  `PHRASE2_IDS = [14095, 491, 32275, 3655, 3043, 264, 11012, 7803, 13]`
  (9 токенов; верифицировано токенизатором Qwen3.5-0.8B; пересечение
  контент-токенов с phrase1 = ∅, общий только 13 «.»).
- **Shuffled-условия (новые, зафиксированы ЭТИМ пре-регом):**
  - `L_i(n)` = токен-последовательность `PHRASE_i_IDS × n` (длина
    `L_n = 9n`);
  - `S_i(n, doc)` = `L_i(n)[π_{i,doc,n}]`, где
    **`π_{i,doc,n} = default_rng(10000·i + 1000·doc_idx + n).permutation(L_n)`**
    — **детерминированная per-doc перестановка** (F1: общий draw для всех
    доков = класс AT2d-B1, draw-дисперсия вне бутстрапа; пер-док сиды
    делают её измеримой). i ∈ {1,2,3,4} = (S1, S2, S1', S2');
    `doc_idx` = замороженный порядок R2-доков (0..13); n в сиде — явная
    независимость доз. **Мультисет, длина, позиции — те же; сломан весь
    порядок (включая биграммы), периодичность в первую очередь.**
  - `S1'(n, doc)` — второй независимый draw от `L1(n, doc)` (i=3);
    `S2'(n, doc)` — второй независимый draw от `L2(n, doc)` (i=4).
- **Estimand REP (m3, точная формулировка):** «**периодический порядок vs
  случайный порядок при том же мультисете**» — НЕ «повторение vs отсутствие
  повторения»: shuffled-блок сам повторяющийся (ожидаемое число смежных
  пар: n=2 → ≈1.0, n=16 → ≈15.0, P = (n−1)/(9n−1) на позицию) — мультисет
  матчит частоты токенов, это правильный контроль контента.
  `REPETITION_SPECIFIC` читается как «канал упорядоченности/периодичности».
  Сужение до «именно период-9» требует арма с другим периодом при том же
  мультисете ((p1+p2)×(n/2), +28 фд) — **follow-up, не в этом прогоне**
  (заявленная H_rep не требует).
- **Критерии phrase2** — как в v1.0 (форма, не CE/эффект; обучаемость —
  диагностика §9).
- **Гейты S_stimulus + S_shuffle:**
  - `S_stimulus` (fail-loud): `L_n = 9n` для L1/L2/S1/S2/S1'/S2';
    `assert tk(PHRASE_i) == PHRASE_i_IDS`; **multiset-check**:
    `sorted(S_i) == sorted(L_i)` для всех (i, doc, n) (assert в
    `run_main`; `phrase_token_check`/`shuffle_multiset_check` в
    claim/манифесте).
  - `S_shuffle` — **диагностика** (m1: не «урок F5», см. §10): (а)
    период-9-чек `¬∀k: S[k] == S[k+9]` (для per-draw перестановок с
    различными токенами вероятность ~9!·2⁹/18! — астрономически мала;
    гейт — fail-loud защита от бага перестановки, не ожидаемый
    сценарий); (б) max count любой 9-граммы в окне `[0, 9n)` —
    **per-(S_i, doc, n) таблица в артефакте**.
  - **Филлеры вне вердиктного пути 2b** (явно, m1/F3б): проверка
    специфичности филлеров — только R2's «нет конкретной фразы»,
    унаследована через R2-store integrity (sha-пин, §10); 8_3-проверка
    9-грамм для филлеров к 2b неприменима.

## 7. Условия и контрасты

### 7.1 Условия

На (док, n∈{2,16}): `ctrl`, `L1`, `L2`, `S1`, `S2`, `S1'`, `S2'`,
`fillerA`, `fillerB` — 4 из R2-store (ctrl, L1, fillerA, fillerB), 5 новых
(L2, S1, S2, S1', S2').

### 7.2 Контрасты и нули

**Вердиктные контрасты** (per-позиция d, per-слой):

```
REP = ((L1 + L2) − (S1 + S2)) / 2     (главный эффект периодичности)
PHR = ((L1 + S1) − (L2 + S2)) / 2     (главный эффект содержимого)
INT = ((L1 − S1) − (L2 − S2)) / 2     (взаимодействие; report-only)
```

(клетки (L1, L2, S1, S2); коэффициенты ±1/2; попарная ортогональность:
скалярные произведения = 0 — проверено в ревью r2 §2.)

**Нули** (per-позиция d, per-слой):

```
N_perm = S1 − S1'                     (draw-шум: тот же мультисет,
                                      та же структура, другой draw) → REP
N_PHR  = S1' − S2'                    (терм-непересекающийся с
                                      {L1, L2, S1, S2})            → PHR
```

- **N_perm (→ REP):** остаточное пересечение с REP **declare** (F2):
  S1 — с −½ в REP и +1 в N_perm, `Cov = −Var(S1)/2 < 0`; под |·| знак
  эффекта не определён.
- **Тождество (зафиксировано как известное ограничение, F2):**
  `PHR − INT = (S1 − S2)` ⇒ `N_content := S1 − S2 = PHR − INT`.
  N_content **не является** валидным нулём PHR (нуль содержит собственные
  термы контраста: при D_S ≈ 0 порог схлопывается — анти-консервативный
  режим; при D_L ≈ 0 — никогда не срабатывает). **N_content —
  legacy/диагностика только.**
- **INT:** нуля нет (report-only + диагностика допущения о нулях:
  значимый INT = контентный эффект в луповой строке ≠ в
  непериодической — тег `INTERACT_SIGNIFICANT`, §11).
- **Двухрежимная оговорка (declare, F2):** для PHR, когда
  непериодическая контентная разница ≈ 0, δ_PHR схлопывается — это H1-
  режим (срабатывание там содержательно верно), но type-I-ошибка в этом
  углу не контролируется на 5%. Свойство нулей того же семейства —
  зафиксировано.

**Диагностика (R2-сравниваемость, в вердикт не идут):**

```
e_spec1 = L1 − fillerA               (R2, заморожен — e_spec R2)
e_spec2 = L2 − fillerB               (новый)
e_null  = fillerA − fillerB          (R2, заморожен)
e_rep_legacy = (e_spec1 + e_spec2)/2 (v1.0-определение)
N_content = S1 − S2                  (тождество PHR − INT, выше)
```

- **Шов (M1) — диагностика для L2** (как v1.1): `seam2(n) =
  cos_raw_L2[cut+L_n−1] − cos_raw_fillerB[cut+L_n−1]` (R2: −0.055…−0.081).

### 7.3 Наблюдаемые per контраст (F4, заморожено до форвардов 2b)

Выбрано по P0 на R2-store (L23; near = p90|e_spec|, d∈[0,15]; δ = p95
per-doc p90|e_null|; doc-bootstrap B=2000, seed 0):

| наблюдаемая | n=2 (PHR) | n=16 (REP) |
|---|---|---|
| cos_raw | CI_low/δ = 0.441 | 0.77 (эквивалентно norm_delta 0.78) |
| norm_delta | **CI_low/δ = 0.609** | 0.78 |
| CE | 0.46 | 0.65 (и слой-слеп) |

- **PHR → `norm_delta`** (P0: 0.609 vs 0.441, margin −0.4529 vs −0.0853;
  выбрано по R2-данным, R2 ничего не решал на n=2 — «преемственность»
  там не аргумент).
- **REP → `cos_raw`** (на n16 эквивалентен norm_delta — сравниваемость
  с R2 сохранена).
- INT/диагностика — обе наблюдаемые.
- Поверхность: у каждого контраста ровно одна primary-наблюдаемая →
  **ровно 2 вердиктных теста** (без Bonferroni, §11).

## 8. Разрешение δ (F4-урок: нуль — того же семейства, что вердиктный)

```
per doc i, dose n:
  near_perm_i,n   = p90 |N_perm_i,n(d)|,   d ∈ [0,15];   far_perm   = mean|·|, d ∈ [48,63]
  near_phr_i,n    = p90 |N_PHR_i,n(d)|,    d ∈ [0,15];   far_phr    = mean|·|, d ∈ [48,63]

δ_REP  = 95th pct {near_perm_i,n}      (28 значений: 14 док × 2 дозы, пул)
δ_far_REP  = 95th pct {far_perm_i,n}
δ_PHR  = 95th pct {near_phr_i,n}       (28 значений, PULED)
δ_far_PHR = 95th pct {far_phr_i,n}
```

- **Пулинг по дозам — проверенное допущение** (F5, P0 из R2-store: per-doc
  p90|e_null| p95: n2 = 0.1526, n16 = 0.1328, ratio = **1.149 < 1.5** →
  per-dose δ не обоснован; pooled (0.1533) ≥ per-dose в обоих случаях →
  не анти-консервативен).
- Вычисляются 2b-машиной **из новых форвардов** (S1, S1', S2, S2') —
  единый пайплайн. `δ_min` неконечен/нулевой → NOT_RESOLVED (гейт S_null).
- **Integrity-якорь (fail-loud):** пересчёт legacy-δ (e_null) из R2-store —
  **по ВСЕМ 4 дозам, R2-пайплайн verbatim** (14 док × 4 = 56 значений),
  **независимо от дозового списка 2b** [2,16] (m2, P0: по 2 дозам =
  0.1533/0.0306 — ложный STOP-ловушка). Ожидаемо bit-идентично R2:
  **0.1480 / 0.0332**; отклонение > 1e-6 → стоп (store повреждён/подменён).
  Это проверка пайплайна, **не** порог вердикта.

## 9. Доза

- **PHR primary: `n = 2`** (пререг). Обоснование (механика насыщения,
  зафиксирована до прогона): I_loop1(n) = 59.2/61.7/63.8/64.6 (n=2/4/8/16,
  док-медианы; +9% — `DOSE_FLAT` R2); кривая обучения из R2-store: r1 CE
  4.66 → r2 0.39 → r3 0.13 nat/tok (n16) — фраза выучена ко 2–3 повтору →
  на n=16 контентное различие L1/L2 минимально; на n=2 — максимально.
- **REP primary: `n = 16`** (пререг) — максимальная доза периодичности (16
  повторов).
- Обе дозы, оба контраста — перекрёстная диагностика (2×2 дозовая таблица в
  claim). n=4/n=8 не гоняются (R2-плато).
- **I_loop2(n) = Σ CE по токенам блока L2** (новое; I_loop1 — из R2-store,
  заморожен).
- **Дозовый тег L2** (по док-медианным, как R2 §9): `DOSE_FLAT` /
  `DOSE_SATURATING` / `DOSE_MONOTONIC` / `DOSE_NOT_RESOLVED` (NaN →
  `DOSE_NOT_RESOLVED`, isfinite-гейт, r2d-2.3).
- **Learnability-parity (диагностика, тег):** если `block-CE_L2(16) /
  block-CE_L1(16) > 3` ИЛИ `< 1/3` (док-медианы) → тег `LEARN_ASYMM`.
  Пререг-ожидание: block-CE L2(16) ~ 0.3–1.0 nat (L1: 0.38–0.51).
  Структурная версия того же вопроса — INT (§7, §11).

## 10. Гейты (до вердикта)

1. **R2-store integrity (главный):** sha256
   `results/AT8/AT8_2_R2_store.json` == **`78419a69a2edbc767248b3a8f9512e19
   61ea82c154970772c66c35e2a42b16c0`**; `__config__`-fingerprint (model,
   layers, n_dose, phrase_ids, docs_sha256, pool_fps, H) == константы 2b;
   `n_docs=14`, 4 домена, ≥2/домен. Провал → стоп (SystemExit), не
   NOT_RESOLVED.
2. **S_stimulus:** phrase_token_check (оба), shuffle_multiset_check
   (S1/S2/S1'/S2', per doc), L_n = 9n, конечность. Fail-loud.
3. **S_shuffle — диагностика** (m1): период-9-чек (а) + per-(S_i, doc, n)
   таблица max 9-gram-count (б). Fail-loud assert (защита от бага
   перестановки); **не** фикс урока F5 (тот про филлеры, а филлеры вне
   вердиктного пути 2b — §3).
4. **Finite-гейт (M5):** ce + cos_raw/cos_state/norm_delta по всем
   условиям × слоям (новые — полный; R2-условия — spot-проверка) + все
   контрасты (3 вердиктных + 2 нуля + 5 legacy/диагностика). Провал →
   NOT_RESOLVED.
5. **G_inside_rep (F3 — положительный контроль вердиктного пути):**
   per doc: `CE(L1 block) < CE(S1 block)` И `CE(L2 block) < CE(S2 block)`
   (тот же мультисет, та же длина, сломан только порядок — если модель не
   видит порядок **внутри** блока, ждать пост-эффекта неоткуда). На
   **обеих** первичных дозах (n=2, n=16); гейт: ≥ `ceil(0.75 × 14) = 11`
   доков на дозу; margin `(CE_S − CE_L)` per doc в отчёт. Провал на дозе →
   контраст этой дозы **нерешён** (тег `GATE_N2`/`GATE_N16`); провал на
   обеих → `INSENSITIVE_CELL`.
6. **G_inside_legacy (диагностика):** старый v1.1 filler-гейт (n=16,
   L1/L2 < fillerA/fillerB, ≥11/14) — про legacy-контрасты
   e_spec1/e_spec2, гейт-роли не имеет.
7. **S_null:** δ_REP, δ_PHR конечны (> 0), §8.

```
   провал на n=16 → REP нерешён (GATE_N16);
   оба → INSENSITIVE_CELL.
3. Вердиктная клетка (L23; ровно 2 теста — поверхность зафиксирована):
   S_phr := CI_low(near_PHR(n=2), norm_delta)  > δ_PHR
   S_rep := CI_low(near_REP(n=16), cos_raw)    > δ_REP
   S_phr ∧ S_rep → BOTH_SPECIFIC (+substructure каждого)
   S_phr only    → PHRASE_SPECIFIC (+substructure)
   S_rep only    → REPETITION_SPECIFIC (+substructure)
   neither       → NO_2B_SPECIFIC_EFFECT
   (substructure _AMBIGUOUS по единственному значимому → NOT_RESOLVED;
   нерешённый контраст (шаг 2) → вердикт по решённому + тег GATE_*)
4. Substructure (для каждого значимого C, его первичная доза, primary
   наблюдаемая):
   CI_low(C_near − C_far) > 0  И  CI_high(C_far) ≤ δ_far(C) → _DECAYS
   CI_low(C_far) > δ_far(C)                                  → _PERSISTS
   иначе                                                     → _AMBIGUOUS
5. INT (отчёт, не вердикт): near_INT(n=2), near_INT(n=16) + CI (L23,
   cos_raw и norm_delta); CI_low(near_INT(n=16)) > δ_REP → тег
   INTERACT_SIGNIFICANT («эффект повторения контент-зависим» — вердикт
   читается с оговоркой).
6. + слойный тег (на n=16; «значим» = near_C_L > δ_L(C); объединение
   {REP, PHR} — правила TZ R2 §10)
7. + дозовый тег L2, + LEARN_ASYMM (если), + G_inside_legacy (отчёт).
```

**Вердиктный словарь** — как v1.1 (`NO_2B_SPECIFIC_EFFECT` /
`PHRASE_SPECIFIC` / `REPETITION_SPECIFIC` / `BOTH_SPECIFIC` /
`INSENSITIVE_CELL` / `NOT_RESOLVED`) + `_DECAYS`/`_PERSISTS`/`_AMBIGUOUS` +
теги `INTERACT_SIGNIFICANT`, `LEARN_ASYMM`, `GATE_N2`, `GATE_N16`.
Чтения — §17.

**Множественность (числом, r2 §2):** 2 односторонних теста, α ≈ 0.025 на
тест (CI_low = 2.5-й перцентиль doc-bootstrap; тест «CI_low > δ»
калиброван под H0 на ≈0.025). FWER(≥1 ложный) = 1 − 0.975² ≈ **4.94%**
при независимости; тесты не независимы (общие доки/стимулы) → фактический
FWER ∈ [2.5%, 4.9%] → семейный уровень ≈ 5% — **поправка не нужна**,
поверхность = ровно 2 зафиксированных пре-регом теста.

**Прочие оговорки (declare):** двухрежимное поведение теста PHR (§7.2);
v1.0-provenance: абсолютные пороги G_inside_legacy (loop < 1.0,
filler ≥ 2.0) калибровались на одиночном предпрогоне **вне финального
пула** (число «2.06» встречается только в r1-ревью, на диске не найдено) —
пороги **только диагностика**, гейт-роли не имеют (с v1.1).

**Диагностика без вердиктной роли** (явно): INT, e_spec1/e_spec2/
e_rep_legacy/e_null/N_content, G_inside_legacy, все слои ≠ L23, доза ≠
primary для каждого контраста, cos_raw/norm_delta ≠ primary.

## 17. Пререг-чтения исходов

- `NO_2B_SPECIFIC_EFFECT` — R2-`NO_LOOP` усиливается: ни содержимое фразы
  (на n=2, где контент жив), ни периодичность (на n=16) не создают
  пост-эффекта сверх shuffled-нулей (на пре-рег-разрешении; отсутствие не
  доказано — конвенция r2d-1.5).
- `PHRASE_SPECIFIC` — канал: содержание конкретной фразы. Согласуется с
  ответом архитектора «после ~2 повторов фраза выучена» (block CE 0.38–0.51)
  — CE внутри блока ≠ пост-эффект; теперь разделены (и меряются на дозе,
  где контент ещё жив).
- `REPETITION_SPECIFIC` — канал: **упорядоченность/периодичность** при том
  же мультисете (m3: не «повторение как таковое»).
- `BOTH_SPECIFIC` — два канала; substructure каждого — в claim.
- `INTERACT_SIGNIFICANT` — эффект повторения контент-зависим (одна фраза
  «садится», другая нет): REP-вердикт читается с этой оговоркой.
- `LEARN_ASYMM` — phrase2 обучается иначе phrase1 (block-CE ratio > 3×):
  PHR читается с оговоркой «содержимое + обучаемость».

  ctrl/loop1/fillerA/fillerB не перегоняются.
- Пул не пересобирается (14 доков R2, тот же filler_map).
- Фразы не меняются (пре-рег §3); seed-формула (10000·i + 1000·doc_idx +
  n) не меняется; автосидов нет (провал S_shuffle — fail-loud, не
  пере-сид).
- **Слияние с AT8_3 — не в этом пре-реге.** 8_3 review r3
  (`docs/AT8_3_review.md`, патч-лист 1–8): 5 вердикт-критических пунктов
  (1–5) открыты в TZ v1.2 (H_eval=97; знаменатель/LOW_POWER; CI-таблица/
  гейт; строгий >0.5 или блокирующий WIDE_CI; доз-зависимый гейт
  филлеров) — слияние унаследовало бы их. Смета (r2 §1(d), верифицировано
  по `docs/AT8_3_TZ.md`: 14 условий/док × 16 доков): 8_3 = **224**; 2b на
  пуле 8_3 с S2' = 5 × 2 × 16 = **160**; слияние = **384** > 336
  (224 + 112 раздельно) — **слияние дороже**. Объединённый пре-рег —
  после закрытия 8_3 (архитектор предлагает расписать: условия, контрасты
  с нулями, дерево REP/PHR/INT + локализация 8_3, store с h-векторами,
  смета). До утверждения объединённого пре-рега standalone-прогон 2b может
  быть запущен отдельно (140 фд ≈ 35–40 мин); если объединённый пре-рег
  утверждён до запуска 2b — standalone пропускается (явное решение в PLAN).
