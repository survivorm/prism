# Очередь перегенераций (после аудита v6)

Рабочий список: чтобы после компакта продолжить отсюда, не решая заново.
**Одна строка за раз**: запустить → дождаться → забрать → сверить якоря → обновить карточку →
отметить `[x]` здесь и в `PLAN.md` → следующий слот.

Механика Kaggle (проверено этим же файлом-источником, не из памяти):
- лимит — **2 одновременные GPU-сессии**; `COMPLETE` успехом не считать, всегда читать лог;
  у идущего ядра вывод (`kaggle kernels output`) появляется только после финиша.
- пуш: `kaggle kernels push -p kaggle_kernel/kernel-<id>` (из `kaggle_kernel/`), либо
  `../.venv/bin/python push_all.py --exp <имя>` (`--all` для всех; `--list`/`--only` НЕ существует).
- забрать: `kaggle kernels output voroninmichael/<slug> -p /tmp/<slug>`.
- сторож очереди: `kaggle_kernel/_push_audit_v6.sh` (ждёт свободных обоих слотов, затем сам
  толкает `kernel-exp3`, через 30 с `kernel-exp2a`; лог `/tmp/push_audit_v6.log`).

## Порядок после каждого финиша

1. Забрать и **прочитать лог** (не только JSON).
2. Сверить якоря, которые не имели права измениться (см. колонку «Сверить после»).
3. Если изменилось только то, что должно — перенести числа в карточку, старое число пометить
   снятым (не удалять), указать дату артефакта.
4. Перед коммитом: `grep -nP "[а-яё][a-zA-Z]+|[a-zA-Z]{3,}[а-яё]|[\x{4e00}-\x{9fff}]" docs/*.md`.
5. Коммит с **явными путями** (дерево общее с параллельной сессией).
