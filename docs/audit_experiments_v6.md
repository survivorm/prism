## 1. Критичные

### F1. E-45c — «калибровочный нуль» не является нулём для измеряемого объекта
`exp45c_gauge_null.py` (докстринг) доказывает: добавка `W → W + 1cᵀ` не меняет «якобиан лог-вероятностей» `J_t = cs_t·(M − u_t(Mᵗu_t)ᵗ)`, «u_t = p_t». Но (а) код меряет **логит-якобиан** `E45.make_j_fn`: `cs·(M − (Mu)uᵀ)`, `u = h/‖h‖` — канон репозитория; (б) для него калибровка **не** в ядре: `δJ = cs·1(c − (c·u)u)ᵀ ≠ 0`. Численно (синтетика в масштабах проекта): drift_J_max = 0.057 / 0.167 / 0.562 при α = 0.05/0.15/0.50 против `TOL_DRIFT = 1e-5`; κ уедет так же. Для лог-вероятностного якобиана drift = 3e-16 — формула докстринга верна, но для другого объекта. KL/TV/top-1 — честные нули.
Следствия: скрипт при запуске обязан упасть по своему же гейту (`exit(1)`) с вердиктом «искать ошибку в J_of/dense_metrics, числа E-45 под подозрением» — **ложно** обвиняя исправный конвейер; артефакта `results/exp45c_gauge_null.json` нет — скрипт никогда не доводился до конца, премиса не проверялась. Содержательно: κ/‖ΔJ‖ на логит-J **чувствительны к чистой калибровке** — это надо знать и в E-45/E-39b-интерпретациях.
**Фикс:** либо мерить нуль на log-prob-J (тогда честно 0), либо заменить аналитическую премису: для логит-J нуль — только поведенческий (KL/TV/top-1), а структурные допуски снять/объяснить.

### F2. E-0.1 — опубликованная гейт-таблица не воспроизводима ни одной конвенцией артефакта
`docs/ref-exp.md:82–89`, `docs/paper.md:528`: C(σ_d) = 0.33/0.45/0.64/0.87, вердикт «Kill-switch не сработал (порог C < 0.1) ни на одном слое». В закоммиченных артефактах (v1 и v5/v6) есть ровно 4 конвенции: `C_b@σ_d` = 0.033/0.070/0.109/0.120; `a` = 0.077/0.099/0.059/0.224; `samepk` = 0.258/0.343/0.709/0.852; `nogauge` = 0.331/0.471/0.795/0.924. Опубликованный ряд совпадает с nogauge только на L6 (0.331), дальше ни с чем (0.45≠0.471, 0.64≠0.709/0.795, 0.87≠0.852/0.924). По **объявленному в шапке скрипта канону** `C_b` kill-switch **срабатывает на L6 и L12** — вердикт-фундамент («поле когерентно на всех слоях») держится на конвенции, которой в артефакте нет. Судя по Оговорке (1) карточки, числа — из v3-пула, который шапка v4+ называет «meaningless».
**Фикс:** переиздать таблицу от текущего артефакта с явной конвенцией; если канон — `C_b`, честно описать L6/L12 ниже порога и что это меняет (или явно сменить канон и почему).

### F4. exp35_preflight — заголовочный «d_S-чек» считает мусор
`exp35_preflight.py:197`: `row['_lab'] = (vv & ~boundary)` — **булева маска** вместо значений `ds[vv & ~boundary]`. В `ds_perm_check` конкатенируются реальные граничные d_S с 0/1 маской: `obs_diff` = среднее значений − доля True, перестановочный пул — вперемешку. Численная демонстрация: obs +0.039 (p=0.024) → −0.109 (p=0.012) — знак и величина невосстановимы. Selfcheck подаёт корректные пары и дефект не ловит.
