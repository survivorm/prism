# Рабочие правила (зафиксированы)

## 1. Выбор варианта — более правильный, более информативный (2026, E-38g)
При наличии выбора (фиксов, интерпретаций, вариантов реализации) выбирать
**более правильный, более информативный** путь, даже если он дольше и
сложнее. Не выбирать «лёгкий» вариант (документировать ограничение,
переименовать, зафиксировать caveat) вместо реальной реализации, если
реальная реализация доступна.

**При выборе — перечитать источник** (ТЗ, ревью, раздел доков), на который
опирается выбор. Не выдумывать варианты «из головы»: перечитать текст,
сравнить варианты по тексту, выбрать по тексту.

Происхождение: E-38g — ревью (docs/E38_fixes.md part-2 §1) давало (a) dual-
проекции, (b) прямую проверку подпространств, (c) честное переименование.
Был выбран (c); ТЗ просило кросс-валидацию «наш хвост ↔ J-Space», для
которой нужен (a) или (b). Урок: фиксировать и перечитывать.
