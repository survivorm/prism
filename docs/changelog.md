# Changelog: Якобианов Мост v3.3 → v4.0

## 1. Математические исправления (paper.md, 13 пунктов)

Все 13 пунктов из `paper_errors.md` применены к `docs/paper.md`. Ниже — список с указанием мест и характера.

| # | Место (v3.3) | Ошибка | Исправление |
|---|---|---|---|
| 1 | §1.2 «Векторное тождество» | $J = \sum_j p_{U,j} J_j$ — неверно: $J$ — матрица $K\times D$, сумма строк — вектор-строка $1\times D$ | Переформулировано: $\sum_j p_j J_j$ — вероятностно-взвешенное среднее строк Якобиана; следствия (инъективность, $J=0$) вынесены в лемму 7.1 ($M_p \succeq 0$, $\ker M_p = \mathrm{span}\{\mathbf{1}\}$) |
| 2 | §1.6, §1.7 | Лишний $1/|U|$ в формулах gap и bridge при нормированных весах $w_i$ | Множитель $1/|U|$ удалён; соотношение $\mathcal{G}_{\text{gap}} = 1 - \mathcal{B}_{\text{bridge}}$ теперь точное (при совпадающих весах) |
| 3 | §1.5, пояснение `gauge_share` | $\|P(p)J\|_F^2/\|J\|_F^2$ описано как «доля энергии, убиваемой проекцией $P$» — перепутано: $P(p)J = J^{(p)}$ — это **gauge-free** часть (оставшаяся); убиваемая — $\|QJ\|_F^2/\|J\|_F^2$, $Q=uu^T$, $u=\mathbf{1}/\sqrt K$ | Переформулировано: `gauge_share_raw` = доля энергии сырого $J$, **оставшейся** после убийства gauge; убиваемая uniform-компонента — $\|QJ\|_F^2/\|J\|_F^2$ |
| 4 | §3.6 | Нулевой собственный вектор производной RMSNorm указан как $g^{-1}\odot\hat u$; на деле $\hat u = x/\|x\|_2$: $M\hat u = \frac{1}{r}\mathrm{diag}(g)(\hat u - \hat u) = 0$ | Заменено на $\hat u$; добавлена явная проверка |
| 5 | §13 (T4 / lemma) | «$P^2 \neq P$ (не проектор; идемпотентен лишь при $p=\text{uniform}$)» — неверно: при $p=\text{uniform}$, $P = \frac{1}{K}I - \frac{1}{K^2}\mathbf{1}\mathbf{1}^T$, $P^2 = \frac{1}{K}P \neq P$ при $K>1$. $P$ не идемпотентен **ни при каком** $p$ | Переформулировано: $P$ — **gauge-оператор** (якобиан softmax), **не проектор**, не идемпотентен ни при каком $p$; термин «проектор» заменён на «gauge-оператор» везде |
| 6 | §12 (Exp 12a) | `uniformity($v_g$)` — размерная ошибка: $v_g \in \mathbb{R}^D$ (hidden), uniform-вектор $\mathbf{1}/\sqrt K \in \mathbb{R}^K$ (token) | Заменено на `uniformity($u_g$)` — левый сингулярный вектор; uniformity определён только для token-пространства |
| 7 | §1.2 (pre-norm блок) | Формула $D_l$ с перепутанными обозначениями: MLP получает $\mathrm{RMSNorm}(\hat h)$, а не $\tilde h$ | Переопределены: $\tilde h = \mathrm{RMSNorm}(h^l)$ (вход Attn), $\hat h = h^l + \mathrm{Attn}(\tilde h)$ (вход второго RMSNorm), $\bar h = \mathrm{RMSNorm}(\hat h)$ (вход MLP); формула исправлена |
| 8 | §13 (T4) | Формула adjusted p-value: $p_{4,\text{adj}} = B \cdot \min(0.05, p_4/\alpha_4)$ — не стандартная Bonferroni | Заменена на $p_{\text{adj}} = \min(1, p_4 \cdot n_{\text{layers}})$; порог $\alpha = 0.05/n_{\text{layers}} = 0.0083$ |
| 9 | §7 (Exp 3) | «Random orthogonal R даёт loss ≈ 1.02 (максимум)» — 1.02 это уровень ортогональности, не максимум (max = 2) | Заменено: «1.02 (уровень ортогональности)» |
| 10 | §7 (Exp 9) | «Топ-3 eigenvalues слоя 0 составляют ~70% от следа» — по числам: 10.5M/17.2M ≈ 61% | Заменено на «≈ 61%» |
| 11 | §7 (Exp 4) | «После K=64 изменение < 0.3% на par» — на деле ≈ 1.3% | Заменено на «< 1.5%» |
| 12 | §1.7 | Соотношение $\mathcal{G}_{\text{gap}} \approx 1 - \mathcal{B}_{\text{bridge}}$ неверно при наличии $1/|U|$ | После исправления #2 соотношение точное (при совпадающих весах); формулировка уточнена |
| 13 | §2.2 (код) | Порог `threshold: float = 1e-6` (абсолютный) vs текст §1.6 (относительный $\tau_l = 0.01 \cdot \mathrm{median}$) | Код исправлен: `threshold_rel: float = 0.01`, $\tau = threshold_rel \cdot \mathrm{median}(\|J_S[i]\|)$; исторический абсолютный порог упомянут в комментарии |

### Ключевые решения реструктуризации

1. **E-ID mapping**: $E\text{-}N$ = старый эксперимент $N$ из v3.3, с подстрочниками (E-6b, E-10a–d, E-11a–c, E-12a–c, E-16a/b, E-27.5/27.6). Идентификаторы стабильны.
2. **Леммы [L-*]**: вынесены из экспериментальных секций в Часть II:
   - `[L-dim]` → §5 (лемма о размерностях)
   - `[L-comp]` → §4 (правило композиции)
   - `[L-gram]` → §5 (Gramian-коррекция)
   - `[L-rank]` → §6 (разведение рангов)
   - `[L-fisher]` → §6 (Fisher/r_eff)
   - `[L-gap]` → §7 (gap/bridge)
   - `[L-gauge]` → §8 (gauge-оператор, не проектор)
   - `[L-rms]` → §8 (производная RMSNorm)
3. **§20 слив трёх таблиц** (v3.3 §10 + §11 + §13.1): каждое утверждение — один раз; при различии формулировок — самая осторожная; более поздняя формулировка авторитетна; прямые противоречия — в конце секции (Q1, Q2), не решаются молча.
4. **Противоречия Q1/Q2**:
   - **Q1**: Defrag r=8 Spearman: v3.3 §10 говорит 0.19, таблица E-11c (§18) — 0.81. Не совпадает ни с одной строкой таблицы. Требует пересмотра JSON-артефактов.
   - **Q2**: Defrag speedup: v3.3 §10 — 2.7–18.9×; вывод E-11b — 4–18×; таблица E-11b — 4.0–17.8×. В §20 взято табличное 4.0–17.8× как наиболее осторожное.
5. **E-11b v1 fidelity metric**: сохранённый JSON отмерен v1-метрикой `‖U_r J_r − J_p‖/‖J_p‖` (сравнивает проекцию сырого J с J_p, растёт с r — артефакт, не сигнал). Баг исправлен в `experiments/exp11b_defrag_cost.py` (c904db3). Значения 14–38% — v1-метрика; после re-run столбец поменяет тренд на убывающий. Speedup-столбец от метрики не зависит.
6. **«Скрипт не синхронизирован с прогоном»**: вынесено в Приложение B (колонка «Примечания»), не в основной текст. §18 (v4.0) содержит только params-сноски под таблицами.
7. **gauge_share — два смысла**: в v3.3 одно имя для двух величин. В v4.0 имена разведены: `gauge_share_softmax` (§6, ESG) и `gauge_share_raw` (§8, gauge-оператор). См. также Приложение A.
8. **Символ $\mathcal{S}$**: в v3.3 набор токенов — $\mathcal{U}$; в v4.0 — $\mathcal{S}$ (support), чтобы не путать с $U$ из спектрального разложения ESG и $U_r$ из defrag. В JSON-артефактах ключи не переименованы.
9. **Приложение A (Глоссарий)**: 28 терминов с каноническими секциями. Формулы gap/bridge/r_KL/ESG/sentinel/gauge_share проверены по §1.5–§1.7 и §2.2 v3.3.
10. **Приложение B (Индекс)**: 30 экспериментов с ID, скриптами, config, JSON, группами, секциями. 5 примечаний о синхронизации скриптов. Реестр H1–H5.
11. **Приложение C (Листинги)**: 9 кодовых блоков, вынесенных из §9–§12 и §14. В теле — только сигнатуры и ключевые комментарии.
12. **Старые §-ссылки** (v3.3 §1.5, §1.6, §1.7, §10, §11, §12, §13, §13.1): сохранены только в историческом контексте (changelog, Q1/Q2, «слив из v3.3»). В основном тексте — ссылки на v4.0 секции.
13. **paper.md (v3.3) не модифицирован** при реструктуризации; все 13 математических исправлений применены к нему до создания v4.0.
