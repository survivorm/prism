# Разбор E-32r.2: корректность, соответствие ТЗ, интерпретация

## 1. Общий вердикт

Реализация в целом **математически корректна и соответствует ТЗ** по структуре (фит кубики без const, `A1 = a + 2b·ε_canon`, `s_l = ε_canon·‖off(b)‖/‖off(ESG_raw)‖`, 3 варианта `p_0`, sentinel `P128_RAW.sum < 0.5`, стратификация Q1/Q4). Но есть **существенные отклонения от полного ТЗ** и **несколько тонких моментов** в коде, которые нужно зафиксировать.

## 3. Ошибки и тонкие места в коде

### 3.1 `pick_p0` для `median_p` — мёртвый код (не критично)
```python
sel = int(np.argmin(np.abs(np.median(P128[ok], 1) - np.median(P128[ok], 1))))
# ^ argmin от нулевого вектора — всегда 0, строка не работает
med = np.median(P128[ok], 0)
sel = int(np.argmin(np.linalg.norm(P128[ok] - med[None, :], axis=1)))
```
Первая строка — артефакт, работает вторая. Результат корректный (позиция с распределением, ближайшим к покомпонентной медиане), но код грязный. Рекомендую убрать первую строку.

### 3.2 Кросс-чеки: несоответствие индексов
```python
tidx = np.where(vp)[0]           # длины S-1
rho['rho_nb_d3_raw'] = spearman(nb[tidx], d3_raw[tidx])
```
`nb` — per-position (длина S), `d3_raw` — per-pair (длина S−1). `nb[tidx]` берёт `nb[0..S-2]`, т.е. левый элемент пары. Это не ошибка, но смещение: правильнее было бы `nb[tidx] + nb[tidx+1])/2` или `max`. Для exploratory-чеков некритично.

### 3.3 `resid_frac` — накопление через `np.linalg.norm(resid, axis=(1,2))`
Проверил: `resid[s,i,j,e] = Z - fit`, `norm` по (i,j) даёт остаток по матрице для каждой (s,e), затем делится на `‖dz[:,:,:,e]‖`. Всё корректно.

### 3.4 Главное содержательное замечание — `resid_frac` при малых ε

| ε | median resid_frac |
|---|---|
| 5% | **0.0345** |
| 10% | 0.0229 |
| 15% | **0.0135** |
| 30% | 0.0033 |
| 50% | 0.0066 |
| 70% | 0.00037 |
| 90% | 0.0044 |
| 110% | 0.0017 |

**Residual_frac МОНОТОННО УБЫВАЕТ с ростом ε** (с локальными выбросами на 50% и 90%). Это классический признак **эффекта знаменателя**: `resid_frac = ‖resid‖/‖dz‖`, а `‖dz‖ ~ ε` в линейном режиме. Если абсолютный остаток примерно постоянный (шумовой пол ~ float32 / нелинейный хвост), то относительный остаток ~ const/ε.

Проверка гипотезы: `resid_frac(5%)/resid_frac(15%) = 0.0345/0.0135 = 2.56 ≈ 3 = 15/5`. Это **сильное свидетельство** того, что «провал» критерия `<1%` на 5–15% — артефакт нормировки, а не реальная неадекватность кубической модели.

**Следствие:** вердикт `A_linear_residual_lt_1pct = false` формально верен, но содержательно вводит в заблуждение. Нужно отчитывать **абсолютный остаток** `‖resid‖` (или `‖resid‖/‖dz(30%)‖`) наряду с относительным.

### 3.5 Формально корректные, но спорные места

- **`fit_all` включает ε ∈ {90%, 110%}** — экстраполяция за пределы Тейлоровского режима. Фит по 8 точкам, где две — вне диапазона, даёт смещение коэффициентов. ТЗ явно помечает 90/110 как экстраполяцию, но лучше было бы фитить по 6 точкам {5..70} и проверять предсказание на 90/110.
- **`frac_c_sig = 0.76`** — 76% позиций имеют значимый кубический член. По ТЗ это «тест формы, не амплитуды» — согласуется с формулировкой «кубическая модель неадекватна как форма, но амплитуда мала». Это нормально, но не должно интерпретироваться как «третий порядок важен».

### 3.6 Selfcheck в коде — корректный
Все 5 проверок (fit_cubic декодирует, fit_all == попарный, gauge_free_rows, pick_p0 детерминирован, E-35 identity) реализованы верно. Особенно хорош assert `abs(abs(cos)-1) < 1e-4` для E-35 identity — защита от рассинхрона аналитического J и `ck['JR']`.

## 4. Интерпретация результатов

### 4.1 Главный результат: `s_l ≪ 1`

```
s_l = 0.0989 [0.0968, 0.1018]
A1_median = 0.0669 [0.0654, 0.0682]
```

`s_l ≈ 0.1` — **readout на L23 линеен** в рабочей точке 15% ‖h‖. IQR по 32 докам узкий (0.097–0.102), т.е. результат **воспроизводим**, не артефакт одного документа. Это подтверждает пилот (0.075 на 1 доке) на полной выборке.

**Вердикт `B_s_l_lt_0.3 = true`** — главный содержательный результат.

### 4.2 Кривизна статистически значима, но мала по амплитуде

- `frac_c_sig = 0.76` — кубический член значим на 76% позиций
- `resid_frac` — 0.3–3.5% в зависимости от ε

Это ровно та картина, которую ТЗ называет «форма vs амплитуда»: модель **неадекватна по форме** (кубика нужна), но **адекватна по величине** (остаток мал). Разделение важно: нельзя говорить «readout линеен», правильнее «readout ≈ линеен с малой, но систематической кривизной».

### 4.3 p0-робастность — пройдена

```
median_p:     0.0416 [0.0276, 0.0570]
argmax_pmax:  0.0379 [0.0315, 0.0560]
argmin_pmax:  0.0421 [0.0278, 0.0545]
p0_stability_max_diff = 0.0795 < 0.1 ✓
```

Разброс между тремя вариантами `p_0` — до 0.08 rad (≈4.6°). Это на грани порога 0.1, но проходит. `p_0` **не критичен** для d3_fixP — можно фиксировать `median_p` как канонический.

### 4.4 Fixed-P контроль воспроизводит E-33r

```
d3_raw_med = 0.162 [0.153, 0.172]  ≈ 9.3°
d3_gf_med  = 1.494 [1.476, 1.514]  ≈ 85.6°
d3_fixP_med = 0.042 [0.028, 0.057] ≈ 2.4°
```

Порядок `raw < fixP ≪ gf` совпадает с E-33r (0.144 → 0.034 → 1.49). Fixed-P **улучшает** структуру top-1 в ~4× относительно raw — подтверждение, что разрушитель структуры — вариация `p_t` по позиции, а не сам оператор `P`.

### 4.5 Стратификация Q1/Q4 — смешанный сигнал

```
bQ1_fro = 0.0743 [0.0717, 0.0769]
bQ4_fro = 0.0723 [0.0700, 0.0773]
delta_b_rel = 0.209 [0.170, 0.272]
```

**Δb_rel = 0.21 < 0.5** (порог ТЗ). IQR [0.17, 0.27] не включает 0, но и не дотягивает до сильного сигнала. Это **слабая позиционная зависимость**, не доказывающая исход (B). ТЗ прямо говорит: при `n ≥ 16` на группу требовать `> 0.5` с permutation p<0.01. Здесь `n` на группу ~7–18 (Q1_n + Q4_n в per_doc), permutation не делался.

### 4.6 Кросс-чеки — все около нуля

```
rho_nb_d3_raw:  0.097 [-0.127,  0.265]
rho_nb_d3_gf:  -0.123 [-0.270,  0.023]
rho_nb_dp:     -0.097 [-0.344,  0.152]
rho_nb_dS:     -0.096 [-0.349,  0.068]
```

Все CI включают 0, |ρ| < 0.15. Это **сильное свидетельство в пользу исхода (C)**: кривизна **независима** ни от gauge-структуры (`d3_gf`, `d3_raw`), ни от position-dependence (`d3_fixP`, `|dp|`), ни от гладкости траектории (`dS`).

### 4.7 Сводная интерпретация

| Сигнал | Указывает на |
|---|---|
| `s_l ≪ 1`, `resid_frac` мал по амплитуде | readout ≈ линеен (главный вывод) |
| `frac_c_sig = 0.76` | кубика нужна по форме, но не по величине |
| `p0_stability < 0.1` | fixed-P каноничен |
| `Δb_rel = 0.21` | слабая позиционная зависимость (не дотягивает до порога ТЗ) |
| Кросс-чеки ≈ 0 | кривизна **не сводится** ни к gauge, ни к position |
| `d3_raw < d3_fixP ≪ d3_gf` | top-1 структура — gauge+position, воспроизводит E-33r |

**Наиболее вероятный исход: (C) — кривизна независима.** Все три ρ низкие, `b_Q1 ≈ b_Q4` в пределах IQR, `b_perP ≈ b_fixP` (через `p0_stability`). Слабое `Δb_rel = 0.21` — скорее шум/слабый эффект, чем сигнал (permutation-тест не проводился, порог ТЗ не пройден).

**Формулировка для §18 (в редакции ТЗ):**
> «Кривизна readout на L23 мала (s_l = 0.099) и не коррелирует ни с gauge-структурой первого порядка, ни с position-dependence. Второй порядок — отдельный объект; для его локализации требуется диагностика вдоль `û` vs top-1 raw (ТЗ, исход C).»

## 5. Рекомендации

### 5.1 Обязательные для полного E-32r.2

1. **Запустить слои 6, 12, 18, 22** — сейчас только L23. Без этого нет ответа на главный вопрос ТЗ о воспроизводимости `s_l ≪ 1` по слоям.
2. **Поднять порог Q1/Q4 до 0.5** (или отчитывать `Δb_rel` с permutation p-value). Текущий `0.2` — самовольное смягчение.
3. **Добавить continuous OLS+HC3** `‖b(t)‖ ~ α·|Δp(t)| + β` — основную метрику ТЗ.
4. **Пересчитать `resid_frac` с абсолютным остатком** (или нормировать на `‖dz(30%)‖`) — иначе «провал» 1% на 5–15% интерпретируется неверно.

### 5.2 Желательные

5. **Убрать ε = 90%, 110% из фита** — фитить по 6 точкам {5..70}, проверять предсказание на 90/110.
6. **Bootstrap CI по документам** (64 итерации) — для `s_l`, `A1`, `Δb_rel`.
7. **Добавить ρ с `Δ_SVD_raw(r=1, t)` и `Δ_SVD_fixP(r=1, t)`** из E-33r — сейчас кросс-чеки идут с `d3_raw/fixP` (текущий d3, а не E-33r), что формально не то, что требует ТЗ.

### 5.3 Мелкие

8. Почистить `pick_p0` (мёртвая строка).
9. Согласовать индексы в кросс-чеках (`nb[tidx]` vs `d3[tidx]`).

Для окончательного разведения A/B/C требуются: (а) слои 6–22, (б) continuous regression `‖b(t)‖ ~ |Δp(t)|`, (в) permutation-тест Q1/Q4 с порогом 0.5.»
