# Согласен: оба канонических p₀ — вырожденные. Предложения по операторам

Диагноз эмпирики подтверждается теоретически. Семейство `P(p) = diag(p) − ppᵀ` при K=128 имеет `‖P‖_op` от `1/K ≈ 0.008` (p = uniform) до `0.25` (p = 2-точечное с p_max = 0.5) и до `0` (p = δ). Оба канонических выбора попадают в **крайние** режимы:

- `median p_t`: p_max = 0.152 → `P(p0)` близко к **diag(p0) − rank-1**, почти диагональный оператор; умножение на него слабо поворачивает правое подпространство `J_t`.
- `argmax H(p_t)`: p_max = 0.998 → `P(p0) ≈ 0` — оператор почти убивает всё.

Промежуточная зона (p_max ≈ 0.3–0.6, `‖P‖_op ≈ 0.2`) — та, где per-token P реально работает как нетривиальный «миксер» — в канонических выборах не представлена.

Ниже — конкретные операторы, ранжированные по тому, насколько чисто они снимают подозрение в тавтологичности A.

---

## 1. **Pair-mean P** (приоритет 1)

Для каждой пары `(t, t+Δ)`:
```
p₀(t, Δ) = (p_t + p_{t+Δ}) / 2
A(pair) = max principal angle между P(p₀)·J_t и P(p₀)·J_{t+Δ}
```

**Что тестирует.** Это «де-вариация» per-token P: ровно та P, которая была бы у пары, если бы P не менялся между t и t+Δ. Гипотезы:
- `A(pair) ≈ gf (= π/2)` → **вариация p_t — причина**; даже «настоящий» P, применённый к паре, убивает структуру.
- `A(pair) ≈ raw ≈ 0.29 (L23)` → **фильтрация P — причина**; структура сохраняется при любой P, даже усреднённой по паре.

**Почему лучше median-p₀.** `p₀(t, Δ)` — гарантированно **реальная** per-pair дистрибуция (mean двух наблюдаемых p). Не может быть вырожденной: `p_max` ограничен `(p_max_t + p_max_{t+Δ})/2`, а эмпирически p_t на соседних позициях близки (E-31: C(1) = 0.3–0.996 по слоям). Это не глобальная статистика, а локальная, привязанная к паре.

**Стоимость.** SVD от `P(p₀(t,Δ))·J_t` — уже считается в gf (только с другим p). +1 batched SVD на позицию/Δ — ~2× от текущего.

## 2. **Cross-position P** — это ровно ТЗ-шная F (приоритет 2)

Для пары `(t, t+Δ)` взять случайный `s ∉ {t, t+Δ}`, `|s − t| ≤ 4`:
```
p₀ = p_s
A(cross) = angle(P(p_s)·J_t, P(p_s)·J_{t+Δ})
```

**Что тестирует.** Замена «p₀ = median/argmax» на «p₀ = реальный p из другой позиции» — сохраняет локальную форму P, но не привязку к паре. Сравнение:
- `A(cross) ≈ A(pair)` → важно «**та же** P на обоих концах», не «**какая** P».
- `A(cross) ≈ gf ≈ π/2` → важно «**та самая** P позиции t», кросс-позиционный P уже не работает.

**Почему это лучше, чем прежняя F в исходной формулировке.** Прежняя F сравнивалась с fixP (median-p₀), который мы теперь знаем как вырожденный. Сравнение с pair-mean делает F самодостаточной — обе стороны теста невырожденные.

**Стоимость.** Ещё +1 SVD на пару; при ограничении `|s−t| ≤ 4` — 4–8 кандидатов на позицию, берём 1 случайный (или медиану по 4).

---

## 3. **Operator-norm-matched synthetic p₀** (приоритет 3, «золотой стандарт»)

Построить `p₀` такое, что:
```
‖P(p₀)‖_op = median_t ‖P(p_t)‖_op   (эмпирическая цель ~0.137)
```
через параметрическое семейство, изолирующее «форму» от «силы»:
```
p₀(k) ∝ exp(β · score(k)),   β подбирается так, чтобы ‖P(p₀)‖_op = target
```
где `score(k)` — ранг токена k в среднем по документу (или просто `−k` при сортировке).

**Что тестирует.** Полностью снимает вопрос «а не вырождена ли p₀»: по построению `‖P‖_op` = медиане по документу. Если A(synth) ≈ raw → P действительно слабый оператор типичной силы, фильтрация не разрушает. Если A(synth) ≈ gf → даже один оператор типичной силы разрушает; значит именно применение P, а не вариация.

**Оговорка.** Искусственная p₀ не имеет «семантики» — но её задача именно в этом: дать эталонный оператор известной нормы.

**Стоимость.** Подбор β — бисекция, 3–5 итераций на документ; SVD батчем как в остальных случаях.

## 4. **Geometric-mean p₀** (приоритет 4, дешёвая замена median)

```
p₀ ∝ exp( (1/T) Σ_t log(p_t + ε) )
```

Лог-среднее «типичных логов» — в отличие от арифметической медианы, сохраняет пики и не выглаживается к uniform. Обычно даёт p_max заметно больше median, но не так экстремально, как argmax H.

**Что тестирует.** Если A(geo-mean) ≈ A(median) — вывод A не зависит от конкретного «типичного» p; если сильно различается — выбор p₀ действительно управляет результатом, и требуется пара (pair-mean + cross-P) для чистого ответа.

**Стоимость.** O(T·K) — пренебрежимо.

---

## 5. **Local-window mean P** (приоритет 4, вариация pair-mean)

Для пары `(t, t+Δ)`:
```
p₀ = mean_{s ∈ [t-w, t+w+Δ]} p_s    (w = 4 или 8)
```

Локальное окно, а не только пара. Сглаживает шум оценивания p_t и убирает чувствительность к одной позиции.

**Что тестирует.** То же, что pair-mean, но устойчивее к выбросам p_t. Если pair-mean и local-window дают одинаковый вывод — оценка робастна.

---

## 6. **Spectral-profile-matched P** (приоритет 5, «академически чистый»)

Выбрать `p₀` так, чтобы **спектр** P(p₀) совпадал с медианой спектров P(p_t) по позициям:
```
eigenvalues(P(p₀)) = median_t sorted eigenvalues(P(p_t))
```
Затем восстановить p₀ из спектра (для P(p) собственные значения определяют p с точностью до перестановки: `{0, p_(2), p_(3), ..., p_(K)}`).

**Что тестирует.** «Типичный оператор» в смысле собственного спектра. Прямо адресует, что именно спектр (а не форма распределения) несёт разрушение.

**Оговорка.** Требует eigh на P(p_t) для каждой позиции — дороже (K×K eigh на позицию). Возможно, не нужно на 32 документах при K=128.

## Что я бы делал на месте исполнителя

Порядок:

1. **Pair-mean P** — минимальная модификация кода (`p0 = (Pdoc[:-dt] + Pdoc[dt:])/2`), сразу даёт чистый ответ.
2. **Cross-P (F)** — вторая половина ответа: важно «та же P» или «любая P из окна».
3. Если вывод pair-mean и cross-P согласован (оба либо ≈ raw, либо ≈ gf) — **A закрыт**, E не нужна.
4. Если расходятся — тогда E (α-sweep) как третий независимый свидетель.

**Ключевой критерий снятия тавтологии.** Три числа на каждом слое:
```
raw   (нет P)
pair  (P пары, применённая к обоим концам)
gf    (per-token P)
```
Если `pair ≈ raw` и `gf ≈ π/2` — это **не тавтология**: пара операторов `(raw, pair)` невырождена (pair использует реальную p_max ≈ типичная), и разрыв между pair и gf — прямое свидетельство вариации p_t. Если `pair ≈ gf ≈ π/2` — тоже не тавтология: даже «правильная» P на обоих концах убивает структуру, значит фильтр доминирует. Тавтологичен только текущий median-p₀, где pair-P и raw сближаются из-за вырожденности оператора.

## Формально — почему pair-mean не вырожден

Теорема: если `p_t` и `p_{t+Δ}` — обе вероятностные (Σp = 1, p ≥ 0), то `p₀ = (p_t + p_{t+Δ})/2` тоже вероятностная, и
```
‖P(p₀)‖_op = p_max(p₀)·(1 − p_max(p₀)) · (1 + O(1/K))
```
где `p_max(p₀) ≥ (p_max(p_t) + p_max(p_{t+Δ}))/2 − O(спред)`. При `p_max(p_t) ≈ p_max(p_{t+Δ})` (что верно на соседних позициях, E-31) получаем `p_max(p₀) ≈ p_max(p_t)` — то есть **P(p₀) имеет ту же силу, что per-token P**. Это ровно то, чего не дают ни median (гладкий), ни argmax H (крайний).

Это и есть рекомендуемое исправление A — оператор pair-mean **по построению** имеет «типичную» силу per-token P, а не крайнюю.
