## E-40.1 — аудит объектов/срезов (гейт всего яруса) — ГОТОВ

Артефакт: `results/E40_1_audit.json`; носитель: `experiments/exp40_1_audit.py`.

**A1. Объект `Δ_gf ≈ π/2` — зафиксирован:** максимум главного угла между топ-r
**правыми** подпространствами gauge-free `J^(p_t)=P(p_t)J` на паре позиций
(t, t+Δ); **r=16** (primary), sweep diag {1,2,4,8,16,32}; слои {6,12,18,22,23};
Δ∈{1,4,8,16}; N=32 (31 после sentinel), seed 42; E-28-метрика. L23@Δ=1:
raw 0.2892 / gf 1.5665 — карточка воспроизведена из JSON точно.

**A2. Знаки Δ_gain — ГЛАВНАЯ НАХОДКА (D7):** во всех 4 коммиченных JSON
(v1/e33r2/rerun/strict±diag), на всех слоях и всех Δ gain = raw−gf **отрицателен**
(−0.004…−0.001 L6 … −1.27…−1.24 L23) — постскриптум E-33r.2 верен; **строка
карточки «Δ_gain = 0.404/0.442/0.444/0.380 (L6–L22)» не воспроизводима ни в одном
артефакте** (stale carry-over вербатим-реструкта, 8b0544c/60b8841). Карточка
исправлена аудитом на артефактные значения.

**A3. «98–99%» — закрыто верхним уровнем:** норма оператора P (O1), не энергия
(E-39-suppl); kill_frac из E-33r.2 JSON 0.977–0.990 — согласуется.

**A4. Коллизия `r_eff`:** E-27.6 T6 = энтропийный PR спектра ESG (K=128),
24.4–31.6 — объект спектра мод; E-39a = пороговый PR `U_obs` (τ=0.05 → 178,
per-doc 31) — объект пространства наблюдений. **Разные объекты с одним именем**;
противоречие «98–99% vs r_eff» уже снято E-39-suppl (норма vs энергия). Правило
яруса: всегда с индексом (`r_eff^ESG` vs `r_eff^U(τ)`). **Open до E-40.2:** какой
p-срез у спектров E-27.5/27.6 (имя файла `S64K64p0` намекает на фиксированный p0).

**A5. D4-флоры (per-cell, из сохранённых per-doc IQR, n=31):**
floor = 1.253·IQR/√n; при Δ=1 утверждение «gain<0» **testable на всех 5 слоях**

**Ворота для E-40.2:** срез C_F/C_top16-линейки E-27.5/27.6 (open A4) — проверить

## E-40.1 (m) — `real/dir-null` на второй модели (пререгистрация, НЕ выполнена)

**Что.** `O1/iso`, `conc`, `V`, `sharpness` и главное `real/dir-null` (E-39-дополнение §2.2) на кэше
`J` другой модели. Кандидат — `Qwen/Qwen3.5-4B`: профильщик exp27b его уже умеет
(`LARGE = resolve_model("Qwen/Qwen3.5-4B")` в `kaggle_kernel/kernel-exp27b/kernel.ipynb`),
E-10b/E-14 на нём уже работали (N=8, K=64).

**Зачем.** В E-39-дополнении `real/dir` = 0.623–0.692 и не двигается ни по слоям, ни по доменам
(§2.2.3, per-doc bootstrap ±0.02–0.05). Это либо число системы, либо свойство данной модели/данного
`U128`. Тест — второй носитель.

**Пререгистрированные исходы (до прогона).**
* **(m1) инвариант:** `real/dir` второй модели попадает в 0.62–0.69 и его bootstrap-CI по
  документам перекрывает этот интервал → число выносится в `paper.md` как константа, подтверждённая
  на двух носителях.
* **(m2) свойство модели:** вне интервала или CI не перекрывается → остаётся числом кэша exp27b,
  в `paper.md` помечается одним носителем, слово «инвариант» не используется.

**Стоимость (важно для планирования).** Дешёвая половина теста уже сделана и бесплатна (тот же
кэш, домены и документы — E-39-дополнение §2.2.3). Вторая половина **не** «30 минут CPU»: нужен
новый `jcache` (GPU-профильщик exp27b, ~13 ГБ выходов, выгрузка датасетом и подмонтирование), то
есть отдельный Kaggle-прогон; по зависимостям это E-41 (кэш), не ярус 0.
D-фильтр: D1/D4/D5/D7 применимы, D2/D3/D6 нет (наблюдательный ярус).

## E-40.5 — кинетика: предрегистрированные ожидания (патч v2 §1.8, НЕ выполнено)

`prism/kinetic.py::kinetic_decomposition` — шесть каналов + флаги; полное замыкание
`Σ6 + eps3 = ‖ΔJ‖²`, причём **Σ5 (без `E_off_manifold`) замыкает `‖ΔJ_proj‖²`, а не `‖ΔJ‖²`**.

Ожидания зафиксированы до прогона:
- **L6–L22:** `linearization_valid = False` (Δ_SVD = 1.4–1.5 рад > π/2 − 0.3 ≈ 1.27);
  отчитываются **только** `E_radial` и `E_off_manifold`. `E_right/left/cross/resid`
  не интерпретируются: у `log Q` нет главной ветви при таких углах. Ожидание
  `E_off_manifold ≈ ‖ΔJ‖²/2` (r = 16 ≪ D = 1024, подпространства почти ортогональны) —
  **это ожидаемый результат, не провал E-40.5**.
- **L23:** `linearization_valid = True` (Δ_SVD = 0.27 рад), `rotation_unique = False`
  (min σ-gap = 0.0092 < 1e-2·σ₁², E-38c). `E_right/left/cross` — интерпретируемы
  с пометкой `ambiguous` (basis-dependent); `E_radial/E_resid/E_off_manifold` — без оговорок.
- Негативный контроль: «5-канальная Gram-матрица замыкает ‖ΔJ‖²» проверять **только**
  на синтетике с rank(ΔJ) ≤ r; на реальных данных это ложь (патч v2 §3.3).

## E-40.7 — `G(l) = 1 − Δ_fixP/Δ_raw` — ГОТОВ (`exp40_7_G_fixation.py`, выполнен впервые)

**Что.** Δ между соседними слоями = max principal angle между top-16 правыми базисами
(window `top`, шаг 1, канал `observational`), посчитанный дважды: на реальном `J^(p_t)` и на
срезе с фиксированным `p̄` (`J^(p̄)`, `p̄` = корпусное среднее P-строка, одно на все слои);
`G = 1 − Δ_fixP/Δ_raw` как **медиана по 32 документам на слой** — то есть числитель и
знаменатель из одного среза и одного оценивателя.

**Числа.** `G` = **0.0062 / 0.0226 / 0.0609 / 0.0664 / 0.2579** на L6/L12/L18/L22/L23
(профиль монотонный по глубине); per-doc медиана 0.041, p10 0.005, p90 0.230. По пререгу —
**`ambiguous`** (монотонно, но `max_G` = 0.258 > 0.2). Собственный Δ_raw воспроизводит
E-33r strict с расхождением 0.37% (L6), 0.47%, 2.0%, 6.4%, 8.3% (L23) — оцениватели
сознательно разные (медиана средних по t против медианы по позициям), поэтому это сверка, а
не идентичность.

**Ограничение, которое нельзя терять.** `ρ_S(G, C_F(1)) = +1.00` и `ρ_S(G, κ) = −1.00` при
n = 5 слоёв — это **насыщение, а не аргумент**: на монотонном по глубине профиле ±1 даёт
любая монотонная ковариата, а `p`-value здесь предполагает независимость слоёв, которой нет.
`ρ_S(G, C_top16(1)) = −0.90` (p 0.037) — тот же дефект, чуть слабее.

**Отклонения от ТЗ.** (Д7-а) слойный Δ_fixP как «побочный выход E-40.1/E-33r» взять
неоткуда: поля `E_fixed_p` нет ни в `exp33r_gauge_anatomy.json`, ни в
`exp33r_gauge_anatomy_strict_diag.json`, ни в `E40_1_audit.json` (проверено по всем трём), так
что `G(l)` построен целиком из собственного per-doc пересчёта, а E-33r оставлен внешним
якорем по Δ_raw. (Д7-б) `p` слойно-инвариантен в кэше ⇒ partial-out по |Δp| и энтропии на
слойном уровне = стрельба по нулям, частотный partial-out дан per-doc. Тег:
`slice=fixP, p_slice=p_0` (корпусное `p̄` в словаре ТЗ — это `p_0`, не отдельное значение).

**Вывод.** Вариация `p` по позициям почти не участвует в межслойном угловом развороте:
фиксация `p̄` снимает 0.6% на L6 и ≤6.6% вплоть до L22, и только тривиальный L23
(`J = W_lm`) теряет 26%. То есть «gauge-объяснение» угловой разницы слоёв не поддерживается
в этом срезе; оставшаяся часть разворота — структура самого транспорта базисов, а не след
того, что `p` меняется от позиции к позиции.
