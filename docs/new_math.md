## Часть 1. Новая математика (единый фрагмент)

### [M-1] Лемма: структурное тождество gauge-направления

**Дано:** факторизация L23 (E-35, точна): `J = (√D/r_t) · M_K · (I − û_t û_t^T)`, `M_K = W_lm[S]·diag(g) ∈ R^{K×D}`, `û_t = h_t/‖h_t‖ ∈ R^D`.

**Определение:** `w := M_K^T · (1/√K) ∈ R^D`. Разложение относительно `û_t`:
```
w = α û_t + β v_⊥,    α = ⟨w, û_t⟩,    β = ‖w − α û_t‖₂ ≥ 0,    v_⊥ = (w − α û_t)/β (при β > 0).
```

**Утверждение:**
```
(1)  J^T·(1/√K) = (√D/r_t) · β · v_⊥            [транспонирование и проектор]
(2)  v_pred := J^T·(1/√K)/‖J^T·(1/√K)‖ = v_⊥     [при β ≠ 0, с точностью до знака]
(3)  (√D/r_t)|β| = σ_g · cos(u_g, 1/√K)          [из (1) и J^T u_g = σ_g v_g]
```

**Следствие (невозможность точной коллинеарности):** если `β = 0`, то `J^T·(1/√K) = 0`, откуда `σ_g = 0`, что противоречит `σ_g/σ_d ≈ 40` (E-12a). Значит, `β ≠ 0` обязательно, и `v_⊥` нетривиально.

**Доказательство:** подстановка факторизации в `J^T·(1/√K)`, использование `(I − û_t û_t^T)w = β v_⊥`, и `J^T u_g = σ_g v_g` по определению SVD. Полное — в приложение (см. Часть 2).

**Что это исправляет:** заменяет неверные формулы с `J^+` и `M_K^+` (они доминируются хвостом, а не gauge). Формулировка (3) — единственная корректная версия alignment-фактора; без неё — систематическое 15% смещение (E-33r: `cos(u_g, 1/√K) ∈ [0.85, 0.99]`).

### [M-2] Определение: матрица голономии и её спектр

**Дано:** топ-r правых сингулярных подпространств `V_t ∈ R^{D×r}` (ортонормированные столбцы), `r = 16` — та же настройка, что в E-28.

**Определение (Procrustes-ротация):** для пар `(i, j)`:
```
V_i^T V_j = W_{ij} Σ_{ij} Z_{ij}^T    (compact SVD),    R_{ij} := W_{ij} Z_{ij}^T ∈ SO(r).
```

**Определение (голономия):** для тройки `(t, t+1, t+2)`:
```
H_{012}(t) := R_{01} R_{12} R_{02}^{-1} ∈ SO(r).
```

**Спектральное разложение:** собственные значения `H_{012}` — `{e^{±iθ_j}}_{j=1..r/2}`, `θ_j ∈ [0, π]` (для `r = 16`: 8 углов). Спектр `{θ_j}` инвариантен к выбору базиса (сопряжение `O_0^T H O_0` сохраняет характеристический многочлен).

**Тождества (согласованность с E-28):**
```
tr(H) = 2 Σ_{j=1..r/2} cos θ_j.
‖H − I‖_F² = 2r − 2 tr(H) = 4 Σ_{j=1..r/2} (1 − cos θ_j).
```
Для `r = 16`, `κ = 0.018` (E-28): `κ² = 0.000324 = 32 − 4Σ cos θ_j`, откуда `Σ cos θ_j ≈ 7.99992`, т.е. все `θ_j ≈ 0` (ротации малы — согласуется с «rigid-but-curved»).

**Инвариантные величины (все базисно-независимы):**
- `Σ_j θ_j` — суммарный угол ротации (Abelian-агрегат);
- `Var({θ_j})` или `H_entropy({θ_j})` — разброс углов (неабелева мера);
- `Σ_j cos θ_j = tr(H)/2`.

**Что это формализует:** `κ` из E-28 — это `‖H − I‖_F`, свёртка `H` в одно число. Полная матрица `H_{012}` и её спектр `{θ_j}` — уже неявно присутствовали (κ определён через `H`), но не выписывались. Это формализация, не новый объект.

### [M-3] Определение: локальная сферическая кривизна Ω(t)

**Дано:** три consecutive единичных вектора `û_t, û_{t+1}, û_{t+2} ∈ S^{D−1}`.

**Определение (сферический избыток):** для тройки `(t, t+1, t+2)`:
```
Ω(t) := | A(û_t, û_{t+1}) + A(û_{t+1}, û_{t+2}) − A(û_t, û_{t+2}) |
где A(u, v) := arccos(⟨u, v⟩) — геодезическое расстояние на S^{D−1}.
```
Для D = 3 это совпадает (с точностью до малости треугольника) с телесным углом; для D > 3 — естественное скалярное обобщение («треугольное неравенство-дефект»), пропорциональное локальному изгибу кривой `û_t`.

**Свойства:**
- `Ω(t) ≥ 0`, `Ω(t) = 0` т. и т.т., когда `û_t, û_{t+1}, û_{t+2}` лежат на одной геодезической;
- `Ω(t)` — **локальная** величина (по тройке), не глобальная фаза (кривая не замкнута);
- `Ω(t)` — базисно-независима.

**Оговорка:** для `D ≫ 3` формула — диагностический скаляр, не «истинный телесный угол» (последний — `(D−2)`-форма). Используется как **локальный Abelian-proxy** для сравнения с `κ` из E-28.

**Сравнение:** `Ω(t)` vs `Σ_j θ_j(t)` по-позиционно.
- Если коррелируют (`ρ > 0.7`) → грассманианная кривизна `κ` определяется движением `û_t` по сфере; вклад анизотропии `M_K` мал.
- Если не коррелируют → есть независимый вклад от `M_K`-анизотропии.

### [M-4] Диагностика (pre-flight): проверка вырождения топ-16

**Перед любым применением неабелева формализма** (Wilczek–Zee или аналог): неабелева голономия требует (почти-)вырожденных собственных подпространств. Если собственные значения `J^T J` (в топ-16) хорошо разделены, каждый сингулярный вектор транспортируется независимо, и голономия редуцируется к набору абелевых фаз.

**Определение:**
```
gap_min(t) := min_{i=1..15} (σ_i(J_t)² − σ_{i+1}(J_t)²)     [минимальный eigengap в топ-16]
```
Порог (в условиях задачи): `ε = 0.01 · σ_1²` (1% от ведущего собственного значения).

**Правило:**
- Если `min_t gap_min(t) > ε` → **неабелев формализм неприменим** (все зазоры разрешимы); не вводить Wilczek–Zee-язык.
- Если `min_t gap_min(t) < ε` → неабелев формализм допустим (но не обязателен; интерпретация через `κ_WZ` — после результатов [M-2]).

**Что это исправляет:** без этой проверки «три компоненты голономии» — декларативны; проверка — **условие применимости**, не новая математика.

**Контекст:** E-27.6 T6 даёт `r_eff = 24.4–31.6` из 31 (плоский спектр — намёк); E-35 даёт `eigengap_{16/17} = 1.035`. Но `1.035` — разница между `σ_16` и `σ_17`, а не внутри топ-16. Внутренние зазоры не измерены — pre-flight это исправляет.

### [M-5] Конвенция: канонический eigenframe `M_K` на `û_t^⊥`

**Проблема:** разложение `H_{012}` на «Abelian» и «fiber» части неканонично без выбора базиса в слое `Gr(r, D−1)` (произвол `O(16)` на каждый `V_t`).

**Конвенция:** в каждом `V_t` выбрать базис, в котором ограничение `M_K^T M_K|_{û_t^⊥}` диагонально (eigenbasis, упорядоченный по убыванию собственных значений; знаки — по детерминанту +1).

**Смысл:** это фиксирует `R_{ij}` и делает разложение `H_{012} = H_{trace} · H_{traceless}` однозначным. Инвариантный скаляр `κ = ‖H − I‖_F` и спектр `{θ_j}` от конвенции не зависят; разложение на «компоненты» — зависит.

**Оговорка:** это **конвенция**, не утверждение о природе. В статью вносится как явная строка «все разложения `H_{012}` — в eigenframe `M_K`; при смене конвенции компоненты меняются, инварианты — нет».

## Часть 3. Что НЕ вносим (moratorium)

Явно **не вносится** в статью на этом этапе:

1. **Термин «Wilczek–Zee» / «κ_WZ» / «неабелева фаза».** До прохождения [M-4] pre-flight — только нейтральные «бесследовая часть», «разброс `{θ_j}`». Терминология — после эмпирики.

2. **Каноническое трёхчленное разложение `κ = Ω + κ_fiber + κ_WZ`.** Даже после [M-2] и [M-5] — только как **конвенциональное** разложение в eigenframe; не как утверждение о природе.

3. **Утверждение «Goodhart = неабелева селекция».** Это — разведочная гипотеза (13-3, пункт В), не следствие. В статью не вносится; в ТЗ тестов — да, как pre-registered exploratory.

4. **«Третий сценарий» (неабелевость в хвосте).** Требует нового измерения (хвостовая голономия вне топ-16), которое не существует. Логическая возможность, не вносится.

5. **Любые новые тензоры, связности, расслоения, кроме уже введённых через [M-2]–[M-5].** Моvo moratorium сохраняется до исходов Фазы 1 (1b-preflight + 1b).
