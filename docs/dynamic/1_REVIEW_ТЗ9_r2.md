## 2. Суждение по трём отвержениям

**D4-обвинение («novelty ≡1.0 — тавтология, константа врёт») — отвержение ПОДТВЕРЖДАЮ, обвинение в тавтологии снимаю.**
Мой r1-аргумент строился на определении «доля не-реэмиссий» (≈8/256 для 8-лупа → ≪1). Формула ядра
(exp85a:29) — `mean(cost[i+k] по first-occurrence i)/base`, т.е. post-novelty cost kernel, НЕ доля
новизны. При этом определении ≡1.0 — эмпирический результат («новизна не двигает стоимость»), а не
тавтология: на 8-лупах first-occurrence обрываются, стоимость после них = дешёвый цикл ≈ base —
снижение ядра по построению НЕ гарантировано. Имя было неверным, результат — нет. Переименование —
правильное закрытие. **НО**: принятая часть (формула+окно в реестр R9-8) в деле отсутствует — см. §3, п.3.

**E3-арифметика («VAR(2) неопределён: 8.3k параметров против ~2k наблюдений») — отвержение ПОДТВЕРЖДАЮ, арифметическая ошибка r1 моя.**
Я посчитал векторные наблюдения как скалярные. Скалярных уравнений: (T−2)·r·N_docs(фит) ≈
252–254·64·17 ≈ **2.7e5** (у ответа 252, при T=256 корректно 254 — на вердикт не влияет) против
2·64² ≈ **8.2k** параметров → система перерешена (~33×), не недоопределена. Оговорка ответа —
эффективная df мала (тракторная/автокорреляция) ⇒ ridge/rank-свип как обязательная чувствительность
вердикта — корректное и достаточное mitigation. **НО**: обязательный свип в тексте R9-6 НЕ записан
(там только базовое «ridge 1e-3») — см. §3, п.2.

**H6-бином («n=8: ≥5/8 при p=0.5 — редкость») — отвержение ПОДТВЕРЖДАЮ, ошибка r1 моя.**
P(X≥5|Bin(8,0.5)) = 93/256 = **0.363** — не редкость. Новые пороги: P(X≥12|Bin(16,0.5)) =
(1820+560+120+16+1)/65536 = 2517/65536 = **0.0384 ≈ 0.038** ✓; фолбэк n=8: P(X≥7) = 9/256 =
**0.0352 ≈ 0.035** ✓. В ТЗ R9-9 записано «ПРЕ-РЕГ порог ≥12/16 (p=0.038)» ✓. Суждение: замена
n=16+≥12/16 — статистически честнее (полный HEAT и так влезает в бюджет по r1-H6-арифметике).
