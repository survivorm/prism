## A2 Определения vs код — 2 MINOR (противоречий нет, два умолчания)

Ключ `"definitions": "rank = индекс id в top_logprobs той же позиции + 1; gap = p1-p2; flip = rank != 1; exp(logprob) без перенормировки"`.
Сверка с кодом (per_position/summarize в exp94_q2rank.py):
- rank: `ids.index(em) + 1 if em in ids else "absent"` — соответствует.
- gap: `(p[0] - p[1]) if len(p) > 1 else 0.0`, p_i = exp(logprob_i) без перенормировки — соответствует.
- flip: в summarize `rank not in (1, "no_probs")` — соответствует, за исключением двух случаев ниже.
- 'absent': определения в ключе нет, код реализует (см. MINOR-1).
- Вложенный ключ divergence_alignment.definitions сверен с кодом: «первое расхождение =
  индекс prefix_len» — код `div = [d ... if pl[d] < 384]`, «первый флип = минимальный j с
  rank != 1 по r1» — код `min j` по r1-строкам — соответствует.
- null_perturbation.definition сверен с кодом: P(rank=k | rank!=1) = p_k / sum_{j>=2} p_j —
  код рисует из xвоста p_tail = p[1:] с рангом = индекс+2 — соответствует.

MINOR-1 (A2): ключ `definitions` не определяет случай, когда emitted id отсутствует в
top_logprobs. Код задаёт rank='absent' и считает это флипом; правило есть в docstring
модуля («если id нет в списке — 'absent'»), но не в самом ключе артефакта. Текст не
противоречит коду (это умолчание, а не расхождение), а эмпирический эффект нулевой:
n_absent_from_top20 = 0 во всех трёх армах (проверено мной независимо). Поэтому MINOR,
не MAJOR. Предписание: дополнить ключ: «если id нет в top_logprobs — rank='absent',
считается флипом».

MINOR-2 (A2): определение «flip = rank != 1» не упоминает no_probs (пустой
top_logprobs), которые код НЕ считает флипами. В данных таких позиций 0 из 14592
(проверено), т.е. определение в данном наборе эквивалентно. Предписание: уточнить:
«позиция без отчёта (нет top_logprobs) флипом не считается».
