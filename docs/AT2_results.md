### 3.2 Floor: тривиальный константный канал

**cos(средний y по доку, y) = 0.9449–0.9456 (k=8…1)** — ВЫШЕ любого readout (0.93).
R² LOO-ridge < 0 везде (−0.20…−0.25): readout объясняет меньше 0 % дисперсии будущего логита —
хуже тривиального предиктора «средний логит дока». Метрика пре-рега (cos по сырым логитам)
доминирована константным каналом: направление будущего логита z_{t−k} почти постоянно внутри дока
(автокосинус по t ≈ 0.92), и cos не чувствителен к реальному содержанию readout.

### 3.3 lk4 (текстовый baseline)

- one-hot vs z cos: median **0.0** на всех k — вырожденное сравнение (D3): при 39–73 % hit-позиций
  целевой токен вне U128, и one-hot = нулевой вектор (покрытие U128: k1 0.48, k2 0.39, k4 0.73, k8 0.73).
- N8-стратум (позиции, предсказуемые 4-грамом; compound.md:134): cos readout 0.86–0.90 — НИЖЕ
  глобального 0.93: текстово-регулярные позиции — именно там, где state-readout слабее.

### 3.4 Вердикт

**NOT_RESOLVED** (исправленная логика D2: (a) требует выигрывающий CI — нижняя граница > 0).
По фиксированному пре-регом дереву ни (a) SCRATCHPAD, ни (b) DEADWEIGHT, ни (c) REDUNDANT_BASIS
не реализуются строго: (a) — weak НЕ выше max(PCA,Haar) (CI отрицательны: −0.002…−0.009);
(b) — readout не «~0», а ниже floor; (c) — часть парных CI статистически исключает 0
(при 4096 позициях различие 1e-3 «значимо»), но эффект ≤0.2 % floor.

**Чтение (результат, а не шум — AGENTS 6):** фиксированная метрика не способная разделить
гипотезы T2, потому что она degeneratна: даже Haar-базис (null) и тривиальный mean-предиктор
не уступают J-базисам. Гипотеза «state h_l несёт readout-абилитное будущее (scratchpad)»
**не подтверждена** disk-only readout'ом в этой метрике; статус T2 — «не подтверждено»,
понижение фиксируется здесь (пре-рег: «иначе (b)/(c), T2 понижается»).

## 4. Отклонения от пре-рега (фиксация)

- **D1 (S4-числа):** scope-цифры lk4 65/4096 (wiki 8 / math 31 / code 25 / chat 1) НЕ
  воспроизводятся с pin-пулы: канон (experiments/exp64_at_battery.py:23-30, побайтово) даёт
  90/4096 (8/41/36/5). Гейт зафиксирован на каноне as-is; review r1 addendum M5; §7 пре-рега
  обновлён до прогона.
- **D2 (вердикт-логика):** в прогоне r1 (wall 300.5 с) логика (a) считала «значимый» CI в обе
  стороны — отрицательный CI (weak ХУЖЕ max(PCA,Haar)) засчитывался как «выигрыш» → вердикт
  SCRATCHPAD — артефакт. Исправлено на win_ci (нижняя граница > 0); прогон r2 — валидный.
  Ресемплинги/метрики r1 и r2 идентичны (детерминизм, S9).
- **D3 (lk4-сравнение):** one-hot токена vs вектор логитов — разные пространства; при токене
  вне U128 one-hot = 0 → cos = 0. Пре-рег это зафиксировал как «cos one-hot vs z», но сравнение
  вырожденно по построению; в артефакте дополнительно отчитано покрытие U128 (39–73 %).
- **D4 (rematching):** d_eff-разброс 2.13 > 1.2 → r_final = 7 (пре-рег §4, как задумано).
