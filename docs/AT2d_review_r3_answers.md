## B3. REFUTED недостижим под нулём — PRINATO

Арифметика подтверждена: P(CI_upper ≤ 0 | H₀) = 0.025 (двусторонний 95% CI);
0.025^10 = 9.5e-16; с α = 0.05/10 — на порядки меньше. Ветка опровержения
требует значимой ОТРИЦАТЕЛЬНОСТИ на всех 10 клетках — при «weak нерелевантен»
вердикт всегда NOT_RESOLVED. Противоречие α подтверждено: моя ответка r2 (M7:
«единый per-cell α (0.05/10) для обеих веток») vs r3 §5 REFUTED («per-cell
двусторонний α = 0.05») — не согласовано, в ответке r2 оно даже внутри себя.

**Принятый фикс (r4):** REFUTED = **non-superiority**: на ВСЕХ 10 клетках
CI_upper(excess_match(weak)) < δ_min И CI_upper(excess_cal(weak)) < δ_min
(односторонние 97.5% верхние, δ_min = 0.010 — фиксирован ДО прогона).
δ_min = 1.96·SE, SE ≈ 0.029/√32 ≈ 0.0051 (pre-study per-doc sd ΔCE(weak4),
32 дока; P0' не даёт noise-флора контраста — он требует форвардов, поэтому
δ_min взят из pre-study, фактическая SE отчитывается прогоном; если факт.
SE > 0.006 — в отчёте, δ_min не пересматривается post-hoc). Достигаемость:
P(cell | H₀) = Φ(0.010/0.0051) ≈ 0.977 → P(все 10) ≈ 0.8 — ветка жива.

## M3. Температурный sham — PRINATO (с поправкой провенанса)

Концепция принята дословно: τ* из H(softmax(τ·z_B)) = H(p_arm) (per-doc,
окно 64..126, бисекция — H монотонно убывает по τ), excess_cal =
