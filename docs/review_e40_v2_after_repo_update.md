## 2. Новые находки по новому коду

### N1. **ТЗ и код замыкают разные нормы ⇒ §12.8/§14.6 сработают ложно** — высший приоритет

- `prism/kinetic.py:164-205` (`channel_energy_matrix`): компоненты `A1=embed(ΔΣ)`, `A2=embed(MΣ̄)`, `A3=embed(−Σ̄N)`, `A4=embed(B−ΔJ_lin)`, `A5=ΔJ−embed(B)`; `G_ij = ⟨A_i, A_j⟩` ⇒ **`Σ_ij G_ij = ‖ΔJ‖²` тождественно** (в `off` входит `A5`).
- `tests/test_transport_kinetic.py:97-104` проверяет именно `G.sum() == ‖ΔJ‖²` (rel 1e-12) с комментарием «accounting, not linearization» ✓.
- **ТЗ §7.2** требует: «5×5 Gram `channel_energy_matrix`: `Σ_{ij} G_{ij} = ‖ΔJ_proj‖²` — алгебраическое тождество, tol `1e-10`, **все слои**»; **§12.8** — «5×5 Gram `channel_energy_matrix` = `‖ΔJ_proj‖²` (exact)»; **§14.6** — «Сумма 5×5 Gram `≠ ‖ΔJ_proj‖²` ⇒ **баг декомпозиции в `kinetic.py`**» ⇒ стоп фазы.
- Докстринг кода сам фиксирует различие: «Restricting the Gram to the four in-frame vectors {radial, left, right, resid} closes only `‖ΔJ_proj‖²` — and on real exp27b data … `E_off ≈ ‖ΔJ‖²/2`, i.e. ‘4×4 closes ‖ΔJ‖²’ is FALSE there».

⇒ На реальных данных L6–L22 `Σ_ij G_ij = ‖ΔJ‖²`, а `‖ΔJ_proj‖² ≈ 0.5‖ΔJ‖²` — **проверка, написанная по ТЗ, разойдётся примерно в 2 раза** и объявит «баг в `kinetic.py``, которого нет. **Правка ТЗ:** `‖ΔJ_proj‖²` → `‖ΔJ‖²` (или явно оба варианта, как в докстринге). Это же касается §12.8 и §14.6.

### N2. **«T4a: 8 ячеек замкнуты» — тавтология; стоп-правило §14.3 недостижимо**

`experiments/exp40_1_t4a.py::triple_from_chunk`:
```
a = ‖PJ‖²;  cross = ⟨J,PJ⟩;  e = ‖J‖²
k2_direct = ‖J − PJ‖²          # прямое измерение
k2 = e − 2*cross + a            # ← из САМОГО тождества
assert |k2 − k2_direct|/e < 1e-9
return {..., "frac_t": k2/e, ...}   # ← frac_K берётся из тождества
```
⇒ `frac_t = 1 − 2c_t + s²_t` **по построению**, и линейность агрегаций даёт тождественное замыкание **ratio_of_means**- и **mean**-ячеек (`residual ≈ 0` до шума fp64). Единственная ячейка с содержанием — **median** (негативный контроль, `assert any(not closed …)`) ✓, и отдельный per-chunk assert на прямое вычитание ✓.

Следствия:
1. Стоп-условие ТЗ §14.3 («если **ни одна** mean/ratio_of_means-ячейка не замкнулась → численный баг или кэш-ошибка») **не может сработать** — кроме шума fp64. Оно не охраняет от «бага или кэш-ошибки».
2. «E6 resolved» и формулировка коммита «T4a 8 ячеек замкнуты» **переоценивают доказательность**: замыкание здесь — алгебра, а не измерение. Содержательный результат E6 — это **T4b**-диагноз (смешанные агрегации в опубликованной тройке ⇒ `s²_implied < 0`) плюс настоящий assert тождества `err < 1e-9` и g_uni-чекпоинт.
3. Чтобы проверка стала содержательной, `frac_K` надо считать **прямо** (`k2_direct`) — тогда остаточная величина показывает, насколько aggregation-согласованность ломается численно; а чтобы проверка «данных» имела смысл, нужен ещё один слой: сравнение `frac_K` **с артефактным** значением из `exp39_supp_three_objects.json` (в текущем коде артефакт используется только для T4b и g_uni, но **не** как контрольная точка ячеек).

### N3. **Аудит-пункт (b) фактически неверен: E-27.6 T6 — не raw и не «ESG-спектр по K=128»**

`experiments/exp27_6_isolation.py:65-80` (`_gram`):
```
Jg = einsum('ik,ikd->id', Pl, Jl)            # Jᵀ p
Jb = Pl[:, :, None] * (Jl - Jg[:, None, :])  # = p_i(J_i − Σ_j p_j J_j) = P(p)J
```
докстринг: «K^F = cos of **full gauge-free J**» ⇒ **применяется per-position `P(p_t)`**, т.е. срез **canonical**, а не raw. При этом `t6_eigengap` берёт спектр **32×32** кросс-документной косинусной матрицы (n=32 документа), а не ESG-грамиан 128×128.

А `exp40_1_manifest.py::ITEMS["(b)"]` утверждает: «r_eff E-27.6 T6 — **ESG-спектр от raw JR** (в конвейере exp27_6 нет P)»; `exp40_1_audit.py:149-151` — «ENTROPY participation ratio of the ESG (JJ^T) spectrum over **K=128 modes**».

⇒ Артефакт `E40_1_core_manifest.json::audit_items["(b)"]` и `E40_1_audit.json::A4_r_eff_collision` содержат **неверный ответ на вопрос §3.1(b) («`r_eff` — на raw или canonical?»)**: правильный ответ — **canonical (`P(p_t)`, per-position)**. Это прямо противоречит и докстрингу `exp27_6_isolation.py`, и самому гейту (`p_slice = p_t`). Отдельно: «ESG-спектр по K=128» — неверное имя объекта (спектр 32×32 кросс-документной матрицы); и `paper.md` §2.3 объявляет меж-сэмпловый пул **невалидным** (`C_b ≈ 0.003–0.05`), т.е. спектр T6 построен на матрице, для которой сам проект запрещает интерпретацию.
