## 1. Вопрос и логика (односторонний тест)

Тестируются два свойства солитонной программы: **локализация** (возбуждение от
луп-вставки пространственно ограничено в поле h(t), не размазано по документу)
и **квази-интеграл** (модовая «энергия» возбуждения сосредоточена в ограниченной
области позиции). Логика:

- `NOT_LOCALIZED` ⇒ **фальсификация** (объект не солитон, независимо от остального).
- `LOCALIZED` — необходимое условие выполнено; **НЕ подтверждение** солитона
  (аддентум А7; статус V3_PATHOLOGY / NOT_RESOLVED не отменяется).
- Условие валидности (урок AT8_2): наблюдаемые — **позиционные**, не оконные
  скаляры (медиана слепа к локальному меньшинству позиций).

## 5. Стимулы и геометрия

- `PHRASE = " The class will be held at the park."`, `PHRASE_IDS =
  [561, 523, 668, 381, 5467, 506, 279, 5926, 13]` — сверка с токенизатором в S4
  (assert; стимул R2, воспроизведён).
- Дозы `n ∈ {2, 4, 8, 16}`, `L_n = 9n`. `inj = ids[:cut] + phrase·n + ids[cut:]`,
  `cut = T//2` на док. **Выравнивание:** `t_inj(d) = cut + L_n + d`,
  `t_ctrl(d) = cut + d`, `d = 0..D` (D = T − cut − 1 на док); оба состояния —
  на одном исходном токене `ids[cut+d]`. S8: ассерт `seq[cut+L_n:] == ids[cut:]`
  для каждого условия.
- **Филлеры (cross-doc внутри домена, механизм R2):** для дока с локальным
  индексом j в домене, `fillerA(n)` = первые 9n токенов дока (j+1) mod 4,
  `fillerB(n)` = (j+2) mod 4. S4: в филлерном блоке нет 9-грамм со счётчиком
  ≥ 3 (период-9 структура; измерено на замороженных 16 доках: макс. счётчик
  144-токеновых блоков = 2, ≥3 нигде нет — единичный повтор 9-граммы это
  текстовый шум, не луп; строгий гейт ≥2 из ТЗ v2 убил бы 4 из 16 доков:
  d4, d6, d8, d10). fillerA ≠ fillerB, filler ≠ loop. Filler-таблица (док →
  источник, диапазон, sha256 на каждую дозу) **замораживается в манифесте до
  прогона**.
- **Случайный блок (положительный контроль, §9):** 144 токена,
  `numpy default_rng(0).integers(0, 248320, 144)` — **заморожен в этом ТЗ**
  (полный список в §12 — source of truth; sha256 `json.dumps(списка)` =
  `0dae5659e99518de2d5b94b9ac320202d41a887577910eecc121b336d47b19cc`;
  sha `bfa37b24…` в TZ v1.0 — ошибка, список не менялся). Устанавливается
  только на n=16.

**Условия на док (14):** `ctrl` (1), `loop(n)` × 4, `fillerA(n)` × 4,
`fillerB(n)` × 4, `rand(n=16)` (1).

## 6. Наблюдаемые (позиционные, per (док, n, слой), d = 0..D)

Обозначения: `δh_c(d) = h_c(t_inj(d)) − h_ctrl(t_ctrl(d))` для c ∈
{loop, fillerA, fillerB, rand}; `A_c(d) = ‖δh_c(d)‖₂ / max(‖h_ctrl(t_ctrl(d))‖₂, 1e-6)`.

| Наблюдаемая | Формула | Роль |
|---|---|---|
| `A_spec(d)` | `‖δh_loop(d) − δh_fillerA(d)‖ / ‖h_ctrl‖` | **ПЕРВИЧНАЯ** — луп-специфичный профиль |
| `A_null(d)` | `‖δh_fillerA(d) − δh_fillerB(d)‖ / ‖h_ctrl‖` | эмпирический null → floor |
| `A_ins(d)` | `‖δh_loop(d)‖ / ‖h_ctrl‖` | реакция вообще (вставка + луп) |
| `A_rand(d)` | `‖δh_rand(d)‖ / ‖h_ctrl‖` | положительный контроль (только n=16) |
| `q(d)` | `Σ_{i≤32} ⟨δh_loop(d), v_i⟩²` | модовая энергия (basis — из PCA) |
| `Q(d)` | `Σ_{d'≤d} q(d')` | кумулятивный квази-интеграл |
| `capture(d)` | `q(d) / ‖δh_loop(d)‖²` | доля возмущения в топ-32 подпространстве |

Базис: `v_i^(L)` — топ-`r = 32` правых сингулярных вектора центрированного
`H_ctrl` (256×1024) слоя L (из контрольного форварда).
Вторично (конвенция R2): `cos_raw/cos_state/norm_delta` per position + `ce`
на каждое условие. **Ось дозы** `I(n)` = Σ CE луп-блока (per док; медиана по
докам в отчёте) — I, не D (D — горизонт, коллизия имён исключена).

**Концептуальная граница (фиксируется в артефакте):** в teacher-forced статике
нет независимой временной оси; «сохранение» операционализировано как
стабильность пространственного профиля q(d) и насыщение Q(d). Глубина ≠ время
(запрет аддентума). Это НЕ тест динамики солитона.

## 7. Floor δ_min (та же статистика, что и профили — урок F4 R2)

- **Позиционный:** `δ_min(n, L, d) = 95th pct A_null(n, L, d)` по докам с
  `D_doc ≥ d` (T разный: при d=0…96 — 16 доков, при d=127 — 11; per (n, слой,
  позиция); numpy linear interpolation — из ≤16 значений это интерполяция
  между 15-й и 16-й порядковыми статистиками; грубость задокументирована).
- **Скалярный:** `δ_global(n, L) = 95th pct` всех значений A_null(n, L)
  (по докам и d) — для сравнения «нет отклика вообще».
- Все сравнения «выше/ниже» — против floor, не против нуля. «Дальные
  позиции» (из черновика) — только диагностика, в вердикт не идут (цикличность:
  «вне влияния» до ответа неизвестно).

## 8. Контроли

- **Положительный (S7a, обязан сработать):** PASS, если для **≥12 из 16 доков**
  на **≥3 из 4 слоёв**: `max_{d ∈ [0,31]} A_rand(d) > max_{d'} δ_min(n=16, L, d')`.
  Иначе — `INSENSITIVE_CELL`, артефакт не интерпретируется.
- **Нуль (S7b):** профиль A_null (медианы, p95) в отчёте; A_null конечен (S5).
  Отдельного вердикта нет — null задаёт floor.

## 9. Статусы и вердиктное дерево (пре-рег, до прогона)

**Per (док, n, слой L)** — по A_spec против позиционного floor δ_min(n, L, ·) (ТЗ v2):
- `NO_RESPONSE`: A_spec(d) ≤ δ_min(n, L, d) для всех d.
- `δ_global(n, L)` — только диагностика (тег BELOW_RESOLUTION в дереве).
- `PERSISTENT`: нет `d ∈ [0, D−m]` с `A_spec(d') ≤ δ_min(n,L,d')` для всех
  `d' ∈ [d, d+m]` (m = 8) → ξ = D.
- `LOCALIZED`: наименьшее такое d существует → `ξ < D`.
- Тег `FAR_BUMP`: доля `d ∈ [ξ+m, D]` с A_spec(d) > δ_min(n,L,d) > 10%
  (только для LOCALIZED; диагноз, не гейт).

**Per (док, n):** статус согласован на **≥3 из 4 слоёв, среди них ≥1 GDN и
≥1 full** → статус дока; `ξ_док(n)` = медиана ξ по согласованным слоям.
Иначе `LAYER_INCONSISTENT` (в neither-счётчики).

**Per доза n:** `frac_persistent(n) = #PERSISTENT/16`,
`frac_localized(n) = #LOCALIZED/16`.

**Дерево (полностью явное, приоритет сверху вниз; v1.2):**

Граничная арифметика (зафиксирована): «≥2 из 4 доз: frac ≥ 0.5» — доза-граница =
**ровно 2 из 4** доз; при 16 доках `frac ≥ 0.5` ⇔ **≥8 из 16** доков на дозе
(8/16 = 0.5; 7/16 = 0.4375 < 0.5). «6 из 16» (0.375) не триггерит.

Обозначения: `np(n)`, `nl(n)` — frac_persistent / frac_localized на дозе n.
1. `INSENSITIVE_CELL` — позитивный контроль провален (§8).
2. `DOSE_MIXED` → `NOT_RESOLVED` + тег `DOSE_MIXED` — выполнены **оба** условия:
   ≥2/4 доз `np ≥ 0.5` И ≥2/4 доз `nl ≥ 0.5` (смешанный дозовый режим, например
   2 дозы PERSISTENT + 2 дозы LOCALIZED). Вердикт — честно «неразрешено»; дозовая
   зависимость ξ(n), np(n), nl(n) — только диагностика.
3. `NOT_LOCALIZED` — на **≥2 из 4 доз** `np ≥ 0.5` (и <2/4 доз с `nl ≥ 0.5`).
   ⇒ локализация опровергнута ⇒ объект не солитон (по пре-регу ТЗ_4-8 §8).
4. `LOCALIZED` — на **≥2 из 4 доз** `nl ≥ 0.5` (и <2/4 доз с `np ≥ 0.5`).
   Необходимое условие выполнено; **не подтверждение солитона**.
5. `NOT_RESOLVED` — иначе. Теги: `DOSE_MIXED` (случай 2); `BELOW_RESOLUTION`
   (на всех 4 дозах max A_spec ≤ δ_global — ниже разрешения, `not_testable`,
   не `refuted`, как AT8_2 v3); `WIDE_CI` (CI95 frac квалификационных доз содержит
   0.5); `FAR_BUMP` (>25% локализованных доков несут тег).

**Дозовая зависимость ξ — диагностика только** (ξ(n), ξ(I(n)); тег DOSE_TREND
при монотонном росте) — НЕ гейт (устраняет противоречие 6.2/6.3 черновика).

**Квази-интеграл (вторичный отчёт, в вердикт не идёт):** насыщение
`Q_sat = (Q(D) − Q(⌊0.75D⌋)) / max(Q(D), 1e-9) ≤ 0.10` → «насыщен»;
отчитывается только при capture-медиане ≥ 0.5 (ТЗ v2), иначе — пометка
«вне подпространства»; профили q(d), Q по дозам. В вердикт не идёт.

## 10. Статистика

- Единица ресемплинга — **документ** (общий контроль, вложенность доз,
  позиционная автокорреляция).
- Doc-bootstrap `B = 2000`, `seed = 0`, перцентильные CI95: на frac_persistent/
  frac_localized (per доза) и на медиану ξ_док. Вердикт — по точным оценкам
  (зафиксировано), CI — в отчёт + тег WIDE_CI.
- Позиционный блок-бутстрап — только вторично (оценка автокорреляции), в
  вердикт не идёт.

## 13. Цена

- 16 доков × 14 условий = **224 форварда** (коррекция черновика 144/9:
  учтены rand-блок и fillerB на всех дозах; переиспользование форвардов R2
  невозможно — store R2 не хранит h-векторов, проверено по ключам).
- Замеры: 6.2 с/фд (R1, без нагрузки) → ~23 мин; 14.3 с/фд (R2, под нагрузкой,
  182 фд/2596 s) → ~53 мин. **Бюджет: 60–90 мин** с PCA и анализом.
- Смоук: 2 дока × 14 условий + 4 (eager/sdpa) ≈ 32 форварда.

## 14. Смоук-план (до полного прогона)

2 дока (wiki + math), все 14 условий. Критерии:
1. `ctrl CE ∈ [2.0, 4.0]` (якорь R2 ~3.2); `loop_block CE(n=16) < 1.0`;
   `filler_block CE ≥ 2.0` (якоря R2).
2. S8 (токен-идентичность суффикса) и S5 (finite) на смоук-наборе.
3. Позитивный контроль: max_{d≤31} A_rand > max_d δ_min(n=16) на ≥2 слоях
   каждого смоук-дока (слабее полного правила — на 2 доках).
4. S0 (eager/sdpa кроссчек, 1 док: ctrl + loop n=16; max относ. разница
   A_spec < 1e-5 → идём в sdpa, иначе STOP).
5. Синтетика машины: 7/7 PASS (LOCALIZED / PERSISTENT / NO_RESPONSE→BELOW /
   INSENSITIVE / LAYER_INCONSISTENT / DOSE_MIXED / NOT_RESOLVED).
Маркер: `SMOKE_PASS`.

## 16. Границы (не утверждать)

- Не измеряет: форму-инвариантность, упругое столкновение двух объектов,
  внутреннюю моду (другие клетки, двухобъектный дизайн).
- `LOCALIZED` не повышает статус до «солитон» и не отменяет V3_PATHOLOGY (AT8_1)
  / NOT_RESOLVED (AT8_2).
- Генерация не считается (teacher-forced). Σc² по глубине ≠ сохранение во времени.
- L23 — readout-adjacent; «среда» по нему — только с согласованием промежуточными.
- Квази-интеграл в строгом физическом смысле (статика) не измеряется — только
  пространственный профиль и насыщение.
- A_spec — векторная разница (луп − филлер той же длины): это «луп сверх
  вставки», а не «луп вообще» (эффект вставки живёт в A_ins).
