## Находки

### М1 (MAJOR) — Yule-Walker-матрица в ТЗ неверна
- **Где:** T0.6, блок «NULL (primary)»: «φ₁,φ₂ решают `[c1 c2; c2 c1][φ₁;φ₂]=[c1;c2]`».
- **Что:** верные Yule-Walker-уравнения AR(2) (γ(k)=φ₁γ(k−1)+φ₂γ(k−2), k=1,2) дают
  `[c0 c1; c1 c0][φ₁;φ₂]=[c1;c2]` — диагональ c0 (не c1), недиагональ c1 (не c2).
- **Почему (числа):** AR(2)-синтетика, истинное φ=(0.5,−0.3), N=20000:
  c0=2.554e4, c1=9.968e3, c2=−2.375e3. Матрица ТЗ `[c1 c2;c2 c1]` → **φ=(1.0, 0.0)**
  (случайное блуждание); корректная `[c0 c1;c1 c0]` → **φ=(0.503, −0.289)**≈истинное.
  Формула σ²=c0−φ₁c1−φ₂c2 при этом верна (k=0 YW), что маскирует ошибку матрицы.
- **Чинить:** заменить матрицу на `[c0 c1; c1 c0][φ₁;φ₂]=[c1;c2]` (или, эквивалентно,
  решать γ(1)=φ₁γ(0)+φ₂γ(1), γ(2)=φ₁γ(1)+φ₂γ(0)); добавить unit-чек «фит восстанавливает
  φ на AR(2)-синтетике с известными φ» (fail-loud гейт ДО прогона).
- **Серьёзность:** блокер — как написано, null = случайное блуждание, тест бессмысленен.

### М2 (MAJOR) — AR(2)-null «fit-then-test на тех же данных» недискриминативен
- **Где:** T0.6, «NULL (primary)» (фит AR(2) из real x, затем F_obs против null'а из этого фита).
- **Что:** тест отклоняет собственный нуль: истинный AR(2)-процесс (гипотеза H0!)
  статистически значим с завышенной частотой.
- **Почему (числа):** калибровка «истинный AR(2) r, ω₀=2π/13 → фит → null → p»
  (12 реализаций, D=256, B=100, T′=383):
  - r=0.9  → frac(p≤0.05) = **0.17** (должно ~0.05);
  - r=0.99 → frac(p≤0.05) = **1.00** (12/12 ложных пиков);
  - r=0.999 → frac(p≤0.05) = **1.00** (12/12).
  Контроль с ORACLE-r (null из истинных φ, без фита): frac(p≤0.05) = **0.00** на всех r
  (p-values равномерны) ⇒ причина — смещение Yule-Walker-оценки r ВНИЗ при r→1 (на T′=383
  r=0.999 фитится как r≈0.986), а высота Лоренц-пика ∝ 1/(1−r²) гиперчувствительна к r:
  r 0.999→0.986 меняет дисперсию осциллятора 1/(1−r²) в ~14× и высоту спектрального пика 1/(1−r)² в ~200×. Реальный loopy-документ (почти незатухающая
  петля, r≈1) попадает ровно в этот режим ⇒ H1 «confirmed» не доказывает «сверх порядка 2».
- **Чинить (варианты, на выбор):**
  1. Тест на ШИРИНУ/форму пика, а не на высоту: отношение F(ω_p) к F на соседних
     ω (peak-to-sideband) или ширина пика на полу-максимум — сравнить с AR(2)-null'ом;
     ширине Dirichlet (~1/T) vs Лоренца (~(1−r²)·T) не мешает смещение r.
  2. Bias-corrected r: фит r с поправкой на конечновыборочное смещение (или null с
     r_фит + Δ, где Δ оценивается калибровкой) — но это хрупко, вариант 1 чище.
  3. Пред-зафиксированный r в null (не фит из тех же данных), напр. r, восстановленный
     по отдельной процедуре/частям ряда — требует своего пре-рега.
  Обязательный гейт ДО прогона: калибровочная таблица «истинный AR(2) r∈{0.9,0.95,0.99,0.999}
  → эмпирический FPR на 5%» должна лежать в ~[0.03, 0.08]; текущее ТЗ её не прописывает.
- **Серьёзность:** блокер — primary-тест H1 валиден лишь при r≲0.85, а loopy-документы
  как раз r≈1; без правки «confirmed» не интерпретируется как «сверх AR(2)».

### м3 (MINOR) — арифметика нормировки F: «E[F]≈1» и «16.5»
- **Где:** T0.6 «ESTIMAND» («Под iid: E[F] ≈ 1») и «POSITIVE» («a = 0.3σ … E[F] ≈
  T′·a²/(2(σ²+a²/2)) ≈ 16.5»).
- **Что/числа:** iid (B=200, T′=383): **mean F = 0.00519 = 2/T′** (не 1; сдвиг ×191.5).
  cos+шум a=0.3σ, D=1024: **F_mean = 0.0479**; аналитика a²/(a²+2σ²) = 0.0431;
  16.5/0.0431 ≈ 383 = T′ (формула ТЗ — это F без деления на T′). Чистый cos: F=0.999 (F —
  доля мощности в линии, O(1)).
- **Почему не блокер:** p-value эмпирический и scale-инвариантный (одна формула на обеих
  сторонах) — валидность тестов не страдает; ошибочны только описательные числа.
- **Чинить:** заменить «E[F]≈1» на «E[F]≈2/T′ (iid)»; «16.5» → «≈a²/(a²+2σ²)≈0.043»;
  либо переопределить F без T′ в знаменателе и пересчитать ВСЕ пороги/гейты (не рекомендуется).
- **Серьёзность:** правка (числа в пре-реге должны быть истинными; «16.5» в отчёте
  скомпрометировало бы положительный контроль при перепроверке).

### м4 (MINOR) — binomial-числа
- H1: P(Bin(30,0.05)≥15) = **2.306e-12**, в ТЗ «≈2.3e-9» (×1000, мантисса совпала).
- H2: P(Bin(66,0.05)≥6) = **0.1118**, в ТЗ «≈0.10» — ок с округлением, но записать 0.11.
- Чинить: 2.3e-9 → 2.3e-12; 0.10 → 0.112. Серьёзность: правка (выводы не меняются).

### м5 (MINOR) — корневой тест нестационарности: зафиксировать полином
- **Что:** «корень |·| > 1+1e-9» — верно только для характеристического
  λ²−φ₁λ−φ₂=0 (|λ|>1 ⇔ нестационарно). ЭКВИВАЛЕНТНО: (φ₁+φ₂>1) ∨ (φ₁−φ₂>1) ∨ (|φ₂|>1).
  НЕ эквивалентно «φ₁²+4φ₂<0» (это лишь «комплексные корни»): стационарный осциллятор
  φ=(0.5,−0.3) даёт φ₁²+4φ₂=−0.95<0, но стационарен (корни 0.25±0.487i, |λ|=0.55<1);
  наоборот, нестационарный (3.0, 0.5): φ₁²+4φ₂=11>0 и |φ₂|<1, а корень 3.158>1.
- **Почему важно:** loopy-документы — осцилляторы (комплексные корни); если в реализации
  «корневой тест» упростят до φ₁²+4φ₂<0, ВСЕ осцилляторные клетки уйдут в iid-null,
  и H1 превратится в тест «не белым шумом».
- **Чинить:** в ТЗ явно: «корни λ²−φ₁λ−φ₂=0; флаг при max|λ|>1+1e-9; эквивалент
  (φ₁+φ₂>1)∨(φ₁−φ₂>1)∨(|φ₂|>1)». Серьёзность: правка.

### м6 (MINOR) — короткие клетки в H2 (T′<2p)
- **Что:** H2-пул содержит 2 corpus-дока с T′<2·48: cor_w8 (T′=82, 1.71 периода при p=48),
  cor_w11 (T′=94, 1.96). Правила для T′<2p в ТЗ нет.
- **Почему:** max_{p∈3..48} на 82 сэмплах: p>41 — алиасинг/один-полтора периода, «линия»
  занимает весь спектр; может ложно поднять g (→ H2 fail → ложный NON-SPECIFIC/REFUTED).
- **Чинить:** per-cell ограничитель сетки p ≤ floor(T′/2) (и пометить p≤T′/2 в отчёте);
  либо исключить 2 клетки из H2 с пометкой (g считается по 64). Серьёзность: правка
  (2 клетки из 66, но влияние на вердикт возможно).

### м7 (MINOR) — positive control вырожден
- **Что:** при a=0.3σ с независимыми фазами 1024 dim'ов Yule-Walker-фит даёт r≈0
  (замер: φ=(0.034,0.019) при p₀=13 и φ=(0.037,0.034) при p₀=27; даже при a=1.5σ r_fit≈0)
  ⇒ «AR(2)-null» в контроле = фактически iid-null; 4/4 проходит как тест «не белый шум»,
  а не как проверка дискриминатора «линия vs Лоренц».
- **Почему:** суммарные (по dim'ам) моменты с независимыми фазами: c(k)≈(a²/2)cos(ωk)·T′D —
  ослабленный чистый косинус, 2-лаг YW которого даёт φ₂≈0 (у чистого косинуса φ₂=−1,
  у «чистого косинуса+шум» φ₂ интерполирует −1→0 с SNR).
- **Чинить:** (а) добавить positive control с НАСТОЯЩИМ узким пиком, где фит даёт r>0
  (например, a≥1.5σ на меньшем числе dim'ов с СОГЛАСОВАННОЙ фазой, или AR(2) r=0.999
  vs «петля» — калибровочная пара); (б) в любом случае гейт М2 (FPR-калибровка) обязателен.
  Серьёзность: правка (гейт проходит, но не валидирует ключевой механизм).

### м8 (MINOR) — «borderline» 10–14 уже значимо под нулём
- P(Bin(30,0.05)≥10)=1.16e-6: f=10 — уже ≫5σ от нуля. Банд «10 ≤ f ≤ 14 → borderline
  (без утверждений)» консервативен относительно бинарного порога, но слово «borderline»
  не отражает, что и f=10 — глубокая значимость. Чинить: переформулировать банд как
  «пред-рег уровень уверенности» (сильный/средний сигнал), не как p-value-статус.

### м9 (MINOR) — wording «NON-SPECIFIC»
- «NON-SPECIFIC: пики есть и у loopy, и у остальных» читается как «петля неспецифична»
  (T0.3 уже показал loopy-структуру). Чинить: «спектральный пик не loopy-специфичен
  (нет loop-specific утверждения)».

### м10 (MINOR) — центрирование null'а не прописано явно
- «Центр. по dim ДО всех статистик» — для real явно; для симуляций null'а (AR(2),

  но для «одинаковая статистика на обеих сторонах» прописать: F_null считается по тому же

### м11 (MINOR) — зафиксировать: H1-пул = 30 degen-доков
