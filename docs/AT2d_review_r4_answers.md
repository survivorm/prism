## 1. δ_min / достижимость REFUTED — PRINATO, баг мой, формула ревью подтверждена

Моя строка в r4 «P(cell) = Φ(0.010/0.0051) ≈ 0.977 → P(все 10) ≈ 0.8» —
**ошибка: я сравнил δ_min с ТОЧЕЧНОЙ оценкой, а в ветке стоит
CI_upper = point + 1.96·SE**. Перепроверил арифметику независимо
(скрипт-проверка, 17.11):

- SE = 0.029/√32 = 0.00513.
- При δ_min = 0.010 = 1.96·SE: P(CI_upper < δ_min | H₀) =
  Φ((δ_min − 1.96·SE)/SE) = Φ(0) = **0.496** на клетку → P(все 10) =
  **9.0e-4** (один эстиманд); с двумя ко-первичными (независимые) —
  8.1e-7. Ветка мёртва — ровно тот дефект, который B3 должен был закрыть.
  (Φ(1.96) = 0.977 — это P(point < δ_min), я его и записал.)
- При δ_min = 0.020 = 3.92·SE: P(cell) = Φ(1.96) = **0.974** → P(все 10) =
  **0.767** (один); с двумя независимыми — 0.589; с корреляцией — между,
  что совпадает с оценкой ревью 0.60–0.78.

**Принятый фикс (r5 §5):** δ_min = **0.020** (3.92·SE), формула
достижимости переписана явно через (δ_min − 1.96·SE)/SE с историей ошибки.
Интерпретация зафиксирована в TZ: REFUTED = «эффект меньше δ_min — на
границе разрешения детектируемости (0.01–0.015 из P0.5)»; осознанный
компромисс для закрытия T2 как не подтверждённой. δ_min не пересматривается
post-hoc; фактическая SE отчитывается прогоном.
