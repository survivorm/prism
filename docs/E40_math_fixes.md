## §1. Блокирующие правки (применить до коммита)

### §1.1. `b_res = O(ε³)`, не `O(ε⁴)`

**Где:** §I.7 ТЗ (раздел про кинетику / `behavior.py`); §I.5 (тройка, если `b_res` упоминается); пререгистрация E-44.

**Что заменить:**

```diff
- b_res = O(ε⁴)  — остаток второго порядка после линейного предиктора
+ b_res = O(ε³)  — остаток: ε²σ₁² + ε³⟨Jv, H[v,v]⟩ + O(ε⁴); первый остаток — 
+ линейно-квадратичная связка ε³⟨Jv, H[v,v]⟩, не ε⁴
```

**Обоснование.** Разложение: `Δz = εJv + (ε²/2)H[v,v] + O(ε³)`, откуда `‖Δz‖² = ε²‖Jv‖² + ε³⟨Jv, H[v,v]⟩ + (ε⁴/4)‖H[v,v]‖² + O(ε⁵)`. При `b_mag = ‖Δz‖²` и `b_lin = ε²‖Jv‖²`: `b_res = ε³⟨Jv, H[v,v]⟩ + O(ε⁴)`. Порядок `O(ε⁴)` был бы верен только при `⟨Jv, H[v,v]⟩ = 0` — проверяемое условие, не тождество.

**Следствия (обязательные):**

1. **Тест редукционного контроля:** `b_res / (ε²σ₁²) → 0` при `ε → 0` (т.е. `o(ε²)`). Не проверять как `O(ε⁴)` — иначе честный `ε³`-член будет прочитан как баг редукции.
2. **Новое обязательное поле артефакта E-44:** `lq_coupling := ⟨Jv, H[v,v]⟩` — линейно-квадратичная связка, signed. Это самостоятельный измеримый объект, не «шум».
3. **В пререгистрации E-44:** явно `expected scaling of b_res — O(ε³)`.

### §1.2. `λ_max ≤ p_max`, не `p_max(1−p_max)`

**Где:** §I.1 ТЗ (алгебра `P(p)`, граница `λ_max`); §2.5.2 статьи (если номер — см. §3.2 перенумерации в предыдущем ТЗ).

**Что заменить:**

```diff
- λ_max(P) ≤ p_max(1 − p_max); в двухточечном пределе λ_max = 2p_max(1 − p_max)
+ λ_max(P) ≤ p_max — безусловная граница (из порядка Лёвнера P ⪯ diag(p), 
+ поскольку ppᵀ ⪰ 0, и λ_max(diag(p)) = p_max)
+ 
+ Для K = 2: λ_max = 2q(1−q) (точное значение; ≤ p_max при q ∈ [0,1])
+ Для K ≥ 3: точное значение — корень секулярного уравнения Σᵢ pᵢ²/(pᵢ − λ) = 1;
+            граница p_max достижима при p = uniform (λ_max = 1/K)
```

**Обоснование.** Контрпримеры:
- `K = 2`, `p = (0.9, 0.1)`: `λ_max = 2·0.9·0.1 = 0.18 > p_max(1−p_max) = 0.09`;
- `K = 128`, остро-фокусированный `p = softmax(randn·3)`: `λ_max ≈ 0.1366 > p_max(1−p_max) ≈ 0.1229`.

`P ⪯ diag(p)` — порядок Лёвнера (поскольку `ppᵀ ⪰ 0`); `λ_max(diag(p)) = p_max`. Отсюда `λ_max(P) ≤ p_max`. Граница оптимальна: при `p = uniform` `λ_max = 1/K = p_max`.

**Следствия:**
1. Заменить `λ_max ≤ p_max(1−p_max)` на `λ_max ≤ p_max` в `prism/p_algebra.py::secular_roots` (комментарий) и в тесте `test_lambda_max_bound`.
2. Если где-то в коде используется `p_max(1−p_max)` как порог — заменить на `p_max`.

### §1.3. `P² ≠ P` — только для interior `p`

**Где:** §I.1 ТЗ (`P` не проектор); тест `test_not_projector`.

**Что заменить:**

```diff
- P² ≠ P ни при каком p (даже при p = uniform: P² = (1/K)P)
+ P² ≠ P для всех p, кроме вершин симплекса p = e_i, где P = 0 
+ (тривиально идемпотентна).
+ 
+ Точнее:
+ - interior p (все pᵢ > 0), p ≠ uniform: P² ≠ P
+ - p = uniform: P² = (1/K)P ≠ P при K > 1
+ - p = e_i (вершина): P = 0, P² = 0 = P (тривиально идемпотентна)
```

**Обоснование.** При `p = e_i`: `P = diag(e_i) − e_i e_iᵀ = 0`, и `P² = 0 = P`. Нулевая матрица идемпотентна по определению. Утверждение «ни при каком `p`» было ложным; при этом содержательный смысл («`P` не проектор в нетривиальных случаях») сохраняется.

**Следствие для теста** `test_not_projector`:
- проверять `P² ≠ P` на interior + uniform;
- **не** проверять на вершине (или проверять как `P == 0`, что тривиально).

### §1.7. Кинетика: `E_off_manifold` — шестой канал, `Σ5 = ‖ΔJ_proj‖²`, не `‖ΔJ‖²`

**Где:** §I.7 ТЗ; §II.6 (`kinetic.py`); §IV тесты.

**Что заменить:**

**(а) §I.7** — определение шестого канала и полная accounting:

```
E_radial     = ‖ΔΣ‖²
E_right      = ‖Σ̄ N‖²
E_left       = ‖M Σ̄‖²
E_cross      = 2 tr(Σ̄ M Σ̄ N)          (signed)
E_resid      = ‖U_tᵀ ΔJ V_t − ΔJ_lin‖²  (независимо, не через conservation)
E_off_manifold = ‖ΔJ − U_t U_tᵀ ΔJ V_t V_tᵀ‖²  (независимо)

Полное тождество:
    ‖ΔJ‖² = Σ5 + E_off_manifold + eps3_correction + O(ε⁴)

где:
- Σ5 = E_radial + E_right + E_left + E_cross + E_resid  →  замыкает ‖ΔJ_proj‖²
- E_off_manifold  →  замыкает ‖ΔJ − ΔJ_proj‖²
- eps3_correction  →  диагностика линеаризации O(ε³), НЕ канал
```

**Критично:** `Σ5 = ‖ΔJ_proj‖²`, **а не `‖ΔJ‖²`**. При `r = 16 ≪ D = 1024` и `Δ_SVD ≈ π/2` (L6–L22) `E_off_manifold ≈ ‖ΔJ‖²/2` — это **ожидаемый результат**, не провал E-40.5. Полное замыкание `‖ΔJ‖²` даёт **сумма всех шести + eps3**.

## §6. Что три ошибки означали по существу

Три ошибки в математической части ТЗ — **три разных класса**, не один:

1. **`b_res = O(ε⁴)`** — ошибка **порядка** (кубический член невидим за «естественной» квадратичной формой). Исправление: явный порядок + новое поле `lq_coupling`.

2. **`λ_max ≤ p_max(1−p_max)`** — ошибка **границы** (была верна в двухточечном пределе, но не в общем). Исправление: порядок Лёвнера `P ⪯ diag(p)` даёт более сильную границу `≤ p_max`.

3. **`P² ≠ P` «ни при каком `p`»** — ошибка **квантора** (утверждение с «ни при каком» не выполняется на вершине). Исправление: ослабление до «для interior + uniform».

Все три — типичные ошибки при работе с алгеброй `P(p)`, где двухточечный предел (`K = 2`) и граница дают **интуицию, которая не переносится** на общий случай. Урок для будущих правок: любая граница `λ_max` или утверждение «для всех `p`» — проверять на `K = 2`, `p = uniform`, `p = e_i` и **на `K ≥ 3`** с численной проверкой через `secular_roots`.
