## 5. L17 (N3: локальное условие)

- Условие **финальной политики** (r2): Δ = +0.0412, CI [+0.0355, +0.0717]
  (не изменилось).
- Новое условие — **L17-local readout** `(h_L17/rms)·w·Eᵀ`: Δ = **+0.0001,
  CI [−0.0266, +0.0136] (∋ 0)**, n_docs 14. Локальная уверенность L17 не
  связана с dip L17.
- corr(L17-local, final) = **−0.051** — локальная и финальная маржи практически
  не связаны.

Честная формулировка (формулировка ревью): **«dip L17 анти-коррелирует с
margin финальной политики, противоположно по знаку dip L23; это не
layer-local boundary-механизм»**. Наблюдение — cross-layer связь геометрии
среды стека с уверенностью финального решения (стрелка не установлена, возможен
конфаунд структуры контента) — материал для отдельного пре-рега, не вердикт
T3.1 (у L17 по пре-регу вердиктов нет).

## 6. Чтение F7-асимметрии (ревью §4, в отчёт как результат)

> На генерации эффект привязан к марже **прихода** (mg[j]), не к марже решения
> (mg[j+1]). При corr(mg[j], mg[j+1]) = 0.72 это позиционный дискриминатор:
> dip трекает уверенность конкретного только что сделанного шага, а не
> «уровень уверенности» как таковой. Чтение: **коррекция после неуверенного
> шага** (T1-флэвор: обратная связь по ошибке), а не «отражение у границы
> перед решением» (T3). На чтении (TF) эффекта нет ни в одном условии
> (corr 0.05, оба Δ плоские).

Оговорки (не убраны): (1) корреляция — причинная стрелка не установлена
(неуверенный шаг может быть следствием поворота, а не причиной); (2) конфаунд
сложности контента: трудный контент даёт и низкий margin, и большой поворот
(третья переменная).

## 7. Итог (по пре-регу r3)

**Вердикты T3.1 (r3): TF = (b) b_non_boundary/weak, генерация = (b)
b_non_boundary/insufficient_power — без изменений к r2.**

1. Направление boundary на генерации установлено (sign 12/14, p = 0.0129, CI
   медианы целиком < 0, |Δ| = 2× порога); точности величины не хватает
   (0.005 до (a); ~25 доков).
2. Эффект позиционный: на марже прихода (N7: при сильной serial-корреляции 0.72
   dip всё равно выбирает mg[j], а не mg[j+1]) — чтение «коррекция после
   неуверенного шага» (T1-флэвор), не «отражение у границы».
3. L17: не локальный механизм (N3: local Δ ≈ 0, CI∋0, corr local/final −0.05);
   связь — с margin финальной политики (cross-layer, описательно).
4. TF: плоско во всех условиях (margin, p1, shift, local-неприменимо) — при
   низкорешиционном fp16-margin (окно: convention_spread 2.70, noise-перенос
   2.84; ‖h‖ gen 10.0 / tf 12.0).
5. Селекционные каналы закрыты: ok-rate 1.0 по бинам (N6), dropped 0 (N8),
   min-n робастен 13–14 доков (N1), p1-оси неразрешимы (N2) — primary-
   статистика на всём множестве пар.
