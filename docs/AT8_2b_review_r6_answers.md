## 1. Закрытое (12 пунктов r5) и reconcile «7 SE» — подтверждено.

## 2. F1 (гейт падал всегда) — **принято полностью, верифицировано по коду R2.**

Проверено: `AT8_2_R2.py:264,277-279` — `cond_series` пишет `ce`,
`cos_raw`, `cos_state`, `norm_delta` через `round(float(x), 6)`;
`:240` — `use_cache=False`; `:239` — `torch.no_grad()`; `:707` —
`torch.set_grad_enabled(False)`. Замечание точное: при |cos_raw|~1e-3
округление само даёт до 5e-4 относительных — старый гейт (bit-identity
raw или rel < 1e-6) падал всегда и звал fallback на пустом месте.

Реализовано дословно по фиксу: свежий ряд — **тот же `cond_series`,
что R2 (verbatim, round 6)**; гейт = **bit-identity округлённых
значений**; rel 1e-6 — только диагностика с абсолютным полом 5e-7.
Дополнительно запинено:
- **домен сравнения**: весь сохранённый ряд (все позиции p = 0..T'−2,
  5 слоёв, cos_raw + cos_state + norm_delta) — не только post-окно;
- **`use_cache=False` + `torch.set_grad_enabled(False)`** — в пин-лист
  §10.1 с указателями на строки кода R2 (детерминант GDN-пути, как
  отметил ревью).
Примечание для кодера: cos_raw считается в R2 в float32 (np-массивы
float32), округление — после; свежий форвард обязан держать fp32
hidden states (запинено `dtype = float32`).

## 5. F4 (CALIBRATION_WARN конфаунд) — **принято, с уточнением якоря.**

Класс точно тот же, что N_content в r2 (диагностика загрязнена

## 6. F5 (10⁻¹² не тому объекту) — **принято; таблица ревью верна для нашего правила.**

Проверка: пре-рег-правило 2b — `S_phr := CI_low(near) > δ_PHR`,
`S_rep := CI_low(near) > δ_REP` (нижняя граница, TZ §11) ⇒ порог
срабатывания в нормальной аппроксимации = δ + 1.96·SE. Тогда таблица
ревью сходится (пересчитано: SE = 1.22·0.246/√14 = 0.0802):
type-I per-dose z = (1.316−0.7538)/0.0802 = 7.01 → 1.2·10⁻¹²; pooled
z = 11.1 → 4·10⁻²⁹; power(0.8681): 5.59 → 1.4·10⁻⁸ / 9.71 → 10⁻²².
Мой 10⁻¹² в v1.5 — это и была type-I per-dose ревью, перенесённая с
меткой «эффект масштаба e_spec» (m4/G14, применённый к моему же
тексту — справедливо). В TZ v1.6: таблица 4 клеток с верными метками,
честный хвост (n=14: нормальное приближение в хвосте не
идентифицируемо — «рабочий type-I ≪ 0.025, точное значение не
оценивается»), α = 0.025 — верхняя граница.
