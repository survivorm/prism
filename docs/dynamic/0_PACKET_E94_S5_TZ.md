# TZ E94/S5 — строгая реконструкция эмиссента из logprobs + DRY (0 GPU)

## 0. Статус и бюджет
CPU-only перечёт существующих артефактов. GPU не занимает, память < 1 ГБ.
Никаких новых запросов к серверу. Вход — только `results/e94/raw_q1.json.tar.gz`

## 1. Вопрос
Ночью установлены два «главных» контраста: `g12 < 0.7` (OR 85, p=1.6e-14) и
«0 флипов из 5534 уверенных» (p=7.5e-17), где *флип* = эмиссент != вершина отчёта.
После S4c/S4d/S4e обнаружилось, что канон запроса включает DRY со штрафом ровно
1.0 логит-юнит (`dry_multiplier 1.0, dry_base 1.0, dry_allowed_length 2,
dry_penalty_last_n 64` — сервер сам это эхом вернул в `generation_settings`).
Рабочая гипотеза H0: **DRY-штраф объясняет эмиссент на каждой позиции, флипы —
артефакт сэмплера, а не свойство модели.** Ночные контрасты тогда переписываются
как «порог штрафа», а p-числа измеряют наше знание о сэмплере.

## 2. Что считается (единственный источник кода — сам код, не память о нём)
Перенос `llama_sampler_dry_apply` из `/home/survivor/work/llama.cpp/src/llama-sampler.cpp`
(строки сверены 12.11, `git log -1` = `0b8cfb8fe`):
* окно = последние `min(|last_tokens|, dry_penalty_last_n=64)` принятых токенов;
  `ring_buffer::rat(i)` = **i-й от нового** (`:95`, `data[(first+sz-i-1)%cap]`);
* шаг 1 `:3424-3456`: `rep_limit` по sequence breakers. Для односимвольных
  breakers (`"\n" ":" "\"" "*"`) `get_overlapping_token_sequences:3330-3335`
  помечает head-ом **каждый** токен, чей детокенизированный текст *содержит*
  символ, с пустым хвостом ⇒ `longest_match = 0`, `rep_limit = i` (дистанция от
  нового токена до первого breaker-токена), и цикл встаёт на первом таком;
* `if (rep_limit < dry_allowed_length) return;` ⇒ у breaker'а штраф вообще нет;
* шаг 2 Z-алгорит `:3486-3527` (в обратном индексировании,/port literatim/):
  `repeat_count[last-k] = min(LCP, rep_limit)`, `last = last_n_repeat-1`;
  по-человечески: `repeat_count[j]` = длина совпадения блока, **кончающегося** на

* шаг 3 `:3545-3556`: при `repeat_count[i] >= allowed` штрафуется

* шаг 4 `:3565-3586`: штраф `multiplier * base**(len-allowed)`; при `base=1.0`
  это **ровно 1.0** для любого штрафного; односимвольные breaker-токены штрафа

Валидация переноса (не «на глаз»): unit-тест на доковом примере самого файла
(`:3475-3479`): окно `a b c c b c y a b c` ⇒ `repeat_count =

## 3. Данные и обработка
* `request.prompt` = список id промпта (64 id), эмиссенты = `response.tokens`,
  на каждом шаге `completion_probabilities[t]` = `{id, logprob, top_logprobs[20]}`.
  Окно на шаге t = `prompt + tokens[:t]` (accept происходит после сэмплинга).
* Только `_r1` — главный контингент ночи (16 документов × 384 = 6144 позиции,
  seed 8181). `_r2` считается **отдельно** и не смешивается (тот же seed, это
  технический повтор, независимая выборка отсутствует).
* Логпробы — log-softmax, разность логпробов = разность логитов, поэтому
  `argmax(logprob − penalty)` законно на любом подмножестве.
* Кандидаты `C` = `top_logprobs[20]` ∪ {эмиссент}. Так как штраф только
  вычитает, любой токен вне `C` имеет `logprob <= lp20`; если лучший `adjusted`
  в `C` не ниже `lp20`, токен вне `C` победить не может — иначе позиция уходит в
  `INCONCLUSIVE`, а не в `EXPLAINED`.

## 4. Предрегистр: корзины и правила вердикта
На каждой позиции:
* `EXPLAINED` — `argmax_{C}(adjusted) == emitted` и `max(adjusted) >= lp20`;
* `INCONCLUSIVE` — `max(adjusted) < lp20` (хвост vocab не виден);
* `UNEXPLAINED` — `argmax_{C}(adjusted) != emitted`;
* `TIE` — точное равенство adjusted у двух и более (считается, не «сглаживается»).

Контроль (обязателен, это тот же прогон с `penalty := 0`): реконструкция без DRY
обязана воспроизвести `emitted` ровно там, где эмиссент = вершина отчёта, и
ошибиться ровно на флипах. Ожидаем: совпадений = 6144 − (число флипов), ошибок =
число флипов. Если контроль ошибается не на флипах — сломан перенос/данные, а не
гипотеза, и H0 не проверялась.

Правила вердикта (до запуска):
1. **H0 подтверждена**, если `UNEXPLAINED == 0`, `TIE == 0`, `INCONCLUSIVE <= 1%`
   и контроль воспроизводит ровно флип-набор. Тогда флипы = следствие DRY, ночные
   контрасты `g12<0.7` и «0/5534» понижаются до описания порога сэмплера, а вывод
   «детерминированность ⇒ систематический дефект индекс/привязка» отзывается
   (штраф детерминирован по построению).
2. **H0 опровергнута**, если `UNEXPLAINED >= 1` — тогда обязательно пофлиповая
   раскладка: сколько из 16 объяснены, чем именно не объяснены.
3. Промежуток (`UNEXPLAINED == 0`, но `INCONCLUSIVE > 1%`) — не вердикт, доделывать.
4. Effect-size гейт: утверждать «DRY объясняет флипы» можно только при объяснённых
   >= 15 из 16 флипов **и** `UNEXPLAINED == 0` по всему контингенту. Половинчатых
   формулировок не будет.

Побочно (без нового вердикта): распределение `g12` на парах «штрафный vs
нештрафный» даёт количественное предсказание порога = 1.0 нат; сверим с эмпирикой
ночи (0.7) и с максимом разрыва на флипах.

## 5. Чего этот тест НЕ касается
Он не проверяет логитные метрики, посчитанные из отчёта до сэмплера (`g12`,
Δ-vs-null, teacher forcing) — они DRY не тронуты уже по тому, что отчёт снимается
раньше сэмплера. Он проверяет только эмиссент-зависимые утверждения. Разделение
«что тронуто, а что нет» — часть результата.
