## Мажорные

### F1 — LEARN_ASYMM на n=16, читается для E_phr@n2 — **принято**

Подтверждено по тексту: §9 — `block-CE_L2(16)/block-CE_L1(16)`, §17 —
оговорка к E_phr. Ровно M3 в другом месте. Проверена и «мёртвость»
порога: пререг-ожидание ratio_16 ∈ [0.3/0.51, 1.0/0.38] = [0.59, 2.63]
— порог 3× действительно недостижим по ожиданию. Фикс: ratio на обеих
первичных дозах, непрерывно в claim; `LEARN_ASYMM_N2` (некалиброванная
эвристика — 3× калиброван на n=16, на n=2 фразы не выучены и
конфаунд именно там) и `LEARN_ASYMM_N16` (калиброванный порог).
E_phr — по своему тегу, REP-контекст — по своему.

### F2 — дозовый тег: формула R2 требует 4 дозы, доступно 2 — **принято**

Подтверждено: правило R2 §9 (`FLAT: I16/I2 ≤ 2; SATURATING: I16/I2 > 2
И I16/I8 ≤ 2; MONOTONIC: I16/I8 > 2 И строго растёт`) при дозах {2,16}
даёт либо вечный `DOSE_NOT_RESOLVED` (None в vals), либо IndexError
(`vals[3]`) — оба исхода проверены мысленно по тексту; `DOSE_SATURATING`
недостижим. Семантика 2-дозного правила сверена с R2-числами: I16/I2 ≤ 2
= насытилось на [2,16] (= `DOSE_FLAT` R2 при I16/I2 = 1.09); I16/I2 > 2
= ещё растёт (= `DOSE_MONOTONIC`; «насыщается посередине» с двумя
дозами неразличимо — поэтому SATURATING удалён, а не подвешен).
Ссылка «как R2 §9» убрана.
**Пометка по формулировке:** их вариант «I16/I2 > 2 И I16 > I2» —
второе клише избыточно (CE > 0 ⇒ I16 > I2 при ratio > 2); правило
записано без него (мёртвое условие в пре-реге — п.9 AGENTS).

## Умеренные

### F4 — «draw-робастность» не переносится на |·| — **принято**

Контрпример верен: m_L=10, m_S=0, m_S'=0 → REP = 10, N_perm = 0 →
fires; отрицательная знаковая ковариация тут не действует —
статистика `p90|·|`. Утверждение убрано из всех четырёх мест (§2,
§7.2 — код и буллет, шапка, §19); на его месте — факт (знаковая
ковариация < 0) + явная квалификация: защита — p95-маржин и
измеренное σ_L/σ_S (m3, ×1.22 norm_delta@n2).

### F5 — INT-тег: порог не калиброван под INT — **принято**

Алгебра проверена: Var(INT) = (σ_L²+σ_S²)/2 ≈ σ² при σ_L=σ_S,
Var(N_PHR) = 2σ², Var(N_perm) = σ² → INT по структуре сматчен с
N_perm, порог δ_PHR на √2 ≈ 1.41× шире по дисперсии. Тег объявлен
**эвристикой без калибровки** (калиброванного нуля нет: лупы
детерминированы — draw'а нет; вторая L-пара в бюджете не заявлена),
INT отчитывается непрерывно с CI всегда.
**Пометка по формулировке:** порог шире — тег **консервативен**
(type-I < 0.025, не «не контролируется» в смысле пере-срабатывания);
δ_PHR при этом на norm_delta — наблюдаемая INT, так что C1 здесь
не воспроизводится (ревью это тоже признаёт). Записано в §11.5 и §17
как «консервативно, но не тест с α=0.025».

### F6 — G_inside_rep гейтит E_phr на order-sensitivity — **принято**

Согласен с логикой: контентная премисса E_phr гарантирована
построением (непересекающиеся контент-токены), гейт — прокси
«строка представлена как периодическая фраза». Объявлено: (а) логика
провала (на n=2 — H_phr не тестируема на этой дозе; на n=16 — H_rep);
(б) пре-рег минимальной медианной маржи **≥ 0.3 nat на n=2** (оценка
маржи по числам ревью: L1(2) = 3.29, S1(2) ≈ 4 → ~0.7; порог 0.3 —
~2× запас под вариацию между доками). На n=16 — бинарный чек
(маржа ~2.1, запас велик).
