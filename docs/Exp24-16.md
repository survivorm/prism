## 0. Постановка задачи и исходные факты

### 0.1. Объект исследования

Для модели с скрытой размерностью \(D\) и слоем \(l\), для входа \(x\) (последовательность длины \(S\)):

\[
J_l(x) = \frac{\partial z}{\partial h^l}\Big|_{\mathcal U} \in \mathbb{R}^{K\times D},
\]

где \(z\) — логиты последней позиции, \(\mathcal U\) — фиксированный набор из \(K\) токенов. Вычисление — по процедуре `paper.md` §2.2 (префикс-кэш, прогон через оставшиеся слои, клонирование GDN-кэша).

**Мотивация.** \(J_l(x)\) — касательная в одной точке; локальность — известное ограничение метода (`paper.md` §6). Для агрегации по данным и построения лоссов дистилляции необходимо знать: (1) существует ли у поля \(x\mapsto J_l(x)\) внутренняя дискретная структура, (2) функциональна ли она, (3) можно ли на ней строить транспорт и регуляризацию. Настоящая серия отвечает на все три вопроса.

### 0.2. Установленные факты (Exp 0.1, выполнен; данные: `results/exp01_coherence.json`)

Модель 0.8B; слои \(\{6,12,18,22\}\); \(K=64\); \(S=64\); 8 сэмплов × 4 домена (wiki, math, code, chat). Измерены косинусы \(C = \langle J_i, J_j\rangle_F/(\|J_i\|_F\|J_j\|_F)\) для трёх типов пар:

| Тип пар | Определение | Результат |
|---|---|---|
| (a) внутри сэмпла | соседние позиции \((S{-}1,S)\), \((S{-}2,S{-}1)\) | \(C\) растёт с глубиной: 0.26 (L6) → 0.42 (L12) → 0.69 (L18) → 0.90 (L22), среднее по 64 парам |
| (b) внутри домена | разные сэмплы одного домена, последняя позиция | \(C \approx 0.005\text{–}0.30\), в основном \(0.01\text{–}0.15\) |
| Разномасштабность | \(\sigma_d / \text{median}\,\delta_a\), где \(\sigma_d\) — std скрытых состояний внутри домена, \(\delta_a=\|h_i-h_j\|\) | \(\approx 0.83\text{–}0.87\) на всех слоях |
| \(L_{p90}\) | 90-й перцентиль \(\|J_i-J_j\|_F/\|h_i-h_j\|\) для пар (a) | 2.47 (L6) → 2.04 (L12) → 0.46 (L18) → 0.21 (L22) |

**Выводы, фиксируемые как исходные:**

1. **Расслоение.** Поле гладко вдоль траектории одного сэмпла («лист») и квази-ортогонально между разными сэмплами, включая один домен: при одинаковом порядке \(\|\Delta h\)\) (отношение 0.83–0.87) косинусы различаются в 10–100×. Норма \(\|\Delta h\|\) не предсказывает близость \(J\).
2. **Фазовый переход L12→L18.** \(L_{p90}\) падает в 5–10×: поле становится «вязким» к выходу.
3. **Следствие для доменных агрегатов.** При \(C_b \approx 0.01\text{–}0.15\) усреднённые доменные грамианы \(G^d=\frac1N\sum J_iJ_i^T\) dominated отдельными сэмплами; их интерпретация как «свойства домена» требует отдельной проверки устойчивости.

## 1. Определения (общие для всей серии)

### 1.1. Узлы и данные

**Узел** — пара \((x, q)\): сэмпл \(x\) длины \(S=64\) и позиция \(q \in \{\text{last}, \text{mid}\}\), \(\text{mid}=S/2\). Якобиан узла вычисляется по префиксу \(x[:q]\) (каузальность: состояние до токена \(q\)).

**Выборка:** \(N_s=128\) англоязычных сэмплов: 28 × {wiki, math, code, chat} + 16 random-tokens. Итого \(N=256\) узлов. Длина фиксирована \(S=64\) (контроль длины). Мультиязычные данные в основной прогон не входят.

**Токенный набор:** глобальный топ-64 ученика по частоте в топ-\(K\) финальных логитов на калибровочном пуле (`paper.md` §4.2), отсортированные token id; **один и тот же набор для обеих моделей** (иначе кросс-модельные ядра не определены).

### 1.2. Gauge-free якобиан

\[
P(p) = \operatorname{diag}(p) - pp^T, \qquad J^{(p)} = P(p)\,J,
\]

где \(p\) — распределение на \(\mathcal U\), перенормированное на \(\mathcal U\). Свойства: \(P(p)\mathbf 1 = 0\) (убирает uniform shift логитов); \(P(p)\) симметрична, но **не идемпотентна** — применяется ровно один раз; повторное проектирование запрещено.

**Конвенции проектора:**
- **self-\(p\)** — \(p\) самого узла; используется для всех внутри-модельных кластеризаций.
- **учитель-\(p\)** — \(P(\bar p_L)\), где \(\bar p_L\) — среднее по домену распределение учителя; используется только для кросс-модельного сравнения ядер. Разность уверенностей моделей при этом уходит в скалярный канал атрибуции, а не в геометрию.

### 1.3. Ядра сходства (на модель × слой × конвенцию)

Для узлов \(i,j\), \(J_i \in \mathbb{R}^{K\times D}\):

\[
K^F_{ij} = \frac{\langle J_i, J_j\rangle_F}{\|J_i\|_F\|J_j\|_F}
\qquad\text{(референс, смесь формы и ориентации)}
\]

\[
G_i = J_i J_i^T \in \mathbb{R}^{K\times K}, \qquad
K^G_{ij} = \frac{\langle G_i, G_j\rangle_F}{\|G_i\|_F\|G_j\|_F}
\qquad\text{(рабочий канал)}
\]

\[
V_i = \text{топ-}r \text{ правых сингулярных векторов } J_i,\ r=8, \qquad
K^V_{ij} = \frac{\|V_i^T V_j\|_F^2}{r}
\qquad\text{(только отчёт)}
\]

**Инвариантность (обоснование статусов).** При замене координат скрытого пространства \(J \mapsto JR\), \(R\) ортогональна:

\[
G \mapsto JR R^T J^T = G \quad\Rightarrow\quad K^G \text{ инвариантно};
\]
\[
V \mapsto R^T V \quad\Rightarrow\quad K^V \text{ не инвариантно}.
\]

Поэтому \(K^G\) несёт функциональную форму чувствительности в общем словаре, а \(K^V\) — ориентацию в конкретном обученном базисе \(h\), которая может быть артефактом представления. **Статус \(K^V\):** только числовые значения в отчёте; любая прикладная интерпретация (включая «диагностику транспорта») запрещена до прохождения Exp 24b.

Масштаб \(\|J_i\|_F^2\) нормировкой исключён из всех ядер и учитывается отдельно как скалярный признак атрибуции.

### 1.4. Кластеризация

**Граф:** kNN, \(k_{nn}=15\), по первичному ядру; вес ребра \(w_{ij} = \max(K_{ij}, 0)\) (отрицательные косинусы не несут информации о сходстве и клипятся в 0).

**Правило выбора \(k\) (предрегистрация, выводы только по primary):**

| Роль | Метод |
|---|---|
| **primary** | Leiden (RBConfigurationVertexPartition), resolution \(=1.0\), seed \(=42\) |
| robustness | спектральный: \(k = \arg\max_k (\lambda_k - \lambda_{k+1})\) при \(\lambda_k \ge 0.05\,\lambda_1\) (собственные значения нормализованного лапласиана графа); если такого \(k\) нет — фиксируется \(k=1\) |
| референс | \(k=5\), k-means на топ-16 спектральном эмбеддинге |

**Вырожденность.** Если primary даёт \(k=1\) или \(k > N/4\): результат документируется как «вырожденное разбиение», гейт (§1.6) и \(\tau\) (§1.7) не применяются. Дополнительно в отчёт всегда входит распределение размеров кластеров (мин/медиана/макс доля).

### 1.5. Разбиения и сравнения

- **Разбиение** \(\pi\) — вектор меток узлов; для узла \((x,q)\) запись \(\pi(x,q)\).
- **ARI** — Adjusted Rand Index (стандартное определение; инвариантен к перестановке меток).
- **Условная энтропия разбиений** \(H(\pi_a \mid \pi_b)\) — стандартная, по совместному распределению меток на общих узлах.

### 1.6. Нуль-модели и гейт структуры

Три нуля с фиксированными ролями:

| Нуль | Конструкция | Роль |
|---|---|---|
| Гауссов | диагональ \(=1\); внедиагональ iid \(\mathcal N(0,\sigma^2)\), \(\sigma = \mathrm{std}\) внедиагонали реального \(K^G\); клип в \([-1,1]\) | нижний пол (референс) |
| **Перестановочный** | диагональ \(=1\); внедиагональные значения реального \(K^G\) случайно перераспределяются между неупорядоченными парами с симметризацией | **верхний пол; база гейта**. Сохраняет эмпирическое распределение шумовых величин, разрушает любую блочную структуру |
| Перестановка меток | реальное \(K^G\) без изменений; метки домен/позиция переставляются по узлам | нуль только для атрибуции (§1.8), не для гейта |

**Гейт структуры** (вычисляется на каждое ядро × слой × модель; все величины из одного прогона; 50 реплик перестановочного нуля; 100 бутстрепов по сэмплам из кэша):

\[
\boxed{
\text{ARI}_{\text{half}} - \overline{\text{ARI}}_{\text{perm}} \ge 0.15
\quad\wedge\quad
\mathrm{CI}^{95}_{\text{boot}}(\text{ARI}_{\text{half}})_{\text{low}} > \overline{\text{ARI}}_{\text{perm}} + 0.05
}
\]

при условии невырожденности (§1.4).

**Полу-сплит.** Множество сэмплов делится пополам; в каждую половину узлы входят **обеими позициями** своих сэмплов (предотвращение утечки между позициями одного сэмпла). Каждая половина кластеризуется отдельно; считается ARI между двумя векторами меток на общих… — корректно: сравнение идёт через ограничение на пересечение не требуется, половины независимы; для сравнения кластеризации двух половин на одних и тех же узлах используется схема: кластеризация половины A, кластеризация половины B, ARI считается после ограничения обеих на свои узлы через согласование по общим сэмплированным узлам бутстрепа. Бутстреп: ресэмплинг **сэмплов** с возвращением (обе позиции едут вместе), пересборка ядер и кластеризация по кэшу (без повторных forward).

### 1.7. Индекс тривиальности и позиция

**Тривиальность.** \(\pi_{H_q}\) — разбиение узлов на 4 квартиля по энтропии \(H(p_i) = -\sum_t p_i(t)\log p_i(t)\).

\[
\tau = \mathrm{ARI}(\pi_{\text{primary}},\, \pi_{H_q})
\]

считается **только на primary**; при вырожденном primary — `n/a`. Интерпретация: \(\tau > 0.7\) — структура есть, но совпадает с энтропийной осью; \(\tau < 0.3\) — нетривиальна; между — смешанная.

**Позиция против листа.**

\[
\rho_{\text{pos}} = \frac{1}{N_s}\sum_{i=1}^{N_s} \mathbb 1\big[\pi(x_i,\text{last}) = \pi(x_i,\text{mid})\big],
\qquad
\rho_{\text{null}} = \sum_c \left(\frac{n_c}{N}\right)^2
\]

(\(\rho_{\text{null}}\) — ожидание при случайном назначении с фактическими размерами кластеров). Интерпретация отношения \(\rho_{\text{pos}}/\rho_{\text{null}}\):
- \(\approx 1\): лист = позиция (или мельче);
- значимо \(>1\), но \(< 1/\rho_{\text{null}}\)-предела: лист тоньше сэмпла, но не позиция;
- \(\rho_{\text{pos}} \to 1\) при отношении \(\gg 1\): лист = сэмпл.

### 1.8. Атрибуция (линейные зонды)

Признаки узла (только инференс-доступные): \(H(p)\), std логитов, позиция {last, mid}, \(\|h\|\), класс следующего токена (пунктуация / служебный / контент — по фиксированному списку), внешний домен, \(\log\|J\|_F^2\), gauge share (доля энергии \(J\) в направлении, максимизирующем \(|\cos(u,\mathbf 1)|\) среди левых сингулярных векторов, `paper.md` §2.3).

Зонд: мультиномиальная логистическая регрессия «метка листа ← признаки»; 5-фолдовый CV с группировкой по сэмплам; метрика — macro-F1 против (а) majority-базлайна и (б) базлайна «только \(H(p)\)».

### 1.9. Кросс-слойные и кросс-модельные сравнения

**Кросс-слой.** Для соседних слоёв на одних узлах: \(\mathrm{ARI}(\pi_l, \pi_{l'})\), \(H(\pi_l \mid \pi_{l'})\), \(H(\pi_{l'} \mid \pi_l)\). Направление: \(H(\pi_l\mid\pi_{l'}) \ll H(\pi_{l'}\mid\pi_l)\) — слой \(l'\) укрупняет (merge) разбиение \(l\); наоборот — уточняет (refine).

**Кросс-модель (учитель L / ученик S), одни и те же узлы:**

- первично: нормализованный HSIC и кофенетическая корреляция (корреляция Пирсона внедиагональных элементов) между \(K^G_L\) и \(K^G_S\) в конвенции учитель-\(p\);
- вторично, только если гейт пройден у обеих моделей: \(\mathrm{ARI}(\pi_L,\pi_S)\) и связность \(B_{ab}\) ниже.

**Связность листов.** \(C \in \mathbb N^{k_L\times k_S}\) — contingency-матрица (узел в листе \(a\) учителя и листе \(b\) ученика). Нормализованная Sinkhorn-проекция (\(\varepsilon=0.05\), 200 итераций):

\[
T = \mathrm{Sinkhorn}\big(\exp(C / (\varepsilon \cdot \max C))\big), \qquad \sum_{ab} T_{ab} = 1
\]

**Пороги merge/split (предрегистрация).** Пусть \(r_a = T_{a\cdot}/\sum_b T_{ab}\), \(c_b = T_{\cdot b}/\sum_a T_{ab}\):
- **merge:** строка \(a\) размазана, если \(\ge 2\) столбцов имеют \(r_{ab} > \max(0.1,\, 1/k_S)\);
- **split:** столбец \(b\) собирающий, если \(\ge 2\) строк имеют \(c_{ab} > \max(0.1,\, 1/k_L)\).

**Матрица \(B_{ab}\):** средний per-sample bridge (`paper.md` §1.7, пара слоёв 30→22) по узлам ячейки; публикуется только для ячеек со счётчиком \(\ge 5\).

## 2. Эксперименты

### Exp 24.0 — Мощность пайплайна кластеризации

**Назначение.** До запуска основного эксперимента измерить минимальный блочный сигнал, который пайплайн (§1.4–1.6) способен детектировать при \(N=256\) и реальном шумовом поле, и откалибровать порог 0.15. Без этого «структура не обнаружена» не отличимо от «пайплайн не видит».

**Обоснование и математика.** Гауссов шум недостаточен как база: реальный шум \(K^G\) структурен (слабые доменные блоки по `paper.md` Exp 13, энтропийная ось по `paper.md` Exp 10d), поэтому planted-сигнал накладывается на **перестановочный нуль реального ядра** (§1.6):

1. Пилотный кэш: 32 сэмпла × 2 позиции = 64 узла, 0.8B, слои \(\{6, 22\}\) → реальное \(K^G\).
2. \(K^{\text{perm}}\) — перестановочный нуль этого \(K^G\).
3. Planted-модель с истинным разбиением \(\ell \sim \mathrm{Uniform}(1..k_{\text{true}})\):

\[
K_{ij} = \min\big(K^{\text{perm}}_{ij} + s\cdot \mathbb 1[\ell_i=\ell_j],\ 1\big), \quad i\neq j
\]

4. На каждой матрице — полный пайплайн (кластеризация → полу-сплит ARI → перестановочный нуль той же матрицы).
5. Мощность и порог:

\[
\mathrm{power}(s,k_{\text{true}}) = \frac{1}{50}\sum_{\text{seeds}} \mathbb 1[\text{гейт пройден}], \qquad
s_{\min}(k_{\text{true}}) = \min\{s:\ \mathrm{power} \ge 0.8\}
\]

**Граничные условия и параметры.**

| Параметр | Значение |
|---|---|
| \(N\) | 256 узлов (как в Exp 24) |
| \(k_{\text{true}}\) | \(\{2, 4, 8\}\) |
| \(s\) | \(\{0,\ 0.02,\ 0.05,\ 0.1,\ 0.2\}\) |
| Семян на клетку | 50 |
| Контроль ложных срабатываний | при \(s=0\) частота прохождения гейта \(\le 0.05\) |
| Правило \(k\), нули, гейт | точно как в §1.4–1.6 |

**Интерпретация.**

| Результат | Вывод | Действие |
|---|---|---|
| \(s_{\min}\) ниже наблюдаемого внедиагонального уровня реального \(K^G\) | Пайплайн чувствителен к реальному масштабу | Запуск Exp 24 |
| \(s_{\min}\) выше наблюдаемого уровня | Реальный сигнал заведомо недетектируем | «Структуры нет» — измеренный факт; Exp 24 сводится к констатации, дальнейшая ставка на пер-сэмпл методы |
| При \(s=0\) гейт проходится \(>5\%\) | Пайплайн находит кластеры в шуме | Порог 0.15 ужесточается до FPR \(\le 0.05\), фиксируется аддендумом |
| Порог 0.15 недостижим даже при \(s=0.2\) | Порог некалибруем | Пересмотр порога по кривой мощности до Exp 24, аддендум |

### Exp 24 — Сканирование листов (центральный)

**Назначение.** Ответ на Q2: существует ли устойчивая внутренняя дискретная структура поля \(J(x)\), не сводимая к энтропии, и как она соотносится у учителя и ученика.

**Обоснование и математика.** Если у модели есть внутренние режимы, ядро \(K^G\) (§1.3) имеет блочную структуру после некоторой перестановки узлов — задача community detection. Эксперимент строит \(K^G\) на 256 узлах, кластеризует по §1.4, проверяет устойчивость по §1.6 и атрибутирует по §1.8.

**Протокол.**

1. Полный кэш: 128 сэмплов × {last, mid} × слои \(\{6,12,18,22\}\) × модели {0.8B, 4B}. Объём: 2048 J-вызовов; кэш ~0.3 ГБ (0.8B) + ~0.7 ГБ (4B), float32.
2. Ядра \(K^F, K^G, K^V\) по §1.3 (кластеризация — только \(K^G\); \(K^F, K^V\) — отчёт).
3. Кластеризация по §1.4; гейт по §1.6; \(\tau\), \(\rho_{\text{pos}}\) по §1.7.
4. Атрибуция по §1.8.
5. Кросс-слой и кросс-модель по §1.9 (включая \(B_{ab}\) при пройденных гейтах).

**Граничные условия и параметры.**

| Параметр | Значение |
|---|---|
| Вырожденные разбиения | §1.4: \(k=1\) или \(k>64\) → «не обнаружено», гейт не применяется |
| Отрицательные \(K^G_{ij}\) | в графе — вес 0; в статистиках — как есть |
| Домен/позиция как вход кластеризации | запрещено; только атрибуты постфактум |
| Язык | только английский в основном прогоне |
| Кластеры в \(B_{ab}\) | только ячейки со счётчиком \(\ge 5\) |
| Предрегистрированные предсказания | **P1:** \(K^V\) почти диагонально (средняя внедиагональ \(<0.1\)) на всех слоях. **P2:** на L6–L12 гейт скорее не проходится (сигнал 0.005–0.03 против пола \(\sim 0.015 = 1/\sqrt{d_{\text{eff}}}\), \(d_{\text{eff}}\approx 4300\)); на L18–L22 возможен проход с малым \(k=1\text{–}3\) (по конвергенции подпространств `paper.md` Exp 13, overlap \(\to 1.0\) на поздних слоях). **P3:** кофенетическая корреляция \(K^G_L\) vs \(K^G_S\) максимальна на L22 |

**Интерпретация.**

| Результат | Вывод | Действие |
|---|---|---|
| Гейт пройден на \(K^G\), \(\tau < 0.3\) | Нетривиальные функциональные режимы | Разрешены Exp 25 и лист-контрастивный член в Exp 26 |
| Гейт пройден, \(\tau > 0.7\) | Структура = энтропийная ось | Спектральный роутинг не используется; вместо него энтропийно-условный транспорт/квантование |
| Гейт не пройден нигде | Грубой внутренней категоризации нет | Доменные средние закрыты; пер-сэмпл парадигма; \(B_{ab}\) не строится |
| \(\rho_{\text{pos}} \approx \rho_{\text{null}}\) | Лист = позиция или мельче | Гранулярность ниже сэмпла |
| \(\rho_{\text{pos}} \gg \rho_{\text{null}}\), \(\to 1\) | Лист = сэмпл | Конструкция редуцируется к пер-сэмпл; кластерный транспорт (Exp 25) не нужен |
| \(\rho_{\text{pos}}\) значимо между 0 и 1 при отношении \(\gg 1\) | Лист тоньше сэмпла | Основной интересный исход; сегментные листья |
| \(K^V\) блочно | Только гипотеза об ориентациях | Запуск Exp 24b; прикладные выводы запрещены |
| \(B_{ab}\): merge-строки локализованы на L6–L12 | Дистилляция теряет различения в средних слоях | Локализация цели для Exp 26; подтверждение потолка readout для ранних слоёв |

### Exp 24b — Функциональный тест блоков \(K^V\)

**Назначение.** Ответ на Q3: блоки в \(K^V\) — функциональные режимы или артефакт обученного базиса скрытого пространства. Условный: запускается только если \(K^V\) показал блоки, прошедшие гейт §1.6.

**Обоснование и математика.** \(K^V\) не инвариантно к базису \(h\) (§1.3), поэтому блоки в нём могут отражать ветвления представления, а не функции. Критерий функциональности: блоки предсказывают однородность функционального отклика на стандартизованную пертурбацию.

Для каждого узла \(i\):

1. \(v_d(x_i)\) — топ-правый сингулярный вектор \(J^{(p)}(x_i)\) (дифференциальное направление, конвенция `paper.md` Exp 12a), \(\|v_d\|=1\).
2. Пертурбация \(h_l \leftarrow h_l + \varepsilon v_d\), полный forward.
3. Функциональный отклик \(r_i = D_{\mathrm{KL}}\big(p_i^{\text{orig}} \,\|\, p_i^{\text{pert}}\big)\).

По разбиению \(\pi^V\) (кластеры \(K^V\)):

\[
F = \frac{SS_{\text{between}}(r)/(k-1)}{SS_{\text{within}}(r)/(N-k)}, \qquad
\eta^2 = \frac{SS_{\text{between}}}{SS_{\text{total}}}
\]

Нуль: те же \(r\) при 100 случайных перестановках меток узлов → распределение \(F_{\text{null}}\), p-value. Контроль: тот же тест на разбиении \(K^G\).

**Граничные условия и параметры.**

| Параметр | Значение |
|---|---|
| \(\varepsilon\) | \(\{0.05,\ 0.1\}\) — граница линейного режима (`paper.md` Exp 12a: при \(\varepsilon \le 0.1\) линейное приближение надёжно, при \(\varepsilon \ge 0.5\) доминируют нелинейности) |
| Минимальный размер кластера | \(n_c \ge 10\); меньшие исключаются из теста |
| Множественность | Бонферрони по 4 слоям × 2 моделям |
| Статус \(K^V\) до результата | Любая прикладная интерпретация запрещена |

**Интерпретация.**

| Результат | Вывод | Действие |
|---|---|---|
| \(F\) значим (\(p<0.05\) после поправки), \(\eta^2\) не ниже контрольного \(K^G\) | Блоки \(K^V\) функциональны | Повышение \(K^V\) до рабочего канала — только отдельным аддендумом |
| \(F\) не значим | Блоки — артефакт базиса | \(K^V\) окончательно снят; транспортные гипотезы проверяются только через Exp 25 |

### Exp 25 — Кластерно-условный транспорт

**Назначение.** Ответ на Q4: является ли найденная структура правильной единицей кондиционирования линейного транспорта (вместо глобального \(G_S^{-1}\), переобучающегося на калибровочные листья). Условный: гейт \(K^G\) пройден.

**Обоснование и математика.** Глобальный транспорт `paper.md` §1.4 — один линейный оператор на всё поле; при расслоении (§0.2) ориентации листьев разных сэмплов различны, и глобальный оператор переобучается на калибровочные ориентации. Если кластеры реальны, транспорт \(W_c\), обученный на половине кластера, переносится на вторую половину.

Для кластера \(c\) (разбиение учителя, перенесённое на узлы ученика), при замороженных транспорте \(\widehat{J}^{\,\text{tgt}}_i\) (§1.2 базовой модели) и проекторе \(\bar P = P(\bar p_L)\):

\[
W_c =
\Big(\textstyle\sum_{i\in c_{\text{train}}} J_i^T \bar P J_i + \lambda I\Big)^{-1}
\Big(\textstyle\sum_{i\in c_{\text{train}}} J_i^T \bar P\, \widehat{J}^{\,\text{tgt}}_i\Big)
\]

Полу-сплит: сэмплы кластера делятся на \(c_A, c_B\); fit на \(A\) → bridge на \(B\), и симметрично. Сравниваются:

\[
\mathcal{B}_{\text{global}} \quad vs \quad \mathcal{B}_{c} \quad vs \quad \mathcal{B}_{i}\ (\text{пер-сэмпл, верхняя граница})
\]

**Граничные условия и параметры.**

| Параметр | Значение |
|---|---|
| \(N_c\) | \(\ge 16\) сэмплов, иначе кластер пропускается с пометкой |
| \(\lambda\) | \(10^{-2}\cdot \frac{1}{N_c}\operatorname{tr}\big(\sum_{i\in c} J_i^T \bar P J_i\big)\) |
| Транспорт, \(E_S\), \(G_S^{-1}\) | Заморожены базовой модели |
| Критерий переноса | \(\mathcal{B}_c(c_B) \ge \mathcal{B}_{\text{global}}(c_B) + 0.03\) |
| Критерий стабильности | \(|\mathcal{B}_c(A{\to}B) - \mathcal{B}_c(B{\to}A)| \le 0.05\) |
| Численная устойчивость | Обусловленность матрицы системы логируется; при \(\kappa > 10^8\) — результат с пометкой |

**Интерпретация.**

| Результат | Вывод | Действие |
|---|---|---|
| \(W_c\) переносится и лучше глобального | Кластер — правильная единица транспорта | \(W_c\) используется в Exp 26 как инициализация/регуляризатор |
| \(W_c \approx W_{\text{global}}\) | Кластеры не несут транспортной информации | Транспорт остаётся глобальным; ценность структуры — только в лоссе |
| \(W_c\) не переносится внутри кластера | Кластер = сэмпл | Кластерный уровень закрыт; только глобальный или пер-сэмпл режим |
| \(W_c \approx \mathcal{B}_i\) | Кластер почти не усредняет | Сверить с \(\rho_{\text{pos}}\); вероятно пер-сэмпл природа |

### Exp 26 — Лист-контрастивный readout-pull

**Назначение.** Ответ на Q5: сохраняет ли структура-сохраняющий лосс перенос на необученные сэмплы там, где поточечный лосс `paper.md` Exp 16 деградирует. Условный: гейт \(K^G\) пройден на слое ученика пары 30→22 (слой 22) **и** закрыт Exp 0.3 (untied модель).

**Обоснование и математика.** Поточечный лосс тянет калибровочные листья и ломает остальные; дискретная форма «тянуть геометрию» — сохранение разбиения учителя: узлы одного листа учителя остаются близкими в \(K^G\) ученика, узлы разных листов не сливаются.

\[
\mathcal{L}(W) =
\lambda_p\,\frac{1}{N}\sum_i\big[1-\cos(J_S^{(p)}(x_i),\widehat{J}^{\,\text{tgt}}(x_i))\big]
+ \lambda_{\text{leaf}}\,\mathcal{L}_{\text{leaf}}
+ \lambda_{\text{KL}}\,D_{\mathrm{KL}}(p_{\text{base}}\|p_{\text{edited}})
  \]

\[
\mathcal{L}_{\text{leaf}} =
\sum_{(i,j)\in \text{SL}}\big(1 - K^G_S(i,j)\big)
+
\sum_{(i,j)\in \text{XL}}\mathrm{relu}\big(K^G_S(i,j) - m\big)
\]

- SL/XL — пары узлов одного/разных листов **учителя** на слое 22;
- \(K^G_S\) — грамианы ученика (§1.3, само-\(p\));
- маржа \(m\) — 25-й перцентиль внедиагональных значений \(K^G_L\);
- readout-only: правится только \(W\) (`lm_head`), при \(J_S = W\,T(x)\) все члены считаются по кэшу без повторных forward через модель.

**Граничные условия и параметры.**

| Параметр | Значение |
|---|---|
| \(\lambda_p, \lambda_{\text{leaf}}, \lambda_{\text{KL}}\) | \(1.0,\ 0.1,\ 0.1\) (конвенция KL-leash `paper.md` Exp 16) |
| Веса | Только после Exp 0.3: \(W\) отвязан от `embed_tokens`; правка только \(W\) |
| Транспорт | \(E_S, G_S^{-1}\) заморожены базовой модели |
| Доза | \(\|\Delta W\|_F\); сравнение доза-кривыми против базлайна (тот же рецепт, \(\lambda_{\text{leaf}}=0\)) |
| Метрики оценки | bridge, KL, **top-\(p\) retention (\(p=0.99\))**, JS на held-out (code). Top-10 не используется |
| Критерий успеха (до запуска) | На сопоставимой дозе: падение top-\(p\) retention на held-out \(\le\) падение базлайна + шумовой пол из Exp 0.2; и \(\rho(d_{\text{geo}}, \text{top-}p) \ge \rho_0\) из Exp 0.2 |
| Вырождение | При \(k=1\) (один лист) \(\mathcal{L}_{\text{leaf}}\) не строится, эксперимент не запускается |

**Интерпретация.**

| Результат | Вывод | Действие |
|---|---|---|
| Доза-кривая лучше базлайна на held-out при том же \(\|\Delta W\|_F\) | Геометрический лосс снимает переобучение на калибровочные листья | Метод валидирован; масштабирование на послойную LoRA (`paper.md` Exp 17) |
| Bridge растёт, но top-\(p\) падает равномерно | Проблема не в поточечности лосса, а в потолке readout (ранние слои, по \(B_{ab}\)) | Подтверждение readout-потолка; переход к LoRA на merge-строках |
| Лосс не лучше поточечного | Структура слишком слаба для регуляризации | Лист-контрастив закрыт; возврат к пер-сэмпл лоссам |
