## 0.3. Фильтр вырожденности

```python
degen(doc) := (max_{k>=2} cos(v_t, v_{t+k}) >= 0.95) or (max_token_share >= 0.90)
```

Не только `max-repeat`: `code_1` имеет период 24 и не ловился uniq-флагом.

Фильтр применяется к **обеим** сторонам любого сравнения (урок P4: loopy в контроле тянул медиану 0.4 против 0.80).

## 0.4. Статистика

- CI — **percentile** `[2.5, 97.5]`, не `min/max` бутстрап-распределения. Кластерный бутстрап по документам.
- Для разностей — **парный** бутстрап по разностям, не пересечение независимых CI.
- Один сид шаффла на (doc, blk) недостаточен: **≥5 сидов**, дисперсия null'а отчитывается отдельно.
- Разрешающая способность (`DELTA_MIN`) сравнивается с шириной парного CI **до** прогона; ниже разрешения ⇒ `not_testable`, не `refuted`.
- Критические `|r_partial|` при α=0.05: n=6 → 0.878; n=10 (1 контроль) → 0.667; n=10 (2 контроля) → 0.707; n=16 (4 контроля) → 0.576 (v1.1, проверено численно). Публиковать вместе с вердиктом.
- LOO sign-тест: **6/6** при n=6, **≥7/8** при n=8. Порог 5/6 невалиден (p=0.109).
- Словарь вердиктов: `confirmed | refuted | not_resolved | not_testable | vacuous`.

## 1.3. Математика (точное ядро, v1.1)

Определения per-doc: `N = T_states − 1` (число приращений), `x_t` — приращение любого из трёх объектов:

```
c(0) = Σ_t ‖x_t‖²,   c(k) = Σ_{t=1}^{N−k} ⟨x_t, x_{t+k}⟩,   ρ̂(k) = c(k)/c(0)
```

**(G1) Грам-инвариант — точно, без стационарности, для любого объекта:**

```
r ≡ ‖Σ_t x_t‖² / c(0) = 1 + 2 Σ_{k≥1} ρ̂(k)
```

**(G2)** Только для `‖x_t‖ ≡ 1`: `ρ̂(k) = (1 − k/N)·ρ̄(k)`. Для `Δh`, `Δu` (нормы переменные) эта формула **неверна** — там знаменатель взвешен нормами.

**(G3) `r` — это ровно DC-доля, ничего больше:**

```
r = N · f_DC,    f_DC ≡ ‖mean(x)‖² / mean(‖x‖²)
```

Тождество, не модель. «Sum-rule» — утверждение о среднем приращении, а не о памяти.

**(G4) Где у T0 есть зубы:**

```
Δu:  r = ‖u_N − u_0‖² / Σ‖Δu‖² ≤ 4 / Σ‖Δu‖² ≡ r_max
```

Ограничение что-то запрещает **только если `r_max < 1`**, т.е. `Σ‖Δu‖² > 4`, т.е. rms-хорда `> 2/√N ≈ 0.102 рад` при N=383 (v1.2, D16: off-by-one, N = T_states−1 = 383). Оценка шага ≈0.10 рад ставила T0 на границу вырожденности — **разрешено измерением (v1.1)**: Σ‖Δu‖² = 19.3…518.3 ⇒ r_max ≤ 0.208 < 1 у всех доков, T0 — арбитр. Для `Δh` и `v̂` числитель не ограничен ⇒ зубов нет вообще.

**(G5) Плато в `ρ̄(v̂)` разрешено:** `r_v = ‖R‖²/N`, `R = Σ v̂_t`, `‖R‖ ≤ N` ⇒ `Σρ̂ ≤ (N−1)/2`. Никакого противоречия с «ограниченностью единичного пути» — нормировка убивает телескоп, как ТЗ и говорит.

**(G6) Точный ортогональный R/A-split** (лучше наивного, у которого есть кросс-член):

```
Δh = r̄·Δu + Δr·ū,   r̄=(r_t+r_{t+1})/2,  ū=(u_t+u_{t+1})/2
⟨Δu, ū⟩ = 0  ТОЧНО  (следствие ‖u‖=1)
‖Δh‖² = r̄²‖Δu‖² + (Δr)²‖ū‖²,  ‖Δu‖=2sin(θ/2),  ‖ū‖=cos(θ/2)
```

Даёт T0.2b однозначную реализацию и sanity-check замыкания энергии.

**(G7) `r` и `Σρ̂` инвариантны к любой перестановке приращений** (`Σx` и `c(0)` не меняются). Следствие: **тест «Σ_real против полосы permutation-суррогатов» вырожден тождественно** — real всегда точно в центре полосы (T0.2).

**(G8) Модель «DC + MA(1)»** (`x_t = m + ξ_t − aξ_{t−1}`) даёт `ρ̄(1) = f − (1−f)a/(1+a²)`, `ρ̄(k≥2) = f`. **(T0.1, v1.2, D2; v1.3, D1′):** модель **опровергнута** на всех трёх объектах против matched blk-2 null — **но** объясняет **≈93% уровня плато (НЕ 97%)**: нуль статистики не ноль — E_null = −0.002228 (blk-2, артефакт) / −0.002448 (аналит. −(1−f)/(N−1)), расхождение est − E_null = 0.00417…0.00439, уровень ≈ f_DC + est ≈ 0.067 ⇒ необъяснено 6.2–6.6% (плато ≈ f_DC ≈ 0.057–0.065; избыток +0.00194 — оценка порядка, см. §1.2). «Refuted» не значит «гипотеза мертва» — она объясняет почти всё, кроме статистически надёжных ≈6–7%. Горб k=3,4 — **excess**, знак **объектно-зависим**: +0.0121 (`v_tangent`) / −0.0134 (`h_raw`) / −0.0137 (`du_unit`); значения медианной кривой +0.113/+0.140 — не excess (v1.1-формулировка «f≈0.06, a≈0.26 воспроизводит дип и плато двумя параметрами; горб — единственный остаток» снята). Это превращает T0.5 из открытого поиска VAR в точный минимальный тест **остатка**.

## 1.4. Подводные камни

1. **Нормировка `(T−k)` vs `T`:** точное соотношение `ρ̂(k) = (1−k/N)·ρ̄(k)` верно **только для единичных норм** (G2); для `Δh`/`Δu` знаменатель взвешен нормами. Обе отчитывать + грам-аудит (G8).
2. **Усечение K и окно.** Барлетт-веса меняют $S(0)$; без окна оценка смещена. Явное поле `window`.
3. **Медиана не момент.** Ни одно линейное тождество к `Δ_med` не применяется.
4. **MA(16)-край:** значение −0.472 на k=16 smooth-кривой — **аномалия медианы косинусов, не доказанный баг** (v1.2, D8, синхронно с ч.2 §4.4: A5-кривая — медиана косинусов касательных, к ней «ACF чистого MA(W)» не применимо вовсе); проверяется фильтр-нулём (T4.1-2), не утверждением. Исключать k≥W **только для сглаженного объекта**; для сырой кривой лаг валиден (П15).
5. **Fourier-суррогат сохраняет спектр ⇒ сохраняет ρ̄ по построению.** Это **положительный контроль**, не null для формы. Null для формы — iid/blk/AR.
6. **Loopy несут другую площадь.** Период-2 процесс $\rho(k)=(-1)^k$ даёт $S(0)=0$ точно ⇒ отрицательную площадь могут нести вырожденные доки, а чистые — хвостом. Без популяционного разреза Σ бессмысленна.
7. **Конечная выборка.** При T=384–640 выборочная Σ несёт систематику окна ⇒ критерий «Σ против суррогатной полосы», **не против нуля**.

# §2. T1 — «Канал с памятью»

**Разделение:** T1a — теория сжатия (уровень M-lite, частично подтверждена). T1b — KV как буфер остатка (гипотеза).

**В базовой недеквантованной модели внутреннего квантователя коридора нет.** Единственная жёсткая проекция — эмиссия токена наружу: $x_t=\arg\max W\,n(h_L^t)$. Квантование в E-65/66 — внешнее вмешательство.

## 2.1. T1a — Структура ошибки важнее её нормы

### Постановка

Ущерб от квантования предсказывается структурой ошибки (subspace-SNR, обнуление малых компонент, корреляционная структура), а не её полной нормой.

### Обоснование — измеренная аномалия

| схема | rel-ошибка весов | Δритм |
|---|---|---|
| W8 per-group | 0.6% | 0.0σ |
| **int8d = W8 per-tensor** | **3.5%** | **−1.0σ** |
| W4 g32 | 8.0% | ≈0.0σ |
| W4 g128 | 10.4% | +0.1σ |
| **W3 g128** | **22.4%** | **−0.6σ** |
| fqres4 (остаточный поток) | — | +1.8σ (ритм убит) |

Ошибка в 6 раз больше — вред в 1.7 раза меньше. Ни одна теория «вред ∝ норма» это не объясняет.

**Эррата, не рецидивировать:** `int8d` — это `torch.ao quantize_dynamic` = **per-tensor симметричный W8, активации fp32**, не A8. Проверено де-квантом.

### Математика

**Квантователь с буфером ошибки:**
$$q_t=Q(h_t+b_{t-1}),\qquad b_t=h_t+b_{t-1}-q_t$$
$$\Rightarrow q_t-h_t=b_{t-1}-b_t \Rightarrow \sum_{t=1}^T(q_t-h_t)=b_0-b_T$$

Если буфер ограничен, средняя ошибка $O(1/T)$, а не случайное блуждание.

**Дизер:** $q_t=Q(h_t+d_t)-d_t$, при условиях Шухмана ошибка независима от сигнала.

**Метрики для регрессии:**
$$\mathrm{SNR}_{\mathcal S}=\frac{\|\Pi_{\mathcal S}\Delta W h\|}{\|\Pi_{\mathcal S}Wh\|},\qquad \mathrm{annih}_{\mathcal S}=\frac{\#\{i\in\mathcal S: \tilde w_i=0\}}{\#\mathcal S}$$

плюс эффективный ранг $\Delta W$ и межпозиционная когерентность ошибки.

**Механизм-ядро:** квантование весов = **фиксированная линейная замена координат**, общая для всех позиций ⇒ относительная геометрия сохраняется (E-39b liveness: попозиционное доворачивание на 0.12 рад даёт ×1.57 κ, а общая правка той же нормы — ×0.99). Квантование активаций = вход-зависимое, попозиционное ⇒ относительную геометрию ломает.

### Подводные камни

1. **Tied weights:** `lm_head ≡ embed_tokens`, квантование головы бьёт по всем 24 слоям; ≈80% KL-ущерба — upstream (embed KL 5.23 vs head 1.36). Разделять каналы.
2. **Динамический диапазон:** один scale на матрицу задаётся выбросами ⇒ малые компоненты округляются в ноль. Это и есть гипотеза; её надо мерить, а не предполагать.
3. **σ_R, σ_P не хардкодить:** пересчитывать на том же пуле. Якорь 3.19 — медиана по 12; 8-doc mean = 3.107. Смешение агрегаций уже сломало вердикт E-69.
4. **GGUF-семантика ≠ fake-quant.** W4g128 в GGUF и RTN-4 — разные объекты.
5. **Дизер добавляет дисперсию.** Без амплитудно-согласованного шумового контроля «дизер помог» = «добавили шум, стало мягче».

### Эксперименты

#### T1a.1 — Регрессия ущерба на структуру ошибки (disk-only) ⭐ первый

Канон: `dip_V,med` (батарея E-65); `dip_raw,mean` — robustness, не основной.
**Вход:** dequant-ошибки всех схем (уже измерены), Δdip/Δnll по схемам.
**Панель:** сначала инвентаризация per-doc `dip × scheme` на диске → n≈96, кластерный бутстрап по докам. Если нет — расширение решётки до 30–50 точек (bits × схема × granularity × {веса, активации} × seed).
**Счёт:** $\mathrm{SNR}_{weak}$, $\mathrm{SNR}_{top}$, $\mathrm{annih}_{weak}$, $\mathrm{annih}_{top}$, eff-rank $\Delta W$, межпозиционная когерентность. `annih_weak`/`SNR_weak` строить из `C_l` **того же слоя**, не из `U_obs` L23 (N6).
**Регрессии:** $\Delta dip \sim X$ и $\Delta nll \sim X$, частные корреляции с контролем полной нормы. `bits` и `granularity` — отдельные ковариаты, отчёт коллинеарности.

**Пре-рег:**
- Δdip предсказывается weak-SNR / annih_weak, **не** полной нормой (частная корреляция значима при контроле нормы).
- Δnll предсказывается top-SNR.
- Вывод «смерть T1a» из пре-рега **убран**: обязательное поле — критический `|r_partial|` и мощность; ниже разрешения ⇒ `not_testable`.
- Confirmatory при малом n: **LOO 6/6** или ≥7/8.

**Цена:** ~40 мин. **Это самый дешёвый тест с готовой аномалией.**

# §3. T2 — «Слабо наблюдаемое будущее-адресуемое состояние»

**Уровень:** M (механизм), центральная гипотеза. **Требует интервенции.**

## 3.1. Постановка

1. Несут ли направления с низкой текущей видимостью и высокой будущей — будущее-релевантное состояние **сверх matched PCA/Haar**?
2. Каков **спектр** отношения «будущее/текущее», устойчив ли он, обучен ли?
3. Каузально: патч такого направления меняет будущее, не текущее?
4. **Адресуемо** ли оно чтением (attention), а не только ненулевым Якобианом?

## 3.2. Обоснование

| факт | число | provenance |
|---|---|---|
| E-45f калибровочная доля правки | random/quant 0.082–0.090 vs **trained 0.34–0.47** | artifact |
| $U_{obs}$ полноранговая | $r_{obs}=1024$, $r_{eff}^{U}(0.05)=178$ | artifact |
| E-46 лист не носитель | leaf_lag1 0.634 vs pca_doc 0.325 | artifact |
| E-79 J-lens ∩ λ₁-плоскость | cos 0.471 / 0.442 / 0.521 (L1/L11/L23) | artifact |
| P1 остаток состояния | 1−cos ≈ 0.13 на k=8..16 | artifact |

E-45f — единственное прямое свидетельство, что обучение **предпочитает** невидимые направления. Всё остальное — косвенно.

## 3.3. Математика

$$J_l^t=\frac{\partial z_t}{\partial h_l^t},\qquad C_l^t=(J_l^t)^\top P_t\,J_l^t$$

$P_t$ — softmax/Фишер-метрика (канон `[L-fisher]`), **не** $W^\top W$ без калибровки.

$$O_H^{fut}(l,t)=\sum_{k=1}^{H}\Big(\frac{\partial z_{t+k}}{\partial h_l^t}\Big)^{\!\top} P_{t+k}\Big(\frac{\partial z_{t+k}}{\partial h_l^t}\Big)$$

**k=0 исключён** — иначе числитель содержит знаменатель.

Обобщённая задача:
$$O_H^{fut}v=\lambda\,(C_l^t+\varepsilon I)\,v,\qquad \lambda=\frac{v^\top O_H^{fut}v}{v^\top(C+\varepsilon I)v}$$

Пороговая форма `null_ε(C) = {v: слабое C, сильное O}` — **первичная**; ratio — вторичный скрининг внутри неё; обязательный чек согласования двух селекций (расхождение = находка о неоднородности нуль-пространства).

Контрпример (исправленный): `C=diag(1,0.01)`, `O=diag(0.5,0.02)`, **δ=1** ⇒ порог берёт e₁, ratio — e₂ (при δ=0.5 пример не работает: e₁ исключён).

**(A1) Архитектурный нуль:** `O_H^fut(L_max) ≡ 0` для k≥1 — `h_{L_max}^t` входит только в голову позиции t; KV всех слоёв считаются из входов блоков, слоя выше 23 нет. ⇒ **все клетки T2 при `l ≤ 22`**; L23 — только как positive-control нуль (G9).
`weak-J` — из `C_l^t` per-(l,t), **не** из `U_obs` L23 (N6). `H = 8` первичный, `H = 16` вторичный; `k=0` исключён.
TF — первичный режим; генерация — отдельная клетка, estimand зависит от реализованного пути ⇒ MC или пин сида.
Оценка `O`: Hutchinson с отчётом `m` и дисперсии; **отбор направлений внутри обучающего фолда** (N7).

**Разложение градиента:**
$$\frac{\partial\mathcal L}{\partial h_l^t}=(J_l^t)^\top g_t+\sum_{s>t}\Big(\frac{\partial h^s}{\partial h_l^t}\Big)^{\!\top}g_s$$

### Вычислительная реальность (обязательная оговорка)

Плотный $O_H^{fut}$: $D^2=10^6$ на $(l,t)$ × 384 позиции × 5 слоёв ≈ 2·10⁹ float — **неподъёмно**.

**Решение:** ограничить кандидатным подпространством размерности $r$ (16–64) и считать $r\times r$ Грамиан:
- либо $r$ JVP-прогонов (точно, дорого),
- либо $m$ Hutchinson-проб (оценка, дешёво, с CI).

**Выбор и его цена — часть ТЗ, не деталь реализации.** Отчитывать $m$, дисперсию оценки, и не сравнивать точный $C$ с оценённым $O$ без поправки.

## 3.4. Подводные камни

1. **Такие направления есть всегда.** Теория обязана предсказывать **спектр λ**, устойчивость и адресуемость — не существование.
2. **ε обязателен.** $r_{eff}^U(0.05)=178$ ⇒ нижние ~800 направлений численно нулевые; без регуляризации знаменателя «скретчпад» = артефакт оценщика. Отчёт по ε-сетке.
3. **Три альтернативы, не одна:**

| исход | патч слабо-J | вердикт |
|---|---|---|
| (a) скретчпад | меняет только будущее | T2 жива |
| (b) мёртвый груз | не меняет ничего | T2 мертва в этой клетке |
| (c) редундантная запись | меняет текущее и будущее одинаково | T2 = переименованный базис |

4. **Gauge/транспорт.** Слабо-наблюдаемое множество преобразуется при смене базиса; сравнение слоёв только через транспорт $R_L$ (стык с T5).
5. **Тип слоя.** Для GDN путь $t\to t+k$ идёт через рекуррентное состояние, для full-attention — через attention. Разные механики; смешивать нельзя.
6. **Ёмкость пробника.** Linear probe на $r$ dims vs PCA на $r$ dims — один ранг, один солвер, одна регуляризация, один CV. Иначе «weak лучше» = «пробник лучше».
7. **Выравнивание.** `row_t → tok[t]` (несмещённое: 0.971 с `norm.weight`, **1.000 без**). Точный хэд Qwen3.5-0.8B L23 = `rms(h_L23) @ E^T` **без** `norm.weight`. L23 — последний слой (24 слоя), не «прокси».
8. **R-null конфаунд.** Случайные веса × свой мусор ≠ null для «выученности». Обязательна клетка random × **real corpus TF**.

## 3.5. Эксперименты

### T2.1 — Readout будущего без новых зондов (disk-only) ⭐

Проекция $h_l^t$ на подпространства: `weak-J` (из $C_l^t$ per-(l,t), **не** из $U_{obs}$ L23), `top-J`, `PCA_doc`, `Haar`.
Первичный readout: **state-level ridge** из спроецированного `h` → направление будущего логита/ошибки; один ранг, солвер, регуляризация, CV.
`lk4` — **текстовый baseline** (не readout проекции); отчитывать **прирост над lk4** и раздельно по lookup-hit (N8).
Matching: по `d_eff` **данных** в подпространстве, не по rank; при расхождении — выравнивать по меньшему, отчитать оба.

**Пре-рег:** `top-J` выигрывает на k=1; `weak-J` выигрывает на k≥2 **сверх PCA и Haar при matched d_eff и над lk4**. Иначе (b)/(c), T2 понижается.

**Цена:** ~1 ч. Ноль новой инфраструктуры.

### T2.2 — Спектр, ε, устойчивость, обученность

- Устойчивость — **главные углы между `null_ε(C)` половин**, не cos отдельных eigvec (зазор 0.0088 ≈ 0.9 % σ₁, E-45g: отбор отдельных векторов неустойчив);
- ε-сетка $\{10^{-6},10^{-4},10^{-2},1\}$ × ранг $\{16,32,64\}$; OOS со селекцией в фолде;
- **null: random weights × real corpus TF** (не own garbage);
- L23 в сетке — только как нуль (G9), не как измерение.

**Пре-рег:** спектр λ устойчив (главные углы, порог пре-регистрируется) и отличается от random-полосы. Иначе — `not_resolved`.

### T2.3 — Каузальный патч внутри ячейки ⭐ точная реализация `do(Z), X=const`

Слой: l ≤ 22 (при l = L_max future-only эффект архитектурно невозможен, A2).
Три режима, раздельные estimand, не смешивать:
- **(а) TF, токены форсированы:** X фиксирован по построению ⇒ чистый тест «видимое мышление — достаточная статистика» (T7);
- **(б) open-loop:** гарантия только на x_t; измеряется компаундинг;
- **(в) генерация с пином сида:** перенос направления из TF.

Гейты патча:
```
argmax_gate: argmax W n(h+δ) == argmax W n(h)
logit_gate:  |δlogit_top1 − δlogit_top2| < 0.01
metric:      декларировать ‖δ‖_h, ‖δ‖_n, |δm| — все три (G5′)
```

| клетка | направление | норма |
|---|---|---|
| P-weak | слабо-J, высокий λ (l≤22) | ε |
| P-top | топ-J | ε |
| **P-ctrl** | **случайное tangential, matched по всем трём нормам** | **ε** |
| P-zero | 0 | 0 |
| P-radial@L23 | радиальный, l=23 | matched — **точный амплитудно-согласованный нуль** (A3/N4, валидация машины) |

Мерить: $\Delta\mathrm{logit}_t$ (≈0 по построению), $\Delta\mathrm{logit}_{t+k}$, изменение генерации.

**Пре-рег:** P-weak меняет будущее при $\Delta_t\approx0$; P-ctrl той же нормы — существенно меньше.
**Без P-ctrl положительный ответ недействителен** (урок e84).
**Цена:** 8 доков × 5 клеток × 87 с ≈ 1 ч.

### T2.4 — Адресуемость

Измерить, читает ли attention из $t+k$ запатченное направление: проекция attention-весов на $\delta$. Наблюдаемость ≠ адресуемость; без этого T2 — про мёртвый груз.

| ось | проверка |

## 3.7. Санити-чеки

- ε→∞ ⇒ спектр → собственные значения $O_H$ (предпочтение weak исчезает);
- ε→0 ⇒ взрыв на численно-нулевых направлениях — **флагается**, не публикуется как находка;
- P-zero ⇒ тождественно нулевой эффект;
- assert неизменности argmax для всех внутриклеточных патчей;
- `Σ_k` в $O_H$ начинается с k=1 (unit-тест на индексах);
- `O_H^fut(L_max) ≈ 0` (G9); `Δz(P-radial@L23) ≡ 0` (N4).

## 4.3. Математика

Голова без bias: `z = √D·W̃h/‖h‖`, `W̃ = diag(g)W`.
Ячейки argmax в h-пространстве — **ТОЧНЫЕ полиэдральные конусы**:
`{h : (w̃_i − w̃_j)ᵀh ≥ 0 ∀j}`, `w̃ = diag(g)w`. Работать в h либо явно оговаривать.
«Искривлённые области из-за RMSNorm» — **удалить**; кривизна была бы при bias-голове.
`dist_n = m/‖w_i−w_j‖` (точно); `dist_h = m‖h‖/(√D‖w̃_i−w̃_j‖)`.
`∇_h m_ij = (√D/‖h‖)(I − ûûᵀ)w̃_ij` ⇒ градиент маржи тангенциален.
**УСЛОВИЕ:** проверить `g` по весам чекпоинта (не по argmax-гейту): `g = 1` ⇒ метрика изотропна, остаётся масштаб `‖h‖/√D`; `g ≠ 1` ⇒ анизотропия `diag(g)`, matched-норма в h и n — разные патчи.
Разбиение `F_i` на слое l — **ПРЕОБРАЗ** конусов под стеком, не конусы. Не смешивать.

Внутри ячейки: $x_t=i$, $h_{t+1}=F_i(h_t,KV_t)$.

Маржа и расстояние до границы:
$$m_t=z_{top1}-z_{top2},\qquad \mathrm{dist}\approx\frac{m_t}{\|w_i-w_j\|}$$

Суффикс-карта: $d(h_t)\approx f(x_{t-k+1:t})$.

**Зерно карты:**
$$K(d)=\mathbb E\big[\cos(\text{шаги})\ \big|\ \text{локальная порча контекста глубины } d\big]$$

LADDER_V2 — точки этой кривой. Из masked blk2: $\tilde q = 2\cdot0.740-1 = 0.48$.

## 4.4. Подводные камни

1. **Слово «отражение» запрещено в teacher-forced.** Токен задан, траектория не отражается. Корректно: кусочная гладкость, анизотропия/углы конусов, антикорреляция в позициях переключения.
2. **T-тренд дипа снят.** Исправленный прогон (`sha_gen TRUE`): −0.159 / −0.165 / −0.156 при rep16 0.0→0.067→0.0. Аргумент «дип углубляется с T ⇒ больше флипов ⇒ глубже» **недействителен**. Не использовать +56%.
3. **T-инвариантность не убивает boundary-версию.** Сэмплинг меняет, какие ячейки посещаются, но не отменяет пересечения границ. Она убивает узкое «дип = свойство жадной политики» (уже закрыто P2).

### T3.1 — Margin-conditional dip (disk-only) ⭐

# §5. Композиции и сквозные гейты

## 5.1. T0 как условный арбитр

**Каждая** механистическая теория (T1a, T1b, T2, T3) обязана воспроизвести:
1. per-doc ρ̂ на **своём** объекте + грам-учёт (G8);
2. распределение площади по k при фиксированной сумме (форма);
3. распределение углов поворота + R/A-split (G6) + f_DC;
4. аномалию чётности b=2 — или явно её не объяснять.

«seam-excluded локальность» — **УДАЛИТЬ**: masked-лестница есть детерминированный позиционный подотбор, не физика (П10).
Арбитраж условен: только на доках с `r_max < 1` (N2). Иначе T0 — учётный гейт.

Не воспроизводит ⇒ теория не принята, даже если её собственный тест зелёный.

## 5.2. T1×T2 — не следствие, а ставка

Буфер должен быть **видим будущему**, а не **невидим настоящему**. Это разные условия, пересекающиеся, но не совпадающие.

`corr(buffer, weak-J)` — **отдельная клетка перед любым утверждением о композиции**:
- высокий $O_H^{fut}$ **и** низкий $J$ ⇒ сильная связь T1×T2;
- только высокий $O_H^{fut}$ ⇒ T1 без T2 (буфер работает, но не через черновик).

## 5.3. T2×T3 — патч внутри ячейки как общий инструмент

Внутриклеточный патч решает одновременно:
- T2: `do(Z), X=const` без «патчим и надеемся»;
- T3: операциональный смысл ячейки как единицы свободы дискретной карты.

Одна реализация, два потребителя. Приоритет реализации.

## 5.4. T3×T0 — кто платит по правилу

T0 говорит, **что** обязано сходиться. T3-margin говорит, **где** платится (позиции переключения). T0.3 (кто несёт площадь) — общий гейт обеих.

# §8. Что не делать (бан-лист этого ТЗ)

| запрещено | почему |
|---|---|
| CHSH на ко-измеренных бинаризациях | $\|S\|\le2$ **тождественно**: поточечно одно из $(B_0\pm B_1)$ = 0, другое ±2. Константная функция, не тест |
| g₂ в текущей конструкции | $g_2 = 1+\mathrm{Cov}_1(I)$ — переименованный лаг-1, не оптический g₂ |
| новые фиты к Δ(k) | гейт per-lag ≤3σ провален всеми четырьмя семействами; остаток 21–85σ |
| Fourier-суррогат как null формы | сохраняет спектр ⇒ сохраняет ρ̄ по построению. Только положительный контроль |
| G-vs-TF на своих токенах | open-loop greedy ≡ TF своих токенов — тавтология |
| кросс-модельные числа без своего энкодера | LFM3-ветка отозвана целиком |
