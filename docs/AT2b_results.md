## Правки 17.11 (ревью-раунд 3: код-уровневое по AT2b.py, B1–B5)

Третье ревью в `docs/AT2b_review.md` (код-уровневое; вердикт «код REVISE,
вердикт прогона отозвать до перезапуска»). Все 5 замечаний сверены с кодом и
измерены — ответы: `docs/AT2b_review_r3_answers.md`.

- **B1 (PRINATO)**: `AT2b.py:495` считает `1 − ‖pred‖²/‖yc‖²` (отношение норм),
  а meta-декларация (`:858`) обещает `1 − SSE/TSS`; диагностика (`diag:387`)
  повторяет ту же формулу. **Отозвана заявка «R²_c > 0 / метрика валидна»** —
  корректное R² не измерялось. В дерево вердикта R² не входит (cos/CI/median
  только) — `SUBSPACE_CONTROL_FAIL` арифметически устоит.
- **B1b (PRINATO)**: S6b = `1 − tss/tss ≡ 0` — тавтология; «floor в нуле» =
  определение, не измерение.
- **B2 (PRINATO, количественно)**: yf не центрирован; ‖c(d)‖_med ≈ 17 vs
  ‖yc_t‖_med ≈ 36 (ratio 0.47–0.78). Контроль падает И ПОСЛЕ центрирования
  (control_cd: L6/L12 CI⊃0) — per-t нестационарность (C1) реальна, B2 — не
  единственный механизм.
- **B3 (ЧАСТИЧНО)**: баг реален (weak_i может брать λ ≤ 1e-12 → QR-дополнение
  нулевых колонок): n_dead_weak > 0 на 2.4% (L6) / 1.5% / 1.1% / 1.0% (L12/18/22)
  клеток, full-axes completion 0.15–0.29%; lift для живых колонок корректен
  (E_real/E_spec = 1.0000). «Один механизм, объясняющий L6-инверсию +
  Haar-аномалию» — отвергнуто: хвост ~1–2% не даёт системных эффектов
  (B2-смещение на всех клетках + нестационарность — основные причины).
- **B4 (PRINATO)**: дерево смешивает mean-CI (control, ветка (a)) и median-
  пороги ((b)/(d)).
- **B5 (PRINATO, мягко)**: X центрирован по 128, затем срез [k:] — для k>0
  окно ≠ окну y; общий для армов, k=0 точен.
