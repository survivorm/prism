## 2. Дыры — по «цена ошибки × дешевизна фикса»

### D1. Block-2 null **не сохраняет лаг-1**. Label неверен, вердикт выживает

Докстринг и `null_note` утверждают: «blk=2 сохраняет ровно лаг-1 (DC+MA(1))». Проверил численно на MA(1), N=20000, 20 сидов:

| | original | block-2 perm |
|---|---|---|
| lag-1 | **−0.396** | **−0.199** |
| lag-2 | −0.0086 | +0.0004 |

Ровно половина. Причина структурная: перестановка пар сохраняет **чётные** старты (`x_{2i}, x_{2i+1}`) и рандомизирует **нечётные** (`x_{2i+1}, x_{2i+2}`). Это тот же эффект, который LADDER_V2 поймал как аномалию b=2 — только здесь он в null'е, а не в оценке.

**Что это значит для вердиктов:** для линейного MA(1) автокорреляция при k≥2 нулевая **независимо** от коэффициента лага-1. Значит тест на k=3,4 и на полосе k≥9 к несовпадению лага-1 нечувствителен внутри линейного класса — **вердикт `refuted` стоит**. Но:

- label «DC+MA(1)» надо заменить на **«pair-block null (чётный лаг-1 + DC)»**;
- для нелинейных альтернатив несовпадение лага-1 уже может протекать в старшие лаги ⇒ нужен **аналитический MA(1)-null, matched по лаг-0/лаг-1** (гауссов, дёшево) как второй столбец.

Это не отзыв результата. Это сужение заявки до того, что реально проверено.

### D2. p-floor + множественность: P4 не проходит family-wise

Все три P4 p-value **тождественно 1/61 = 0.016393** — минимум при 60 сидах. Bonferroni по 6 пре-регам (3 объекта × P4/P5) требует α = 0.00833, т.е. **B ≥ 119** (мой расчёт). Сейчас P4 формально не проходит поправку, хотя эффект 18–25σ.

Фикс бесплатный: `NNULL = 199` (min p = 0.005) **или** объявить σ/эффект первичным каналом, p — вторичным. P5 в безопасности (level 10–14σ), P4 — нет.

### D3. Level-канал P5 берёт max|σ| по трём статистикам — непоследовательно

rev.3 MINOR-12 специально слил sign-тест в один ē, чтобы не было α≈0.098 через OR. Но level-канал остался `max(|σ(e3)|, |σ(e4)|, |σ(ē)|) ≥ 3` — та же самая инфляция, только с другой стороны.

**Вердикты не меняются**: ē один даёт −10.2 / −10.9 / +14.1σ. Фикс: level только по ē, e3/e4 — описательно. Бесплатно.

### D4. P2_corpus: 16 доков без токенов — и они в пуле и в отдельной строке

`G0a_provenance`: `corpus_toks: absent (0/16)`, декод-проба «невыполнима в принципе». При этом:

- все 16 входят в `pool5` (n=53), 14 — в `pool4` (n=51, исключены `cor_w11`, `cor_w8` по K<96);
- строка `source_P2_corpus` имеет `row_allowed: true` (n=16 ≥ 12) и публикует `dip_V_med = −0.1671`.

Это **ровно тот класс отказа, который убил ветку LFM3**: правдоподобные числа без верифицируемого входа. G0-a записан как deviation, но не enforced.

Плюс: `pooled_nondeg dip_V_med = −0.0891` против якоря `−0.0722` — пулы разные (`degen_tz` n=53 vs `loopy_ladder nonwiki` n=35), и 16 из 53 — корпус. Число не сопоставимо с якорем и частично корпус-обусловлено.

**Фикс:** (i) обязательная companion-таблица по источникам (gen-only / +corpus / +own); (ii) до восстановления токенов — все корпус-зависимые числа `provenance_limited`, строку `source_P2_corpus` не публиковать как домен-подобную.

### D5. Главный вопрос T0 не агрегирован

Аддентум спрашивал: **компенсируется ли отрицательная площадь лага-1 положительной при k≥2, т.е. Σρ̄ ≈ 0?**

`sum_rho_full` и `f_dc` считаются на каждой клетке и лежат в store — но **ни одна агрегатная строка их не отчитывает**. В claim есть `r`, `r_max`, дипы. Ответа на заголовочный вопрос T0 на уровне пула нет.

Фикс — постобработка store, **без перепрогона**: добавить в агрегаты `sum_rho_full`, `f_dc`, S(0) per object × {T, T−k} × {none, bartlett}.

### D6. Две нормировки в одной клетке — заявлено, но следствие не проговорено

`rho_Tk` — энерго-взвешенная (знаменатель Σ‖x_t‖²), `dip_mean_1`/`dip_med_1` — косинусы (`per_t_cos` → `rho_t`). Поля `moment_stat_independent`, `rho_Tk_norm` это фиксируют. Но следствие надо написать явно:

> тождество S(0) = 1 + 2Σρ̄ требует **unit-variance** нормировки; для энерго-взвешенной ρ̂ замыкается **Gram**-тождество (G8), а не unit-ACF.

Иначе T0 в аддентуме снова окажется алгеброй для величины, которая ей не подчиняется — рецидив О1 на новом уровне.

## 3. Что это делает с теориями

**T0 — статус повышен.** Из «не пересчитана» → **арбитр, который уже убил одного кандидата**. Формулировка аддентума «равенство S(0)=0 — отдельная гипотеза, не следствие» теперь эмпирически поддержана: структура сверх линейного null есть, и она локализована (k=3,4 + полоса k≥9).

**T3 — новое ограничение, не опровержение.** Любая margin/flip-механика обязана объяснить, **почему сырые приращения анти-горбят на k=3,4, а тангенсная рамка горбит**. Ортогонализация — нелинейная позиционно-зависимая смена рамки (медиана θ=55°), знак она перевернуть может. Значит: «горб = внутриячеечная рекуррентность» **нельзя заявлять без указания рамки**.

**T4.1 становится срочнее.** Кросс-член raw-dot vs cos — теперь не гигиена, а прямой тест на то, не создаёт ли метрика «горб» из анти-горба. Дешёвый, на диске.

**T1/T2 — не затронуты напрямую**, но «плато сверх DC+MA(1)» теперь измеренная цель для любой буфер/скретчпад-истории.
