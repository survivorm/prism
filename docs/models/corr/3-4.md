## §2. Блокирующие правки (до запуска)

### E1. §8.3: MP-скобка посчитана для p=8, а матрица 6×6

В 6×6 матрице p = 6 переменных. Точные края:
- **p=6:** λ₊(n=32) = 1 + 6/32 + 2√(6/32) = **2.053**; λ₊(n=192) = 1 + 6/192 + 2√(6/192) = **1.385**.

Последствие не катастрофично (скобка p=8 консервативнее), но протокол с зафиксированными порогами не имеет права цитировать скобку чужого этапа — после прогона «консервативность» станет предметом спора. Фикс: в §8.3 — [2.05; 1.38] и PR ∈ [1,6]; 2.25/1.45 и PR ∈ [1,8] переезжают в §8.6 (этап 8×8); пороги R1–R3 для 8×8 переформулируются явно на стадии (l1) — PR ≥ 6 при p=6 (теоретический максимум, плоский спектр) и PR ≥ 6 при p=8 (промежуточное значение) — разные планки.

### E5 (новая). Транспорту нужен конвеншн знаков и перестановок до polar/log

Q_U = polar(U_tᵀU_{t+1}) математически корректна, но тонкая SVD определена с точностью до знака столбцов и порядка сортировки σ:

- один случайный флип знака столбца j между t и t+1 → Q_U несёт −1 на диагонали → log Q_U даёт члены с iπ → M — мусор;
- пересечение σ_j ≈ σ_{j+1} → перестановка столбцов → Q_U перестановочная → log на главной ветви не определён.

Мой вывод в §1 предполагает Q_U ≈ I-соседнюю; без конвеншна замороженная рецептура не well-posed. Фикс (одна строка в §5.1 — часть вменяемости рецептуры, не новая сущность):

1. выравнивание знаков: sign(u_j(t)ᵀu_j(t+1)) → +1 перед полярным фактором;
2. сопоставление столбцов по максимуму |U_tᵀU_{t+1}| (венгерский), а не по рангу σ; флаг `order_cross` при расхождении с сортировкой;
3. проверка близости: ‖log Q_U‖_F мал и спектр Q_U вдали от −1, иначе `unstable_transport`;
4. все флипы/перестановки пишутся в артефакт E-40.5.

### E6 (новая). Тройка (c, cos, frac_K) из E39_supplement §2.2.1 агрегатно невозможна

Алгебра: для K = (I−P)J тождество **‖K‖²/‖J‖² = 1 − 2c + s²**, где c = ⟨J,PJ⟩/‖J‖², s = ‖PJ‖/‖J‖; и **cos(J,PJ) = c/s**. Два числа определяют третье — тройка переопределена, и это её юнит-тест. Подстановка таблицы (2-10 §2):

|---|---|---|---|---|---|---|
| L6 | 1.22e-3 | 0.088 | 0.0139 | 0.99775 | 0.9966 | −0.0012 |
| L12 | 1.07e-3 | 0.085 | 0.0126 | 0.99802 | 0.9966 | −0.0014 |
| L18 | 5.49e-4 | 0.066 | 0.0083 | 0.99897 | 0.9981 | −0.0009 |

Доказательство несогласованности ещё жёстче: из (c, frac_K) получается **s² = frac_K − 1 + 2c < 0 на всех пяти слоях** (от −0.0007 до −0.0015) — отрицательный квадрат нормы. Значит, как минимум одна из трёх величин — не агрегат того объекта, которым названа. Наиболее вероятное объяснение доброкачественное: смешаны семантики (ratio-of-means против mean-of-ratios по позициям, центрирование, либо разные срезы строк). Фикс (в (a1), без новых сущностей): четвёртое поле записи — **semantics of aggregation** (ratio-of-means / mean-of-ratios / median / centered); assert на кэше: агрегатная тройка обязана удовлетворять тождеству до 1e-9. До разноса тройка цитируется только с явной меткой семантики; вставка в paper §2.5 ждёт разноса.

## §4. Ядро проекта: что из списка достойно переиспользуемой математики

### §4.1. Критерий включения

Конструкция входит в ядро, если:

- **(я1)** используется ≥ 2 экспериментами (или всеми стадиями одной серии);
- **(я2)** имеет алгебраическую форму: аргументы — (p, J, матрицы), никаких констант из кэша внутри формул;
- **(я3)** имеет машинно-проверяемое тождество или юнит-тест;
- **(я4)** переживает смерть любой из H1–H5 и любой исход death-list.

Следствие: пороги (0.5 в (a); 0.05 и Q_95 в unstable_left; ρ < 0.3 / ρ > 0.5 в E-44), ставки (r_cross ≈ 60), кластеризация C1–C4, интервал real/dir — **не ядро**. Это протокол: он умирает или выживает вместе с экспериментом. Ядро — то, что переживает любой исход.

### §4.2. Состав ядра K0–K4

**K0. Алгебра P(p)** — модуль `p_algebra`. Извлечено из: E39_supplement (тождества), E-44 (фактор Фишера), неявно из всех срезов.

- P = diag(p) − ppᵀ — **три роли одного объекта**: ∂p/∂z (якобиан софтмакса), метрика Фишера–Рао на симплексе в логит-координатах, аннигилятор калибровки (P·1 = 0). P² ≠ P — не проектор; но при D = diag(p^{−1/2}): DPD = I − √p√pᵀ — конгруэнтен ортопроектору на 1^⊥ (Сильвестер: rank K−1, инерция (K−1, 0, 0); спектр в [0, p_max], поскольку 0 ⪯ P ⪯ diag(p)).
- Замкнутые формы: tr P = 1 − ‖p‖₂²; tr P² = ‖p‖₂² − 2‖p‖₃³ + (‖p‖₂²)²; собственные значения — корни секулярного уравнения **Σᵢ pᵢ²/(pᵢ − λ) = 1**; в двухточечном пределе λ_max = 2p_max(1−p_max), при размазанном остатке → p_max(1−p_max) — это и есть обоснование диапазона 0.09–0.18 у 2-10 §4.4.
- **Юнит-тесты модуля = ассерты (a3).** E-40.1(a3) — первый реюз ядра: прогон юнит-тестов до всякого эксперимента.

**K1. Калибровочный фактор и канонический срез** — модуль `slices`. Извлечено из: линейки E-33r/E-36, формулировки 2-10 §1.3.

- J ~ J + 1wᵀ; **J^(p_t) = P(p_t)J = ∂p/∂h по цепному правилу** — каноничность алгебраическая (формулировку 2-10 возвожу в определение ядра);
- трёхсрезовый инструмент raw / J^(p_t) / fixP;
- **правило срез-локальности:** тождества выполняются в каждом срезе; константы не переносятся между срезами (обобщение урока sentinel 50.7%: ассерты per-slice, числа per-cache).

**K2. Транспорт на SVD-расслоении** — модуль `transport`. Извлечено из: E-40.5 (рецептура 3-8 §4.3).

- замороженная рецептура §5.1 + E5 (well-posedness);
- потребители уже в списке: E-40.5, E-41.4, E-42 (F_lt, вертикальный транспорт), E-44 (g₂) — четыре;
- юнит-тест: синтетика (случайная ортогональная Q с известным log; порядок остатка ε²), CPU-секунды.

**K3. Нулевая гигиена** — модуль `nulls`. Извлечено из: E-40.4 (перестановка внутри кривой), E-40.5 (равнокорреляционное чтение), E-40.8 (MP/PR), E-44 (два нуля, per-cell floors), 2-9 (редукционный контроль).

- правило 23: любой ‖OX‖²/‖X‖² читается против operator-iid **и** content-matched нуля + изо-референс ‖O‖²_F/K;
- композиционность → энергии + равнокорреляционный уровень ρ̂ + парные отклонения (Айтчисон: ранг ≤ p−1, средняя внедиагональ −1/(p−1));
- MP-скобки с поэтапным p (фикс E1), перестановочный ранг, PR = (Σλ)²/Σλ²;
- редукционный контроль: любой тест X→Y сначала вычитает тривиальное предсказание, построенное из X (b_lin — первый экземпляр);
- двухчастный порог max(относительная планка, нулевой перцентиль);
- поле агрегационной семантики (E6).

**K4. Дешёвые инварианты** — модуль `cheap_invariants`. Извлечено из: E39_supplement (c, cos, frac_K, iso-референс). Моё пополнение этого раунда.

Для грамма G = JJᵀ (сторона словаря; P и G — в одном срезе, правило K1):

- **c = tr(PG)/tr(G)** — взвешенное по G среднее спектра P ⇒ c ∈ [0, λ_max(P)];
- при G ≈ γI: c ≈ tr(P)/K, s² ≈ tr(P²)/K, **cos_pred = tr(P)/√(K·tr P²)**;
- общее определение: **коэффициент выравнивания A := c/c_pred = K·tr(PG)/(tr P·tr G)** — безразмерный; A = 1 означает «P и грамм J спектрально независимы» (родовая изотропия), A ≫ 1 — грамм J селективен к вершине спектра P.

Применение к cos(J, PJ) ≈ 0.08 (наблюдаемая уже внесена в аудит, 1-12 §1.1 «новое»): три измеренных числа (c, s, cos) предсказываются **из одного вектора p̃ замкнутыми формулами** — tr P̃ и tr P̃² вычисляются из кэша одной строкой, без единого форварда. Дальше две чистые ветви:

- **A ≈ 1:** «почти ортогональная фильтрация» 2-10 §2 — родовое поведение изотропии; заодно предсказывается плоскость по слоям ровно настолько, насколько плоско ‖p̃‖² — совпадает с проверкой уязвимости №1 самого 2-10;
- **A ≫ 1:** грамм J действительно выровнен с вершиной спектра P — структурный факт, и тогда у A появляется право стать переменной матрицы при расширении.

В обеих ветках интерпретация 2-10 выживает, но получает шкалу. Юнит-тест модуля — то самое тождество E6: 1 − 2c + s² = frac_K. Несогласованная тройка — первый пациент, которого модуль лечит.

Калибровка ожиданий (не утверждение): обращение родовой формулы c ≈ (1 − ‖p̃‖₂²)/128 даёт из измеренных c имплицитное ‖p̃‖₂² от ≈0.94 (L22) до ≈0.73 (L23); измерение фактического ‖p̃‖² из кэша — одна строка в (a1) — решает, родовая это изотропия или анизотропия.

### §4.3. Что НЕ входит в ядро

- C1–C4 (гипотеза о данных, не алгебра);
- все пороги / ставки / интервалы (умирают или выживают вместе с экспериментом);
- death-list'ы, R1–R3, таблицы исходов (процесс);
- любые числа с клеймом «одного кэша».

**Правило версионирования:** изменение ядра = повторный прогон его ассертов; ядро не может дрейфовать молча. Граница: ядро содержит только объекты с алгебраическими тождествами; всё, что требует прогонов для проверки, — протокол. Ядро мало по замыслу: пять модулей, ~десяток формул, ~шесть ассертов; если ядро растёт дальше страницы — это протокол, протекающий в ядро.
