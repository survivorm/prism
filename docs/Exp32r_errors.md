### 1. Selfcheck (5) — тест на `quad_frac` проверяет не то, что думает

```python
a1z = np.zeros((3, 4)); a2z = np.zeros((3, 4))
norms_z = np.array([10.0, 20.0, 30.0])
c1z = a1z + 2.0 * a2z * (EPS_REL[0] * norms_z)[:, None, None]
```

`a2z` имеет форму `[3, 4]`, а `(EPS_REL[0]*norms_z)[:, None, None]` — `[3, 1, 1]`. Бродкастинг даёт `[3, 3, 4]`, а не `[3, 4]`. Ассерты проходят **вакуумно** (все нули в первом случае, все −1 во втором — потому что все элементы одинаковы по построению), но тест не проверяет реальную форму `[T, K, K]`.

Правильно:

```python
a1z = np.zeros((3, 4, 4)); a2z = np.zeros((3, 4, 4))   # [T, K, K]
c1z = a1z + 2.0 * a2z * (EPS_REL[0] * norms_z)[:, None, None]   # [3,4,4]
# и то же для a1q/a2q
```

Иначе это фальшивая уверенность: если кто-то сломает `quad_frac` (например, забудет `norms`), selfcheck это не поймает.

### 3. `P128_RAW` fallback — флаг, а не факт

```python

```

Это **гипотеза**, зашитая в комментарий и логику заполнения L19 из другого слоя. Если `P128_RAW` в E-27b-кэше хранится **по слоям** (что более вероятно, судя по тому, что в E-33r `P128[t]` индексировался вместе с `J_l`), то `sent = RAW.sum(-1) < 0.5` для L19 станет **маской другого слоя**, и L19 получит неверный sentinel.

Проверка перед прогоном (одна строка):

```python

l0 = next(iter(raws))
for l in raws:

    same = np.allclose(raws[l][k0], raws[l0][k0])
```

Если во всех слоях совпадает — предположение верно, fallback безопасен. Если нет — надо (а) требовать полный кэш по P128_RAW на всех 6 слоях, (б) либо явно пересчитать `P128_RAW` для L19 из `forward(H_L19)`.

### 4. `import json` внутри `if __name__ == '__main__'`

```python
if __name__ == '__main__':
    import json
    try:
        main()
```

Работает (импорт на module-level внутри `if` биндится в module globals, `main()` его видит), но вводит в заблуждение: `main()` использует `json.dump`, и читатель должен проследить, что `json` доступен. Перенести в шапку:

```python
import json
...
if __name__ == '__main__':
    try:
        main()
```
