### 1.1. Тавтология или валидное утверждение?
Валидно, но с одной поправкой в формулировке. Feedforward ⇒ h_t = F(context): p-периодичность
токенов → p-периодичность h — это причинная необходимость, и ТЗ честно это признаёт
(ОБЛАСТЬ, абзац «честная»). Гипотеза «петля ⇒ стабильный repeat» — это **тестируемое
necessary-условие**, а не тавтология: альтернатива (динамический режим — h-осцилляция без
п-периодичности токенов) не исключена конструктивно и как раз проверяется T0.6 (линия в h)
+ T0.7 (repeat в токенах). Граница «когда repeat НЕ даёт h-структуру» — это 11 loopy-undetected,

**Поправка (косметика):** пункт (c) ОБЛАСТИ «в динамике h нет период-p компонента, не
определяемого repeat'ом» читается как априорное УТВЕРЖДЕНИЕ, а не как граница области —
это же самое, что T0.7 должен проверить (H5, descriptively). Перефразировать: «T0.7 не
ставит вопрос о динамике сверх токенов в общем (требует новых форвардов); внутри пула

## 2. ESTIMAND + НУЛИ

### 2.1. PPF(p) / rep_frac(p) — корректно
PPF(p) = #{t: tok[t]=tok[t+p]}/(T−p) — доля позиций в p-repeat; для «стабильности» —
правильная мера. Крайние случаи на данных: p ∈ 3..48, T ∈ {384, 83..255} → T−p ≥ 34 > 0
везде; p > T/2 допустимо (каждая фаза ≤ 2 образцов — не ошибка, lookup вырождается в
x^sur = x, см. 2.6). Реализации нужен guard p ≥ T → None (нетокенные corpus-доки исключены
пулом, см. 5.2, но guard обязателен). ✓ с guard.

### 2.2–2.3. C(p) = Σ_v f(v)², RATIO = PPF/C — корректно
C — вероятность совпадения под эмпирическим мультиномиальным («шанс»); E[PPF] = C для iid
(см. 6.4: iid V=4096 → max_p RATIO = 1.012). RATIO — избыток над шансом, малый словарь
учитывается. ✓

### 2.4. maxrun(p) — корректно, но конвенция не зафиксирована
«Длина (в токенах)» двусмысленна: число совпавших позиций (m) vs размах токенов (m+p−1).
G1a фиксирует конвенцию числом (T−p = 370 для чистого p-repeat — это конвенция «число
совпавших позиций»). **Поправка (правка):** в ESTIMAND явно: «maxrun(p) = число
последовательных t с tok[t]=tok[t+p] в длиннейшем беге (конвенция G1a: чистый p-repeat → T−p)».

### 2.5. Q(p) + permutation null «как T0.6» — сверено с кодом, точное совпадение
`AT0_6_spectrum.py`: T′ = T−1 per-doc (h[1:], без начального); центрирование по t НА x (T′,D)
после отсечения; σ²_d = np.var(x, axis=0) (ddof=0, на центрированном x); S_d(p) = Σ_t x·e^{−2πit/p}
(через x.T @ E.conj); B=199; p = (n_ge+1)/(B+1); сид 2026+doc_idx·1009+s (doc_idx в sorted(96));
exact-null assert: перестановка сохраняет per-dim var (rtol 1e-10). T0.7 формулирует то же.
**Единственное расхождение:** T0.6-коммит — SMOKE-прогон (round v2-r1: H1 n=1, H2 n=1, G7 4/20),
полный прогон 30/66 в репо НЕТ (см. 5.1) — значит, T0.7 будет первым полным committed Q на 30
доках, и «как T0.6» = «как smoke-валидированная реализация T0.6». Формулы идентичны —
переиспользование корректно. ✓

### 2.6. (C) lookup (токен,фаза) — корректно, с двумя замечаниями
x^sur_{t,d} = mean_{t': tok[t']=tok[t] ∧ t'≡t (mod p)} — детерминированное lookup, без
случайности. Мало образцов на (токен,фаза): группа размера 1 → x^sur = x → resid = 0
(консервативно: одиночные вхождения НЕ вносят остатка — это bias в пользу «чистый
copy-paste», описать в отчёте). Фаза mod p при p > T/2: ≤ 2 образца на фазу — допустимо.
**Замечание:** x^sur не p-периодичен в общем (зависит от токена, не только от фазы) —
соответственно Q_resid(p) меряет p-компоненту остатка, а не «всё, что не (токен,фаза)» —
описание в ТЗ («доля период-p мощности h, не объяснённая (токен,фаза)») корректно именно
для p-компоненты, но см. 2.5/5.3 про нормировку σ² в Q_resid.

### 2.7. НУЛИ — корректно с одной оговоркой
(A) rep_frac/maxrun детерминированы — null не нужен ✓; «случайный повтор при малом словаре»
учтён через RATIO (шанс C) — но H1/H2 используют rep_frac БЕЗ RATIO-коррекции: при малом
словаре PPF может быть ≥ 0.8 «шансом» (iid V=1000: max_p RATIO до 1.59 — нет, PPF само по
себе ≈ C ≈ 0.004 ≪ 0.8 — риск нереален на данных: словарь gen-доков >> 1000, min PPF
«шанса» мал). Оговорка: фиксировать в отчёте словарь (unique tokens) per doc.
(B) permutation null — как T0.6, exact ✓ (2.5). (C) descriptive ✓.
