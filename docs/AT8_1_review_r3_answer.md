**Итог по T8.2:** выполненный эксперимент валиден как **«релаксация поля к базовой линии
после вставки луп-блока (доза-ответ)»**: окно возвращается к контролю, не к глобальному
разбавлению (frac_to_global = 0.2328 по 116 измеримым парам), возмущение мало (pert0
медиана 0.014–0.017) и не масштабируется с дозой (ratio = 1.0333 по полной измеримой
популяции, TZ §5). Как тест солитонной упругости — не годится (A2, A3, A4).
**T8.2-r2** («релаксация фона»: filler-контроль той же длины, гейт невырожденности
baseline, ассерты A1/A6, tol из разброса; альтернатива — двухобъектный дизайн) —
декларирован, постановка в очередь — по решению юзера.
