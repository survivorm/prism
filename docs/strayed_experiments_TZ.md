# ТЗ: разведка экспериментов на «сбившиеся» (strayed) — первый проход

> Задание пользователя (дословно), 2026-11-19.

Исследовательская задача, последовательная. Беру эксперимент из списка `./experiments/`;
из самого скрипта и из `docs/ref-exp.md` смотрю постановку. Отвечаю на вопросы
(с проверками, если необходимо):

1. **То ли эксперимент спрашивает?** Корректно ли поставлен вопрос. Сомнения → сразу
   в список, с комментарием.
2. **Правильные ли математические средства** в рамках цели: сущности, методы, границы
   точности. Всё при необходимости проверяю и доказываю.
3. **Можно ли точнее ответить** на поставленный вопрос, опираясь на математику и другие
   эксперименты проекта (там, где постановка и средства корректны, но вердикт
   недостаточно очевиден).
4. **Follow-up с высокой научной ценностью**, которого нет в проекте (личное творчество:
   «ах, они задали такой вопрос — а почему не спросили такой?»).
5. **Корректна ли реализация**: соответствует ли ТЗ, учтены ли ограничения методов,
   выжат ли максимум из полученных данных.

## Правила прохода

- Первый проход **разведочный**; вопросы идут по порядку.
- Как только по одному из вопросов ясно, что эксперимент **уже требует внимания** —
  пишу его в `./docs/strayed_experiments.md` и дальше по этому эксперименту не иду.
  Исключение — **вопрос 4**: follow-up можно добавлять в любом случае (чтобы не потерять
  мысль), даже если эксперимент уже в списке.
- ТЗ перечитывать раз в ~5 ходов (чтобы не забыть).
- Формат записи в `strayed_experiments.md`: ID · класс (Q1/Q2/Q3/Q5) · суть · чем
  подтверждено (файл:строка / исполнение) · рекомендация.
- Вопрос 3/4 — не находка, а предложение: пишутся отдельным разделом «Идеи» и не
  блокируют проход по эксперименту.
- Заявленное «доказываем» = воспроизводимая проверка (исполнение/арифметика/чтение кода),
  а не «глазами».

## Порядок

Последовательный по группам каталогов `experiments/` (e01_10 → e11_20 → … → at/),
внутри — по номеру эксперимента. Карточка в `docs/ref-exp.md` — источник постановки
и чисел; скрипт — источник реализации.
