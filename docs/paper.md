## 1. Мотивация, цели, статус

**Суть метода.** Даны две модели одного семейства (Qwen3.5-4B и Qwen3.5-0.8B), общий словарь. Метод сравнивает **чувствительность декодирования** — то, как скрытые состояния каждой модели влияют на финальные логиты. Сравнение происходит через пространство словаря, которое является общей системой координат для обеих моделей.

**Ключевая интуиция.** Для задач с softmax-выводом важны не все компоненты скрытого состояния, а только их проекция на пространство, реально влияющее на выходные вероятности. Математически это выражается через Якобиан `∂p/∂h_l`: он кодирует, какие направления в `h_l` двигают распределение выходов, а какие — нет.

**Цели (по приоритету):**

| Приоритет | Цель | Что получаем | Статус |
| --- | --- | --- | --- |
| **P0** | Диагностика: послойная карта расхождения Якобианов (`𝓖_gap`) | Тепловая карта по слоям | ✅ Подтверждено (E-1 identity, E-2 карта) |
| **P1** | Карта чувствительности для квантования: какие направления защищать | Правые сингулярные векторы `J^T J` (hidden space); ESG = `JJ^T` (token space) | ⚠️ Частично (E-12c структурно; E-12b — VOID после пересъёма v4; low-rank набор `r_KL≤4` — E-11a) |
| **P2** | Трансформация младшей модели | Лосс для оптимизации | ✅ Валидирован (Exp 17–19: LoRA-дистилляция bridge-лоссом + logit-KD-контроль + детектор разрушения; §7) |
| **P3** | Регуляризатор при дообучении | Дополнительный лосс | гипотеза, отложено |

P0, P1 и P2 — реализованные уровни; P3 отложен до дополнительных исследований. P0 и P1 — разные артефакты: P0 показывает, насколько `J_S` отличается от `J_S_target`, P1 — какие направления hidden state наиболее чувствительны. P2 (Exp 17–19) показывает, что bridge-лосс работает как causal-механизм трансформации (LoRA r=4), при этом logit-KD-контроль подтверждает направленность движения, а детектор разрушения различает направления.

> **Фиксация позиции.** Если не указано иное, все карты чувствительности и Якобианы вычисляются для последнего токена последовательности: `t = S-1`.
**Статусы P2/P3 (из §2 old: P-карта; формулы — ref-impl §3, здесь в сокращении).**
P2 реализован (Exp 17–19, блок 4.8): лосс $\mathcal{L}_{p2} = \sum_l \alpha_l \cdot \mathcal{G}_{\text{gap}}(l)$ — bridge-лосс на matrix-free per-sample J-rows (LoRA r=4 на lm_head + o_proj(l_S), chunked backward/HVP).
P3 — гипотеза, отложен (Exp 19): $\mathcal{L}_{p3} = \sum_l \beta_l \, \|J_S(l) - J_S^{\text{target}}(l)\|_F^2$.

**Чего метод не утверждает.** Метод измеряет локальную структуру
softmax-логитов по hidden state после gauge-free проекции; он не измеряет
производительность на задачах, не является «мерой обучения» (E-15, блок 4.2),
не утверждает переносимость bridge-метрики между экспериментами
(ограничение, §6) и не использует направление gauge как handle
(E-12a/b/c, §6).

### 2.1 Якобиан и gauge-разложение

**Модели.** Старшая модель `M_L`: скрытая размерность `D_L`, `n_L` слоёв, словарь `V`. Младшая `M_S`: `D_S < D_L`, `n_S` слоёв, тот же словарь `V`. Матрица эмбедингов `E ∈ R^{V×D}`; при tied weights `W = E` (§3).

**Якобиан (определение).** Для слоя `l`, позиции `t`:

$$J_l^{(t)} = \frac{\partial z_t}{\partial h^l_t} \in \mathbb{R}^{V \times D}$$

где `z_t ∈ R^V` — логиты, `h^l_t ∈ R^D` — скрытое состояние. На практике вычисляется только для фиксированного набора токенов `𝒮` (ref-impl §4): `J_l^(t)|_𝒮 ∈ R^{|𝒮|×D}`.

**Слой-переходный Якобиан.** Для скрытого состояния `h^l`:

$$D_l(x) = \frac{\partial h^{l+1}(x)}{\partial h^l(x)} \in \mathbb{R}^{D \times D}$$

**Правило композиции** `[L-comp]`. По цепному правилу:
> **Что доказано:** в тексте §2.1 (chain rule, proof sketch); ref-math молчит.

$$J_l^{(t)} = W_{\mathrm{lm}} \prod_{i=l}^{L-1} D_i(x)$$

Произведение упорядочено справа налево; матрицы `D_i` зависят от `x` и в общем случае не коммутируют — порядок имеет значение.

**Структура pre-norm блока.** Для `h^{l+1} = h^l + MLP(RMSNorm(h^l + Attn(RMSNorm(h^l))))`:

$$D_l = I + \frac{\partial \mathrm{MLP}}{\partial \bar h} \cdot \frac{\partial \mathrm{RMSNorm}}{\partial \hat h} \cdot \left( I + \frac{\partial \mathrm{Attn}}{\partial \tilde h} \cdot \frac{\partial \mathrm{RMSNorm}}{\partial h^l} \right)$$

где `h̃ = RMSNorm(h^l)` (вход Attn), `ĥ = h^l + Attn(h̃)` (вход второго RMSNorm), `h̄ = RMSNorm(ĥ)` (вход MLP); вклад каждого RMSNorm — §2.5 `[L-rms]`.

**О взвешенных строках.** Величина `Σ_{j∈𝒮} p_{𝒮,j} J_j` (сумма по `𝒮` полная, `Σ p_{𝒮,j} = 1`), где `J_j = ∂z_j/∂h` — строка Якобиана для токена `j`, — это вероятностно-взвешенное среднее строк Якобиана: вектор-строка `1×D`, в общем случае **не равный** самой матрице `J`. Свойства gauge-оператора `P(p)` устанавливаются в §2.5 `[L-gauge]` и из этого среднего не выводятся.

**Gauge-free Якобиан** (определение; свойства оператора — §2.5 `[L-gauge]`). Для задач, инвариантных к uniform shift логитов (softmax, cross-entropy), важна не `J` целиком, а её gauge-free компонента:

$$J^{(p)} = P(p)\, J, \qquad P(p) = \mathrm{diag}(p) - pp^T$$

где `p = p_S ∈ R^K` — softmax, урезанный и ренормализованный на носителе:

$$p_S(k) = \frac{p(k)}{\sum_{j \in \mathcal{S}} p(j)}, \qquad k \in \mathcal{S}$$

Оператор убивает gauge-направление (uniform shift), сохраняя token-discriminating направления. `J^(p)` используется в defrag (§2.3, E-11a) и surgery (ref-exp, блок 4.5).

**SVD-бандл (определение).** В каждой точке (l, t) фиксируем топ-r сингулярных пар (r = 16): `J_{l,t} = U_{l,t} Σ_{l,t} V_{l,t}ᵀ` — три проекции одного поля: Σ — радиальная, V — правая угловая, U — левая угловая. Калибровка p входит в правый фактор через `J^(p) = P(p)J` — это аддитивная gauge-компонента, не радиальная и не угловая; угловые и радиальные наблюдаемые снимаются на каноническом срезе (E-38, §4.8).

**Горизонтальные O(r)-связности (по t).** Параллельный перенос вдоль t — полярный фактор (совместим с Procrustes по построению):

    R^l_{t,t+Δ} = polar(V_{l,t}ᵀ V_{l,t+Δ}) ∈ O(r)   (правая)
    R^{L,l}_{t,t+Δ} = polar(U_{l,t}ᵀ U_{l,t+Δ}) ∈ O(r)   (левая)

Правая голономия определена в [D-holonomy] (§2.3): `H = R_{01}R_{12}R_{02}^{-1}`, `κ = ‖H − I‖_F`, угловой спектр `{θ_j}`; левая — аналогично по `U_{l,t}`. Левая-правая согласованность — свойство голономии, а не IPR.

**Оговорка (L-связь на raw J).** Левая горизонтальная связность `R^{L,l}` на raw `J_{l,t}` мерит **gauge-дрейф**, а не структуру: gauge-направление `v_g` действует слева (токены), [L-gauge]. `R^{L,l}` на raw допустима только в gauge-free срезах `J^(p) = P(p_t)J` или fixP `P(p_0)J` (E-25/E-26); правая сторона `R^{R,l}` чиста под token-shift.

### 2.2 ESG (Embedding Structural Geometry)

**Лемма** `[L-dim]`. Пусть `J_L ∈ R^{|𝒮|×D_L}`, `J_S ∈ R^{|𝒮|×D_S}`, `E_L ∈ R^{V×D_L}`, `E_S ∈ R^{V×D_S}`. Тогда:

- **(а)** Проекция в пространство словаря: `J̃_L = J_L · E_L^T ∈ R^{|𝒮|×V}`;
- **(б)** Целевой Якобиан для младшей модели: `J_S_target = J̃_L · E_S ∈ R^{|𝒮|×D_S}`;
- **(в)** `J_S` и `J_S_target` имеют одинаковую размерность `|𝒮|×D_S` и непосредственно сравнимы.

**Проблема неортогональности.** При кросс-модельной проекции `J_L · E_L^T · E_S` матрица `E_S` неортогональна (`E_S^T E_S ≠ I`). Даже при `J_L = J_S` и `E_L = E_S` (одна и та же модель) лосс не равен нулю — проекция `E_S` «вращает» векторы в пространстве младшей модели.

**Коррекция** `[L-gram]`. После проекции через `E_S` применить правую коррекцию:

$$J_S^{\text{target}} = (J_L \cdot E_L^T) \cdot E_S \cdot G_S^{-1}, \qquad G_S^{-1} = \mathrm{pinv}(E_S^T E_S)$$

`pinv` — через SVD для числовой стабильности. Эквивалентно `E_S · G_S^-1 = (E_S^T)^+` (при `σ_min(E_S) > 0`) — псевдообратная строки `E_S^T`, т.е. замена `E_S` на её ортогональную проекцию в `R^D`. Для identity-случая (`E_L = E_S`):

$$J_S^{\text{target}} = J_L \cdot E^T \cdot E \cdot \mathrm{pinv}(E^T E) = J_L$$

Смысл коррекции: `J_L E_L^T` — координаты в токен-пространстве; умножение на `E_S G_S^-1` — проекция этих координат в пространство младшей модели, корректная при `σ_min(E_L^T E_S) > 0` (матрица пересечения не вырождена — для моделей одного семейства выполнено).

**Оптимизация.** `G_S^-1` вычисляется один раз и кэшируется на диск (`results/.gramians/`) + в memory-кэш. Ключ — SHA-256 по форме/device + **представительным строкам** `E_S` (первой, последней и 10 детерминированным mid-строкам, равномерно по глубине: `step = (V−1)//10`, см. `_gramian_key`). Полная матрица 248k×1024 слишком дорога для хеша. Это репрезентативный, а не полный хеш: две разные матрицы эмбедингов с совпадающими образцовыми строками (и формой) столкнутся в кэше. В текущем сценарии (1–2 модели фиксированной провены) риск нулевой; при смене модели с тем же V и D **или при обновлении torch** кэш надо чистить (`results/.gramians/`) — ключ не включает версию torch/`rcond`.

> Свойства Грамиана (condition number, ранг, достаточность регуляризации) — результаты, см. E-6b, E-8, E-3.

**Пространства и представления.** Собственные векторы ESG живут в разных пространствах:

- **ESG eigenvectors** (`JJ^T`): живут в **токенном** пространстве `R^K`. Каждая строка `J_i` — градиент логитов по скрытому состоянию для токена `i`; `JJ^T` = Грамиан токенов.
- **Right singular vectors** (`J^T J`): живут в **hidden** пространстве `R^D` — чувствительность hidden dimensions; собственные векторы `J^T J` = направления в hidden space, по которым модель наиболее чувствительна.
- **Связь через SVD:** `J = UΣV^T`, где `U ∈ R^{K×K}` — левые (token space), `V ∈ R^{D×D}` — правые (hidden space). ESG использует `U`; анализ hidden directions требует `V`.

**Два IPR (определение).**

- **Токен-IPR** (левые собственные векторы `u_k` ESG):
  `IPR(u_k) = Σ_i |u_{k,i}|⁴`, `i = 1..K` — локализация моды на токенах; spectral localization / mobility gap определяется на нём.
- **Нейрон-IPR** (правые сингулярные векторы `v_k`, `V`):
  `IPR(v_k) = Σ_j |v_{k,j}|⁴`, `j = 1..D` — локализация моды на нейронах; null — Haar-распределение на S(D). Токен-специфичность на нейрон-IPR **не распространяется**: словаря «нейрон → токены» нет.

Левая-правая согласованность — свойство голономии (§2.1), а не IPR; два IPR измеряют локализацию на двух разных осях (§2.6).

### 2.3 Jacobian gap (метрика близости Якобианов)

**Определение (ESG).** Empirical Sensitivity Gramian для слоя `l` на `N` Якобианах одной траектории:

$$\bar{G}_l = \frac{1}{N} \sum_{i=1}^{N} J_l^{(i)} \left(J_l^{(i)}\right)^T \in \mathbb{R}^{|\mathcal{S}| \times |\mathcal{S}|}$$

Спектральное разложение: `Ḡ_l = U Λ U^T`. Собственные векторы `u_1, …, u_K` — главные направления чувствительности декодирования в **токен-пространстве**.

> **Семантика пулляции (важно).** Пул допустим **в пределах одной траектории** (позиции одного документа): внутри-сэмпловая когерентность `C_a` в 8–41× выше шумового пола (E-27.6). Меж-сэмпловый пул **невалиден** (E-0.1: `C_b ≈ 0.003–0.05`, почти ортогонально) — он усредняет несвязанные Якобианы. Агрегация по сэмплам — только на уровне скалярных метрик (λ, PR, SNR, `r_eff`), не на уровне матрицы (реализация: `compute_esg` — внутри-траектория, `compute_esg_per_sample` — sample-local, `prism/esg.py`). Практические протоколы E-9/E-13/E-14 пулят по последним позициям N **разных** сэмплов — допустимо приближение в гладких слоях, и то только в той конвенции считывания, где gauge не меняется между точками: $C_a$ = 0.258→0.852 (один проектор на пару) / 0.331→0.924 (без gauge), тогда как со своим $P(p_t)$ на каждую позицию $C_a$ = 0.077→0.224 (аудит v6 F2: прежнее обоснование «где `C(σ_d)` велико, E-0.1» ссылалось на v3-число, не воспроизводимое артефактом, и снято).

> **Примечание.** Это НЕ Neural Tangent Kernel в классическом смысле (Jacot et al., 2018): NTK — градиенты по параметрам, ESG — градиенты по активациям. Термин NTK не использовать.

**Спектральные метрики** (для сингулярного разложения `J^(p)`, `σ_1 ≥ σ_2 ≥ …`):

- **uniformity**(`u`) = `⟨u, 1_𝒮/√K⟩² ∈ [0,1]` — доля направления `u` вдоль uniform-режима `𝒮`. Определён только для векторов token-пространства.
- **Эффективные ранги** (спектр `Ḡ_l = U Λ U^T`, `λ_k = σ_k²`, `p_k = λ_k/Σλ`):
  - энтропический: `r_eff = exp(−Σ_k p_k log p_k)`;
  - stable rank: `r_stable = trace(JJ^T) / λ_1` (отношение полной энергии к максимуму — метрика «насколько спектр не сосредоточен в одной моде»);
  - participation ratio: `PR = (Σ λ_k)² / Σ λ_k²` (для спектра `JJ^T`). Stable rank и PR — **разные метрики**, совпадающие только для rank-1 спектра (пример: `λ = (4,1,1,1,1)`: `r_stable = 8/4 = 2`, `PR = 64/20 = 3.2`; `Σλ² = 16+1+1+1+1 = 20`, в ранней версии здесь стояло `64/18 ≈ 3.6` — арифметическая ошибка, опечатка ТЗ, код (`spectral.stable_rank`) считает правильно); не смешивать. Метрика `F = 1/√(r_eff (K + D − r_eff))` (блок 4.3).
- **gauge_share (ESG-версия)** — доля энергии `JJ^T`, приходящаяся на uniform-направление в токен-пространстве: `gauge_share = Σ_k (u_k^T 1)² λ_k / Σ_k λ_k`, где `J = UΛV^T` — SVD (эквивалентно: `u^T JJ^T u / trace(JJ^T)`, `u = 1/√K`). В топ-1 приближении: `λ₁ · uniformity(u₁) / trace`. ⚠️ Колонка `gauge_share_0` у E-10a — **не** этот прокси: там `1 − λ₁ᶜ/λ₁⁰` (отношение сырого и центрированного топ- eigenvalue), систематически выше топ-1-прокси в ×1.3–2.6 (аудит §2.10, сноска † к таблице E-10a). **Сноска (E-39-дополнение):** на одном и том же `J` эта мера **тождественна** `g_uni` (§2.5) — обе равны `‖Jᵀ1‖²/(K‖J‖²_F)` (проверено численно, расхождение ≤ 8e-16); измеренные значения по кэшу exp27b (N=32, K=128): **0.215 (L6), 0.188 (L12), 0.143 (L18), 0.126 (L22), 0.140 (L23)**. Ни при каком протоколе `gauge_share` не давал 98–99 % (E-14: 0.48 → 0.08); эти проценты — норма оператора, см. §4.5; детальный разбор — в git-истории `docs/E39_supplement.md`.
- **Trace** = `Σ_i σ_i²` — общая чувствительность.
- **SNR** — отношение «сигнал» к «шуму» по сэмплам: `signal = ‖среднее J‖²_F`, `var = среднее‖J‖²_F − ‖среднее J‖²_F` (числа — блок 4.5, E-14). Приписка «leave-one-out» из ранней версии убрана: код (`spectral.snr_e14_parts`, побитово сверенный с артефактами E-14) считает обычное среднее по всем сэмплам, а не среднее без $i$-го (аудит `audit3_math.md`, git history (git history) п. В).

Различение ESG-`gauge_share` и `g_uni` (§2.5) имеет смысл **только между разными `J`**: `g_uni` определяется на сыром `J` (`‖QJ‖_F²/‖J‖_F²`, `Q = uu^T` — проекция на uniform-направление строк), тогда как `gauge_share` может считаться на срезе `P(p)J` или на центрированном `J`, и это уже другие величины с другими числами. На **одном и том же** `J` две формулы дают один и тот же функционал (`Σ_k(u_kᵀ1)²λ_k/Σλ_k = ‖Jᵀ1‖²/(K‖J‖²_F)`), так что «разные объекты» здесь — про срез, а не про формулу. Числа: и та и другая мера 0.126–0.215 по слоям 6–22 (L23 — 0.140), то есть есть и мала в дифференциальных слоях, и **никогда не 98–99 %**; при этом `g_uni(J^gf) ≡ 0` тождественно, ибо `P(p)·1 = p(1 − Σp) = 0` (E-39-дополнение, §1).

**Разведение рангов.** Символ `r` используется в двух смыслах, которые следует отличать:

1. **Спектральный ранг** `r_eff` — энтропический / stable rank / participation ratio спектра `JJ^T` (определения выше; метрика `F`).
2. **Функциональный ранг** `r_KL` — минимальное `r`, такое что KL defrag-r аппроксимации `J^(p) ≈ U_r J_r` совпадает с KL полной `J^(p)` (числа — E-11a, блок 4.8). Не путать со спектральными рангами: согласие `r_KL` с `r_eff`/`PR` — отдельная проверка, а не допущение.

Оба ранга одного порядка на L6–L18 (E-9, E-14), и их согласие — отдельная проверка, а не допущение.

**Лемма о спектре** `[L-rank]`. `Ḡ_l = JJ^T ≥ 0` симметрична; собственные значения — квадраты сингулярных значений `J`. Для rank-deficient `J` (см. §2.5 `[L-rms]`: произведение `D_i` вырождено) спектр имеет нулевое собственное значение с кратностью ≥ `K − rank(J)` (`K = |𝒮|`); при `K < D − n_rms` (где `n_rms` — число RMSNorm-блоков на пути `h → logits`, каждый даёт множитель ранга `D−1`, см. `[L-rms]`) полная матрица может быть полного строчного ранга — нулевых СЗ в `JJ^T` нет вовсе (нуль-пространство `J^T J` в D-пространстве имеет размерность `D − rank(J)` — это другой объект). Top-`m` сингулярные значения определяют всю полезную информацию.
> **Что доказано:** в тексте §2.3 (спектр симметричной неотрицательной матрицы); ref-math молчит.

**Определение** `[D-holonomy]` (матрица голономии и её спектр). Для топ-r правых сингулярных подпространств `V_t ∈ R^{D×r}` (ортонормированные столбцы; `r = 16` — та же настройка, что в E-28). Procrustes-ротация для пары `(i, j)`: `V_i^T V_j = W_{ij} Σ_{ij} Z_{ij}^T` (compact SVD), `R_{ij} := W_{ij} Z_{ij}^T ∈ O(r)` (полярный фактор; без det-fix, как в E-28). Голономия для тройки `(t, t+1, t+2)`: `H_{012}(t) := R_{01} R_{12} R_{02}^{-1} ∈ O(r)`. `κ = ‖H_{012} − I‖_F` из E-28 — свёртка `H_{012}` в одно число; полная матрица и её спектр — базисные инварианты (сопряжение `O_0^T H O_0` сохраняет характеристический многочлен).
> **Что доказано:** ref-math §4 E.2 — H = H₀₁₂ ортогональна; трассовое тождество tr(H) = 2Σcosθ_j и κ² = 4Σ(1−cosθ_j); κ и угловой спектр инвариантны относительно выбора базиса, компонентное разложение — нет (фиксируется `[D-holonomy-frame]`).

**Спектральное разложение.** Генерично (и в частности для измеренного `κ = 0.018` (число кэшевого оператора L23; на настоящем `J` — 0.0106, E-38e, и рассуждение ниже от этого не зависит), где `H ≈ I`): `det H = +1`, нет собственных значений ±1, и собственные значения `H_{012}` — `{e^{±iθ_j}}_{j=1..r/2}`, `θ_j ∈ [0, π]` (для `r = 16`: 8 углов). В этом случае тождества (согласованность с E-28; вывод — ref-math §4 E.2); `κ²`-тождество справедливо для любой ортогональной `H`:

$$\operatorname{tr}(H) = 2\sum_{j=1}^{r/2} \cos\theta_j, \qquad \|H - I\|_F^2 = 2r - 2\operatorname{tr}(H) = 4\sum_{j=1}^{r/2}(1 - \cos\theta_j)$$

Для `r = 16`, `κ = 0.018` (E-28, L23): `κ² = 0.000324 = 32 − 4·Σ cos θ_j` ⇒ `Σ cos θ_j ≈ 7.99992`, т.е. все `θ_j ≈ 0` (ротации малы — согласуется с «rigid-but-curved»). Базисно-независимые величины: `Σ_j θ_j` — суммарный угол ротации (Abelian-агрегат); `Var({θ_j})` — разброс углов (неабелева мера); `Σ_j cos θ_j = tr(H)/2`. Формализация уже неявно присутствовавшего в E-28 (`κ` определён через `H`), не новый объект.

> **Конвенция** `[D-holonomy-frame]` (канонический eigenframe). Разложение `H_{012}` на «Abelian» и «fiber» части неканонично без выбора базиса в `V_t` (произвол `O(r)` на каждый `t`). Конвенция: в каждом `V_t` — собственный базис ограничения `P_{V_t}·M_K^T M_K·P_{V_t}|_{V_t}` (самосопряжённый `r×r` оператор на `V_t`; по убыванию собственных значений; знаки — по детерминанту +1). Это фиксирует `R_{ij}` и делает разложение однозначным. Инварианты `κ = ‖H−I‖_F` и спектр `{θ_j}` от конвенции **не** зависят; разложение на компоненты — зависит. Все разложения `H_{012}` в статье — в eigenframe `M_K`; при смене конвенции компоненты меняются, инварианты — нет. Это **конвенция**, не утверждение о природе.
> **Что доказано:** конвенция (канонический eigenframe) — в тексте §2.3; ref-math см. [D-holonomy].

**Тождество** `[L-fisher]`. `P = ∂ softmax/∂ z`, поэтому `J^(p) = P J = ∂p/∂h` — канонический Якобиан выходного распределения, и `J^T P J` — информация Фишера:
> **Что доказано:** в тексте §2.3 (P = ∂softmax/∂z, J^(p) = PJ); ref-math молчит.

$$\mathrm{KL}\left(p \,\|\, p_{h+\delta}\right) = \tfrac{1}{2}\, \delta^T J^T P J\, \delta + O(\|\delta\|^3)$$

Первый порядок тождественно нулевой (softmax инвариантен к сдвигу логитов); **ведущий ненулевой член — квадратичный**, и он корректен при `‖δ‖ ≪ ‖h‖`. Для gauge-направления `v_g` (левый сингулярный вектор `u_g`, uniformity `u_g` ≈ 1): `J^(p) v_g ≈ 0`, т.е. в **L2-метрике на δp в top-K окне** gauge-направление почти не меняет распределение. ⚠️ Это не то же самое, что «нулевая информация Фишера»: истинная квадратичная форма KL — `½ε²·Var_p(Jv)`, и в ней остаток `u_g` (uniformity 0.61–0.98) и хвост за top-K дают коэффициент в ~20–30× больше L2-предиктора — в KL-метрике первого порядка gauge и differential **сопоставимы** (E-12a v4.1). Сравнивать KL по полному forward при `‖δ‖ ~ ‖h‖` с L2-предсказанием нельзя (см. E-12a).

### 2.4 Jacobian bridge (метрика переносимости между моделями)

**Определение (gap, разрыв).** Для слоя `l`:

$$\mathcal{G}_{\text{gap}}(l) = \sum_{i \in \mathcal{S}} w_i \left(1 - \frac{J_S[i] \cdot J_S^{\text{target}}[i]}{\|J_S[i]\| \cdot \|J_S^{\text{target}}[i]\| + \epsilon}\right)$$

где:

- `w_i = p_L(i) / Σ_{j∈𝒮} p_L(j)` — вероятность токена `i` в распределении старшей модели, **нормированная на 𝒮** (в реализации — по **незамаскированным** строкам: после применения маски масса исключённых строк перераспределяется на оставшиеся, режим (ii)). Асимметрия осознанна: используется именно `p_L` (не `p_S` и не среднее) — фиксируется система отсчёта старшей модели.
- `ε = 10^-8`.
- Строки `J_S` и `J_S_target` соответствуют **одним и тем же токенам** из `𝒮` (выравнивание гарантировано §2.2).

**Определение (bridge, мост).**

$$\mathcal{B}_{\text{bridge}}(l) = \sum_{i \in \mathcal{S}} w_i \frac{J_S[i] \cdot J_S^{\text{target}}[i]}{\|J_S[i]\| \cdot \|J_S^{\text{target}}[i]\| + \epsilon}$$

**Соотношение** `[L-gap]`. При совпадающих весах `w_i`: `𝓖_gap = 1 − 𝓑_bridge` **точно** (при усреднении по строкам без весов — ровно `1 − cos`). Направления противоположны:
> **Что доказано:** в тексте §2.4 (при совпадающих весах); ref-math молчит.

| Метрика | Формула | Направление |
| --- | --- | --- |
| **gap** `𝓖_gap` | взвешенная `(1 − cos)` | **меньше = лучше** |
| **bridge** `𝓑_bridge` | взвешенное среднее `cos` | **больше = лучше** |

Исторически именовалось «L_bridge / мост» для обеих величин — вызывало путаницу; теперь имена фиксированы. В JSON: ключи `gap` (E-1…E-15) и `bridge` (E-16a/b) — направление однозначно.

**Диапазон.** `𝓖_gap ∈ [0, 2]` (поскольку `𝓖_gap = 1 − cos`): `0` — полное совпадение направлений, `2` — анти-выравнивание, `≈ 1` — уровень нуля (ортогональность случайных векторов в высокоразмерном пространстве). Меньше = лучшее выравнивание (`gap = 0` ⇔ Якобианы коллинеарны). Наблюдаемые `gap ≈ 1.00–1.03` на ранних слоях интерпретируются как отсутствие выравнивания (стохастическая независимость), а не «структурный конфликт». Ограничение метрики (E-33r.2): для raw $J$ топ-16 подпространства соседних позиций почти ортогональны ($\Delta_{SVD} \approx \pi/2$), и косинусная метрика вырождается — «максимальная дистанция» на самом деле = потеря смысла метрики, не физический сигнал.

**Sentinel-режимы** (определены один раз; все последующие упоминания — «см. §2.4»):

- **(i) sentinel** — все строки маскированы (gap = 1.00). Это **не реальное значение**: `jacobian_gap, sentinel-ветка (bridge.py)` возвращает 1.0, когда маска пуста. В таблицах маркируется «1.000 (sentinel)».
- **(ii) partial mask** — часть строк жива, доля отчитывается полем `masked_fraction`.
- **(iii) baseline ≈ 1.00** — все строки живы, но выравнивание отсутствует (уровень ортогональности, не артефакт маски).

**Маска и порог.** Если `‖J_S[i]‖ ≤ τ` **или** `‖J_S^{\text{target}}[i]‖ ≤ τ` — строка `i` исключается из суммы (реализация: `_valid_mask (bridge.py)` — маска по обеим нормам, порог **одинаков** для обеих). Дефолт — `τ = 0` (sentinel-only: маскируются только нулевые строки; все численные протоколы статьи работают в этом режиме). Исторически дефолтом был абсолютный `τ = 10^-6`. Для decay-маски (исключение затухших, но ненулевых строк) статья использует **относительный** квантиль слоя, чтобы избежать систематического смещения (масштабы `J` различаются на порядки между слоями):

$$\tau_l = 0.01 \cdot \mathrm{median}_i \left( \|J_S[i]\| \right)$$

(калибровка — E-6: на L18 `τ_l ≈ 10^-4` — на порядок выше абсолютного 10^-6; при sentinel-доле > 0 результаты маркируются, а не молча маскируются).

**Масштабная слепота.** Так как Gap — это `(1 − cos)`, он слеп к абсолютному масштабу `J_S` (калибровке уверенности). Для предотвращения геометрической слепоты оптимизации к калибровке Gap отчитывается совместно с метрикой масштаба:

$$s(l) = \log \frac{\|J_S\|_F}{\|J_S^{\text{target}}\|_F}$$

`s(l) ≈ 0` — масштабы совпадают; `s(l) ≫ 0` — младшая модель систематически «громче» старшей по чувствительности (и наоборот).

### 2.5 Калибровочные инварианты

**Определение (gauge-оператор).** `P(p) = diag(p) − pp^T`, где `p = p_S` — softmax, урезанный и ренормализованный на `𝒮` (§2.1). Свойства — в `[L-gauge]`.

**Лемма** `[L-gauge]` (gauge-оператор). Пусть `P = P(p)`:
> **Что доказано:** в тексте §2.5 (свойства оператора P(p)); ref-math молчит.

1. **Положительная полуопределённость.** `P` симметричен, `x^T P x = Var_p[x] ≥ 0`, `ker P = span{1}`, rank = `K−1`.
2. **Не проектор.** `P` **не идемпотентен ни при каком невырожденном** `p` (даже при `p = uniform`: `P = (1/K) I − (1/K²) 1 1^T` и `P² = (1/K) P ≠ P` при `K > 1`; вершина `p = e_i` — вырожденное исключение: `P = 0`) — это **не проектор**, а якобиан softmax (gauge-оператор).
3. **Определённость и инъективность на классах.** Оператор корректно определён на классах эквивалентности `J ~ J + 1 w^T` (uniform-сдвиг строк) и инъективен на них: `P J = 0 ⇒ J = 1 c^T ~ 0`.
4. **Каноничность и инвариантность.** `J^(p) = P J = ∂p/∂h` — канонический Якобиан выходного распределения (`P = ∂ softmax/∂ z`, `[L-fisher]`); инвариантен к uniform shift логитов: сдвиг `z → z + c·1` добавляет к `J` строку, пропорциональную `1^T`, а `P 1 = p − p(p^T 1) = 0`.

**Замкнутые формы и спектр `P(p)`** `[L-p-spectrum]`. `tr P = 1 − ‖p‖₂²`; `tr P² = ‖p‖₂² − 2‖p‖₃³ + (‖p‖₂²)²` (знаменатель изотропного референса `‖P‖²_F/K = tr P²/K`); собственные значения — корни секулярного уравнения `Σᵢ pᵢ²/(pᵢ − λ) = 1`; граница `λ_max ≤ p_max` (из `P ⪯ diag p`), в двухточечном пределе `λ_max = 2p_max(1 − p_max)`; для типичных sharp `p` при `K = 128` диапазон `≈ 0.09–0.18` (измерено 0.1366). При sharp `p` `‖P‖²_F = 0.0883 = 11.3/K` — на порядок выше uniform-значения `1/K`, любое «насколько P маленький» должно это учитывать (E-39-дополнение §2.2).

Утечка на усечённом носителе: `O(p(𝒮)(1 − p(𝒮)))`, где `p(𝒮) = Σ_{j∈𝒮} p_j` — доля массы, приходящаяся на носитель (независимый равномерный сдвиг `1_𝒮` обнуляется точно).

**Тождество** `[L-fisher]` (см. §2.3): `P = ∂ softmax/∂ z`, `J^(p) = ∂p/∂h`, `J^T P J` — информация Фишера.

**Лемма** `[L-gauge-J]` (структурное тождество gauge-направления; доказано: ref-math §E.1). Дано: факторизация L23 (E-35, точна) `J = (√D/r_t)·M_K·(I − û_t û_t^T)`, `M_K = W_lm[𝒮,:]·diag(g) ∈ R^{K×D}`, `û_t = h_t/‖h_t‖ ∈ R^D`. Определение: `w := M_K^T·(1/√K) ∈ R^D`; разложение относительно `û_t`: `w = α û_t + β v_⊥`, `α = ⟨w, û_t⟩`, `β = ‖w − α û_t‖₂ ≥ 0`, `v_⊥ = (w − α û_t)/β` (при `β > 0`).
> **Что доказано:** ref-math §4 E.1 — структурное тождество из точного факторизации L23: J = c·M·(I − ûûᵀ), c = √D/r_t; gauge-направление — Jᵀ(1/√K) = c·β·v_⊥. Векторное тождество Jᵀ(1/√K) = σ_g·cos(u_g, 1/√K)·v_g в общем случае неверно — верно только скалярное; ‖J⁺·1‖ доминируется хвостом спектра и неверен как alignment-фактор.

1. `J^T·(1/√K) = (√D/r_t)·β·v_⊥` (транспонирование и проектор);
2. `v_pred := J^T·(1/√K)/‖J^T·(1/√K)‖ = v_⊥` (при `β ≠ 0`, с точностью до знака);
3. `⟨J^T·(1/√K), v_g⟩ = σ_g·cos(u_g, 1/√K)` — тождество; как следствие, `(√D/r_t)|β| = ‖J^T·(1/√K)‖ ≥ σ_g·|cos(u_g, 1/√K)|` (Коши–Буняковский), с **равенством** т. и т.т., когда `v_⊥ ∥ v_g` (преобраз uniform-направления — точно gauge-направление).

**Следствие (невозможность точной коллинеарности).** Если `β = 0`, то `J^T·(1/√K) = 0` ⇒ `1/√K ⊥ im J` ⇒ все левые сингулярные векторы ⊥ `1/√K`, в частности `cos(u_g, 1/√K) = 0` — противоречие с измеренным `cos(u_g, 1/√K) ∈ [0.85, 0.99]` (E-33r; E-12a: uniformity `u_g` 0.61–0.98). Значит, `β ≠ 0`, `v_⊥` нетривиально. (В идеализации `u_g = 1/√K` это читается как `σ_g = 0`, противоречие `σ_g/σ_d ≈ 40×`, E-12a.)

**Что это исправляет:** заменяет неверные формулы с `J^+` и `M_K^+` (они доминируются хвостом, а не gauge); пункт (3) — единственная корректная версия alignment-фактора: без него `‖J^T·(1/√K)‖` переоценивает gauge-компоненту систематически (E-33r: `cos(u_g, 1/√K) ∈ [0.85, 0.99]`, сдвиг ~15%). Полное доказательство — ref-math §4 E.1.

**Gauge-направление.** `v_g ∈ R^{D_S}` — правый сингулярный вектор `J_S`, чей левый сингулярный вектор `u_g` максимизирует `|cos(u_g, 1)|` (`1/√K` — нормированное uniform-направление в токен-пространстве, `K = |𝒮|`). `v_g` отвечает за mode-shift (сдвиг всех логитов одновременно); направления, ортогональные `v_g`, несут token-discriminating информацию. Gauge-коррекция в `J^(p)` убирает именно `v_g`, оставляя информативные направления для моста.

**`g_uni` (raw gauge-share).** `g_uni = ‖Q J‖_F² / ‖J‖_F²`, где `Q = u u^T`, `u = 1/√K` — доля энергии **сырого** `J` в uniform-режиме токен-пространства (строки), **убиваемая** gauge-оператором (uniform-компонента; при `p = uniform` точно: `P Q = 0`). Отличается от ESG-gauge_share (§2.3) только тогда, когда та считается на другом срезе `J`: на одном `J` это одна и та же величина (`Σ_k (u_k^T 1)² λ_k / Σ_k λ_k = ‖Jᵀ1‖²/(K‖J‖²_F)`). **Измерено** (E-39-дополнение, кэш exp27b, N=32): `g_uni` = 0.215 / 0.188 / 0.143 / 0.126 на L6/L12/L18/L22 и 0.140 на L23 — монотонно убывает с глубиной до L22 и слегка растёт в L23; по документам разброс того же порядка, что и по слоям (L6: 0.166–0.269, L22: 0.103–0.165). Это **не** «98–99 %»: столько энергии несёт uniform-направление, а не всё, что убирает `P(p)`.

> **Где лежат измеренные энергетические числа (область применимости; E-34, артефакт `results/exp39_supp_pscale_probe.log`; текст дополнения — в git `b671390`, серия E-39 из дерева удалена).** Ридаут во всех этих числах — не словарь, а фиксированное множество `U128` (топ-128 токенов по частоте по корпусу, одна база на все позиции и домены: иначе ESG-спектры несопоставимы). Масса `U128` под полным softmax распределена почти равномерно на (0,1) (среднее 0.490, медиана 0.476, p10 0.005, p90 0.995; по доменам среднее 0.443 wiki / 0.540 math / 0.519 code / 0.456 chat) и в **50.7 %** позиций `< 0.5` (E-34) — то есть в половине позиций `p` есть ренормировка усечённого распределения. От этого зависят `O1`, энергетический `frac_K` и их референсы — в частности `Σp²` **только с указанием режима**: ренормированный `p` даёт 0.4686 (all) / 0.5708 (alive), raw `P128_RAW` — 0.2380 (all) / 0.4666 (alive); отозванные старые пары 0.415/0.557 не цитировать (выведены из медианы референса `(I−P)`, не прямое измерение; артефакт — `results/exp39_supp_pscale_probe.log` (stdout `experiments/exp39_supp_pscale_probe.py`, блок `sump2_*`)); не зависят `g_uni` (в формуле `p` нет) и **медианные** по позициям отношения «величина / операторный референс» (числитель и знаменатель одной степени по `p`) — отсюда правило: такие отношения отчитывать медианой и не превращать sentinel в бинарную маску. Размерностная оговорка: «uniform» = uniform по 128 векторам `U128`, а не по словарю; значения `gauge_share` E-10a (K = 32) несопоставимы с `g_uni` (K = 128) абсолютными числами — только трендом.
> **Метка базиса.** Все измеренные числа статьи, посчитанные на кэше `exp27b`, несут `basis=U128-freq`: столбцы считывания — одно фиксированное частотное множество `U128` на все позиции. Пересчёт зависимых на пер-позиционном базисе (`exp27c`, `basis=U128-pos`) — отдельный раунд: задним числом значения не подменяются, а сопоставлять числа из разных базисов без этой метки запрещено.

**Тройка `(c, s, frac_K)` и правило срез-агрегации** `[L-triple]`. `c = ⟨J, PJ⟩_F/‖J‖²_F` (кросс-член разложения `‖(I−P)J‖²`), `s = ‖PJ‖_F/‖J‖_F` (norm-ratio, она же E-33r «98–99 %»), `frac_K = ‖(I−P)J‖²_F/‖J‖²_F` (энергия), `cos(J, PJ) = c/s` (не независимый объект). Точное тождество `frac_K = 1 − 2c + s²` выполняется попозиционно и на агрегате — но только когда все три члена взяты с **одного среза позиций и одной агрегацией** (по умолчанию отношение сумм `ratio_of_means`). Медиана отношения и отношение сумм — разные объекты: подстановка медианного `frac_K` со средним `c` даёт фиктивное `s² < 0` (ровно так выглядел «нерешённый» E6 до разбора 2026-11-03). Измеренная самосогласованная тройка (alive-срез, L6/L12/L18/L22/L23): `c` = 1.215e−3/1.067e−3/5.491e−4/4.810e−4/2.087e−3, `s` = 0.01381/0.01258/0.00830/0.00750/0.01939, `cos = c/s` = 0.088/0.085/0.066/0.064/0.108, `frac_K` = 0.9978/0.9980/0.9990/0.9991/0.9962 (`results/exp39_supp_three_objects.json`, `K_from_I_minus_P`; полная таблица и all-срез — E-39-дополнение §2.2.1).

**Геометрический смысл `cos(J, PJ)`.** Из PSD `P` следует только `c ≥ 0` — и ничего про выравнивание: измеренно `cos(J, PJ)` = 0.064–0.108 (углы 82–86°), т.е. `PJ` — **маленькое перпендикулярное возмущение** `J`, а не «удаление доминирующего направления». Это примиряет `‖PJ‖ ≈ 0.02‖J‖` с `‖K‖ ≈ ‖J‖`: `‖J − PJ‖² = ‖J‖² + ‖PJ‖² − 2c‖J‖² ≈ ‖J‖²`.

**Производная RMSNorm** `[L-rms]`. Для `y = RMSNorm(x)`, `r = √(⟨x,x⟩/D)`, `û = x/‖x‖₂` (`‖û‖ = 1`), `g = 1 + w` (вектор веса):
> **Что доказано:** в тексте §2.5 (дифференцирование y = (x/rms(x))·(1+w)); ref-math молчит.

$$\frac{\partial y}{\partial x} = \frac{1}{r}\, \mathrm{diag}(g)\, \left(I - \hat u \hat u^T\right)$$

(порядок множителей важен: `diag(g)` — слева; при `g = 1` матрица симметрична, при `g ≠ 1` — нет). Свойства: `û` — нулевой собственный вектор (`M û = (1/r) diag(g)(û − û) = 0`), матрица ранга `≤ D−1`, **неортогональна**. Каждый RMSNorm — множитель ранга `D−1`, поэтому произведение `∏ D_i` вырождено (`det = 0`), и **полная** сумма показателей Ляпунова равна `−∞`; FTLE определяется **только для top-m** сингулярных значений. При вычислении FTLE в сумму top-m показателей входит вклад `log(1/r)` на каждом RMSNorm (см. Math.md §3: QR-алгоритм, лог-аккумуляция, оговорки `n = 24–32`): это дрейф масштаба от нормировки, а не хаотичность.

**Объекты и их условия** (v6.0). Канонический объект первого порядка — `$E_K = J^{(p)}(J^{(p)})^T$` (gauge-free ESG, строка выше), не raw `ESG = JJ^T`. Оговорка: `P(p)` — не идемпотентен (§2.5 `[L-gauge]`), поэтому `E_K` — «убитый gauge» в смысле энергии, а не точной проекции. У убранного `P` две несводимые доли: uniform-направление несёт `g_uni` = 0.126–0.215 энергии `J` (верхняя оценка «gauge-энергии»), а всё, что убирает `P`, — это 97.8–99.0 % **нормы** `J` (E-33r `survive_frac` — энергетический прокси `‖P‖²_F/‖J‖²_F`; прямой нормовый срез `‖(I−P)J‖/‖J‖` = 0.9974 (L6) / 0.9975 (L23) — прокси занижает прямое значение, оба числа теперь публикуются вместе, аудит `docs/audit_experiments.md` (git history) §2.3), в энергии 99.95–99.98 % и 0.249–0.685× собственного изотропного референса `‖P‖²_F/K` — то есть величина про норму `P`, а не про данные. Отсюда, в частности, что каноничность `E_K` опирается на инвариантность softmax (срез gauge-free по построению), а не на то, что `P` убирает доминирующее направление данных: `P` ровно настолько же убивает и изотропный вход (`‖P‖²_F = 0.0883` = 11.3 × uniform-ного `1/K`, референс `6.90e-4 = 11.3/K²`), а направленная добавка к дефициту не зависит ни от глубины, ни от домена (0.623–0.692 на полном корпусе позиций, E-39-дополнение §2.2–2.2.3). Практическое следствие (E-34): первый порядок (gauge-free) cross-talk не растёт с глубиной (`$\rho_{gf}$` = 0.064–0.069 на L6–L23) — per-token first-order protection salva-able.

**Канонический срез и порядок.** На каноническом срезе `J^(p) = P(p)J` определяется `R_can = λmax(E_K)/tr(E_K)` (E_K — gauge-free ESG, ниже) — калибровочно-корректный параметр порядка. Сырой аналог `R_raw = λmax(JJ^T)/tr(JJ^T)` (на raw-J) смешивает калибровку и порядок: на «плоском» сыром спектре даёт ложный порядок — диагностический скаляр (§2.10), **не** параметр порядка; называть R_raw параметром порядка запрещено. `R_raw − R_can` — число: доля калибровки в top-режиме.

**G(l) — доля p-индуцированной decorrelation.** `G(l) = 1 − ΔfixP(l)/Δraw(l)`, где `ΔfixP`, `Δraw` — decorrelation-метрики слоя l на срезах fixP и raw (E-25/E-26). G — **структурная** доля позиционной неустойчивости, снимаемая фиксацией p. `gauge_share` (§2.3) — **энергетическая** доля ESG на uniform-направлении; это **разные объекты**: `P(p_t)` убивает 98–99% **нормы** `J` (нормово, E-33r; энергия и отношение к изотропному референсу — выше по этому разделу, и это свойство оператора, а не данных), но фиксированный `p_0` сохраняет ~53% позиционной структуры на L23 (структурно). G — не «доля калибровки» и не параметр порядка.

### 2.6. Три оси локализации

| Ось | Объект | Измерение | Null |
|---|---|---|---|
| токены (левый спектр, U) | token-IPR `IPR(u_k) = Σ_i‖u_{k,i}‖⁴` | локализация моды на токенах; mobility gap | matched-null по токенным маржиналям (E-34-суррогат) |
| нейроны (правый спектр, V) | neuron-IPR `IPR(v_k) = Σ_j‖v_{k,j}‖⁴` | локализация моды на нейронах | Haar на S(D) |
| мода (спектр) | положение `off²`, `b_off`, defect в спектре `λ_k` (E-30b/E-32-tail) | модальная локализация | перестановочный нуль |

Оси **ортогональны по построению**: они измеряют **разные** предикаты (токен-локализация, нейрон-локализация, модальная локализация), поэтому их несовпадение — **не** противоречие, а два ответа на два вопроса. Локализация на токенах не влечёт локализации на нейронах и наоборот. (Консенсус: docs/models 1-6 §2, 2-6 §1.3, 3-5; голономическая ось (κ, {θ_j}) — не ось локализации, см. [D-holonomy].)

### 2.7. Вертикальный транспорт D_l

Слой-переходный Якобиан `D_l = ∂h^{l+1}/∂h^l` (§2.1) вырожден по рангу (rank ~70/1024, E-6b). Вертикальный транспорт правого фактора — полярное разложение:

$$D_l V_{l,t} \approx Q_{l,t}\, \Sigma^{\mathrm{vert}}_{l,t}$$

**Основное определение — полярный фактор** `Q_{l,t} = polar(D_l V_{l,t})` (единственный совместим с Procrustes-связностью по построению). QR-реортогонализация и проекция на `V_{l+1,t}` — **контрольные** определения, не равноправные; при расхождении знака β по определениям F_lt становится классом объектов, а не объектом — это контракт, а не баг.

Распад отчитывается тремя числами: вращение (`Q` — gauge/калибровка), растяжение (`Σ^vert` — RG-радиальный поток), выживший ранг (потеря ранга от RMSNorm — отдельный факт).

### 2.8. Смешанная плакетка F_lt

Единственный новый вычислительный объект работы. `F_lt = dist_Gr(A, B)` — расстояние между подпространствами, достигнутыми двумя путями переноса вокруг плашки (t-перенос, затем l-перенос vs l-перенос, затем t-перенос). Дискретная плакетка над **чисто 1D-базой** — это **не** риманова кривизна (нет ни действия, ни метрики на (l, t)).

Решётка глубины **неравномерна**: (6,12), (12,18), (18,22), (22,23); все производные по глубине нормируются на зазор: `β = dκ/dln l`. Претест: знак β по трём определениям транспорта (§2.7) — совпадение подтверждает, что F_lt — один объект.

### 2.9. Кинетическая SVD-декомпозиция

Движение `ΔJ = J_{t+1} − J_t` в транспортном фрейме (Procrustes-выравнивание (t, t+1) **до** дифференцирования) разлагается на **пять каналов** (не четыре — кросс-член первого порядка не прячется в остаток):

| Канал | Выражение |
|---|---|
| правый транспорт | `‖Σ dV‖²` |
| радиальная | `‖dΣ‖²` |
| левая | `‖dU Σ‖²` |
| кросс-член | `2 tr(Σ M Σ N)`, `M = dUᵀU`, `N = dVᵀV` (антисимметричны) |
| остаток + калибровка | `‖ΔJ − (сумма выше)‖²` |

Кросс-член — σ-взвешенная фробениусова корреляция левых и правых инфинитезимальных поворотов; **первого порядка** по углам; тождественно нулевой при r = 1 (антисимметричная 1×1 — нулевая; это контроль, не баг). Систематически ненулевой — стороны запёрты одной траекторией; нулевой в среднем — стороны вращаются независимо. Это дешёвый напарник теста запирания (1.2). Доли отчитываются в двух нормировках — σ-взвешенной и сырой.

### 2.10. Диагностические скаляры

- `τ` — локальный масштаб спада; интерпретация `τ = ℓ_p` (длина переноса) допустима **только** после двойного фита C_F и C_top16 (tier 0.2), иначе τ — просто локальный масштаб спада.
- `κ_s` (связность сэмпла), `ρ_s` (связность домена) — обсервационные скаляры; каузальные утверждения — только через интервенции (tier 2.4). Корреляции (включая частичные) — скрининг избыточности, не причинный тест.
- `R_raw` — диагностический скаляр (выше, §2.5), не параметр порядка.

### 2.11. E_K и таблица объектов

#### 2.11.1 E_K — канонический объект первого порядка (v6.0)

**Определение:** `$E_K = J^{(p)}(J^{(p)})^T$` — канонический объект первого порядка (gauge-free ESG-грамиан на срезе `p = p_0`, fixP). Это не «эффективное пространство» (формулировка v6.0 снята): свойства `E_K` — инвариантные свойства среза `J^(p)`, а не свойства какого-либо «пространства, в котором ESG действует».

**Условие:** `$E_K$` имеет ранг `rank(J^(p)) ≤ r = 16 < K`. В направлении, ортогональном к образующим `E_K`, грамиан нулевой (нулевые собственные значения) — это свойство грамиана, не «действия ESG». Оговорка аудита (E-40.6): публикуемый там профиль `R_can` строится на другом объекте — корпусном пуле `Σ_t P(p_t)J_t(P(p_t)J_t)ᵀ` по всем живым позициям с per-position `p_t` (ранг ≤ 128), — а не на однослойном срезе `p_0` ранга ≤ 16; под одним именем `R_can` это две разные величины, до приведения определения к одному объекту числа E-40.6 не цитировать.

**Следствие:** `R_can = λmax(E_K)/tr(E_K)` вычисляется только на `E_K` (§2.5); `R_raw` на raw `JJ^T` — только диагностика.

**effective** (v6.0) — объект, полученный после проекции `P(p)` и/или редуцирования к топ-r модам; префикс всегда указывает на приближение (полный объект — без префикса). Примеры: `$E_r = P(p)·ESG·P(p)$` (топ-r), уровень 2 ниже.

**linearity** (v6.0) — свойство быть линейным отображением: `J(δh₁ + δh₂) = J·δh₁ + J·δh₂`. `J` — линейный по определению; `ESG = JJᵀ` — квадратичная форма, не линейный. «Первый порядок» = линейная часть, «второй» = квадратичная.

#### 2.11.2 Объекты и их условия (таблица, v6.0)

| Объект | Определение | Условие |
|---|---|---|
| `P(p)·J` | `P(p)·(W·g)·diag(1/r)` | точное при `L = L_max` |
| `P(p)·E_r·P(p)` | проекция `E_r = P(p)·ESG·P(p)` в топ-r моды | редуцированный уровень 2; `E_r → E_{r+1}` — добавление одной моды |
| `P_u·M·diag(√D/√(r·r))·Mᵀ·P_u` | уровень 2 | только `L = L_max` |
| `P_u·M·P_u` | без `diag(√D/√(r·r))` | только `L = L_max` |
| `E_r`, `E_{r+1}` | `P(p)·ESG·P(p)`, топ-r | L6–L23 |
| `A_r = P(p)·E_r·P(p)` | пересечение: E-28 → уровень 2; E-30 → топ-r | L6–L23, L23 |
| `P_u·A^T·A·P_u` | уровень 2, `L = L_max` | только L23 |

**Иерархия уровней (по точности):**
1. **Уровень 3:** `J → ESG → P(p)·ESG·P(p) → E_r` — наиболее точный.
2. **Уровень 2:** `P(p)·J → P(p)·ESG·P(p)`, `P_u·M·diag(√D/√(r·r))·Mᵀ·P_u`, `P_u·A^T·A·P_u` — редуцированный, приближённый.
3. **Уровень 1:** `M·diag(√D/√(r·r))·Mᵀ`, `A^T·A`, `ESG` без проекций — наименее точный, только `L = L_max`.

**Терминология (v6.0).** «первый порядок» — линейное отображение `J: δh ↦ J·δh`; «второй порядок» — квадратичная форма `δhᵀ·H·δh`; «gauge» — направление, убиваемое `P(p)`: `P(p)·1 = 0`; «gauge-free» — объект после удаления gauge-компоненты: `P(p)·ESG·P(p)`; «level 1/2/3» — уровни точности (иерархия выше); «effective» — объект после проекции/редуцирования; «mode» — собственное направление `ESG`; «top-r» — r наибольших собственных направлений (`r ≤ K`); «null model» — `E_Q[ρ]` по Хааровским Q; «sentinel» — позиция с `sum(p128_raw) < 0.5`, исключается из пар.

**Терминология.** «Лист» (leaf) — топ-r (r = 16) subspace-структура, зависящая от позиции; «расслоение» (fiber bundle) — глобальное свойство поля $J$, не зависящее от позиции (E-27, E-28).

## 3. Архитектурный контекст и протокол

### 3.1 Архитектурный контекст: Qwen3.5

Архитектурные факты, влияющие на корректность вычислений. Производные — в §2.

**Гибридная архитектура.** `config.layer_types[layer_idx]` определяет тип слоя: `"full_attention"` → `Qwen3_5Attention` (GQA); `"linear_attention"` → `Qwen3_5GatedDeltaNet` (GDN). Типы чередуются.

**GDN: рекуррентное состояние.** GDN поддерживает рекуррентное состояние `S_t ∈ R^{H × D_k × D_v}`:

```
S_t = g_t * S_{t-1} + k_t * delta_t^T
output_t = S_t * q_t
```

Кэш GDN содержит `conv_state: [1, conv_dim, conv_kernel_size − 1]` и `recurrent_state: [1, num_v_heads, head_k_dim, head_v_dim]`. GDN — не трансформер: обратный проход идёт через рекуррентную цепочку, а не через attention-матрицы.

**Мутация кэша.** `torch_causal_conv1d_update` мутирует `conv_state` in-place (`conv_state.copy_(...)`); GDN обновляет `recurrent_state` через `cache_params.update_recurrent_state(...)`. Поэтому ни `copy.deepcopy(prefix_cache)`, ни ручной клон не чинят in-place-запись в сохранённый узел графа — это делает только `_clone_gdn_states_on_entry()`. Используется `_deep_clone_cache()` (ручной клон всех тензоров + объектные атрибуты кэша; `deepcopy` на 5.15.1 тоже даёт независимые копии — ручной клон нужен для detach и устойчивости к переименованию полей слоёв), см. ref-impl §1 и C.1.

**Tied weights.** `_tied_weights_keys = {"lm_head.weight": "model.embed_tokens.weight"}` — т.е. `W = E`, и проекция через `E` корректна для логитов. Защита: `extract_embeddings` (ref-impl §4) при каждом вызове проверяет `data_ptr`-тождество `lm_head.weight` и `embed_tokens.weight` и при их расхождении выдаёт `UserWarning` — молчаливое использование не той матрицы анэмбеддинга для нетянутых чекпоинтов превращается в громкий сигнал (в рамках статьи все модели — с tied weights).

**MRoPE.** Multi-dimensional RoPE: строится 4-компонентный тензор позиций `[4, B, S]` (text, temporal, height, width), для текстового входа все 4 компоненты одинаковы. Фактический API модели получает от него `pos[1:]` — три компонент, которые ждёт `rotary_emb` (3-осевой `mrope_section`), — а `pos[0]` уходит в `position_ids` текста; численно это одно и то же, потому что все компоненты равны (аудит `audit4.pdf`, git history (git history) M6 уточняет формулировку, не числа). При вычислении Якобиана для последнего токена с кэшем: все компоненты `= S − 1`.

**RMSNorm — не идентичность.** `Qwen3_5RMSNorm`: `output = (x / rms(x)) * (1 + weight)`; вес инициализирован нулями, поэтому на старте `1 + w = 1` и RMSNorm — чистая нормализация `y = x/RMS(x) ≠ x`. Производная — §2 `[L-rms]`.

**Ограничения версии 1:** CPU (Intel Iris Xe / SYCL, 64 GB, `torch.set_num_threads(4)`, float32 — fp16 на CPU на порядок медленнее, применение fp16 требует отдельной валидации); текстовый вход (`Qwen3_5ForCausalLM`); `model.model` — `Qwen3_5TextModel` (единый путь для flat-моделей всех размеров; для мультимодального wrapper `Qwen3_5ForConditionalGeneration` путь — `model.model.language_model`, обрабатывается `_lm_module()`, `prism/jacobian.py`); dtype Якобиана — dtype модели (`model_dtype`, fp16 на GPU — `h.to(model_dtype)`); в экспериментах — Qwen3.5-4B (32 слоя, `D_L = 2560`) и Qwen3.5-0.8B (24 слоя, `D_S = 1024`).
### 3.2 Общий экспериментальный протокол

**Модели.** Основной — Qwen3.5 0.8B (D=1024, L=24); кросс-модельные прогоны — Qwen3.5 4B (D=2560, L=32) → 0.8B (блоки 4.2; E-10b). E-0.1 — self-bridge 0.8B (4B не загружался — зафиксировано в PLAN).

Честная мощность: N=1–4 в блоках 4.1/4.2/4.8, N=32 в блоках 4.3–4.7; актуальные N — в «Граница вывода» каждого блока.

**Канальная метка (пререгистрация).** Все канальные результаты помечаются четырёхкоординатной меткой `[natural/ΔW] × [raw/gf/fixP] × [top/tail] × [left/right]`. Неполная метка — не интерпретируема: метка — часть результата, а не постфактумная разметка. Запрещённые комбинации: `[raw × left]` — **запрещена** (не генерируется; gauge-дрейф — §2.1 оговорка). `[ΔW × fixP]` — **открыт** (консенсус Спикеров 1–3 до E-41; E-38h/i — cached-h, не fixP).

**Пререгистрация (обязательные поля).** Для каждого теста tier 0–2: (1) гипотеза в фальсифицируемой форме; (2) null-модель; (3) что умирает при провале; (4) объект измерения и срезы; (5) критерий решения; (6) tier; (7) что остаётся при успехе. Контракт пререгистрации — шестираундовый консенсус (docs/models).

**Лестница каузальности.** (1) корреляции / обсервационные данные — только скрининг избыточности; (2) частичные регрессии с контролями (энтропия, sentinel, ‖J‖, домен) — «обсервационная версия», не каузально; (3) интервенции (tier 2.4) — единственный источник каузальных утверждений.

**Таксономия null-моделей.** Token-IPR: matched-null по токенным маржиналям (E-34-суррогат: `Q^T diag(√ESG_ii)` — рандомизация векторов при сохранении собственных значений). Neuron-IPR: Haar на S(D). Спектр ESG: E-34-суррогат, Haar-подпространства, Wishart/MP. Плоский спектр (E-27.6 T6) измерен на матрицах сходства / кросс-сэмпловых грамианах — остаётся диагностическим нулём **только** для матриц сходства, не для ESG.

### 4.1. Корректна ли цепочка и что несёт сигнал

**Вопрос.** Держится ли identity-цепочка, и какой компонент метрики несёт сигнал (learned W vs случайная ортогональная, полнота спектра EᵀE)?

**Канал.** [natural] × [raw] × [top-16/top-512 (E-8)] × [правый: E-3 — случайная R (правая связь); E-5 — перестановка эмбеддингов (оба края); E-1/E-6b — полная J].

**Что получили.**
- **E-1** (N=1, K=4; 0.8B): все 24 слоя gap ≈ 10⁻⁸ (макс 1.0×10⁻⁷); детерминизм PASS (макс разница 0.0).
- **E-3** (N=4, K=32; 0.8B, GPU-ре-ран v3, 2026-11-05): с `pinv(EᵀE)` тождественный проход даёт gap по 24 слоям от −3.5e-08 до +9.3e-08 (L0 = −5.5e-09); без коррекции — **0.533–0.841** (L0 = 0.622); **null «случайная ортогональная R» = 1.002 ± 0.007** — то есть ортогональному отображению метрика обязана дать ровно единицу, и даёт. Разница corrected vs raw — 10⁷×. Пул калибровки этого ре-рана не закреплён пином (очередь R1/R12), поэтому числа сопоставимы с более ранним прогоном по порядку и направлению, но не бит-в-бит; артефакт в git — `results/exp3_ablation.json`, и цитируются именно он.

- **E-6b** (0.8B): κ(EᵀE) = 1684; все eigenvalues > 0 (полный ранг 1024, min eig 12.5); Tikhonov λ ≤ 0.01 не меняет результат.

**Вывод.** [И] Реализация корректна (E-1). Inverse Gramian критичен: без него loss 0.700 (L0; 0.533–0.861 по 24 слоям) vs 10⁻⁸. Три режима упорядочены: corrected (≈0) < raw (0.700) < random R (1.02) — Gramian correction убирает bias, learned W убирает rotation; learned W ≠ случайная ортогональная (E-3). ### 4.8. Прикладной контур, управляемость, Goodhart

**Вопрос.** Можно ли двигать мост редактированием readout, означает ли рост моста улучшение модели, и работает ли прикладной контур (defrag/квантование)?

**Канал.** [ΔW] × [raw (E-16a/b, E-39b) / gf (E-11a)] × [top-K: K = 32/64/256, топ-r r ≤ 32 (E-11c, E-39b r=16)] × [обе стороны (lm_head = E — одна матрица на обоих краях)].

**Что получили.**
- **E-11a** (N=4, K=32; слои 6/12/18; переснят после аудита v4): $r_{KL} \le 4$ — KL(dr4) = KL(dr32) bitwise; прежние «defrag при r=4, KL(gf)~10.5» — артефакт якоря/двойного softmax (озвано, карточка).
- **E-11b** (N=2, K=256; слои 6/12/18): speedup 2.7–18.9× (sample-строки) / 4.0–17.8× (cell); fidelity-метрика v1 — баг (пересчёт).
- **E-11c** (N=8, K=64; 8 par, T4): defrag r ≤ 32 разрушает мост: Spearman r = 8/16/32 = 0.81/0.71/0.43 — мост ломается уже на low-probability хвосте топ-K.
- **E-12b** (N=4, K=32; слои 6/12/18; переснят после аудита v4): **VOID** — при исправленном хвосте KL≤2e−6 и top-1=1.0 везде (бюджет 2/8/6 бит безвреден); прежние «KL≈15, оба разрушают» — артефакт якоря (озвано).
- **E-12c** (N=4, K=32; слои 6/12/18): мост map 0.001 vs uniform 0.014–0.020 — карта несёт сигнал.
- **E-16a** (K=256, N=4; 100 шагов, T4; аналитический last-layer readout, loss (1−cos) + 0.1·KL(leash), Adam lr=1e-3): bridge **0.599965 → 0.7543** при ‖ΔW‖ **0 → 100.7**, KL leash **0 → 0.2403**; continuation до 1000 шагов: bridge **0.921** при ‖ΔW‖ = 128.8; V1 alpha-sweep — VOID.
- **E-16b** (финальный ΔW, 1000 шагов; C4 held-out, n=6): bridge 0.603 → 0.921; **top-p retention 0.837 → 0.416** — антикорреляция «bridge растёт / поведение ломается».
- **Exp 17–19** (P2): bridge-лосс движет LoRA-дистилляцию (P2 валидирован как механизм); downstream-валидация — не запущена.
- **E-39a** (N=32, S=128, L23; U-observability gate серии E-39, dry-run без тренировки; VU-фикс: V_new = bottom-16 правых СВ U_obs, ⊥ û_t): U_obs полноранговая (r_obs = 1024, точного null-пространства нет) — r_eff(U_obs, τ=0.05) = 178 — умеренный режим (меж-doc = 31 — кривизна в значительной мере position-level); baseline κ(L23) = 0.0162 (E-38d воспроизведён, noop-контроль 1.7e-9; это значение суррогатного оператора L23 — на настоящем `J` 0.0099, E-38e, поэтому отношения κ до/после внутри серии корректны, а абсолютная величина — характеристика оператора); **M_K-хирургия (топ-16 → U_obs⊥) даёт κ' = 0.00030 — flattening 54×** (a_random 0.000297 / b_principal 0.000380 / c_balanced 0.000393), целевое κ < 0.005 достигается в превью; ранжирование a_random < b_principal < c_balanced значимо по всем трём парам (32/32 / 32/32 / 21/32, Bonferroni α=0.05/3); ρ_noise ≈ 0.0002 (≈0.02%); κ' — превью на cached-û (tied-веса), не измерение E-39c.
- **E-39b** (GPTQ 4-bit g128 по одному `lm_head`, tied-модель; κ(L23) до/после): **`pass` поведенчески / интерпретация κ ослаблена аудитом** — κ 0.016233 → 0.016043 (ratio 0.988, β/σ₁ без изменения) при J_rel_drift 0.12 и PPL +0.90 %. Поведенческий вывод держится: readout-PTQ не ломает поведение, flatness-регуляризатор не нужен. Интерпретация «12 %-е возмущение **калибровочно выровнено** с листом» не проверена: matched-null (случайный гауссов `ΔW`, σ бисекцией под тот же медианный дрейф J, 3 семени, `exp39b_kappa_matched_null.py`) даёт ratio 0.9887–1.0011 — сдвиг GPTQ лежит внутри разброса шума весов той же величины; при этом κ живая (`exp39b_kappa_liveness.py`: независимое попозиционное доворачивание топ-r на δ = 0.12 рад при дрейфе 0.082 даёт ×1.57, при 0.17 — ×4.65): дело в классе возмущения — правка весов readout есть одна общая линейная замена координат для всех позиций, от неё relative twist не меняется. Отсюда же «режимов с ростом κ (×10 при PPL +1–2 %) собрать не удалось» читается как «класс readout-only, позиционно-некогерентных ΔW не двигает κ», не как «таких режимов нет»; κ в E-39b считается на всех тройках/позициях (docstring P1.3) — с alive-масочными числами E-34/E-40 напрямую не сопоставима (оговорка в артефакте: «часть устойчивости принадлежит метрике»).
- **E-39c_pre** (N=8 C4 held-out, S=128, L23; pre-stage E-39c — KL-budget + α-sweep + tied-weight decomposition; тот же VU-фикс, V_new = bottom-16 ⊥ û_t): **M_K-хирургия (α=1, full) — FAIL по KL**: mean KL = 6.31 nats/token (≈126× бюджета 0.05, ≈50% от log V). α-sweep (α ∈ {0, 0.01, …, 1.0}): **ни один α не проходит оба ограничения** — малые α не спасают KL (мин KL при α>0 = 0.135 = 2.69× бюджета уже при α=0.01), крупные α не спасают κ' (κ' < 0.005 только при α ≥ 0.7, где KL ≈ 6.3): trade-off **disjoint** (KL-safe α = ∅, κ'-safe α = [0.7, 0.9, 1.0], пересечение = ∅) — infeasibility упирается в *tension*, не в тонкий margin. Tied-weight decomposition: embed_only KL = 5.23 (≈80% стоимости — upstream-пропагация через все 24 слоя), head_only KL = 1.36 (readout-only). V_new-стратегии: a_random κ' = 0.00030 (лучший flattening), b/c 0.00038/0.00039 — все три FAIL по KL → провал **structural** (V_new ⊥ V_top), не следствие выбора bottom-16. Вывод: чистая алгебраическая M_K-хирургия на tied-weight модели **фундаментально несовместима** с сохранением поведения (flattening = убить position-dependence = убить signal); E-39d (readout-тренировка, не трогающая embed) — ниже.
- **E-39d** (L23 readout-only тренировка: 128 строк `lm_head` (131K params), g frozen; loss = λ·L_flat + λ_KL·KL-leash, PPL только мониторинг; сетка λ × 3 seeds, протокол — ref-exp): **0 SUCCESS / 6 PARTIAL / 6 DIVERGED** по вердикту «κ'<0.005 ∧ PPL≤+2 % ∧ KL<0.05». При λ=0.01 все 3 seeds дают κ' = 0.0044–0.0045 **и** KL 0.029–0.035 одновременно — тренировка (131K свободных параметров против 16-dim подпространства алгебры) пробивает disjoint-регион E-39c_pre (KL в 4.6× ниже минимума алгебры), но PPL провален при каждом λ (+12–106 %). Ordering-loss expansion дала механизм: без защиты рангов flatness достигается **rank permutation** K-токенов (corr_f 0.59 → PPL +12 %); с ordering (corr_f 0.999) — PPL +0.99 %, KL 0.0043, но **κ floor 0.0092**; ordering без flatness κ не двигает (0.0160 ≈ base) — независимое подтверждение амплитудной инвариантности κ (тот же результат, что E-39b). Floor 0.0092 эмпиричен (эластичность листа vs замороженный g vs локальный минимум — открыто). **Вердикт: κ<0.005 достижим только перестановкой рангов, ломающей декодирование; при защите рангов floor 0.0092 — negative result с механизмом, κ load-bearing.** E-39e (full backprop) отменён: больше степеней свободы cheat-перестановке, а не меньше.
- **E-39f** (полный tied-PTQ, `lm_head ≡ embed_tokens`; разложение ущерба head/upstream): на 4 битах κ 0.01623 → 0.01593 (0.981) при PPL +1.76 %, оба канала в κ ниже разрешения (`both_channels_small`; H-39f «upstream ≥ 50 %» не подтверждена — κ-доля 0.470 измерена в двухбитном `b2g128`, в четырёхбитном доли не определены: `shares_defined = false` при |Δ_total| = 0.00030 < порога), зато в PPL-ущербе upstream-канал даёт 49 % (4 бит) / 72 % (2 бит) — согласно E-39c_pre (embed KL 5.23 vs head 1.36). Доза-ответ: на 2 битах (drift 0.64) κ **падает** до 0.01112 (−31 %) при PPL +102 % — разрушенная модель «плосче» живой: «κ ↓ ⇒ лучше» неверно как направление (границы — §6 п.18).
- **E-39m** (исходное §6: base vs честный flat-носитель E-39d под одним tied-GPTQ, одна калибровка): **`flat_neutral`** — ΔPPL flat − base = +0.53pp [−0.015, +1.07] (4 бит) и −0.10pp [−1.61, +1.19] (3 бит): плоский лист не делает квантование ни дешевле, ни дороже (гейт конъюнктивный, вердикт по обеим шкалам; по абсолютной шкале на 4 битах floor хуже — cmp +2.13pp [1.29, 2.90], но в неё входит предущер носителя +1.59 %, поэтому «хуже» — не про PTQ-чувствительность, аудит §2.14); цена flat (+1.59 % fp16) и сам κ-флор переживают PTQ (0.00928 vs base 0.01600, dry-run readout-канал). Попутно закрыта неоднозначность E-39d: `order_mode=pairwise` даёт коллапс (PPL +2921 %, κ выше base) — честный флор = pearson.

**Вывод.** [И] Readout-редакция — causal lever: одна матрица (lm_head) двигает мост к target с ограниченным collateral по KL (E-16a). [П] «Рост bridge = улучшение» — **Goodhart на геометрическом прокси, не неудача оптимизации**: точечный bridge не является валидной целевой функцией качества (E-16b). Отсюда — требование многоточечного ограничения, а не более сильного оптимизатора. Прикладной контур: defrag дешёвый, но ломает мост при r ≤ 32 (E-11c); квантование по карте сохраняет мост (E-12c). H4 — частично (P2): механизм управляемости работает, downstream-эффект не валидирован.

**Граница вывода.** (а) exp16 — аналитический last-layer readout, exp19 — per-token full-path: **разные величины bridge, не сравнимы** (structural, не bug). (б) α\* не определена: knee за 100 шагов не достигнут; 0.3207 = ‖ΔW‖/‖W‖ на шаге 100 — доза, не оптимум. (в) V1 alpha-sweep VOID — caps ≥ 0.1 не bind, его «α\* = 0.01» — артефакт. (г) N = 4 — демонстрация механизма, не оценка на популяции. (д) Fidelity E-11b — v1-метрика (баг), значение не отчитывается.

**Статус и следствие.** Серия E-39 закрыта как negative result с механизмом: flat leaf (κ<0.005) несовместим с сохранением поведения, **κ load-bearing** (три независимых пути — алгебра-хирургия KL 126×, тренировка+перестановка PPL +12 %, ordering-floor 0.0092; ревью-сверка — git-история `docs/E39_supplement.md`). Следствия: «управление эластичностью L23 снижает Goodhart» закрыто отрицательно уже на этапе flattening; downstream на flat-модели (E-39g/h) приостановлены; E-39e отменён (full backprop усиливает cheat-перестановку); PTQ-контур (E-39b/f/m) показал, что и защищать лист от квантования не от чего — κ к амплитудным возмущениям инертна, а «плоскость» больших доз — это разрушение, не защита. Приоритет прежний: многоточечная метрика + downstream-валидация, а не увеличение дозы; P2 открыт (LoRA-дистилляция), P3 закрыт до метрики. Числа-пересказы series-уровня вынесены: протоколы и все прогоны — ref-exp блок 4.8, ревью-история — git-история `docs/E39+_answers.md`.

  `φ = −3.09`). Якорь: сырые кривые воспроизводят E-31 с отклонением `1.19e-07`.
- **E-40.3 (FFT остатка).** Лог-периодичности нет: в log-сетке не значимо ничего (p = 0.41…0.98),
  на линейной значимы 3 ячейки из 10 при ω ≈ 1.26…3.7 (масштабы 1.7–5 Δ) — низкочастотный остаток
  формы кривой, а не выделенная решёточная шкала. Нуль — распределение **максимума по ω**:
  точечная σ на `argmax`, выбранном по тем же данным, даёт σ = 4…6 на заведомо пустом сигнале.
  Ковариата вместо периодичности: медиана per-doc остатка ↔ sentinel-доля документа,
  ρ = +0.29…+0.74, **все десять ячеек положительны**.
- **E-40.4 (`r_cross`).** 127 на обоих слоях (18 и 22): кумулятивные доли сходятся только на
  последних 1/128 мод; пик разности 0.435/0.619 против 95-го перцентиля нуля 0.181/0.336
  (`p = 2e-3`). Ставка ТЗ `r_cross ≈ 60` — `miss`, `H4_strong_status = alive`; bootstrap-CI
  **вырожден [127, 127]**, поэтому неопределённость читается по `frac_boot_no_crossing` =
  0.41 (L18) / 0.57 (L22).
- **E-40.5 (кинетика, шесть каналов).** Замыкание 5×5-Gram `≤ 2.7e-15`; доля
  `linearization_valid` = 0.0003/0.002/0.044/0.234/**1.000** (L6…L23) — пререгистрация
  подтверждена, на L6–L22 каналы `E_right/left/cross` не интерпретируются;
  `E_off_manifold/‖ΔJ‖²` = 0.64/0.70/0.80/0.69/0.81 — направление подтверждено, уровень «≈ 0.5»
  нет (+28–62 %); левый канал неотличим от null (1.0 нестабильных пар при B = 1000

  каналов на L23 = 2 (PR 2.38, `ρ̂ = 0.42`).
- **E-40.6 (`R_can`/`R_raw`).** `R_can` = 0.0644/0.0672/0.0861/0.1001/0.1143 растёт с глубиной,

  `R_can_nogauge` совпадает с `R_can` до 5e-5 на L6–L22 и расходится только на тривиальном

  выполнено 2 из 4 (`monotone_or_flat__one_sided_no_L0`, L0 в кэше нет).
- **E-40.7 (`G(l) = 1 − Δ_fixP/Δ_raw`).** `G` = 0.0062/0.0226/0.0609/0.0664/**0.2579**

  [0.222, 0.284]): фиксация корпусного `p̄` снимает ≤6.6 % межслойного углового разворота вплоть
  до L22 и 26 % только на L23 (`J = W_lm`) → «gauge-объяснение» угловой разницы слоёв в этом
  срезе не поддерживается, а узкое место — **число слоёв**, а не шум (на пяти слоях `ρ_S = ±1`
  даёт любая монотонная ковариата).
- **E-40.8 (синтез 6×6).** λ = 2.133/1.104/0.905/0.709/0.625/0.524 против перестановочных
  p95 1.520/1.268/1.116/1.006/0.908/0.779 ⇒ **ранг 1** (bootstrap CI [1, 2]), PR 4.64
  (CI [3.74, 5.12]) ⇒ `R3`, `framework_single_object = indeterminate`; замороженная
  кластеризация не выделяется (внутрикластерные |ρ| 0.285/0.206 против межкластерных 0.201).
  Первый прогон дал `R1`/`dead`: столбец `S04` не сошёлся с носителем по ключам документов
  (`dom/i` против `dom#i`) и мёртвый NaN-столбец «не коррелировал ни с чем».

**Вывод.** [И] Форма затухания при целой сетке Δ **не разрешена** (это не «формы нет»);
лог-периодичности нет; носитель шести мер **одномерен**, но и «рамка мертва», и «один объект
жив» запрещены одним и тем же артефактом. [И] Вариация `p` по позициям почти не участвует в
межслойном развороте базисов. [И] Поле кэша не интерпретируется по имени: логики считывания =

(`mean|Δ| = 0.53`, `corr = 0.9836`), сдвигает sentinel `50.71 % → 55.44 %` и занижает `KL` на

### 4.10. Ущерб, память листа и рамки (E-45…E-46)

**Вопрос.** Двигает ли обученная правка весов структуру листа сильнее, чем шум, и является ли
лист носителем состояния (следующего токена)?

**Канал.** [interventional + natural] × [raw] × [r = 16] × L23; носитель — собственные правки
(`results/exp45_edits_sparse.npz`), κ-метрика E-38d; E-45b/E-46 — рама листа на 32 документах
× 4096 позиций.

**Что получили.**
- **E-45 (нет «невидимого разрушения»).** База `κ₀ = 0.016233`. Под квантизацией (GPTQ-4, RTN-8) и
  плотными случайными правками `κ/κ₀ ∈ [0.9954, 1.0074]`, полоса одного повторного замера
  (8 seed-нуллей) — `[0.9920, 1.0024]` (±0.52 п.п.); за то же время поведение уходит куда угодно:
  `KL_B ∈ [9.2e-05, 4.78]` (в 5×10⁴ раз), `ΔPPL_B` — от долей процента до **+7374 %**. Единственное,
  что `κ` двигает сильно, — систематическое уплощение: `κ/κ₀ = 0.325 / 0.211 / 0.129`.
- **E-45f (дешевизна уплощения).** Калибровочная доля правки `s = 0.082–0.090` (= `1/√128`) у
  случайных и квантизационных против **0.34–0.47** у обученных: треть-половина движения `J` у
  обученного носителя лежит вдоль направления, которое на вывод не влияет.
- **E-45g (разрез `r = 16` не для сравнения базисов).** Медианный сингулярный зазор 0.0088
  (≈ 0.9 % от σ₁); чувствительность `κ` к возмущению вне образа `W_U → J` — ×11.5 при `ε = 1e-3` с
  насыщением ×342 при `ε ≥ 0.01`, то есть направление `V₁₆` вращается от возмущений на два порядка
  меньше самих правок. Сравнимы только инварианты (`σ`, `PR`, `g_uni`, величина голономии).
- **E-45b (перекрёстный носитель).** Тот же лист на свежем тексте (не на кэше exp27b):
  `g_uni = 0.1409` против `0.1403` на кэше; связь листа с поведением слабая и не уникальна —
  26 пар из 54 при `|z| > 3` против блочного нуля, максимум `|ρ| = 0.208`, и `‖h‖` с `‖J‖`
  предсказывают не слабее (`ρ(κ, ‖h‖) = −0.142` при `z = −7.1`).
- **E-46 (листа-носителя нет).** `score = KL / KL своей рамы` (меньше = лучше): `leaf_lag1` 0.634
  против `pca_doc` 0.325 и `pca_doc_raw` 0.102 — обычный PCA того же текста на той же размерности
  лучше, «лист лучше на 0 % документов». Единственное преимущество листа над случайным
  подпространством (Haar) живёт ровно до сравнения при равной норме: в голом KL `−0.344`
  (лист лучше на 100 % документов), при восстановлении нормы `+0.266` (на 0 %). Итог артефакта:
  «носителя нет: как минимум один null не хуже листа».

**Вывод.** [И] Предиктор ущерба — дрейф правки, а не `κ`: метрика, у которой диапазон отклика
меньше полосы повторного замера, не метрика качества; `κ` остаётся детектором ровно одного
направленного изменения (уплощения), и после вычитания калибровки — валиден только для него.
[И] Из листа нельзя строить носитель состояния: практические методы (сжатие активаций, steering,
выбор размеров) обязаны начинать с PCA-null'а на том же тексте. [И] Базисы листа несравнимы
покомпонентно — ни между правками, ни с PCA.

**Граница вывода.** Всё на L23 (тривиальный `J = W_lm`, суррогат кэша, §6 п. 26) и на r = 16;
26 значимых пар из 54 не означают причинности; PCA-null'ы берутся на том же тексте, но без
gauge-free-преобразования, поэтому «лист хуже PCA» — про предсказание следующего токена, а не про
структуру поля.

**Статус и следствие.** Закрывает ставку «лист = носитель» в отрицательной форме и переводит
нулевую гипотезу для всех будущих steering-результатов на «PCA того же текста».

**Источник.** вердикты `experiments/exp45_verdicts.py`; критерии E-45b/E-46 — `exp46_verdicts.py`.
`results/exp45_damage_vs_structure.json`, `exp45f_gauge_decomp.json`, `exp45g_cut_stability.json`,
`exp45_kappa_seed_null.json`, `exp45b_leaf_table.json.gz`, `exp46_frame_as_memory.json.gz`;
логи `exp45_verdicts.log`, `exp45b_analysis.log`, `exp46_verdicts.log` (сверка —
`experiments/exp45_table_check.py`, `experiments/exp40plus_doc_check.py`).

### 4.11. Второй носитель: переносится ли механика (E-47/E-48)

**Вопрос.** Все числа поля J сняты на одной модели (Qwen3.5-0.8B, GQA + RMSNorm). Что из них
свойство объекта «последняя нормировка + head», а что — свойство конкретной модели?

**Канал.** [natural] × [raw] × [top-16]; второй носитель — LFM3-1.7B (conv-архитектура, свой
продюсер кэша); пререгистрация критериев K0.*/K1.*/P2 **до** чисел (`docs/leaf_dynamics.md` §9).

**Что получили.**
- **E-47 (Qwen, механика).** Формула листа `J = r·M(I − ρ u ûᵀ)` подтверждена: вся зависимость
  `V₁₆` от позиции идёт через одну `u`, `g_t ≡ 1.000`; пересчёт `J` только из `(H, W_lm, g)` даёт
  относительное расхождение `2.7e-07` при численном поле `1.4e-06` (в 5.3 раза ниже пола ⇒ механика
  не тонет в арифметике), а знак `r(s,a)` по бинованным средним даёт фит
  `s = 0.383·tanh(a/0.715)` (`R² = 0.867`, фит по бинам, не поле артефакта). Линейная кинематика «`s` следует за `a`»
  мертва в обоих режимах (K0.1 = 0.38, K1.1 = 0.134) — не из-за отсутствия связи, а потому что
  `a` почти всегда на полке насыщения (а `a_med` 0.85–1.0 — далеко на полке того же фита). Планарность шага
  вращения устойчива (`p ≈ 0.81–0.87`), но петлю от нормального режима не отличает (K1.3 — null).
- **E-48a (LFM3, те же критерии).** Механика переносится: route-дрейф того же порядка, колено
  насыщения на том же `a` (`a0 = 0.708` против 0.715 у Qwen), `p_med = 0.8915`, `g_t ≡ 1.0`. Доменные эффекты —
  нет: после перегенерации с верным readout (см. ниже) доля документов с петлёй — wiki 10/16,
  code 4/16, chat 3/16, math 2/16 при 15.2 / 0.1 / 0.2 / 0.2 петли на документ (wiki/math/code/chat); **направление**
  доменного контраста оказалось тем же, что у Qwen (зацикливается в первую очередь wiki, math —
  самый устойчивый), не переносятся количества (13/16 против 10/16) и периодичность петли:
  периодичность петли держится, но слабее: AC(s) ≥ 3 на периоде у 24/27 петлевых документов Qwen
  (89 %) и у 14/19 (74 %) у LFM3.
  Прежняя версия этого пункта («направление контраста не совпадает с Qwen», «14.7 петли на
  документ у math», «17/28 с AC(s) ≥ 3») описывала генерацию без гейна `w` финальной нормы —
  `argmax(rms(x) @ Wᵀ)` вместо `lm_head(w ⊙ rms(x))` — и снята после R9/R10
  (`docs/regen_queue.md`, `docs/leaf_dynamics.md` §9.5); на верной политике энтропия шага
  выросла на всех доменах (например math 0.72 → 0.81 бит), а петли не-wiki доменов схлопнулись
  (документов с петлёй 28 → 19 из 64).
- **E-47c/E-48 (P2, предсказание петли).** Лист к предсказанию петли почти не добавляет:
  `ΔAUC(all − triv)` = **−0.008** (Qwen) и **+0.088** (LFM3, `AUC` leaf 0.763 / triv 0.735 /
  all 0.823) — тривиальные фичи (энтропия, повторы) ловят тот же режим дешевле; в вырожденных
  документах коллапса тривиальный признак «следующий токен = предыдущий» даёт `eq_prev_rate`
  до 0.938 и практически идеален. Вердикт у LFM3 остался отрицательным, но **по другой ноге
  критерия**: пререгистрация требует одновременно `AUC_leaf ≥ 0.8`, форы ≥ 5 токенов и
  `ΔAUC ≥ 0.05`; после перегенерации третья нога перешагнута (+0.088 > 0.05), не сошлись первая
  и вторая (0.763 < 0.8, фора 0 — нет ни одного Δ с leaf-AUC ≥ 0.8). До перегенерации было
  +0.017 — то есть прирост листа к тривиальным фичам на LFM3 растёт вместе с правкой readout,
  и утверждать «лист не добавляет» для этой архитектуры можно только в формулировке
  «сам по себе лист не предсказывает», а не «в добавке к энтропии нет ничего».

**Вывод.** [И] Механика листа (форма `J`, u-only зависимость, насыщение с коленом `a ≈ 0.7`,
планарность шага, инвариантность in-loop/out-loop) — свойства объекта last-norm + head,
переносимые между GQA-Qwen и conv-LFM3. [И] Доменные эффекты и режимы зацикливания — свойства
конкретной модели и токенизатора: **направление** доменного контраста переносится (у обоих
носителей зацикливается прежде всего wiki, math — самый устойчивый), не переносятся количества
(13/16 против 10/16 документов с петлёй) и сила периодичности петли (AC(s) ≥ 3 у 89 % против 74 %).
[И] «Лист сам по себе предсказывает петлю» — отвергнуто на двух носителях; «в добавке листа к
тривиальным фичам нет ничего» на LFM3 не утверждается: `ΔAUC` = +0.088 выше порога 0.05,
отрицательный вердикт держится на `AUC_leaf` 0.763 < 0.8 и нулевой форе.

**Граница вывода.** Второй носитель один и другой архитектуры, но не другой размерности readout;
`r(s,a)` внутри петли и CI планарности живут только в stdout ядра (в JSON их нет — при следующем
прогоне P1 их обязаны писать в `verdicts`); кросс-модельное сравнение абсолютных `κ` заблокировано
§6 п. 26.

**Статус и следствие.** Все «инвариантные» числа поля J теперь разделены на переносимые
(механика) и непереносимые (домен/режим); заявки вида «наш метод работает для LLM вообще»
обязаны ссылаться на 4.11, а не на числа одной модели.

## 6. Ограничения и долги

Формат: «что → что блокирует».

1. [И] **Sample-local**: меж-сэмпловый пул Якобианов невалиден (E-0.1) →
   агрегация между моделями — только на уровне скалярных метрик; лист
   строится пер-сэмплом.
2. [И] **Gauge-направление зависит от контекста** (E-12a/b/c) и частично лежит в
   нуль-пространстве проектора (E-0.1) → направление нельзя использовать как
   handle; только разложение и метрики.
3. [И] **На L22–L23 часть $\rho$ коррелирует с p-прыжками** (Spearman 0.29/0.36)
   → интерпретация $\rho$ в этих слоях требует осторожности; p-фокус —
   отдельный сигнал (E-34).
4. [И] **Permutation p-values (B=1000) вычислены только для E-27.5/27.6 T4/T7 и
   E-6b** → для остальных экспериментов значимость не установлена; единственный
   каркас — bootstrap CI.
5. [И] **Sample-local Грамианы и sentinel gap = 1.000 — не измеряемые значения**
   (E-35, E-36); $P(p)$ не идемпотентна → «gap = 1.000» нельзя читать как
   «gap существует»; композиция уровней — нетривиальна.
6. [И] **Bridge-метрики exp16 и exp19 не сопоставимы** (разная сборка) → вывод P2:
   «негативно в исследованном диапазоне», не «в целом».
7. [И] **$lpha^*$ не определена** (knee не достигнут) → P2 нельзя дозировать

9. [И] **«Лист живёт в калибровке» — отклонено** → поле листа строится

12. [И] **E-6 L18 SNR вынесен из секций** → таблица r-скана (SNR = 2.803

13. [И] **τ = ℓ_p без оговорки** (локальный масштаб спада) → интерпретация

14. [И] **Mobility edge (Anderson)** — пространственная локализация; здесь —

16. [П] **Flat-null для ESG** — предупреждение: плоский спектр (E-27.6 T6)

17. [И] **E-39l: два независимых ограничения** → (а) обе серии монотонны по

    деградации $W_{lm}$) `ρ_res = 0` при наличии каузальной связи. E-39l отвечает

    «drift вызывает деградацию»; каузальный тест (drift-loss vs flatness-loss)

    исчез и носитель эксперимента.
18. [И] **E-39b/E-39f: границы PTQ-гейта (пять → шесть)** → (а) квантуется только readout
    (`gate.readout_channel_only`): в tied-weight модели квантование `lm_head.weight`
    меняет и `embed_tokens` (E-39c_pre: ≈80 % ущерба лежит в embed-канале), поэтому `pass` и `ΔPPL = +0.90%` относятся к readout-слайсу; полный tied-PTQ (E-39f) лист тоже не ломает, но каналы head/upstream в κ неразличимы: разрешение
    κ на этом корпусе ±0.0012 (п. 25), поэтому разложение ущерба принадлежит PPL, а не κ; (б) точен только L23 —
    на L6–L22 J readout-линеаризован (`synthetic_readout_j`), и их κ (0.0046–0.0098) не
    сравнимы с leaf-кривизной E-28 (κ(L6) = 3.96, κ(L22) = 1.56, разница в 3 порядка);
    (в) робастность листа частично — свойство метрики: κ есть функционал от
    Procrustes-углов топ-r базиса, инвариантный к амплитуде и гладким малым возмущениям
    M_K, то есть «12% ошибки веса → 0% κ» следует уже из определения κ; измеренные версии того же (амплитуда уходит при стоящем направлении; PPL +9.6 % при
    неразличимом κ) и честный пол E-39d — в карточках ref-exp;
    (г) `cos_ug_1k_proxy` (0.9171) — proxy $JJ^{\top}\mathbf{1}$, не exact $u_g$ из E-38f
    (0.862): разные объекты, не сравнимы; (д) на измеренных уровнях (int8, 4/3/2 бита) κ либо стоит, либо **падает** — ветка «κ растёт ⇒
    связана с PPL» не тестирована ни на одном уровне, а int8-RTN есть control, а не baseline;
    (е) null-модель E-39f перевернула ожидание ТЗ: κ на Haar-канале в разы **меньше** реальной,
    то есть û-канал структурирован. Числа и протоколы — карточки E-39b/E-39c_pre/E-39d/E-39f
    в `docs/ref-exp.md`.
19. [И] **Изотропный референс обязателен для «энергии, убитой оператором»** →
    любая доля вида `‖O·X‖²/‖X‖²` сообщается вместе с `‖O‖²_F/dim` и отношением
    `real/iso`, с явным указанием, что измеряется: норма оператора или свойство данных.
    Отдельная ловушка того же ряда: `‖OJ‖/‖J‖` (норма) и `‖OJ‖²/‖J‖²` (энергия)
    различаются квадратом — «98–99 %» E-33r было нормой там, где текст говорил про
    энергию; для одного оператора это три разные величины (норма / энергия / отношение к референсу — числа в §2.11)
    и число называют полным именем. Отношение `real/iso` читается как свойство данных только
    после null'а из п. 22.
20. [И] **При слове «gauge» указывать объект** → uniform-доля энергии `J` (`g_uni`,
    тождественна ESG `gauge_share` на том же `J`), операторная доля (`O1`), или направление
    (`uniformity`, `align`); значения — §2.5 и §2.11. Доля uniform-режима у `J^gf = P(p)J` тождественно нулевая
    (`P(p)·1 = p(1 − Σp) = 0`), поэтому «доля gauge», измеренная после `P(p)`,
    свидетельством не является.
21. [И] **Канальный фильтр `corr_f`** → `corr_f` (корреляция рангов K-логитов) — контроль
    интервенционного канала (ΔW): он отвечает на «редакция не сломала поведение». В
    natural/наблюдательном канале он запрещён: там возмущение обязано менять поведение,
    и `corr_f` становится исключением из выборки без основания (E-44-ТЗ §6 D2/D6).
22. [И] **Два null'а для любого «X предсказывает Y», где X — энергия `J`** → (а) изотропный
    `J ~ N(0,1)`: механический, показывает норму оператора и обязан давать отношение 1;
    (б) **dir-matched** — случайные направления при сохранённых нормах строк/позиций: только он
    отделяет структуру данных от структуры оператора и распределения норм. Читается второе
    отношение, `real / dir-null` (значение, срез и оговорки — §2.11; тренд по глубине идёт из норм
    строк, а не из направлений). Корреляция вида
    `ρ(энергия, поведение)`, не прошедшая через (б), неинтерпретируема.
23. [И] **Обобщение п. 22 на любой оператор:** величина вида `f(O, X)` (норма, доля энергии,
    производная от `OX`) обязана иметь оба null'а — **operator-null** (`X` изотропен при той же
    размерности: сколько `O` съел бы у случайного входа; отделяет оператор от данных) и
    **content-matched null** (`X` с сохранёнными нормами/маргиналами, рандомизированными
    направлениями; отделяет структуру данных от артефактов нормировки и агрегации). Для
    чисто-данных функционалов (без оператора) content-matched null всё равно обязателен,
    operator-null неприменим. Инстансы этого правила в данном футере — п. 19, 20 и 22
    (`g_uni`, `O1`, `R_can − R_raw`, `G(l)`, `frac_K_from_J`); **п. 21 инстансом не является**:
    он про применимость метрики к каналу, а не про нули, и из п. 23 не выводится.
    Дополнительное требование к обоим null'ам: отношение «реальное / null» считается на
    **одном и том же** срезе позиций, на полном объёме и на одном агрегате. В E-39-дополнении
    вариант «числитель по корпусу, знаменатель по 128 позициям» дал 0.63–0.70, вариант «обе стороны
    по 128 позициям» — 0.64–0.74, и только полный корпус с обеих сторон даёт 0.62–0.69
    (`docs/E39_supplement.md` §2.2, сноска, git-история).
24. [И] **Отношение — только со срезом и агрегацией:** любая тройка/отношение
    (`c, s, cos, frac_K`, `real/null`, `значение/референс`) публикуется с явными
    **срезом позиций** (`all` / `alive_non_sentinel`) и **агрегацией**
    (`ratio_of_means` / `mean` / `median` / `per_position`); `aggregation` —
    identity-relevant поле `ChannelTag`. Медиана отношения ≠ отношение сумм:
    тождество `frac_K = 1 − 2c + s²` держится только при общей агрегации (E6:
    смешение медианы и среднего дало фиктивное `s² < 0` в опубликованной таблице).
25. [И] **Разрешающая способность — часть результата, а геометрия κ — не прокси
    поведения в обе стороны.** (а) Тесты сдвига κ регистрируют paired-бутстрап по
    **разностям** (не пересечение независимых marginal CI), и DELTA_MIN сравнивают с
    разрешением **до запуска**: на этом носителе (N=32, S=128) парный CI сдвига κ равен
    ±0.0012 ≈ 7 % от κ (E-39f), поэтому DELTA_MIN = 1e-3 лежал на границе различимости;
    сдвиг ниже разрешения получает статус «not testable», а не «refuted».
    (б) Все четыре квадранта «геометрия × поведение» непусты: E-39d honest floor
    (κ −42 % при PPL +0.99 %), E-39f b3g128 (PPL +9.6 % при неразличимом κ), E-39d cheat
    и E-39b/f (целые κ при целом/разрушенном поведении). PPL не различает честное
    уплощение и перестановку рангов (+1 % против +1 %), различает только `corr_f`
    (0.999 против 0.594) — см. также п. 21.
26. [И] **`J` слоя 23 в кэше `exp27b` — суррогат** → продюсер кэша зовёт формулу финальной
    нормировки на её же выходе, поэтому все числа L23, посчитанные по кэшу (Δ_SVD 0.266,
    голономия 0.018, κ 0.0162 и все отношения «до/после» серии E-39) — характеристики этого
    оператора, а не модели: на настоящем `∂logits/∂h` тот же лист даёт 0.169 / 0.0106 / 0.0099
    (×0.64 / ×0.60 / ×0.61), то есть ещё плосче, а масштабно-инвариантные доли (`g_uni`, `O1/iso`)
    не двигаются дальше 3 % (E-38e). Отношения внутри одной серии от этого не страдают (один
    оператор в числителе и знаменателе), абсолютные величины — да; блокирует межмодельные
    сравнения абсолютного κ на L23, пока кэш не пересобран.

27. [И] **Нуль для «есть ли пик» — распределение максимума по частоте, а не высота на выбранном
    пике** → если `ω = argmax` выбирается по тем же данным, точечная σ смещена вверх: в E-40.3
    «локальный фильтр» давал σ = 4…6 на всех десяти ячейках при заведомо пустом сигнале, после
    переписывания нуля на `max` по ω не значимо ничего (p = 0.41…0.98) → блокирует любые
    заявления о периодичности/решёточной шкале без max-нуля; частный случай п. 22–23.
28. [И] **Ключ объекта — часть контракта; отсутствующая статистика обязана быть NaN, а не нулём** →
    в E-40.8 ключи `dom/i` против `dom#i` превратили столбец в NaN, `corr6` оставила такие пары
    нулями, и «не коррелирует ни с чем» стало вердиктом `R1`/`dead`; после нормализации ключей и
    fail-loud гейта вердикт стал `R3` → блокирует любые синтезы (6×6, PCA рамки, «кто из мер жив»)
    без явной сверки ключей носителя.
29. [И] **Метрика обязана быть сверена с определением до использования: нуль и положительный
    контроль — одной и той же функцией и на той же форме `(N, D)`, что и цитируемое число** →
    в E-7 «CKA ≈ 0» означал `‖H(XYᵀ)H‖²_F`, а не `tr(K_c L_c)`; у этой функциональности контроль
    лежит ниже нуля (0.284 против 0.329 при 64×128), а настоящий CKA на форме E-7 (N=5,
    D=2560×1024) даёт 0.99713 на нуле и 0.99790 на контроле, то есть динамического диапазона нет
    вовсе. Отдельно: нуль, снятый на другой форме (0.34 при 64×128 для чисел, полученных при N=5), —
    не нуль. Отрицательного результата мало: нужно ещё указать, при каком `N` метрика вообще что-то
    меряет — на посаженном общем факторе (кросс-D 2560×1024) превышение над null'ом разрыва
    соответствий составляет +0.020 (N=64), +0.066 (N=256), +0.179 (N=1024). Проверка дешёвая
    (секунды на CPU, без моделей) и обязана лежать рядом со скриптом:
    `exp7_cka_baseline.py --self-check` → `results/exp7_cka_selfcheck.json`.


## 7. Прикидки

Формат: гипотеза → какой результат что решит → стоимость.

1. [П] **Доза-кривая bridge дальше 100 шагов.** Гипотеза: knee существует при
   $\alpha^* > 0.3207$ (кривая выпуклая, knee вне исследованного диапазона).
   Результат: knee найден → P2 дозируем оптимально, bridge-лосс становится
   инструментом; плоская → P2 опровергнут для readout-редакции.
   Стоимость: ~100 шагов оптимизации (каш E-16a, ≈ ×2 вычислительный бюджет).
2. [П] **[M-4] pre-flight на cache E-33r.** Гипотеза: gap_min(t) мал в хвосте
   (спектр доминируется gauge-режимом), неабелев формализм неприменим.
   Результат: gap_min(t) > 0.01·σ₁² → снять moratorium, посчитать Ω(t) vs
   Σθ_j(t); иначе → подтвердить абелев предел. Стоимость: дёшево (cache
   есть).
3. [П] **Permutation p для остальных экспериментов.** Гипотеза: bootstrap CI
   достаточно для основных выводов; p добавляет значимость для
   E-27.5/27.6-класса результатов. Результат: какие выводы «значимы», а какие
   «CI содержит 0». Стоимость: B=1000 permutation на эксперимент — дорого,
   приоритет низкий.
4. [П] **Defrag r > 4 на метрическом уровне.** Гипотеза: fidelity при r > 4
   сохранится (схождение при r = 4), bridge сохранится. Результат: минимальный
   ранг для «defrag без потери метрик». Стоимость: пересчёт карт (дёшево,
   cache есть).
5. [П] **M-pinning (E-37) на других глубинах.** Гипотеза: pinning меняет
   геометрию листа только на L23 (W-слой). Результат: layer-specific ли
   эффект M-pinning. Стоимость: пересчёт cache на 2–3 слоях (умеренная).
6. [П] **P3 регуляризатор ($\mathcal{L}_{p3}$, §1).** Гипотеза: J-сближение
   сохраняет структуру при fine-tuning. Результат: P3 — из гипотезы в метод.
   Стоимость: не оценена (нужна fine-tuning-инфраструктура).
7. [П] **Межмодельная агрегация скалярных метрик.** Гипотеза: при sample-local
   оговорке (E-0.1) скалярные метрики (SNR, PR, ρ) сопоставимы между
   моделями. Результат: применимость метода к «модельному ряду» (цель ТЗ).
   Стоимость: не оценена (нужны новые модели).
8. [П] **Управление эластичностью L23-листа (серия E-39).** Гипотеза: плоский
   лист (κ → 0) снижает Goodhart: readout-редакция даёт drift без потери поведения
   и улучшает downstream (PTQ, distillation, long-context). E-39a (gate): surgery feasible в превью
   (κ' 0.0162 → 0.00030, 54×, r_eff = 178).
   **Статус (не пересказ §4.8): REFUTED, negative с механизмом, κ load-bearing** — ни один из трёх
   путей не проходит по операционализации κ<0.005 ∧ PPL≤+2 % ∧ KL<0.05; разбор и числа — §4.8 и
   ref-exp блок 4.8.

9. [П] **Пересчёт канонической линейки на позиционном базисе (exp27c).** Гипотеза:
   sentinel-ковариата E-40.3 (ρ = +0.29…+0.74, все десять ячеек положительны) — свойство
   частотного базиса U128, а не структура кривой по Δ. Результат: ковариата исчезает → числа
   §4.5/§4.9 остаются в силе на позиционном базисе; остаётся → «канон» привязан к базису readout
   и это надо писать в определения. Стоимость: новый jcache с per-position top-K (GPU, ~13 ГБ
   выходов, выгрузка датасетом), не «30 минут CPU».
10. [П] **`real/dir-null` на втором носителе (E-40.1 (m), пререгистрация).** Гипотеза:
    `real/dir` = 0.623–0.692 — константа системы, а не число кэша exp27b. Кандидат —
    `Qwen/Qwen3.5-4B` (профильщик exp27b его уже умеет). Исходы зафиксированы до прогона:
    попадание в 0.62–0.69 с перекрывающимся per-doc bootstrap-CI ⇒ в статью как константа,
    подтверждённая на двух носителях; иначе — остаётся числом одного кэша, слово «инвариант»
    не используется.
