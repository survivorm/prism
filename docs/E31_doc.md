## 3. Точный текст по блокам

### 3.1. Цель

Заменить текущую формулировку на:

> **Цель.** Измерить длину когерентности `ξ` поля `J` вдоль траектории и проверить гипотезу «нить vs лист». E-0.1 дал две точки (соседние пары), E-27.6 показал рост `C_a` с глубиной; полная кривая `C(Δpos)` даёт форму распада, а позиционно-разрешённая карта — локализацию разрывов, если они есть. Идеология: если поле — нить, `C` быстро падает; если лист — медленно.

### 3.2. Математика (NEW)

Добавить блок:

> **Математика.** Усреднённая кривая `C(Δpos) = E_t[cos(J_t, J_{t+Δpos})]`, где `cos` — **Frobenius-cosinus полной матрицы** `cos(J_t, J_{t+Δ}) = ⟨J_t, J_{t+Δ}⟩_F / (‖J_t‖_F ‖J_{t+Δ}‖_F)`. Конвенция отличается от E-0.1 («cos по строкам в порядке ранга» — другая величина, не используется). `Δpos ∈ {1, …, min(S−1, 32)}`. Среднее по всем допустимым парам внутри документа, где обе позиции не sentinel.
>
> **Второй срез.** `C_top-r(Δpos)` — косинус **max** главного угла между топ-`r` правыми подпространствами (`V_r ⊂ R^D`), `r = 16` (та же метрика, что в E-28: `max`, не `mean`/`RMS`). `V_r` — через `eigh(J_t J_t^T)`: `V_r = J_t^T U_r / σ_i`. Frobenius-когерентность полного `J` и когерентность топ-`r` подпространства — **разные объекты**, их расхождение — самостоятельный сигнал.
>
> **Форма распада.** Аппроксимация `C ~ exp(−Δ/ξ)` vs `C ~ Δ^{−α}`; выбор по AIC на медианной кривой (`AIC = n ln(RSS/n) + 4`, k = 2 параметра).
>
> **Позиционная конвенция.** В dense-кэше `t = 0` — последняя позиция, `t = 127` — первая; `Δpos` определён в кэш-t; при маппинге на границы предложений `seq_pos = S − 1 − t`.
>
> **Sentinel.** Пара `(t, t+Δ)` исключается, если хотя бы один конец — sentinel (`P128_RAW sum < 0.5`, конвенция E-34). Доля исключённых пар фиксируется.

### 3.3. Подводные камни (NEW, сжато)

> **Подводные камни (сжато из ТЗ).** (1) Sentinel-строки: `cos` с нулевой строкой не определён — пара исключается; доля исключённых отчитана. (2) Edge effects по `Δ`: для больших `Δ` мало пар — CI по сэмплам обязателен. (3) Пул `J` по сэмплам некорректен (`C_b ≈ 0` из E-0.1): `C(Δ)` — скаляр, per-sample сначала, потом медиана/IQR по 32 документам (протокол E-34). (4) `offset_mapping` — требование к данным; добавлен в `calibration.py`. (5) Сегментация по доменам: wiki/chat — `nltk.sent_tokenize`; code — границы `\n\n`; math — формулы как единицы. (6) Усреднённая кривая vs карта — комплементарные срезы (форма vs локализация). (7) Chunk-boundary гипотеза закрыта (test 5): периодичности κ на `t ≈ 31/63/95` нет — отдельная проверка не запускается.

### 3.4. Метод (расширить)

Текущее «метод (кратко)» → структурировать:

> **Метод.** Post-processing dense-кэша E-27 (`JR` — raw `J`; `P128` — нормализованный `p`; `P128_RAW` — для sentinel). Без GPU, без новых форвардов. Шаги: (1) модификация `calibration.py` → `save_offset_mapping=True`; (2) rebuild pool + проверка fingerprint побайтово vs кэш; (3) границы предложений по доменам → token-idx через `offset_mapping` (incremental decode + roundtrip fallback); (4) `vtop16(J)` через `eigh(JJ^T)` батчем (~5–10 с/док); (5) `C(Δ)`, `C_top-16(Δ)`, карта `C(t, 16)`, `seg_split(intra/inter)`; (6) `fit_decay` (exp vs power, AIC). Всё на CPU.

### 3.5. Pre-flight (расширить)

Текущая фраза «MAD-детектор (порог $> 1.5\bar{dP} + 3\mathrm{MAD}$), нашёл всего 4 пика, из них 1 у границы» **не соответствует коду**: код использует `median + max(2·1.4826·MAD, 1e-6)`. Заменить на:

> **Pre-flight (dP vs границы предложений).** Детектор: `dP(t) = ‖p_{t+1} − p_t‖` (P128, softmax-нормализация), порог `thr = median(dP) + 2·1.4826·MAD`; пик засчитывается у границы, если попадает в ±2 перехода. Результат по доменам:
>
> | Домен | Пиков | У границы | Доля |
> |---|---|---|---|
> | wiki | 2 | 1 | 0.50 |
> | math | 0 | 0 | — |
> | code | 2 | 0 | 0.00 |
> | chat | 0 | 0 | — |
> | **Итого** | **4** | **1** | **0.25** |
>
> Pre-flight **не пройден** в статистическом смысле (4 пика, 1 у границы). Сегментный срез всё же подсчитан: `C_intra(1) = 0.980–0.990` (L12–L23) — безразличен к границе, т.к. почти все пары `Δ=1` лежат внутри сегмента; `n_inter(Δ=1)_med = 1` пара/док — срез не значим.
>
> **Критерий разрыва карты** (`map16_breakpoints`): позиции `t`, где `C(t, 16) < median(C(·, 16)) − 3·1.4826·MAD`. Результат: `[]` на всех слоях — разрывов нет (при этом pre-flight не пройден, поэтому карта не интерпретируется как лингвистическая структура).

### 3.6. Результаты (таблица + две кривые)

Таблица уже есть — оставить, но добавить в подпись к таблице:

| **$\xi$** | Параметр экспоненциального распада $C \sim \exp(-\Delta/\xi)$. В E-31 формально > 100 на всех слоях (распад слабее окна $\Delta \le 32$). | §18 (E-31) |
| **$\alpha$ (степенной)** | Показатель $C \sim \Delta^{-\alpha}$. В E-31: 0.0004–0.080 (падает с глубиной); AIC предпочитает power-law. | §18 (E-31) |
