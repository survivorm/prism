## 1. C1 (δ не привязан к наблюдаемой) — ПРИНЯТО, верифицировано

TZ v1.2 §8/§19 задают δ без наблюдаемой, а P0-таблица в ответке r2
помечена «(L23, cos_raw)» — кодер, следующий §8+P0, считает δ на
cos_raw, а статистику на norm_delta. Масштабы (P0 r2): near 0.8681 vs
δ 0.1526 (×5.7); по δ-шкалам 1.1590/0.1526 = ×7.6. Под H0
`near_{norm_delta} ≈ 0.87 > δ_{cos_raw} ≈ 0.15` → S_phr срабатывает
всегда. Жёсткий флиппер подтверждён.

**v1.3:** каждый порог привязан к наблюдаемой своего контраста —
`δ_PHR/δ_far_PHR` → norm_delta, `δ_REP/δ_far_REP` → cos_raw — в §8, §11
и §19 (явная строка «смешанные наблюдаемые = флиппер»).

## 2. M1 (PHR — не эстиманд H_phr) — ПРИНЯТО, алгебра проверена

Базис (D_L, D_S, уровни строк m_L, m_S): `PHR_main = D_L + D_S`,
`INT = D_L − D_S`, **простой эффект `E_phr := L1 − L2 = 2D_L =
PHR_main + INT`** (тождества проверены символьно: `PHR_main + INT ==
E_phr` ✓, `PHR_main − INT == S1 − S2 = N_content` ✓, терм-непересекаемость
`{L1,L2}` vs `{S1',S2'}` ✓).

Режимы — как в таблице ревью: bag-of-words (D_L ≈ D_S ≠ 0) даёт
`PHR_main ≈ 2·D_S` → fires, но это не запоминание повторённой фразы.
С простым эффектом: `E_phr = 2D_L` в bag-режиме имеет **ту же шкалу,
что и N_PHR ≈ 2D_S** → near ≈ середина распределения нуля < p95 →
**не срабатывает** (правильно); в режиме запоминания (D_L ≫ D_S) →
fires. Тест теперь буквально спрашивает: «контентное различие больше,
когда контент повторён, чем когда перемешан?»

**Принято:** вердиктное количество H_phr = `E_phr = L1 − L2` против
`δ_PHR` (N_PHR). PHR_main → диагностика («контент по строкам в среднем»).
Дополнение (не спор): исключение bag-режима не структурное — firing в
bag-углу остаётся type-I (α ≈ 0.025); если fires без INTERACT_SIGNIFICANT
(INT ≈ 0) — чтение «контент (bag) эффект, порядок не установлен».
**Регрессионный тест:** новый синтетический сценарий 7 `bag_mode`
(D_L ≈ D_S ≈ шкала нуля, INT ≈ 0 → ожидаемо НЕ PHRASE_SPECIFIC).

## 3. M2 (путь провала гейта) — ПРИНЯТО, верифицировано

Текст v1.2 §11 шаг 3 дословно: «нерешённый контраст (шаг 2) → вердикт
по решённому + тег GATE_*» — при нулевом решённом ведёт в
`NO_2B_SPECIFIC_EFFECT`, который §17 читает как «ни содержимое, ни
периодичность» — отсутствие измерения как свидетельство отсутствия (A3).
**v1.3:** дерево разведено (в §11): оба протестированы и оба нулевые →
`NO_2B`; один нулевой + второй нерешён → `NOT_RESOLVED + GATE_N2/N16`;
один fires + второй нерешён → `<CHANNEL>_SPECIFIC + GATE_*` (чтение
вердикта не покрывает нерешённый канал).

## 4. M3 (слойный тег на n=16 для обоих) — ПРИНЯТО, верифицировано

Текст v1.2 шаг 6 дословно: «слойный тег (на n=16; … объединение
{REP, PHR})» — PHR (теперь E_phr) читается на дозе, где контент стёрт
(§9: r1 4.66 → r2 0.39 → r3 0.13 nat/tok). **v1.3:** тег per-contrast на
своей первичной дозе (E_phr@n2, REP@n16); объединение — только если оба
значимы на своих дозах; явная пометка «тег по точечной оценке
(near_C_L > δ_L(C), без CI) — наследие R2; в отличие от CI-правила
вердикта».

## 6. Минорные

- **m1 (коллизия сид-формулы) — принято, верифицировано:**
  `10000·1 + 1000·10 + 2 = 20002 = 10000·2 + 1000·0 + 2` ✓ (S1(doc10) ≡
  S2(doc0) @n=2; затронуты доки 10–13 между смежными i). **Фикс:**
  `default_rng(zlib.crc32(f"S{i}|{doc}|{n}".encode()))` — идиом G17
  (`docs/TZ_add_0-3.md`, идиом репо `exp64_P3_ladder.py`). **Уточнение:**
  без `% 99991` (полные 32 бита): с 112 сидами пространство 99991 даёт
  P(≥1 коллизия) ≈ **6.2%** (birthday), в 32 битах ≈ 1.5e-6. `% 99991` в
  репо — для малых пространств сидов; здесь — нет.
- **m2 (doc_idx не запинен) — решено м1:** имя дока **в самом сид-стринге**
  (`S1|wiki_0|2`) — индексу не нужна; таблица 14 имён (замороженный
  порядок R2) — в TZ §4 для манифеста.
- **m3 (двухрежимная оговорка) — принято, самокоррекция:** оговорка v1.2
  («порог схлопывается к нулю») — **остаток эпохи N_content**: для
  N_PHR = S1'−S2' (два независимых draw разных фраз) схлопывания нет —
  draw-шум всегда > 0. Реальный риск — σ_L vs σ_S (порог с S-строк
  занижает L-шум → анти-консервативен для обоих контрастов). **P0 r3
  (R2-store, L23), across-doc SD near-статистик:**

  | | SD(e_spec)/SD(e_null) | mean spec / null |
  |---|---|---|
  | n2 cos_raw | 0.756 | 0.0809 / 0.0896 |
  | n2 norm_delta | 1.220 | 0.8681 / 0.7538 |
  | n16 cos_raw | 1.023 | 0.1020 / 0.0840 |
  | n16 norm_delta | 1.470 | 1.2251 / 0.9737 |

  Не «≫»: max ×1.47 (для E_phr: ×1.22) → задекларировано в TZ §7.2 с
  числами; чек — прокси (e_spec смешивает вариацию филлера) — граница,
  не доказательство; частично покрывается p95-марином (порог — 95-й
  перцентиль near нуля, не среднее).
- **m4 (G14-координаты) — принято:** TZ §13 — каждое число в claim
  тагится (контраст, наблюдаемая, доза, слой).
- **m5 (сматчен-нуль) — принято, ПРИНЯТ (не «явно зафиксирован
  текущий»):** `N_perm := (S1 + S2 − S1' − S2')/2`. Проверено
  алгеброй: `Var = σ_S² = Var(REP)` при σ_L=σ_S (старый S1−S1': 2σ_S² →
  1.41× переконсервативен); **дополнительно** (моё, проверено): REP и
  N_perm **отрицательно коррелированы** через общие S1,S2
  (`Cov = −σ²/2`): высокий draw-уровень S-строк **одновременно снижает
  статистику и повышает порог** (оба в anti-firing сторону) — тест
  draw-робустен. (Уточнение к своему первому черновику: в
  `REP − N_perm` члены S1+S2 **не** отменяются, а удваиваются —
  «draw-парность» — через отрицательную корреляцию, не через
  сокращение.) Старый (S1−S1') — диагностика.
- **m6 (смета) — принято:** раздельно 224 + 140 = **364** (112 — до
  S2'), слитно 384. Вывод без изменений; число обновлено в TZ §18.
- **m7 (семантика S_shuffle) — принято:** в TZ v1.3 — **bug-guard**
  (fail-loud assert), одно слово, не «диагностика».
