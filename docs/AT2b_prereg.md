# AT2b (T2.1b) — пре-рег: центрированная state-readout клетка (disk-only)

Дата: 16.11. Статус: НЕИЗМЕНЯЕМО после записи (fix-до-прогона как в AT2-пре-реге).

**Исход:** AT2 (T2.1) — NOT_RESOLVED; внешнее ревью `docs/AT2_review.md` приняло гейты
и провал как «провал измерения», не свидетельство против T2; патч (раздел 10 ревью) +
находки r2-exec (`docs/AT2_review_answers.md` R2E-1…3) — объект этого пре-рега.

**Клетка T2.1b** (docs/AT2_results.md §5 + ревью §10): та же клетка (state h_l → readout
будущего логита), но: (1) **центрированная метрика** (устраним DC-пол: floor r1 =
0.9449–0.9456 выше всех readout 0.9279–0.9331, R² < 0 везде); (2) **k=0 контроль**
(посылка «weakly observable» — функциональная проверка разбиения top/weak);
(3) **настоящий Haar** (QR гауссиана) вместо Сильвестра (DC-строка 0, структурированные
строки) + **uniform-направление** + **DC-free варианты** базисов; (4) **DELTA_MIN +
METRIC_UNINFORMATIVE** (дерево r1 недостижимо: 96/96 парных CI исключают 0 при полосе
≤0.004); (5) **lk4: n per k + CI, non_informative** (one-hot cos = 0.0 на всех k —
вырождено по D3); (6) **N8 report-only** (интерпретация отложена — ревью F4).

## 1. Входы (disk-only, ноль новых форвардов)

Тот же кэш exp27b + модель, что AT2 (S1 — те же 7 sha, см. AT2-пре-рег §7):
`/data/prism_kernels/exp27b/results/exp27b_jcache_L{6,12,18,19,22,23}.pt`,
`exp27b_pool_ids_L23.pt`; `/data/Qwen/Qwen3.5-0.8B` (tied E, z-маршрут
z = H_L23 @ Eᵀ, без повторной нормировки). Пул: 32 дока (4 домена × 8), S=128.

## 2. Метрика (F2 — главная правка)

- Цель: `y = z_U128[d, :128-k, :]` (будущий логит, как в r1; k=0 → текущий логит).
- **Центрирование:** `ȳ_{d,k} = mean_t(y[d])` per (док, k); `y_c = y − ȳ`.
  X — **одинаковый пайплайн для ВСЕХ арм (включая `*_dc`)**: проекция на V →
  центрирование по t per (l,doc,S) на всём t=0..127 → срез [k:]. `*_dc` различаются
  **только базисом** (V vs V_dc) — одинаковая статистика на обеих сторонах сравнения
  (само-аудит правило 1; «без отдельного центрирования» из v1 пре-рега снято —
  неоднозначно).
- **Первичная:** `cos_c(t) = cos(pred_t − ȳ, y_t − ȳ)` per позиция → медиана по позициям
  (документно-медианная конвенция серии), отчёт per (l, k, S).
- **Floor (C2 — выбрано и записано; в центрированной метрике константный предиктор
  в cos даёт 0/0 — предиктор ȳ_d сам):**
  - *cos-метрика, первичный floor* = **uniform-random direction arm** (одна фиксированная
    случайная прямая, SEED=0): по изотропии cos_c ≈ 0; отчёт per (l,k) — **медиана +
    doc-bootstrap CI** (B=1000) — floor это полоса с неопределённостью, не одно число.
  - *R²-метрика, точный floor*: константный предиктор in-sample ⇒
    `R²_c = 1 − TSS_c/TSS_c = 0` (0/0 не возникает: TSS_c = Σ(y−ȳ)² > 0). Числовая
    проверка per (doc,k): |R²_c| < 1e-12 (гейт **S6b**).
  - R² readout-армов — по центрированному TSS (per-фолд, среднее), как в r1.
- Ridge: тот же (α=1.0, LOO-doc, 32 фолда), **правка R2E-1:** no-penalty на intercept —
  `A[-1, -1] -= ALPHA` (в r1 было `A[0,0]` — feature 0; latent, влияние ≈0, вердикт не
  менялся — зафиксировано в answers).

## 3. Базисы (F1, F7)

- **top/weak:** per (l,t), eigh(G), G = P^{1/2}(JRJRᵀ)P^{1/2}, lift + QR-реортонормация
  (как в r1).
- **pca:** per (l,doc), SVD центрированного H того же дока (как в r1).
- **haar:** **настоящий Haar — Haar-равномерный ортонормальный базис: QR(G),
  G ~ N(0,1)^{1024×r_final}** (глобальный). Генерация: ОДИН `rng_base =
  np.random.default_rng(0)` — сначала draw G (1024×r_final), затем draw uniform;
  знаки/базис QR детерминированы потоком (S9 smoke bit-identical закрывает
  LAPACK-зависимость). (Сильвестр из r1 убран из null-армов: строка 0 = DC,
  строки 1,3,5 — Ньют-квис/смешанные.)
- **uniform:** одна глобальная случайная прямая (Gaussian/норма, r=1) из того же
  `rng_base` после G — floor-референс (§2).
- **DC-free варианты (F1-фикс):** для каждого из {top, weak, pca, haar, uniform}:
  `V_dc = QR(V − (V·dc) dcᵀ)`, dc = ones(1024)/32 — арм `*_dc` (DC-компонента вычищена
  из базиса). Пайплайн X для `*_dc` — тот же, что для всех арм (§2): проекция на V_dc,
  затем центрирование по t; различие только в базисе (V vs V_dc).
- **Асимметрия объявлена (F7):** top/weak — per (l,t) из J-кэша; pca — per (l,doc)
  (unsupervised, на том же доке, утечки по y нет — «лучший unsupervised док-базис»);
  haar/uniform — глобальные. В артефакте: meta-блок `asymmetry`.
- d_eff rematching — как в r1 (r_final; ожидание 7).

В дереве вердикта участвуют 4 арма {top, weak, pca, haar}; uniform и `*_dc` —
контроли (не в вердикт), как ker-J/L23 в r1.

## 4. k=0 контроль (F3)

KS_RUN = (0, 1, 2, 4, 8). k=0: цель = текущий логит z[t], X = proj на всех t.
**Гейт SUBSPACE_CONTROL (обязателен до интерпретации k≥1; C1 — ОДНОСТОРОННИЙ):**
per-doc bootstrap (B=1000, SEED=0) CI `top − weak` на k=0; **pass = НИЖНЯЯ граница
CI > 0 на ВСЕХ 4 слоях** (AND-over-l):
`control_ok = all(ci_top_minus_weak[L][k=0][0] > 0 for L in LAYS)`.
Формулировка «CI исключает 0» **недостаточна**: отрицательный CI (top < weak) тоже
«исключает 0» (D2-артефакт r1) — отрицательный CI = разбиение top/weak
функционально перевёрнуто → гейт падает. Median Δ отчитывается per слой
(отдельным условием гейта не является — следует из lower > 0). Провал → вердикт
**`SUBSPACE_CONTROL_FAIL`**
(разбиение top/weak функционально не работает — k≥1 отчитывается, но не интерпретируется
как ответ на T2; это НЕ «ещё одна правка метрики» — T2.1 останавливать). Ожидание:
не пререгистрировано (50/50 — сам тест); оба исхода информативны.

## 7. Дерево вердиктов (F6 — DELTA_MIN)

**DELTA_MIN = 0.01** (пре-рег-выбор: 1% абсолютного уровня; на r1-полосе 0.004 всё
упало бы в METRIC_UNINFORMATIVE — честный исход, а не NOT_RESOLVED по формальному
признаку). **Нотация: `cos_median` в §7 — центрированная метрика cos_c из §2**
(ключ артефакта не переименован — зафиксировано в schema-поле `metric` артефакта;
review V1). Калибровка уровня по факту (review V5): артефакт отчитывает
`delta_min_calibration` — max парного разброса J-арм-медиан и ширина floor CI
против DELTA_MIN; если DELTA_MIN больше всей полосы — METRIC_UNINFORMATIVE
съест всё, и это видно в артефакте, а не по постфактумной догадке. Приоритет:
**control → (a) → (b) → (c) → (d) → NOT_RESOLVED**;
L23/ker-J/uniform/`*_dc` — контроли, не в вердикт.

- **SUBSPACE_CONTROL_FAIL:** гейт §4 не пройден.
- **(a) SCRATCHPAD (T2 жива):** на **≥2 из k ∈ {2,4,8}**: weak > max(pca, haar) —
  weak побеждает и pca, и haar per (l,k) **односторонне: нижняя граница per-doc
  bootstrap CI > 0** (win_ci, конвенция r1; «исключает 0» — не годится, C1),
  для ВСЕХ 4 l (AND-over-l), И median(weak − max(pca,haar)) > DELTA_MIN.
  **Почему ≥2 (review V3):** один k-уровень с noise effect-size+CI может дать
  ложный SCRATCHPAD (forking threshold без пре-рега); два независимых k-уровня
  (2/4 или 4/8 — разные горизонта будущего) — минимум подтверждения; ≥3 не
  выбрано (один прогон не имеет мощности на тройное подтверждение).
- **(b) DEADWEIGHT:** на ВСЕХ (l,k) ∈ {4 l × 4 k}: |cos_median(top)| ≤ DELTA_MIN
  И |cos_median(weak)| ≤ DELTA_MIN (J-арма не несут читаемого будущего — в
  центрированной метрике «не превосходит изотропный null» тождественно ≈0).
- **(c) REDUNDANT_BASIS:** на всех (l,k) все парные CI между {top, weak, pca, haar}
  содержат 0 И на k=1 top ≥ max(остальных) по медиане (без требования значимости).
- **(d) METRIC_UNINFORMATIVE (новая ветка, F6):** max по (l,k) max-парная
  |cos_median-разность| между {top, weak, pca, haar} ≤ DELTA_MIN —
  «статистически различимо, практически эквивалентно».
- Иначе **NOT_RESOLVED** (детали в артефакте). Смешанные случаи → NOT_RESOLVED с
  деталью (конвенция r1).

## 8. Gейты (до записи артефакта; провал = артефакта нет)

  позиций** (пул пре-регистрирован в AT2-пре-реге; scope 4.4e-08 — wiki_0 только).
  **Дополнительно в отчёт (не гейт):** KL на всех 32 дока×128 (мелкое-1 ревью: пул

- **S3** ориентация: hi (mean P(next-token), top1) > 0.1/0.1; flip lo < 0.05/0.05.

  НЕ пре-регистрирован; слово «пре-регистрирован» к нему не применять — ревью §5;
  r1: 0.381/0.490 vs lo 0.014/0.017).
- **S4** lk4-канон: 90/4096, per-домен 8/41/36/5.
- **S5** eig-закрытость: как r1 (32 (l,t), SEED=0; rel < 1e-9, lift-резидуал < 1e-6).
- **S6** P-zero (**реализован, R2E-3; C2 — assert на ВЕСА, не на cos**): ridge с
  нулевыми фичами (31 фолд, per k) ⇒ W_X = 0 (rel < 1e-10) И intercept = mean(y_f)
  (rel < 1e-10). **Не на cos:** в центрированной метрике нулевые фичи дают ŷ = 0-вектор
  и cos(0, y_c) — 0/0 не определено; assert «cos = референс» из r1 не переносится.
  (В r1 пре-рег был, реализации не было — зафиксировано в answers.)
- **S6b** R²-floor (C2): константный предиктор in-sample ⇒ R²_c = 0 per (doc,k);
  проверка |R²_c| < 1e-12 (см. §2 — floor R²-метрики).
- **S7** полнота (C3 — явная формула, отпечаток «заявленные фиксы ↔ реально
  посчитанные клетки»):

  KS = (0,1,2,4,8);  позиций на док = 625 = 128+127+126+124+120 = Σ_k (128−k)

  дошёл до per-position цикла; если len не сверяется с формулой — новый арм потерян.
  Артефакт явно отчитывает (review V4): `S7_expected`, `kerJ_in_per_position: false`,
  `kerJ_in_verdict: false`, `k`, `arms_main`, `arms_L23` — сверка «заявленные фиксы ↔

- **S8** trackio: run `at2b_t21b_r1`; t=0 config (started_at ISO, device=cpu, model,

## 10. Цена

Загрузка ~15 с; eigh per (l,t) 3–8 мин; PCA 2–4 мин; ridge: 4 l × 5 k × 10 арм ×
32 фолда × мелкие r×r-солверы ≈ 12–18 мин (r1: 295 c на 4 арм×4 k); lk4+bootstrap —
минуты. **Итого ≈ 20–35 мин CPU** (4 тр.), пик памяти ~11 G (z_full + p_soft ≈ 8 G).
Один прогон; перепуск — только по гейтам/крашу.

## 11. Ожидания (не гейты)

- k=0 гейт: не пререгистрировано (сам тест; оба исхода информативны, §4).
- Дерево: с центрированием динамический диапазон восстанавливается (floor→0);
  исход один из {SCRATCHPAD, DEADWEIGHT, REDUNDANT_BASIS, METRIC_UNINFORMATIVE,
  NOT_RESOLVED} — дерево теперь достижимо во всех случаях (DELTA_MIN).
- Haar/uniform ≈ 0 в центрированной метрике (изотропия) — контроль на артефакте.
- PCA r1-эффект (proигрыш фиксированному хаару) должен исчезнуть, если он был
  DC-артефактом (F7).
