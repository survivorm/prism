## B1 — sham-дисперсия: PRINATO (утверждение), частичное возражение (величина)

**Принято:** формулировка r2 «дисперсия draw к draw мала (изотропия)» —
математически неверна. Изотропность даёт несмещённость среднего
(E = k/D), не малую дисперсию: Beta(k/2,(D−k)/2), per-t rel-разброс
70.5% (k=4, D=1024). Ревью-требование «измерить, НЕ предполагать» —
выполнено (P0.1, 200 draw × 8 дока × 5 слоёв, окно t<64):

```
L   mean      theo     sd_pooled  sd_within_doc  sd_between_doc
L6  0.00385   0.00391  9.99e-4    8.21e-5        2.89e-5
L12 0.00400   0.00391  1.12e-3    1.09e-4        4.40e-5
L18 0.00387   0.00391  1.13e-3    9.40e-5        5.12e-5
L22 0.00388   0.00391  1.29e-3    1.25e-4        6.01e-5
L19 0.00391   0.00391  1.28e-3    9.40e-5        4.44e-5
```

**Частичное возражение — величина эффекта:** расчёт мощности в ревью
использует per-t sd (0.002754) для doc-уровневого E. Но doc-уровневый E
усреднён по 64 позициям окна (в pre-study/метрике — по 64..127 значениям):
измеренная per-doc draw-дисперсия = **8.2e-5–1.25e-4**, т.е. в 22–33 раза
меньше per-t (√64-подавление, как и предсказывает усреднение). В ΔCE-
единицах (|c| = 12.93): **1.1e-3–1.6e-3** vs doc-bootstrap SE 5.1e-3 —
вторичный (~6% дисперсии) источник, не «ожидаемый эффект 0.6 sd» (реальное
отношение: 0.023/1.6e-3 ≈ 14 sd per-doc; для 32-doc агрегата shared-
фрейма: 1.6e-3/√32 ≈ 3e-4 → ~77 sd). Критерий ревью «|c|·sd > 0.5·effect
⇒ редизайн» выполнен по замеру — НЕ срабатывает (1.1–1.45× по sd_pooled —
граница; по per-doc — запас в 7–13 раз).

**Тем не менее fix принят полностью** (per-doc фреймы, r3 §2): (а) это
делает CI корректными по построению (draw-дисперсия в бутстрапе, а не
снаружи) — структурно правильный дизайн независимо от величины; (б)
защита от c > 12.9 (c гуляет 7.3…23 по армам; при c=23: 1.25e-4×23 =
2.9e-3 — всё ещё < SE, но перестраховка бесплатна); (в) цена нулевая
(фреймы генерируются из сидов, форварды те же).

- «Энергия объясняет 80% вариации ΔCE» — подтверждено; «весь заявленный
