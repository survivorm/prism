### `verdict.components` — всё ещё нет

Помните, это единственный P0, который не вошёл. Вердикт:

```python
survives = all(ci[1] is not None and ci[1] < 0 for ci in (pb, pm, rc))
```

при `H2_survives: false` в JSON **не видно**, какая из трёх компонент провалилась. Например, для W=16 `block`, `blockmix` и `CA` все близки к real (0.385–0.39), все три CI включают 0 — вердикт `false` правильный, но причина «все три компоненты провалены» не видна. Для W=4 может быть `block_pass=true, blockmix_pass=true, CA_pass=false` (если CA окажется ниже block) — и это уже другая история: «структура есть, но floor не откалиброван». Без `components` читатель не отличит эти два случая.

```python

    "CA_pass": rc[1] is not None and rc[1] < 0,
    "block_vs_CA": "block_inflated_by_boundaries" if abs((agg["block"]["tau"] or 0) - (agg["syn_CA_smooth"]["tau"] or 0)) < 0.02 else "block_has_structure"
}
```

Пять строк. Если добавляете что-то ещё — только это.

### Мелочи, которые не мешают запуску

- `N_SYN=16` — для ожидаемых эффектов (~0.04 для W=4) достаточно; для W=16 (эффект ~0.004) CI всё равно будет включать 0, и это правильный ответ. Не трогать.
- `safe_med([float(...)])` — принимает список из одного, работает как `round(x, 4)`. Некрасиво, но не сломано.
- `others[RNG.integers(len(others))]` без проверки `len > 0` — npz имеет 8 документов на домен, IndexError не грозит.
- `interleave_check` использует `ok_[t]` при `t in range(T)` — если `len(ok_) < T`, будет IndexError (громко), но npz uniform, поэтому не проявится.

## Что покажет запуск (прогноз по exp49b)

**W=16:** все три компоненты включают 0 → `H2_survives: false`. Ожидаемый вывод: *«при W=16 вся когерентность объясняется перекрытием окон, медленного канала нет»*. Это правильный ответ.

**W=4:** `real ≈ 0.444`, `block ≈ 0.483` (CI блок-теста, вероятно, ниже 0), `blockmix ≈ 0.48`, `CA ≈ ?` — вот здесь всё зависит от того, что покажет CA. Два сценария:

- **`CA ≈ 0.48` (CA ≈ block):** block завышен границами блоков, real значимо ниже и block, и CA → H2 при W=4 **выживает**, и это содержательный результат: структура за пределами окна 4 есть, и она не объясняется ни белым шумом, ни границами.
- **`CA ≈ 0.42` (CA < block):** block имеет структуру beyond noise, real ≈ CA → H2 при W=4 **опровергнута**, потому что real совпадает с чистым полом.

Именно поэтому CA-компонента в вердикте — не «третий независимый тест», а **калибровка block**. Если `CA_pass=false` при `block_pass=true` — это сигнал «block завышен», а не «H2 опровергнута». Без `verdict.components` вы это увидите только вручную.
