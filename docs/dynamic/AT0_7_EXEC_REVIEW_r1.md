## Резидуальные риски исполнителя — принимаю/отклоняю

- (a) **H5 R-диапазон [2.88e-31, 3.66e-30] vs r0 [2.5e-32, 3.5e-30]** — **ПРИНИМАЮ**. Мой независимый
  пересчёт воспроизвёл [2.8847e-31, 3.6603e-30] в bit-совпадении с claim; независимый пересчёт r3-ревью дал
  тот же диапазон — т.е. r2-якорь [2.5e-32, 3.5e-30] — outlier (порядок суммирования/резиды fp64). Оба
  диапазона ≪ 1e-20 ⇒ алгебраическое тождество подтверждено; субстантивно разницы нет (косметика К3 —
  пометка r0_expected).
- (b) **ρ_s = 0.4947 близок к 0.4 (n=30, descriptive)** — **ПРИНИМАЮ** с пометкой. Gate объявлен ТЗ как
  descriptive (не pre-reg-порог 5%); воспроизведён пересчётом в <1e-11; при n=30 разброс ρ_s велик
  (≈1/√n), запас 0.095 — умеренный. Интерпретация «h-линия следует за repeat'ом» — описательная,
  вердикт на неё опирается как на согласующее (H1 — primary).
- (c) **p_perm 30/30 на полу 1/200** — **ПРИНИМАЮ**. n_ge = 0 для всех 30 (независимый пересчёт);
  Q_obs = 1.9e4…7.6e4 при E[Q] = D = 1024 — эффекты на 1–2 порядка сверх нуля, пол 1/200 — предел
  разрешения B=199, не «все значимы на грани». p_perm здесь — вторичный канал (основное — Q vs maxrun/
  rep_frac), что соответствует T0.6-конвенции.
- (d) **пин v2.2 vs WIP v3 в репо** — **ПРИНИМАЮ с фиксом-формулировкой (M1)**. Пин byte-верифицируемо =
  v2.2-эра (blob 7bef68b; код v2.2 a601edc + 1 docstring-строка), формулы Q/null/сиды = v2.2 (30/30
  пересчёт). Угроза «чужая сессия переписывает AT0_6» исключена архитектурно: WIP-файл не импортируется
  (`sys.modules["AT0_6_spectrum"]` = пин до импорта core/tests), sha-ассерт в main.
