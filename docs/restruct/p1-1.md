2. **§8 «Карта доказательств» должна быть генерируемой.** Рукописной она станет четвёртой копией вердиктов — та же болезнь v4.0 (карточки/§20/B.1). Рукописное место обратной ссылки — одна строка в карточке; §8 строится из них скриптом.
3. **Обратная ссылка — список секций, не один блок.** E-16a/b питают §4.8, §5 (опровергнуто), §6 (Goodhart) и §7 (многоточечная метрика).
