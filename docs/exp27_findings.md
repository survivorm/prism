## 5. Корректировки (баги v10)

5.1 Truncation test 6.2 **невалиден**: S128 pair(64,65) == S64 pair(0,1)
до float-noise (|diff| < 3e-7) — causal attention: pos64@S128 видит
токены 0..63 = ровно pos63@S64. Тест измерял тождество, а не truncation.
Заменён в v11 на pair (32,33)@S128.
5.2 Math-пул **дегенерирован**: 8 сэмплов = 2 уникальных текста
(окно 320 слов, сдвиг 200 → 120-словный overlap + truncation к 256).
Дубли: si 0-3,5,7 ≈ идентичны, si 4,6 ≈ идентичны. C_b math ≈ 0.5–0.9
доминирует → C_b baseline завышен. Fикс v11: шаг сдвига 320 (без overlap)
+ dedup. Требует полной перегенерации math-пула (новые J на всех
math-позициях — wiki/code/chat переиспользуются из ckpt v10).
5.3 S=128 dip — **реальный** (все 6 слоёв), не артефакт одного слоя.
5.4 C_b verdict «COHERENT» — **артефакт 5.2**; честный C_b = WEAK/ORTH.
