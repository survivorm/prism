# AT0_8 (T8.1) — пре-рег «Пороговое возбуждение» (TЗ docs/TZ_add_4-8.md §8, v1.5)

**Клетка:** T8.1 «Multi-observable threshold» — решает статус «солитона»: либо снять слово
«солитон» из заголовков (генерическая компетентность), либо дать ему первый настоящий
аргумент (λ_c^dip отделён). T8.2 — только при «кандидат жив»; T8.3 — требует T2.2 (волна 3)
и сырых h-вставок E-71B (на диске нет) — оба НЕ в этой клетке.

## 1. Что меняется против E-71 (version break — объявлен)

| E-71 (audit2, 11.11) | AT0_8 (T8.1) |
|---|---|
| сетка 0.1 (11 точек) | сетка T8.1 11 точек + 2 точки T9.1 = **13** (общий прогон) |
| 8 wiki-доков | **6** wiki (TЗ) + **4 holdout** (math/code/chat) |
| dip + nll | **9 наблюдаемых** + health ray + генерация |

| артефакт `results/e71/SOLITON.json` | **нет на диске** — контекст E-71A по TЗ §8.2 (citation: dip ≈0 до
  λ=0.5 (−0.005), взрыв 0.6→0.7 (−0.045→−0.207), плато −0.22; красный флаг: dip(0.7)
  глубже финального −0.174 на 19%). Числа E-71 НЕ пересчитываются и в артефакт не входят. |

Оба λ=0 различаются: E-71 FIX-λ=0 — все параметры случайны (FIX audit2 B2 уже включал 1-D);
AT0_8 λ=0 — та же формула `randn·std`, но **другой сид-набор и модель-состояние** (новый
прогон). Старый артефакт недоступен ⇒ сравнение bit-в-бит невозможно; версия разрыва
зафиксирована строкой.

## 2. Модель и среда

- `Qwen/Qwen3.5-0.8B` (tied weights), dtype fp32, `.eval()`, `torch.set_grad_enabled(False)`.
- Локальный путь: `/data/Qwen/Qwen3.5-0.8B`; Kaggle: `AutoModelForCausalLM.from_pretrained("Qwen/Qwen3.5-0.8B")`.
- Лёгкая загрузка `sd0 = {k: v.clone()}`; интерполяция `W(λ) = λ·sd0[k] + (1−λ)·sd_r[k]`
  через `copy_` (одна модель-оболочка, веса перезаписываются — паттерн exp71).
- `sd_r[k] = torch.randn(v.shape, generator=Generator().manual_seed(seed)) * v.std()` —
  **ВСЕ тензоры, включая 1-D** (RMSNorm gain, bias — если есть). Гейт S2b проверяет.
- Слой для h: **L23** (output последнего слоя, как в exp71/E-64 батарее). layer_types —
  полный список из config (24 слоя) в артефакте (волна 0 TЗ).
- Устройство: смоук — CPU (conda py3.12.9 torch2.14.1); полный прогон — Kaggle T4 GPU fp32
  (`m.cuda()` если cuda доступен; device=cuda в артефакте; числа не сравниваются с CPU-прогоном).
  **Тorch-fallback (без fla/triton) — референсный путь серии (AT0_4): единый на смоук и Kaggle —
  численная согласованность операций между прогонами.** 4 CPU-треда (OMP/OPENBLAS/MKL=4 ДО импорта
  torch, AT0_4-конвенция).

## 5. Наблюдаемые (определения, фиксированы)

Агрегация док→кривая: **медиана по 6 main-докам** (дип-конвенция exp71: dip_med = median).
Для holdout-наблюдаемой — медиана по 4 holdout-докам.

| наблюдаемая | семейство | определение |
|---|---|---|
| dip | field | `curves_series(h23[0:T])["dip"]` = c[0] (lag-1), функции **пин**: `experiments/kaggle_e64gpu/e64_gpu.py` sha256 `8c517e18f801fa877dfde9265ed5ce18df1e7d3af705194fc01ff6b150cf7633` (dcurve/vpath_units/curves_series, вычитаются из исходника, exec; гейт S7) |
| hump | field | то же `["hump"]` = max(c[1:8]) |
| plateau | field | то же `["plateau"]` = median(c[8:]) |
| nll_main | (не в наборе, контекст+гейт S4) | средн. CE по позициям t≥1, teacher-forced, в каждой записи |
| nll_holdout | semantics (одиночное) | средн. CE по 64 позициям каждого holdout-дока → медиана 4 доков |
| margin | (одиночное) | медиана по позициям t≥1 (top1 − top2 logit) → медиана 6 доков |
| pr_sigma | leaf | SVD(h23[0:T]) (float64): (Σσ²)² / Σσ⁴ → медиана 6 доков |
| eff_rank | leaf | SVD(h23[0:T]) (float64): exp(−Σ p·ln p), p = σ²/Σσ² (positive part) → медиана 6 доков |
| rep16 | mode | генерация: доля 16-окон **без перекрытия** (i=0,16,32,…; окно <16 — не считается) с <12 distinct токенов, по prompt+gen токенам |
| loopy | mode | генерация: 1{max_{k=2..min(95,⌊(T_all−1)/3⌋)} c_k > 0.95}, где c_k — ACF-кривая той же curves_series-машины (vpath-единичные шаги h23 по всем prompt+gen позициям, median по t); c_1 (dip) исключён — dip = ритм, не луп (конвенция exp64: `max(curves_k1_96[1:]) > 0.95`) |

**Генерация (rep16/loopy):** prompt 32 ток. (wiki_0[:32]), greedy (T=0), до T_gen=256
сгенерированных токенов или первого EOS (stop); KV-cache (DynamicCache, паттерн e64_gpu.py).
T_act < 32 ⇒ флаг `degenerate_short` (rep16/loopy считаются, если T_prompt+T_act ≥ 17,
иначе None + флаг). Детерминизм: greedy, без RNG (сид-зависимость только через веса).
Человекочитаемый sample: `decode(prompt+gen)` в каждой записи (λ,сид) (health ray §9.6).

**Кривые:** O(λ) по (λ,сид) = агрегированное значение; кривая seed-avg = среднее по 3
сидам. u(λ), монотонность, λ_c — по LAM11.

## 6. Машина λ_c (фиксирована ДО прогона)

Для каждой наблюдаемой O (по LAM11, per seed):
1. `u(λ) = (O(λ) − O(0)) / (O(1) − O(0))`. Если |O(1) − O(0)| < 1e-6·max(1,|O(0)|,|O(1)|)
   ⇒ исход `no_range` (λ_c не определено).
2. **Переход:** первый индекс j, где `u(λ_j) ≥ 0.5 И u(λ_{j+1}) ≥ 0.5` (персистентность:
   удержано ≥2 соседних точек сетки) ⇒ `λ_c,seed = λ_j`. Нет такой пары ⇒ `no_transition`
   (вкл. случай u(1)<0.5 — но u(1)=1 по определению при range>0, так что это = «нет
   удержанного перехода до конца»).
3. **Оvershoot:** `max u > 1` ⇒ флаг + argmax. (Для dip: dip(λ) глубже обоих концов.)
4. **Монотонность (критерий ДО прогона, v1.4):** `|Spearman(λ, O)| ≥ 0.9` по seed-avg
   кривой (LAM11). Не прошла ⇒ `excluded_non_monotone[]` (+ значение ρ); исход наблюдаемой
   `non_monotone_excluded` (НЕ молчаливый дроп).
5. **CI:** по 3 сидам λ_c,seed: `[min, max]`. Разброс max−min > 1 шага (локальный шаг
   сетки в точке) ⇒ `not_resolved`.
6. **Бисекция** (уточнение, seed-avg кривая): j0 = первый индекс, где u_seedavg(λ_j0) ≥ 0.5
   (всегда существует: u(1)=1); интервал [λ_{j0−1}, λ_{j0}] (для j0=0 — [0, 0.2]) сужать вдвое
   до ширины ≤ 0.02 или ≤5 итераций. Точки бисекции — **union по наблюдаемым** (порядок:
   dip → nll_holdout → eff_rank → loopy → margin → hump → plateau → pr_sigma → rep16),
   **кап ≤ 6 точек** (при превышении — флаг `bisection_capped=true`, ширина может остаться
   > 0.02; вердикты — по coarse-сетке, бисекция — уточнение). Одна пара форвардов
   (λ_b, сид) считается на все наблюдаемые.
   Результат: `lambda_c_refined` (report-only; вердикты — по coarse λ_c, как в TЗ:
   «совпадают/отделён» — в шагах сетки).
7. **Вторичная статистика (не входит в вердикты):** `u_exit` — первый λ, где
   |O_seedavg(λ) − O(0)_seedavg| > 2·σ_null, σ_null = std O по 3 сидам при λ=0.
   (405×-расхождение u_exit между наблюдаемыми ⇒ только вторично.)

**Сравнения (фиксированы):**
- «Совпадают» ⇔ |λ_c^i − λ_c^j| ≤ max(локальный шаг в λ_c^i, локальный шаг в λ_c^j)
  И CI [min,max] пересекаются.
- «Отделён» ⇔ |λ_c^i − λ_c^j| ≥ 2·max(те же шаги) И CI не пересекаются.
  Bonferroni: α = 0.05/4 (4 пары dip×{nll_holdout, eff_rank, loopy, margin}); per-seed
  sign-test (все 3 сида показывают отдалённость ≥2 шага) — p_raw = 0.125, p_bonf = 0.125/4
  = 0.03125 — отчитывается; при n_seeds=3 порог 0.0125 недостижим ⇒ «отделён» опирается
  на геометрический критерий (TЗ), p — вторично. Зафиксировано ДО прогона.
- Семьи (≥2 члена): field {dip,hump,plateau}, leaf {pr_sigma,eff_rank}, mode {rep16,loopy}.
  `family_intra_consistent` — все пары внутри семьи «совпадают». Одиночки (nll_holdout,
  margin) — внутрисемейный тест вакуумен (G10), участвуют в межсемейном сравнении.

## 7. Вердикты (приоритет V3 > V2 > V1 > V0)

- **V3 PATHOLOGY:** `u_dip(0.7) > 1` (dip(0.7) глубже dip(1)) И `rep16(0.7) > rep16(1)`
  (seed-avg) ⇒ «порог = патология (overshoot + вырождение генерации), переинтерпретация;
  слово «солитон» не подтверждается». (TЗ: «overshoot на λ=0.7 сопровождается rep16 выше
  нормы ⇒ патология».)
- **V2 SOLITON_CANDIDATE:** λ_c^dip `отделён` (по §6) от ≥1 из {nll_holdout, eff_rank,
  loopy, margin} ⇒ «кандидат жив → T8.2» (только на прямой интерполяции, не на обучении —
  оговорка обязательна).
- **V1 GENERIC_COMPETENCE:** λ_c^dip `совпадает` с ВСЕМИ четырьмя выше И все resolved
  наблюдаемые совпадают в ≤1 шага с CI-пересечениями ⇒ «генерическая компетентность;
  слово «солитон» снимается».
- **V0 NOT_RESOLVED:** dip ∈ {non_monotone_excluded, not_resolved, no_range,
  no_transition} ⇒ «не-вердикт, причина: <исход>» (отдельные исходы других наблюдаемых —
  в артефакте, на вердикт не влияют).
- Mixed (dip совпадает с некоторыми и отделён от других, но не ≥2 шага от ни одного) ⇒
  V0 NOT_RESOLVED с деталью (зафиксировано: смешанный случай — не-вердикт).

## 8. Гейты (до записи артефакта; провал = артефакта нет)

- **S1** config: num_hidden_layers=24, hidden_size=1024, vocab — в артефакте (layer_types
  полный список); модель загружена fp32.
- **S2** λ=1: SHA256 каждого тензора state_dict == SHA256 соответствующего тензора base
  (побитово исходная модель) — проверяется в каждой (сид, λ=1) записи.
- **S2b** λ=0: для каждого тензора: `max|sd_r − sd0| > 0`; крупные (n≥1024):
  |mean| < 3·std/√n и std(sd_r)/std(sd0) ∈ [0.8, 1.25]; мелкие (n<1024: dt_bias/A_log —
  MC-шум std велик): std-отношение ∈ [0.5, 2.0] (mean-проверка на мелких статистически
  неосмысленна — MC-шум mean ~ 1/√n; случайность гарантируют max|diff|>0 + std-отношение);
  отдельно: (а) все 1-D тензоры прошли (count 1-D и мелких — в артефакте),
  (б) **shape-дубли не идентичны** (A_log во всех linear-слоях и пр. — разные случайные
  значения; генератор per-ключ с сидами seed·1000003+idx). (Сверка state_dict по norms — TЗ §8.7.)
  **Tied weights:** `embed_tokens.weight` ≡ `lm_head.weight` — один storage под двумя ключами
  (измерено: data_ptr равны, tie_word_embeddings=True; 321 ключ = 320 тензоров + 1 dup).
  set_interp копирует в него два значения из sd_r — детерминированно выигрывает последний
  по порядку state_dict (embed); модельный λ=0 рандомизирует единый тензор (tied —
  свойство архитектуры, не дефект). S2 (λ=1) — оба copy_ из одного sd0-тензора, побитовость
  не страдает.
- **S3** полнота: множество ключей store == ожидаемое (LAM13 × SEEDS × (docs+gen)) —
  **точное равенство множеств, не truthiness**; resume — по ключам (скип готовых),
  финальный гейт — полнота.
- **S4** nll_main ≠ null в каждой doc-записи; nll_holdout ≠ null в каждой (λ,сид) записи.
- **S5** dip/hump/plateau finite; pr_sigma ≥ 1; eff_rank ≥ 1 (в каждой doc-записи).
- **S6** disjoint: S6-assert (домены + 16-ток. префиксы) + holdout-имена ∩ main-имена = ∅.
- **S7** sha256 e64_gpu.py == `8c517e18f801fa877dfde9265ed5ce18df1e7d3af705194fc01ff6b150cf7633` — до exec функций.
- **S8** health ray (dip_band_hinge, loopy, nll_holdout) + человекочитаемый sample — в
  каждой (λ,сид) записи. `dip_band_hinge = |dip_med(λ) − dip_med(1)|` (тот же сид).
- **S9** бисекция: width ≤ 0.02 или итераций = 5; точки бисекции ⊂ LAM13 ∪ bisect-сетки;
  все bisection-форварды в store.
