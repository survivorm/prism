  статус пайплайна — это статус `tail` (всегда 0, `set -o pipefail` нет) ⇒ else-ветка с

  Серьёзность: косметика (мёртвая ветка + вводящий в заблуждение комментарий).
  Чинить (опционально): `"$PY" -c … > /tmp/_rev.txt 2>&1; rc=$?; tail -2 /tmp/_rev.txt; if [ $rc -ne 0 ]; then echo "!!! …"; fi`.
