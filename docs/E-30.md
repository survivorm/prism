# E-30. Mode decomposition: где сидит остаточный ρ_gf

## Цель и идеология

E-34 дал `ρ_gf ≈ 0.06` (абсолютно мало) и `ρ_gf/ρ_null` = 0.98 (L6) → 3.61 (L23) — по абсолютному порогу первый порядок диагонален, по относительному gauge-free cross-talk статистически отличим от нуль-модели начиная с L12. Открытый вопрос: **какая часть `ρ_gf` сидит в топ-2..5 модах ESG (структурный остаток), а какая — в хвосте (распределённый)?** Ответ определяет, идёт ли `ρ_gf/ρ_null` из readout второго порядка (E-32) или из распределённого первого порядка, где per-token защита в первом порядке частично сломана.

Идеология: чистая линейная алгебра, без Гессиана. Если хвост мод несёт >50% `off²(A)`, «диагональность первого порядка» — это артефакт агрегации, а не структура.

## Математика

**Объект.** `A = P(p)·ESG·P(p)`, где `P = diag(p) − ppᵀ`. Собственное разложение ESG: `ESG = Σ_k λ_k u_k u_kᵀ`, `λ₁ ≥ λ₂ ≥ …`.

**Кумулятивная кривая ρ_gf(r).** Для `r ∈ {1, …, K}`:

```
ESG_r   = Σ_{k≤r} λ_k u_k u_kᵀ              (топ-r усечение ESG)
A_r     = P · ESG_r · P                     (усечение коммутирует с P)
off²(r) = ‖A_r‖_F² − ‖diag(A_r)‖_F²
ρ_gf(r) = √(off²(r) / (K−1)) / ‖diag(A_r)‖_F
```

При `r=K` воспроизводит `ρ_gf` из E-34. `ρ_gf(r)` — неубывающая по построению (off² аддитивна по модам, но не линейно; кривая может быть немонотонной из-за сокращений кросс-членов, что само по себе сигнал).

**Приращение по моде.**

```
Δoff²(r) = off²(r) − off²(r−1)
Δρ_gf(r) = ρ_gf(r) − ρ_gf(r−1)
```

**Индекс концентрации.** Participation ratio приращений `w_r = Δoff²(r) / off²(K)`:

```
PR_modes = (Σ_r w_r)² / Σ_r w_r²  = 1 / Σ_r w_r²
```

`PR_modes = 1` — весь cross-talk в одной моде. `PR_modes ≫ 5` — распределён по многим. Порог решения: `PR_modes ≤ 5` — структурный остаток, `PR_modes > 15` — распределённый, между — неоднозначно.

**Нуль-модель per-r.** Для усечённого `ESG_r` диагональ `diag(ESG_r)_i = Σ_{k≤r} λ_k u_k[i]²` меняется с `r`. Нуль-модель пересчитывается на каждом `r` тем же batched-методом, что в E-34:

```
ρ_null(r) = E_Q[ρ(Qᵀ diag(ESG_r) Q)]
```

Два режима отчёта:
- **Абсолютный:** `ρ_gf(r)` — кривая роста.
- **Относительный:** `ρ_gf(r) / ρ_null(r)` — растёт ли сигнал быстрее нуль-модели с `r`.

**Альтернативная декомпозиция (диагностическая).** Собственные моды `A` (не ESG): `A = Σ_j μ_j v_j v_jᵀ`, `A_j = Σ_{j'≤j} μ_j v_j v_jᵀ`. Даёт «чистую» модульную картину без P-смешивания; сравнение с ESG-версией показывает, насколько P перепутывает ESG-моды.

**Alignment топ-мод.** `|⟨v_j, u_k⟩|` для `j,k ∈ {1..5}` — насколько топ-моды A совпадают с топ-модами ESG. Если топ-1 A-моды имеют низкий alignment с ESG-модами, P радикально перемешивает базис.

## Подводные камни

1. **P не проектор — усечение не сохраняет диагональ.** `diag(A_r) ≠ diag(A)` для `r<K`. Поэтому `ρ_gf(r)` не «часть ρ_gf», а «ρ_gf усечённого объекта». Кумулятивная кривая — эвристика, а не разложение.
2. **Кросс-члены между модами.** `off²(A) ≠ Σ_k off²(P λ_k u_k u_kᵀ P)`. Разложение неаддитивно. `Δoff²(r)` — приращение, а не вклад; может быть отрицательным при деструктивной интерференции.
3. **unif0 топ-мод сдвигает нуль.** На L6–L18 `u₁` близок к uniform (`unif0 = 0.64–0.80`), `P u₁` мал → `ρ_gf(1)` может быть крошечным. На L23 `unif0 = 0.74`, но топ-мода ESG в E-10a давала `unif0 = 0.50` — расхождение с E-34 уже зафиксировано.
4. **Нуль-модель per-r.** `ρ_null(r)` меняется с `r`, `ρ_gf(r)/ρ_null(r)` — отношение двух кривых. Не интерпретировать `ρ_gf(1)` как «вклад моды 1», это «ρ_gf объекта с одной модой».
5. **Конечный ранг `P ESG P`.** `rank(P) = K−1`, значит rank(A) ≤ K−1. Мода `u_K` (если `P u_K ≠ 0`) может стать нулевой в A. Проверять ранг `A_r` через `μ_j > ε`.
6. **Порог `K=128`.** Не путать с E-35 `r ∈ {1,8,16,32,128}`. E-30 — разложение полного ESG по модам, r — число мод, не размерность подпространства.
7. **Per-sample vs pooled.** Как в E-34: `ρ_gf(r)` считается на каждом сэмпле, агрегируется медианой по сэмплам. Пул ESG до отношения некорректен.

## Что собираем

Per-layer (L6, L12, L18, L22, L23):

- `ρ_gf(r)` для `r ∈ {1, 2, 3, 4, 5, 8, 16, 32, 64, 128}` — медиана и IQR по сэмплам.
- `ρ_gf(r) / ρ_null(r)` — те же точки.
- `Δoff²(r)` для `r ∈ {1..10}` — приращения по модам.
- `PR_modes` — participation ratio приращений.
- `w_r = Δoff²(r) / off²(K)` — профиль распределения.
- Топ-5 `μ_j(A)` vs `λ_k(ESG)` — сравнение спектров.
- `alignment(v_j, u_k)` для `j,k ∈ {1..5}`.
- `unif0(u_k)` для `k ∈ {1..5}` — какие моды близки к uniform (кандидаты на «P убивает»).

## Как

1. Загрузить exp27b dense-кэш (`JR`, `P128`), `{6, 12, 18, 22, 23}`, K=128.
2. Для каждого `(sample, position, layer)`: `ESG = J Jᵀ`, `P = diag(p) − ppᵀ`, eigendecomposition ESG.
3. Для `r ∈ {1..K}`: `A_r = P ESG_r P`, `off²(r)`, `diag_r`, `ρ_gf(r)`.
4. Нуль-модель `ρ_null(r)` — тот же `null_rho_batched`, но на `diag(ESG_r)`.
5. `Δoff²(r)`, `w_r`, `PR_modes`.
6. Собственные моды `A = A_K`, топ-5 `μ_j, v_j`, `alignment(v_j, u_k)`.
7. Per-sample → медиана + IQR.
8. Сохранить `results/exp30_mode_decomposition.json`.

**Стоимость:** ~5–15 минут CPU на слой (128 eigendecomposition `K×K` × 4096 позиций = доминанта). Batched через `torch.linalg.eigh` — секунды. Итого <1 часа на все 5 слоёв.

## Интерпретация

| Паттерн | Что означает | Следствие |
|---|---|---|
| `PR_modes ≤ 5`, `ρ_gf(5)/ρ_gf(128) > 0.7` | cross-talk сосредоточен в топ-2..5 модах ESG | E-32 центральный и **таргетированный**: проверить, что топ-моды Hessian `b` совпадают с этими модами |
| `PR_modes > 15`, кривая растёт линейно по `r` | cross-talk распределён в хвосте | **P1 фундаментально сломана в первом порядке** в слабой форме: защита топ-мод не помогает |
| `ρ_gf(1)/ρ_null(1) ≈ 1`, `ρ_gf(128)/ρ_null(128) > 3` | сигнал живёт в хвосте, топ-моды = чистый шум | readout первого порядка диагонален в топ-модах, но не в хвосте — структура второго порядка |
| `PR_modes` растёт с глубиной (L6 → L23) | распределение cross-talk «размазывается» к выходу | согласуется с ростом `ρ_gf/ρ_null` из E-34 |
| `alignment(v_1, u_1) < 0.5` | P перепутывает базисы | декомпозиция по модам ESG — не декомпозиция A; смотреть вторичную (по модам A) |
| `unif0(u_2..5) ≈ 1`, `unif0(u_1) < 0.8` | не топ-1, а топ-2..5 близки к uniform | P(p) убивает именно их; `ρ_gf` — остаток дифференциальных мод |

## Критерии остановки

- Запуск — **до E-32** (см. порядок ниже).
- Если `PR_modes ≤ 5` и кривая сатурируется до `r=8` → E-32 становится центральным с явной гипотезой «Hessian cross-talk в тех же модах».
- Если `PR_modes > 15` и кривая квазилинейна → E-32 **переопределяется** как «почему хвостовые моды несут cross-talk, если топ диагонален»; приоритет уходит к E-31 и к возможному E-30b (разложение по модам A).
- Если `PR_modes ∈ (5, 15)` → разбить хвост на «средний» (r=6..32) и «дальний» (r>32), сравнить с `ρ_null(r)`.
- Sentinel — тот же протокол, что в E-34 (неактивен на текущем кэше, зафиксировать).
