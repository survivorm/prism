# План реализации: Prism (Якобианов Мост v3.0)

**Среда:** CPU (Intel Iris Xe / SYCL), 64GB RAM, uv + pyproject.toml
**Охват:** P0 (диагностика) + P1 (ESG карта чувствительности)
**Статус:** план к согласованию

---

## Предварительные соображения

- **CPU-режим:** inference и backward pass на CPU в ~10-50x медленнее GPU. Все параметры (|U|, N сэмплов, S длина) подкручены под CPU.
- **RAM:** 64GB shared. Две модели (8B fp16 ~16GB + 0.8B fp16 ~1.6GB) + кэш + градиенты = ~25-35GB. Влезает, но нужно следить за пиковой памятью.
- **|U|:** на GPU paper предлагает 256. На CPU начинаем с 64, масштабируем.
- **N (калибровочных сэмплов):** paper — 32. На CPU — 8 для быстрого прототипа, потом 16-32.
- **S (длина последовательности):** paper — 2048. На CPU — 512 для скорости.

## Этап 2: Вычисление Якобиана (раздел 2.2 paper)

- [ ] 2.1 `jacobian.py`: `compute_jacobian_for_tokens()` — 3-проходная функция
  - Проход 1: префикс → кэш (без последнего токена)
  - Проход 2: полная последовательность → hidden_states
  - Проход 3: h[layer] через remaining layers + кэш → логиты → grad
- [ ] 2.2 Qwen3.5-специфика в проходе 3:
  - MRoPE: `position_ids` формы `[4, 1, 1]`, все компоненты = S-1
  - `rotary_emb(h, position_ids[1:])` для position embeddings
  - `model.config.layer_types` для определения типа слоя (full/linear attention)
  - `mask = None` при seq_len=1 с кэшем
  - Без `use_cache=True` в вызове layer.forward() (см. corrections.md #1)
  - `copy.deepcopy(prefix_cache)` (см. corrections.md #5 — для v1 допустимо)
  - **GDN-кэш:** conv_state + recurrent_state — deepcopy клонирует оба типа (см. corrections.md #2)
- [ ] 2.3 Цикл по token_set для autograd.grad (fallback из paper, медленно на CPU)
  - **CPU-адаптация:** рассмотреть `torch.func.jacrev` для векторизации — на CPU vmap может быть быстрее цикла, т.к. batch-операции используют MKL/OpenBLAS
- [ ] 2.4 Валидация: проверь форму J [|U|, D] на одном сэмпле, одном слое
  - **Ориентировочное время:** |U| × N × время_backward. На CPU, |U|=64, 1 слой, 1 сэмпле: ~2-5 минут (8B модель). Для 0.8B: ~30 секунд.

## Этап 3: Якобианов Мост (раздел 2.3 paper)

- [ ] 3.1 `bridge.py`: `jacobian_bridge(J_L, J_S, E_L, E_S, probs_L)`
  - Проекция: `J_L @ E_L.T` → `[|U|, V]`
  - Обратная проекция: `J_L_projected @ E_S` → `[|U|, D_S]`
  - Косинусное сходство с маскированием (порог τ=1e-6)
  - Взвешивание по вероятностям старшей модели
- [ ] 3.2 Валидация: размерности совпадают, лосс ∈ [0, 1]
  - **Ориентировочное время:** <1 секунда (только матричные операции)

## Этап 7: ESG — Карта чувствительности (раздел 2.5 paper, Цель P1)

- [ ] 7.1 `esg.py`: `compute_esg(model, layer_idx, samples, token_set)`
  - Сбор J для всех сэмплов
  - G = (1/N) Σ J_i @ J_i.T → [|U|, |U|]
  - Спектральное разложение → топ-n_components собственных векторов
- [ ] 7.2 Вычисление ESG для нескольких выбранных слоёв (напр., 0, n/4, n/2, 3n/4, n-1)
  - Для обеих моделей (8B и 0.8B)
- [ ] 7.3 Визуализация: спектры собственных значений (bar chart), первые собственные векторы (heatmap)

## Итоговая оценка времени (CPU!)

| Этап | Задача | Ориентировочно |
| ------ | -------- | ---------------- |
| 0 | Инициализация проекта | 30 мин |
| 1 | Калибровка + загрузка | 30-60 мин (загрузка 8B на CPU) |
| 2 | Якобиан (реализация + отладка) | 3-5 часов |
| 3 | Мост | 30 мин |
| 4 | Эксп 1 (идентичность) | 1-2 часа |
| 5 | Эксп 2 (тепловая карта) | 4-8 часов |
| 6 | Эксп 3, 6, 7 (абляции + бейзлайны) | 5-10 часов |
| 7 | ESG (P1) | 4-8 часов |
| 8 | Эксп 4, 5, 8 (доп. абляции) | 8-16 часов |
| | **Итого** | **~26-52 часа** |

> **Важно:** время сильно зависит от конкретных слоёв и длины последовательности. На CPU 8B модель — это медленно. Можно ускорить:
>
> - `S=256` вместо 512 (в 2x быстрее, в 4x меньше памяти)
> - `N=4` вместо 8 (в 2x быстрее)
> - `|U|=32` вместо 64 (в 2x быстрее, т.к. backward pass |U| раз)
> - Начать с 0.8B → 0.8B для отладки, потом 8B

**Минимальный жизнеспособный путь:** Этапы 0-4 на 0.8B только (3-5 часов). Если Эксп 1 проходит → переходим к 8B.
