## Эксперимент E28. «Листовая структура и локальная кривизна поля»

### Мотивация

Мы знаем (из подтверждённых результатов), что поле $J$ когерентно вдоль траектории одного документа и ортогонально между документами. Но мы не знаем:
1. Где заканчивается лист (есть ли чёткие границы внутри документа).
2. Плоское ли поле $J$ или искривлённое (можно ли глобально тривиализовать).
3. Коррелируют ли границы с синтаксическими особенностями позиций.

Все три вопроса решаются одной связкой метрик на уже посчитанных матрицах.

### Математика

**Объекты на входе** (из кэша):
- Якобианы $J^{(p)}_t \in \mathbb{R}^{K \times D}$ для позиций $t = 1, \ldots, T$ одного документа, для фиксированного слоя $l$ и модели $m$.
- Если кэш содержит несколько слоёв — повторяем для каждого слоя отдельно.

**Шаг 1. Границы листов через главные углы.**

Для каждой пары последовательных позиций $(t, t+1)$:
1. Вычисляем SVD: $J_t = U_t \Sigma_t V_t^T$, $J_{t+1} = U_{t+1} \Sigma_{t+1} V_{t+1}^T$.
2. Берём правые сингулярные векторы $V_t, V_{t+1} \in \mathbb{R}^{D \times r}$ (топ-$r$ сингулярных чисел, где $r$ — эффективный ранг, например $r = 16$ или $r = 32$).
3. Считаем матрицу перекрытия: $M_t = V_t^T V_{t+1} \in \mathbb{R}^{r \times r}$.
4. Сингулярные числа $\sigma_i(M_t)$ дают косинусы главных углов: $\theta_i(t) = \arccos(\sigma_i(M_t))$.
5. Метрика разрыва: $\Delta_{\text{SVD}}(t) = \max_i \theta_i(t)$ или $\|\theta\|_2$.

Если $\Delta_{\text{SVD}}(t)$ мал (< порога) — мы внутри листа. Если скачок — граница.

**Шаг 2. Локальная кривизна через тройки позиций.**

Для каждой тройки $(t, t+1, t+2)$:
1. Вычисляем Procrustes-выравнивание между последовательными парами:
   $$R_{12} = \arg\min_{R \in O(D)} \|V_{t+1} - V_t R\|_F$$
   $$R_{23} = \arg\min_{R \in O(D)} \|V_{t+2} - V_{t+1} R\|_F$$
   $$R_{13} = \arg\min_{R \in O(D)} \|V_{t+2} - V_t R\|_F$$
2. Голономия цикла: $H_t = R_{12} R_{23} R_{13}^{-1}$.
3. Кривизна: $\kappa(t) = \|H_t - I\|_F$.

Если $\kappa(t) \approx 0$ для всех $t$ — поле локально плоское. Если $\kappa$ систематически ненулевая — поле искривлено.

**Шаг 3. Корреляция с позицией.**

Строим профиль $\Delta_{\text{SVD}}(t)$ и $\kappa(t)$ вдоль последовательности. Ищем пики. Сопоставляем пики с:
- Типом токена (пунктуация, конец строки, спецтокены — если есть в кэше).
- Относительной позицией в документе (начало / середина / конец).
- Если есть разметка домена — с границами доменных блоков.

### Краевые условия и подводные камни

1. **Выбор ранга $r$.** Эффективный ранг может быть мал (4–8). Если взять $r = D$ (полный), шумовые малые сингулярные числа дадут ложные разрывы. Берём $r$ по порогу: $\sum_{i=1}^r \sigma_i^2 / \sum_{i=1}^D \sigma_i^2 > 0.99$. Или фиксируем $r = 16$ и проверяем устойчивость при $r = 8, 32$.

2. **Знак сингулярных векторов.** SVD не уникален по знаку столбцов $V$. Procrustes должен быть инвариантен к знакам (он и есть, если $V_t^T V_{t+1}$ считается корректно). Но если в реализации SVD знаки прыгают случайно, $\Delta_{\text{SVD}}$ может дать ложные пики. Нужно убедиться, что используется согласованный SVD (например, фиксировать знак по первому ненулевому элементу каждого столбца).

3. **Вырожденные случаи.** Если на какой-то позиции $\text{rank}(J_t) < r$ (матрица вырождена), SVD даст нулевые сингулярные числа и неопределённые векторы. Такие позиции нужно либо пропускать, либо дополнять до ранга $r$ нулями.

4. **Размерность моделей.** Если сравниваем 4B и 0.8B, у них разное $D$. Procrustes между моделями невозможен без выравнивания. В этом эксперименте мы работаем внутри одной модели — разный $D$ не проблема.

5. **Кривизна через тройки требует минимума 3 позиций.** На границах документа ($t = 1$ и $t = T-1$) кривизна не определена. Это нормально — просто не считаем на краях.

### Тонкости ТЗ

- «Граница листа» — это не абсолютное значение $\Delta_{\text{SVD}}$, а **относительный скачок** по сравнению с медианным уровнем внутри документа. Порог: $\Delta_{\text{SVD}}(t) > \text{median} + 2 \cdot \text{MAD}$.
- «Плоское поле» означает $\kappa(t) < 10^{-3}$ для всех $t$ (с учётом численного шума). Если $\kappa$ порядка $10^{-2}$–$10^{-1}$ — поле искривлено.
- Не путать левые ($U$) и правые ($V$) сингулярные векторы. Поле $J$ живёт в скрытом пространстве → правые векторы $V$ описывают геометрию скрытого пространства. Левые векторы $U$ описывают токенное пространство. Для геометрии скрытого состояния берём $V$.

### Выход

- Профиль $\Delta_{\text{SVD}}(t)$ для каждого документа и слоя.
- Профиль $\kappa(t)$.
- Список позиций-границ (пики $\Delta_{\text{SVD}}$).
- Сводная таблица: среднее $\kappa$ по документу, доля позиций с $\kappa > 10^{-3}$.

  Если кэш содержит несколько слоёв и моделей — запускаем для каждой комбинации (слой, модель) отдельно. Это даст карту: как листовая структура и кривизна меняются по глубине и между масштабами.
