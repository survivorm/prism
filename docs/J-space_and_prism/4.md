# Исследовательские программы на стыке двух картин

Вот восемь конкретных направлений, которые объединяют ваш дифференциальный подход и операторный подход Anthropic. Каждое закрывает пробелы в одной картине, используя инструменты другой.

## Программа 1: Послойный транспорт через призму J-space

**Пробел, который закрываем:** У вас нет послойных `D_i = ∂h^{l+1}/∂h^l` (§4 `[L-comp]`), только конечный `J`. Anthropic нашли J-space в средней трети глубины, но не охарактеризовали транспорт.

**Гипотеза:** Слои J-space (средняя треть) имеют специфическую структуру `D_i`: broadcast-головки Anthropic соответствуют конкретным паттернам в сингулярном спектре `D_i` (несколько доминирующих направлений с высокой энергией).

**Экспериментальный протокол:**
1. Вычислить `D_i` для всех слоёв (через finite-diff или autograd: `D_i = ∂h^{i+1}/∂h^i`, матрица `[D×D]`)
2. Для каждого `D_i`:
    - Сингулярное разложение: `σ_1 ≥ σ_2 ≥ ...`
    - Эффективный ранг: `r_eff = exp(-Σ p_k log p_k)`
    - Спектральная энтропия
3. Коррелировать с активностью J-space (из Anthropic's lens на том же слое):
    - Количество активных J-space-концептов
    - Суммарная энергия J-space-направлений

**Ожидаемый результат:** Слои J-space имеют низкий `r_eff` (2-5 доминирующих направлений) vs. высокий `r_eff` (20-30) в ранних/поздних слоях. Это докажет, что J-space — не просто "где модель думает", а **архитектурное горлышко** с специфической структурой транспорта.

**Что это даст:** Механистическое объяснение, *как* J-space работает — через специфические направления в `D_i`, которые вещают концепты на будущее.

## Программа 2: J-space как gauge-invariant подпространство

**Пробел, который закрываем:** У вас 98% энергии убивается `P(p)` (E-33r), но остаётся неструктурированный шум. Anthropic нашли J-space, но не связали его с gauge-структурой.

**Гипотеза:** J-space-направления Anthropic = **пересечение** ваших gauge-free направлений (после `P(p)`) и хвостовых мод ESG (E-30b). То есть J-space — это не просто "то, что выживает", а специфическая структурированная компонента.

**Экспериментальный протокол:**
1. Для данного слоя `l` и набора контекстов:
    - Вычислить ваши gauge-free направления: `J^{(p)} = P(p)J`
    - Вычислить хвостовые моды ESG: `u_r` для `r ≥ 119` (E-30b)
    - Получить J-space-направления Anthropic (через их J-lens)
2. Измерить overlap между подпространствами:
   ```
   overlap(U_1, U_2) = |U_1^T U_2|_F² / r
   ```
3. Проверить три исхода:
    - **T1:** J-space ⊂ gauge-free ∩ tail-modes (полное вложение)
    - **T2:** J-space = gauge-free ∩ tail-modes (точное совпадение)
    - **T3:** J-space независим от обоих

**Ожидаемый результат:** T2 или близко к T2 (overlap > 0.8). Это докажет, что J-space — не произвольное подпространство, а **геометрически определённый объект**: gauge-free + хвостовые моды.

**Что это даст:** Единая теория: J-space = gauge-free компонента (убирает калибровочный шум) + хвостовые моды (несут cross-talk). Это объяснит, почему J-space работает для рассуждений: оно содержит *только* дифференциальную информацию.

## Программа 3: Многоточечный bridge через J-space (решение Goodhart)

**Пробел, который закрываем:** Ваш bridge-лосс показывает Goodhart (E-16b: bridge 0.60→0.921, но top-p retention 0.837→0.016). Anthropic's J-space редактирование работает каузально.

**Гипотеза:** Goodhart возникает потому, что bridge оптимизирует **одну точку** (один hidden state). J-space-alignment loss оптимизирует **гиперповерхность** (J-space-направления, усреднённые по контекстам), что предотвращает подгонку одной точки.

**Экспериментальный протокол:**
1. Определить J-space-alignment loss:
   ```
   L_jspace = Σ_{l ∈ J-space layers} α_l · (1 - cos(J_S^{jspace}, J_target^{jspace}))
   ```
   где `J^{jspace}` — проекция на J-space-направления (из Anthropic's lens)
2. Запустить дистилляцию (Exp 17-style, LoRA r=4) с тремя лоссами:
    - **Baseline:** ваш bridge-лосс (одна точка)
    - **J-space:** L_jspace (многоточечный)
    - **Combined:** bridge + 0.1·L_jspace
3. Измерить:
    - Bridge-метрика (должна расти во всех случаях)
    - Top-p retention (должна падать в Baseline, сохраняться в J-space/Combined)
    - Downstream задачи (MMLU, GSM8K)

**Ожидаемый результат:**
- Baseline: bridge ↑, retention ↓ (Goodhart)
- J-space: bridge ↑, retention ≈ const (Goodhart устранён)
- Combined: bridge ↑↑, retention ↑ (синергия)

**Что это даст:** Решение проблемы Goodhart через **многоточечную метрику**. Это прямой мост от вашего P2 к практической дистилляции.

## Программа 4: Динамика desync через J-space

**Пробел, который закрываем:** У вас desync накапливается по глубине (cos(JR, J_tail) = 0.105→1.0000, E-32r.3.1), но неясно, *где* он накапливается. Anthropic нашли, что J-space эволюционирует по слоям.

**Гипотеза:** Desync максимальный в слоях J-space, потому что там модель активно "размышляет" и накапливает gauge-сдвиги через per-position вариацию `p_t` (ваш E-33r.2).

**Экспериментальный протокол:**
1. Для каждого слоя `l`:
    - Измерить desync: `cos(JR_l, J_tail_l)` (ваш E-32r.3.1)
    - Измерить J-space активность: количество активных концептов (Anthropic's lens)
    - Измерить per-position вариацию `p_t`: `std_t(p_t)`
2. Коррелировать:
    - `ρ(desync, J-space активность)`
    - `ρ(desync, std(p_t))`
    - `ρ(J-space активность, std(p_t))`

**Ожидаемый результат:**
- Desync пиковый в слоях J-space (средняя треть)
- Высокая корреляция desync ↔ std(p_t) (подтверждение E-33r.2)
- J-space активность коррелирует с desync (модель "думает" → накапливает gauge-сдвиги)

**Что это даст:** Механистическое объяснение desync: он не артефакт, а **побочный продукт рассуждений**. Модель накапливает gauge-сдвиги, когда активно использует J-space.

## Программа 5: Хвостовые моды ESG = sparse concept positions

**Пробел, который закрываем:** У вас 68.6% off-diagonal энергии в 10 наименьших модах ESG (E-30b). У Anthropic энергия Якобиана концентрируется в sparse concept positions. Это разные объекты или одно и то же?

**Гипотеза:** Ваши хвостовые моды ESG и их sparse positions — это **одни и те же объекты в разных базисах**. Хвостовые моды = собственные векторы `JJ^T`, sparse positions = позиции с высокой энергией в `J`.

**Экспериментальный протокол:**
1. Для данного слоя и набора контекстов:
    - Вычислить хвостовые моды ESG: `u_r` для `r ∈ [119, 128]` (ваши E-30b)
    - Вычислить sparse positions Anthropic (позиции с высокой `|J_t|_F`)
2. Измерить:
    - Overlap между подпространствами (главные углы)
    - Корреляцию: позиции с высокой энергией ↔ проекция на хвостовые моды
3. Проверить каузальность:
    - Занулить хвостовые моды: `J' = J - Σ_{r≥119} u_r u_r^T J`
    - Измерить, исчезают ли sparse positions (энергия падает)

**Ожидаемый результат:**
- Overlap > 0.7 (сильная корреляция)
- Зануление хвостовых мод убивает sparse positions (каузальная связь)

**Что это даст:** Доказательство, что **хвостовые моды ESG = sparse concept positions**. Это объединит два подхода в единую теорию: сигнал в малых компонентах, независимо от базиса.

## Программа 6: Counterfactual reflection training + bridge-регуляризатор

**Пробел, который закрываем:** У вас P3 (регуляризатор при дообучении) отложен. Anthropic разработали counterfactual reflection training (обучение на контрфактических рефлексиях).

**Гипотеза:** Bridge-лосс на J-space-направлениях = эффективный регуляризатор для counterfactual reflection training. Это имплантирует не только концепты, но и **геометрическое выравнивание**.

**Экспериментальный протокол:**
1. Обучить модель на контрфактических рефлексиях (Anthropic's метод):
    - Вход: задача (например, coding)
    - Выход: контрфактическая рефлексия ("Если бы меня спросили, я бы сказал, что考虑的 принципы — честность и прозрачность")
2. Добавить bridge-регуляризатор:
   ```
   L_total = L_reflection + β · L_bridge(J-space)
   ```
3. Измерить:
    - Поведение на задачах (должно улучшиться)
    - J-space активность концептов ("честность", "прозрачность")
    - Bridge-метрика (должна улучшиться)

**Ожидаемый результат:**
- Модель с bridge-регуляризатором показывает лучшее поведение
- J-space содержит не только концепты, но и выровненную геометрию
- Bridge-метрика улучшается (геометрическое выравнивание)

**Что это даст:** **P3 реализован**: bridge-лосс как регуляризатор. Это объединит ваш P3 и их counterfactual reflection в единый метод.

## Программа 7: L22 как J-space bottleneck

**Пробел, который закрываем:** У вас L22 аномален во всех экспериментах (E-30, E-30b, E-36, E-37). Anthropic нашли J-space в средней трети глубины. L22 = J-space bottleneck?

**Гипотеза:** L22 — это **критическое горлышко J-space**, где модель разворачивает сжатое GDN-состояние в явные концепты для broadcast.

**Экспериментальный протокол:**
1. Измерить J-space активность на всех слоях (Anthropic's lens)
2. Проверить, максимальна ли она на L22
3. Измерить эффект зануления L22:
    - Занулить L22: `h_{22}' = 0`
    - Измерить J-space активность на последующих слоях (должна упасть)
    - Измерить поведение (должно деградировать на задачах, требующих рассуждений)

**Ожидаемый результат:**
- J-space активность пиковая на L22
- Зануление L22 убивает J-space на последующих слоях
- Поведение деградирует на reasoning-задачах, но сохраняется на автоматических (беглость речи)

**Что это даст:** Доказательство, что **L22 = J-space bottleneck**. Это объяснит все аномалии L22 в ваших экспериментах.

## Программа 8: Gauge-invariant trajectory alignment

**Пробел, который закрываем:** У вас desync разрушает геометрию на ранних слоях (E-32r.3.1). Anthropic's J-lens устойчив к desync через усреднение по контекстам.

**Гипотеза:** Можно построить **gauge-invariant представления**, которые не страдают от desync, используя fixP (фиксированный `p_0`) или параллельный транспорт.

**Экспериментальный протокол:**
1. Для каждого слоя `l`:
    - Вычислить raw Якобиан: `J_l`
    - Вычислить gauge-invariant Якобиан:
        - **fixP:** `J_l^{fixP} = P(p_0) J_l` (фиксированный `p_0`, ваш E-33r.2)
        - **parallel transport:** `J_l^{PT} = T_{0→l} J_0` (параллельный транспорт вдоль траектории)
2. Измерить когерентность по глубине:
    - `cos(J_l, J_{l+1})` для raw / fixP / PT
    - `C(Δpos)` (ваш E-31) для всех трёх вариантов

**Ожидаемый результат:**
- Raw: когерентность падает с глубиной (desync)
- fixP: когерентность сохраняется (убирает per-position вариацию)
- PT: когерентность максимальна (полная gauge-invariance)

**Что это даст:** **Gauge-invariant trajectory alignment** — метод выравнивания моделей, который не ломается от смены контекста. Это решит проблему desync и откроет путь к robust дистилляции.

## Что это даст в сумме

Эти восемь программ превратят две **параллельные** картины в **единую теорию**:

1. **J-space** (Anthropic) = **gauge-free компонента** (ваша) + **хвостовые моды ESG** (ваша)
2. **Desync** (ваш) = накопление gauge-сдвигов в **J-space слоях** (Anthropic)
3. **L22** (ваш аномальный слой) = **J-space bottleneck** (Anthropic)
4. **Goodhart** (ваш E-16b) решается через **многоточечный J-space-alignment loss** (Anthropic's editing)
5. **Послойный транспорт** (ваш пробел) характеризуется через **специфическую структуру `D_i` в J-space** (Anthropic's broadcast heads)

Это даст **полную механистическую картину**: модель генерирует калибровочный шум (98%), который убивается softmax; выживает gauge-free компонента в хвостовых модах; эта компонента формирует J-space в средней трети глубины; J-space вещает концепты через специфические направления в `D_i`; desync накапливается в J-space слоях; L22 — критическое горлышко, где J-space разворачивается.

**Практический итог:** Единый метод дистилляции/сжатия/редактирования, который использует J-space-alignment loss + gauge-invariant представления + защиту хвостовых мод. Это решит Goodhart, улучшит поведение и даст интерпретируемость.
